# 机器学习任务 · 自测

> **对应材料**：`machine_learning_tasks/`（判别 / 生成 / 表征 / 强化学习四大类，每个任务都有 `.md` + `train_*.py`）
> **纪律**：代码题合上 `train_*.py`，口述模型结构 + loss + 数据流；并反思"你的脚本用合成随机数据，模型真的学到东西了吗"。

## 判别任务

- 分类（ResNet）：残差连接为什么让深层可训？你的 `train_resnet.py` 用了什么数据，loss 真的下降了吗？
- 回归（MLP）：为什么回归用 MSE、分类用交叉熵？MSE 配 sigmoid 输出有什么梯度问题（饱和 + 慢收敛）？
- 目标检测（Faster R-CNN）：RPN 做什么？anchor 和 RoI pooling 各解决什么？两阶段 vs 一阶段（YOLO）trade-off？
- 语义分割（U-Net）：skip connection 为什么对分割关键？encoder-decoder 的下/上采样各保留什么？
- 实例分割（Mask R-CNN）：相比 Faster R-CNN 多了什么分支？RoIAlign 相比 RoIPool 解决了什么（量化误差）？
- 合上 `train_unet.py` / `train_resnet.py`，口述网络结构和前向 shape 流。

## 无条件生成

- GAN 的 min-max 博弈？模式崩塌是什么？为什么 GAN 难训（不稳定）？
- VAE 的 ELBO 推导？重参数化技巧为什么需要？KL 项的作用（正则 latent 趋近先验）？
- DDPM：前向 q 和反向 p 各是什么？为什么预测噪声 ε 而非 x_0？β 方差表怎么设（linear / cosine）？
- Flow Matching 相比 DDPM 的优势（ODE vs SDE、更直的轨迹、单步采样潜力）？
- 合上 `train_ddpm.py` / `train_VAE.py` / `train_GAN.py`，口述各自的 loss。

## 条件生成

- CGAN / CVAE / conditional DDPM / DIT 怎么把条件注入模型？
- classifier-free guidance 原理？训练时怎么混有条件 / 无条件、推理时怎么外推？
- conditional Drifting / Flow Matching 和无条件版本的区别？
- 合上 `train_conditional_ddpm.py`，口述条件怎么进入网络。

## 表征学习

- BERT MLM：为什么 mask 15% 且按 80/10/10 拆分（mask / 随机 / 保持）？
- SimCLR：对比 loss（InfoNCE）？数据增强为什么关键？projection head 为什么训练用、下游不用？
- CLIP：见多模态域。
- Next-token（GPT）：见架构域 / 从零训练域。
- 合上 `train_bert_mlm.py` / `train_simclr.py`，口述 loss 计算。

## 序列生成

- Seq2Seq 的 encoder-decoder attention 怎么对齐？teacher forcing 是什么？
- Transformer（见架构域）。
- Mamba 的 SSM 选择性机制？相比 Transformer 的线性复杂度优势怎么来的？为什么能处理长序列？
- 合上 `train_seq2seq.py` / `train_mamba.py`，口述前向流程。

## 强化 / 模仿

- PPO（见强化学习域）。
- 行为克隆（BC）：为什么会产生 compounding error（小错误累积）？DAgger 怎么解决（在线纠偏）？
- 合上 `train_bc.py`，口述 BC 的 loss 和训练流程。

## 反思（每个任务都问自己）

- 你的 `train_*.py` 用 `torch.randint` 合成随机数据，模型能学到任何结构吗？这验证了"机制对"还是"模型会学"？
- 怎么改成用真数据（MNIST / CIFAR）让 loss 真正下降、产出可见结果？
- 哪些任务你只是"照着模板填"，哪些是你真正理解了 loss 和结构的设计？
