# 欢迎体验Anthropic的交互式提示工程教程 - Bedrock版

## 课程介绍与目标

本课程旨在为您提供在Bedrock中使用Claude进行最佳提示工程的全面、循序渐进的理解。

**完成本课程后，您将能够**：
- 掌握优秀提示的基本结构
- 识别常见的失败模式，并学习解决这些问题的“80/20”技术
- 了解Claude的优点与局限性
- 从零开始为常见用例构建强大的提示

## 课程结构与内容

本课程结构旨在为您提供多次练习编写和调试提示的机会。课程分为**9个章节，附带相关练习**，以及一个包含更高级方法的附录。建议您**按章节顺序学习课程**。

**每个课程下方都有一个“示例操场”区域**，您可以在此自由试验课程中的示例，观察更改提示如何影响Claude的响应。此外，还有一个[答案密钥](https://docs.google.com/spreadsheets/d/1jIxjzUWG-6xBVIa2ay6yDpLyeuOh_hR_ZB75a47KX_E/edit?usp=sharing)。虽然该答案密钥是为1P API请求设计的，但解决方案是相同的。

注意：本教程使用的是我们最小、最快且最经济的模型Claude 3 Haiku。Anthropic还有[另外两个模型](https://docs.anthropic.com/claude/docs/models-overview)，即Claude 3 Sonnet和Claude 3 Opus，它们比Haiku更智能，其中Opus是最智能的模型。

准备好开始时，请前往`01_基本提示结构`继续。
