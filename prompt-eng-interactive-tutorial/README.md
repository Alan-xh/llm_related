# 欢迎体验Anthropic的提示工程交互教程

## 课程介绍与目标

本课程旨在为您提供全面的、循序渐进的指导，帮助您掌握如何为Claude设计最佳提示。

**完成本课程后，您将能够**：
- 掌握优秀提示的基本结构
- 识别常见的失败模式，并学习“80/20”技巧来解决它们
- 了解Claude的优点与局限性
- 从头开始为常见用例构建强大的提示

## 课程结构与内容

本课程设计了多个实践机会，让您亲自练习编写和调试提示。课程分为**9个章节，附带相应练习**，以及一个包含更高级方法的附录。建议您**按章节顺序学习课程**。

**每个课程下方都有一个“示例 playground”区域**，您可以自由实验课程中的示例，观察修改提示如何改变Claude的回应。此外，还有一个[答案密钥](https://docs.google.com/spreadsheets/d/1jIxjzUWG-6xBVIa2ay6yDpLyeuOh_hR_ZB75a47KX_E/edit?usp=sharing)。

注意：本教程使用我们最小、最快、成本最低的模型Claude 3 Haiku。Anthropic还有[另外两个模型](https://docs.anthropic.com/claude/docs/models-overview)，Claude 3 Sonnet和Claude 3 Opus，它们比Haiku更智能，其中Opus是最智能的。

*本教程还以[Google Sheets使用Anthropic的Claude for Sheets扩展](https://docs.google.com/spreadsheets/d/19jzLgRruG9kjUQNKtCg1ZjdD6l6weA6qRXG5zLIAhC8/edit?usp=sharing)的形式存在。我们推荐使用该版本，因为它更用户友好。*

准备好开始时，请前往`01_基本提示结构`继续。
