# Word2Vec 技术详解文档

**文档版本：** V1.0\
**更新日期：** 2026年7月12日\
**摘要：** 本文档全面解析了 Word2Vec 算法的核心思想、两种模型架构（CBOW与Skip-gram）的训练细节、网络结构，并深入探讨了其与现代 Embedding 模型及 Transformer 架构的本质区别。

---

## 1. Word2Vec 概述

Word2Vec 是谷歌在2013年提出的一种用于生成 **词向量（Word Embedding）** 的浅层神经网络模型。其核心思想是：**通过上下文环境来学习词的稠密向量表示**，使得语义相近的词在向量空间中距离更近。

---

## 2. 两种核心模型架构：CBOW 与 Skip-gram

Word2Vec 包含两种不同的训练架构（模型），它们的训练目标正好相反。

| 对比维度 | **Skip-gram** | **CBOW (连续词袋模型)** |
| :--- | :--- | :--- |
| **核心思路** | 用**中心词**来预测**上下文**（周围的词） | 用**上下文**（周围的词）来预测**中心词** |
| **输入/输出** | 输入是目标词，输出是其上下文窗口内的词 | 输入是上下文多个词的向量之和/平均，输出是中心词 |
| **训练速度** | 较慢（对每个中心词，需预测多个上下文词） | **更快**（每个训练样本只更新一次） |
| **擅长任务** | **语义**任务更好，更能捕捉罕见词的特性 | **句法**任务表现更好，对常用词学习更佳 |
| **对罕见词影响** | 罕见词作为中心词时会被反复“特训”，向量质量高 | 罕见词作为上下文时容易被常见词“淹没” |

> **选择建议：**
> -   **语料庞大、注重语义（特别是罕见词）** → 选择 **Skip-gram**。
> -   **追求训练速度、语料较小或注重句法结构** → 选择 **CBOW**。
> *注：有研究指出，修正了开源库（如Gensim）中CBOW的梯度更新错误后，其性能可与Skip-gram媲美。*

## 3. 模型训练过程详解

### 3.1 训练任务与架构归属
-   **训练任务（目标问题）**：CBOW是“完形填空”，Skip-gram是“根据词语联想上下文”。
-   **模型架构（网络结构）**：因为任务相反，两者的输入/输出层结构完全不同。
-   **算法家族**：两者统称为 **Word2Vec** 算法工具包中的两种模式。

### 3.2 训练流程对比

#### （1）Skip-gram 训练流程（从1到多）
1.  **构造样本**：对于句子“我/喜欢/吃/苹果”，中心词“吃”会生成样本：(吃, 喜欢)、(吃, 我)、(吃, 苹果)等。
2.  **前向传播**：输入“吃”的One-hot编码，经隐藏层得到词向量，再由输出层Softmax输出概率分布。
3.  **计算损失**：计算预测词（如“喜欢”）与真实上下文词的交叉熵损失。
4.  **反向传播**：**针对每一个输出词分别计算梯度并累加**，最后统一更新1次隐藏层权重。

#### （2）CBOW 训练流程（从多到1）
1.  **构造样本**：对于同样的句子，输入为上下文(“喜欢”, “苹果”)，输出为中心词(“吃”)，**只形成1条样本**。
2.  **前向传播**：将上下文的One-hot编码传入，在隐藏层**将这两个词的向量相加并求平均**，得到“平均上下文向量”。
3.  **计算损失**：用平均向量预测中心词，计算交叉熵损失。
4.  **反向传播**：因为只有1个输出词，误差信号会**同时反推并更新“喜欢”和“苹果”两个输入词的权重**。

### 3.3 训练加速技巧
在实际训练中，为了应对海量词汇的Softmax计算压力，通常采用以下两种技术：
1.  **Hierarchical Softmax（层次Softmax）**：将输出层替换为一棵霍夫曼二叉树，将计算复杂度从 `O(V)` 降至 `O(log V)`。
2.  **Negative Sampling（负采样）**：将多分类问题简化为二分类问题，每次仅更新正样本和少量采样的负样本。

## 4. 网络结构与本质剖析

### 4.1 网络骨架（两者共用）
-   **输入层**：维度 `V`（词典大小）。
-   **隐藏层**：维度 `N`（词向量维度），其权重矩阵 `W1` 即为词向量查找表。
-   **输出层**：维度 `V`（输出概率分布）。
-   **核心思想**：训练完成后，我们丢弃输出层，**直接提取隐藏层的权重矩阵 `W1`（形状 V×N）** 作为词向量。

### 4.2 数据流差异
-   **CBOW**：隐藏层对多个输入词向量**取平均**，然后预测1个输出词。
-   **Skip-gram**：隐藏层直接使用1个输入词向量，在输出层**重复计算**以预测多个上下文词。

## 5. Word2Vec 与现代 RAG Embedding / Transformer 的区别

随着深度学习的发展，Word2Vec 已被更先进的模型取代。以下是核心区别：

| 对比维度 | **Word2Vec** | **RAG 句子 Embedding / 现代Transformer** |
| :--- | :--- | :--- |
| **能力层级** | 词义（Word Level） | 句意/篇章语义（Sentence/Document Level） |
| **是否动态** | ❌ **静态**。多义词无法区分（如“苹果”永远是一个向量）。 | ✅ **动态/上下文相关**。根据上下文动态生成向量（如“苹果手机”与“吃苹果”区分）。 |
| **网络深度** | 浅层（1层隐藏层） | 深层（12层+ Transformer） |
| **训练目标** | 预测相邻词（共现统计） | 对比学习 / 语义相似度（拉近相关文本，推远无关文本） |
| **处理语序** | 丢失语序（简单平均） | 完全保留语序（通过自注意力机制） |
| **RAG检索效果** | 差（字面匹配，易漏召回） | 极佳（语义匹配，泛化性强） |

## 6. 实践建议：Transformer 训练时是否使用 Word2Vec？

**结论：当前训练Transformer网络时，不再使用预训练的Word2Vec向量作为输入嵌入层的初始化。**

### 6.1 不推荐的原因
1.  **静态 vs. 动态矛盾**：Word2Vec的静态向量无法解决多义词问题，与Transformer的动态语义能力冲突。
2.  **数值分布不匹配**：研究指出，直接使用Word2Vec预训练向量（如GloVe）初始化Transformer，效果有时甚至不如**随机初始化**（使用Xavier等初始化方法），因为分布不匹配会导致梯度不稳定。
3.  **分工不同**：现在的`Tokenizer`只负责切分文本并转为数字ID，而`Embedding层`（`nn.Embedding`）是一个可训练的网络层。

### 6.2 当前的标准做法：端到端训练
1.  **随机初始化**：模型的`Embedding层`及所有Transformer层均使用随机值初始化。
2.  **联合训练**：在大规模语料上训练时，`Embedding层`的向量会随整个网络参数一起通过反向传播不断优化。
3.  **自然适配**：经过充分训练后，模型学到的向量是**上下文相关**且**为当前任务优化的**，效果远超静态的Word2Vec向量。
