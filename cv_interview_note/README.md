# CV 相关知识及面试题

## 简介

本仓库为**计算机视觉（Computer Vision）**面试相关概念，参考 `llm_interview_note` 的结构与详细程度整理，覆盖从传统图像处理到现代多模态大视觉模型的核心知识点。如果对你有用，麻烦点一下 `star`，谢谢！

本仓库与 [llm_interview_note](../llm_interview_note) 为姊妹仓库，前者侧重于 NLP / LLM，本仓库侧重于 CV / 视觉大模型，二者共享部分基础（如 Transformer、分布式训练、损失函数等），可结合阅读。

## 在线阅读

可使用 docsify 在本地启动在线阅读：

```bash
# 全局安装 docsify-cli
npm i docsify-cli -g
# 在仓库根目录启动
docsify serve cv_interview_note
# 浏览器访问 http://localhost:3000
```

## 注意

- 相关答案为本人参考网络资源、论文、官方文档整理撰写，若有不合理地方，欢迎指出修正；
- 图片部分采用文字描述 + 公式 + 流程图（mermaid / ASCII）的形式呈现，便于在无图环境下阅读；
- 涉及代码片段以 PyTorch 为主，必要处会给出对应论文链接。
