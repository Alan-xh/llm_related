# 6.归一化

## 1.概述

**归一化（Normalization）** 是深度网络训练稳定的关键技术。CV 中常用 **BatchNorm、GroupNorm、LayerNorm、InstanceNorm** 等，每种归一化有不同的统计维度和适用场景。理解各种归一化的原理对训练稳定、迁移学习、小 batch 训练至关重要。

## 2.为什么需要归一化？

### 2.1 内部协变量偏移（Internal Covariate Shift）

- 每层输入分布随训练变化；
- 后层需要不断适应新分布；
- 训练慢且不稳；
- **BN 论文最初动机**：固定每层输入分布。

### 2.2 实际原因（后续研究）

- BN 真正起作用的原因是**让损失地形更平滑**（Santurkar et al., 2018）；
- 梯度更稳定、可信；
- 允许更大学习率。

### 2.3 归一化的好处

1. 训练更稳；
2. 允许大学习率；
3. 加速收敛；
4. 缓解梯度消失/爆炸；
5. 一定正则化效果（BN）。

## 3.归一化的维度

对于 4D 张量 $(N, C, H, W)$：

| 归一化 | 统计维度 | 公式中的轴 |
| --- | --- | --- |
| **BatchNorm** | $(N, H, W)$ per channel | N, H, W |
| **LayerNorm** | $(C, H, W)$ per sample | C, H, W |
| **InstanceNorm** | $(H, W)$ per sample per channel | H, W |
| **GroupNorm** | $(C/G, H, W)$ per sample | C/G 组, H, W |

可视化（$\mu, \sigma$ 计算范围）：

```
BatchNorm        LayerNorm        InstanceNorm     GroupNorm
(N,H,W) per C    (C,H,W) per N    (H,W) per N,C    (C/G,H,W) per N

  C C C             N N N            N N N           N N N
N ■ ■ ■          C ■ ■ ■          C ■ □ □         C ■ ■ □
  ■ ■ ■            ■ ■ ■            ■ □ □         C ■ ■ □
  ■ ■ ■            ■ ■ ■            ■ □ □         C □ □ ■
                                                     □ □ ■
```

## 4.BatchNorm（BN）

### 4.1 原理

**论文**：Batch Normalization (Ioffe & Szegedy, 2015)

对每个通道在 $(N, H, W)$ 维度计算均值方差：

$$
\mu_c = \frac{1}{NHW} \sum_{n, h, w} x_{n,c,h,w} \\
\sigma_c^2 = \frac{1}{NHW} \sum_{n, h, w} (x_{n,c,h,w} - \mu_c)^2 \\
\hat{x} = \frac{x - \mu_c}{\sqrt{\sigma_c^2 + \epsilon}} \\
y = \gamma \hat{x} + \beta
$$

$\gamma, \beta$ 是可学习的缩放和平移参数。

### 4.2 训练 vs 推理

**训练**：用当前 batch 的统计量；

**推理**：用训练累积的**滑动平均**统计量：

```python
running_mean = momentum * running_mean + (1 - momentum) * batch_mean
running_var = momentum * running_var + (1 - momentum) * batch_var
```

推理时用 `running_mean, running_var`，**不依赖 batch**。

### 4.3 优点

1. **训练稳定**：固定每层输入分布；
2. **加速收敛**：可用大学习率；
3. **正则化**：batch 内统计扰动有正则效果；
4. **CV 标配**：ResNet、MobileNet 等都用。

### 4.4 缺点

1. **依赖 batch size**：小 batch 时统计不准，效果差；
2. **训练/推理不一致**：训练用 batch，推理用累积统计；
3. **分布式需 SyncBN**：跨卡同步统计；
4. **不适合 RNN/Transformer**：序列长度变化。

### 4.5 代码

```python
nn.BatchNorm2d(num_features, eps=1e-5, momentum=0.1, affine=True,
               track_running_stats=True)
```

## 5.LayerNorm（LN）

### 5.1 原理

对每个样本在 $(C, H, W)$ 维度计算均值方差：

$$
\mu_n = \frac{1}{CHW} \sum_{c, h, w} x_{n,c,h,w} \\
\hat{x} = \frac{x - \mu_n}{\sqrt{\sigma_n^2 + \epsilon}} \\
y = \gamma \hat{x} + \beta
$$

### 5.2 优点

1. **不依赖 batch size**：每样本独立；
2. **训练/推理一致**：用同样公式；
3. **适合序列数据**：RNN、Transformer 标配；
4. **ViT 默认**：替代 BN。

### 5.3 缺点

1. **在 CNN 上效果不如 BN**：通道间归一化破坏特征差异；
2. **计算量略大**。

### 5.4 代码

```python
nn.LayerNorm(normalized_shape, eps=1e-5, elementwise_affine=True)
# 在 ViT 中：
# x: (B, N, D), 在 D 维归一化
nn.LayerNorm(embed_dim)
```

## 6.InstanceNorm（IN）

### 6.1 原理

对每个样本每个通道在 $(H, W)$ 维度归一化：

$$
\mu_{n,c} = \frac{1}{HW} \sum_{h, w} x_{n,c,h,w} \\
\hat{x} = \frac{x - \mu_{n,c}}{\sqrt{\sigma_{n,c}^2 + \epsilon}}
$$

### 6.2 特点

1. **风格归一化**：每样本每通道独立；
2. **不依赖 batch**；
3. **风格迁移标配**：让生成图风格稳定；
4. **GAN 中常用**。

### 6.3 与 BN 区别

- BN：跨样本同通道归一化（保留通道差异）；
- IN：单样本内归一化（去除风格信息）。

## 7.GroupNorm（GN）

### 7.1 原理

**论文**：Group Normalization (Wu & He, 2018)

把通道分为 $G$ 组，每组在 $(C/G, H, W)$ 维度归一化：

$$
\mu_{n,g} = \frac{1}{(C/G) HW} \sum_{c \in g, h, w} x_{n,c,h,w}
$$

### 7.2 优点

1. **不依赖 batch size**：小 batch 时表现稳定；
2. **介于 LN 和 IN 之间**：通道分组而非全部或单通道；
3. **适合检测/分割**：batch 小时替代 BN；
4. **YOLOv5、Mask R-CNN 常用**。

### 7.3 典型参数

- $G = 32$（默认）；
- $G = 16$ 也常见；
- 每组通道数 = $C / G$，需整除。

### 7.4 代码

```python
nn.GroupNorm(num_groups=32, num_channels=C)
```

## 8.WeightNorm

### 8.1 原理

不归一化激活，而归一化**权重**：

$$
w = \frac{v}{\|v\|} \cdot g
$$

把权重分解为方向 $v / \|v\|$ 和大小 $g$。

### 8.2 优点

1. 不依赖 batch；
2. 不改变激活分布；
3. 适合 RNN、强化学习。

## 9.各归一化对比

| 归一化 | 统计维度 | 依赖 batch | 训练推理一致 | 典型应用 |
| --- | --- | --- | --- | --- |
| BN | (N,H,W) per C | 是 | 否 | CNN |
| LN | (C,H,W) per N | 否 | 是 | Transformer |
| IN | (H,W) per N,C | 否 | 是 | 风格迁移 |
| GN | (C/G,H,W) per N | 否 | 是 | 小 batch CV |
| WN | 权重 | 否 | 是 | RNN, RL |

## 10.归一化在 ResNet vs ViT

### 10.1 ResNet

- 用 **BN**；
- 每个 conv 后接 BN-ReLU；
- 推理时 BN 融合到 conv：$W' = W \cdot \gamma / \sqrt{\sigma^2 + \epsilon}, b' = \beta - \mu \cdot \gamma / \sqrt{\sigma^2 + \epsilon}$。

### 10.2 ViT

- 用 **LN**；
- Pre-LN（在 attention/FFN 前）：训练更稳；
- Post-LN（在残差后）：原始 Transformer，训练不稳。

```python
# Pre-LN（推荐）
class Block(nn.Module):
    def forward(self, x):
        x = x + self.attn(self.norm1(x))
        x = x + self.ffn(self.norm2(x))
        return x

# Post-LN（原始）
class Block(nn.Module):
    def forward(self, x):
        x = self.norm1(x + self.attn(x))
        x = self.norm2(x + self.ffn(x))
        return x
```

## 11.归一化的位置

### 11.1 Conv + BN + ReLU

```
Conv -> BN -> ReLU
```

最经典组合。

### 11.2 Conv + ReLU + BN（不推荐）

- ReLU 后负值变 0，BN 统计被偏置；
- 一般不用。

### 11.3 BN + Conv（Pre-activation）

- ResNet v2 用：BN-ReLU-Conv；
- 训练更稳，能训更深网络。

## 12.面试常考问题

**Q1：BN 的原理？训练和推理的区别？**

- 训练：用当前 batch 的 $\mu, \sigma^2$；
- 推理：用训练累积的 running_mean, running_var；
- 通过 momentum 滑动平均累积。

**Q2：为什么 BN 在小 batch 时效果差？**

- batch 小 -> $\mu, \sigma^2$ 估计不准；
- 训练不稳；
- 解决：用 SyncBN 跨卡同步、用 GN、用 LN。

**Q3：BN 和 LN 的本质区别？**

| 维度 | BN | LN |
| --- | --- | --- |
| 统计维度 | (N,H,W) per C | (C,H,W) per N |
| 依赖 batch | 是 | 否 |
| 保留通道差异 | 是 | 否 |
| 适合 | CNN | Transformer |

**Q4：为什么 ViT 用 LN 不用 BN？**

- ViT 处理 patch 序列，类似 NLP；
- LN 不依赖 batch，序列长度变化时稳定；
- BN 在 Transformer 上效果差。

**Q5：GN 解决什么问题？**

- 小 batch 时 BN 统计不准；
- GN 不依赖 batch；
- 通道分组保留一定通道间差异；
- 检测/分割任务（batch 小）常用。

**Q6：BN 的正则化效果来自哪里？**

- batch 内统计扰动（每 batch 不同的 $\mu, \sigma^2$）；
- 等效于给输入加噪声；
- 起到正则化作用。

**Q7：为什么推理时 BN 不依赖 batch？**

- 用训练时累积的 running_mean, running_var；
- 单样本推理也能用；
- 训练/推理差异是 BN 的一个缺点。

**Q8：BN 融合到 conv 怎么做？**

$$
W' = W \cdot \gamma / \sqrt{\sigma^2 + \epsilon}, \quad b' = \beta - \mu \cdot \gamma / \sqrt{\sigma^2 + \epsilon}
$$

- 推理时 BN 等价于线性变换；
- 融合后无额外计算；
- TensorRT 等推理引擎自动做。

**Q9：Pre-LN 和 Post-LN 的区别？**

- Pre-LN：在 attention/FFN 前归一化，残差路径无归一化；
- Post-LN：在残差后归一化；
- Pre-LN 训练更稳，能训深层 Transformer；
- 现代 ViT 都用 Pre-LN。

**Q10：InstanceNorm 为什么适合风格迁移？**

- 每样本每通道独立归一化；
- 去除风格信息（如颜色、纹理统计）；
- 保留内容信息；
- 让生成图风格稳定。

## 13.总结

- **BN**：CV 经典，依赖 batch，CNN 标配；
- **LN**：不依赖 batch，Transformer 标配；
- **IN**：风格迁移，去除风格信息；
- **GN**：小 batch 替代 BN，检测/分割常用；
- **WN**：归一化权重，适合 RNN/RL；
- 选择归一化要考虑**任务类型、batch size、模型架构**；
- ViT 时代 LN 成为默认选择。
