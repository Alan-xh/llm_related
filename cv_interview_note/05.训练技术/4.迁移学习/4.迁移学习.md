# 4.迁移学习

## 1.概述

**迁移学习（Transfer Learning）** 是把在大数据集上预训练的模型迁移到下游任务的方法。CV 中迁移学习几乎是**默认做法**：

- ImageNet 预训练 ResNet -> 医学影像分类；
- MAE 预训练 ViT -> COCO 检测；
- CLIP -> 各种下游视觉任务。

迁移学习让**小数据任务也能用大模型**，是深度学习工程化的核心技术。

## 2.迁移学习分类

### 2.1 按 pretrain 数据分类

| 类型 | 描述 | 例子 |
| --- | --- | --- |
| **Supervised Pretrain** | 有标签大数据预训练 | ImageNet-21k -> ResNet |
| **Self-Supervised Pretrain** | 无标签自监督预训练 | MAE / DINO / SimCLR -> ViT |
| **Multimodal Pretrain** | 多模态对比预训练 | CLIP / ALIGN -> 视觉编码器 |

### 2.2 按迁移方式分类

| 类型 | 描述 |
| --- | --- |
| **Fine-tuning** | 全模型或部分层参数更新 |
| **Feature Extraction** | 冻结 backbone，只训新加层 |
| **Prompt Tuning** | 仅优化 prompt（视觉少见） |
| **Adapter / LoRA** | 加少量参数微调 |
| **Linear Probe** | 冻结 backbone，只训线性分类头 |

## 3.Fine-tuning 策略

### 3.1 全模型微调（Full Fine-tuning）

- 所有参数都更新；
- 数据足够时效果最好；
- 典型：ImageNet 预训练 ResNet -> 自定义分类任务。

### 3.2 冻结 backbone + 训分类头（Linear Probe）

- 冻结 backbone，只训线性分类头；
- 评估预训练表示质量；
- 数据极少时用。

```python
for param in model.backbone.parameters():
    param.requires_grad = False
# 只训分类头
```

### 3.3 部分冻结（Partial Freeze）

- 冻结浅层，训深层；
- 浅层特征通用，深层任务特定；
- ResNet 中冻结 conv1~conv3，训 conv4~conv5 + FC。

### 3.4 渐进解冻（Gradual Unfreezing）

- ULMFiT 思想；
- 先训分类头，再逐层解冻；
- 训练更稳。

## 4.学习率策略

### 4.1 不同层不同学习率（Layer-wise LR）

- 浅层用小 lr（已学好）；
- 深层用大 lr（需适配新任务）；
- 分类头用最大 lr；

```python
optimizer = optim.AdamW([
    {'params': model.stem.parameters(), 'lr': 1e-5},
    {'params': model.layer1.parameters(), 'lr': 1e-5},
    {'params': model.layer2.parameters(), 'lr': 5e-5},
    {'params': model.layer3.parameters(), 'lr': 1e-4},
    {'params': model.layer4.parameters(), 'lr': 1e-4},
    {'params': model.head.parameters(), 'lr': 1e-3},
], weight_decay=0.05)
```

### 4.2 Discriminative Fine-tuning

- 第 $i$ 层学习率 $\eta_i = \eta_{base} \cdot \gamma^{L-i}$，$\gamma < 1$；
- 浅层 lr 小，深层 lr 大。

### 4.3 ULMFiT Slanted Triangular LR

- 先线性 warmup，再余弦退火；
- 让模型先适应新任务，再精调。

## 5.迁移学习的关键问题

### 5.1 数据量与策略

| 数据量 | 推荐策略 |
| --- | --- |
| < 1k | Linear Probe + 强增强 |
| 1k ~ 10k | 冻结浅层 + 微调深层 |
| 10k ~ 100k | 全模型微调 |
| > 100k | 从头训练也可 |

### 5.2 域差距（Domain Gap）

- 源域与目标域差异大时（如自然图 -> 医学影像），迁移效果差；
- 解决：
  1. **域适配**（DA）：DANN、MMD；
  2. **中间域预训练**：在源域 + 目标域中间数据预训练；
  3. **自监督预训练**：在目标域做自监督预训练。

### 5.3 灾难性遗忘（Catastrophic Forgetting）

- 微调时模型忘记预训练知识；
- 解决：
  1. **小学习率**；
  2. **L2 约束**：限制参数偏离预训练值；
  3. **EWC**（Elastic Weight Consolidation）：重要参数少更新；
  4. **冻结部分层**。

## 6.自监督预训练迁移

### 6.1 优势

- 不需人工标签，可用海量无标签数据；
- 学到的表示更通用；
- 在小数据下游任务上优势明显。

### 6.2 代表方法

| 方法 | 类型 | 特点 |
| --- | --- | --- |
| **SimCLR** | Contrastive | 强增强对比 |
| **MoCo** | Contrastive | 动量编码器 + 队列 |
| **BYOL** | Non-contrastive | 自蒸馏 |
| **DINO** | Self-distillation | ViT 自蒸馏 |
| **MAE** | Generative | mask 重建像素 |
| **BEiT** | Generative | mask 重建 VQ token |

### 6.3 评估方式

- **Linear Probe**：冻结 backbone + 线性头，评估表示质量；
- **Fine-tuning**：全模型微调，评估迁移性能；
- **Few-shot**：每类少量样本，评估少样本泛化。

## 7.多模态预训练迁移（CLIP）

### 7.1 CLIP 迁移

- **Zero-shot 分类**：直接用文本 prompt 做分类，无需微调；
- **Linear Probe**：冻结视觉编码器 + 线性头，性能极强；
- **Fine-tuning**：在下游数据上微调，进一步提升；
- **Prompt Tuning**：CoOp、CoCoOp 学习 prompt。

### 7.2 CLIP 的迁移优势

- 覆盖类别广（400M 图文对）；
- 视觉-语言对齐，适合多模态任务；
- Zero-shot 性能极强；
- 已成为多模态基础模型。

## 8.Prompt Tuning

### 8.1 视觉 Prompt

- 借鉴 NLP 中 prompt tuning；
- 加入可学习的 prompt token；
- 冻结主干，只训 prompt；

### 8.2 VPT（Visual Prompt Tuning）

- 在 ViT 输入序列加可学习 prompt token；
- 每层都可加；
- 参数量极小（< 1% backbone）；
- 性能接近 full fine-tuning。

### 8.3 CoOp（Context Optimization）

- CLIP 文本端 prompt 用可学习 token 替代；
- 冻结 CLIP 主干，只优化 prompt；
- 5-shot 性能大幅超过 zero-shot。

## 9.Adapter / LoRA

### 9.1 Adapter

- 在每层加小型 bottleneck 模块；
- 冻结主干，只训 adapter；
- 参数量 < 1% backbone；
- 缺点：增加推理延迟。

### 9.2 LoRA

- 用低秩矩阵 $BA$ 模拟权重更新 $\Delta W$；
- 冻结 $W$，只训 $A, B$；
- 参数量 $O(rd)$（r 远小于 d）；
- 推理时可合并 $W + BA$，**无额外延迟**；
- 详见 [llm_interview_note/05.有监督微调/4.lora](../../llm_interview_note/05.有监督微调/4.lora/4.lora.md)。

### 9.3 视觉 LoRA

- 在 ViT 的 QKV 或 FFN 上加 LoRA；
- 适合大模型微调；
- Diffusion 模型微调（LoRA for SD）。

## 10.代码示例

### 10.1 ImageNet 预训练模型加载

```python
import torchvision.models as models
import torch.nn as nn

# 加载 ImageNet 预训练 ResNet-50
model = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V2)

# 替换分类头
num_classes = 10
model.fc = nn.Linear(model.fc.in_features, num_classes)

# 冻结浅层
for name, param in model.named_parameters():
    if 'layer4' not in name and 'fc' not in name:
        param.requires_grad = False
```

### 10.2 不同层不同学习率

```python
optimizer = optim.AdamW([
    {'params': [p for n, p in model.named_parameters() if 'layer4' in n], 'lr': 1e-4},
    {'params': model.fc.parameters(), 'lr': 1e-3},
], weight_decay=0.05)
```

### 10.3 LoRA 实现（简化）

```python
class LoRALinear(nn.Module):
    def __init__(self, in_features, out_features, r=8):
        super().__init__()
        self.W = nn.Linear(in_features, out_features, bias=False)
        self.W.weight.requires_grad = False  # 冻结
        self.A = nn.Linear(in_features, r, bias=False)
        self.B = nn.Linear(r, out_features, bias=False)
        nn.init.zeros_(self.B.weight)  # B 初始化为 0
    def forward(self, x):
        return self.W(x) + self.B(self.A(x))
```

## 11.面试常考问题

**Q1：迁移学习的本质是什么？**

把在大数据集上学到的通用表示迁移到下游任务，让小数据任务也能用大模型。

**Q2：Fine-tuning 和 Linear Probe 的区别？**

- Fine-tuning：所有参数更新，数据足够时效果最好；
- Linear Probe：冻结 backbone + 训线性头，评估预训练质量，数据少时用。

**Q3：什么时候该冻结浅层？**

- 数据少（< 10k）；
- 浅层特征通用（边缘、纹理）；
- 浅层 lr 小，深层 lr 大。

**Q4：迁移学习的学习率怎么设？**

- 比从头训练小 10 倍；
- 不同层不同 lr（layer-wise）；
- 浅层 lr 小，深层 lr 大；
- 分类头 lr 最大。

**Q5：什么是灾难性遗忘？怎么解决？**

- 微调时模型忘记预训练知识；
- 解决：
  1. 小学习率；
  2. L2 约束；
  3. EWC（重要参数少更新）；
  4. 冻结部分层；
  5. Replay（混合预训练数据）。

**Q6：CLIP 为什么迁移能力这么强？**

- 400M 图文对预训练，类别覆盖广；
- 视觉-语言对齐；
- Zero-shot 能力强；
- Linear Probe 性能极强；
- 适合多模态下游任务。

**Q7：自监督预训练相比有监督有什么优势？**

- 不需人工标签，可用海量无标签数据；
- 学到的表示更通用；
- 小数据下游任务上优势明显；
- MAE、DINO 等方法在 ImageNet 上超过有监督预训练。

**Q8：LoRA 的原理？为什么省参数？**

- 用低秩矩阵 $BA$ 模拟 $\Delta W$；
- 参数量 $O(rd)$ vs $O(d^2)$，r 远小于 d；
- 推理时可合并 $W + BA$，无额外延迟；
- 详见 [llm_interview_note/05.有监督微调/4.lora](../../llm_interview_note/05.有监督微调/4.lora/4.lora.md)。

**Q9：VPT（Visual Prompt Tuning）是什么？**

- 在 ViT 输入序列加可学习 prompt token；
- 冻结主干，只训 prompt；
- 参数量极小（< 1% backbone）；
- 性能接近 full fine-tuning。

**Q10：域差距大时怎么迁移？**

- 自然图 -> 医学影像域差距大；
- 解决：
  1. 域适配（DANN、MMD）；
  2. 中间域预训练；
  3. 在目标域做自监督预训练（如医学影像 MAE）；
  4. 渐进式微调。

## 12.总结

- **Fine-tuning**：全模型或部分层微调，最常用；
- **Linear Probe**：冻结 backbone + 线性头，评估预训练质量；
- **Layer-wise LR**：浅层小 lr、深层大 lr；
- **自监督预训练**：MAE、DINO 等迁移能力强；
- **CLIP 迁移**：Zero-shot、Linear Probe、Fine-tuning；
- **Prompt Tuning**：VPT、CoOp 等；
- **Adapter / LoRA**：参数高效微调；
- 迁移学习是 CV 工程化的**核心技术**，几乎所有实际任务都用。
