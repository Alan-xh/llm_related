# 5.分布式训练

## 1.概述

CV 模型规模和数据量不断增长，单卡训练已不可行。**分布式训练**让训练扩展到多卡、多机，是现代深度学习必备技术。CV 中分布式训练技术与 LLM 共通，详见 [llm_interview_note/04.分布式训练](../../llm_interview_note/04.分布式训练/)。本节聚焦 CV 特有部分。

## 2.分布式训练分类

### 2.1 数据并行（Data Parallelism, DP）

- **每张卡持有完整模型**；
- 数据分批到各卡；
- 各卡前向 + 反向；
- 梯度 AllReduce 同步；
- **最常用**。

**PyTorch DDP**（DistributedDataParallel）：

```python
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

dist.init_process_group("nccl")
model = model.to(local_rank)
model = DDP(model, device_ids=[local_rank])
```

### 2.2 模型并行（Model Parallelism）

- 模型太大放不下单卡；
- **张量并行**：矩阵分块（Megatron-LM）；
- **流水线并行**：层间分块（GPipe、PipeDream）；
- CV 中较少用，多用于大 LLM。

### 2.3 优化器并行（ZeRO）

- ZeRO-1：分片优化器状态；
- ZeRO-2：分片优化器 + 梯度；
- ZeRO-3：分片优化器 + 梯度 + 参数；
- DeepSpeed 实现。

## 3.CV 中的数据并行

### 3.1 DDP 标准流程

```python
import torch
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, DistributedSampler

# 1. 初始化
dist.init_process_group("nccl")
local_rank = int(os.environ["LOCAL_RANK"])
torch.cuda.set_device(local_rank)

# 2. 模型
model = build_model().cuda()
model = DDP(model, device_ids=[local_rank])

# 3. 数据
sampler = DistributedSampler(dataset)
loader = DataLoader(dataset, batch_size=batch_size, sampler=sampler)

# 4. 训练
for epoch in range(epochs):
    sampler.set_epoch(epoch)  # 重要！每 epoch 重新打乱
    for batch in loader:
        loss = model(batch)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
```

### 3.2 关键注意点

1. **DistributedSampler**：每卡分到不同数据；
2. **set_epoch**：每 epoch 重新打乱，否则重复；
3. **batch size**：总 batch = per_gpu_batch × num_gpus；
4. **学习率**：按 linear scaling rule 调整；
5. **同步点**：loss.backward() 时 AllReduce 梯度。

## 4.Synchronized Batch Normalization

### 4.1 BN 在分布式下的问题

标准 BN 只在单卡计算均值/方差，batch size 小时统计不准：

- 单卡 batch=2 -> BN 估计极不准；
- 多卡 batch=32 但每卡 batch=2 -> 各卡 BN 独立，效果差。

### 4.2 SyncBN

**SyncBN** 跨卡同步统计：

1. 各卡计算本地 sum、sum_sq；
2. AllReduce 同步得到全局 sum、sum_sq；
3. 用全局统计计算均值/方差；
4. 等效于用总 batch size 做 BN。

```python
import torch.nn as nn
model = nn.SyncBatchNorm.convert_sync_batchnorm(model)
```

### 4.3 何时用 SyncBN？

- 单卡 batch < 8 时；
- 检测、分割等需要小 batch 的任务；
- 大 batch 时（> 16 per GPU）标准 BN 已足够。

## 5.混合精度训练（AMP）

### 5.1 原理

- 用 FP16/BF16 做前向反向，速度快、省显存；
- 主权重用 FP32 保存，避免精度损失；
- Loss Scaling 防止小梯度下溢。

### 5.2 PyTorch AMP

```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
for batch in loader:
    optimizer.zero_grad()
    with autocast():
        loss = model(batch)
    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()
```

### 5.3 BF16 vs FP16

| 维度 | FP16 | BF16 |
| --- | --- | --- |
| 指数位 | 5 | 8 |
| 尾数位 | 10 | 7 |
| 动态范围 | 小 | 大（与 FP32 同） |
| 精度 | 高 | 低 |
| 需要 Loss Scaling | 是 | 否 |
| Ampere+ 支持 | 是 | 是 |

- BF16 不需 loss scaling，训练更稳；
- A100/H100 优先 BF16；
- 旧卡（V100）只能 FP16。

## 6.大 batch 训练

### 6.1 Linear Scaling Rule

$$
\eta_{new} = \eta_{base} \times \frac{B_{new}}{B_{base}}
$$

- batch 翻倍，学习率翻倍；
- 配合 warmup；
- Facebook 用 256 GPU 1 小时训 ImageNet。

### 6.2 LARS / LAMB

**Layer-wise Adaptive Rate Scaling**：

- 每层独立学习率；
- 学习率正比于权重范数 / 梯度范数；
- 大 batch 训练专用；
- LAMB 是 LARS 的 Adam 版本。

### 6.3 大 batch 的问题

1. **泛化变差**：等效 epoch 数减少；
2. **学习率需调**：linear scaling rule；
3. **warmup 重要**：初期更不稳；
4. **可加 mixup 等增强**：缓解泛化下降。

## 7.梯度累加

### 7.1 应用场景

- 显存不够大 batch；
- 想要等效大 batch 但单卡放不下；
- 通过多次小 batch 反向累加梯度。

### 7.2 实现

```python
accumulation_steps = 4
optimizer.zero_grad()
for i, batch in enumerate(loader):
    with autocast():
        loss = model(batch) / accumulation_steps  # 注意除以累加步数
    scaler.scale(loss).backward()
    if (i + 1) % accumulation_steps == 0:
        scaler.step(optimizer)
        scaler.update()
        optimizer.zero_grad()
```

**注意**：

- Loss 要除以累加步数（保持梯度尺度）；
- BN 统计仍是单 batch 大小（可能不准）；
- 必要时用 SyncBN 或 GN。

## 10.常见问题排查

### 10.1 死锁

- 某些卡前向慢，其他卡等；
- 排查：模型分支不一致导致 AllReduce 不同步；
- 解决：避免条件分支或确保所有 rank 一致。

### 10.2 梯度爆炸/消失

- 梯度范数过大或为 0；
- 加 gradient clipping；
- 检查初始化、学习率、BN。

### 10.3 显存不足

- 用 AMP；
- 用 gradient checkpointing（用算力换显存）；
- 减小 batch size + 梯度累加；
- 用 ZeRO-3 分片。

### 10.4 训练速度慢

- 检查 GPU 利用率（nvidia-smi）；
- I/O 瓶颈：用 LMDB、webdataset、prefetch；
- CPU 增强：用 DALI；
- 通信瓶颈：检查 NCCL 配置。

## 11.面试常考问题

**Q1：DDP 和 DP 的区别？**

- DP：单进程多线程，受 GIL 限制，效率低，已不推荐；
- DDP：多进程，每卡一个进程，效率高，PyTorch 推荐；
- DDP 通信开销小（仅梯度 AllReduce）。

**Q2：DistributedSampler 为什么要 set_epoch？**

- 不 set_epoch 则每 epoch 数据顺序相同；
- set_epoch 让每 epoch 重新打乱，避免重复采样。

**Q3：SyncBN 解决什么问题？**

- 小 batch 时 BN 统计不准；
- SyncBN 跨卡同步统计，等效于用总 batch 做 BN；
- 检测、分割等小 batch 任务必用。

**Q4：大 batch 训练要注意什么？**

1. 学习率按 linear scaling rule；
2. Warmup 重要；
3. 可能泛化变差；
4. 用 LARS/LAMB；
5. 可加 mixup 等增强。

**Q5：混合精度训练原理？**

- FP16 前向反向 + FP32 主权重；
- Loss scaling 防小梯度下溢；
- 速度快、省显存；
- BF16 不需 loss scaling。

**Q6：BF16 和 FP16 的区别？**

- BF16 指数位多（8 vs 5），动态范围与 FP32 同；
- BF16 精度低但训练稳；
- BF16 不需 loss scaling；
- Ampere+（A100/H100）支持 BF16。

**Q7：梯度累加的原理？**

- 显存不够大 batch；
- 多次小 batch 反向，梯度累加；
- Loss 要除以累加步数；
- BN 统计仍是单 batch（需 SyncBN/GN）。

**Q8：什么是 ZeRO？**

- Zero Redundancy Optimizer；
- ZeRO-1：分片优化器状态；
- ZeRO-2：分片优化器 + 梯度；
- ZeRO-3：分片优化器 + 梯度 + 参数；
- 大模型训练必备。

**Q9：如何排查分布式训练死锁？**

1. 检查所有 rank 是否一致执行同样操作；
2. 避免条件分支（if rank == 0: ...）后跟集合通信；
3. 用 NCCL_DEBUG=INFO 查看通信日志；
4. 用 torch.distributed.barrier() 同步。

**Q10：CV 中什么时候用模型并行？**

- 大模型（如 ViT-Huge、Swin-L）单卡放不下；
- 高分辨率输入（如医学影像 1024×1024）显存大；
- 通常用 ZeRO-3 或 FSDP 即可，少用模型并行。

## 12.总结

- **数据并行 DDP**：最常用，简单稳定；
- **SyncBN**：小 batch 时必用；
- **混合精度 AMP**：速度 + 显存双提升；
- **大 batch 训练**：linear scaling + warmup；
- **ZeRO**：大模型训练必备；
- **梯度累加**：显存不够时模拟大 batch；
- 详见 LLM 笔记的分布式训练章节。
