# 1.损失函数

## 1.概述

**损失函数（Loss Function）** 衡量模型预测与真实标签的差异，是模型训练的"指南针"。CV 中按任务分为**分类、回归、检测、分割、生成** 等多种损失。理解各种 loss 的特性、适用场景和组合方式是设计训练流程的核心技能。

## 2.分类损失

### 2.1 Cross Entropy（交叉熵）

**二分类**（BCE）：

$$
L_{BCE} = -[y \log \hat{y} + (1-y) \log(1-\hat{y})]
$$

**多分类**（CE）：

$$
L_{CE} = -\sum_i y_i \log \hat{y}_i = -\log \hat{y}_{true}
$$

**PyTorch**：

```python
criterion = nn.CrossEntropyLoss()  # 含 softmax
loss = criterion(logits, targets)
# 或
loss = F.cross_entropy(logits, targets)
```

**特点**：

1. 最常用分类 loss；
2. 配合 softmax 使用；
3. 对预测错且自信的样本惩罚大。

### 2.2 Label Smoothing CE

$$
L = -\sum_i y'_i \log \hat{y}_i, \quad y'_i = (1-\epsilon) y_i + \frac{\epsilon}{K}
$$

详见 [04.训练数据与增强/3.标签策略](../../04.训练数据与增强/3.标签策略/3.标签策略.md)。

### 2.3 Focal Loss

**论文**：Focal Loss for Dense Object Detection (Lin et al., Facebook, 2017)

**动机**：标准 CE 在类别不平衡或难样本多时效果差，简单样本仍贡献大量 loss。

**公式**：

$$
L_{FL} = -\alpha (1 - p_t)^\gamma \log p_t
$$

其中 $p_t$ 是真实类的预测概率，$\alpha$ 是类权重，$\gamma$ 是 focusing parameter。

**作用**：

1. **降低易样本权重**：$(1-p_t)^\gamma$ 让 $p_t \to 1$ 时 loss $\to 0$；
2. **关注难样本**：$p_t$ 小时 $(1-p_t)^\gamma$ 大；
3. **$\alpha$ 平衡类别**：缓解类别不平衡。

**典型参数**：$\gamma = 2$，$\alpha = 0.25$。

**应用**：RetinaNet（解决单阶段检测器精度低问题）、长尾分类。

```python
class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2):
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma

    def forward(self, logits, targets):
        ce = F.cross_entropy(logits, targets, reduction='none')
        p = torch.exp(-ce)
        loss = self.alpha * (1 - p) ** self.gamma * ce
        return loss.mean()
```

## 3.回归损失

### 3.1 L1 / MAE

$$
L_1 = \frac{1}{N} \sum |y_i - \hat{y}_i|
$$

**特点**：

1. 梯度恒为 ±1，**训练稳定**；
2. 在 0 处不可导；
3. 对离群点鲁棒；
4. 输出中位数（vs L2 输出均值）。

### 3.2 L2 / MSE

$$
L_2 = \frac{1}{N} \sum (y_i - \hat{y}_i)^2
$$

**特点**：

1. 处处可导；
2. 对离群点敏感（误差平方放大）；
3. 梯度随误差增大 -> 训练前期快但后期震荡；
4. 输出均值。

### 3.3 Smooth L1（Huber Loss）

$$
L_{smooth} = \begin{cases}
0.5 (y - \hat{y})^2, & |y - \hat{y}| < 1 \\
|y - \hat{y}| - 0.5, & \text{otherwise}
\end{cases}
$$

**特点**：

1. 结合 L1 和 L2 优点：误差小用 L2（光滑），误差大用 L1（不爆炸）；
2. Fast R-CNN 首次用于检测框回归；
3. 检测任务标准 loss。

### 3.4 IoU Loss

**论文**：UnitBox: An Advanced Object Detection Network (Yu et al., 2016)

**动机**：L1/L2 对框的 4 个坐标独立回归，**未考虑框的整体性**。

**公式**：

$$
L_{IoU} = 1 - \frac{|B \cap B^*|}{|B \cup B^*|}
$$

其中 $B$ 是预测框，$B^*$ 是真实框。

**优点**：

1. 把框作为整体评估；
2. 尺度不变；
3. 与检测评估指标一致。

### 3.5 GIoU（Generalized IoU）

**论文**：Generalized Intersection over Union (Rezatofighi et al., 2019)

**动机**：IoU 在框不重叠时为 0，梯度消失。

**公式**：

$$
L_{GIoU} = 1 - \text{IoU} + \frac{|C \setminus (B \cup B^*)|}{|C|}
$$

其中 $C$ 是包含 $B$ 和 $B^*$ 的最小外接矩形。

**优点**：即使框不重叠也有梯度。

### 3.6 DIoU / CIoU

**论文**：Distance-IoU Loss (Zheng et al., 2020)

**DIoU**：

$$
L_{DIoU} = 1 - \text{IoU} + \frac{\rho^2(b, b^*)}{c^2}
$$

其中 $\rho$ 是中心点欧氏距离，$c$ 是对角线长度。

**CIoU**：在 DIoU 基础上加入长宽比：

$$
L_{CIoU} = 1 - \text{IoU} + \frac{\rho^2}{c^2} + \alpha v
$$

其中 $v = \frac{4}{\pi^2}(\arctan\frac{w^*}{h^*} - \arctan\frac{w}{h})^2$，$\alpha = \frac{v}{(1-IoU) + v}$。

**优点**：

1. 收敛快（直接优化中心距离）；
2. 不重叠时也有梯度；
3. 考虑长宽比（CIoU）。

**YOLOv5、YOLOv7、YOLOv8 默认使用 CIoU**。

## 4.分割损失

### 4.1 像素级 CE

对每个像素做分类：

$$
L = \frac{1}{HW} \sum_{i} \text{CE}(p_i, y_i)
$$

### 4.2 Dice Loss

**论文**：V-Net (Milletari et al., 2016)

**Dice 系数**：

$$
Dice = \frac{2 |P \cap G|}{|P| + |G|}
$$

**Dice Loss**：

$$
L = 1 - Dice
$$

**优点**：

1. 直接优化分割评估指标（mIoU）；
2. **类别不平衡鲁棒**（小目标也贡献 loss）；
3. 医学影像分割常用。

**缺点**：梯度不稳定，常与 CE 组合使用。

### 4.3 Tversky Loss

Dice 的扩展，分别加权 FP 和 FN：

$$
T = \frac{TP}{TP + \alpha FP + \beta FN}
$$

**适用**：医学影像中 FN 比 FP 更严重（漏检肿瘤），可设 $\beta > \alpha$。

### 4.4 Focal Dice / Focal Tversky

结合 Focal 思想，关注难像素。

## 5.对比学习损失

### 5.1 InfoNCE

**论文**：Representation Learning with Contrastive Predictive Coding (Oord et al., 2018)

**公式**：

$$
L = -\log \frac{\exp(sim(q, k^+) / \tau)}{\sum_i \exp(sim(q, k_i) / \tau)}
$$

- $q$：query；
- $k^+$：正样本 key；
- $k_i$：所有 key（含负样本）；
- $\tau$：温度；
- $sim$：相似度（余弦）。

**应用**：CLIP、MoCo、SimCLR、BLIP 等。

### 5.2 Triplet Loss

$$
L = \max(0, d(a, p) - d(a, n) + m)
$$

- $a$：anchor；
- $p$：positive；
- $n$：negative；
- $m$：margin；
- $d$：距离。

**应用**：人脸识别（FaceNet）、reID。

### 5.3 NCE（Noise Contrastive Estimation）

简化 softmax：把多分类转为二分类（正样本 vs 噪声样本）。

## 6.生成模型损失

### 6.1 GAN 损失

**Generator**：

$$
L_G = -\log D(G(z))
$$

**Discriminator**：

$$
L_D = -\log D(x) - \log(1 - D(G(z)))
$$

**变体**：

- **LSGAN**：用 MSE 替代 CE，更稳定；
- **WGAN**：用 Wasserstein 距离，缓解模式崩溃；
- **Hinge GAN**：用 hinge loss，SNGAN、BigGAN 使用。

### 6.2 KL Divergence

$$
D_{KL}(p \| q) = \sum p \log \frac{p}{q}
$$

**应用**：VAE 中让后验 $q(z|x)$ 接近先验 $p(z)$。

### 6.3 Perceptual Loss

**论文**：Perceptual Losses for Real-Time Style Transfer (Johnson et al., 2016)

**思想**：用预训练 VGG 的中间特征计算 loss，而非像素级 loss：

$$
L = \sum_l w_l \| \phi_l(y) - \phi_l(\hat{y}) \|^2
$$

**优点**：

1. 关注感知相似而非像素相似；
2. 适合风格迁移、超分、图像生成。

### 6.4 Diffusion Loss

去噪 diffusion 训练：

$$
L = \mathbb{E}_{t, x_0, \epsilon} \| \epsilon - \epsilon_\theta(x_t, t) \|^2
$$

让模型预测添加的噪声 $\epsilon$。

## 7.多任务损失

多任务学习时，不同任务 loss 加权求和：

$$
L = \sum_i w_i L_i
$$

**权重选择方法**：

1. **手动调参**：经验值；
2. **Uncertainty Weighting**（Kendall et al.）：用任务不确定性自动加权：
   $$ L = \sum_i \frac{1}{2\sigma_i^2} L_i + \log \sigma_i $$
3. **GradNorm**：动态调整权重让各任务梯度范数平衡。

## 8.损失函数选择指南

| 任务 | 推荐 loss |
| --- | --- |
| 分类（平衡） | CE + Label Smoothing |
| 分类（不平衡） | Focal Loss / Class-Balanced CE |
| 分类（ViT 训练） | CE + Mixup + Label Smoothing |
| 框回归 | Smooth L1 / GIoU / CIoU |
| 语义分割 | CE + Dice |
| 实例分割 | CE + Dice（mask）+ Smooth L1（box） |
| 关键点 | MSE / Smooth L1 + OKS |
| GAN | Hinge / WGAN-GP |
| VAE | Reconstruct + KL |
| Diffusion | MSE（噪声预测） |
| 对比学习 | InfoNCE |
| 知识蒸馏 | CE + KL |

## 9.面试常考问题

**Q1：CE 和 BCE 的区别？**

- CE：多分类，配合 softmax，标签是 one-hot；
- BCE：二分类或多标签，配合 sigmoid，每类独立计算。

**Q2：Focal Loss 解决什么问题？**

- 类别不平衡 + 难易样本不均；
- $(1-p_t)^\gamma$ 降低易样本权重，关注难样本；
- RetinaNet 用 Focal Loss 让单阶段检测超越两阶段。

**Q3：Smooth L1 比 L1/L2 好在哪？**

- L1 在 0 处不可导，L2 对离群点敏感；
- Smooth L1：误差小用 L2（光滑），误差大用 L1（不爆炸）；
- 检测框回归标配。

**Q4：IoU 系列损失的演进？**

- IoU：不重叠时梯度为 0；
- GIoU：考虑最小外接矩形，不重叠也有梯度；
- DIoU：直接优化中心点距离，收敛快；
- CIoU：加入长宽比，YOLOv5+ 默认。

**Q5：Dice Loss 为什么适合医学分割？**

- 直接优化 mIoU 评估指标；
- 对类别不平衡鲁棒（小目标贡献相对大）；
- 缺点：梯度不稳定，常与 CE 组合。

**Q6：Perceptual Loss 是什么？**

用预训练 VGG 中间特征计算 loss，关注感知相似而非像素相似。适合风格迁移、超分、生成。

**Q7：InfoNCE 的温度 $\tau$ 作用？**

- $\tau$ 小：分布更尖锐，关注最相似负样本；
- $\tau$ 大：分布更平滑，关注所有负样本；
- 典型 $\tau = 0.07 \sim 0.1$。

**Q8：知识蒸馏的 loss 怎么写？**

$$
L = \alpha \text{CE}(y, p_s) + (1-\alpha) T^2 \text{KL}(p_t^T \| p_s^T)
$$

- 第一项：hard label 监督；
- 第二项：teacher soft prediction 蒸馏；
- $T$：温度；
- $T^2$：保持梯度尺度。

**Q9：多任务 loss 怎么平衡？**

1. 手动调参；
2. Uncertainty Weighting（自动）；
3. GradNorm（梯度平衡）；
4. DWA（动态权重平均）。

**Q10：KL 散度和交叉熵的关系？**

$$
H(p, q) = H(p) + D_{KL}(p \| q)
$$

- 当 $p$ 是 hard label（$H(p) = 0$）时，CE = KL；
- 监督学习中常用 CE 而非 KL，因为 $H(p)$ 是常数。

## 10.总结

- **分类**：CE、Focal、Label Smoothing；
- **回归**：L1、L2、Smooth L1、IoU 系列；
- **分割**：CE、Dice、Tversky；
- **对比学习**：InfoNCE、Triplet、NCE；
- **生成**：GAN、KL、Perceptual、Diffusion MSE；
- **多任务**：加权求和，可用 uncertainty weighting 自动平衡；
- 选择 loss 要考虑**任务类型、数据分布、训练稳定性**。
