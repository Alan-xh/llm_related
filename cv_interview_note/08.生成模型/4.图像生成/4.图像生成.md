# 4.图像生成

## 1.概述

**图像生成（Image Generation）** 是生成模型的核心应用，根据输入生成逼真图像。除了 GAN、VAE、Diffusion 三大主流，还有 **自回归模型、流模型、能量模型** 等。

## 2.生成模型分类

| 类型 | 代表 | 思想 |
| --- | --- | --- |
| GAN | StyleGAN, BigGAN | 对抗训练 |
| VAE | VAE, VQ-VAE | 变分推断 |
| Diffusion | DDPM, Stable Diffusion | 加噪-去噪 |
| **自回归** | PixelCNN, DALL-E | 逐像素生成 |
| **流模型** | Glow, RealNVP | 可逆变换 |
| **能量模型** | EBM, EBMs | 能量函数 |

## 3.自回归模型（Autoregressive）

### 3.1 核心思想

把图像视为像素序列，逐像素预测：

$$
p(x) = \prod_{i=1}^{N} p(x_i | x_{<i})
$$

- 类似语言模型（GPT）；
- 显式概率，可计算似然；
- 慢（逐像素）。

### 3.2 PixelCNN（2016）

**论文**：Pixel Recurrent Neural Networks (van den Oord et al., DeepMind)

- 用 CNN 做自回归；
- **Masked Convolution**：只能看之前的像素；
- 逐像素生成。

```
Masked Conv: 卷积核只看"过去"像素
[0 0 0]
[0 1 0]   <- 中心及之前可见
[1 1 1]
```

### 3.3 PixelSNAIL（2017）

- Attention + CNN；
- 长程依赖；
- 性能更强。

### 3.4 ImageGPT（2020）

- OpenAI；
- GPT 架构做图像；
- 无监督预训练，下游任务表现好。

### 3.5 DALL-E（2021）

- OpenAI；
- VQ-VAE 把图像离散化；
- Transformer 自回归学文本->图像 token；
- 文本到图像的开创者。

### 3.6 自回归优缺点

优点：
1. 显式似然；
2. 训练稳定；
3. 可解释。

缺点：
1. 生成慢（逐像素）；
2. 误差累积。

## 4.流模型（Normalizing Flows）

### 4.1 核心思想

通过**可逆变换**学数据分布：

$$
z = f_\theta(x), \quad x = f_\theta^{-1}(z)
$$

- $f$ 可逆且 Jacobian 易计算；
- 显式似然：

$$
\log p(x) = \log p(z) + \log \left| \det \frac{\partial f}{\partial x} \right|
$$

### 4.2 RealNVP（2017）

- Coupling Layer：分两半，一半变换一半；
- 可逆、Jacobian 三角形易算；
- 堆叠多层。

### 4.3 Glow（2018）

- OpenAI；
- 1×1 卷积 + Affine Coupling；
- 可逆，生成质量高；
- 支持插值。

### 4.4 优缺点

优点：
1. 精确似然；
2. 生成快（单次前向）；
3. 可逆。

缺点：
1. 架构受限（需可逆）；
2. 表达能力弱；
3. 高维计算量大。

## 5.能量模型（EBM）

### 5.1 核心思想

定义能量函数 $E_\theta(x)$：

$$
p(x) = \frac{\exp(-E_\theta(x))}{Z(\theta)}
$$

- $Z(\theta)$：配分函数，难算；
- 用 Score Matching 或 MCMC 训练。

### 5.2 代表

- **EBM**（Energy-Based Model）；
- **JEM**（Joint Energy Model）；
- 与 Score-based Diffusion 关系密切。

### 5.3 优缺点

优点：
1. 统一框架；
2. 灵活。

缺点：
1. 训练难（配分函数）；
2. 采样慢（MCMC）。

## 6.文本到图像生成

### 6.1 代表模型

| 模型 | 公司 | 技术 |
| --- | --- | --- |
| DALL-E | OpenAI | VQ-VAE + Transformer |
| DALL-E 2 | OpenAI | CLIP + Diffusion |
| DALL-E 3 | OpenAI | Diffusion + 重描述 |
| Stable Diffusion | Stability AI | LDM |
| Imagen | Google | Diffusion + T5 |
| Midjourney | Midjourney | Diffusion |
| GLIDE | OpenAI | Classifier-Free Guidance |

### 6.2 核心组件

1. **文本编码器**：CLIP / T5 / FLAN-T5；
2. **生成模型**：Diffusion；
3. **引导**：Classifier-Free Guidance；
4. **潜在空间**：LDM 降低计算量。

### 6.3 DALL-E 3 的改进

- 用**重描述**（recaptioning）改善文本对齐；
- GPT-4V 生成详细描述；
- 解决"模型不懂复杂 prompt"问题。

## 7.图像编辑

### 7.1 Inpainting

- 修复图像缺失区域；
- Diffusion 在 mask 区域生成；
- 保持非 mask 区域不变。

### 7.2 Outpainting

- 扩展图像边界；
- Diffusion 在边界外生成；
- 保持原图内容。

### 7.3 图像到图像

- ControlNet：用边缘、深度等条件；
- IP-Adapter：图像作为条件；
- DreamBooth：个性化生成。

## 8.个性化生成

### 8.1 DreamBooth（2022）

- 用少量图（3-5张）微调 Diffusion；
- 学特定主体（如你的宠物）；
- 保留原模型知识。

### 8.2 LoRA（Low-Rank Adaptation）

- 低秩矩阵微调；
- 训练快、参数少；
- 是 Diffusion 个性化的主流。

### 8.3 Textual Inversion

- 学新 token embedding；
- 用少量图学一个"词"；
- 轻量但能力有限。

## 9.视频生成

### 9.1 代表模型

| 模型 | 公司 | 特点 |
| --- | --- | --- |
| Sora | OpenAI | DiT 架构，60s 视频 |
| Runway Gen-2 | Runway | 商用视频生成 |
| Pika | Pika | 短视频生成 |
| Stable Video Diffusion | Stability AI | 开源视频生成 |
| AnimateDiff | 开源 | 动画风格 |

### 9.2 核心挑战

1. **时序一致性**：帧间连贯；
2. **长视频**：避免漂移；
3. **计算量大**：视频数据量大；
4. **运动控制**：精确控制运动。

## 10.3D 生成

### 10.1 NeRF（Neural Radiance Field）

- 用神经网络表示 3D 场景；
- 从任意视角渲染；
- 是 3D 生成的基础。

### 10.2 3D 生成模型

- **DreamFusion**：SDS loss + NeRF；
- **Magic3D**：高分辨率 3D；
- **Point-E / Shap-E**：直接生成 3D；
- **Gaussian Splatting**：高效 3D 表示。

## 11.面试常考问题

**Q1：生成模型有几类？**

1. GAN：对抗；
2. VAE：变分推断；
3. Diffusion：加噪-去噪；
4. 自回归：逐像素；
5. 流模型：可逆变换；
6. 能量模型：能量函数。

**Q2：自回归模型的优缺点？**

优点：
1. 显式似然；
2. 训练稳定；
3. 可解释。

缺点：
1. 生成慢；
2. 误差累积。

**Q3：流模型为什么可逆？**

- 架构设计为可逆（Coupling Layer）；
- Jacobian 易计算；
- 支持精确似然。

**Q4：DALL-E 怎么做文本到图像？**

1. VQ-VAE 把图像离散化为 token；
2. 文本 tokenize；
3. Transformer 自回归学文本->图像 token；
4. 生成时自回归出图像 token，VQ-VAE 解码。

**Q5：DALL-E 3 的重描述？**

- GPT-4V 生成详细描述；
- 用 (简短 prompt, 详细描述) 训练；
- 让模型理解复杂 prompt；
- 提升文本对齐。

**Q6：DreamBooth 怎么个性化？**

- 用少量图（3-5 张）微调；
- 引入新 token（如"[V] dog"）；
- 保留原模型知识；
- 先验保持 loss 防止过拟合。

**Q7：LoRA 在 Diffusion 中的应用？**

- 低秩矩阵微调；
- 只训小量参数；
- 训练快、易切换；
- 是 Diffusion 个性化主流。

**Q8：视频生成的挑战？**

1. 时序一致性；
2. 长视频漂移；
3. 计算量大；
4. 运动控制；
5. 时空 attention 复杂。

**Q9：Sora 为什么强？**

1. DiT 架构可扩展；
2. 大规模数据训练；
3. 时空 patch 表示；
4. 长视频生成能力。

**Q10：3D 生成的方法？**

1. DreamFusion：SDS + NeRF；
2. Magic3D：两阶段高分辨率；
3. Point-E / Shap-E：直接生成；
4. Gaussian Splatting：高效表示。

**Q11：图像编辑有哪些任务？**

1. Inpainting：修复缺失；
2. Outpainting：扩展边界；
3. Image-to-Image：风格转换；
4. ControlNet：结构控制；
5. 个性化：DreamBooth、LoRA。

**Q12：CLIP 在生成中的作用？**

1. 文本编码器：把文本变 embedding；
2. 引导生成（CFG）；
3. 评估（CLIPScore）；
4. DALL-E 2 用 CLIP 做 prior。

**Q13：Stable Diffusion 为什么开源意义重大？**

1. 普及 AIGC；
2. 社区生态（LoRA、ControlNet）；
3. 降低门槛；
4. 推动创新。

**Q14：生成模型的选择？**

| 场景 | 推荐 |
| --- | --- |
| 高质量图像 | Stable Diffusion, DALL-E 3 |
| 个性化 | DreamBooth, LoRA |
| 视频生成 | Sora, Runway |
| 3D 生成 | DreamFusion, Shap-E |
| 实时 | GAN（StyleGAN） |
| 编辑 | ControlNet, InstructPix2Pix |

**Q15：生成模型的未来？**

1. **统一架构**：DiT 等可扩展；
2. **多模态**：文本、图像、视频、3D 统一；
3. **长视频**：Sora 等；
4. **可控生成**：ControlNet 等；
5. **物理仿真**：理解物理规律；
6. **个性化**：少量样本定制。

## 12.总结

- **GAN** 对抗训练，清晰但不稳定；
- **VAE** 变分推断，稳定但模糊；
- **Diffusion** 加噪-去噪，当前 SOTA；
- **自回归** 逐像素，似然显式但慢；
- **流模型** 可逆，精确但受限；
- **文本到图像**：CLIP + Diffusion + CFG；
- **个性化**：DreamBooth、LoRA；
- **视频生成**：Sora、DiT；
- **3D 生成**：DreamFusion、NeRF；
- Diffusion 是 AIGC 的核心技术。
