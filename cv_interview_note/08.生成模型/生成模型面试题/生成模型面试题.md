# 生成模型面试题

## 1.基础概念

### Q1：生成模型要解决什么问题？

- 学习数据分布 $p(x)$，并能从中**采样新样本**；
- 与判别模型（学 $p(y|x)$）相对；
- 核心评估：样本质量、多样性、生成速度、似然。

### Q2：生成模型有哪些主要类别？

| 类别 | 代表 | 思想 |
| --- | --- | --- |
| GAN | StyleGAN | 对抗训练 |
| VAE | VQ-VAE | 变分推断 |
| Diffusion | DDPM, SD | 加噪-去噪 |
| 自回归 | PixelCNN, DALL-E | 逐步预测 |
| 流模型 | Glow | 可逆变换 |
| 能量模型 | EBM | 能量函数 |

### Q3：GAN、VAE、Diffusion 的整体对比？

| 维度 | GAN | VAE | Diffusion |
| --- | --- | --- | --- |
| 训练方式 | 对抗 | 变分下界 | 去噪回归 |
| 稳定性 | 差 | 好 | 好 |
| 生成质量 | 清晰 | 模糊 | 清晰 |
| 多样性 | 易崩溃 | 好 | 好 |
| 似然 | 无 | 下界 | 下界 |
| 采样速度 | 快（单步） | 快（单步） | 慢（多步迭代） |

### Q4：显式密度与隐式密度模型的区别？

- 显式：直接建模 $p(x)$（VAE 下界、流模型精确似然、自回归）；
- 隐式：只学采样过程，不含密度（GAN）；
- Diffusion 的反向过程有概率解释，介于两者之间。

## 2.GAN

### Q5：GAN 的目标函数？

$$
\min_G \max_D \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z}[\log(1 - D(G(z)))]
$$

- D 最大化：分清真假；
- G 最小化：骗过 D；
- 最优时 $p_g = p_{data}$，$D(x) = 1/2$。

### Q6：什么是模式崩溃（mode collapse）？

- G 只输出少数几种样本骗过 D；
- 多样性丧失，覆盖不了真实分布多峰；
- 解决：minibatch discrimination、unrolled GAN、WGAN、VSGAN、对比正则等。

### Q7：GAN 训练为什么不稳定？

- 极小极大博弈无全局单调目标；
- 梯度消失：D 太强时 G 学不动；
- JS 散度在分布不重叠时无梯度；
- 超参敏感，需要平衡 G/D 学习率。

### Q8：WGAN 的改进？

- 用 Wasserstein 距离替代 JS 散度，分布不重叠时仍有梯度；
- 要求 critic 满足 Lipschitz 约束：权重裁剪（WGAN）/ 梯度惩罚（WGAN-GP）；
- 训练更稳，loss 与生成质量相关。

### Q9：条件 GAN（cGAN）如何可控生成？

- D 与 G 都额外接收条件 $c$（标签 / 文本 / 图）；
- $G(z, c) \to x$，$D(x, c)$ 判断真假与匹配；
- pix2pix 即以图为条件的 cGAN。

### Q10：StyleGAN 系列的关键技术？

1. Mapping network $W$ 空间解耦风格；
2. AdaIN 逐层注入风格；
3. 渐进式增长（v1）/ 简化架构（v2）；
4. StyleGAN3 解决纹理粘连（aliasing）。

## 3.VAE

### Q11：ELBO 的推导与含义？

$$
\log p(x) \geq \mathbb{E}_{q(z|x)}[\log p(x|z)] - KL(q(z|x) \| p(z))
$$

- 由 $\log p(x) = \text{ELBO} + KL(q(z|x) \| p(z|x))$ 得；
- 后验 $p(z|x)$ 不可解，最大化 ELBO 即同时逼近后验、最大化似然。

### Q12：重参数化技巧为什么必要？

- $z \sim \mathcal{N}(\mu, \sigma^2)$ 采样节点不可导；
- 改写为 $z = \mu + \sigma \odot \epsilon, \epsilon \sim \mathcal{N}(0, I)$；
- 随机性移到 $\epsilon$，梯度可经 $\mu, \sigma$ 回传 encoder。

### Q13：VAE 与 AE 的区别？

| 维度 | AE | VAE |
| --- | --- | --- |
| 潜变量 | 确定值 | 分布 $q(z|x)$ |
| 概率解释 | 无 | 有（ELBO） |
| 生成能力 | 无（空间无结构） | 有（先验采样） |
| 损失 | 重建 | 重建 + KL |

### Q14：VAE 生成模糊的原因？

- 高斯假设 + MSE 倾向输出"均值"；
- KL 约束使后验偏散，$z$ 信息不足；
- 解决思路：引入对抗（VQ-GAN）、扩散（LDM decoder）。

### Q15：VQ-VAE 的离散化思路？

- codebook 最近邻量化：$z_q = \arg\min_k \|z_e - e_k\|$；
- 直通估计（straight-through）传梯度；
- 损失 = 重建 + codebook 对齐 + commitment；
- 离散 token 是 DALL-E、BEiT 等模型的基础。

### Q16：什么是 posterior collapse？

- decoder 太强直接忽略 $z$，KL 项为 0；
- 缓解：KL annealing、削弱 decoder、VQ 离散化、free bits。

## 4.扩散模型

### Q17：前向过程的公式？

$$
q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t}\, x_{t-1}, \beta_t I)
$$

- 可一步到位：$x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$。

### Q18：扩散模型的训练目标？

- 网络预测加入的噪声 $\epsilon_\theta(x_t, t)$；

$$
L = \mathbb{E}_{x_0, \epsilon, t} \left[ \| \epsilon - \epsilon_\theta(\sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t}\epsilon, t) \|^2 \right]
$$

- 训练稳定（纯回归），无对抗。

### Q19：反向过程如何采样？

$$
p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t))
$$

- 从 $x_T \sim \mathcal{N}(0, I)$ 起步，逐步用 $\mu_\theta$ 去噪。

### Q20：DDIM 的加速原理？

- 非马尔可夫前向假设，训练目标与 DDPM 兼容；
- 推理时任意子序列跳步（20~50 步）；
- 确定性采样，同 latent 可复现。

### Q21：score-based model 与 DDPM 的关系？

- score matching 学 $\nabla_x \log p(x)$；
- $\epsilon_\theta \propto -\nabla_{x_t} \log p(x_t)$，噪声预测即分数；
- SDE 统一框架（VP-SDE / VE-SDE）。

### Q22：Diffusion 与 GAN 各自优缺点？

| 维度 | Diffusion | GAN |
| --- | --- | --- |
| 质量 + 多样性 | 好 | 好（多样性差） |
| 训练稳定性 | 好 | 差 |
| 采样速度 | 慢（迭代） | 快（单步） |
| 可控性 | 条件机制丰富（CFG 等） | cGAN 较弱 |

## 5.Stable Diffusion

### Q23：latent diffusion 的核心动机？

- 像素扩散计算量大，VAE 压缩后（512→64×64×4）开销降约 48 倍；
- 感知压缩与生成学习解耦。

### Q24：CFG 的公式与作用？

$$
\hat{\epsilon} = \epsilon(z_t, \varnothing) + w(\epsilon(z_t, c) - \epsilon(z_t, \varnothing))
$$

- 沿条件方向外推，$w$ 常取 7~8；
- 太小欠遵从 prompt，太大画面过饱和。

### Q25：SD 三个组件分别是什么？

1. VAE：latent 与像素互转；
2. UNet：带 time embedding 与 cross-attention 的去噪网络；
3. CLIP text encoder：文本 token 化（77×768）。

### Q26：img2img 中 strength 的作用？

- 控制初始加噪程度 / 去噪起点；
- 0.2~0.4 微调原图，0.6~0.8 大幅重绘，1 等价 txt2img。

### Q27：LoRA 的原理？

- 假设微调增量低秩：$\Delta W = BA$；
- 参数量降低 3~4 个量级，可合并、可叠加。

### Q28：SDXL 与 SD3 的核心变化？

- SDXL：2.6B UNet，双文本编码器，refiner，micro-conditioning；
- SD3：MMDiT 联合注意力 + rectified flow + 三文本编码器（含 T5）。

### Q29：ControlNet 如何保证不破坏原模型？

- 冻结原 UNet；
- 可训练副本分支用**零卷积**初始化，训练初始输出为 0，从恒等映射平滑学习。

## 6.评价指标

### Q30：IS（Inception Score）的原理与缺陷？

$$
IS = \exp\left(\mathbb{E}_x KL(p(y|x) \| p(y))\right)
$$

- 单张图类别明确（条件熵低）+ 整体多样（边缘熵大）得分高；
- 缺陷：依赖 Inception 分类器、不看真实数据分布、对模式崩溃不敏感。

### Q31：FID 怎么计算？为什么比 IS 常用？

$$
FID = \|\mu_r - \mu_g\|^2 + \text{Tr}(\Sigma_r + \Sigma_g - 2(\Sigma_r \Sigma_g)^{1/2})
$$

- 真实 / 生成图像的 Inception 特征拟合高斯后的 Fréchet 距离；
- 同时对比真实分布，能反映质量与多样性，越低越好；
- 缺陷：需要大样本、依赖特征提取器。

### Q32：PPL（Perceptual Path Length）衡量什么？

- StyleGAN 提出，衡量隐空间插值路径上图像变化的感知平滑度；
- 越小说明隐空间越平滑、解耦越好。

### Q33：还有哪些常用生成评估指标？

- **CLIPScore**：图文对齐程度；
- **Precision / Recall**：分别衡量质量与多样性；
- **FID 变体**：KID（无偏、小样本友好）、rFID；
- **人工评估 / 用户研究**：仍是金标准。

## 7.综合题

### Q34：如何为业务选生成模型？

| 场景 | 推荐 |
| --- | --- |
| 高质量文生图 | SD / SDXL / SD3 |
| 实时图像转换 | GAN（pix2pix、StyleGAN） |
| 表征 + 重建 | VAE / VQ-VAE |
| 可控生成 | SD + ControlNet |
| 个性化主体 | DreamBooth / LoRA / IP-Adapter |

### Q35：生成模型当前的主要挑战？

1. 采样速度（扩散多步迭代）；
2. 长文本 / 复杂语义对齐；
3. 可控性与一致性（人物、风格跨图保持）；
4. 评估指标与人感不完全一致；
5. 数据版权与安全问题。
