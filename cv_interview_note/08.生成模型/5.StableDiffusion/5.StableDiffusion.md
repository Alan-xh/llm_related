# 4.StableDiffusion

## 1.概述

**Stable Diffusion（SD）** 由 Stability AI、Runway 与慕尼黑 LMU 合作于 2022 年开源，其技术基础是 **LDM（Latent Diffusion Model）**。SD 把扩散过程从像素空间搬到**隐空间（latent space）**，大幅降低计算成本，使高质量文生图能在消费级 GPU 上运行，是 AIGC 普及的里程碑。

**论文**：High-Resolution Image Synthesis with Latent Diffusion Models (Rombach et al., 2022)

### 1.1 发展时间线

| 时间 | 版本 | 关键变化 |
| --- | --- | --- |
| 2022.08 | SD 1.4 / 1.5 | CLIP ViT-L 文本编码器，512 分辨率 |
| 2022.11 | SD 2.x | OpenCLIP、深度图条件、768 分辨率 |
| 2023.07 | SDXL | 3.5B UNet、双文本编码器、refiner |
| 2024.06 | SD 3 | MMDiT 架构、rectified flow |
| 2024.10 | SD 3.5 | 开源版本、多模态 DiT 改进 |

## 2.LDM 核心原理

### 2.1 为什么在隐空间扩散

- 像素空间扩散（DDPM）计算量巨大：一张 512×512×3 图像含约 78 万维，注意力操作开销 $O((HW)^2)$；
- LDM 观察：**感知压缩与生成学习可以解耦**；
- 先用 VAE 把图像压缩到隐空间，扩散只在隐空间进行，最后解码回像素。

### 2.2 VAE 压缩

- 训练一个自编码器，下采样倍率 $f=8$：$512 \times 512 \times 3 \to 64 \times 64 \times 4$；
- 压缩比：像素减少 $\frac{512 \times 512 \times 3}{64 \times 64 \times 4} = 48$ 倍；
- 4 通道隐编码（KL 正则或 VQ 正则）保留绝大部分感知信息；
- 扩散在 $64 \times 64 \times 4$ 的 latent 上进行，训练与推理开销下降 1~2 个数量级。

### 2.3 latent 与 pixel 扩散对比

| 维度 | Pixel Diffusion | Latent Diffusion |
| --- | --- | --- |
| 扩散空间 | 像素 | VAE latent |
| 计算量 | 大 | 小（约 1/48） |
| 分辨率扩展 | 难 | 容易 |
| 生成细节 | 理论上限高 | 受 VAE 重建上限约束 |

## 3.SD 三大组件

```
                    文本 prompt "a cat"
                          │
                          ▼
              ┌───────────────────────┐
              │ CLIP Text Encoder     │
              │ (77 tokens × 768 dim) │
              └───────────┬───────────┘
                          │ context (K,V)
                          ▼
噪声 z_T ──> ┌───────────────────────┐
            │   UNet (去噪骨干)      │
            │   ResBlock + Attn      │
            │   time emb + cross-attn│
            └───────────┬───────────┘
                        │ 预测噪声 ε (T 步迭代去噪)
                        ▼
                 latent z_0 (64×64×4)
                        │
                        ▼
              ┌───────────────────────┐
              │ VAE Decoder           │
              └───────────┬───────────┘
                          ▼
                  图像 512×512×3
```

### 3.1 VAE

- **Encoder**：图像 $\to$ latent（仅 img2img / 训练时用）；
- **Decoder**：latent $\to$ 图像（每次生成必用）；
- 8 倍下采样，latent 通道数 4；
- SD3 / FLUX 的 VAE 压缩到 16 通道，保留更多细节。

### 3.2 UNet

- 结构：对称 encoder-decoder + 中间层，含大量 **ResBlock** 与 **自注意力 / 交叉注意力**；
- **Time Embedding**：把时间步 $t$ 用正弦编码 + MLP 注入每个 ResBlock：

$$
h = h + \text{SiLU}(\text{Linear}(\text{SinEmb}(t))) \cdot h
$$

- **Cross-Attention**（文本注入位置）：

$$
\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right)V, \quad Q \text{来自图像特征}，K, V \text{来自文本}
$$

- SD1.5 UNet 约 860M 参数，SDXL 约 2.6B。

### 3.3 CLIP Text Encoder

- 用 CLIP 的 text tower（ViT-L/14 的文本端，768 维，最多 77 token）；
- 输出 77×768 的 token 序列，作为 cross-attention 的 $K, V$；
- **只取文本端，不用图像端**，训练时常冻结；
- 77 token 上限是 SD 对超长 prompt 理解差的原因之一。

### 3.4 完整推理流程（文生图）

```text
1. prompt ──CLIP──> text embedding (77×768)
2. 采样 z_T ~ N(0, I),  shape 64×64×4
3. for t = T, T-1, ..., 1:
     ε_θ = UNet(z_t, t, text_emb)      # 预测噪声
     z_{t-1} = sampler(z_t, ε_θ)        # 采样器更新
4. image = VAE_Decoder(z_0)             # 解码得 512×512 图像
```

## 4.文本条件机制

### 4.1 Cross-Attention 细节

- UNet 每个分辨率层的 attention block 后接 cross-attention；
- 图像特征 reshape 为序列做 $Q$，文本 token 做 $K, V$；
- 注意力权重即"图像区域关注哪些词"，是 prompt 权重技巧（如 `(word:1.2)`）的作用位置。

### 4.2 Classifier-Free Guidance（CFG）

- 训练时以概率 0.1~0.2 丢弃条件（置空 prompt），模型同时学会条件 / 无条件去噪；
- 推理时外推两者差异，放大条件影响：

$$
\hat{\epsilon}_\theta(z_t, c) = \epsilon_\theta(z_t, \varnothing) + w \cdot \left(\epsilon_\theta(z_t, c) - \epsilon_\theta(z_t, \varnothing)\right)
$$

- $w = 1$：无引导；$w$ 常取 7~8；

```python
# CFG 伪代码
eps_cond   = unet(z_t, t, text_emb)
eps_uncond = unet(z_t, t, null_emb)
eps        = eps_uncond + w * (eps_cond - eps_uncond)
```

### 4.3 guidance scale 的影响

| $w$ | 效果 |
| --- | --- |
| 1 | 贴合分布但欠拟合 prompt |
| 5~9 | 常用区间，质量与对齐平衡 |
| 过大（>15） | 过饱和、对比度过高、画面崩坏 |

## 5.采样器

| 采样器 | 类型 | 特点 | 步数 |
| --- | --- | --- | --- |
| DDPM | 随机 | 原始方法，慢 | ~1000 |
| DDIM | 确定性 | 非马尔可夫，可跳步，同 seed 可复现 | 20~50 |
| Euler a | 随机 | 收敛快、风格有创造性，细节偏"手绘" | 20~30 |
| Euler | 确定性 | 稳定、直接 | 20~30 |
| DPM++ 2M | 确定性 | 高质量，常配 karras 噪声表 | 20~30 |
| DPM++ 2M SDE | 随机 | 细节更丰富，稍慢 | 20~30 |
| UniPC | 预测-校正 | 少步数（5~10）表现好 | 5~10 |

- **karras schedule**：噪声表按余弦排布，末端步长更细，低步数质量更高；
- 随机采样器换 seed 结果变化大；确定性采样器同 seed 严格可复现。

## 6.版本演进

### 6.1 SD1.5 vs SD2.x

| 维度 | SD 1.5 | SD 2.x |
| --- | --- | --- |
| 文本编码器 | CLIP ViT-L（OpenAI） | OpenCLIP ViT-H（更大） |
| 分辨率 | 512 | 768 原生 |
| 条件能力 | 仅有文本 | + 深度图（Depth2Img） |
| 生态 | 最丰富（LoRA 无数） | 相对少 |

- OpenCLIP 换掉了 CLIP 的过滤数据，NSFW 与名人内容被削弱，但也导致部分风格能力变化；
- OpenNSEEQ（OpenCLIP 训练细节）非核心组件，理解为"更大更强的开源 CLIP"即可。

### 6.2 SDXL（2023）

- UNet 2.6B + 更多 attention block，原生 1024 分辨率；
- **双文本编码器**：CLIP ViT-L + OpenCLIP ViT-bigG，两路拼接（77×2048）；
- **Refiner**：两级流水线，base 生成粗图，refiner 在同 latent 上精修高频细节；
- 额外 size / crop conditioning：把原始尺寸、裁剪坐标作为条件，避免构图偏差；
- micro-conditioning 显著改善了人体结构与手部。

### 6.3 SD3（2024）

**论文**：Scaling Rectified Flow Transformers for High-Resolution Image Synthesis (Esser et al., 2024)

- **MMDiT（Multimodal DiT）**：文本与图像 token 用**两套独立权重**做联合注意力，不再以 cross-attention 侧注入；

```
图像 token ──Q_i,K_i,V_i(权重A)──┐
                                 ├── joint self-attention ──> 更新图像 token
文本 token ──Q_t,K_t,V_t(权重B)──┘                └──> 更新文本 token
```

- **Rectified Flow** 训练目标：直接学"直线路径"从噪声到数据，少步数采样质量更高；
- 文本编码器三个：CLIP-L + CLIP-bigG + T5-XXL（拼成 4096 维），大幅提升文字渲染与复杂 prompt 理解；
- 8B 参数，遵循 scaling law 训练。

## 7.生态与微调

| 方法 | 训练对象 | 参数量 | 显存/数据需求 | 特点 |
| --- | --- | --- | --- | --- |
| Full Finetune | 整个 UNet | 100% | 极高 | 效果最强、易灾难遗忘 |
| DreamBooth | 整个 UNet + 稀有 token | 100% | 3~5 张图 | 学特定主体，需先验保持 loss |
| Textual Inversion | 新增 1 个 token embedding | ~1K 参数 | 3~5 张图 | 极轻量，能力有限（只学概念） |
| LoRA | 低秩增量矩阵 | ~0.1~1% | 几十~几百张 | 训练快，可多个叠加切换 |
| ControlNet | UNet 副本（可训练） | ~1B（冻结主干） | 大量配对图 | 精确空间控制（边缘/姿态/深度） |
| IP-Adapter | 解耦 cross-attn 适配器 | ~22M | 大量图 | 图像作为 prompt，保持身份 |

### 7.1 ControlNet

- 复制 UNet encoder 的一份作为可训练分支，零卷积初始化；
- 冻结原 UNet，条件图（canny、openpose、depth 等）控制构图；
- `可控条件 + 文本语义` 解耦，控制精度远高于 prompt。

### 7.2 LoRA

- 假设微调的权重增量是低秩的：$\Delta W = BA$，$B \in \mathbb{R}^{d \times r}, A \in \mathbb{R}^{r \times k}$，$r \ll \min(d, k)$；
- 只训 $A, B$，参数量从 $d \times k$ 降到 $r(d + k)$；
- 推理时可合并回原权重，**零额外延迟**；
- SD 社区事实上的微调标准，多个 LoRA 可按权重线性组合。

### 7.3 DreamBooth 与 Textual Inversion

- DreamBooth：少量图全参微调 + 稀有 token（如 `sks dog`）指代主体，配合先验保持 loss 防过拟合；
- Textual Inversion：不动网络权重，只在 embedding 空间为新概念找一个向量；
- 共同点：少样本个性化；差异：前者改权重能力强但易遗忘，后者极轻但只能学简单概念。

## 8.应用

### 8.1 txt2img

- 纯噪声起步，文本引导去噪，即第 3.4 节标准流程。

### 8.2 img2img

1. 原图经 VAE encoder 得 latent；
2. 按 **strength** 加噪到某一步 $t_{start}$（不是 $T$）；
3. 从 $t_{start}$ 开始去噪。

- **strength**：加噪比例，0~1；
  - 小（0.2~0.4）：接近原图，微改；
  - 大（0.6~0.8）：构图保留、内容重画；
  - 1.0：等价 txt2img；
- 本质是在"原图"与"纯噪声"之间选起点，控制生成自由度。

### 8.3 Inpainting

- mask 指定重绘区域；
- 每步去噪时：mask 内用预测结果，mask 外用原图加噪后的 latent；
- SD2/SDXL 有专门 inpainting 权重（多 5 通道输入：4 latent + 1 mask）。

### 8.4 Upscale

- **Latent upscale**：放大 latent 再低强度去噪（易加细节也易变脸）；
- **专用超分模型**：ESRGAN、SD Upscale（分块超分 + 重绘）；
- SDXL Refiner 也可视作精修式 upscale。

## 9.延伸：其他生成范式与应用

### 9.1 自回归模型

- 把图像当 token 序列，$p(x) = \prod_i p(x_i | x_{<i})$，显式似然、训练稳定，但逐步生成慢；
- **PixelCNN**（2016）：masked conv 逐像素生成；**PixelSNAIL**：加 attention；**ImageGPT**（2020）：GPT 架构做图像自回归；
- **DALL-E**（2021）：VQ-VAE 离散化图像为 token，Transformer 自回归"文本->图像 token"，文生图开创者。

### 9.2 流模型与能量模型

- **流模型**（RealNVP 2017、Glow 2018）：可逆变换 + 易算 Jacobian，精确似然、单次前向生成，但架构受限、高维表达弱；
- **能量模型**（EBM）：$p(x) \propto \exp(-E_\theta(x))$，配分函数难算，训练（score matching）与采样（MCMC）都难，与 score-based diffusion 理论相通。

### 9.3 视频与 3D 生成

- **视频生成**：核心挑战是时序一致性、长视频漂移与算力；代表：Sora（DiT + 时空 patch）、Stable Video Diffusion、AnimateDiff、Runway / Pika；
- **3D 生成**：NeRF 用神经网络表示辐射场做任意视角渲染；DreamFusion 用 SDS loss 把 SD 的先验蒸馏进 NeRF；Point-E / Shap-E 直接生成 3D；Gaussian Splatting 提供高效 3D 表示。

## 10.面试常考问题

**Q1：为什么在 latent 空间做扩散而不是像素空间？**

- 像素空间维度高、冗余大，扩散训练贵；
- VAE 先做感知压缩（48 倍降维），去掉高频冗余、保留语义结构；
- 扩散专注生成学习，效率提升 1~2 个数量级；
- 代价：细节上限受 VAE decoder 制约。

**Q2：SD 的三大组件及作用？**

| 组件 | 作用 |
| --- | --- |
| VAE | 压缩 / 解码，连接像素与 latent |
| UNet | 去噪骨干，预测每步噪声 |
| CLIP text encoder | 文本编码，经 cross-attn 注入 |

**Q3：CFG 的原理？guidance scale 怎么影响结果？**

- 无分类器引导：同一模型做条件与无条件两种预测，沿"条件-无条件"方向外推；
- $w$ 越大 prompt 遵从度越高，但过大会过饱和、画面崩坏；常用 7~8；
- 训练时随机丢条件（10~20%），无需额外分类器。

**Q4：img2img 的 strength 是什么？**

- 对原图的加噪比例，决定去噪起点 $t_{start}$；
- 小 strength 保留原图多，大 strength 重画自由度大；
- strength=1 退化为 txt2img。

**Q5：LoRA 为什么能用极少参数微调？**

- 微调的权重变化量 $\Delta W$ 是低秩的；
- $\Delta W = BA$，秩 $r$ 取 8~128，参数量降 3~4 个数量级；
- 低容量天然正则，不易灾难遗忘；
- 推理时可合并，零延迟。

**Q6：ControlNet 如何做到精确控制？**

- 复制 UNet encoder 为可训练分支 + 零卷积初始化（初始不扰动原模型）；
- 冻结主干，条件图只在副本中注入；
- 空间控制与文本语义解耦。

**Q7：time embedding 的作用与注入方式？**

- 告诉网络当前在去噪的第几步（噪声水平）；
- 正弦位置编码 + MLP 后以 scale-shift 或加法注入每个 ResBlock。

**Q8：文本如何注入 UNet？**

- CLIP 编码为 token 序列；
- 在 UNet 的 cross-attention 中做 $K, V$，图像特征做 $Q$；
- 注意力权重对应图像区域与词的关联。

**Q9：DDIM 为什么能加速？**

- 建立非马尔可夫前向过程，保证与 DDPM 同一训练目标；
- 推理可跳步、确定性采样，20~50 步即可；
- 同 seed 结果可复现。

**Q10：SD2.x 相比 1.5 的主要变化？**

- CLIP ViT-L -> OpenCLIP ViT-H；512 -> 768 原生；
- 新增 depth2img、更强 prompt 理解。

**Q11：SDXL 的关键改进？**

- 2.6B UNet、原生 1024；
- 双文本编码器（CLIP ViT-L + OpenCLIP bigG）拼接；
- base + refiner 两段式；size/crop micro-conditioning。

**Q12：SD3 的 MMDiT 与传统 cross-attention 的区别？**

- 传统：文本做 $K,V$ 单向注入图像；
- MMDiT：文本、图像各自一套 $Q,K,V$ 权重，做联合 self-attention，双向信息交换；
- 配合 rectified flow，少步数高质量。

**Q13：DreamBooth、Textual Inversion、LoRA 如何选？**

- 学特定主体且显存够：DreamBooth；
- 只学一个新概念、要求极轻：Textual Inversion；
- 学风格 / 大幅能力增强、要多模型叠加：LoRA。

**Q14：inpainting 如何保持 mask 外区域不变？**

- 每步把 mask 外 latent 替换为原图加噪到该步的值；
- 专用 inpainting 模型额外输入 mask 通道。

**Q15：latent 64×64 是怎么来的？为什么是 4 通道？**

- 512/8 = 64，VAE 下采样倍率 8；
- 4 通道是 KL 正则 VAE 的设计选择，信息瓶颈保住语义细节；
- SD3 升到 16 通道以保留更多高频信息。

## 11.总结

- **LDM** 把扩散搬到 VAE latent，是 SD 高效的核心；
- 三大组件：**VAE（压缩）/ UNet（去噪）/ CLIP（文本条件）**；
- **CFG** 通过条件外推平衡质量与 prompt 遵从；
- 采样器（DDIM、Euler a、DPM++）决定速度与风格差异；
- 版本演进：1.5 -> 2.x（OpenCLIP）-> SDXL（双编码器 + refiner）-> SD3（MMDiT + rectified flow）；
- 生态：**ControlNet、LoRA、DreamBooth、IP-Adapter** 构成可控与个性化生成体系；
- 应用：txt2img / img2img（strength）/ inpainting / upscale；
- 其他范式（自回归、流、能量模型）与视频、3D 生成的思想共同构成生成模型全景。
