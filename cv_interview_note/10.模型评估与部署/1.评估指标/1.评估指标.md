# 1.评估指标

## 1.概述

模型训练完成后，需要用**量化指标**衡量好坏；不同任务有不同的指标体系。**评估指标**是模型选型、调参、上线的依据，也是面试高频考点。

**按任务分类**：

| 任务 | 主指标 | 辅助指标 |
| --- | --- | --- |
| 分类 | Accuracy / F1 | PR 曲线、ROC/AUC |
| 目标检测 | mAP@0.5、mAP@0.5:0.95 | FPS、AR |
| 语义分割 | mIoU | Dice、PA |
| 实例/全景分割 | Mask mAP、PQ | mIoU |
| 图像生成 | FID | IS、LPIPS、CLIP Score |

## 2.分类指标

### 2.1 混淆矩阵

二分类基础，所有指标都由它派生：

|  | 预测正 | 预测负 |
| --- | --- | --- |
| 真实正 | TP（真正例） | FN（假负例） |
| 真实负 | FP（假正例） | TN（真负例） |

- **TP**：预测为正且确实为正；
- **FP**：预测为正但实际为负（误检）；
- **FN**：预测为负但实际为正（漏检）；
- **TN**：预测为负且确实为负。

### 2.2 Precision / Recall / F1

$$
Precision = \frac{TP}{TP + FP}
$$

$$
Recall = \frac{TP}{TP + FN}
$$

$$
F1 = \frac{2 \cdot P \cdot R}{P + R}
$$

- **Precision**（查准率）：预测为正中真正为正的比例，关注**误检**；
- **Recall**（查全率）：真实为正中被找出来的比例，关注**漏检**；
- **F1**：P 和 R 的调和平均，两者都要高 F1 才高；
- 调和平均对低值敏感：P=1.0、R=0.1 时 F1≈0.18，而非算术平均的 0.55。

**Accuracy 陷阱**：

$$
Accuracy = \frac{TP + TN}{TP + FP + FN + TN}
$$

- 类别不平衡时失效：99% 负样本，全预测负也有 99% 准确率；
- 此时应用 F1 / PR-AUC 等。

**F-beta**：

$$
F_\beta = (1+\beta^2)\frac{P \cdot R}{\beta^2 P + R}
$$

- β>1 偏重 Recall（如癌症筛查）；
- β<1 偏重 Precision（如垃圾邮件拦截）。

### 2.3 PR 曲线

- 横轴 Recall，纵轴 Precision；
- 阈值从高到低扫描，每个阈值对应一个 (R, P) 点；
- **AP**（Average Precision）= PR 曲线下面积：

$$
AP = \int_0^1 P(R) \, dR \approx \sum_{k=1}^{n} P(k) \cdot \Delta r(k)
$$

- 实际用离散求和（如 11 点插值或全点求和）；
- **正样本越多，PR 曲线越可靠**；
- 类别不平衡下 PR 曲线比 ROC 更敏感。

### 2.4 ROC 与 AUC

- **ROC**：横轴 FPR，纵轴 TPR；

$$
TPR = \frac{TP}{TP + FN}, \quad FPR = \frac{FP}{FP + TN}
$$

- **AUC**：ROC 曲线下面积，取值 [0.5, 1]；
- **概率解释**：随机取一正一负样本，正样本得分更高的概率；
- AUC=0.5 等价于随机猜测；
- 对类别不平衡**不敏感**（FPR 分母是负样本数），不平衡场景慎用。

**PR vs ROC 选择**：

| 维度 | PR 曲线 | ROC 曲线 |
| --- | --- | --- |
| 适用场景 | 类别极不平衡 | 类别相对平衡 |
| 关注点 | 正样本检出质量 | 整体排序能力 |
| 不平衡敏感性 | 敏感（推荐） | 不敏感 |
| 典型任务 | 检测、搜索召回 | 医疗诊断、风控 |

### 2.5 多分类指标：macro / micro

设每类有 $P_i, R_i$：

- **macro**（宏平均）：先算每类指标再平均，

$$
P_{macro} = \frac{1}{C}\sum_{i=1}^{C} P_i
$$

- **micro**（微平均）：把所有类的 TP/FP 汇总后再算，

$$
P_{micro} = \frac{\sum_i TP_i}{\sum_i TP_i + \sum_i FP_i}
$$

- **weighted**：按样本数加权平均；
- **macro 每类权重相同**：小类别差会拉低指标，关注小类时用；
- **micro 由大类主导**：样本多的话语权大；
- 多分类单样本可拆成多个二分类（one-vs-rest）。

### 2.6 Top-K 准确率

$$
Top\text{-}K\ Acc = \frac{命中真实标签在前K预测内的样本数}{总样本数}
$$

- ImageNet 常用 Top-1 和 Top-5；
- Top-5 容忍"接近正确"的预测。

## 3.检测指标

### 3.1 IoU

$$
IoU = \frac{|B_{pred} \cap B_{gt}|}{|B_{pred} \cup B_{gt}|}
$$

- 预测框与真实框的交并比；
- 判定 TP/FP 的标准（如 IoU > 0.5 算检出）；
- 目标框回归的核心度量（IoU Loss / GIoU / DIoU / CIoU 的基础）。

### 3.2 mAP@0.5 与 mAP@0.5:0.95

**计算流程**（单类）：

```
1. 所有预测框按置信度降序排序
2. 逐个判定 TP（IoU>=阈值且未匹配过）/ FP
3. 累积计算 PR 曲线 -> AP
4. 多类 AP 取平均 -> mAP
```

- **mAP@0.5**（VOC 风格）：IoU 阈值 0.5，较宽松；
- **mAP@0.5:0.95**（COCO 风格）：IoU 从 0.5 到 0.95 步长 0.05 共 10 个阈值取平均，

$$
mAP@[.5:.95] = \frac{1}{10}\sum_{t=0.50}^{0.95} mAP@t
$$

- COCO 指标对**框的定位精度**要求更高；
- 通常 mAP@0.5:0.95 明显低于 mAP@0.5。

### 3.3 COCO 评测细节

- **AP^S / AP^M / AP^L**：按目标面积分层评测：

| 指标 | 目标面积（像素） |
| --- | --- |
| AP small | < 32² |
| AP medium | 32² ~ 96² |
| AP large | > 96² |

- 小目标 AP 低是普遍现象（下采样丢失信息）；
- **AR**（Average Recall）：每图最多检出 N 个框的召回（AR@1/10/100）；
- **注意事项**：
  - COCO 用 101 点插值法算 AP；
  - 所有类平均（含无目标类），不是只算出现类；
  - 预测框数上限影响 AR。

### 3.4 NMS 与 mAP 的关系

- 推理时先按置信度过滤，再 **NMS** 去重，最后才评测；
- **NMS 阈值**影响 mAP：
  - 阈值太低（如 0.3）：密集目标相邻框被误删 -> 漏检 -> mAP 降；
  - 阈值太高（如 0.7）：冗余框多 -> FP 增多 -> mAP 降；
  - 通常 0.5 是折中，需在验证集上调；
- **Soft-NMS**：不直接删除，而是降低重叠框置信度，密集场景更友好；
- 检测头后处理（NMS）是 mAP 评测链路的一环，改 NMS 策略也会改变指标。

### 3.5 速度指标

- **FPS**：每秒处理帧数；
- **延迟（Latency）**：单帧耗时（ms），需说明 batch 和硬件；
- 精度-速度权衡：mAP 高不代表可用，需看 Pareto 前沿。

## 4.分割指标

### 4.1 mIoU

$$
mIoU = \frac{1}{C}\sum_{c=1}^{C}\frac{TP_c}{TP_c + FP_c + FN_c}
$$

- 语义分割**主指标**；
- 每类 IoU = 交集像素 / 并集像素，再对类取平均；
- 小类别 IoU 波动大，常配合 per-class IoU 观察；
- 像素级不平衡严重，loss 与指标并不一致（CE 优化像素平均，mIoU 按类平均）。

### 4.2 Dice

$$
Dice = \frac{2|A \cap B|}{|A| + |B|}
$$

- 与 F1 等价（像素级）；
- **医学分割常用**，对小目标更友好（分母无 TN）；
- Dice Loss 可直接优化该指标。

### 4.3 PQ（全景分割）

$$
PQ = \underbrace{\frac{\sum_{(p,g)\in TP} IoU(p,g)}{|TP|}}_{SQ} \times \underbrace{\frac{|TP|}{|TP| + 0.5|FP| + 0.5|FN|}}_{RQ}
$$

- **SQ**（Segmentation Quality）：匹配对平均 IoU；
- **RQ**（Recognition Quality）：类似 F1；
- 匹配规则：IoU > 0.5 视为匹配（每个 GT 最多匹配一个预测）。

## 5.生成指标

### 5.1 FID（Fréchet Inception Distance）

- 用 Inception 网络分别提取**真实图**与**生成图**的特征，假设高斯分布，算两分布的距离：

$$
FID = \|\mu_r - \mu_g\|^2 + Tr(\Sigma_r + \Sigma_g - 2(\Sigma_r\Sigma_g)^{1/2})
$$

- **越低越好**；与人类感知相关性较好；
- 是当前图像生成的**主流指标**；
- 缺点：依赖 Inception 特征、需要足够样本数（小样本偏差大）、可能被对抗攻击。

### 5.2 IS（Inception Score）

$$
IS = \exp\left(E_x\, KL(p(y|x)\,\|\,p(y))\right)
$$

- $p(y|x)$：单张图的类别分布，应**尖锐**（生成图清晰可辨）；
- $p(y)$：整体类别分布，应**均匀**（多样性好）；
- **越高越好**；
- 缺点：不看真实数据分布、对 Inception 权重敏感，已逐渐被 FID 取代。

### 5.3 LPIPS（感知相似度）

- 用深度特征（如 AlexNet/VGG）加权距离度量两张图的**感知差异**：

$$
LPIPS(x, x') = \sum_l \frac{1}{H_l W_l}\sum_{h,w} \|w_l \odot (\phi_l(x)_{hw} - \phi_l(x')_{hw})\|_2^2
$$

- **越低越相似**；
- 比像素级 L2 更符合人眼感知；
- 用于：图像复原、超分、图像翻译、蒸馏（LDM 的感知损失）。

### 5.4 CLIP Score

- 用 CLIP 图文编码器的余弦相似度衡量**图文一致性**：

$$
CLIP\text{-}Score = \max(100 \cdot \cos(E_i, E_t), 0)
$$

- 文生图常用（如 SDXL 及各类文生图评测）；
- 越高图文越匹配；
- 缺点：难以衡量美学质量、可被高频细节干扰。

### 5.5 生成指标对比

| 指标 | 方向 | 衡量 | 主要问题 |
| --- | --- | --- | --- |
| FID | 越低越好 | 真实分布距离 | 依赖样本量与 Inception |
| IS | 越高越好 | 清晰度 + 多样性 | 不对比真实数据 |
| LPIPS | 越低越好 | 感知相似度 | 只比较两图 |
| CLIP Score | 越高越好 | 图文一致性 | 不衡量画质 |

## 6.指标选择建议

| 场景 | 推荐指标 | 原因 |
| --- | --- | --- |
| 类别平衡分类 | Accuracy | 直观够用 |
| 类别不平衡（负样本极多） | F1 / PR-AUC | Accuracy 虚高 |
| 关注小类 | macro-F1 | 小类话语权大 |
| 排序/阈值未定 | AUC | 与阈值无关 |
| 医疗诊断（漏诊代价高） | Recall / F2 | 偏重查全 |
| 目标检测 | mAP@0.5:0.95 + AP^S | 兼顾定位与小目标 |
| 语义分割 | mIoU（+Dice） | 类平均更公平 |
| 医学分割 | Dice | 小目标敏感 |
| 图像生成 | FID（+CLIP Score） | 主流组合 |
| 图像复原/超分 | LPIPS + PSNR/SSIM | 感知 + 像素 |

**选型原则**：

1. **指标与业务对齐**：误检和漏检哪个代价大；
2. **多指标联合看**：单一指标易被 hack；
3. **报告阈值与决策**：mAP 是阈值无关的，但上线要定阈值；
4. **注意数据分布**：测试集与线上分布是否一致。

## 7.面试常考问题

**Q1：Precision 和 Recall 的区别？如何权衡？**

- Precision：查准，预测为正中真正为正比例（关注误检）；
- Recall：查全，真实为正中被检出比例（关注漏检）；
- 通过调整分类阈值权衡：阈值高 P 高 R 低，阈值低反之；
- 按业务代价选择，或用 F1 / F-beta 综合。

**Q2：为什么类别不平衡时不用 Accuracy？**

- 全预测多数类 Accuracy 就很高但无意义；
- 例：1% 正样本，全预测负 Accuracy=99%，Recall=0；
- 应该用 F1、PR-AUC、macro 平均等。

**Q3：AUC 的概率含义？**

- 随机取一正一负样本，模型给正样本打分更高的概率；
- 与阈值无关，衡量排序能力；
- AUC=0.5 等于随机猜。

**Q4：ROC-AUC 和 PR-AUC 怎么选？**

- 不平衡严重（正样本稀少）：PR-AUC 更敏感直观；
- 平衡场景或关注整体排序：ROC-AUC；
- ROC 的 FPR 在负样本极大时增长缓慢，会高估模型。

**Q5：macro-F1 和 micro-F1 的区别？**

- macro：先算每类 F1 再平均，各类等权，小类影响大；
- micro：先汇总所有类 TP/FP/FN 再算，大类主导；
- 关注小类用 macro，关注整体用 micro。

**Q6：mAP@0.5 和 mAP@0.5:0.95 的区别？**

- mAP@0.5：单一 IoU 阈值 0.5，定位要求宽松；
- mAP@0.5:0.95：10 个阈值平均，定位要求严；
- 同一模型 mAP@0.5:0.95 通常低很多；
- COCO 风格更能区分定位质量。

**Q7：NMS 阈值如何影响 mAP？**

- 阈值低：密集目标相邻框被误删，漏检增，mAP 降；
- 阈值高：冗余框 FP 增多，mAP 降；
- 需在验证集上调，常用 0.5 附近；
- Soft-NMS 用衰减代替删除，密集小目标更稳。

**Q8：为什么小目标 AP 通常低？如何改善评测？**

- 深层特征图分辨率低，小目标信息丢失；
- 改善：高分辨率输入/特征（FPN 浅层）、切图推理、anchor 匹配策略；
- 评测上 COCO 专门报告 AP^S 分层指标。

**Q9：mIoU 为什么按类平均而不是全部像素平均？**

- 像素平均被大类主导（背景占大多数），小类被淹没；
- 按类平均（macro）每个类等权，更公平；
- 代价是小类 IoU 方差大，指标抖动。

**Q10：FID 比 IS 好在哪？**

- FID 对比生成分布与真实分布，IS 只看生成分布自身；
- FID 与人类感知相关性更强；
- IS 无法发现"记住训练集"（模式坍缩到真实子集仍可能高分）。

**Q11：上线一个检测模型，只看 mAP 够吗？**

- 不够；
- 还要看：FPS/延迟（是否实时）、误检率/漏检率（按业务阈值算）、
  长尾类别表现、bad case 分析、鲁棒性（光照/遮挡）；
- mAP 是阈值无关的均值，线上是固定阈值的点表现。

**Q12：Dice 和 IoU 的关系？**

- $Dice = \frac{2IoU}{1+IoU}$，单调递增；
- Dice 是 F1 的像素形式；
- Dice 对小目标更敏感（分母不含 TN）。

## 8.总结

- **分类**：混淆矩阵是根，P/R/F1 是核心，不平衡用 PR-AUC + macro；
- **检测**：IoU -> PR -> AP -> mAP，COCO 用多阈值 + 分层面积；
- **NMS 属于评测链路**：阈值调优直接影响 mAP；
- **分割**：mIoU 是主指标，医学用 Dice，全景用 PQ；
- **生成**：FID 主流，感知用 LPIPS，图文一致性用 CLIP Score；
- **选指标就是选业务偏好**：误检 vs 漏检代价决定方向。
