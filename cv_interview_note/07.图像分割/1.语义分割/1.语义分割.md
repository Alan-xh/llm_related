# 1.语义分割

## 1.概述

**语义分割（Semantic Segmentation）** 是计算机视觉中的基础任务，目标是为图像中**每个像素**分配一个类别标签。与目标检测输出 bbox 不同，语义分割输出**像素级分类**，是密集预测（Dense Prediction）任务的代表。

| 任务 | 输出 | 粒度 |
| --- | --- | --- |
| 分类 | 整图一个类别 | 图像级 |
| 检测 | N 个 bbox | 区域级 |
| **语义分割** | 每像素一个类别 | **像素级** |
| 实例分割 | 像素级 + 实例区分 | 实例级 |

## 2.FCN（Fully Convolutional Network, 2015）

**论文**：Fully Convolutional Networks for Semantic Segmentation (Long, Shelhamer & Darrell, UC Berkeley)

**核心创新**：**首次用全卷积网络做语义分割**，将分类网络的 FC 层替换为卷积层，实现端到端的像素级预测。

### 2.1 架构

```
Input (H×W×3)
    │
    ▼
VGG/ResNet Backbone (去 FC)
    │
    ▼ 粗 feature map (H/32 × W/32 × C)
    │
    ▼ 反卷积 / 上采样
    │
Output (H×W×num_classes)  # 每像素预测类别
```

### 2.2 核心思想

1. **全卷积**：去掉分类网络的 FC 层，全用卷积，可接受任意尺寸输入；
2. **转置卷积**：上采样低分辨率 feature 到原图尺寸；
3. **跳连（Skip）**：融合浅层细粒度 + 深层语义。

### 2.3 FCN-8s 的跳连

```
pool5 (H/32) ── 反卷积 ×2 ──┐
                              ├── 融合 ── 反卷积 ×2 ──┐
pool4 (H/16) ───────────────┘                        ├── 融合 ── 反卷积 ×8 ── Output
                                                    │
pool3 (H/8) ────────────────────────────────────────┘
```

### 2.4 缺点

1. **感受野与分辨率矛盾**：深层语义好但分辨率低，浅层反之；
2. **细节模糊**：边缘不清晰；
3. **未利用全局上下文**。

## 3.U-Net（2015）

**论文**：U-Net: Convolutional Networks for Biomedical Image Segmentation (Ronneberger et al.)

**核心思想**：**对称 encoder-decoder + 跳连**，医学图像分割的标杆。

### 3.1 架构

```
Encoder (下采样)               Decoder (上采样)
Input ── conv ── pool ─┬── conv ──── conv ── Output
                       │   │
                   ┌───┘   └───┐
                   │  concat  │  ← 跳连
                   │           │
              └── pool ── conv ── conv ── up ──┘
```

形状像 "U"：

- 左侧（Encoder）：逐步下采样，提取语义；
- 右侧（Decoder）：逐步上采样，恢复分辨率；
- **跳连**：将 encoder 同层 feature concat 到 decoder，补全细节。

### 3.2 优点

1. **小数据集友好**：医学图像数据少时仍表现好；
2. **细节精确**：跳连保留浅层细节；
3. **结构简洁**：易实现、易扩展；
4. **数据增强有效**：弹性形变增强。

### 3.3 U-Net 变体

- **U-Net++**：嵌套 U-Net，密集跳连；
- **Attention U-Net**：跳连加注意力；
- **U-Net 3+**：全尺度跳连；
- **nnU-Net**：自适应配置 U-Net，医学分割神器。

## 4.DeepLab 系列

### 4.1 DeepLab v1（2015）

- **CRF 后处理**：DCNN + CRF 精修边界；
- **空洞卷积**（atrous convolution）：扩大感受野不降分辨率。

### 4.2 DeepLab v2（2016）

- **ASPP（Atrous Spatial Pyramid Pooling）**：多尺度空洞卷积并行；

```
Input feature
    ├─ 1×1 conv
    ├─ 3×3 conv, rate=6
    ├─ 3×3 conv, rate=12
    └─ 3×3 conv, rate=18
        │
        ▼ concat + 1×1 conv
```

### 4.3 DeepLab v3（2017）

- **改进 ASPP**：加 BN + 全局平均池化分支；
- 去掉 CRF，纯网络结构。

### 4.4 DeepLab v3+（2018）

**核心改进**：**Encoder-Decoder + ASPP**：

```
Input ── Backbone ──┬── ASPP ──┐
                    │           │
                    └── 浅层 ───┴── Decoder ── Output
```

- Decoder 用低层特征补细节；
- 成为语义分割的**强 baseline**。

### 4.5 空洞卷积（Atrous Convolution）

$$
y[i] = \sum_k x[i + r \cdot k] \cdot w[k]
$$

- $r$：膨胀率（rate）；
- 扩大感受野不增加参数、不降分辨率；
- $r=1$ 退化为标准卷积。

## 5.PSPNet（2017）

**论文**：Pyramid Scene Parsing Network (Zhao et al., CUHK)

**核心创新**：**金字塔池化模块（PPM）**，聚合全局上下文：

```
Input feature ──┬── 1×1 pool (全局)
                ├── 2×2 pool
                ├── 3×3 pool
                └── 6×6 pool
                    │
                    ▼ concat + 上采样
```

- 不同尺度池化捕获全局-局部信息；
- 解决 FCN 的"缺乏全局上下文"问题；
- 场景解析（Scene Parsing）任务 SOTA。

## 6.SegFormer（2021）

**论文**：SegFormer: Simple and Efficient Design for Semantic Segmentation with Transformers (Xie et al., NVIDIA)

**核心思想**：**Transformer Encoder + 轻量 MLP Decoder**。

### 6.1 架构

```
Input ── Mix Transformer (MiT) Encoder ── 多尺度 feature
                                              │
                                              ▼
                                    MLP Decoder (融合 + 上采样)
                                              │
                                              ▼
                                          Output
```

### 6.2 特点

1. **无位置编码**：用 3×3 卷积的 zero-padding 隐式编码位置；
2. **多尺度 feature**：4 个 stage 输出都参与；
3. **轻量 MLP Decoder**：比 CNN decoder 更简单；
4. **性能强、参数少**：SegFormer-B5 mIoU 51.8%，比 DeepLab v3+ 好。

## 7.Encoder-Decoder vs Dilated

语义分割网络分两大流派：

| 流派 | 代表 | 特点 |
| --- | --- | --- |
| Encoder-Decoder | U-Net, DeepLab v3+ | 下采样再上采样，恢复分辨率 |
| Dilated（空洞卷积） | DeepLab v1/v2/v3, PSPNet | 不下采样，保持分辨率 |

## 8.损失函数

### 8.1 Cross Entropy

$$
L = -\frac{1}{N} \sum_i \sum_c y_{ic} \log \hat{y}_{ic}
$$

- 像素级 CE；
- 类别不平衡时加权 CE。

### 8.2 Dice Loss

$$
L_{Dice} = 1 - \frac{2 \sum_i p_i g_i + \epsilon}{\sum_i p_i + \sum_i g_i + \epsilon}
$$

- 直接优化 Dice 系数；
- 对类别不平衡鲁棒；
- 医学分割常用。

### 8.3 Lovász Loss

- 直接优化 IoU；
- 比 Dice 更好的凸近似。

### 8.4 组合

$$
L = L_{CE} + \lambda L_{Dice}
$$

医学分割常用组合。

## 9.评价指标

### 9.1 Pixel Accuracy

$$
PA = \frac{\sum_i TP_i}{\sum_i (TP_i + FP_i)}
$$

### 9.2 Mean IoU（mIoU）

$$
mIoU = \frac{1}{C} \sum_{c=1}^{C} \frac{TP_c}{TP_c + FP_c + FN_c}
$$

- **主指标**：每类 IoU 平均；
- Cityscapes、ADE20K 等基准。

### 9.3 Frequency Weighted IoU

按类别频率加权，反映整体性能。

## 10.经典数据集

- **PASCAL VOC 2012**：21 类，小数据集；
- **Cityscapes**：19 类城市场景，5000 张精标 + 20000 张粗标；
- **ADE20K**：150 类场景解析，25K 训练；
- **COCO-Stuff**：COCO 加 stuff 标注；
- **CamVid**：道路场景。

## 11.面试常考问题

**Q1：FCN 的核心创新？**

1. 全卷积网络，去掉分类网络的 FC；
2. 转置卷积上采样到原图尺寸；
3. 跳连融合浅层细节 + 深层语义；
4. 端到端像素级预测。

**Q2：U-Net 为什么在医学图像分割上好？**

- 对称结构恢复细节；
- 跳连保留浅层信息；
- 小数据集友好；
- 弹性形变增强适应医学图像；
- 简洁易用。

**Q3：空洞卷积的作用？**

- 扩大感受野不增加参数；
- 不降低分辨率（保持像素级精度）；
- 多尺度（ASPP）。

**Q4：DeepLab v3+ 的架构？**

- Encoder：Backbone + ASPP；
- Decoder：浅层特征 + ASPP 输出融合；
- ASPP：多尺度空洞卷积 + 全局池化；
- 比 v3 更精确。

**Q5：ASPP 怎么做多尺度？**

- 多个并行分支，rate 不同（6, 12, 18）；
- 加 1×1 conv 和全局池化；
- concat 融合，捕获多尺度上下文。

**Q6：PSPNet 的金字塔池化？**

- 4 个尺度池化（1×1, 2×2, 3×3, 6×6）；
- 聚合全局-局部信息；
- 解决 FCN 缺乏全局上下文问题。

**Q7：SegFormer 为什么无位置编码？**

- 用 3×3 卷积的 zero-padding 隐式编码位置；
- 支持任意输入尺寸；
- 简化设计。

**Q8：Dice Loss 和 CE 的区别？**

- CE：像素级，类别不平衡敏感；
- Dice：直接优化 IoU，对不平衡鲁棒；
- 医学分割常用 CE + Dice 组合。

**Q9：mIoU 怎么计算？**

- 每类 IoU = TP / (TP + FP + FN)；
- 所有类 IoU 平均；
- 是语义分割主指标。

**Q10：语义分割怎么处理小目标？**

1. 高分辨率输入 / 高分辨率 feature；
2. FPN 多尺度；
3. 空洞卷积保持分辨率；
4. 细粒度 loss（边界 loss）。

**Q11：U-Net++ 相比 U-Net 的改进？**

- 嵌套跳连，不同深度连接；
- 减少语义鸿沟；
- 浅层特征更充分利用；
- 精度更高。

**Q12：DeepLab 系列演进？**

- v1：空洞卷积 + CRF；
- v2：ASPP；
- v3：改进 ASPP + BN，去 CRF；
- v3+：Encoder-Decoder + ASPP。

## 12.总结

- **FCN** 开创全卷积语义分割；
- **U-Net** 对称结构 + 跳连，医学分割标杆；
- **DeepLab 系列** 空洞卷积 + ASPP，强 baseline；
- **PSPNet** 金字塔池化，全局上下文；
- **SegFormer** Transformer + 轻量 decoder；
- **损失**：CE + Dice 组合常用；
- **指标**：mIoU 主指标；
- 语义分割是密集预测的基础任务。
