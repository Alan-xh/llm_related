# 3.全景分割

## 1.概述

**全景分割（Panoptic Segmentation）** 由 Kirillov 等于 2018 年提出，**统一了语义分割和实例分割**：

- **Stuff（不可数）**：天空、道路、草地等，由语义分割处理；
- **Thing（可数）**：人、车、狗等，由实例分割处理；
- **全景**：每个像素分配 (类别, 实例 ID)，无重叠、无遗漏。

### 1.1 三种分割对比

| 任务 | Thing | Stuff | 实例区分 |
| --- | --- | --- | --- |
| 语义分割 | ✓ | ✓ | ✗ |
| 实例分割 | ✓ | ✗ | ✓ |
| **全景分割** | **✓** | **✓** | **✓** |

### 1.2 输出格式

每个像素的标签：

$$
\text{label}_i = (\text{class}_i, \text{instance\_id}_i)
$$

- Stuff 类的 instance_id 无意义（统一为 0 或不区分）；
- Thing 类每实例独立 ID。

## 2.Panoptic FPN（2019）

**论文**：Panoptic Feature Pyramid Networks (Kirillov et al., Facebook)

**核心思想**：**FPN 统一处理 thing 和 stuff**。

### 2.1 架构

```
Image ── Backbone ── FPN ──┬── 实例分割 head（Mask R-CNN）
                            └── 语义分割 head（FPN 多尺度融合）
                                    │
                            合并 → 全景分割结果
```

- 共享 backbone + FPN；
- thing 用 Mask R-CNN；
- stuff 用 FPN 多尺度语义分割；
- 后处理合并。

### 2.2 合并冲突

- thing 和 stuff 重叠区域：thing 优先；
- thing 之间重叠：高分优先。

## 3.Panoptic DeepLab（2020）

**论文**：Panoptic-DeepLab: A Simple, Strong, and Fast Baseline for Bottom-Up Panoptic Segmentation (Cheng et al., Google)

**核心思想**：**Bottom-up**（自底向上），不做检测，直接预测：

1. **语义分割**：每像素类别；
2. **中心点预测**：thing 类的实例中心；
3. **Embedding**：像素归属哪个中心。

### 3.1 流程

```
Image ── Backbone ──┬── Semantic head（每像素类别）
                    ├── Center head（thing 中心点）
                    └── Offset head（像素到中心偏移）
                            │
                            ▼
                    像素聚类 → 实例
```

### 3.2 优点

1. 速度快（无检测）；
2. 简单优雅；
3. 单尺度推理。

## 4.MaskFormer（2021）

**论文**：Per-Pixel Classification is Not All You Need for Semantic Segmentation (Cheng et al., Meta)

**核心思想**：**把分割视为 mask 分类**，而非像素分类。

### 4.1 核心转变

- 传统：每像素分类（C 类）；
- MaskFormer：N 个 query，每 query 预测 (class, mask)；
- **统一语义/实例/全景**。

### 4.2 架构

```
Image ── Backbone ── Pixel Decoder ── Transformer Decoder
                                            │
                                    N 个 query
                                            │
                                ┌───────────┴───────────┐
                            class prediction      mask prediction
```

- query 数 N（如 100）；
- 每 query 学一个 (类别, mask)；
- 适合 thing + stuff 统一。

## 5.Mask2Former（2022）

MaskFormer 的改进版，详见 [2.实例分割](../2.实例分割/2.实例分割.md)。

核心改进：

1. **Masked Attention**：query 只关注前景；
2. **多尺度 feature**；
3. **性能 SOTA**：COCO panoptic PQ 57.8。

## 6.评价指标：PQ（Panoptic Quality）

### 6.1 PQ 计算

$$
PQ = \underbrace{\frac{\sum_{(p,g) \in TP} \text{IoU}(p, g)}{|TP|}}_{\text{分割质量 (SQ)}} \times \underbrace{\frac{|TP|}{|TP| + \frac{1}{2}|FP| + \frac{1}{2}|FN|}}_{\text{识别质量 (RQ)}}
$$

- **匹配**：IoU > 0.5 的预测-GT 对算 TP；
- **SQ（Segmentation Quality）**：匹配对的平均 IoU；
- **RQ（Recognition Quality）**：类似 F1-score。

### 6.2 PQ 变体

- **PQ**：全部类；
- **PQ^{Th}**：thing 类；
- **PQ^{St}**：stuff 类。

## 7.经典数据集

- **COCO Panoptic**：80 thing + 53 stuff，118K 训练图；
- **ADE20K**：150 类（含 thing + stuff）；
- **Cityscapes**：19 类（8 thing + 11 stuff）；
- **Mapillary Vistas**：66 类街景；
- **Mapillary Panoptic**。

## 8.面试常考问题

**Q1：全景分割是什么？**

- 统一语义分割（stuff）+ 实例分割（thing）；
- 每像素 (类别, 实例 ID)；
- 无重叠、无遗漏。

**Q2：全景分割和实例分割的区别？**

- 实例分割只分 thing（可数目标）；
- 全景分割：thing + stuff（背景）；
- 全景 = 实例 + 语义。

**Q3：Panoptic FPN 怎么做全景？**

- 共享 FPN；
- thing 用 Mask R-CNN；
- stuff 用 FPN 语义分割；
- 后处理合并（thing 优先）。

**Q4：Panoptic DeepLab 的 bottom-up 思路？**

- 无检测，直接预测；
- 语义 + 中心点 + offset；
- 像素聚类得到实例；
- 速度快、简单。

**Q5：MaskFormer 的核心转变？**

- 传统：像素级分类（C 类）；
- MaskFormer：mask 分类（N 个 query 预测 (类, mask)）；
- 统一语义/实例/全景。

**Q6：PQ 指标怎么算？**

- IoU > 0.5 的对算 TP；
- PQ = SQ × RQ；
- SQ：匹配对平均 IoU；
- RQ：TP / (TP + 0.5FP + 0.5FN)。

**Q7：stuff 和 thing 的区别？**

- Stuff：不可数背景（天空、道路），无实例区分；
- Thing：可数目标（人、车），需实例区分；
- 全景分割处理两者。

**Q8：全景分割的难点？**

1. thing + stuff 统一；
2. 重叠处理；
3. stuff 类别多、面积大；
4. 评价指标复杂；
5. 实例区分（密集场景）。

**Q9：Mask2Former 为什么强？**

1. Masked Attention 高效；
2. 多尺度 feature；
3. 匈牙利匹配；
4. 统一三任务；
5. 性能 SOTA。

**Q10：全景分割的后处理？**

- thing 优先于 stuff；
- thing 之间高分优先；
- 合并 thing mask + stuff mask；
- 处理重叠区域。

## 9.总结

- **全景分割** 统一语义 + 实例分割；
- **Panoptic FPN** 共享 FPN，双 head；
- **Panoptic DeepLab** bottom-up，无检测；
- **MaskFormer / Mask2Former** mask 分类范式统一；
- **PQ** 是主指标（SQ × RQ）；
- 全景分割是分割任务的"终极形态"。
