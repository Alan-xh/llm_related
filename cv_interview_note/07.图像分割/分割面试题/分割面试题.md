# 分割面试题

## 1.基础概念

### Q1：图像分割的任务是什么？

为图像中每个像素分配标签。分三类：
- 语义分割：每像素类别；
- 实例分割：类别 + 实例 ID；
- 全景分割：thing + stuff 统一。

### Q2：语义分割、实例分割、全景分割的区别？

| 任务 | Thing | Stuff | 实例区分 |
| --- | --- | --- | --- |
| 语义分割 | ✓ | ✓ | ✗ |
| 实例分割 | ✓ | ✗ | ✓ |
| 全景分割 | ✓ | ✓ | ✓ |

### Q3：分割和检测的区别？

- 检测：输出 bbox（区域级）；
- 分割：输出 mask（像素级）；
- 分割是密集预测任务。

### Q4：分割任务的评价指标？

- **mIoU**：每类 IoU 平均（语义分割主指标）；
- **PA**：Pixel Accuracy；
- **mPA**：Mean Pixel Accuracy；
- **Mask mAP**：实例分割主指标；
- **PQ**：全景分割主指标（SQ × RQ）；
- **Dice**：医学分割常用。

## 2.语义分割

### Q5：FCN 的核心创新？

1. 全卷积网络，去掉 FC 层；
2. 转置卷积上采样到原图尺寸；
3. 跳连融合浅层细节 + 深层语义；
4. 端到端像素级预测。

### Q6：U-Net 的特点？

- 对称 encoder-decoder；
- 跳连保留浅层细节；
- 医学图像分割标杆；
- 小数据集友好。

### Q7：U-Net 为什么在医学图像好？

1. 跳连保留细节；
2. 小数据集友好；
3. 弹性形变增强适应医学；
4. 结构简洁易扩展。

### Q8：空洞卷积的作用？

- 扩大感受野不增加参数；
- 不降低分辨率；
- DeepLab、PSPNet 的核心。

### Q9：DeepLab v3+ 的架构？

- Encoder：Backbone + ASPP；
- Decoder：浅层特征 + ASPP 输出融合；
- ASPP：多尺度空洞卷积 + 全局池化。

### Q10：ASPP 怎么做多尺度？

- 多个并行分支，rate 不同（6, 12, 18）；
- 加 1×1 conv 和全局池化；
- concat 融合多尺度上下文。

### Q11：PSPNet 的金字塔池化？

- 4 个尺度池化（1×1, 2×2, 3×3, 6×6）；
- 聚合全局-局部信息；
- 解决 FCN 缺乏全局上下文问题。

### Q12：SegFormer 为什么无位置编码？

- 用 3×3 卷积的 zero-padding 隐式编码位置；
- 支持任意输入尺寸；
- 简化设计。

### Q13：U-Net++ 的改进？

- 嵌套跳连，不同深度连接；
- 减少语义鸿沟；
- 浅层特征更充分利用。

### Q14：语义分割的损失函数？

- **CE**：像素级分类；
- **Dice Loss**：直接优化 Dice，对不平衡鲁棒；
- **Lovász Loss**：直接优化 IoU；
- 组合：CE + Dice。

### Q15：mIoU 怎么计算？

$$
mIoU = \frac{1}{C} \sum_{c=1}^{C} \frac{TP_c}{TP_c + FP_c + FN_c}
$$

每类 IoU 平均，是语义分割主指标。

## 3.实例分割

### Q16：Mask R-CNN 相比 Faster R-CNN 的改进？

1. 加 mask 分支；
2. RoI Pooling -> RoI Align；
3. mask 每类独立；
4. 损失加 mask loss。

### Q17：RoI Align 为什么重要？

- RoI Pooling 坐标取整有量化误差；
- 对 mask 精度影响大；
- RoI Align 用双线性插值，无误差；
- 小目标精度提升明显。

### Q18：Mask R-CNN 的 mask 为什么每类一个？

- 每类独立 mask 通道；
- 避免类间竞争；
- 让分类和分割解耦。

### Q19：YOLACT 怎么实现实时？

- mask = 原型 × 系数 的线性组合；
- 无需 RoI 操作；
- 原型 mask 全图共享。

### Q20：CondInst 的条件卷积？

- 每实例预测一组卷积核；
- 用这些核卷积 feature 生成 mask；
- 参数自适应。

### Q21：SOLO 的"按位置分割"？

- 图像分 S×S 网格；
- 每格预测一个实例；
- 中心性过滤偏移预测。

### Q22：Mask2Former 为什么统一？

- Transformer + 匈牙利匹配；
- query 预测 (class, mask)；
- 实例 / 语义 / 全景同一套。

## 4.全景分割

### Q23：全景分割是什么？

- 统一语义分割（stuff）+ 实例分割（thing）；
- 每像素 (类别, 实例 ID)；
- 无重叠、无遗漏。

### Q24：stuff 和 thing 的区别？

- Stuff：不可数背景（天空、道路），无实例区分；
- Thing：可数目标（人、车），需实例区分。

### Q25：Panoptic FPN 怎么做全景？

- 共享 FPN；
- thing 用 Mask R-CNN；
- stuff 用 FPN 语义分割；
- 后处理合并（thing 优先）。

### Q26：PQ 指标怎么算？

- IoU > 0.5 的对算 TP；
- PQ = SQ × RQ；
- SQ：匹配对平均 IoU；
- RQ：TP / (TP + 0.5FP + 0.5FN)。

### Q27：MaskFormer 的核心转变？

- 传统：像素级分类；
- MaskFormer：mask 分类（N 个 query 预测 (类, mask)）；
- 统一三任务。

## 5.SAM 系列

### Q28：SAM 的核心创新？

1. 可提示分割（点/框/文本/mask）；
2. 零样本泛化；
3. 交互式精修；
4. SA-1B 数据训练。

### Q29：SAM 的三个组件？

1. Image Encoder（ViT）；
2. Prompt Encoder（点/框/文本）；
3. Mask Decoder（Transformer）。

### Q30：SAM 为什么能零样本？

- 11 亿 mask 训练，覆盖广；
- 学习通用分割能力；
- prompt 机制适配任意任务。

### Q31：SAM 的模糊感知？

- 一个提示可能对应多个目标；
- 默认输出 3 个 mask（不同粒度）；
- 让用户选择。

### Q32：SA-1B 数据集？

- 11 亿 mask，1100 万图像；
- 自动标注引擎生成；
- 历史上最大分割数据集。

### Q33：SAM 2 的改进？

1. 视频分割（时序跟踪）；
2. Memory Bank；
3. Hiera encoder 更快；
4. 速度 6 倍提升。

### Q34：EfficientSAM 怎么轻量化？

- 轻量 encoder（TinyViT）；
- SAMI 预训练；
- 从大 SAM 蒸馏。

### Q35：FastSAM 的思路？

- YOLOv8 实例分割 + prompt 后处理；
- 把可提示分割转为实例分割 + 选择；
- 速度快 50 倍。

### Q36：HQ-SAM 解决什么问题？

- SAM 小目标、精细边界差；
- HQ-Output Token + Global-Local Fusion；
- 边界精度提升。

## 6.综合题

### Q37：分割任务的难点？

1. 像素级精度要求；
2. 类别不平衡（小目标）；
3. 细节边界；
4. 多尺度；
5. 实例区分（密集场景）；
6. 速度与精度平衡。

### Q38：分割怎么处理多尺度？

1. FPN 多尺度特征；
2. 空洞卷积（ASPP）；
3. 金字塔池化（PSPNet）；
4. 多尺度推理（TTA）；
5. U-Net 跳连。

### Q39：分割怎么处理小目标？

1. 高分辨率输入；
2. 高分辨率 feature（空洞卷积保持）；
3. FPN 浅层特征；
4. 细粒度 loss（边界 loss）；
5. 切图推理。

### Q40：分割的部署优化？

1. **轻量 backbone**：MobileNet、EfficientNet；
2. **模型压缩**：剪枝、量化；
3. **知识蒸馏**：大模型蒸馏小模型；
4. **TensorRT** 加速；
5. **实时分割**：BiSeNet、Fast-SCNN。

### Q41：实时分割的方法？

- **BiSeNet**：双分支（空间 + 语义）；
- **Fast-SCNN**：浅层分割；
- **ICNet**：级联网络；
- **ENet**：早期实时分割；
- **FastSAM**：YOLOv8 + 后处理。

### Q42：分割任务的迁移学习？

1. 预训练：ImageNet 分类或自监督；
2. 微调：分割任务；
3. 冻结 backbone，只训 head；
4. 逐层解冻；
5. SAM 等基础模型零样本。

### Q43：分割和检测的关系？

- 检测输出 bbox，分割输出 mask；
- 实例分割 = 检测 + mask；
- Mask R-CNN = Faster R-CNN + mask 分支；
- Mask2Former 统一两者。

### Q44：分割模型的选择？

| 场景 | 推荐 |
| --- | --- |
| 实时（移动端） | BiSeNet, Fast-SCNN |
| 高精度语义 | DeepLab v3+, SegFormer |
| 实例分割 | Mask R-CNN, Mask2Former |
| 全景分割 | Mask2Former |
| 医学分割 | U-Net, nnU-Net |
| 通用零样本 | SAM, SAM 2 |

### Q45：分割的未来趋势？

1. **基础模型**：SAM 系列通用分割；
2. **统一框架**：Mask2Former 统一三任务；
3. **视频分割**：SAM 2 等；
4. **多模态**：文本 + 图像分割（Grounding SAM）；
5. **3D 分割**：点云、场景分割；
6. **开放词表**：Open-Vocabulary Segmentation。
