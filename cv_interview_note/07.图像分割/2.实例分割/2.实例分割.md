# 2.实例分割

## 1.概述

**实例分割（Instance Segmentation）** = **目标检测 + 语义分割**：不仅要分割出每个像素的类别，还要**区分不同实例**。例如图中有 3 只猫，语义分割给所有猫一个标签，实例分割给每只猫独立的 mask。

| 任务 | 输出 |
| --- | --- |
| 语义分割 | 每像素一个类别（同类实例合并） |
| **实例分割** | 每像素一个类别 + 实例 ID |
| 全景分割 | 语义 + 实例统一 |

## 2.Mask R-CNN（2017）

**论文**：Mask R-CNN (He et al., Facebook)

**核心思想**：在 Faster R-CNN 基础上**加 mask 分支**，做实例分割。

### 2.1 架构

```
Image ── Backbone + FPN ── RPN ── RoI Align ──┬── 分类 head
                                               ├── 框回归 head
                                               └── mask head ( FCN )
```

- 与 Faster R-CNN 共享 backbone；
- 每个 RoI 预测：类别 + bbox + mask；
- mask 分支是 FCN，每类一个 mask（避免类间竞争）。

### 2.2 RoI Align 的关键作用

- RoI Pooling 量化坐标引入误差；
- **RoI Align** 用**双线性插值**，无量化误差；
- 对小目标精度提升明显；
- 是 Mask R-CNN 成功的关键。

### 2.3 损失函数

$$
L = L_{cls} + L_{bbox} + L_{mask}
$$

- $L_{cls}$：分类 CE；
- $L_{bbox}$：Smooth L1；
- $L_{mask}$：每像素二分类 CE（按类别取对应 mask）。

### 2.4 性能

- COCO instance segmentation mAP 37.1（ResNet-50-FPN）；
- 端到端训练，速度接近 Faster R-CNN。

## 3.YOLACT（2019）

**论文**：YOLACT: Real-time Instance Segmentation (Bolya et al.)

**核心思想**：**实时**实例分割，把 mask 分解为**原型 mask + 系数**。

### 3.1 架构

```
Image ── Backbone + FPN ──┬── Detection head（预测 bbox + 系数）
                          └── Proto head（生成 K 个原型 mask）
                                    │
                          mask = Σ coeff_k × proto_k
```

### 3.2 Protonet 思想

- 预测 K 个原型 mask（如 32 个）；
- 每个检测框预测 K 个系数；
- mask = 系数 × 原型 的线性组合；
- **无需 RoI 操作**，速度快。

### 3.3 性能

- 30+ FPS，COCO mask mAP 29.8；
- 首个实时实例分割。

## 4.CondInst（2020）

**论文**：CondInst: Conditional Convolution for Instance Segmentation (Tian et al., 旷视)

**核心思想**：**条件卷积**，根据实例动态生成卷积核。

### 4.1 思路

- FCOS 检测框架；
- 每个实例预测一组卷积核参数；
- 用这些核卷积 feature 生成 mask；
- **无固定 mask head**，参数自适应。

### 4.2 优点

1. 参数效率高；
2. 形变适应强；
3. 精度优于 Mask R-CNN。

## 5.SOLO / SOLOv2（2020）

**论文**：SOLO: Segmenting Objects by Locations (Wang et al., 旷视)

**核心思想**：**按位置分割**，把图像分 S×S 网格，每格预测 mask。

### 5.1 SOLO 架构

```
Image ── FPN ── 每网格预测：
              ├── 类别
              ├── mask（动态或固定）
```

- **S×S 网格**：每格负责一个实例；
- **中心性**：过滤偏离中心的预测；
- 无需 RoI、无需 anchor。

### 5.2 SOLOv2 改进

- **动态 mask**：原型 mask + 动态卷积核；
- 类似 YOLACT 但更优雅；
- 精度速度兼顾。

## 6.Mask2Former（2022）

**论文**：Masked-attention Mask Transformer for Universal Image Segmentation (Cheng et al., Meta)

**核心思想**：**DETR 思想做分割**，统一语义/实例/全景分割。

### 6.1 架构

```
Image ── Backbone ── Pixel Decoder ── Transformer Decoder
                                            │
                                    N 个 query
                                            │
                                ┌───────────┴───────────┐
                            class prediction      mask prediction
```

### 6.2 核心组件

1. **Masked Attention**：query 只关注前景区域；
2. **Multi-scale Feature**：高分辨率 + 低分辨率；
3. **Hungarian Matching**：一对一标签分配；
4. **统一框架**：实例/语义/全景都用同一套。

### 6.3 性能

- COCO 实例分割 mAP 50.1（Swin-L）；
- ADE20K 语义分割 mIoU 57.8；
- 全任务 SOTA。

## 7.实例分割方法对比

| 方法 | 类型 | 速度 | 精度 | 特点 |
| --- | --- | --- | --- | --- |
| Mask R-CNN | 两阶段 | 中 | 中 | 经典 baseline |
| YOLACT | 单阶段 | 快 | 中 | 原型 + 系数 |
| CondInst | 单阶段 | 快 | 高 | 条件卷积 |
| SOLOv2 | 单阶段 | 快 | 高 | 按位置分割 |
| Mask2Former | Transformer | 中 | SOTA | 统一框架 |

## 8.评价指标

### 8.1 Mask mAP

- 类似检测 mAP，但用 mask IoU 替代 bbox IoU；
- COCO 主指标：mAP@[0.5:0.95]；
- mAP@0.5、mAP@0.75。

### 8.2 Mask IoU

$$
\text{Mask IoU} = \frac{|M_{pred} \cap M_{gt}|}{|M_{pred} \cup M_{gt}|}
$$

## 9.面试常考问题

**Q1：实例分割和语义分割的区别？**

- 语义分割：每像素一个类别，同类实例合并；
- 实例分割：每像素类别 + 实例 ID，区分同类实例；
- 例：3 只猫，语义分割全标"猫"，实例分割分别标 1, 2, 3。

**Q2：Mask R-CNN 相比 Faster R-CNN 的改进？**

1. 加 mask 分支；
2. RoI Pooling -> RoI Align（消除量化误差）；
3. mask 每类独立，避免类间竞争；
4. 损失加 mask loss。

**Q3：RoI Align 为什么重要？**

- RoI Pooling 坐标取整有量化误差；
- 对 mask 精度影响大（mask 需像素级精度）；
- RoI Align 用双线性插值，无误差；
- 小目标精度提升明显。

**Q4：Mask R-CNN 的 mask 为什么每类一个？**

- 每类独立 mask 通道，避免类间竞争；
- 让分类和分割解耦；
- 类别已知后取对应 mask。

**Q5：YOLACT 怎么实现实时？**

- mask = 原型 × 系数 的线性组合；
- 无需 RoI 操作；
- 原型 mask 全图共享；
- 系数随检测框预测。

**Q6：CondInst 的条件卷积？**

- 每实例预测一组卷积核；
- 用这些核卷积 feature 生成 mask；
- 参数自适应，无固定 head；
- 形变适应强。

**Q7：SOLO 的"按位置分割"？**

- 图像分 S×S 网格；
- 每格预测一个实例；
- 中心性过滤偏移预测；
- 无 anchor、无 RoI。

**Q8：Mask2Former 为什么统一？**

- Transformer + 匈牙利匹配；
- query 预测 (class, mask)；
- 实例：每 query 一个目标；
- 语义：query 数 = 类别数；
- 全景：实例 query + 物体类 query。

**Q9：实例分割的难点？**

1. 实例区分（密集场景）；
2. 形变适应（细长目标）；
3. 小目标 mask 精度；
4. 速度与精度平衡；
5. 边界精度。

**Q10：Mask R-CNN 的损失？**

$$
L = L_{cls} + L_{bbox} + L_{mask}
$$

- $L_{cls}$：分类 CE；
- $L_{bbox}$：Smooth L1；
- $L_{mask}$：每像素二分类 CE（按类）。

**Q11：实例分割如何处理遮挡？**

1. RoI Align 精确定位；
2. mask 分支独立预测；
3. NMS 后处理；
4. 关系建模（Mask2Former）；
5. 数据增强（Copy-Paste）。

**Q12：实例分割 vs 全景分割？**

- 实例分割：只分"thing"（可数目标，如人、车）；
- 全景分割：thing + stuff（不可数背景，如天空、道路）；
- 全景 = 实例 + 语义。

## 10.总结

- **Mask R-CNN** 经典 baseline，Faster R-CNN + mask；
- **RoI Align** 消除量化误差是关键；
- **YOLACT** 实时，原型 + 系数；
- **CondInst** 条件卷积，参数自适应；
- **SOLOv2** 按位置分割，动态 mask；
- **Mask2Former** Transformer 统一分割框架；
- 实例分割 = 检测 + 像素级 mask；
- 评价指标：mask mAP。
