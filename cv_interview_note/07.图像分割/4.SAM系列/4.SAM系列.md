# 4.SAM系列

## 1.概述

**SAM（Segment Anything Model）** 由 Meta 于 2023 年 4 月发布，是**首个通用分割大模型**，能根据**任意提示**（点、框、文本、mask）分割任意目标。SAM 在 11 亿 mask 上训练，具有**强大的零样本泛化能力**，被誉为"分割领域的 GPT 时刻"。

## 2.SAM（Segment Anything, 2023）

**论文**：Segment Anything (Kirillov et al., Meta AI)

### 2.1 核心目标

- **可提示分割**：用点、框、文本等任意提示分割目标；
- **零样本泛化**：训练后能分割未见过的目标；
- **交互式**：用户可通过多次提示精修结果。

### 2.2 架构

```
Image ── Image Encoder (ViT-H/L/B) ── Image Embedding
                                            │
Prompt (点/框/mask) ── Prompt Encoder ──┐
                                         ▼
                                Mask Decoder (Transformer)
                                         │
                                         ▼
                                  Mask + IoU Score
```

三个核心组件：

1. **Image Encoder**：ViT-H/L/B，对图编码（每图只算一次）；
2. **Prompt Encoder**：编码点、框、mask、文本提示；
3. **Mask Decoder**：轻量 Transformer，融合 image embedding + prompt embedding，输出 mask。

### 2.3 提示类型

- **点**：前景点 / 背景点；
- **框**：目标 bbox；
- **mask**：粗略 mask 精修；
- **文本**：语义提示（SAM 主要用 CLIP embedding）。

### 2.4 模糊感知（Ambiguity-Aware）

- 一个提示可能对应多个目标（如点在球衣上，可能指球员或球衣）；
- SAM 默认输出 **3 个 mask**（不同粒度：整体、部分、子部分）；
- 让用户选择最合适的。

### 2.5 数据：SA-1B

- **11 亿 mask**，1100 万图像；
- 自动标注引擎生成；
- 历史上最大分割数据集。

### 2.6 训练

1. **辅助手动标注**：训练初版模型；
2. **辅助半自动标注**：模型预测 + 人工修正；
3. **全自动标注**：模型自动生成 mask，置信度筛选。

### 2.7 性能

- 零样本实例分割：超越 RIS（Referring Image Segmentation）SOTA；
- 零样本边界检测：超越专门模型；
- 速度：每图 prompt 处理 ~50ms（web 浏览器可运行）。

### 2.8 应用场景

- **图像编辑**：分割目标 + 编辑；
- **医学影像**：零样本分割器官；
- **遥感**：分割地物；
- **视频**：分割跟踪；
- **AR/VR**：实时分割。

## 3.SAM 2（2024）

**论文**：SAM 2: Segment Anything in Images and Videos (Meta AI)

### 3.1 核心改进

1. **视频分割**：支持视频流，时序跟踪；
2. **Memory Bank**：记住之前帧的 mask；
3. **架构升级**：更高效的 image encoder（Hiera）；
4. **性能更强**：精度提升，速度快 6 倍。

### 3.2 架构

```
Video Frame t ── Image Encoder ──┐
                                  │
Prompt ── Prompt Encoder ────────┤
                                  │
Memory Bank (前几帧 mask) ────────┤
                                  ▼
                          Mask Decoder
                                  │
                                  ▼
                          Mask(t) + Memory
```

- 每帧 prompt 一次，模型自动跟踪到后续帧；
- Memory Bank 存储时序信息。

### 3.3 数据：SA-V

- **600K 视频**，51M mask；
- 视频分割数据集。

### 3.4 性能

- 交互式视频分割 8 倍速度提升；
- 零样本图像分割精度优于 SAM；
- 6 倍速度提升。

## 4.EfficientSAM（2023）

**论文**：EfficientSAM: Leveraged Masked Image Pretraining for Efficient Segment Anything (MIT, IBM)

### 4.1 动机

- SAM 的 ViT-H 太大（636M 参数）；
- 边缘设备难以部署；
- 需要轻量版本。

### 4.2 改进

1. **轻量 image encoder**：TinyViT / EfficientViT；
2. **SAMI 预训练**：masked image modeling 改进；
3. **蒸馏**：从大 SAM 蒸馏到小模型。

### 4.3 性能

- 参数减少 20 倍；
- 速度提升 10 倍；
- 精度接近 SAM。

## 5.FastSAM（2023）

**论文**：Fast Segment Anything (Zhao et al., CAS)

### 5.1 核心思想

- 用 **YOLOv8** 检测框架做 SAM；
- 把"可提示分割"转为"实例分割 + prompt 后处理"。

### 5.2 流程

```
Image ── YOLOv8-Seg ── 实例 mask 列表
                            │
                    └─ Prompt 后处理
                       (点/框 选 mask)
                            │
                            ▼
                        目标 mask
```

### 5.3 性能

- 速度比 SAM 快 50 倍；
- 精度略低于 SAM；
- 适合实时场景。

## 6.HQ-SAM（2023）

**论文**：Delving Deep into Segment Anything: A Foundation Model for Zero-shot Segmentation (Ke et al., ETH)

### 6.1 动机

- SAM 对小目标、精细边界分割不够好；
- 需要提升 mask 质量。

### 6.2 改进

1. **HQ-Output Token**：额外的高质量 mask token；
2. **Global-Local Fusion**：融合全局和局部特征；
3. **HQ 数据集**：精细标注数据训练。

### 6.3 性能

- 边界精度大幅提升；
- 小目标改善明显；
- 保留 SAM 零样本能力。

## 7.SAM 系列对比

| 模型 | 年份 | Image Encoder | 速度 | 特点 |
| --- | --- | --- | --- | --- |
| SAM | 2023 | ViT-H/L/B | 慢 | 通用分割大模型 |
| SAM 2 | 2024 | Hiera | 快 | 视频 + 速度提升 |
| EfficientSAM | 2023 | TinyViT | 快 | 蒸馏轻量化 |
| FastSAM | 2023 | YOLOv8 | 极快 | YOLO + 后处理 |
| HQ-SAM | 2023 | ViT-H | 慢 | 高质量 mask |

## 8.SAM 与传统分割对比

| 维度 | 传统分割 | SAM |
| --- | --- | --- |
| 训练方式 | 任务专用 | 通用预训练 + 零样本 |
| 提示 | 无 | 点/框/文本/mask |
| 数据 | 任务数据集 | SA-1B（11亿 mask） |
| 泛化 | 任务内 | 跨任务、跨域 |
| 交互 | 无 | 交互式精修 |

## 9.面试常考问题

**Q1：SAM 的核心创新？**

1. 可提示分割（点/框/文本/mask）；
2. 零样本泛化；
3. 交互式精修；
4. 大数据（SA-1B）训练；
5. 架构：Image Encoder + Prompt Encoder + Mask Decoder。

**Q2：SAM 的三个组件？**

1. **Image Encoder**：ViT 编码图像；
2. **Prompt Encoder**：编码点/框/文本提示；
3. **Mask Decoder**：Transformer 融合，输出 mask。

**Q3：SAM 为什么能零样本？**

- 11 亿 mask 训练，覆盖广；
- 学习了"分割任何目标"的通用能力；
- prompt 机制让模型适配任意任务。

**Q4：SAM 的模糊感知？**

- 一个提示可能对应多个目标（不同粒度）；
- SAM 默认输出 3 个 mask（整体/部分/子部分）；
- 让用户选择。

**Q5：SAM 的数据 SA-1B？**

- 11 亿 mask，1100 万图像；
- 自动标注引擎生成；
- 历史上最大分割数据集；
- 99% 自动标注。

**Q6：SAM 2 的改进？**

1. 视频分割（时序跟踪）；
2. Memory Bank；
3. Hiera encoder 更快；
4. 速度 6 倍提升；
5. SA-V 视频数据集。

**Q7：EfficientSAM 怎么轻量化？**

1. 轻量 encoder（TinyViT）；
2. SAMI 预训练；
3. 从大 SAM 蒸馏；
4. 参数减少 20 倍。

**Q8：FastSAM 的思路？**

- YOLOv8 实例分割 + prompt 后处理；
- 把"可提示分割"转为"实例分割 + 选择"；
- 速度快 50 倍，精度略低。

**Q9：HQ-SAM 解决什么问题？**

- SAM 小目标、精细边界差；
- HQ-Output Token + Global-Local Fusion；
- 边界精度大幅提升。

**Q10：SAM 的应用？**

- 图像编辑；
- 医学影像；
- 遥感；
- 视频分割；
- AR/VR；
- 数据标注。

**Q11：SAM 的局限？**

1. 大模型推理慢；
2. 文本提示能力弱（原版）；
3. 小目标、精细边界差；
4. 视频时序一致性（SAM 2 改进）；
5. 特定领域（医学）需微调。

**Q12：SAM 和 DETR 的区别？**

- DETR：检测任务，固定类别；
- SAM：分割任务，零样本；
- DETR 需训练专用类别；
- SAM 通用预训练 + prompt。

## 10.总结

- **SAM** 是首个通用分割大模型，prompt 驱动；
- **架构**：Image Encoder + Prompt Encoder + Mask Decoder；
- **数据**：SA-1B（11 亿 mask）；
- **SAM 2** 支持视频，速度更快；
- **EfficientSAM / FastSAM** 轻量化；
- **HQ-SAM** 提升边界质量；
- SAM 开启"视觉基础模型"时代，影响深远。
