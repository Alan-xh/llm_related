# 4.BEiT

## 1.概述

**BEiT（Bidirectional Encoder representation from Image Transformers）** 由微软在 2021 年提出，是**首个将 BERT 式掩码自监督学习成功应用于视觉 Transformer** 的工作。BEiT 借鉴 NLP 中 BERT 的 MLM（Masked Language Model）思路，**对图像 patch 做掩码建模**，让 ViT 在无需人工标签的情况下学到通用视觉表示。

**论文**：BEiT: BERT Pre-Training of Image Transformers (Bao et al., 2021)

## 2.动机

### 2.1 ViT 的小数据问题

- ViT 在 ImageNet-1k 上从头训练不如 CNN；
- 需要大规模有标签数据（JFT-300M、ImageNet-21k）才能发挥优势；
- 标注数据昂贵。

### 2.2 NLP 的成功经验

- BERT 通过 MLM 自监督预训练，在 NLP 取得巨大成功；
- 视觉能否借鉴？核心难点：**视觉 token 不像文本 token 那样离散**。

## 3.BEiT 的核心思想

### 3.1 整体框架

```
              Image
                │
        ┌───────┴───────┐
        ▼               ▼
   VQ-VAE             Patch Embed
   (tokenizer)        (ViT 输入)
        │               │
   visual tokens     patch tokens
        │               │
        │      随机 mask 40%
        │               │
        │               ▼
        │           ViT Encoder
        │               │
        │           预测被 mask 位置
        │               │
        ▼               ▼
       visual tokens (ground truth)
                  │
                  ▼
       Cross-Entropy Loss
```

### 3.2 两阶段：Tokenizer + 网络

**关键创新**：把图像变成**离散视觉 token**（类似文本 token），让 BERT 思路直接可用。

**Step 1：训练 VQ-VAE 作为 image tokenizer**

- 用 VQ-VAE 把图像编码为**离散 token** map；
- 每个 token 对应一个 $8 \times 8$ 像素区域；
- 这些 token 就是"图像的词汇表"（典型 8192 个）。

**Step 2：BERT 式预训练**

- 输入：图像 patch（ViT 标准 patch embedding）；
- 随机 mask 40% 的 patch（用特殊 [MASK] token 替换）；
- ViT Encoder 处理未 mask 的 patch；
- 在被 mask 的位置预测对应的 visual token（VQ-VAE 输出）；
- 用 Cross-Entropy Loss 监督。

### 3.3 Block-wise Masking

不像 BERT 随机 mask 单个 token，BEiT 用 **block-wise masking**：

- mask 连续的 block（如 $2 \times 4$、$4 \times 2$、$3 \times 3$ 等矩形区域）；
- 至少 mask 40% 的 patch；
- 优点：避免模型"看一个像素猜另一个"，让模型学到**语义级别**的推断。

### 3.4 与 MAE 的区别

| 维度 | BEiT | MAE |
| --- | --- | --- |
| 输入 | 仅未 mask 的 patch | 仅未 mask 的 patch |
| 监督目标 | VQ-VAE 离散 token | 像素值（连续） |
| Loss | Cross-Entropy | MSE |
| Decoder | 无（直接预测） | 轻量 decoder 重建 |
| Mask 比例 | 40% | 75% |

**BEiT 的优势**：离散 token 包含语义信息，预测 token 比 predict 像素更"高级"；
**MAE 的优势**：不需要训练 tokenizer，简单直接，scaling 好。

## 4.BEiT 的预训练

### 4.1 数据

- ImageNet-1k（1.3M 图像）训练；
- 无需标签，只用图像本身。

### 4.2 训练目标

对于被 mask 的位置 $i$：

$$
L = -\sum_{i \in \mathcal{M}} \log p(z_i \mid x_{\backslash \mathcal{M}})
$$

其中 $z_i$ 是 VQ-VAE 给出的第 $i$ 位置的 visual token，$x_{\backslash \mathcal{M}}$ 是未 mask 的 patch。

### 4.3 训练细节

- ViT-Base/16；
- AdamW，lr 1.5e-3，weight decay 0.05；
- 250 epochs on ImageNet-1k（~800 epoch equivalent）；
- Batch 2048；
- Block-wise masking 40%。

## 5.BEiT 性能

### 5.1 ImageNet 微调

| 方法 | 预训练 | 微调 top-1 |
| --- | --- | --- |
| ViT-B（从头） | - | 77.9% |
| ViT-B（DeiT） | ImageNet-1k 有监督 | 81.8% |
| ViT-B（JFT-300M 有监督） | JFT-300M | 81.8% |
| **ViT-B（BEiT 自监督）** | ImageNet-1k | **83.2%** |

**结论**：BEiT 用相同的 ImageNet-1k 数据，但**自监督预训练**比有监督训练效果好 1.4%。

### 5.2 下游任务

- **COCO 检测**：50.4 AP（比有监督 +1.0）；
- **ADE20K 分割**：45.6 mIoU（比有监督 +1.3）；
- 表明 BEiT 学到的表示通用性强。

## 6.BEiT v2

**论文**：BEiT v2: Masked Image Modeling with Vector-Quantized Visual Tokenizers (Peng et al., 2022)

**改进**：

1. **VQ-KL 蒸馏**：让 patch 表示直接对齐 visual token 的语义；
2. **Patch aggregation**：浅层 patch 表示聚合成高层语义；
3. **改进 tokenizer**：更好捕获语义信息；
4. **性能**：ImageNet-1k top-1 = 85.5%（ViT-B/16）。

## 7.与 BERT 的对比

| 维度 | BERT | BEiT |
| --- | --- | --- |
| Token 类型 | 文本 word | 视觉 VQ token |
| Tokenizer | WordPiece | VQ-VAE |
| Mask 策略 | 15% 单 token | 40% block-wise |
| 监督 | masked token id | masked visual token id |
| Loss | CE | CE |
| 预训练数据 | 文本 | 图像 |

## 8.面试常考问题

**Q1：BEiT 解决了什么问题？**

让 ViT 在 ImageNet-1k 上**无需人工标签**做自监督预训练，达到或超过有监督预训练的性能。

**Q2：BEiT 的核心思想是什么？**

借鉴 BERT 的 MLM：

1. 用 VQ-VAE 把图像编码为**离散 visual token**；
2. 对 patch 做 block-wise mask；
3. ViT 预测被 mask 位置的 visual token（CE loss）。

**Q3：为什么 BEiT 要用 VQ-VAE 做 tokenizer？**

- 把图像变成**离散 token**，让 BERT 思路直接可用；
- 离散 token 包含语义信息，比 predict 像素更"高级"；
- VQ-VAE 通过 codebook 学习到图像的高层语义表示。

**Q4：BEiT 和 MAE 的区别？**

| 维度 | BEiT | MAE |
| --- | --- | --- |
| 监督 | VQ token（离散） | 像素值（连续） |
| Loss | CE | MSE |
| Mask 比例 | 40% | 75% |
| 是否需要 tokenizer | 需要（VQ-VAE） | 不需要 |

**Q5：BEiT 为什么用 block-wise masking？**

- 避免模型"看一个像素猜另一个"；
- 强制模型用周围语义推断被 mask 区域；
- 学习语义级而非像素级的表示。

**Q6：BEiT 的 visual token 是什么？**

通过 VQ-VAE 把图像编码为离散 token：

- VQ-VAE encoder 把图像压成低分辨率 feature map；
- 通过 codebook 量化为离散 id；
- 这些 id 就是 visual token，类似文本中的 word id。

**Q7：为什么 BEiT 比 DeiT 有监督效果还好？**

- 自监督利用了数据中**所有信息**（不仅是标签）；
- 标签是稀疏信号（1 个标签/图），像素是密集信号；
- BEiT 让 ViT 学到更通用的视觉表示。

**Q8：BEiT 在小数据上表现如何？**

- 100% ImageNet：BEiT > DeiT > ViT；
- 10% ImageNet：BEiT 优势更明显（自监督适合小数据）；
- 1% ImageNet：BEiT 仍领先，但所有方法都掉很多。

**Q9：VQ-VAE 的 codebook 大小怎么选？**

- 太小：表达力不够，重建差；
- 太大：训练慢，部分 code 可能不用；
- 典型值：8192（BEiT）、4096（DALL-E）。

**Q10：BEiT 与 SimCLR/MoCo 等 contrastive 方法有何区别？**

| 维度 | BEiT | SimCLR/MoCo |
| --- | --- | --- |
| 学习信号 | 重建 mask token | 对比正负样本 |
| 需要负样本 | 否 | 是 |
| 需要大 batch | 否 | SimCLR 是 |
| 是否需要专门结构 | 否（直接 ViT） | 是（projection head） |
| 适合 | ViT | ResNet |

## 9.总结

- **BEiT = BERT for Vision + VQ-VAE tokenizer**；
- 把图像转为离散 visual token，做 MLM 自监督预训练；
- 比 DeiT 有监督效果更好，证明自监督学习在视觉的潜力；
- 与 MAE 并列 ViT 自监督双雄；
- BEiT v2 进一步提升，但 MAE 因简单逐渐成为主流。
