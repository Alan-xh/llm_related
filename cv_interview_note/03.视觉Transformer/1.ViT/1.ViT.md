# 1.ViT

## 1.概述

**Vision Transformer（ViT）** 由 Google 在 2020 年提出，首次将 NLP 中的 Transformer 成功应用于图像分类任务。ViT 抛弃了 CNN 的卷积操作，**将图像切分为 patch 序列**输入 Transformer Encoder，证明了"纯 Transformer 在大数据下可以超越 CNN"。

**论文**：An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale (Dosovitskiy et al., 2020)

## 2.动机

### 2.1 CNN 的局限

1. **归纳偏置强**：平移等变 + 局部性假设，限制模型表达；
2. **感受野有限**：长距离依赖建模弱；
3. **大数据下可能"过度归纳偏置"**：限制模型上限。

### 2.2 Transformer 优势

1. **几乎无归纳偏置**：完全数据驱动；
2. **全局建模**：自注意力可一次看到全图；
3. **可扩展性好**：模型越大、数据越多，性能越强。

## 3.ViT 架构

### 3.1 整体流程

```
Image (H×W×C)
   │
   ├── Patch Embedding (Conv 16×16, stride=16)
   │      → (N, D), N = (H/16) × (W/16)
   │
   ├── Prepend [CLS] token
   │      → (N+1, D)
   │
   ├── Add Position Embedding
   │      → (N+1, D)
   │
   ├── Transformer Encoder × L
   │   ├─ Multi-Head Self-Attention
   │   ├─ MLP (FFN)
   │   └─ LayerNorm + Residual
   │
   ├── [CLS] token output
   │
   └── MLP Head → class logits
```

### 3.2 Patch Embedding

把 $H \times W \times C$ 的图像切为 $P \times P$ 大小的 patch，共 $N = (H/P) \times (W/P)$ 个。每个 patch 展平后线性映射到维度 $D$：

$$
\text{Patch Embed}(\text{img}) = \text{Linear}(\text{flatten}(\text{patches})) \in \mathbb{R}^{N \times D}
$$

**实现技巧**：等价于一个卷积核大小 $P$、步长 $P$、输出通道 $D$ 的卷积：

```python
self.proj = nn.Conv2d(3, embed_dim, kernel_size=patch_size, stride=patch_size)
# forward
x = self.proj(img).flatten(2).transpose(1, 2)  # (B, N, D)
```

**典型参数**：$P = 16$，输入 224×224 -> 14×14 = 196 个 patch。

### 3.3 [CLS] Token

借鉴 BERT，在序列最前面**插入一个可学习的特殊 token `[CLS]`**，最终用它做分类。

**为什么用 [CLS]？**

- 避免直接对 patch 做平均（某些任务需要全局信息）；
- 通过自注意力让 [CLS] 聚合所有 patch 的信息；
- [CLS] 本身无图像内容，能"公平"地聚合全局信息。

### 3.4 位置编码

由于自注意力本身**无位置感知**，必须加入位置编码告诉模型每个 patch 的位置。

**ViT 用 1D 可学习位置编码**：

$$
\text{Position Embed} \in \mathbb{R}^{(N+1) \times D}
$$

加到 patch embedding 上：

$$
x = \text{PatchEmbed}(\text{img}) + \text{PosEmbed}
$$

**为什么不 2D 编码？** 论文实验表明 1D 和 2D 效果差不多，1D 更简洁。

### 3.5 Transformer Encoder

标准 Transformer Encoder，每个 block：

```
x → LayerNorm → Multi-Head Self-Attention → + residual → LayerNorm → MLP → + residual → out
```

**MLP（FFN）**：

$$
\text{MLP}(x) = \text{GELU}(x W_1 + b_1) W_2 + b_2
$$

中间维度通常为 $4D$。

### 3.6 分类头

```python
cls_token = x[:, 0]              # 取 [CLS]
logits = self.head(cls_token)    # Linear(D -> num_classes)
```

**预训练**：用大型数据集（JFT-300M、ImageNet-21k）做监督学习或 MAE 自监督；
**微调**：在 ImageNet-1k 等下游任务上微调。

## 4.ViT 的关键特性

### 4.1 无归纳偏置

ViT 几乎无 CNN 的平移等变和局部性假设，**完全靠数据学习**。

**后果**：

- **大数据优势明显**：在 JFT-300M 上预训练后大幅超越 CNN；
- **小数据劣势明显**：在 ImageNet-1k 上从头训练不如 ResNet。

### 4.2 全局感受野

第一层就通过自注意力看到全局，而 CNN 需要堆叠很多层才获得大感受野。

### 4.3 计算复杂度

自注意力复杂度 $O(N^2 D)$，$N$ 是 patch 数。对于 224×224 + 16×16 patch，$N = 196$，可接受。但**高分辨率图像** $N$ 急剧增大（384×384 -> 576 个 patch）。

## 5.ViT 模型规格

| 模型 | 层数 $L$ | 维度 $D$ | MLP 维度 | 头数 $h$ | 参数量 |
| --- | --- | --- | --- | --- | --- |
| ViT-Tiny | 12 | 192 | 768 | 3 | 5.7M |
| ViT-Small | 12 | 384 | 1536 | 6 | 22M |
| ViT-Base | 12 | 768 | 3072 | 12 | 86M |
| ViT-Large | 24 | 1024 | 4096 | 16 | 307M |
| ViT-Huge | 32 | 1280 | 5120 | 16 | 632M |

## 6.实验结果

### 6.1 大数据预训练优势

| 数据集 | 大小 | ViT vs ResNet |
| --- | --- | --- |
| ImageNet-1k | 1.3M | ViT-L 略差或持平 |
| ImageNet-21k | 14M | ViT-L 持平或略优 |
| JFT-300M | 300M | **ViT-H 大幅超越** |

**结论**：ViT 的"无归纳偏置"特性需要大数据才能发挥优势。

### 6.2 计算效率

ViT 比 ResNet 计算量更小但精度更高（在 JFT-300M 预训练下）。

## 7.可视化分析

### 7.1 Attention 距离

研究发现：

- 浅层 attention 跨度较小（类似局部卷积）；
- 深层 attention 跨度大（全局）；
- 不同 head 学到不同的关注模式。

### 7.2 位置编码可视化

学到的位置编码呈现**网格结构**，相邻 patch 位置编码相似，符合空间结构。

### 7.3 Patch Embedding 可视化

第一层 patch embedding 学到的滤波器类似**Gabor 滤波器**（边缘/纹理检测），与 CNN 浅层相似。

## 8.ViT 的局限

1. **小数据表现差**：无归纳偏置的代价；
2. **计算复杂度 $O(N^2)$**：高分辨率图像计算爆炸；
3. **难以做密集预测任务**：原始 ViT 的 [CLS] 头只能做分类，密集预测需改造；
4. **训练成本高**：需要大数据 + 大算力。

## 9.面试常考问题

**Q1：ViT 把图像怎么输入 Transformer？**

切分为 16×16 patch -> 展平 -> 线性映射为 D 维向量 -> 加位置编码 -> 加 [CLS] token -> 输入 Transformer Encoder。

**Q2：ViT 为什么用 [CLS] token？**

- 借鉴 BERT，让一个无图像内容的 token "公平"地聚合所有 patch 信息；
- 通过自注意力，[CLS] 能学到全局表示；
- 避免对 patch 简单平均（损失信息）。

**Q3：ViT 的位置编码为什么用 1D？**

实验表明 1D 和 2D 效果差不多，1D 更简洁；后续 Swin 等改用相对位置编码以更好地建模局部关系。

**Q4：ViT 为什么在小数据上不如 CNN？**

ViT 几乎无归纳偏置（无平移等变、无局部性），完全靠数据学习。小数据不足以学到这些隐式规律，而 CNN 通过结构内置这些归纳偏置，小数据表现更稳。

**Q5：ViT 与 CNN 的本质区别？**

| 维度 | CNN | ViT |
| --- | --- | --- |
| 归纳偏置 | 平移等变 + 局部性 | 几乎无 |
| 感受野 | 由小到大渐进 | 第一层就全局 |
| 数据效率 | 小数据好 | 需大数据 |
| 长距离依赖 | 弱 | 强 |
| 计算复杂度 | 线性 | $O(N^2)$ |

**Q6：ViT 计算复杂度？为什么是 $O(N^2)$？**

自注意力中 $QK^T$ 是 $N \times D$ 乘 $D \times N$ -> $N \times N$ 矩阵，复杂度 $O(N^2 D)$。$N$ 是 patch 数，与图像分辨率平方成正比。

**Q7：ViT 怎么处理高分辨率图像？**

- 直接处理会让 $N$ 爆炸（如 1024×1024 -> 4096 patches）；
- 解决方案：Swin 的窗口注意力、PVT 的下采样、Deformable Attention 等。

**Q8：ViT 的 Patch Embedding 怎么实现？**

等价于一个卷积核大小 $P$、步长 $P$、输出通道 $D$ 的卷积。PyTorch 中：

```python
nn.Conv2d(3, embed_dim, kernel_size=patch_size, stride=patch_size)
```

**Q9：为什么 ViT 第一层就看到全局，CNN 要堆很多层？**

- ViT 的自注意力让每个 patch 直接与所有其他 patch 交互；
- CNN 的卷积是局部的，需要堆叠多层让感受野扩大到全图。

**Q10：ViT 在分类以外的任务上能用吗？**

能，但需要改造：

- **检测**：DETR 系列把 ViT 作为 backbone；
- **分割**：用 patch token 作为像素特征，配合上采样；
- **密集预测**：Swin、PVT 等层级化 ViT 更适合。

## 10.总结

- **ViT 把图像视为 patch 序列**，用纯 Transformer 处理，无卷积；
- **大数据优势明显**：JFT-300M 预训练大幅超越 CNN；
- **小数据劣势明显**：无归纳偏置的代价；
- **核心创新**：Patch Embedding + [CLS] Token + 1D Position Embedding + 标准 Transformer Encoder；
- **后续工作**：DeiT（数据高效）、Swin（层级化）、BEiT（自监督）、MAE（掩码自监督）等大量改进。
