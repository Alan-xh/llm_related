# 2.SwinTransformer

## 1.概述

**Swin Transformer** 由微软亚洲研究院在 2021 年提出，是**层级化**的视觉 Transformer，解决了 ViT 计算复杂度 $O(N^2)$ 和不能做密集预测任务的问题。Swin 在多个 CV 任务（分类、检测、分割）上达到 SOTA，并获 ICCV 2021 Best Paper。

**论文**：Swin Transformer: Hierarchical Vision Transformer using Shifted Windows (Liu et al., 2021)

**核心创新**：

1. **层级结构**：类似 CNN，多 stage 下采样；
2. **窗口注意力（W-MSA）**：把 $O(N^2)$ 降为 $O(N)$；
3. ** shifted 窗口（SW-MSA）**：让相邻窗口信息流动；
4. **相对位置编码**：更好地建模局部关系。

## 2.动机

### 2.1 ViT 的问题

1. **计算复杂度 $O(N^2)$**：高分辨率图像不可行；
2. **不层级化**：所有 patch 都是同一分辨率，不适合检测、分割等密集预测任务（需要多尺度特征）；
3. **小数据表现差**。

### 2.2 CNN 的启发

- 多 stage 渐进下采样；
- 每个 stage 输出不同分辨率特征，可用作 FPN；
- 局部性 + 平移不变性。

## 3.Swin 架构

### 3.1 整体结构

```
Image (224×224×3)
   │
   ├── Patch Partition (4×4, stride=4) → (56×56×48)
   │
   ├── Stage 1: Linear Embedding → (56×56×96)
   │   └── Swin Block × 2 [W-MSA + SW-MSA]
   │
   ├── Patch Merging (stride=2) → (28×28×192)
   │   └── Stage 2: Swin Block × 2
   │
   ├── Patch Merging → (14×14×384)
   │   └── Stage 3: Swin Block × 6
   │
   ├── Patch Merging → (7×7×768)
   │   └── Stage 4: Swin Block × 2
   │
   └── LN + GAP + FC → 分类 logits
```

**Patch Merging**：相邻 2×2 patch 拼接 -> 通道变 4 倍 -> LayerNorm -> 1×1 卷积降为 2 倍 -> 输出 H/W 减半、通道翻倍。等价于 CNN 的 stride=2 下采样。

### 3.2 窗口注意力（W-MSA）

**ViT 全局注意力**：每个 patch 与所有 patch 交互，复杂度 $O(N^2)$。

**Swin 窗口注意力**：把 feature map 划分为 $M \times M$ 窗口（典型 $M=7$），**只在窗口内做自注意力**：

- 每窗口 $M^2$ 个 patch，自注意力复杂度 $O(M^4)$；
- 共 $\frac{N}{M^2}$ 个窗口，**总复杂度 $O(N \cdot M^2)$，与 $N$ 线性**；
- 56×56 -> 8×8 个 7×7 窗口，每窗口 49 个 patch，复杂度大幅降低。

### 3.3 Shifted 窗口（SW-MSA）

**W-MSA 问题**：窗口间无信息交流，等价于"巨型卷积"，限制了模型表达。

**SW-MSA 解决方案**：在下一层把窗口**偏移半个窗口大小**（$\lfloor M/2 \rfloor$）：

```
Layer l:   [W1][W2][W3][W4]     标准窗口
Layer l+1:   [W1'][W2'][W3'][W4']  偏移窗口
```

- 偏移后窗口跨越原窗口边界，使信息跨原窗口流动；
- 偏移后窗口数会变化，可通过 cyclic shift 高效实现。

**Cyclic Shift 高效实现**：

1. 把 feature map 上下左右各平移 $\lfloor M/2 \rfloor$（环形移位）；
2. 仍按标准 $M \times M$ 划窗做 W-MSA；
3. 对跨越边界的窗口用 **attention mask** 屏蔽跨窗口的 attention。

**两 block 配对**：W-MSA 和 SW-MSA 交替使用：

```
Block 1: W-MSA (window)
Block 2: SW-MSA (shifted window)
Block 3: W-MSA
Block 4: SW-MSA
...
```

### 3.4 相对位置编码

Swin 使用**相对位置偏置** $B \in \mathbb{R}^{(2M-1) \times (2M-1)}$，加到 attention 矩阵：

$$
\text{Attention}(Q, K, V) = \text{Softmax}\left( \frac{QK^T}{\sqrt{d}} + B \right) V
$$

- $B$ 是可学习参数，索引由 query 和 key 的相对位置决定；
- 范围 $[-(M-1), M-1] \times [-(M-1), M-1]$，共 $(2M-1) \times (2M-1)$ 个值；
- **实验证明相对位置偏置至关重要**，去掉掉 1~2% 精度。

### 3.5 Swin Block 结构

```
       ┌─ LN → W-MSA / SW-MSA → +residual ─┐
input ─┤                                    ├─ output
       └─ LN → MLP → +residual ─────────────┘
```

## 4.Swin 模型规格

| 模型 | 层数 | 维度 $C$ | 头数 | 参数量 | ImageNet top-1 |
| --- | --- | --- | --- | --- | --- |
| Swin-T | [2,2,6,2] | 96 | [3,6,12,24] | 28M | 81.3% |
| Swin-S | [2,2,18,2] | 96 | [3,6,12,24] | 50M | 83.0% |
| Swin-B | [2,2,18,2] | 128 | [4,8,16,32] | 88M | 83.5% |

## 5.关键优势

### 5.1 计算高效

- W-MSA 把全局注意力的 $O(N^2)$ 降为 $O(N)$；
- 窗口大小 $M=7$ 时，对 224×224 输入计算量与 ResNet-50 相当。

### 5.2 层级特征

- 4 个 stage 输出 4 个分辨率特征（1/4, 1/8, 1/16, 1/32）；
- 类似 ResNet，可直接用作 FPN backbone；
- **检测、分割任务表现优异**。

### 5.3 多尺度建模

- 早期窗口小，关注局部；
- 后期窗口大（虽然 $M$ 不变，但感受野等效扩大），关注全局；
- 自然形成多尺度特征。

## 6.Swin 在下游任务的表现

### 6.1 目标检测（COCO）

- Swin-L + Cascade Mask R-CNN：53.6 mAP（当时 SOTA）；
- 比 ResNet-50 + 同检测器高 4~5 mAP；
- 比 ConvNeXt 略优或持平。

### 6.2 语义分割（ADE20K）

- Swin-L + Semantic FPN：53.5 mIoU；
- Swin-L + Mask2Former：超过 55 mIoU；
- 长距离建模对场景理解任务帮助大。

### 6.3 图像分类（ImageNet）

- Swin-L 在 ImageNet-1k 上 84.5%（带 21k 预训练）；
- 与 ConvNeXt 持平。

## 7.面试常考问题

**Q1：Swin Transformer 解决了 ViT 的什么问题？**

1. **计算复杂度** $O(N^2) \to O(N)$，可处理高分辨率；
2. **层级结构**：多 stage 下采样，输出多尺度特征，适合密集预测任务；
3. **小数据表现**：通过窗口局部注意力引入归纳偏置，相对 ViT 在小数据上更稳。

**Q2：W-MSA 的复杂度是多少？**

每窗口 $M^2$ 个 patch，注意力 $O(M^4)$；共 $N/M^2$ 个窗口，**总复杂度 $O(NM^2)$，与 $N$ 线性**。

**Q3：SW-MSA 解决什么问题？怎么实现？**

- 问题：W-MSA 窗口间无信息交流；
- 解决：偏移窗口半个窗口大小，使新窗口跨越原窗口边界；
- 实现技巧：cyclic shift（环形移位）+ attention mask 屏蔽跨原窗口的 attention。

**Q4：Swin 为什么用相对位置编码？**

- ViT 的绝对位置编码不能反映 patch 间的相对关系；
- 相对位置编码对窗口内的相对位置敏感，**更符合视觉任务的局部性**；
- 实验证明相对位置偏置至关重要，去掉掉 1~2% 精度。

**Q5：Patch Merging 是什么？**

类似 CNN 的 stride=2 下采样。把 2×2 邻域 patch 拼接（通道变 4 倍）-> LayerNorm -> 1×1 卷积降为 2 倍 -> H/W 减半、通道翻倍。

**Q6：Swin vs ViT 的区别？**

| 维度 | ViT | Swin |
| --- | --- | --- |
| 结构 | 单 stage | 4 stage 层级 |
| 注意力 | 全局 | 窗口 + 偏移 |
| 复杂度 | $O(N^2)$ | $O(N)$ |
| 位置编码 | 1D 绝对 | 2D 相对 |
| 适合任务 | 分类 | 通用（分类/检测/分割） |
| 归纳偏置 | 几乎无 | 局部性 + 平移不变 |

**Q7：Swin 和 ConvNeXt 哪个好？**

- 性能相近；
- Swin 训练慢、推理稍慢（窗口划分开销）；
- ConvNeXt 部署更友好（量化稳定、内存友好）；
- 工业部署常选 ConvNeXt，研究/挑战 SOTA 选 Swin。

**Q8：为什么 W-MSA 和 SW-MSA 要交替使用？**

- 单用 W-MSA：窗口间无信息交流，等价于"巨型卷积"；
- SW-MSA 让相邻窗口信息流动；
- 交替使用 = "窗口内精细 + 跨窗口交流"。

**Q9：Swin 的 cyclic shift 为什么高效？**

- 直接实现 shifted window 需要重新划分窗口、处理跨边界窗口；
- cyclic shift 用 `torch.roll` 一次移位，仍按标准 $M \times M$ 划窗；
- 通过 attention mask 屏蔽不该交流的位置，**无额外计算开销**。

**Q10：Swin 的 attention mask 是怎么设计的？**

在 SW-MSA 中，cyclic shift 后部分窗口包含来自原不同窗口的 patch。这些 patch **不应跨原窗口做 attention**。attention mask 是一个 $M^2 \times M^2$ 矩阵，标记哪些 patch 对可以 attention、哪些不可以。

## 8.总结

- **Swin = 层级 + 窗口注意力 + 偏移窗口 + 相对位置编码**；
- 把 ViT 的 $O(N^2)$ 降为 $O(N)$，可处理高分辨率；
- 层级结构输出多尺度特征，适合检测、分割等密集预测任务；
- 是 ViT 之后最重要的视觉 Transformer 之一，广泛用作 backbone；
- 后续工作：Swin V2（扩大模型与分辨率）、CSWin（十字形窗口）、DAT（可变形窗口）等。
