# 3.DeiT

## 1.概述

**DeiT（Data-efficient Image Transformers）** 由 Facebook AI 在 2021 年提出，**让 ViT 不依赖大规模预训练数据**就能在 ImageNet-1k 上达到与 CNN 相当甚至更优的性能。DeiT 通过**强数据增强 + 蒸馏**两个手段解决了 ViT 的"小数据劣势"问题。

**论文**：Training data-efficient image transformers & distillation through attention (Touvron et al., 2021)

## 2.动机

### 2.1 ViT 的痛点

ViT 在 JFT-300M 等大数据上预训练后大幅超越 CNN，但：

1. **必须在大型数据集上预训练**才能发挥优势；
2. 在 ImageNet-1k（1.3M）上从头训练不如 ResNet；
3. 训练成本极高，普通研究者难以复现。

### 2.2 DeiT 的目标

**用普通算力（8 张 V100 训练 3 天）在 ImageNet-1k 上从头训练 ViT**，达到 CNN 同等水平。

## 3.DeiT 的关键技术

### 3.1 强数据增强

ViT 无归纳偏置，小数据上容易过拟合，需要**更强的数据增强**：

1. **RandAugment**：随机选择多种增强操作；
2. **Mixup**：图像和标签混合：
   $$ x_{mix} = \lambda x_a + (1-\lambda) x_b, \quad y_{mix} = \lambda y_a + (1-\lambda) y_b $$
3. **CutMix**：图像区域拼接：
   $$ x_{cut} = M \odot x_a + (1-M) \odot x_b $$
4. **Random Erasing**：随机擦除区域；
5. **Stochastic Depth**：随机跳过某些层，类似 Dropout 但作用在层间；
6. **Label Smoothing**：标签平滑 $y' = (1-\epsilon) y + \epsilon/K$。

### 3.2 优化策略

- **AdamW 优化器**（不是 SGD）；
- **Cosine Learning Rate + Warmup**：3 epoch warmup，30 epoch 后 cosine 衰减；
- **EMA**：指数滑动平均权重；
- **重复采样**：每个 epoch 重复采样多次；
- **长训练**：300 epochs（ViT 原版只 30 epoch）。

### 3.3 Teacher-Student 蒸馏

DeiT 最重要的创新：用强 CNN（RegNet）作为 teacher 蒸馏 ViT student。

**蒸馏损失**：

$$
L = \alpha \cdot \text{CE}(y, \text{soft\_logits}_s) + (1-\alpha) \cdot \text{CE}(p_t, \text{logits}_s)
$$

- $p_t$ 是 teacher 的 soft prediction；
- $\alpha$ 是平衡系数。

### 3.4 Distillation Token

DeiT 引入**第二个特殊 token**（除了 [CLS]），叫 **distillation token**：

- 在输入序列最前面加 [CLS] 和 [dist] 两个 token；
- [CLS] 用真实标签监督；
- [dist] 用 teacher 的 soft 标签监督；
- 两个 token 通过自注意力互相交流；
- **推理时**：[CLS] 和 [dist] 输出**相加**作为最终预测。

```
Image → Patch Embed → [CLS] + [dist] + patches → Transformer × L →
  [CLS] → MLP → CE loss (hard label)
  [dist] → MLP → KL loss (soft teacher label)
```

### 3.5 Hard vs Soft Distillation

| 方式 | 公式 | 特点 |
| --- | --- | --- |
| Hard | $L = \text{CE}(y, \text{logits}_s)$ + $\text{CE}(\arg\max p_t, \text{logits}_s)$ | teacher 预测 argmax 后做 CE |
| **Soft（DeiT 默认）** | $L = \alpha \text{CE}(y, \cdot) + (1-\alpha) \text{KL}(p_t \| p_s)$ | teacher soft label 监督 |

实验表明 soft distillation 效果略好。

## 4.DeiT 模型规格

| 模型 | 参数量 | FLOPs | ImageNet top-1 | 训练数据 |
| --- | --- | --- | --- | --- |
| DeiT-T | 5M | 1.3G | 72.2% | ImageNet-1k |
| DeiT-S | 22M | 4.6G | 79.8% | ImageNet-1k |
| DeiT-B | 86M | 17.5G | 81.8% | ImageNet-1k |
| DeiT-B (384) | 86M | 55.4G | 83.1% | ImageNet-1k |

**对比 ViT-B（在 JFT-300M 预训练）**：81.8% on ImageNet-1k。
**DeiT-B（无需大数据预训练）**：81.8%，**持平**！

## 5.Distillation Token 的作用

### 5.1 为什么 [CLS] + [dist] 两个 token？

实验发现：

- 单 [CLS] token + 蒸馏 loss：效果略差；
- [CLS] + [dist] 两个 token：效果最好；
- 两个 token 学到**不同的特征**：[CLS] 偏向图像本身的语义，[dist] 偏向 teacher 的归纳偏置。

### 5.2 CNN teacher vs Transformer teacher

实验发现：

- **CNN teacher** 蒸馏效果远好于 Transformer teacher；
- CNN 的归纳偏置（平移不变、局部性）通过蒸馏传递给 ViT；
- 让 ViT 同时具备 Transformer 的全局建模和 CNN 的归纳偏置。

### 5.3 为什么 [CLS] 和 [dist] 相加作为最终预测？

- 两个 token 互补：[CLS] 学图像本身，[dist] 学 teacher 的归纳偏置；
- 推理时相加 = ensemble，比单独使用任一 token 更稳定。

## 6.训练细节

### 6.1 训练设置

- 8 × V100 GPU，训练 3 天；
- ImageNet-1k（1.3M 图像）；
- Batch size 1024；
- 300 epochs；
- AdamW，lr 5e-4 * batch/512，weight decay 0.05；
- Cosine LR + 3 epoch warmup。

### 6.2 数据增强组合

```python
transform = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.08, 1.0)),
    transforms.RandomHorizontalFlip(),
    RandAugment(),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
    RandomErasing(),
])
# Mixup / CutMix 在 batch 维做
```

## 7.DeiT 的意义

1. **让 ViT 普惠**：不需要 JFT-300M 大数据，普通研究者也能训；
2. **证明数据增强对 Transformer 至关重要**；
3. **蒸馏传递归纳偏置**：让 ViT 兼具 Transformer 和 CNN 的优点；
4. **后续工作基础**：DeiT 是后续大量 ViT 改进的基础（DeiT-III、DeiT-V2 等）。

## 8.面试常考问题

**Q1：DeiT 解决了 ViT 的什么问题？**

ViT 必须在 JFT-300M 等大数据上预训练才能超越 CNN，DeiT 让 ViT 在 ImageNet-1k 上从头训练达到 CNN 同等水平。

**Q2：DeiT 的关键技术是什么？**

1. **强数据增强**：RandAugment + Mixup + CutMix + Random Erasing + Stochastic Depth；
2. **优化策略**：AdamW + Cosine LR + Warmup + EMA + 长训练；
3. **Teacher-Student 蒸馏**：用 RegNet CNN 作 teacher 蒸馏 ViT；
4. **Distillation Token**：引入第二个特殊 token 学 teacher 的归纳偏置。

**Q3：为什么 CNN teacher 比 Transformer teacher 蒸馏效果好？**

CNN 内置平移等变 + 局部性等归纳偏置，通过蒸馏传递给 ViT，让 ViT 同时具备两种模型的优点。Transformer teacher 本身也无归纳偏置，蒸馏收益小。

**Q4：[CLS] 和 [dist] token 的区别？**

- [CLS]：用真实 hard label 监督，学图像本身语义；
- [dist]：用 teacher soft label 监督，学 teacher 的归纳偏置；
- 推理时相加作为 ensemble。

**Q5：为什么 DeiT 用 AdamW 而不是 SGD？**

- Transformer 对优化器敏感，AdamW 收敛更稳；
- CNN 用 SGD 常更好，但 Transformer 用 AdamW 几乎是标配。

**Q6：Mixup 和 CutMix 的区别？**

- **Mixup**：图像整体线性混合 + 标签线性混合；
- **CutMix**：图像区域拼接 + 标签按区域面积加权；
- CutMix 保留更多局部结构，对 ViT 这种无局部性归纳偏置的模型更重要。

**Q7：Stochastic Depth 是什么？**

训练时随机跳过某些层（用 identity 替代），推理时用所有层。类似 Dropout 但作用在层间，能正则化 + 加速训练。

**Q8：DeiT 和 ViT 在架构上的区别？**

- 架构几乎相同（标准 Transformer Encoder）；
- DeiT 多一个 distillation token；
- 训练策略完全不同（强增强 + 蒸馏 + 长训练）；
- DeiT 不需要大数据预训练。

**Q9：DeiT 在小数据上的表现？**

得益于数据增强和蒸馏，DeiT 在 ImageNet-1k 上的小数据子集（如 10% 数据）表现比 ViT 强很多，但仍不如 CNN（如 ResNet）。

**Q10：Label Smoothing 的作用？**

- 把 hard label [0, 0, 1, 0] 变成 soft label [0.033, 0.033, 0.9, 0.033]；
- 防止模型过度自信，提升泛化；
- 通常 $\epsilon = 0.1$。

## 9.总结

- **DeiT = 强数据增强 + CNN 蒸馏 + 长训练**；
- 让 ViT 在 ImageNet-1k 上从头训练达到 CNN 水平，无需大数据预训练；
- **distillation token** 是核心创新，让 ViT 学到 CNN 的归纳偏置；
- 后续 DeiT-V2 引入 BEiT 自监督、知识蒸馏改进等进一步提升；
- DeiT 之后，"用 CNN 蒸馏 ViT"成为标准做法。
