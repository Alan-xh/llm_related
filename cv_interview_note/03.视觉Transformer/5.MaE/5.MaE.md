# 5.MaE

## 1.概述

**MAE（Masked Autoencoder）** 由何恺明团队在 2021 年提出，是**最简单、最有效**的视觉自监督方法之一。MAE 借鉴 BERT 的 mask 预训练思路，**随机 mask 75% 的 patch，然后重建被 mask 的像素**。简单设计 + 高效训练让 MAE 成为 ViT 自监督的代表方法。

**论文**：Masked Autoencoders Are Scalable Vision Learners (He et al., 2021)

## 2.动机

### 2.1 视觉与语言的区别

| 维度 | 语言 | 视觉 |
| --- | --- | --- |
| 信息密度 | 高（每个词重要） | 低（冗余大） |
| Mask 比例 | 15% | 75% |
| 任务难度 | 中等 | 太低（mask 少时） |

**关键洞察**：图像信息高度冗余，相邻像素高度相关。mask 15% 时模型可以"看一个像素猜另一个"，学不到语义信息。**必须 mask 极高比例（75%）**才能强制模型学真正的高层语义。

### 2.2 已有方法的局限

- **BEiT**：需要训练 VQ-VAE tokenizer，复杂；
- **Contrastive（SimCLR/MoCo）**：需要负样本、大 batch、复杂技巧；
- **MAE**：**最简单**，仅 mask + 重建像素。

## 3.MAE 架构

### 3.1 整体流程

```
Image
  │
  ├── Patch Embed (16×16)  →  N = 196 个 patch
  │
  ├── Random mask 75%      →  49 个 visible patch（保留）
  │
  ├── ViT Encoder          →  only on visible patches (49 个)
  │
  ├── Insert mask tokens   →  完整 196 个位置
  │       (mask token 是可学习的)
  │       + position embedding
  │
  ├── ViT Decoder          →  在 196 个位置上做
  │
  └── Linear projection    →  预测每 patch 的像素值
                                ↓
                          MSE Loss (vs 原始像素)
```

### 3.2 不对称架构（关键设计）

**Encoder**：标准 ViT，**只处理 visible patches（25%）**；

**Decoder**：轻量 ViT（窄、浅），处理**完整 196 个位置**（visible + mask token）。

**为什么不对称？**

- Encoder 是预训练后真正使用的部分，**只处理 25% 大幅加速**（4 倍快、4 倍省内存）；
- Decoder 只在预训练时用，可以轻量；
- 像素重建是低语义任务，不需要重 decoder。

### 3.3 Mask Token

被 mask 的位置在 decoder 输入处插入一个**可学习的 [MASK] token**（共享）：

```python
mask_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
# 在 decoder 输入序列中，mask 位置替换为 mask_token
# 加上对应位置的 position embedding
```

### 3.4 重建目标

**重建什么？**

- 每个 patch 的**原始像素值**（被归一化后）；
- 不重建 visible patches（已知的）。

**Loss**：

$$
L = \frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \| p_i - \hat{p}_i \|^2
$$

其中 $p_i$ 是 patch $i$ 的真实像素，$\hat{p}_i$ 是预测值，$\mathcal{M}$ 是 mask 集合。

**归一化**：每个 patch 内部做 per-patch 归一化（减均值除方差），让模型关注**结构**而非**亮度**。

### 3.5 Mask 策略

- **随机均匀 mask**（不 block-wise）；
- **75% mask 比例**（关键）；
- 不需要任何 block 约束。

**为什么随机而不是 block-wise？**

- 高 mask 比例下，随机和 block 效果差不多；
- 随机更简单，且任务更难（被 mask 区域分散）。

## 4.MAE 训练

### 4.1 预训练

- ViT-Large/16；
- ImageNet-1k 自监督（只用图像，不用标签）；
- 1600 epochs（虽然 epoch 多，但每 epoch 只处理 25% patch，速度快）；
- AdamW，batch 4096；
- 强数据增强：RandAugment + Mixup + CutMix。

### 4.2 微调

- 加 [CLS] token + 分类头；
- 用预训练 encoder 初始化；
- 端到端微调 100 epochs；
- 用 EMA 提升稳定性。

## 5.MAE 性能

### 5.1 ImageNet 微调

| 方法 | 预训练 | ViT-B | ViT-L | ViT-H |
| --- | --- | --- | --- | --- |
| 有监督 DeiT | IN-1k | 81.8 | - | - |
| 有监督 JFT-300M | JFT-300M | 81.8 | 84.0 | 85.2 |
| **MAE** | IN-1k | 83.6 | 85.9 | 86.9 |

**结论**：

1. MAE 自监督（IN-1k）**超过有监督 JFT-300M**；
2. **scaling 性好**：ViT 越大，MAE 增益越大；
3. 简单 + 强大 = 现代自监督首选。

### 5.2 下游任务

- **COCO 检测**：53.3 AP（比有监督 +4）；
- **ADE20K 分割**：53.6 mIoU（比有监督 +4）；
- **迁移学习**：在 iNaturalist、Flowers 等小数据集上优势明显。

## 6.MAE 的优势

### 6.1 高效

- Encoder 只处理 25% patch，**预训练快 4 倍**；
- 显存占用少 4 倍；
- 训练大模型可行。

### 6.2 简单

- 不需要 VQ-VAE tokenizer（BEiT 需要）；
- 不需要负样本、对比学习（SimCLR/MoCo 需要）；
- 不需要特殊技巧；
- **MSE loss + 标准 ViT 即可**。

### 6.3 可扩展

- ViT 越大，增益越大；
- 可以扩展到 ViT-Huge 甚至更大；
- 数据越多效果越好。

### 6.4 学到语义表示

- 75% mask 让模型必须用**高层语义**才能重建；
- 可视化重建结果：MAE 能恢复物体的整体结构（不是简单插值）。

## 7.MAE 可视化

### 7.1 重建结果

给一张图，mask 75%，MAE 重建：

- 物体的整体轮廓能恢复；
- 细节（如纹理）可能不准；
- 表明 MAE 学到了"对象级"表示。

### 7.2 Attention 可视化

- 最后一层 attention 关注物体整体；
- 浅层关注局部细节；
- 与有监督训练的 attention 模式相似。

## 8.MAE 变种与后续工作

### 8.1 VideoMAE

- 把 MAE 扩展到视频；
- mask 比例 90%（视频时空冗余更高）；
- 极度高效的 video 自监督。

### 8.2 AudioMAE

- MAE 用于音频频谱图；
- 同样有效。

### 8.3 MultiMAE

- 多模态 MAE：RGB + 深度 + 语义分割；
- 共享 encoder 处理多模态。

### 8.4 CAE（Context Autoencoder）

- 改进 decoder，让 encoder 学到更多语义；
- 缩小 encoder-decoder 之间的"语义差距"。

### 8.5 AE-MAE / SimMIM

- SimMIM（微软）：用 Swin/ResNet，不抽取 visible，直接全图 mask 重建；
- SimpleBEiT、AE-MAE 等变种。

## 9.与 BEiT 的对比

| 维度 | MAE | BEiT |
| --- | --- | --- |
| 监督 | 像素（连续） | VQ token（离散） |
| Loss | MSE | CE |
| Encoder 输入 | visible only | visible only |
| Decoder | 轻 | 无 |
| Mask 比例 | 75% | 40% |
| Tokenizer | 不需要 | VQ-VAE |
| 训练速度 | 快 | 慢（要 tokenizer） |
| 性能 | 略优 | 优 |

**MAE 是当前 ViT 自监督的主流**，因为简单高效。

## 10.面试常考问题

**Q1：MAE 的核心思想？**

随机 mask 75% patch，用剩余 25% visible patch 重建被 mask 区域的像素。通过极高 mask 比例强制模型学高层语义。

**Q2：MAE 为什么 mask 75% 这么高？**

图像信息高度冗余，相邻像素高度相关。mask 太少（如 15%）模型可以"看一个像素猜另一个"，学不到语义。75% 才能强制模型用真正的语义理解去重建。

**Q3：MAE 的不对称架构是什么？为什么这么设计？**

- Encoder 重（标准 ViT），**只处理 visible patches**；
- Decoder 轻，处理完整 196 个位置；
- 设计原因：
  1. Encoder 是真正用的部分，只处理 25% 大幅加速；
  2. 像素重建是低语义任务，轻 decoder 足够；
  3. 避免 encoder 被低层任务"污染"。

**Q4：MAE 的 decoder 是什么样的？**

- 轻量 ViT（典型 8 层、维度 512）；
- 输入：visible patches + mask tokens + position embedding；
- 输出：每 patch 的像素预测。

**Q5：MAE 重建的目标是什么？**

- 每个 patch 的**原始像素值**（per-patch 归一化后）；
- Loss：MSE；
- 不重建 visible patches（已知的）。

**Q6：MAE 和 BEiT 的区别？**

| 维度 | MAE | BEiT |
| --- | --- | --- |
| 监督 | 像素 | VQ token |
| Tokenizer | 无 | VQ-VAE |
| Loss | MSE | CE |
| Mask 比例 | 75% | 40% |

**Q7：MAE 为什么比有监督 JFT-300M 还好？**

- 自监督利用了数据中**所有信息**（每像素都是监督信号）；
- 标签是稀疏信号（1 个/图），像素是密集信号；
- MAE 学到更通用、更迁移友好的表示。

**Q8：为什么 MAE 不需要 VQ-VAE tokenizer？**

- MAE 直接预测像素值（连续）；
- BEiT 预测离散 token 需要 tokenizer；
- MAE 简单但同样有效。

**Q9：MAE 训练为什么这么快？**

- Encoder 只处理 25% patch（4 倍加速）；
- Decoder 轻；
- 虽然 epoch 多（1600），但每 epoch 计算量小。

**Q10：MAE 学到的表示有什么特点？**

- 语义性强：能恢复物体整体结构；
- 通用性强：迁移到检测、分割效果好；
- 可扩展：模型越大，MAE 增益越大；
- 与有监督训练的 attention 模式相似，但泛化更好。

**Q11：MAE 是否能用于 CNN？**

可以但不直接适用：

- 卷积是局部操作，无法直接处理稀疏 visible patches；
- 需要 special 设计（如 ConvNeXt + sparse conv，或 SimMIM 的方式）；
- ViT 是天然适配 MAE 的架构。

**Q12：MAE 训练 1600 epoch 不慢吗？**

每 epoch 只处理 25% patch，等效计算量约为 ViT 标准 epoch 的 1/4。所以 1600 epoch ≈ 标准 400 epoch 的计算量。

## 11.总结

- **MAE = 高比例随机 mask + 不对称 encoder-decoder + 像素重建**；
- 简单、高效、scaling 好；
- 在 ImageNet-1k 自监督超过有监督 JFT-300M；
- 学到的表示通用性强，下游任务提升明显；
- 是当前 ViT 自监督的主流方法；
- 启发了大量后续工作（VideoMAE、AudioMAE、MultiMAE 等）；
- 何恺明团队后续的 **MaskFeat** 进一步改进目标（HOG 特征而非像素）。
