# 斯坦福CS231n

## 1.课程概况

- **课程名**：CS231n: Deep Learning for Computer Vision（斯坦福大学）；
- **官网**：<https://cs231n.stanford.edu/>（课程安排、讲义、作业均可在官网及课程 GitHub 找到）；
- **内容**：从图像分类入手，系统讲解 CNN、训练技巧、检测分割、生成模型、强化学习与视觉等；
- **特点**：作业实战性强（numpy 手写神经网络/卷积/反向传播，后改为 PyTorch）；
- **适合**：CV 入门第一课，配合本仓库各章节查漏补缺。

## 3.各 Lecture 核心要点

### L1：计算机视觉概述与课程历史

- 视觉是理解世界的核心感知通道；
- 从 Hubel & Wiesel 的猫视觉皮层研究，到感受野概念；
- 历史脉络：块世界 -> 特征表示（SIFT）-> 数据集驱动（ImageNet）-> 深度学习复兴（AlexNet 2012）。

### L2：图像分类流水线

- 图像分类是 CV 基础任务：语义鸿沟问题（像素 -> 语义）；
- 挑战：光照、形变、遮挡、类内差异、背景干扰；
- 数据驱动方法：收集数据 -> 训练 -> 预测。

### L3：kNN 与线性分类

- **kNN**：距离度量（L1/L2）+ 最近邻投票；图像上效果差（维度灾难、语义不敏感），但介绍了很多基础概念（超参、交叉验证）；
- **线性分类器**：$f(x) = Wx + b$，为神经网络打基础；
- **SVM / Softmax** 两种损失函数与多类扩展。

### L4：优化与反向传播

- 梯度下降、数值梯度 vs 解析梯度；
- **反向传播**：链式法则在计算图上的递归应用；
- 课程作业用 numpy 手写两层神经网络。

### L5：卷积神经网络

- 卷积层（局部连接、权值共享）、池化、FC；
- 参数量与感受野计算；
- CNN 为什么适合图像（平移不变、层次化特征）。

### L6：训练神经网络 I

- 激活函数（Sigmoid/Tanh/ReLU 等）；
- 数据预处理（去均值/归一化/PCA/白化）；
- 权重初始化（全零不行、Xavier/He）；
- Batch Normalization（原理、train/test 差异）。

### L7：训练神经网络 II

- 优化算法：Momentum、Nesterov、AdaGrad、RMSProp、Adam；
- 学习率调度、二阶方法简介（L-BFGS）；
- 正则化：L2、Dropout、数据增强、early stopping。

### L8：训练神经网络 III / 深度学习软件

- 超参调试策略（随机搜索、由粗到细）；
- 训练效果检查（loss 曲线、权重更新比）；
- 深度学习框架（早期 Theano/Torch，现在以 PyTorch 为主）。

### L9：CNN 架构

- AlexNet、VGG（小核深层堆叠）、GoogLeNet（Inception、1×1）、ResNet（残差连接）；
- 特点对比表（层数、参数量、错误率）；
- 后续版本补充：MobileNet、EfficientNet、NAS。

### L10：循环神经网络（部分年份）

- RNN / LSTM / GRU 基础；
- 视觉相关应用：图像描述（image captioning）、视频理解。

### L11：检测与分割

- 检测：滑动窗口 -> R-CNN 系列 -> YOLO/SSD 单阶段；
- 分割：语义分割（FCN）、实例分割、全景分割概览；
- 评测：IoU、mAP、mIoU。

### L12：视觉识别与定位（部分年份）

- 定位、细粒度识别；
- 可视化与理解 CNN（Saliency Map、特征反演、愚弄图像）。

### L13：生成模型

- 无监督学习与像素级模型（自回归）简介；
- **VAE**（变分下界、重参数化）；
- **GAN**（生成器/判别器博弈、训练不稳问题）；
- 近年版本补充扩散模型概念。

### L14：深度强化学习（部分年份）

- MDP、Q-learning、Policy Gradient；
- 视觉应用：Atari 游戏、机器人控制。

### L15：深度学习高效方法与硬件（部分年份）

- GPU/TPU 计算特性；
- 模型效率：量化、剪枝、移动端部署概览。

### 后续新增（近年版本）

- **Transformer / ViT**：注意力机制与视觉应用；
- **自监督学习**：对比学习（SimCLR/MoCo）、掩码建模（MAE）；
- **自监督 + 检测分割专题、3D 视觉、多模态**等专题讲座。

## 4.推荐学习路径

```
第 1 步: L1-L5 基础(分类/优化/反向传播/CNN)
         -> 配合仓库 01、02 章
第 2 步: L6-L8 训练技巧 -> 配合仓库 04、05 章
第 3 步: 作业1(kNN/SVM/Softmax/两层NN)
         作业2(全连接+BN+Dropout)
         作业3(numpy 手写 CNN / 后期 PyTorch 版)
第 4 步: L9 架构 + L11 检测分割 -> 仓库 02、06、07 章
第 5 步: L13 生成模型 -> 仓库 08 章
第 6 步: 近年新增 Transformer/自监督 -> 仓库 03 章
```

**建议**：

1. **作业必须做**：手写反向传播一次，胜过看十遍推导；
2. 官方 notes（cs231n.github.io）比视频更系统，适合快速复习；
3. 面试重点多在 L4（反向传播）、L6-8（训练细节）、L9（架构演进）、L11（检测分割）；
4. 深入某方向后回到本仓库对应章节看更完整的面试导向整理。
