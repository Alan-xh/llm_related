# 5.传统特征

## 1.概述

深度学习之前，CV 系统的核心是**手工特征（Hand-crafted Features）**。这些特征经过精心设计，能在保留关键信息的同时压缩维度，是 SIFT、HOG、SURF、ORB 等经典算法的基础。**理解这些传统特征对学习 CNN 的特征可视化、局部描述子、SLAM 等领域仍然重要**。

传统特征大致分为：

1. **角点检测**：Harris、FAST、Shi-Tomasi
2. **局部描述子**：SIFT、SURF、ORB、BRIEF
3. **全局描述子**：HOG、LBP、Gabor、Haar

## 2.角点检测

**角点（Corner）**：两条或多条边缘交汇的点，**在两个方向上梯度都很大**。角点是最稳定的特征点，适合做匹配、跟踪。

### 2.1 Moravec 角点检测器（1980）

最早期的角点检测算法：计算每个像素在 4 个方向（水平、垂直、两条对角）上移动 1 像素后的 SSD（平方误差和），取**最小值**作为角点响应。该最小值大 -> 在所有方向上都变化大 -> 角点。

**缺点**：各向异性、对边缘敏感、不可微。

### 2.2 Harris 角点检测（1988）

**核心思想**：用 Taylor 展开将 Moravec 的 SSD 离散差分变为连续导数，构造**结构张量（Structure Tensor）**：

$$
M = \sum_{(x,y) \in W} w(x, y) \begin{bmatrix} I_x^2 & I_x I_y \\ I_x I_y & I_y^2 \end{bmatrix}
$$

其中 $I_x, I_y$ 是图像在 x、y 方向的梯度，$w(x, y)$ 是窗口权重（常用高斯）。

**响应函数**：

$$
R = \det(M) - k \cdot \text{trace}^2(M) = \lambda_1 \lambda_2 - k(\lambda_1 + \lambda_2)^2
$$

其中 $\lambda_1, \lambda_2$ 是 $M$ 的两个特征值。

**判定**：

| $\lambda_1, \lambda_2$ | 含义 | R |
| --- | --- | --- |
| 都小 | 平坦区域 | 小 |
| 一个大一个小 | 边缘 | 负 |
| 都大 | 角点 | 大 |

**特点**：

1. **旋转不变**：特征值不随坐标轴旋转；
2. **光照线性变化不变**：梯度对线性亮度变化不敏感；
3. **尺度敏感**：放大图像后角点可能变成边缘；
4. **可微、计算高效**。

```python
gray = np.float32(gray)
dst = cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)
```

### 2.3 Shi-Tomasi 角点检测（GoodFeaturesToTrack, 1994）

改进 Harris 的响应函数：

$$
R = \min(\lambda_1, \lambda_2)
$$

若 $R > T$ 则认为是角点。**比 Harris 在多数场景下更稳定**，常用于光流跟踪的"好特征"。

### 2.4 FAST 角点检测（2006）

**Features from Accelerated Segment Test**：以像素 p 为中心，考察半径为 3 的圆周上 16 个像素。若**连续 N 个像素**（N=9 或 12）都比 p 的亮度高 $t$ 或低 $t$，则 p 为角点。

**加速**：

1. 先检测位置 1、5、9、13（上下左右），若至少 3 个不满足则直接排除；
2. 用机器学习决策树进一步加速；
3. 用非极大值抑制去重复。

**特点**：极快，适合实时应用（SLAM、AR）；本身没有描述子，常配 BRIEF 形成 ORB。

## 3.SIFT（尺度不变特征变换）

**论文**：Distinctive Image Features from Scale-Invariant Keypoints (David Lowe, 2004)

SIFT 是**最经典的传统局部特征**，对**尺度、旋转、光照、视角变化**都具有较强不变性。

### 3.1 算法步骤

1. **尺度空间极值检测**：构建高斯金字塔 + DoG 金字塔，在 3D 空间 $(x, y, \sigma)$ 找局部极值（与 26 个邻居比较）；
2. **关键点定位**：用 DoG 函数的 Taylor 展开精确定位，去除低对比度点和边缘响应点（用 Hessian 矩阵）；
3. **方向分配**：在关键点邻域计算梯度方向直方图（36 bins，每 10°），取主方向作为关键点方向，**实现旋转不变**；
4. **关键点描述子**：在主方向坐标系下，将 16×16 邻域划分为 4×4 子区域，每个子区域计算 8 方向梯度直方图，得到 $4 \times 4 \times 8 = 128$ 维向量；
5. **描述子归一化**：归一化后对阈值截断（0.2），再归一化，**抑制高梯度影响、增强光照不变性**。

### 3.2 SIFT 的不变性

| 变化 | 不变原因 |
| --- | --- |
| 尺度 | DoG 多尺度极值 |
| 旋转 | 主方向对齐 |
| 光照线性 | 梯度方向归一化 |
| 视角 | 局部描述子鲁棒 |

### 3.3 SIFT 的缺点

1. **计算量大**：高斯金字塔 + 描述子计算开销大；
2. **专利保护**（专利 2020 已过期）：曾限制商业使用；
3. **对模糊图像、低纹理区域效果差**。

```python
sift = cv2.SIFT_create(nfeatures=500)
kps, des = sift.detectAndCompute(gray, None)
```

## 4.SURF（加速鲁棒特征）

**论文**：SURF: Speeded Up Robust Features (Bay et al., 2006)

SIFT 的加速版本，主要改进：

1. **用 Box Filter 近似高斯二阶导**，借助**积分图**加速，比 SIFT 快 3~5 倍；
2. **用 Hessian 矩阵行列式**找极值，比 DoG 更稳定；
3. **描述子降维**：64 维（vs SIFT 128 维）。

**特点**：速度比 SIFT 快很多，性能略低；曾受专利保护，OpenCV 4.x 之后已移到主仓库（专利过期）。

## 5.ORB（Oriented FAST and Rotated BRIEF）

**论文**：ORB: an efficient alternative to SIFT or SURF (Rublee et al., 2011)

ORB = **FAST 关键点 + BRIEF 描述子**，并加入旋转不变性。是**开源、免专利、极快**的局部特征。

### 5.1 算法步骤

1. **FAST 检测关键点**；
2. **Harris 角点响应排序**：保留 top N；
3. **图像金字塔**：实现多尺度检测；
4. **计算关键点方向**：用灰度质心法（Intensity Centroid），把邻域质心相对几何中心的向量方向作为主方向；
5. **BRIEF 描述子**：在关键点邻域随机采样点对 $(p, q)$，比较灰度 $I(p) < I(q)$ 得到二值位；
6. **旋转 BRIEF（rBRIEF）**：根据主方向旋转采样模式，保证旋转不变。

### 5.2 优点

1. **速度快**：比 SIFT 快两个数量级；
2. **免专利**：商业友好；
3. **二进制描述子**：用 Hamming 距离匹配，速度极快。

**典型应用**：SLAM（ORB-SLAM）、实时匹配、AR。

```python
orb = cv2.ORB_create(nfeatures=500)
kps, des = orb.detectAndCompute(gray, None)
bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = bf.match(des1, des2)
```

## 6.BRIEF 描述子

在关键点邻域 $S \times S$ 区域（如 31×31）内，按某种概率分布随机选 $n$ 对点 $(p_i, q_i)$，比较灰度：

$$
b_i = \begin{cases} 1, & I(p_i) < I(q_i) \\ 0, & \text{otherwise} \end{cases}
$$

得到 $n$ 位（一般 256 位）二进制串作为描述子。

**优点**：极快、占用内存小；
**缺点**：对旋转、尺度敏感（ORB 修复了旋转问题）。

## 7.HOG（方向梯度直方图）

**论文**：Histograms of Oriented Gradients for Human Detection (Dalal & Triggs, 2005)

HOG 是一种**全局/区域描述子**，最经典的应用是**行人检测**。

### 7.1 算法步骤

1. **预处理**：转灰度、Gamma 校正（开 0.5 次方）降低光照影响；
2. **计算梯度**：用 Sobel 求梯度幅值和方向；
3. **划分 Cell**：图像分成 8×8 的 cell，每个 cell 内统计梯度方向直方图（9 bins，0~180°，无符号）；
4. **Block 归一化**：将 2×2 个 cell 组成 block，对 36 维向量做 L2-Hys 归一化（截断 + L2）；
5. **滑动 Block**：block 之间重叠（步长 = 1 cell），增强局部不变性；
6. **拼接**：所有 block 的归一化向量拼接为最终特征。

### 7.2 参数

- Cell 大小：8×8（典型）；
- Block 大小：2×2 cells（典型）；
- 直方图 bins：9（0~180°）；
- 重叠：步长 8 像素（即 1 cell）；
- 输入图像大小：64×128（INRIA 行人数据集）。

**总维度**：$7 \times 15 \times 36 = 3780$ 维。

### 7.3 HOG + SVM 行人检测

经典流水线：HOG 提特征 -> 线性 SVM 分类 -> 滑窗 + NMS 输出检测框。这是 2012 年之前行人检测的 SOTA。

```python
hog = cv2.HOGDescriptor()
hog.setSVMDetector(cv2.HOGDescriptor_getDefaultPeopleDetector())
boxes, weights = hog.detectMultiScale(gray)
```

## 8.LBP（局部二值模式）

**思想**：3×3 邻域中，每个像素与中心像素比较，大于等于中心为 1，否则为 0，得到 8 位二进制数作为中心像素的 LBP 值。

$$
\text{LBP}(x_c, y_c) = \sum_{i=0}^{7} s(I_i - I_c) \cdot 2^i, \quad s(x) = \begin{cases} 1, & x \geq 0 \\ 0, & x < 0 \end{cases}
$$

**改进**：

1. **均匀 LBP（Uniform LBP）**：0/1 跳变次数 ≤ 2 的模式，占比 > 90%，可以大幅降维（58 类 + 1 类其他）；
2. **圆形 LBP**：邻域从 3×3 改为半径 R 上的 P 个采样点；
3. **旋转不变 LBP**：旋转二进制串取最小值。

**应用**：人脸识别、纹理分类、表情识别。常与直方图统计结合使用。

## 9.Haar-like 特征

**思想**：用模板（白色矩形 - 黑色矩形）覆盖图像，计算差值作为特征。模板包括边、线、对角等。

**加速**：用**积分图**，任意矩形区域的和可在 $O(1)$ 计算。

**应用**：Viola-Jones 人脸检测（2001）的核心特征 + AdaBoost + Cascade 分类器，是历史上第一个实时人脸检测器。

## 10.特征匹配

得到关键点 + 描述子后，需要进行匹配：

| 方法 | 适用 | 距离 |
| --- | --- | --- |
| **暴力匹配 BFMatcher** | 任意 | L2（SIFT/SURF）、Hamming（ORB/BRIEF） |
| **FLANN** | 大规模 | 近似最近邻，快 |
| **KD-Tree** | 低维 | 精确最近邻 |
| **Ratio Test** | SIFT/SURF | 最近 / 次近 < 0.7 -> 接受 |
| **RANSAC** | 几何约束 | 剔除外点，估计单应矩阵 |

```python
# SIFT + Ratio Test + RANSAC
bf = cv2.BFMatcher(cv2.NORM_L2)
matches = bf.knnMatch(des1, des2, k=2)
good = [m for m, n in matches if m.distance < 0.75 * n.distance]
src = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
dst = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
H, mask = cv2.findHomography(src, dst, cv2.RANSAC, 5.0)
```

## 11.各特征对比

| 特征 | 维度 | 速度 | 不变性 | 典型应用 |
| --- | --- | --- | --- | --- |
| Harris | - | 快 | 旋转 | 跟踪、SLAM |
| SIFT | 128 | 慢 | 尺度+旋转+光照 | 图像拼接、匹配 |
| SURF | 64/128 | 中 | 尺度+旋转+光照 | 同 SIFT |
| ORB | 256 | 极快 | 旋转+部分尺度 | 实时 SLAM、AR |
| HOG | ~3780 | 中 | 几何 + 光照 | 行人/目标检测 |
| LBP | 58 | 极快 | 纹理 | 人脸、纹理识别 |
| Haar | 数千 | 极快 | 几何 | 人脸检测（VJ） |

## 12.面试常考问题

**Q1：Harris 角点检测为什么旋转不变但尺度敏感？**

- 结构张量 $M$ 的特征值 $\lambda_1, \lambda_2$ 不随坐标轴旋转而改变（只是特征向量方向变化），故旋转不变；
- 但放大图像后，原本"角点"在更大窗口下可能变成"边缘"（一侧梯度大、另一侧小），故尺度敏感。

**Q2：SIFT 为什么尺度不变？**

通过高斯金字塔 + DoG 在 $(x, y, \sigma)$ 三维空间找极值，对每个关键点自动确定最佳尺度，使其在图像缩放后仍能匹配到对应尺度的关键点。

**Q3：SIFT 的 128 维描述子是怎么得到的？**

主方向对齐后，16×16 邻域划为 4×4 子区域，每个子区域 8 方向直方图 -> $4 \times 4 \times 8 = 128$ 维。

**Q4：HOG 和 SIFT 的区别？**

- HOG 是**区域/全局描述子**，描述整块图像区域的梯度方向统计；
- SIFT 是**局部描述子**，只描述关键点邻域；
- HOG 没有尺度不变，但适合检测固定尺度的行人；
- SIFT 强调不变性，适合匹配、拼接。

**Q5：为什么 ORB 用二进制描述子？**

1. 计算快：只需比较灰度大小；
2. 存储省：256 bit = 32 byte；
3. 匹配快：用 XOR + popcount 算 Hamming 距离，CPU 有专门指令。

**Q6：积分图为什么能加速 Haar 特征？**

积分图 $ii(x, y) = \sum_{x' \leq x, y' \leq y} I(x', y')$，任意矩形区域 $(x_1, y_1) \sim (x_2, y_2)$ 的像素和可由 4 次查表得到：$S = ii(x_2,y_2) - ii(x_1,y_2) - ii(x_2,y_1) + ii(x_1,y_1)$。复杂度 $O(1)$，大幅加速 Haar 特征计算。

## 13.总结

- **角点检测**：Harris、Shi-Tomasi、FAST；
- **局部描述子**：SIFT、SURF、ORB、BRIEF，是匹配、SLAM、AR 的基础；
- **全局/区域描述子**：HOG、LBP、Haar，用于目标检测、纹理识别；
- **加速技术**：积分图（Haar）、Box Filter + 积分图（SURF）、二进制描述子（ORB）；
- 深度学习时代，传统特征依然在**低算力场景、几何精度要求高的任务（如 SLAM、三维重建）**中不可或缺。
