# 2.颜色空间

## 1.概述

**颜色空间（Color Space）**是用一组数值描述颜色的数学模型。不同颜色空间侧重不同方面：有的贴近人眼感知（HSV、LAB），有的便于显示（RGB），有的便于压缩传输（YUV）。在 CV 任务中，**选择合适的颜色空间往往能显著提升算法效果**，例如肤色检测常用 HSV、光照不变特征常用 LAB。

## 2.RGB 颜色空间

**RGB** 是最常用的颜色空间，基于**加色法**：任何颜色都可由红（R）、绿（G）、蓝（B）三种基色按不同比例混合得到。

- 三维笛卡尔坐标系，每个轴取值 0~255（8bit）；
- 形成一个边长 256 的立方体，原点 (0,0,0) 为黑色，对角点 (255,255,255) 为白色；
- **缺点**：R/G/B 三通道高度相关，亮度变化会同时影响三通道，**不适合直接做颜色分割**；与人类对颜色的直觉感知不一致。

```python
import cv2
img = cv2.imread("a.jpg")          # OpenCV 默认 BGR 顺序
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
```

## 3.HSV / HSI 颜色空间

**HSV** 模型贴近人眼对颜色的感知，由三个分量组成：

| 分量 | 全名 | 含义 | 取值范围 |
| --- | --- | --- | --- |
| **H** | Hue（色相） | 颜色种类（角度） | 0~360°（OpenCV 中 0~179） |
| **S** | Saturation（饱和度） | 颜色纯度 | 0~1（或 0~255） |
| **V** | Value（明度） | 颜色亮度 | 0~1（或 0~255） |

**几何模型**：用倒立的圆锥/六棱锥表示，顶点为黑色，底面圆心为白色，外圈为纯色。

**优势**：

1. **亮度与色度分离**：V 通道独立，处理光照变化时只动 V，不影响色调；
2. **直觉化**：H 直接对应颜色种类，便于做颜色阈值分割（如红色目标检测、绿色车牌定位）；
3. **肤色检测、目标跟踪**等任务常用 HSV。

**OpenCV 注意**：8bit 图像下 H 范围是 0~179（除以 2 以放进 8bit），S/V 范围是 0~255。

```python
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
# 红色 H 范围 0~10 和 170~180（OpenCV 中 0~10 与 170~179）
lower_red1 = np.array([0, 70, 50])
upper_red1 = np.array([10, 255, 255])
lower_red2 = np.array([170, 70, 50])
upper_red2 = np.array([180, 255, 255])

mask2 = cv2.inRange(hsv, lower_red2, upper_red2)
mask = cv2.bitwise_or(mask1, mask2)
```

## 4.HSL 与 HSV 的区别

- **HSV 中 V = max(R, G, B)**，纯色对应 V=255、S=255；
- **HSL 中 L = (max + min) / 2**，纯色对应 L=0.5、S=1；
- L=0.5 时是纯色，L<0.5 偏暗，L>0.5 偏亮；
- HSV 更适合**图像处理**，HSL 更适合**人类直觉调色**（如 CSS）。

## 5.LAB 颜色空间

**CIE LAB** 是基于人眼感知设计的均匀颜色空间，最贴近人类视觉：

| 分量 | 含义 | 范围 |
| --- | --- | --- |
| **L** | 亮度 Lightness | 0（黑）~100（白） |
| **a** | 红↔绿轴 | -128（绿）~+127（红） |
| **b** | 蓝↔黄轴 | -128（蓝）~+127（黄） |

**特点**：

1. **设备无关**：与具体显示设备解耦；
2. **均匀性**：相同数值差对应相同的人眼感知差异，**适合做颜色距离/相似度计算**；
3. **亮度分离**：L 独立，便于做光照不变特征；
4. **经典应用**：色彩迁移（Color Transfer）、图像风格迁移中的颜色匹配、海水/天空分割。

```python
lab = cv2.cvtColor(img, cv2.COLOR_BGR2LAB)
L, a, b = cv2.split(lab)
```

## 6.YUV / YCbCr 颜色空间

**YUV** 是电视广播、视频压缩领域常用的颜色空间，将**亮度（Y）与色度（U/V）分离**：

- **Y**：亮度（luma）分量，即灰度图；
- **U（Cb）**：蓝色色差；
- **V（Cr）**：红色色差。

**为什么分离 Y 和 UV？** 人眼对亮度敏感、对色度不敏感，因此 JPEG、MPEG 等编码方案对色度通道进行**下采样**（如 4:2:2、4:2:0），可在不显著降低视觉质量的前提下大幅压缩数据。

**YUV → RGB**（BT.601 标准）：

$$
\begin{bmatrix} R \\ G \\ B \end{bmatrix} =
\begin{bmatrix} 1.164 & 0.000 & 1.596 \\ 1.164 & -0.392 & -0.813 \\ 1.164 & 2.017 & 0.000 \end{bmatrix}
\begin{bmatrix} Y-16 \\ U-128 \\ V-128 \end{bmatrix}
$$

## 7.灰度化（Grayscale）

灰度化是将彩色图像转为灰度图的过程，常用方法：

1. **加权平均（最常用，符合人眼亮度感知）**：

   $$
   Y = 0.299 R + 0.587 G + 0.114 B
   $$

   人眼对绿色最敏感，对蓝色最不敏感，所以 G 权重最大。

2. **平均值法**：$Y = (R + G + B) / 3$；
3. **最大值法**：$Y = \max(R, G, B)$；
4. **取单通道**：直接取 G 通道作为灰度（绿色通道亮度信息最丰富）。

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
# 等价于 Y = 0.299R + 0.587G + 0.114B
```

## 8.二值化（Binarization）

二值化是将灰度图变为只有 0/255 两值的图像，常用方法：

- **全局阈值**：`cv2.threshold`，固定阈值 T；
- **Otsu**：自动选择阈值，使类间方差最大，适合双峰直方图；
- **自适应阈值**：`cv2.adaptiveThreshold`，对每个像素根据邻域均值/高斯加权均值计算阈值，**适合光照不均**的场景。

```python
_, bin_otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
bin_adapt = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                  cv2.THRESH_BINARY, 11, 2)
```

## 9.颜色空间对比总结

| 颜色空间 | 维度 | 优点 | 缺点 | 典型应用 |
| --- | --- | --- | --- | --- |
| RGB | 3 | 显示器原生 | 通道相关性强 | 显示、深度学习输入 |
| HSV/HSI | 3 | 亮度色度分离 | 不均匀 | 颜色分割、跟踪 |
| LAB | 3 | 感知均匀 | 计算复杂 | 颜色匹配、迁移 |
| YUV/YCbCr | 3 | 压缩友好 | 不直观 | 视频编码 |
| Gray | 1 | 简单 | 无色彩 | 边缘检测、OCR |
| CMYK | 4 | 减色法，印刷用 | 不便处理 | 印刷 |

## 10.面试常考问题

**Q1：为什么深度学习模型输入常用 RGB 而不是 HSV？**

- RGB 与训练数据（ImageNet 等）的统计特性一致；
- RGB 三通道相对独立，CNN 能通过卷积自动学到合适的色彩特征；
- HSV 虽然直观但 H 是周期量，处理不便。

**Q2：图像预处理时为什么经常先转 LAB 再做颜色匹配？**

- LAB 是**感知均匀**空间，相同欧氏距离对应相同的人眼感知差异；
- L 独立表示亮度，便于做光照归一化。

**Q3：BGR 与 RGB 混用会怎样？**

- OpenCV 默认 BGR，matplotlib/PIL 默认 RGB，混用会让图像"偏色"（红蓝互换）；
- 但若整个流程都用 BGR（如 OpenCV 读 + OpenCV 写），结果正常；
- 与预训练模型对接时，**必须确认模型期望的通道顺序**（如 ResNet 在 ImageNet 上训练，期望 RGB）。

## 11.总结

- 不同颜色空间服务于不同目的：显示用 RGB，处理用 HSV/LAB，压缩用 YUV；
- **亮度与色度分离**是设计颜色空间的常见思路，便于处理光照变化；
- 跨库处理图像时务必留意**通道顺序（BGR/RGB）**和**数值范围（0~255 vs 0~1）**，这是新手最常踩的坑。
