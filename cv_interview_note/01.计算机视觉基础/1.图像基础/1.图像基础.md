# 1.图像基础

## 1.概述

计算机视觉（Computer Vision, CV）是一门研究如何使机器"看"的科学，即用摄影机和电脑代替人眼对目标进行识别、跟踪和测量等机器视觉，并进一步做图形处理，使电脑处理成为更适合人眼观察或传送给仪器检测的图像。**图像是 CV 的最基本输入**，理解图像的数字化表示是学习 CV 的第一步。

## 2.图像的数字化表示

### 2.1 模拟图像与数字图像

- **模拟图像**：通过连续的物理量（如光学投影）表示的图像，空间坐标和亮度都是连续的。比如传统胶片照片。
- **数字图像**：将模拟图像在空间坐标和亮度上都进行**离散化**得到的图像，可用矩阵表示，便于计算机存储和处理。

**数字化过程包含两个步骤**：

1. **采样（Sampling）**：将空间上连续的图像离散化为一个个离散的点（像素 Pixel）。采样越密，图像分辨率越高，细节越清晰。
2. **量化（Quantization）**：将每个像素的亮度值离散化为有限个离散值（通常是 0~255 即 8bit）。量化层级越多，图像层次越丰富。

### 2.2 数字图像的矩阵表示

一幅大小为 $M \times N$ 的灰度图像可表示为一个二维矩阵：

$$
f(x, y) \in \mathbb{R}^{M \times N}, \quad x \in [0, M-1], y \in [0, N-1]
$$

其中 $f(x, y)$ 表示第 $x$ 行第 $y$ 列像素的亮度值。对于 8 位灰度图像，$f(x, y) \in [0, 255]$，0 表示纯黑，255 表示纯白。

彩色图像（RGB）则用三维张量表示：$f(x, y, c)$，其中 $c \in \{R, G, B\}$，即形状为 $H \times W \times 3$。

**深度学习中常见的图像数据格式**：

- **CHW**（Channel-Height-Width）：PyTorch 默认格式，形状为 `(C, H, W)`。
- **HWC**（Height-Width-Channel）：TensorFlow / OpenCV 默认格式，形状为 `(H, W, C)`。
- **NCHW / NHWC**：批处理时增加 batch 维度，PyTorch 默认 NCHW。

### 2.3 像素与分辨率

- **像素（Pixel）**：数字图像的最小单元。每个像素有位置 $(x, y)$ 和亮度值 $f(x, y)$ 两个属性。
- **空间分辨率（Spatial Resolution）**：单位长度内的像素数，常用 DPI（dots per inch）或 PPI（pixels per inch）表示。
- **灰度分辨率（Intensity Resolution）**：像素亮度可取的离散级数，例如 8bit 图像有 256 级灰度。
- **位深（Bit Depth）**：存储每个像素所需的比特数。8bit 灰度 → 256 级；16bit → 65536 级；24bit RGB = 3×8bit。

## 3.图像分类

### 3.1 按通道数分类

| 类型 | 通道数 | 形状（HWC） | 说明 |
| --- | --- | --- | --- |
| 二值图像 | 1 | (H, W, 1) | 像素值 0 或 1（或 0/255），常用于掩码 |
| 灰度图像 | 1 | (H, W, 1) | 像素值 0~255 |
| RGB 彩色图像 | 3 | (H, W, 3) | 红、绿、蓝三通道 |
| RGBA | 4 | (H, W, 4) | 多一个透明度通道 Alpha |
| 多光谱/高光谱 | 多 | (H, W, C) | 遥感图像，C 可达数十至上百 |

### 3.2 按位深分类

- **8bit**：最常见的图像格式，灰度 256 级。
- **16bit**：医学影像（CT/MRI）常用，灰度范围更广。
- **32bit float**：深度学习模型内部表示，方便反向传播。

### 3.3 按内容分类

- **自然图像**：日常拍摄的图像。
- **医学图像**：CT、MRI、X-ray、超声等。
- **遥感图像**：卫星或无人机拍摄的地面图像。
- **文档图像**：扫描文档、OCR 场景。
- **深度图像**：每个像素存储深度信息（距离）。

| **NIfTI/DICOM** | - | 医学影像专用格式 | 医学影像分析 |

## 5.图像的坐标系

不同库对图像坐标系的定义略有差异：

- **OpenCV / NumPy 数组**：`img[y, x]`，即 `(row, col)` → `(y, x)`，原点在左上角，y 向下、x 向右。
- **PIL / matplotlib**：与 OpenCV 类似，原点在左上。
- **数学坐标系**：原点在左下，y 向上。
- **图像中心坐标系**（旋转、仿射变换常用）：以图像中心为原点。

```python
import cv2
img = cv2.imread("a.jpg")          # BGR, HWC, uint8
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
print(img.shape)                   # (H, W, C)
pixel = img[100, 200]              # 第 100 行、第 200 列像素
```

## 6.直方图（Histogram）

**图像直方图**是图像像素强度分布的统计图。对于灰度图像，横轴是灰度值（0~255），纵轴是该灰度值出现的像素数（或频率）。

**作用**：

1. **图像质量分析**：直方图集中在低值 → 图像偏暗；集中在高值 → 偏亮；集中在中间 → 对比度低。
2. **直方图均衡化（Histogram Equalization）**：通过非线性拉伸重新分布像素强度，使直方图尽量均匀，**增强对比度**。
3. **直方图规定化（Histogram Matching/Specification）**：将一幅图像的直方图变换为指定的目标直方图，常用于风格统一。
4. **目标分割**：基于直方图的双峰法选取阈值。

```python
import cv2
import numpy as np
img = cv2.imread("a.jpg", cv2.IMREAD_GRAYSCALE)
hist = cv2.calcHist([img], [0], None, [256], [0, 256])
eq = cv2.equalizeHist(img)
```

## 7.图像的采样与插值

改变图像大小（缩放、resize）时，需要在原图像上采样并重新计算新位置像素值，即**插值（Interpolation）**：

- **最近邻插值（Nearest Neighbor）**：取最近的像素值。速度快但易产生锯齿。
- **双线性插值（Bilinear）**：用周围 4 个像素加权平均。质量与速度平衡，最常用。
- **双三次插值（Bicubic）**：用周围 16 个像素。质量更高，常用于放大。
- **Lanczos 插值**：使用 sinc 函数，质量最好但计算量大。

双线性插值公式（已知 $Q_{11}, Q_{12}, Q_{21}, Q_{22}$，求点 $P(x, y)$）：

$$
f(P) \approx \frac{1}{(x_2-x_1)(y_2-y_1)} \begin{bmatrix} x_2-x & x-x_1 \end{bmatrix} \begin{bmatrix} f(Q_{11}) & f(Q_{12}) \\ f(Q_{21}) & f(Q_{22}) \end{bmatrix} \begin{bmatrix} y_2-y \\ y-y_1 \end{bmatrix}
$$

## 8.常用图像处理库对比

| 库 | 语言 | 优势 | 不足 |
| --- | --- | --- | --- |
| **OpenCV** | C++/Python | 算法齐全、速度快 | 默认 BGR 易混淆 |
| **PIL/Pillow** | Python | API 友好，适合 IO | 计算性能弱 |
| **scikit-image** | Python | 与 NumPy 无缝衔接 | 部分算法较慢 |

## 9.总结

- 数字图像的本质是离散矩阵，由**采样 + 量化**得到；
- 图像按通道、位深、内容有多种分类，需要根据任务选择合适的格式；
- 坐标系、数据格式（CHW vs HWC）在不同库间不一致，**转换格式时务必确认**，否则极易踩坑（如 BGR/RGB 反了会让图像发蓝发红）；
- 直方图是分析图像亮度分布的简单而强大工具，是阈值分割、均衡化等基础算法的依据。
