# 2.BLIP系列

## 1.概述

**BLIP（Bootstrapping Language-Image Pre-training）** 系列是 Salesforce 提出的视觉-语言预训练工作，核心贡献是**统一理解与生成**的架构（BLIP）与**数据自举清洗**（CapFilt），以及后续用轻量 **Q-Former** 桥接冻结视觉模型与冻结 LLM 的 **BLIP-2**。BLIP-2 的 Q-Former 成为多模态领域的经典组件，影响了 MiniGPT-4、InstructBLIP 等大量工作。

| 时间 | 模型 | 核心贡献 |
| --- | --- | --- |
| 2022.01 | BLIP | 三任务统一架构 + CapFilt 数据清洗 |
| 2023.01 | BLIP-2 | 冻结 backbone + Q-Former 轻量桥接 |
| 2023 | InstructBLIP | BLIP-2 + 指令微调数据 |

## 2.BLIP（2022）

**论文**：BLIP: Bootstrapping Language-Image Pre-training for Unified Vision-Language Understanding and Generation (Li et al., Salesforce, 2022)

### 2.1 动机

1. 已有 VLP 模型要么只擅长理解（对比式，如 ALBEF），要么只擅长生成（编码器-解码器，如 SimVLM），难以兼得；
2. 网络爬取的图文对噪声大：配对文本常常与图像无关，直接训练损害性能。

### 2.2 MED 架构（统一理解与生成）

BLIP 提出的 **MED（Multimodal mixture of Encoder-Decoder）**：同一个 text encoder 的三种工作模式：

```
                 Image
                   │
            Image Encoder (ViT, 共享)
                   │
     ┌─────────────┼──────────────────┐
     ▼             ▼                  ▼
  单模态文本     图文交叉注意力      解码模式
  Text Encoder   Text Encoder       Text Decoder
  (自注意力)     (+cross-attn)      (causal + cross-attn)
     │             │                  │
   ITC 目标      ITM / LM 目标      文本生成
```

1. **单模态编码器**：图像、文本独立编码，做 **ITC**（图文对比学习，类 CLIP）；
2. **图文编码器**：text encoder 中插入 cross-attention 层融合图像特征，做 **ITM**（图文匹配，二分类）与图像-文本对比；
3. **图像-文本解码器**：将 cross-attention 层替换为 causal 自注意力，做 **LM**（给定图像生成文本，caption 生成）。

### 2.3 训练目标

- **ITC**（Image-Text Contrastive）：对齐图文特征空间（同 ALBEF，含动量蒸馏）；
- **ITM**（Image-Text Matching）：二分类判断图文是否匹配，hard negative 采样；
- **LM**（Language Modeling）：自回归生成 caption，用 causes mask 保证因果性。

### 2.4 训练细节

- 数据：1400 万图像（COCO + Visual Genome + 网络图文对），Web 图文占比 68%；
- 采用 ALBEF 的**动量蒸馏**（momentum distillation）：动量编码器生成软伪目标，缓解噪声数据下的不一致；
- 训练目标顺序：先 ITC，再 ITM（hard negative 采样），最后 LM；
- ITM 的 hard negative：用 ITC 相似度挑最容易混淆的负样本。

### 2.5 CapFilt：数据自举

**核心思想**：训练一个 captioner 生成伪标题，再训练一个 filter 过滤噪声数据，用清洗后的数据重新预训练。

```
初始噪声数据 Web 图文对
        │
   预训练 MED 模型
        │
   ┌────┴─────┐
   ▼          ▼
Captioner   Filter
(生成伪标题) (ITM 头打分)
   │          │
   └────┬─────┘
        ▼
保留：原配对中 filter 通过的 + captioner 生成且 filter 通过的
        │
        ▼
  用清洗后数据重新预训练
```

- **Captioner**：LM 模式，对网络图像生成新的伪 caption；
- **Filter**：ITM 模式，删除与图像不匹配的原始文本与生成的低质量文本；
- 结果：COCO 上微调后 captioning 达到当时 SOTA，检索性能显著超过同等规模模型。

## 3.BLIP-2（2023）

**论文**：BLIP-2: Bootstrapping Language-Image Pre-training with Frozen Image Encoders and Large Language Models (Li et al., Salesforce, 2023)

### 3.1 动机

- 端到端预训练大视觉模型 + 大语言模型代价极高（参数量大、算力贵）；
- 模态差异大：视觉 token 与文本 token 分布差距大，直接拼在一起训练效率低；
- **核心问题**：如何用最小的可训练参数，弥合冻结的单模态模型之间的模态鸿沟？

### 3.2 核心思想：冻结 + 轻量桥接

```
Image ──> 冻结 Image Encoder ──> 视觉特征 (如 257×1408)
   (CLIP ViT-g/14 或 EVA-CLIP)         │
                                       ▼
                              Q-Former (188M, 可训练)
                                32 个可学习 query
                                       │
                              32×768 固定长度输出
                                       │
                    ┌──────────────────┴──────────────────┐
                    ▼ (阶段二接 LLM)                       ▼ (阶段一自监督)
              全连接层 -> LLM 输入                ITC / ITM / 图文生成
           (OPT: 作为前缀 soft prompt)
           (FlanT5: 作为前缀输入)
                                       │
                                       ▼
                            冻结 LLM (OPT / FlanT5) -> 文本输出
```

- **冻结 image encoder**（CLIP ViT-g / EVA-CLIP）与**冻结 LLM**（OPT、FlanT5）全程不更新；
- 只训练 **Q-Former（188M 参数）**，预训练可训练参数比 Flamingo 少约 54 倍；
- 在多个 VQA / captioning 基准上取得 SOTA，且零样本图文生成能力强。

### 3.3 两阶段训练

**阶段一：模态表征学习（冻结 image encoder，无 LLM）**

- 让 Q-Former 学会从视觉特征中提取与文本最相关的信息；
- 三个目标（详见第 4 节）：ITC、ITM、ITG（图文生成），全部**共享同一个 Q-Former**；
- 注意：不同目标下 query 与文本的注意力 mask 策略不同，控制信息流。

**阶段二：对接 LLM（冻结 LLM，生成学习）**

- **Decoder-only LLM（OPT）**：Q-Former 输出经全连接投影为 LLM embedding 尺寸，作为**前缀 soft prompt**，教会 LLM 生成正确 caption（answer 前不加文本输入）；
- **Encoder-Decoder LLM（FlanT5）**：Q-Former 输出放在文本输入前面，与分隔符一起输入，训练 LLM 生成文本；
- 损失只有 LLM 的语言建模损失。

### 3.4 InstructBLIP

- 沿用 BLIP-2 架构，把各种数据集转成**指令格式**（"描述这张图""图中数字是多少"）；
- 指令感知的 Q-Former：文本指令也输入 Q-Former 参与 cross-attention；
- 多模态指令微调的代表工作，显著提升零样本能力。

## 4.Q-Former 结构详解

### 4.1 基本结构

- 与 BLIP 的 text encoder 同构：BERT-base 初始化，含 2 个共享的自注意力模块共 188M 参数；
- 输入端有 **32 个可学习 query 向量**（维度 768），每个 query 可与图像特征做 cross-attention；
- 输出固定为 **32×768**，与输入图像分辨率 / patch 数无关（天然压缩 + 定长接口）。

### 4.2 query 的作用

1. **信息瓶颈**：把数百个视觉 token 压缩为 32 个，只保留与文本相关的信息；
2. **定长接口**：为冻结 LLM 提供固定长度的 soft prompt，屏蔽视觉端长度变化；
3. **可分解性**：每个 query 自动学到不同的关注点（如不同区域 / 属性），可视化显示 query 与图像不同部分相关。

### 4.3 与 LLM 的接口方式

| LLM 类型 | 接口方式 |
| --- | --- |
| Decoder-only（OPT） | Q-Former 输出 -> FC 投影 -> 作为前缀 soft prompt，LLM 只见"图 + 答案" |
| Encoder-Decoder（FlanT5） | Q-Former 输出 -> FC -> 与指令文本拼接后一起输入 encoder |

### 4.4 三种训练目标共享 Q-Former

| 目标 | 文本 query 注意力 | 图像 query 注意力 | 说明 |
| --- | --- | --- | --- |
| ITC | 不能看图 | 不能看文本 | 图文 query 独立编码算对比 |
| ITM | 不能看图 | 能看文本 | query 融合图文判断是否匹配 |
| ITG（LM） | causal mask | 能看文本 | query 自回归生成文本（去掉了文本的自注意力，只用 query 与文本 cross-attention） |

- 通过精心设计的 mask 控制信息流，使三个目标不互相泄漏；
- 三目标联合训练让 query 兼顾对齐、匹配与生成能力。

## 5.性能

- BLIP-2 在 VQAv2、OK-VQA、COCO captioning 等基准上大幅超过同等规模模型（如 Flamingo80B 有一项可胜出，可训练参数少两个数量级）；
- 零样本图像-文本生成（看图说话、视觉对话）表现出色，是当时最实用的开源 VLM 之一。

## 6.优缺点

| 模型 | 优点 | 缺点 |
| --- | --- | --- |
| BLIP | 理解 + 生成统一；CapFilt 自举数据；动量蒸馏抗噪 | 参数效率一般；文本生成较弱（BERT 初始化） |
| BLIP-2 | 训练参数极少（188M）；对接任意 LLM；零样本强 | 32 token 信息瓶颈丢失细节；LLM 冻结限制指令跟随；OCR / 细粒度弱 |

## 7.面试常考问题

**Q1：BLIP 的两个核心创新？**

1. **MED 架构**：单模型统一理解（ITC/ITM）与生成（LM）三种模式，共享参数；
2. **CapFilt**：用 captioner 生成伪标题、filter 过滤噪声，自举清洗网络图文数据后重新训练。

**Q2：BLIP-2 的核心思想？为什么冻结两个 backbone？**

用轻量 Q-Former（188M）桥接冻结的 image encoder 与冻结 LLM，只训练桥接模块。冻结原因：单模态模型已经足够强，端到端训练算力不可承受；冻结也避免了灾难性遗忘与训练不稳定。

**Q3：Q-Former 是什么？32 个 query 有什么用？**

BERT 式结构 + 32 个可学习 query，通过 cross-attention 从视觉特征中提取定长（32×768）的、与文本最相关的表征。query 起信息瓶颈、定长接口与多功能分解的作用。

**Q4：BLIP-2 两阶段训练分别做什么？**

- 阶段一：冻结视觉端，用 ITC / ITM / ITG 三目标训练 Q-Former 的图表征能力；
- 阶段二：冻结 LLM，Q-Former 输出投影为 soft prompt 接入 LLM，用 LM 损失学会生成式对话 / 描述。

**Q5：三个训练目标为什么要用不同的 attention mask？**

- ITC 需要独立编码图文避免信息泄漏；
- ITM 需要 query 同时看图与文本做匹配判断；
- ITG 需要 causal mask 保证自回归生成不看到未来 token；
- 共享 Q-Former 的情况下只能靠 mask 控制信息流。

**Q6：CapFilt 的流程？**

预训练 MED -> captioner 生成伪标题 -> filter（ITM）对原始文本与伪标题过滤 -> 混合保留数据重新预训练，循环自举提升数据质量。

**Q7：BLIP-2 怎么接 decoder-only 与 encoder-decoder LLM？**

- decoder-only（OPT）：Q-Former 输出投影后作为前缀 soft prompt；
- encoder-decoder（FlanT5）：与指令文本拼接后输入 encoder。

**Q8：BLIP 与 CLIP 的区别？**

| 维度 | CLIP | BLIP |
| --- | --- | --- |
| 架构 | 双塔 | MED（对比 + 融合 + 解码） |
| 训练目标 | 仅 ITC | ITC + ITM + LM |
| 能力 | 检索 / 零样本分类 | 理解 + 生成（caption / VQA） |
| 数据 | WIT 4 亿 | 清洗后的 129M（CapFilt） |
| 交互深度 | 点积级 | cross-attention 级 |

**Q9：Q-Former 相比简单 MLP projector 的优劣？**

- Q-Former：可训练模块自带信息压缩与文本对齐训练，对冻结 LLM 更友好，但结构复杂、推理多一截计算；
- MLP projector（LLaVA）：简单直接，端到端微调时让 LLM 适应视觉 token，数据充足时同样甚至更好；
- BLIP-2 时代 LLM 多为冻结，Q-Former 是当时最优解。

**Q10：InstructBLIP 改进了什么？**

将多任务数据转成指令格式做指令微调，Q-Former 感知指令文本，大幅提升零样本指令跟随与 VQA 能力。

**Q11：BLIP-2 的信息瓶颈（32 query）有什么副作用？**

- 细粒度信息（小字 OCR、密集小目标）可能在压缩中丢失；
- 后续 Qwen-VL 等改为直接用更多视觉 token + cross-attention，部分即为此原因。

**Q12：BLIP 的动量蒸馏（ALBEF）为什么能抗噪？**

噪声图文对的目标标签可能错误；用动量模型生成软目标代替硬标签，让学生拟合更平滑的分布，降低错误标签的冲击。

## 8.总结

- **BLIP**：MED 架构统一理解与生成，CapFilt 自举清洗噪声图文数据；
- **BLIP-2**：冻结 image encoder + 冻结 LLM，仅训练 188M 的 Q-Former，两阶段（表征学习 + 生成学习）；
- **Q-Former**：32 个可学习 query 的定长信息瓶颈，通过不同 mask 支持 ITC / ITM / ITG 三目标；
- Q-Former 思想被 MiniGPT-4、InstructBLIP、Qwen-VL 等广泛继承；
- 与 LLaVA 的"简单 MLP + 端到端指令微调"形成两条技术路线，共同推动多模态大模型发展。
