# 1.CLIP

## 1.概述

**CLIP（Contrastive Language-Image Pre-training）** 由 OpenAI 于 2021 年提出，通过**对比学习**在 **4 亿图文对**（Web Image Text，WIT）上做大规模预训练，让模型直接从自然语言监督中学习视觉表示。CLIP 无需任务专属训练即可做**零样本分类**，是视觉-语言预训练（VLP）的奠基工作，也是后续开放词汇检测、文生图（Stable Diffusion 的 text encoder）、多模态大模型（LLaVA 等）的核心组件。

**论文**：Learning Transferable Visual Models From Natural Language Supervision (Radford et al., OpenAI, 2021)

### 1.1 发展历程

| 时间 | 模型 | 核心贡献 |
| --- | --- | --- |
| 2021.01 | CLIP | 对比学习 + 4 亿图文对 + 零样本分类 |
| 2021 | ALIGN（Google） | 18 亿噪声图文对，对齐双塔 |
| 2022 | FLAVA / CoCa | 单模型统一对比 + 生成目标 |
| 2022 | OpenCLIP | 开源复现，最大 LaION-2B 数据 |
| 2023 | EVA-CLIP | 强数据 + 训练技巧，80 亿参数 |
| 2023 | SigLIP | sigmoid 损失替代 softmax，无需大 batch |

## 2.双塔架构

### 2.1 整体结构

```
              Image                          Text
                │                              │
        Image Encoder                   Text Encoder
      (ViT-L/14 或 RN50x64)           (GPT-2 式 12 层 Transformer)
                │                              │
            图像特征 I_i                     文本特征 T_j
        (如 768 维, L2 归一化)          (如 512 维, L2 归一化)
                │                              │
                └──────────┬───────────────────┘
                           ▼
                 相似度矩阵 (N×N)
                 I_i · T_j / τ
                           │
              对角线为正样本，其余为负样本
                           │
                  InfoNCE 对比损失
```

- **双塔（dual encoder）**：图像和文本各自独立编码，只在最后做点积交互；
- **优点**：文本特征可离线预计算，检索 / 零样本分类效率极高；
- **缺点**：图像和文本交互浅（仅一个点积），细粒度理解弱于融合式模型（如 BLIP）。

### 2.2 图像编码器

- **ResNet 系列**：RN50 改进版（RN50x4、RN50x16、RN50x64），用注意力池化替代全局平均池化；
- **ViT 系列**：ViT-B/32、ViT-B/16、ViT-L/14；效果最好；
- **最大模型**：ViT-L/14@336px（336 分辨率微调），零样本 ImageNet 76.2%。

### 2.3 文本编码器

- GPT-2 风格的 Transformer（12 层、512 维、8 头）；
- 句尾加 `[EOS]` token，取其输出作为句子表征；
- 上下文长度 77（沿用至今，很多生图模型提示词长度限制的来源）。

## 3.对比损失（InfoNCE）

### 3.1 损失公式

对一个 batch 的 $N$ 个图文对，图像 $i$ 与文本 $j$ 的余弦相似度为：

$$
S_{ij} = \frac{I_i \cdot T_j}{\|I_i\| \|T_j\|}
$$

图像侧的对比损失（对每行做 softmax，对角线为正样本）：

$$
\mathcal{L}_{image} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp(S_{ii}/\tau)}{\sum_{j=1}^{N} \exp(S_{ij}/\tau)}
$$

文本侧 $\mathcal{L}_{text}$ 对称定义，总损失：

$$
\mathcal{L} = \frac{1}{2}(\mathcal{L}_{image} + \mathcal{L}_{text})
$$

### 3.2 温度参数 τ

- 可学习的标量，初始化为 0.07（logit 缩放，训练中限制范围避免过拟合）；
- τ 控制分布锐度：τ 小 → 分布尖锐，惩罚硬负样本更狠；τ 大 → 更平滑；
- CLIP 训练中 τ 自动降到约 0.01，等价于只关注最难的负样本。

### 3.3 伪标签任务

- CLIP 的预训练任务本质是一个 **N 分类"伪标签"任务**：batch 内第 $i$ 张图对应第 $i$ 句文本，其余皆为负样本；
- 没有人工标注，"标签"就是网络爬取的配对文本（天然噪声、弱监督）；
- 依赖超大规模数据 + 大 batch（最大 32768）提供足够负样本。

## 4.大规模无监督预训练

### 4.1 数据：WIT

- **Web Image Text**：4 亿图文对，OpenAI 从互联网构建；
- 覆盖 50 万个"查询词"，按频率平衡采样，避免只学到常见类别；
- 相比 ImageNet 类别数爆炸式扩大，是零样本能力的来源。

### 4.2 训练细节

- 最大 batch 32768（对比学习需要大量负样本）；
- ViT-L/14 训练 32 个 epoch，256 个 V100 训练约 2 周；
- 混合精度 + 渐进式学习率 warmup + 余弦衰减。

## 5.零样本分类流程

### 5.1 类别文本 prompt

把每个类别 $c$ 构造成一句话（prompt），如 `"a photo of a {c}"`：

1. 对全部类别构造 prompt，用 text encoder 离线编码成类别向量 $\{T_c\}$；
2. 输入图像经 image encoder 得到 $I$；
3. 计算相似度，softmax 得到类别分布：

$$
P(y=c \mid image) = \frac{\exp(S(I, T_c)/\tau)}{\sum_{c'} \exp(S(I, T_{c'})/\tau)}
$$

### 5.2 prompt engineering 与 ensemble

- **零样本 ImageNet**：用 `"a photo of a {c}."` 比 `"a photo of a {c}"` 高约 1.5%；加入场景提示（"a photo of the large {c}" 等 80 个模板）ensemble 再提约 3.5%，最终 76.2%；
- 说明：CLIP 对 prompt 措辞敏感，好的 prompt 能显著激活其知识。

### 5.3 零样本 / 线性探测性能

| 评测方式 | ImageNet top-1 | 说明 |
| --- | --- | --- |
| 零样本（prompt ensemble） | 76.2% | 无需任何训练样本 |
| 线性探测（冻结特征） | 85.0% 左右 | 冻结 encoder + 线性分类器 |
| 有监督 ResNet-50 | 76% 左右 | 全量微调 |

- 零样本 CLIP 在 27 个数据集中的 16 个上超过有监督 ResNet-50 全微调；
- 在细粒度 / 特殊分布（卫星图、淋巴结转移等）数据集上明显弱于有监督（分布外数据缺失）。

## 6.模型变体与规模

| 模型 | Image Encoder | 零样本 IN top-1 |
| --- | --- | --- |
| CLIP RN50 | ResNet-50 改 | 59.6% |
| CLIP ViT-B/32 | ViT-B/32 | 63.2% |
| CLIP ViT-B/16 | ViT-B/16 | 68.3% |
| CLIP ViT-L/14 | ViT-L/14 | 75.5% |
| CLIP ViT-L/14@336px | 336px 微调 | 76.2% |

- 零样本性能随模型规模和数据规模平滑提升，符合 scaling law；
- 这是 CLIP 最重要的实验结论：自然语言监督可随算力持续扩展。

## 7.下游应用

1. **开放词汇检测 / 分割**：OWL-ViT、ViLD、CLIPSeg、GroupViT，用 CLIP 文本特征替代固定类别分类器；
2. **跨模态检索**：图文互检（双塔 + 向量数据库，工业界标准方案）；
3. **文生图 text encoder**：Stable Diffusion v1 直接用冻结 CLIP 文本编码器；后续 SDXL/SD3 部分保留；
4. **多模态大模型视觉端**：LLaVA、Flamingo 等用 CLIP ViT 作为视觉编码器；
5. **零样本 / 开放词表分类**：无需训练直接对新类别分类；
6. **图文审核、重复图检测、视频封面打标**等工业场景。

## 8.局限性

1. **细粒度分类弱**：车型、鸟种、植物等细粒度任务零样本明显不如专用模型；
2. **组合推理弱**：对计数、空间关系（"左边的杯子"）、属性绑定（"红色的方块和蓝色的圆"）表现差；
3. **OCR / 文字理解弱**：训练数据中文本图像少，MNIST 零样本仅约 88%（有监督轻松 99%+）；
4. **对分布外数据敏感**：训练分布外的领域（医疗、卫星）零样本性能骤降；
5. **对 prompt 敏感**：措辞差异带来数个点的波动；
6. **双塔交互浅**：不适合需要深层图文交互的任务（如 VQA）。

## 9.相关模型：OpenCLIP、EVA-CLIP、SigLIP

### 9.1 OpenCLIP

- 社区开源复现，最大贡献是 **Laion-400M / Laion-5B** 开放图文数据集；
- 完整开源了从 ViT-B 到 ViT-g / ViT-G 的训练配方与权重。

### 9.2 EVA-CLIP

- 联想 / 昆仑万维等出品，结合 EVA 预训练初始化 image encoder；
- 更大数据 + 训练技巧，80 亿参数版本零样本 ImageNet 达 80%+。

### 9.3 SigLIP

**论文**：Sigmoid Loss for Language Image Pre-Training (Zhai et al., Google, 2023)

- 用 **sigmoid 损失**替代 softmax 对比损失：每个图文对独立二分类，不依赖 batch 内负样本；

$$
\mathcal{L} = -\frac{1}{n} \sum_{i=1}^{N} \sum_{j=1}^{N} \log \frac{1}{1 + e^{z_{ij}(S_{ij}/\tau - b)}}
$$

其中 $z_{ij}=1$（配对）或 $-1$（非配对），$b$ 为可学习偏置；

- 优点：无需超大批量，中小 batch 下性能更好，收敛快，已广泛用于多模态大模型（如 PaliGemma、现代 LLaVA 变体）的视觉端。

## 10.面试常考问题

**Q1：CLIP 的核心思想？**

用自然语言作为监督信号：4 亿图文对上做对比学习，让配对图文特征相似、非配对远离。学到的对齐空间支持零样本分类，且随数据 / 模型规模平滑扩展。

**Q2：为什么用双塔而不是融合式（cross-attention）？**

- 双塔图文独立编码，文本特征可离线缓存，推理只需点积，适合检索与零样本分类；
- 融合式交互深、精度高，但每对图文都要过一遍大网络，成本高；
- CLIP 目标是大规模预训练 + 高效迁移，双塔是精度与效率的折中。

**Q3：InfoNCE 损失的形式和温度参数的作用？**

$$
\mathcal{L} = -\frac{1}{N} \sum_{i} \log \frac{\exp(S_{ii}/\tau)}{\sum_{j} \exp(S_{ij}/\tau)}
$$

- τ 可学习，控制 softmax 锐度；
- τ 越小越聚焦硬负样本，训练中自动降到约 0.01。

**Q4：CLIP 怎么做零样本分类？**

1. 每个类别拼成 prompt（"a photo of a {c}"）；
2. text encoder 离线编码全部类别；
3. 图像特征与类别特征算相似度，softmax 取最大；
4. 多模板 ensemble 可再提点。

**Q5：CLIP 的"伪标签"是什么意思？**

预训练把 batch 内配对图-文当正样本、跨对当负样本，构成 N 路分类，"标签"由数据配对关系自动产生，无需人工标注。

**Q6：CLIP 的主要局限？**

- 细粒度、组合推理（计数 / 空间关系）、OCR 弱；
- 分布外领域性能骤降；
- 对 prompt 措辞敏感；
- 双塔交互浅，不适合 VQA 等深度交互任务。

**Q7：CLIP 为什么需要大 batch？**

InfoNCE 的负样本来自 batch 内其他样本，负样本越多、越多样，对比任务越有区分度。SigLIP 用 sigmoid 损失摆脱了这一依赖。

**Q8：SigLIP 相比 CLIP 改了什么？**

- sigmoid 逐对二分类替代 softmax 行 / 列归一化；
- 不需要大 batch 与全局负样本，中小规模训练更快更好；
- 加了可学习偏置补偿类不平衡。

**Q9：CLIP 在 Stable Diffusion 中的作用？**

作为 text encoder 把 prompt 编码为语义向量，经 cross-attention 注入 UNet 引导生成；提示词 77 token 限制即来自 CLIP 文本编码器。

**Q10：CLIP 为什么重要（影响）？**

- 证明自然语言监督可扩展，开启视觉零样本时代；
- 是开放词汇检测 / 分割、文生图、多模态 LLM（LLaVA 视觉端）的基础组件；
- 引发 OpenCLIP / EVA-CLIP / SigLIP 等大规模复现与改进。

## 11.总结

- **CLIP** = 双塔 + 对比学习 + 4 亿图文对，零样本 ImageNet 76.2%；
- **损失**：对称 InfoNCE + 可学习温度 τ；
- **零样本流程**：类别 prompt 编码 → 图文相似度 → 分类；
- **应用**：检索、开放词汇检测 / 分割、SD text encoder、MLLM 视觉端；
- **局限**：细粒度、组合推理、OCR 弱；
- **后续**：OpenCLIP（开源）、EVA-CLIP（更大更强）、SigLIP（sigmoid 损失）；
- CLIP 是多模态预训练的事实基座，理解它是理解现代多模态大模型的前提。
