# 3.LLaVA系列

## 1.概述

**LLaVA（Large Language-and-Vision Assistant）** 由威斯康星大学-Madison、微软等于 2023 年提出，是**开源多模态大模型（MLLM）**的代表：用 **CLIP ViT** 做视觉编码器、**简单 MLP** 做投影、**Vicuna（LLaMA 系）** 做语言模型，通过 **GPT-4 生成的多模态指令数据**做指令微调，首次以极简架构 + 低成本达到接近 GPT-4V 的多模态对话能力，开创了"视觉编码器 + 连接器 + LLM"的开源范式。

**论文**：Visual Instruction Tuning (Liu et al., 2023)

### 1.1 发展历程

| 时间 | 版本 | 核心改进 |
| --- | --- | --- |
| 2023.04 | LLaVA | CLIP + MLP + Vicuna，GPT-4 生成指令数据，两阶段训练 |
| 2023.10 | LLaVA-1.5 | MLP 改两层 GELU、336px 高分辨率、学术任务数据混合 |
| 2024.01 | LLaVA-NeXT | AnyRes 高分辨率、视频支持、更强数据 |
| 2024 | LLaVA-OneVision | 统一图像 / 视频 / 多图任务 |

## 2.LLaVA-1（2023）

### 2.1 架构

```
Image (224×224)
    │
CLIP ViT-L/14 (视觉编码器, 冻结)
    │
视觉特征 (256×1024)
    │
Linear Projection (一层线性, 可训练)   <- "language image projector"
    │
视觉 token (256×4096, 与 LLM 词向量同维)
    │
与指令文本 token 拼接
    │
Vicuna-13B (LLM, 训练时用 LoRA 微调)
    │
文本回复
```

三段式结构：**视觉编码器（CLIP ViT-L/14，冻结）+ 投影层（单层 Linear，可训练）+ LLM（Vicuna v0 7B/13B）**。

### 2.2 多模态指令数据：GPT-4 生成

- 人工写多模态指令数据成本高，LLaVA 的解法是**只用文本的 GPT-4**，把图像的 COCO 标注（bbox、类别）以文本形式输入 prompt，让 GPT-4 生成三种数据：

| 类型 | 输入 | 输出 | 数量 |
| --- | --- | --- | --- |
| 对话（Conversation） | 图像 + 角色 A 提问 | 多轮问答 | 58k |
| 详细描述（Detailed Description） | 图像 + 要求描述 | 长描述 | 23k |
| 复杂推理（Complex Reasoning） | 图像 + 推理问题 | 分步推理答案 | 77k |

- 共 158k 样本（含 58k 面向生成任务）；
- 该思路（用强 LLM 合成指令数据）成为后续 MLLM 数据构造的标准做法。

### 2.3 两阶段训练

| 阶段 | 数据 | 训练部分 | 目标 |
| --- | --- | --- | --- |
| 阶段一：特征对齐预训练 | 595k 图文对（CC3M 过滤的 caption 数据） | 只训练投影层 | 把视觉特征对齐到 LLM 词向量空间 |
| 阶段二：端到端指令微调 | 158k GPT-4 指令数据 | 投影层 + LLM（LoRA） | 学会按指令回答视觉问题 |

```
阶段一（特征对齐）:
  图像 -> 冻结 CLIP -> 冻结 LLM 前的视觉 token
                      + caption 文本
                      -> 只更新 MLP projector

阶段二（指令微调）:
  图像 -> 冻结 CLIP -> MLP projector（更新）
                      + GPT-4 指令对话
                      -> 更新 projector + LLM（LoRA）
```

- 阶段二也可只训 LoRA，视觉编码器全程冻结；
- 全流程在 8×A100 上一天内可完成，成本极低。

### 2.4 评测

- 提出 **LLaVA-Bench**：留出 30 张未见图像，用 GPT-4（文本）给模型输出打分（相对分数）；
- Science QA 多模态题目上达到 SOTA（超过 GPT-4 的 82.69% 达 92.53%，微调后）；
- 合成数据对未见指令的泛化良好，说明文本 GPT-4 生成的多模态指令数据有效。

### 2.5 输入输出格式

- 多模态指令模板：`USER: <image>\n<问题> ASSISTANT: <回答>`；
- 图像特征以 `<image>` 占位符插入，训练时替换为投影后的视觉 token 序列；
- 训练损失：只对回答部分 token 计算自回归交叉熵（prompt 部分不参与）。

## 3.LLaVA-1.5（2023）

**论文**：Improved Baselines with Visual Instruction Tuning (Liu et al., 2023)

用最少的改动大幅提升性能，是后续无数开源 MLLM 的默认基线。

### 3.1 关键改进

1. **投影层：单层 Linear -> 两层 MLP（GELU）**：扩大视觉-语言连接容量，几乎免费的显著提升；
2. **高分辨率输入：224px -> 336px**：CLIP-336px 编码器，改善 OCR / 细节类任务；
3. **学术任务数据混合**：加入 VQA、GQA、OCR、区域描述等学术数据集（回答格式化为短答案），显著提升相关基准；
4. **负样本 / 幻觉抑制数据**：加入"图中没有 xxx"类负样本，缓解物体幻觉；
5. 训练采用 LoRA 端到端（视觉编码器仍冻结），13B 模型用 1×A100 一天可训完。

### 3.2 性能

- 在 11 个基准上取得 SOTA（TextVQA、DocVQA、ScienceQA 等），如 TextVQA 58.2%、DocVQA 36.2%（13B）；
- 首个在部分基准上超过 Qwen-VL、InstructBLIP 的开源轻量模型。

## 4.LLaVA-NeXT（2024）

### 4.1 AnyRes 高分辨率策略

- 问题：ViT 位置编码固定，直接放大大图效果差；336px 对文档 / 图表仍不够；
- 解法：**把大图切成多个 336px 的网格子图 + 一个缩略全局图**，分别过 CLIP 编码后拼接：

```
     原始大图 (如 672×1344)
        │
   AnyRes 切分
   ┌────┬────┐
   │ 1  │ 2  │
   ├────┼────┤        +  全局缩略图 (336px)
   │ 3  │ 4  │
   └────┴────┘
        │
   每块独立过 CLIP ViT
        │
   拼接所有 patch token (可达 2880 个)
        │
   MLP projector -> LLM
```

- 分辨率提升至 672×672 到 3360×6720 挡位，token 数按需扩展；
- OCR、文档理解基准（DocVQA、ChartQA）大幅提升。

### 4.2 其他改进

- **数据升级**：GPT-4V 生成的更高质量指令数据、更多学术数据；
- **视频支持**：帧采样 + 时序 token 融合，支持视频对话（LLaVA-NeXT-Video）；
- 训练策略：先低分辨率对齐，再逐步 AnyRes 课程式提升分辨率。

## 5.同期工作对比

| 模型 | 视觉端 | 连接器 | LLM 端 | 特点 |
| --- | --- | --- | --- | --- |
| LLaVA | CLIP ViT-L（冻结） | MLP | Vicuna（LoRA 微调） | 极简 + 指令数据开创者 |
| MiniGPT-4 | EVA-CLIP ViT-g（冻结） | Q-Former + Linear | Vicuna（只训 LoRA） | BLIP-2 思路，对齐预训练 + 少量指令数据 |
| Qwen-VL | OpenCLIP ViT-bigG（冻结） | 单层 Linear（后加 cross-attn） | Qwen LLM（全参微调） | 多任务多分辨率、检测 grounding、中文强 |
| InternVL | InternViT-6B（可训练） | MLP | InternLM | 视觉端可训且规模巨大（6B） |
| BLIP-2 | EVA-CLIP（冻结） | Q-Former（三目标预训练） | OPT / FlanT5（冻结） | 轻量桥接、无指令微调 |

- 两条路线：**简单连接器 + 端到端指令微调**（LLaVA / Qwen-VL）vs **复杂连接器 + 冻结 LLM**（BLIP-2 / MiniGPT-4）；
- 实践证明：数据质量与规模比连接器结构更重要，简单 MLP + 充分微调即可很强。

## 6.训练数据构造

### 6.1 指令数据来源

1. **强 LLM 合成**（LLaVA 首创）：图像标注文本 + GPT-4 生成对话 / 描述 / 推理；
2. **学术数据格式化**：VQA / OCR / grounding 数据集转成"指令 + 短答案"格式；
3. **GPT-4V / 闭源模型合成**：直接输入图像生成高质量对话（LLaVA-NeXT）；
4. **人工标注 / 校验**：LLaVA 原始 158k 中含人工检查；高质量对话集常人工参与；
5. **负样本数据**：不存在物体的否定问答，抑制幻觉。

### 6.2 数据配比经验

- 特征对齐阶段用大规模 caption（595k），指令阶段用高质量混合数据；
- 短答案学术数据与长对话数据混合时需控制比例，否则长答案风格会被带偏。

### 6.3 指令数据的三种类型（LLaVA 原始设置）

| 类型 | 示例 | 作用 |
| --- | --- | --- |
| 对话 | "图里有什么？" -> 多轮问答 | 培养对话能力 |
| 详细描述 | "描述这张图" -> 长段描述 | 培养丰富表达 |
| 复杂推理 | "如果……会怎样？" -> 分步推理 | 培养推理能力 |
| 负样本 | "图里有 X 吗？"（无 X） -> "没有" | 抑制幻觉 |

## 7.面试常考问题

**Q1：LLaVA 的架构与训练流程？**

CLIP ViT-L（冻结）+ 单层 Linear projector + Vicuna（LoRA）。两阶段：先用 595k caption 只训 projector 做特征对齐，再用 158k GPT-4 指令数据端到端（projector + LLM）指令微调。

**Q2：projector 为什么用简单 MLP 而不是 Q-Former？**

1. 端到端指令微调时 LLM 可训，能自行适应视觉 token，无需复杂桥接；
2. MLP 不压缩信息（保留全部 576 个视觉 token），细粒度信息（OCR / grounding）不丢失；
3. Q-Former 压缩到 32 token 是为冻结 LLM 设计的瓶颈，信息损失大；
4. 实验证明（LLaVA-1.5）简单两层 MLP 已足够，结构越简单越利于扩展与稳定。

**Q3：LLaVA 的指令数据怎么来的？**

用纯文本 GPT-4：把 COCO 的类别 + bbox 标注写成文本 prompt，让 GPT-4 生成对话 / 详细描述 / 复杂推理三类多模态指令数据（158k）。

**Q4：LLaVA-1.5 相比 1.0 的改进？**

1. Linear -> 两层 GELU MLP；
2. 224px -> 336px；
3. 混入 VQA / OCR 等学术短答案数据；
4. 负样本抑制幻觉。

**Q5：AnyRes（LLaVA-NeXT）怎么处理高分辨率？**

把大图切成多个 336px 网格块 + 一张全局缩略图，分别过 CLIP 后拼接全部 token 输入 LLM。克服固定位置编码限制，OCR / 文档任务大幅提升。

**Q6：两阶段训练为什么第一阶段冻结 LLM 只训 projector？**

对齐阶段数据（caption）质量与风格不适合指令跟随，且只训 projector 可防止 LLM 在简单数据上被带偏 / 过拟合，先建立"视觉 token 到词向量空间"的粗映射。

**Q7：LLaVA 与 BLIP-2 路线的区别？**

| 维度 | LLaVA | BLIP-2 |
| --- | --- | --- |
| 连接器 | MLP | Q-Former（三目标预训练） |
| LLM | 可训（LoRA / 全参） | 冻结 |
| 视觉 token | 全保留 | 压缩为 32 |
| 训练目标 | 自回归 LM | ITC/ITM/ITG + LM |
| 适用 | 指令对话 | 零样本理解 + 生成 |

**Q8：MiniGPT-4 和 LLaVA 的异同？**

同为"冻结视觉端 + Vicuna"的开源 MLLM；MiniGPT-4 用 Q-Former + 先在图文对上对齐预训练再用少量（约 3.5k）高质量对话微调，LLaVA 直接大量指令数据端到端。

**Q9：LLaVA 怎么缓解幻觉？**

负样本指令数据（"图中没有 X 吗"）、POPE 类评测数据训练、后续工作用 RLHF / 操作反馈（如 LLaVA-RLHF）或对比解码。

**Q10：为什么视觉编码器可以一直冻结？**

CLIP 预训练已提供强大语义特征；冻结保持其泛化能力、降低显存与训练成本；InternVL 等工作证明解冻 + 更大视觉端（6B）还能再涨点，属于资源换性能。

**Q11：LLaVA 的训练成本为什么低？**

- 视觉端冻结，只训 projector + LoRA；
- 指令微调数据仅 158k 样本；
- 7B 模型 8×A100 一天、13B 单卡一天（1.5）即可复现，是社区快速跟进的关键。

**Q12：MLLM 推理时视觉 token 太长怎么办？**

AnyRes 大图可产生数千 token，常用压缩手段：相邻 patch 池化、pixel shuffle 合并、query 聚合（Perceiver / Q-Former 式），以及仅对高分块保留更多 token 的非均匀策略。

## 8.总结

- **LLaVA**：CLIP + MLP + Vicuna 极简三段式，GPT-4 合成指令数据 + 两阶段训练，定义开源 MLLM 范式；
- **LLaVA-1.5**：两层 MLP + 336px + 学术数据混合，成为最强开源基线；
- **LLaVA-NeXT**：AnyRes 高分辨率 + 视频，扩展到文档 / 图表 / 视频场景；
- **同期路线**：MiniGPT-4（Q-Former）、Qwen-VL（grounding + 中文）、InternVL（6B 可训视觉端）各有侧重；
- 核心结论：**数据 > 结构**，简单连接器 + 高质量指令微调即可达到复杂桥接的效果；
- 评测：LLaVA-Bench（GPT-4 打分）成为开放式多模态对话的常用参考基准；
- LLaVA 生态（LLaVA-OneVision 等）仍是多模态研究与落地的重要基线。
