# 5.注意力机制

## 1.概述

**注意力机制（Attention Mechanism）** 让网络能**动态地聚焦于重要区域**，是现代深度网络的核心组件。在 ViT 之前，CV 中的注意力主要分为：

1. **通道注意力**（SENet、ECA）：关注"哪些通道更重要"；
2. **空间注意力**（CBAM、SAN）：关注"哪些位置更重要"；
3. **混合注意力**（CBAM、BAM）：通道 + 空间；
4. **自注意力**（Non-local、ViT）：像素间全局关系。

## 2.SENet（Squeeze-and-Excitation, 2017）

**论文**：Squeeze-and-Excitation Networks (Hu et al., Momenta)

**思想**：学习每个通道的权重，"重要通道加权、不重要的抑制"。

### 2.1 SE 模块

```
input X (C×H×W)
  │
  ├─ Squeeze: GAP ────────────────► s (C×1×1)
  │                                  │
  │  Excitation:                     │
  │  FC (C→C/r) → ReLU → FC (C/r→C) │
  │  → Sigmoid                       │
  │                                  ▼
  └─────────────────────── × ──── out (C×H×W)
```

**步骤**：

1. **Squeeze**：GAP 把每个通道 $H \times W$ 压成 1 个标量 -> $s \in \mathbb{R}^C$；
2. **Excitation**：两层 FC（带 bottleneck，缩放比 $r=16$）+ ReLU + Sigmoid 得到通道权重 $w \in \mathbb{R}^C$；
3. **Reweighting**：原 feature map 通道维乘 $w$。

### 2.2 参数量

SE 模块参数：$2 \cdot C^2 / r$，相对卷积层可忽略。

### 2.3 效果

- 加在 ResNet-50 上，参数量增加约 10%，ImageNet top-1 提升 1.4%；
- ImageNet 2017 冠军；
- 现已成为各种 backbone 的标配组件（MobileNetV3、EfficientNet）。

### 2.4 缺点

- FC 层引入额外参数和计算；
- 仅建模通道注意力，无空间注意力；
- GAP 会丢失空间信息。

## 3.ECA（Efficient Channel Attention, 2020）

**论文**：ECA-Net: Efficient Channel Attention for Deep Convolutional Neural Networks

**思想**：**避免降维**，用 1D 卷积代替 FC 实现局部通道交互。

**做法**：

1. GAP 后得到 $s \in \mathbb{R}^C$；
2. 不做 FC 降维，直接对 $s$ 做 **1D 卷积**（核大小 $k$ 自适应）：
   $$ k = \left| \frac{\log_2 C + b}{\gamma} \right|_{odd} $$
3. Sigmoid 得到权重。

**优势**：

- **无降维**：保留全部通道信息；
- **参数极少**：只有 $k$ 个参数；
- 性能与 SE 相当或更优。

## 4.CBAM（Convolutional Block Attention Module, 2018）

**论文**：CBAM: Convolutional Block Attention Module (Woo et al., DGIST)

**思想**：**通道 + 空间** 串联注意力。

### 4.1 结构

```
input X (C×H×W)
  │
  ├─ Channel Attention:
  │   GAP + GMP → MLP → Sigmoid → 通道权重
  │   X × 通道权重 = X'
  │
  ├─ Spatial Attention:
  │   AvgPool + MaxPool along C → concat → 7×7 conv → Sigmoid → 空间权重
  │   X' × 空间权重 = X''
  │
  └─ X''
```

### 4.2 通道注意力

$$
M_c(F) = \sigma( \text{MLP}(\text{GAP}(F)) + \text{MLP}(\text{GMP}(F)) )
$$

**对比 SE**：CBAM 同时用 GAP 和 GMP，比 SE 仅用 GAP 信息更全。

### 4.3 空间注意力

1. 沿通道维做 AvgPool 和 MaxPool -> 2 个 $H \times W \times 1$ 的图；
2. concat -> $H \times W \times 2$；
3. 7×7 卷积降为 $H \times W \times 1$；
4. Sigmoid 得到空间权重。

**作用**：告诉网络"图像中哪些位置重要"。

### 4.4 效果

- 加在 ResNet、MobileNetV2 上均有 1~2% 提升；
- 检测、分割任务也有效。

## 5.BAM（Bottleneck Attention Module, 2018）

**思想**：通道 + 空间**并联**注意力（CBAM 是串联）。

```
       ┌─── Channel Branch ────┐
input ─┤                        ├── + ── sigmoid ── × ── out
       └─── Spatial Branch ────┘
```

## 6.Non-local Neural Network（2018）

**论文**：Non-local Neural Networks (Wang et al., CMU & Facebook)

**思想**：在 CNN 中引入**自注意力**，建模**全局像素间关系**。

$$
y_i = \frac{1}{C(x)} \sum_{\forall j} f(x_i, x_j) g(x_j)
$$

其中 $f$ 是相似度函数（如点积、Gaussian）、$g$ 是值函数（1×1 卷积），$C(x)$ 是归一化因子。

**对应到 Transformer**：

- $f$ = QK^T；
- $g$ = V；
- Non-local = 单头自注意力，但**位置无关**（无位置编码）。

**应用**：视频理解、目标检测、分割。计算复杂度 $O(H^2 W^2)$，对大特征图不友好。

## 7.GCNet（Global Context, 2019）

**思想**：发现 Non-local 学到的注意力图**几乎全图相同**，简化为**全局上下文模块**：

$$
F'_i = F_i + W_{v2} \cdot \text{ReLU}(W_{v1} \cdot \sum_j \text{softmax}(W_k F_j))
$$

用一个全局上下文加到每个位置，参数少、计算快、效果与 Non-local 相当。

## 8.SAN（Self-Attention 之外）

**Self-Attention** 在 CNN 中的几种形式：

- **Non-local**：单头，无位置编码；
- **GCNet**：简化版，全局共享；
- **AA (Stand-Alone Self-Attention)**：完全用自注意力替代卷积；
- **SASA (Sanity-checking)**：纯自注意力 backbone；
- **Axial-DeepLab**：轴向注意力，沿 H、W 分别做，降低复杂度。

## 9.CA（Coordinate Attention, 2021）

**论文**：Coordinate Attention for Efficient Mobile Network Design (Hou et al., 深度音乐)

**思想**：**编码位置信息**进通道注意力（SE/CBAM 丢失位置信息）。

**做法**：

1. 沿 H 方向 GAP（生成 $1 \times W \times C$）；
2. 沿 W 方向 GAP（生成 $H \times 1 \times C$）；
3. 各自做 1×1 卷积 + ReLU；
4. 拼接为两个方向的 attention。

**优点**：同时建模通道 + 位置（水平、垂直），适合检测分割任务。

## 10.SKNet（Selective Kernel, 2019）

**论文**：SKNet: Selective Kernel Networks (Li et al., 旷视)

**思想**：**多尺度卷积核 + 软选择**。让网络为每个目标动态选择不同感受野。

**结构**：

1. 两个不同核大小的卷积分支（3×3 和 5×5）并行；
2. Add -> GAP -> FC -> Softmax -> 得到两个分支的权重；
3. 加权求和。

## 11.各注意力模块对比

| 模块 | 类型 | 计算开销 | 适用场景 | 优点 |
| --- | --- | --- | --- | --- |
| SENet | 通道 | 极小 | 通用 | 简单有效，已成标配 |
| ECA | 通道 | 极小 | 通用 | SE 的无降维改进 |
| CBAM | 通道+空间 | 小 | 通用 | 综合考虑通道和位置 |
| BAM | 通道+空间 | 小 | 通用 | 并联结构 |
| Non-local | 全局自注意力 | 大（$O(N^2)$） | 视频、检测 | 建模长距离依赖 |
| GCNet | 简化全局 | 小 | 检测 | Non-local 的简化 |
| CA | 通道+位置 | 小 | 检测/分割 | 编码位置信息 |
| SKNet | 多尺度选择 | 中 | 通用 | 动态感受野 |

## 12.代码示例：SE 模块

```python
import torch
import torch.nn as nn

class SEBlock(nn.Module):
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.avg_pool = nn.AdaptiveAvgPool2d(1)
        self.fc = nn.Sequential(
            nn.Linear(channels, channels // reduction, bias=False),
            nn.ReLU(inplace=True),
            nn.Linear(channels // reduction, channels, bias=False),
            nn.Sigmoid()
        )

    def forward(self, x):
        b, c, _, _ = x.size()
        y = self.avg_pool(x).view(b, c)
        y = self.fc(y).view(b, c, 1, 1)
        return x * y.expand_as(x)
```

## 13.面试常考问题

**Q1：SENet 的工作原理？**

- **Squeeze**：GAP 把每个通道 $H \times W$ 压成 1 个标量；
- **Excitation**：FC-ReLU-FC-Sigmoid 得到通道权重；
- **Reweighting**：原 feature map 通道维乘以权重。

让网络学习"哪些通道重要"。

**Q2：SE 为什么用 FC 降维再升维？**

1. 减少参数（瓶颈结构）；
2. 增加非线性，提升表达能力；
3. 让通道间信息交互。

**Q3：ECA 为什么比 SE 好？**

- ECA 不做降维，避免信息损失；
- 用 1D 卷积让每个通道只与相邻通道交互，更高效；
- 参数极少（只有 $k$ 个），效果与 SE 相当或更优。

**Q4：CBAM 的空间注意力是怎么做的？**

沿通道维做 AvgPool 和 MaxPool 得到 2 个 $H \times W$ 图，concat 后 7×7 卷积降为 1 通道，Sigmoid 得到空间权重。

**Q5：Non-local 与 Transformer 自注意力有何区别？**

- Non-local 是单头、无位置编码、计算量 $O(N^2)$；
- Transformer 自注意力多头、有位置编码、有 FFN 和残差；
- Non-local 通常作为 CNN 的插件，Transformer 是端到端架构。

**Q6：注意力机制是万能的吗？**

不是。注意力也有局限：

1. **计算开销大**：自注意力 $O(N^2)$；
2. **数据需求高**：注意力模型通常需要更多数据；
3. **可能冗余**：研究发现部分注意力图几乎是均匀分布，作用有限；
4. **小数据集上不一定有提升**。

**Q7：通道注意力和空间注意力的本质区别？**

- **通道注意力**：在"什么特征重要"维度做加权（每通道 1 个权重）；
- **空间注意力**：在"哪里重要"维度做加权（每位置 1 个权重）；
- 实际中常串联使用，先通道后空间。

## 14.总结

- **SENet** 开启通道注意力时代，已成为 backbone 标配；
- **ECA** 是 SE 的轻量改进；
- **CBAM** 综合通道 + 空间注意力；
- **Non-local** 把自注意力引入 CNN，是 ViT 的前身；
- **CA** 编码位置信息，适合检测分割；
- 注意力机制让网络"动态关注重要区域"，是从 CNN 走向 ViT 的关键过渡。
