# 4.轻量化网络

## 1.概述

移动端、嵌入式设备算力有限，**模型大小、推理速度、能耗**成为关键指标。**轻量化网络**通过**结构设计、参数压缩、硬件感知**等手段在保证精度的同时大幅降低计算量，是工业部署的核心技术。

**核心指标**：

- **FLOPs**（浮点运算次数）：衡量计算量，常用 GFLOPs（$10^9$）；
- **Params**（参数量）：模型大小，常用 M（百万）；
- **Latency**（推理延迟）：实际部署指标，受硬件影响大；
- **MACs / MACCs**：乘加操作数，约等于 2×FLOPs；
- **内存访问开销（MAW）**：影响实际速度，与参数量不一定成正比。

## 2.SqueezeNet（2016）

**论文**：SqueezeNet: AlexNet-level accuracy with 50x fewer parameters

**核心思想**：用 **Fire Module** 替代大卷积核。

**Fire Module**：

1. **Squeeze**：1×1 卷积降维（输出通道 $s_{1×1}$，远小于输入通道）；
2. **Expand**：1×1 和 3×3 卷积并行升维（输出通道 $e_{1×1} + e_{3×3}$）；
3. **Concat**：在通道维拼接。

**结果**：达到 AlexNet 精度，参数量减少 50 倍（主要是替代了 FC 层）。

## 3.MobileNet 系列

### 3.1 MobileNetV1（2017）

**论文**：MobileNets: Efficient Convolutional Neural Networks for Mobile Vision Applications (Howard et al., Google)

**核心思想**：**深度可分离卷积（Depthwise Separable Convolution）** 替代标准卷积。

**分解**：

1. **Depthwise**：每个输入通道用 1 个卷积核单独卷积 -> 通道数不变；
2. **Pointwise**：1×1 卷积做通道融合。

**参数量对比**（输入 $C_{in}$, 输出 $C_{out}$, 核 $k \times k$）：

- 标准卷积：$k \cdot k \cdot C_{in} \cdot C_{out}$
- 深度可分离：$k \cdot k \cdot C_{in} + 1 \cdot 1 \cdot C_{in} \cdot C_{out}$

**比例**：

$$
\frac{k^2 C_{in} + C_{in} C_{out}}{k^2 C_{in} C_{out}} = \frac{1}{C_{out}} + \frac{1}{k^2}
$$

3×3 卷积时约为 **1/8 ~ 1/9**。

**宽度乘子 $\alpha$ 和分辨率乘子 $\rho$**：

- $\alpha \in \{1, 0.75, 0.5, 0.25\}$ 控制通道数；
- $\rho \in \{1, 0.875, 0.75, 0.625\}$ 控制输入分辨率；
- 提供精度-速度权衡。

### 3.2 MobileNetV2（2018）

**论文**：MobileNetV2: Inverted Residuals and Linear Bottlenecks (Sandler et al., Google)

**核心创新**：

1. **倒残差（Inverted Residual）**：与 ResNet 相反，**先升维再降维**；
2. **线性瓶颈（Linear Bottleneck）**：最后一个 1×1 卷积**不用激活函数**。

**Inverted Residual Block**：

```
        ┌── 1×1 升维 (t×), BN, ReLU6 ──┐
input ──┤                                ├── + ── out
        │  3×3 DW conv, BN, ReLU6        │
        │  1×1 降维 (proj), BN (线性!) ──┘
        └────── identity (短接) ─────────┘
```

其中 $t$ 是扩展因子（典型 6），输入输出通道数都小，中间高维。

**为什么"倒残差"？**

- ResNet Bottleneck：宽 -> 窄 -> 宽，shortcut 在宽处；
- MobileNetV2：窄 -> 宽 -> 窄，shortcut 在窄处。

**为什么用线性瓶颈？**

- 低维特征经过 ReLU 会丢失信息（负半轴全置零）；
- 实验证明：最后 1×1 不加 ReLU6 性能更好。

**为什么 shortcut 在低维？**

- 低维特征是输入输出的"瓶颈"，加入 shortcut 让信息直接传递；
- 减少内存访问。

### 3.3 MobileNetV3（2019）

**论文**：Searching for MobileNetV3 (Howard et al., Google)

**核心创新**：

1. **硬件感知 NAS**：用 NetAdapt 算法搜索每层最佳通道数；
2. **SE 模块**：在 bottleneck 中加入通道注意力；
3. **h-swish 激活**：swish 的硬近似，无需浮点运算；
4. **重新设计耗时层**：减少早期层通道数、调整网络结构。

**h-swish**：

$$
\text{h-swish}(x) = x \cdot \frac{\text{ReLU6}(x + 3)}{6}
$$

**性能**：比 V2 在 ImageNet 上提升约 1.7%，同时延迟降低 20%。

## 4.ShuffleNet 系列

### 4.1 ShuffleNetV1（2017）

**核心思想**：**分组卷积 + 通道重排（Channel Shuffle）**。

**问题**：分组卷积使信息只能在组内流动，组间无信息交流。

**Channel Shuffle 操作**：

1. 把通道 reshape 为 (g, n)；
2. 转置为 (n, g)；
3. flatten 回 1D。

使分组卷积后通道信息得以跨组流动。

**ShuffleNet Unit**：

```
input ── 1×1 GConv → BN → ReLU
     ── 3×3 DW Conv → BN
     ── 1×1 GConv → BN → ReLU ── + ── out
       (channel shuffle between blocks)
```

### 4.2 ShuffleNetV2（2018）

**论文**：ShuffleNet V2: Practical Guidelines for Efficient CNN Architecture Design (Ma et al., 旷视)

**核心贡献**：基于**4 条硬件实验指导原则**重新设计。

**4 条原则**：

1. **输入输出通道数相等时 MAC 最小**；
2. **过度使用分组卷积会增加 MAC**；
3. **网络碎片化（多分支）会降低并行度**；
4. **元素级操作（ReLU、Add）不可忽视**。

**ShuffleNetV2 Unit**：

- 取消分组卷积，改用通道分割（channel split）；
- 一半直接 shortcut，另一半做 3 个卷积；
- concat 替代 add，避免 element-wise 加法；
- concat 后做 channel shuffle。

## 5.EfficientNet（2019）

**核心思想**：**复合缩放** —— 同时缩放深度 $\alpha^\phi$、宽度 $\beta^\phi$、分辨率 $\gamma^\phi$，约束 $\alpha \beta^2 \gamma^2 \approx 2$。

详见 [2.经典网络](../2.经典网络/2.经典网络.md)。

## 6.GhostNet（2020）

**论文**：GhostNet: More Features from Cheap Operations (Han et al., 华为)

**观察**：CNN feature map 中存在大量**冗余**（相似特征图）。

**思路**：先做少量"本征"卷积，再用**廉价线性操作**生成"幽灵"特征图，拼接为完整输出。

$$
Y = [Y_{intrinsic}, Y_{ghost}]
$$

**优点**：在相同参数量下精度更高。

## 7.RepVGG（2021）

**论文**：RepVGG: Making VGG-style ConvNets Great Again (Ding et al., 旷视)

**核心思想**：**训练时多分支，推理时等价转换为单分支**。

**训练时**：

$$
y = \text{conv}_{3×3}(x) + \text{conv}_{1×1}(x) + \text{BN}(x)
$$

**推理时**：通过**结构重参数化**，把 3 个分支合并为一个 3×3 卷积：

- 1×1 卷积可视为 padding 后的 3×3 卷积；
- BN 可融合进卷积权重；
- 恒等 BN 也可视为 3×3 卷积。

**优势**：训练有多分支的精度优势（类似 ResNet），推理时是 VGG 式简单结构，**推理极快**。

## 9.模型加速技术

### 9.1 算子优化

- **im2col + GEMM**：把卷积转为矩阵乘法，利用 BLAS 高度优化；
- **Winograd**：减少乘法次数（小核 3×3 时约 2.25 倍加速）；
- **FFT 卷积**：大核时有效；
- **Depthwise 卷积优化**：避免 im2col，直接滑动窗口。

### 9.2 张量化、低比特

- FP16 推理：速度翻倍，几乎无精度损失；
- INT8 量化：4 倍加速，需要校准；
- 混合精度：层敏感部分保留 FP16。

### 9.3 网络结构搜索（NAS）

- NASNet、EfficientNet 用 NAS 搜索最优结构；
- NetAdapt 在硬件上感知延迟搜索。

## 10.面试常考问题

**Q1：深度可分离卷积为什么省参数？**

把标准卷积 $k \times k \times C_{in} \times C_{out}$ 拆为 depthwise（$k \times k \times C_{in}$，做空间卷积） + pointwise（$C_{in} \times C_{out}$，做通道融合），3×3 时约为 1/9。

**Q2：MobileNetV2 的"倒残差"和 ResNet 的残差有何区别？**

- ResNet：宽 -> 窄 -> 宽（瓶颈降维），shortcut 在宽处；
- MobileNetV2：窄 -> 宽 -> 窄（瓶颈升维），shortcut 在窄处；
- MobileNetV2 这样设计是为了让 DW conv 在高维空间做（更有效），输入输出保持低维（省内存）。

**Q3：为什么 MobileNetV2 最后的 1×1 卷积不用激活？**

低维特征经过 ReLU 会丢失大量信息（负半轴全置零）。实验证明加 ReLU6 会掉 2~3% 精度。

**Q4：ShuffleNet 的 channel shuffle 解决什么问题？**

分组卷积使信息只能在组内流动，跨组无交流。channel shuffle 把通道重新排列，使下一层分组卷积能接收到来自不同组的通道，实现信息跨组流动。

**Q5：ShuffleNetV2 的 4 条原则是什么？**

1. 输入输出通道数相等时 MAC 最小；
2. 过度分组增加 MAC；
3. 网络碎片化降低并行度；
4. element-wise 操作不可忽视。

**Q6：RepVGG 训练时多分支，推理时单分支是怎么做的？**

**重参数化**：

- 1×1 卷积 padding 成 3×3；
- BN 融合到卷积：$W' = W \cdot \gamma / \sqrt{\sigma^2 + \epsilon}, b' = \beta - \mu \cdot \gamma / \sqrt{\sigma^2 + \epsilon}$；
- 恒等映射视为特殊 1×1 卷积（对角矩阵）；
- 3 个 3×3 卷积核 + bias 相加得到最终单个 3×3 卷积。

**Q7：FLOPs 低就一定快吗？**

不一定。实际速度受**内存访问开销、并行度、硬件特性**影响。例如：

- DW 卷积 FLOPs 极低但实际不快（MAW 高、难以用 GEMM 优化）；
- 多分支网络 FLOPs 低但内存访问多，速度慢；
- 应以**实际硬件 latency** 为最终指标。

**Q8：移动端一般用什么网络？**

- 高精度需求：MobileNetV3-Large、EfficientNet-Lite；
- 极致轻量：MobileNetV3-Small、ShuffleNetV2；
- 推理友好：RepVGG（多分支已合并）；
- 通常配合 INT8 量化使用。

## 11.总结

- **深度可分离卷积**是 MobileNet 系列、ShuffleNet 的核心；
- **倒残差 + 线性瓶颈**是 MobileNetV2 的关键设计；
- **硬件感知原则**让 ShuffleNetV2 在实际设备上更快；
- **NAS + SE + h-swish** 让 MobileNetV3 达到精度速度双优；
- **重参数化**让 RepVGG 训练时享多分支精度、推理时享单分支速度；
- **FLOPs 不等于速度**，必须以硬件实测为准。
