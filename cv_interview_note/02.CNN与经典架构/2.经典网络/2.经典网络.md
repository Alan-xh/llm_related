# 2.经典网络

## 1.概述

从 LeNet（1998）到 ConvNeXt（2022），CNN 架构演进经历了 **"深度化、模块化、轻量化、Transformer 化、回归化"** 五个阶段。理解经典网络的演进逻辑，有助于在新的任务上选择合适的 backbone 或设计新结构。

## 2.LeNet-5（1998）

**论文**：Gradient-Based Learning Applied to Document Recognition (LeCun et al.)

**结构**：`Conv -> Pool -> Conv -> Pool -> FC -> FC -> Output`

| 层 | 类型 | 输出大小 | 参数量 |
| --- | --- | --- | --- |
| C1 | Conv 5×5, 6 | 28×28×6 | 156 |
| S2 | AvgPool 2×2 | 14×14×6 | 12 |
| C3 | Conv 5×5, 16 | 10×10×16 | 1,516 |
| S4 | AvgPool 2×2 | 5×5×16 | 32 |
| C5 | Conv 5×5, 120 | 1×1×120 | 48,120 |
| F6 | FC 84 | 84 | 10,164 |
| Output | FC 10 | 10 | 840 |

**贡献**：

1. 首次提出卷积 + 池化 + 全连接的现代 CNN 范式；
2. 用于手写数字识别（MNIST），银行支票识别实用化；
3. 用 **tanh 激活**（现代用 ReLU）。

**局限**：参数量小、容量低、训练数据少，无法处理复杂自然图像。

## 3.AlexNet（2012）

**论文**：ImageNet Classification with Deep Convolutional Neural Networks (Krizhevsky et al.)

**背景**：ImageNet 2012 比赛冠军，top-5 错误率 15.3%，远超第二名（26.2%），**引爆深度学习浪潮**。

**结构**：8 层（5 卷积 + 3 全连接），输入 224×224×3。

```
Conv1: 11×11, 96, stride=4  -> 55×55×96
MaxPool: 3×3, stride=2      -> 27×27×96
Conv2: 5×5, 256             -> 27×27×256
MaxPool: 3×3, stride=2      -> 13×13×256
Conv3: 3×3, 384             -> 13×13×384
Conv4: 3×3, 384             -> 13×13×384
Conv5: 3×3, 256             -> 13×13×256
MaxPool: 3×3, stride=2      -> 6×6×256
FC6: 4096
FC7: 4096
FC8: 1000
```

**关键创新**：

1. **ReLU 激活函数**：替代 tanh，收敛速度提升约 6 倍；
2. **Dropout**：FC 层 0.5 dropout 防过拟合；
3. **数据增强**：随机裁剪、水平翻转、PCA 颜色扰动；
4. **GPU 训练**：双 GTX 580 训练 5~6 天；
5. **局部响应归一化（LRN）**：后续证明作用有限，已被 BN 取代；
6. **重叠池化**：pool size 3, stride 2，比传统 non-overlap 略好。

**参数量**：约 60M，绝大部分集中在 FC 层。

## 4.VGG（2014）

**论文**：Very Deep Convolutional Networks for Large-Scale Image Recognition (Simonyan & Zisserman, Oxford)

**核心思想**：**用小卷积核（3×3）堆叠替代大卷积核**。

**关键观察**：两个 3×3 卷积堆叠 = 一个 5×5 卷积的感受野，但参数更少、非线性更强：

- 5×5 卷积参数量：$25 C^2$；
- 2 个 3×3 堆叠参数量：$2 \times 9 C^2 = 18 C^2$，减少 28%；
- 非线性层数翻倍。

**结构**：VGG-16 / VGG-19，5 段卷积 + 3 FC。

```
输入 224×224×3
[Conv3-64 ×2] -> Pool -> 112×112×64
[Conv3-128 ×2] -> Pool -> 56×56×128
[Conv3-256 ×3] -> Pool -> 28×28×256
[Conv3-512 ×3] -> Pool -> 14×14×512
[Conv3-512 ×3] -> Pool -> 7×7×512
FC 4096 -> FC 4096 -> FC 1000
```

**贡献**：

1. 证明**深度**比核大小更重要；
2. 简洁统一的结构，迁移学习效果极好；
3. 3×3 卷积成为现代网络默认选择。

**缺点**：

1. **参数量大**（138M），主要在 FC 层；
2. **计算量大**，推理慢；
3. 内存占用高。

## 5.GoogLeNet / Inception（2014）

**论文**：Going Deeper with Convolutions (Szegedy et al., Google)

**核心思想**：**Inception 模块** + **1×1 卷积降维** + **全局平均池化**。

### 5.1 Inception v1 模块

并行使用不同尺寸卷积（1×1, 3×3, 5×5）和池化，最后在通道维拼接：

```
        ┌── 1×1 conv ─────────────────┐
input ──┼── 1×1 conv → 3×3 conv ──────┤
        ├── 1×1 conv → 5×5 conv ──────┼── concat
        └── 3×3 max pool → 1×1 conv ──┘
```

**1×1 卷积的作用**：先降维再做 3×3/5×5 卷积，大幅减少参数量。例如输入 256 通道做 5×5 卷积输出 64 通道：

- 直接：$5 \times 5 \times 256 \times 64 = 409,600$；
- 1×1 降维到 32 再做：$1 \times 1 \times 256 \times 32 + 5 \times 5 \times 32 \times 64 = 8,192 + 51,200 = 59,392$，**减少 7 倍**。

### 5.2 GoogLeNet 结构

- 22 层，参数量仅 7M（远少于 VGG 138M）；
- 末尾用 **GAP** 替代 FC，大幅降参；
- 中间层有 **辅助分类器**：缓解梯度消失，提供正则。

### 5.3 Inception 后续演进

| 版本 | 改进 |
| --- | --- |
| v2 | 用两个 3×3 替代 5×5；引入 BN |
| v3 | 因子化 7×7 → 1×7 + 7×1；label smoothing |
| v4 | 与 ResNet 思想结合 |
| Inception-ResNet | 引入残差连接 |

**贡献**：开创了**多尺度并行卷积**和**1×1 卷积降维**两个重要技巧。

## 6.ResNet（2015）—— 详见 [3.残差网络](../3.残差网络/3.残差网络.md)

**核心思想**：**残差连接（skip connection）** 解决深度网络退化问题。

- ResNet-152 比 VGG-19 深 8 倍，但参数量更少、训练更快；
- 错误率 3.57%，**首次超越人类**（人类 5.1%）；
- 是现代 CV 的标准 backbone。

## 7.DenseNet（2017）

**论文**：Densely Connected Convolutional Networks (Huang et al., Cornell)

**核心思想**：**稠密连接**——每层的输入是前面所有层输出的拼接。

$$
x_l = H_l([x_0, x_1, \dots, x_{l-1}])
$$

**Dense Block** 内每一层都接收前面所有层的 feature map 拼接作为输入。

**优点**：

1. **特征重用**：参数高效；
2. **梯度反传通畅**：缓解梯度消失；
3. **隐式深度监督**。

**缺点**：内存消耗大（需保存中间 feature map），推理时优化较复杂。

## 8.SENet（2017）

**论文**：Squeeze-and-Excitation Networks (Hu et al., Momenta)

**核心思想**：**通道注意力** —— 让网络学习每个通道的重要性。

**SE 模块**：

1. **Squeeze**：GAP 把每个通道压成 1 个数 -> $1 \times 1 \times C$；
2. **Excitation**：FC-ReLU-FC-Sigmoid 得到通道权重 -> $1 \times 1 \times C$；
3. **Reweighting**：原 feature map 通道维乘以权重。

**贡献**：以极小参数代价提升各类 backbone 性能，是**注意力机制在 CV 的早期代表作**。

## 9.MobileNet 系列

详见 [4.轻量化网络](../4.轻量化网络/4.轻量化网络.md)。

- v1：深度可分离卷积；
- v2：倒残差 + 线性瓶颈；
- v3：硬件感知 NAS + SE + h-swish。

## 10.EfficientNet（2019）

**论文**：EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks (Tan & Le, Google)

**核心思想**：**复合缩放（Compound Scaling）** —— 同时缩放深度、宽度、分辨率。

$$
\text{depth} = \alpha^\phi, \quad \text{width} = \beta^\phi, \quad \text{resolution} = \gamma^\phi
$$

约束 $\alpha \cdot \beta^2 \cdot \gamma^2 \approx 2$（FLOPs 翻倍），$\phi$ 是缩放系数。

- B0 到 B7 共 8 个版本；
- 由 NAS 搜索基础结构 + 复合缩放；
- 一度是 ImageNet 上的 SOTA。

## 11.ConvNeXt（2022）

**论文**：A ConvNet for the 2020s (Liu et al., Meta)

**核心思想**：用 ViT 的设计哲学**反向改造 ResNet**，证明纯 CNN 仍能与 ViT 抗衡。

**改造步骤**：

1. **训练策略对齐**：用 ViT 的数据增强（Mixup、CutMix、RandAugment）和训练时长（300 epochs）；
2. **宏观结构**：阶段比例从 (3,4,6,3) 改为 (3,3,9,3) 仿 Swin；
3. **Patchify**：4×4 stride=4 卷积替代 stem；
4. **Inverted Bottleneck**：类似 MobileNetV2，反向残差；
5. **大核 7×7**：替代 3×3，depthwise conv；
6. **微观改进**：GELU 替换 ReLU、LN 替换 BN、减少激活与归一层使用频率。

**结论**：纯卷积网络经过精心设计可与 Swin Transformer 性能持平，且推理更高效。

| 网络 | 年份 | 核心创新 | 参数量 | ImageNet top-5 |

| LeNet-5 | 1998 | 卷积+池化范式 | 60K | MNIST 99.2% |
| AlexNet | 2012 | ReLU + Dropout + GPU | 60M | 15.3% |
| VGG | 2014 | 小卷积核堆叠 | 138M | 7.3% |
| GoogLeNet | 2014 | Inception + 1×1 + GAP | 7M | 6.7% |

| DenseNet | 2017 | 稠密连接 | 8M (161) | - |

## 13.面试常考问题

**Q1：为什么用小卷积核（3×3）替代大卷积核？**

1. 参数更少：2 个 3×3 = 18C² vs 1 个 5×5 = 25C²；
2. 非线性更强：2 个 ReLU 比 1 个更深；
3. 感受野相同：2 个 3×3 堆叠感受野 = 1 个 5×5。

**Q2：1×1 卷积有什么用？**

降维、升维、跨通道融合、增加非线性、降参。Inception 中先降维再卷积大幅减少参数。

**Q3：ResNet 之前为什么网络不能很深？**

1. 梯度消失/爆炸（BN 缓解）；
2. **退化问题**：深层网络反而比浅层差，并非过拟合，是优化困难。ResNet 用残差连接解决。

**Q4：为什么 GoogLeNet 用 GAP 替代 FC？**

- FC 层参数量巨大（VGG FC 占 90%+ 参数）；
- GAP 无参数、保留空间信息、抗过拟合；
- 适合高分辨率 feature map。

**Q5：VGG 参数量为什么这么大？**

FC6 输入 7×7×512 = 25088，输出 4096 -> 1.02 亿参数；FC7 + FC8 又有 ~1700 万 + 400 万。FC 层占总参数 90% 以上。

**Q6：MobileNet 用深度可分离卷积为什么省参数？**

详见 [4.轻量化网络](../4.轻量化网络/4.轻量化网络.md)。

**Q7：ConvNeXt 的意义是什么？**

证明纯 CNN 经过精心设计也能达到 ViT 同等性能，纠正了"Transformer 必然胜过 CNN"的偏见；同时提供**部署更友好**的方案（推理更高效、量化更稳定）。

## 14.总结

- **LeNet** 奠基；**AlexNet** 引爆；**VGG** 深化；**GoogLeNet** 多尺度并行；**ResNet** 残差连接；**DenseNet** 稠密连接；**SENet** 通道注意力；**MobileNet/EfficientNet** 轻量高效；**ConvNeXt** 卷积回归。
- 演进逻辑：**更深、更宽、更精简、更注意力化、更数据驱动**；
- 理解这些经典网络的设计动机，能在新任务中灵活组合各种技巧。
