# 3.残差网络

## 1.概述

**ResNet（Residual Network）** 由何恺明等人在 2015 年提出，通过**残差连接（skip connection / shortcut）** 解决了深层网络的**退化问题（degradation problem）**。ResNet 让训练 100+ 层的网络成为可能，是现代深度学习最重要的架构创新之一，至今仍是 CV 的标准 backbone。

**论文**：Deep Residual Learning for Image Recognition (He et al., 2015)

## 2.背景：退化问题

### 2.1 现象

实验发现：单纯堆叠层数，网络加深后**训练误差反而上升**（不是过拟合，因为训练误差也升高）：

- 56 层网络在 CIFAR-10 上比 20 层网络训练误差和测试误差都更高；
- 这种现象**不是梯度消失**（BN 已缓解），而是优化困难。

### 2.2 直觉解释

理论上浅层网络是深层网络的特例（深层网络只需把多出的层学成恒等映射），所以深层网络的解空间包含浅层网络。但实际优化中，**恒等映射对深层网络来说很难学**。

### 2.3 解决思路

让网络学习**残差** $F(x) = H(x) - x$，而不是直接学 $H(x)$。最终输出：

$$
H(x) = F(x) + x
$$

- 若某层是冗余的，网络只需把 $F(x) \to 0$，输出就退化为 $x$（恒等映射），**学 0 比学恒等容易得多**；
- 残差连接提供"信息高速公路"，梯度可直接反传到任意浅层。

## 3.ResNet 结构

### 3.1 残差块（Residual Block）

**BasicBlock**（用于 ResNet-18/34）：

```
       ┌─── Conv 3×3, BN, ReLU ───┐
x ─────┤                          ├── + ── ReLU ── out
       └─── Conv 3×3, BN ─────────┘
       └────────── identity ──────┘
```

**Bottleneck**（用于 ResNet-50/101/152）：

```
       ┌── 1×1 Conv, BN, ReLU ─────┐
       │                           │
x ─────┼── 3×3 Conv, BN, ReLU ─────┤── + ── ReLU ── out
       │                           │
       └── 1×1 Conv, BN ───────────┘
       └────────── identity ───────┘
```

**为什么用 Bottleneck？**

- 1×1 降维 -> 3×3 卷积通道数少 -> 1×1 升维；
- 同等参数量下能堆更深，计算量更小。

### 3.2 整体结构

```
输入 224×224×3
Conv 7×7, 64, stride=2  -> 112×112×64
MaxPool 3×3, stride=2   -> 56×56×64
Stage1: [3, 4, 6, 3] 个 block, 64 通道  -> 56×56×256
Stage2: 同上, 128 通道, 第一个 block stride=2 -> 28×28×512
Stage3: 同上, 256 通道, 第一个 block stride=2 -> 14×14×1024
Stage4: 同上, 512 通道, 第一个 block stride=2 -> 7×7×2048
GAP -> FC 1000
```

不同深度 ResNet 的层配置：

| 网络 | conv2 (64) | conv3 (128) | conv4 (256) | conv5 (512) | 总层数 |
| --- | --- | --- | --- | --- | --- |
| ResNet-18 | 2×2 | 2×2 | 2×2 | 2×2 | 18 |
| ResNet-34 | 3×2 | 4×2 | 6×2 | 3×2 | 34 |
| ResNet-50 | 3 | 4 | 6 | 3 | 50 |
| ResNet-101 | 3 | 4 | 23 | 3 | 101 |
| ResNet-152 | 3 | 8 | 36 | 3 | 152 |

### 3.3 下采样策略

- **Stage 间**：第一个 block 的 stride=2，特征图减半、通道翻倍；
- **conv1**：7×7 stride=2 + maxpool stride=2，下采样 4 倍；
- 总下采样 32 倍（输入 224 -> stage5 输出 7）。

### 3.4 通道匹配

当 stride=2 或通道数变化时，shortcut 不能直接相加，需要 **1×1 卷积 + BN** 投影匹配：

```python
if stride != 1 or inplanes != planes * expansion:
    downsample = nn.Sequential(
        nn.Conv2d(inplanes, planes * expansion, 1, stride, bias=False),
        nn.BatchNorm2d(planes * expansion),
    )
```

## 4.残差连接的数学理解

### 4.1 梯度反传

反向传播时：

$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial H} \cdot \left( \frac{\partial F}{\partial x} + 1 \right)
$$

- 加法中的 **1** 保证梯度可以无衰减地传到上一层；
- 即使 $\partial F / \partial x$ 很小，梯度也不会消失。

### 4.2 恒等映射视角

如果每个残差块都学到 $F(x) = 0$，整个网络就退化为浅层网络。**残差连接让"什么都不做"成为最容易学的解**。

### 4.3 视角：ResNet 是浅层网络的指数集成

Unraveling ResNet（Veit et al., 2016）发现：ResNet 可视为 $2^n$ 个不同路径的集成，每条路径是一个浅层网络。这解释了为何深层 ResNet 仍能优化。

## 5.ResNet 变种

### 5.1 ResNet-v2（Pre-activation ResNet, 2016）

**改进**：把 BN-ReLU 放到卷积**前面**（pre-activation），即 BN-ReLU-Conv 形式。

```
       ┌── BN-ReLU-Conv 1×1 ──┐
x ─────┤                       ├── + ── out
       │  BN-ReLU-Conv 3×3     │
       │  BN-ReLU-Conv 1×1 ────┘
       └────── identity ───────┘
```

**优势**：

1. 最后一个 BN 不在主路径上，信息流动更直接；
2. 训练更稳定，能训更深网络（1000 层）；
3. 正则化更强。

### 5.2 Wide ResNet（WRN, 2016）

**思想**：**加宽**比加深更高效。Bottleneck 通道数增加 $k$ 倍。

- WRN-50-2（宽 2 倍）≈ ResNet-101 性能，但训练更快。

### 5.3 ResNeXt（2017）

**思想**：**分组卷积**，引入"基数（cardinality）"。

$$
\mathcal{F}(x) = \sum_{i=1}^{C} \mathcal{F}_i(x)
$$

- 把一个 64 通道的卷积拆为 32 组每组 4 通道，再聚合；
- 在相同参数量下性能优于 ResNet；
- 启发了后续 MobileNet、EfficientNet。

### 5.4 ResNeSt（2020）

**Split Attention**：分组卷积 + 通道注意力，结合 ResNeXt 与 SENet。

### 5.5 Res2Net（2019）

**思想**：在单个残差块内**多尺度特征**。把 3×3 卷积通道分组，组间做卷积并累加，形成层次化感受野。

## 6.为什么残差连接如此有效？

### 6.1 损失地形平滑

Li et al. (2018) "Visualizing the Loss Landscape" 可视化发现：**残差连接让损失地形更平滑**，而普通深层网络的损失地形非常崎岖、充满局部极小。

### 6.2 缓解梯度消失/爆炸

shortcut 提供"梯度高速公路"，梯度可以无衰减地到达任意浅层。

### 6.3 隐式集成

ResNet 可视为 $2^n$ 个浅层网络的指数集成。

### 6.4 简化优化目标

学 $F(x) \to 0$ 比学恒等映射容易，"什么都不做"成为可达解。

## 7.感受野与特征金字塔

### 7.1 ResNet 各 stage 感受野

| Stage | 输出尺寸 | 理论感受野 |
| --- | --- | --- |
| conv1 | 112×112 | 7 |
| conv2 | 56×56 | 11 |
| conv3 | 28×28 | 19~27 |
| conv4 | 14×14 | 43~75 |
| conv5 | 7×7 | 91~171 |

**注意**：有效感受野远小于理论感受野，呈高斯分布。

### 7.2 FPN（Feature Pyramid Network, 2017）

ResNet 输出**多尺度特征**，FPN 通过**自顶向下 + 横向连接**融合多尺度信息，是检测/分割任务的标配：

```
C2 ──── 1×1 ─── P2 ─── 3×3 ──── out P2
                  ↑ upsample
C3 ──── 1×1 ─── P3 ─── 3×3 ──── out P3
                  ↑
C4 ──── 1×1 ─── P4 ─── 3×3 ──── out P4
                  ↑
C5 ──── 1×1 ─── P5 ─── 3×3 ──── out P5
                  ↓ 3×3 stride 2
                  P6
```

## 8.代码实现

```python
import torch.nn as nn

class BasicBlock(nn.Module):
    expansion = 1
    def __init__(self, inplanes, planes, stride=1, downsample=None):
        super().__init__()
        self.conv1 = nn.Conv2d(inplanes, planes, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(planes)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(planes, planes, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(planes)
        self.downsample = downsample

    def forward(self, x):
        identity = x
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        if self.downsample is not None:
            identity = self.downsample(x)
        return self.relu(out + identity)
```

## 9.面试常考问题

**Q1：ResNet 解决了什么问题？怎么解决的？**

解决深层网络的**退化问题**（训练误差随深度上升）。通过残差连接让网络学残差 $F(x) = H(x) - x$，"什么都不做"（恒等映射）成为容易学的解，同时 shortcut 提供梯度高速公路。

**Q2：残差连接为什么能缓解梯度消失？**

反向传播时梯度 $\frac{\partial L}{\partial x} = \frac{\partial L}{\partial H} (\frac{\partial F}{\partial x} + 1)$，加法中的 1 保证梯度可无衰减传到浅层。

**Q3：ResNet-50 和 ResNet-34 的区别？**

- 34 用 BasicBlock（2 层 3×3 卷积）；50 用 Bottleneck（1×1 → 3×3 → 1×1 三层）；
- 50 比 34 深，但参数量更少（Bottleneck 用 1×1 降维）；
- 50 性能更好。

**Q4：为什么 Bottleneck 用 1×1 降维？**

3×3 卷积在低维空间计算，参数和 FLOPs 大幅减少，相同计算预算下能堆更深。

**Q5：shortcut 什么时候需要 1×1 卷积投影？**

当输入输出通道数或 stride 不匹配时，需要 1×1 卷积把 shortcut 变换到与主路径输出一致。

**Q6：ResNet-v2 的 pre-activation 有什么好处？**

1. 最后一个 BN 不在主路径，信息流动更直接；
2. 训练更稳定，能训 1000 层网络；
3. 正则化更强。

**Q7：为什么 ResNet 用 BN 而不用 LN？**

- CV 中 BN 在 batch + H/W 维度归一化，保留通道间差异（不同通道代表不同特征，不应被归一化）；
- LN 会把通道一起归一化，破坏通道间差异；
- 但 BN 依赖 batch size，小 batch 时效果差（这时用 GN）。

**Q8：ResNet 各 stage 输出尺寸？**

输入 224 -> conv1 (112) -> maxpool (56) -> conv2 (56) -> conv3 (28) -> conv4 (14) -> conv5 (7)。

**Q9：FPN 解决什么问题？**

多尺度目标检测：浅层特征分辨率高但语义弱，深层特征语义强但分辨率低。FPN 通过自顶向下 + 横向连接融合两者，得到既有高分辨率又有强语义的特征金字塔。

**Q10：ResNet-152 比 ResNet-50 好在哪？为什么不是越深越好？**

- 152 比 50 top-5 错误率略低（约 0.5%）；
- 但收益递减，且训练成本大幅上升；
- 实践中 ResNet-50 是**性价比最高的选择**，工业部署首选。

## 10.总结

- **残差连接**是 ResNet 的核心，让"深层网络可训"成为可能；
- **Bottleneck** 是 ResNet-50+ 的标准结构，1×1 降维让 3×3 计算高效；
- **ResNet-v2 的 pre-activation** 进一步优化训练稳定性；
- **ResNeXt 引入分组卷积**，Wide ResNet 主张"加宽比加深高效"；
- **FPN** 把 ResNet 多尺度特征利用起来，成为检测/分割标配；
- ResNet 至今仍是 CV 最常用的 backbone，**面试必考**。
