# 检测面试题

## 1.基础概念

### Q1：目标检测的任务是什么？

定位图像中所有目标的位置（bbox）+ 识别类别。输出：N 个 (bbox, class, score)。

### Q2：检测和分类的区别？

| 维度 | 分类 | 检测 |
| --- | --- | --- |
| 输出 | 类别 | 类别 + 位置 |
| 目标数 | 1（图） | N（图） |
| 难点 | 类间差异 | 多尺度、密集、定位 |

### Q3：检测算法分几类？

1. **两阶段**：R-CNN 系列（RPN + 检测头）；
2. **单阶段**：YOLO、SSD、RetinaNet；
3. **Transformer**：DETR 系列（端到端）。

### Q4：IoU 是什么？怎么计算？

$$
\text{IoU} = \frac{|A \cap B|}{|A \cup B|}
$$

两框交集面积 / 并集面积。范围 [0, 1]，越大越重叠。

### Q5：mAP 是什么？

- **AP**：某类 PR 曲线下面积；
- **mAP**：所有类 AP 平均；
- COCO mAP：在 IoU=[0.5:0.05:0.95] 上平均；
- 主指标 mAP@[0.5:0.95]。

## 2.两阶段检测

### Q6：R-CNN 系列的演进？

- R-CNN：Selective Search + CNN + SVM；
- Fast R-CNN：整图过 CNN + RoI Pooling；
- Faster R-CNN：RPN 替代 Selective Search；
- Mask R-CNN：加 mask 分支。

### Q7：RPN 的原理？

- 在 feature map 上滑动；
- 每位置预测 k 个 anchor 的前景/背景 + 框偏移；
- 3×3 conv 提特征 + 两个 1×1 conv（分类、回归）。

### Q8：RoI Pooling 和 RoI Align 的区别？

- RoI Pooling：坐标取整，量化误差，对小目标不友好；
- RoI Align：双线性插值，无量化误差；
- Mask R-CNN 引入 RoI Align。

### Q9：FPN 解决什么问题？

- 多尺度检测：小目标用高分辨率，大目标用强语义；
- 自顶向下 + 横向连接；
- 标配。

### Q10：Cascade R-CNN 的级联思想？

- 单 IoU 阈值难调；
- 级联多个检测头，IoU 阈值递增（0.5 -> 0.6 -> 0.7）；
- 高质量检测器。

## 3.单阶段检测

### Q11：单阶段检测器精度低的根本原因？

类别不平衡：anchor 多，正样本少，易负样本主导 loss。Focal Loss 解决。

### Q12：Focal Loss 的原理？

$$
L_{FL} = -\alpha (1 - p_t)^\gamma \log p_t
$$

- $(1-p_t)^\gamma$ 降低易样本权重；
- $\gamma = 2$；
- RetinaNet 用 Focal Loss 让单阶段超越两阶段。

### Q13：SSD 怎么处理多尺度？

6 个不同分辨率 feature map，浅层检测小目标，深层检测大目标。

### Q14：FCOS 的 Anchor-free 思想？

每像素预测到框边的距离 (l, t, r, b) + centerness。无 anchor。

### Q15：YOLOX 相比 YOLOv5 的改进？

1. Anchor-free；
2. 解耦 head；
3. SimOTA 标签分配；
4. 强数据增强。

## 4.YOLO 系列

### Q16：YOLO 的核心思想？

把检测视为回归问题，一次前向预测所有框 + 类别，无需 RPN。

### Q17：YOLOv1 vs Faster R-CNN？

| 维度 | YOLOv1 | Faster R-CNN |
| --- | --- | --- |
| 流程 | 单阶段 | 两阶段 |
| 速度 | 快 | 慢 |
| 精度 | 低 | 高 |
| 小目标 | 差 | 好 |

### Q18：YOLOv3 的多尺度检测？

3 个尺度（13×13、26×26、52×52），分别检测大、中、小目标。

### Q19：YOLOv4 的 BoF 和 BoS？

- BoF：训练时增强，不增加推理开销（Mosaic、Mixup）；
- BoS：少量推理开销但提升明显（Mish、CSP、PANet）。

### Q20：YOLOv8 的 DFL？

Distribution Focal Loss，把框回归视为概率分布，学到不确定性，提升定位精度。

### Q21：YOLOv10 的 NMS-free？

一致性双分配：训练时一对多，推理时一对一。真正端到端。

### Q22：Mosaic 增强的好处？

1. 等效 batch × 4；
2. 自然包含小目标；
3. 减少大 batch 需求；
4. 适应多尺度。

## 5.DETR 系列

### Q23：DETR 的核心创新？

1. 检测视为集合预测；
2. Transformer Encoder-Decoder；
3. 匈牙利匹配；
4. 无 anchor、无 NMS。

### Q24：DETR 为什么需要匈牙利匹配？

N 个预测 vs K 个 GT（K < N），一对一匹配保证每个 GT 只被一个 query 学，避免重复预测。

### Q25：DETR 训练为什么慢？

- query 从随机初始化学到"位置 + 内容"模式；
- 匈牙利匹配初期不稳定；
- 全局注意力收敛慢；
- 500 epochs vs Faster R-CNN 12 epochs。

### Q26：Deformable DETR 解决什么问题？

- 全局注意力计算大，无法高分辨率；
- 可变形注意力：每 query 只关注 4 个采样点；
- 多尺度 + 高分辨率；
- 训练快 10 倍。

### Q27：DN-DETR 的去噪训练？

给 GT 加噪声作为"噪声 query"，让模型学去噪，与主任务联合训练，加速收敛。

### Q28：DINO 相比 DN-DETR 的改进？

1. 对比去噪（CDN）；
2. Mixed Query Selection；
3. Look Forward Twice；
4. SOTA 63.3 mAP。

### Q29：RT-DETR 怎么实现实时？

1. 高效混合 encoder；
2. 不确定性最小化 query 选择（减少 query 数）；
3. IoU-aware query selection；
4. 108 FPS。

### Q30：DETR 为什么无 NMS？

匈牙利匹配保证每个 GT 只被一个 query 学，query 之间不重复预测，无需 NMS。

## 6.Anchor & NMS

### Q31：Anchor 是什么？为什么需要？

预定义参考框，基于它回归偏移比直接回归绝对坐标稳定，让分类回归解耦。

### Q32：Anchor-based vs Anchor-free？

| 维度 | Anchor-based | Anchor-free |
| --- | --- | --- |
| 超参 | 多 | 少 |
| 设计 | 复杂 | 简单 |
| 精度 | 略高 | 已追平 |
| 代表 | Faster R-CNN, YOLOv3 | FCOS, YOLOv8 |

### Q33：NMS 的原理？

1. 按置信度排序；
2. 取最高分框加入结果；
3. 删除与该框 IoU > 阈值的其他框；
4. 重复直到处理完。

### Q34：Soft-NMS 解决什么问题？

标准 NMS 直接删除重叠框，密集场景误删。Soft-NMS 降低重叠框置信度，不直接删。

### Q35：DIoU-NMS 的改进？

用 DIoU（考虑中心距离）替代 IoU，同时考虑重叠和中心位置，密集场景更友好。

## 7.综合题

### Q36：检测器评估指标？

- mAP@[0.5:0.95]：主指标；
- mAP@0.5：VOC 标准；
- AR（Average Recall）：1, 10, 100 框/图；
- FPS：推理速度。

### Q37：小目标检测为什么难？怎么解决？

难：分辨率低、信息少、易被背景淹没。
解决：

1. 高分辨率输入；
2. FPN 多尺度；
3. 小尺度 anchor；
4. 数据增强（Mosaic 含小目标）；
5. 上下文信息；
6. 切图检测（SAHI）。

### Q38：密集场景检测为什么难？

- 目标相互遮挡；
- NMS 误删相邻目标；
- anchor 匹配冲突；
- 解决：
  1. Soft-NMS / DIoU-NMS；
  2. Repulsion loss；
  3. 关系建模（DETR）；
  4.CrowdHuman 等密集数据训练。

### Q39：检测器部署要注意什么？

1. **backbone 选择**：精度-速度权衡；
2. **量化**：FP16/INT8；
3. **剪枝**：减少冗余；
4. **蒸馏**：大模型蒸馏小模型；
5. **TensorRT/ONNX** 优化；
6. **多尺度推理**：TTA 提升精度；
7. **后处理优化**：并行 NMS。

### Q40：检测器选择？

| 场景 | 推荐 |
| --- | --- |
| 实时（移动端） | YOLOv8n, YOLOv5n |
| 实时（服务器） | YOLOv8s/m, RT-DETR-R50 |
| 高精度 | YOLOv8x, DINO, Cascade R-CNN |
| 小目标 | 切图 + YOLOv8 |
| 密集场景 | RT-DETR, DINO |
| 端到端 | DETR 系列 |

### Q41：检测和分割的关系？

- 检测输出 bbox；
- 实例分割 = 检测 + mask；
- 全景分割 = 语义 + 实例；
- Mask R-CNN = Faster R-CNN + mask 分支。

### Q42：什么是 Open-Vocabulary Detection？

- 传统检测：固定类别（COCO 80 类）；
- OVD：用文本描述任意类别，如 CLIP + 检测；
- Grounding DINO、GLIP 等代表；
- 跨越类别限制。

### Q43：检测器怎么处理长尾分布？

1. **重采样**：罕见类过采样；
2. **重加权**：focal loss、class-balanced loss；
3. **解耦训练**：先正常训，再 class-balanced 训 head；
4. **数据增强**：罕见类增强更多；
5. **Copy-Paste**：把罕见类目标粘贴。

### Q44：检测中的损失函数组合？

$$
L = L_{cls} + \lambda_{bbox} L_{bbox} + \lambda_{giou} L_{giou}
$$

- $L_{cls}$：CE 或 Focal；
- $L_{bbox}$：Smooth L1 或 L1；
- $L_{giou}$：GIoU/DIoU/CIoU。

### Q45：检测中的数据增强？

- **Mosaic**：4 图拼接（YOLOv4+）；
- **Mixup / CutMix**；
- **Copy-Paste**：目标粘贴；
- **随机裁剪、翻转、颜色扰动**；
- **多尺度训练**：随机输入尺寸；
- 注意：bbox 标签要同步变换。
