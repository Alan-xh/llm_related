# 2.单阶段检测

## 1.概述

**单阶段检测器**直接从图像预测框和类别，**省去 RPN**，速度快但精度略低。代表：**YOLO、SSD、RetinaNet**。单阶段检测器是工业实时检测的主流。

## 2.YOLO（You Only Look Once, 2016）

**论文**：You Only Look Once: Unified, Real-Time Object Detection (Redmon et al., 2016)

**核心思想**：把检测视为**回归问题**，一次前向预测所有框。

详见 [3.YOLO系列](../3.YOLO系列/3.YOLO系列.md)。

## 3.SSD（Single Shot MultiBox Detector, 2016）

**论文**：SSD: Single Shot MultiBox Detector (Liu et al., UNC)

**核心思想**：在**多尺度 feature map** 上预测，每位置预定义 anchor，直接预测类别 + 框偏移。

### 3.1 结构

```
Input -> VGG-16 -> Conv layers
                  │
                  ├── conv4_3 (38×38) ── 预测
                  ├── conv7    (19×19) ── 预测
                  ├── conv8_2  (10×10) ── 预测
                  ├── conv9_2  (5×5)   ── 预测
                  ├── conv10_2 (3×3)   ── 预测
                  └── conv11_2 (1×1)   ── 预测
```

每层 feature map 每位置预定义 $k$ 个 anchor：

- conv4_3: 4 anchors；
- conv7~conv11_2: 6 anchors；
- 总计 ~8732 个 anchor。

### 3.2 多尺度设计

- 不同层 feature map 分辨率不同；
- 浅层（高分辨率）检测小目标；
- 深层（低分辨率）检测大目标；
- 总 mAP 大幅提升。

### 3.3 损失

$$
L = L_{conf} + \alpha L_{loc}
$$

- $L_{conf}$：分类 CE（含难例挖掘，正负样本 1:3）；
- $L_{loc}$：Smooth L1 框回归。

### 3.4 优点

1. 速度快：59 FPS（VOC2007）；
2. 多尺度：覆盖大小目标；
3. 端到端训练。

### 3.5 缺点

1. **小目标精度低**：浅层 anchor 多但语义弱；
2. **anchor 数量大**：8732 个，需 NMS；
3. **类别不平衡**：负样本远多于正样本。

## 4.RetinaNet（2017）

**论文**：Focal Loss for Dense Object Detection (Lin et al., Facebook)

**核心思想**：**Focal Loss** 解决单阶段检测器的**类别不平衡**问题。

### 4.1 类别不平衡问题

- 单阶段每图 ~10^4 个 anchor；
- 正样本（与 GT 匹配）通常 < 100；
- 大量易负样本主导 loss；
- 模型学到"全预测为背景"。

### 4.2 Focal Loss

$$
L_{FL} = -\alpha (1 - p_t)^\gamma \log p_t
$$

- $(1 - p_t)^\gamma$ 降低易样本权重（$p_t \to 1$ 时 loss $\to 0$）；
- $\gamma = 2$ 是典型值；
- $\alpha$ 平衡类别。

### 4.3 RetinaNet 结构

```
Input -> ResNet + FPN
           │
           ├── P3, P4, P5, P6, P7
           │
        Classification Subnet  +  Box Regression Subnet
        (每层独立预测)          (每层独立预测)
```

- 5 个 FPN 层，每层每位置 9 个 anchor（3 尺度 × 3 长宽比）；
- 分类子网：4 个 3×3 conv + 1×1 conv（输出 KA 通道，K 类 × A anchor）；
- 回归子网：4 个 3×3 conv + 1×1 conv（输出 4A 通道）。

### 4.4 优点

1. **精度超越两阶段**：COCO mAP 40.4%（vs Faster R-CNN 36.8%）；
2. 速度仍然快；
3. Focal Loss 是单阶段检测的里程碑。

## 5.FCOS（Fully Convolutional One-Stage, 2019）

**论文**：FCOS: Fully Convolutional One-Stage Object Detection (Tian et al., 旷视)

**核心思想**：**Anchor-free** 检测，每像素直接预测到框边的距离。

### 5.1 结构

- Backbone + FPN；
- 每像素预测：
  - 分类 score；
  - **l, t, r, b**：到框左、上、右、下边的距离；
  - **centerness**：中心性（离中心越近越重要）。

### 5.2 优点

1. **无 anchor**：减少超参；
2. **简单**：完全卷积；
3. **性能强**：和 anchor-based 持平或更优。

### 5.3 Centerness 的作用

- 训练时所有像素都参与，但远离中心的像素预测不准；
- Centerness 让中心像素权重大；
- 推理时 $score = cls \times centerness$。

## 6.CenterNet（2019）

**论文**：Objects as Points (Zhou et al., UT Austin)

**核心思想**：把目标视为**一个点**（中心），预测中心点 + 大小。

### 6.1 结构

- 输入 -> Hourglass 网络 -> 输出 3 个 feature map：
  - **Heatmap**：每类每像素是中心点的概率；
  - **Offset**：中心点亚像素偏移；
  - **Size**：目标宽高。

### 6.2 优点

1. **极简**：无 anchor、无 NMS；
2. **速度快**；
3. **可扩展**：3D 检测、姿态估计等。

## 7.EfficientDet（2020）

**论文**：EfficientDet: Scalable and Efficient Object Detection (Tan et al., Google)

**核心思想**：**BiFPN + 复合缩放**。

### 7.1 BiFPN

- 双向 FPN（自顶向下 + 自底向上）；
- 加权特征融合；
- 比标准 FPN 更高效。

### 7.2 复合缩放

- 同时缩放 backbone、BiFPN、分辨率、head；
- B0~B7 共 8 个版本；
- COCO mAP 53.7%（B7）。

## 8.YOLOX（2021）

**论文**：YOLOX: Exceeding YOLO Series in 2021 (Ge et al., 旷视)

**核心思想**：现代 YOLO 设计：

1. **Anchor-free**；
2. **解耦 head**（分类回归独立）；
3. **SimOTA** 标签分配；
4. **强数据增强**（Mosaic、Mixup）。

### 8.1 解耦 head

- 传统 YOLO：分类回归共享 head；
- YOLOX：分类回归独立 head，加速收敛、提升精度。

### 8.2 SimOTA 标签分配

- OTA（Optimal Transport Assignment）的简化版；
- 把 GT 分配给 anchor 视为最优传输问题；
- SimOTA 简化计算，效果接近。

## 9.单阶段 vs 两阶段

| 维度 | 两阶段 | 单阶段 |
| --- | --- | --- |
| 流程 | RPN + 检测头 | 直接预测 |
| 精度 | 高 | 略低（RetinaNet 后追平） |
| 速度 | 慢 | 快 |
| 超参 | 多 | 较少 |
| 训练复杂度 | 高 | 中等 |
| 推理延迟 | 高 | 低 |
| 适合 | 高精度 | 实时 |

## 10.面试常考问题

**Q1：单阶段检测器精度低的根本原因？**

- 类别不平衡：anchor 多，正样本少；
- 易负样本主导 loss；
- 解决：Focal Loss（RetinaNet）、难例挖掘（SSD）。

**Q2：Focal Loss 解决什么问题？**

- 单阶段检测器易负样本主导；
- $(1-p_t)^\gamma$ 降低易样本权重；
- 关注难样本；
- 让单阶段超越两阶段。

**Q3：SSD 怎么处理多尺度？**

- 6 个不同分辨率 feature map；
- 浅层检测小目标，深层检测大目标；
- 每层 anchor 尺度不同；
- 总计 ~8732 anchor。

**Q4：RetinaNet 和 SSD 的区别？**

| 维度 | SSD | RetinaNet |
| --- | --- | --- |
| Backbone | VGG | ResNet+FPN |
| Loss | CE + 难例挖掘 | Focal Loss |
| 精度 | 中等 | 高 |

**Q5：FCOS 的 Anchor-free 思想？**

- 每像素预测到框边的距离 (l, t, r, b)；
- 不需 anchor；
- centerness 解决远离中心像素预测不准问题；
- 简化设计，减少超参。

**Q6：CenterNet 怎么把检测变成关键点检测？**

- 目标视为一个中心点；
- 预测 heatmap（中心概率）+ offset + size；
- 无 anchor、无 NMS；
- 可扩展到姿态、3D 检测。

**Q7：YOLOX 相比 YOLOv5 的改进？**

1. Anchor-free；
2. 解耦 head；
3. SimOTA 标签分配；
4. 强数据增强；
5. 性能优于 YOLOv5。

**Q8：EfficientDet 的 BiFPN 是什么？**

- 双向 FPN；
- 加权特征融合；
- 比标准 FPN 高效；
- 配合复合缩放达到 SOTA。

**Q9：单阶段检测器怎么处理小目标？**

1. 多尺度 feature map（SSD、RetinaNet）；
2. 高分辨率 feature（高分辨率输入）；
3. FPN 融合多尺度；
4. 小 anchor 尺度；
5. 数据增强（Mosaic 含小目标）。

**Q10：为什么 RetinaNet 后单阶段可以超越两阶段？**

- Focal Loss 解决类别不平衡；
- 单阶段天然速度优势；
- 多尺度 FPN；
- 优化技术进步（标签分配、解耦 head 等）。

## 11.总结

- **YOLO 系列**：实时检测标杆，详见下一节；
- **SSD**：多尺度 anchor，开单阶段先河；
- **RetinaNet**：Focal Loss 解决类别不平衡，单阶段超越两阶段；
- **FCOS**：Anchor-free，简单高效；
- **CenterNet**：检测 = 关键点检测，极简；
- **EfficientDet**：BiFPN + 复合缩放；
- **YOLOX**：现代 YOLO 设计（Anchor-free + 解耦 head + SimOTA）；
- 单阶段检测器是工业实时检测的主流。
