# 3.YOLO系列

## 1.概述

**YOLO（You Only Look Once）** 是最经典、最广泛使用的实时目标检测器。从 2016 年 YOLOv1 到 2024 年 YOLOv10/YOLO11，YOLO 系列不断演进，**速度和精度持续提升**，是工业检测的事实标准。本节系统梳理 YOLO 各版本的核心创新。

## 2.YOLOv1（2016）

**论文**：You Only Look Once: Unified, Real-Time Object Detection (Redmon et al.)

**核心思想**：把检测视为**回归问题**，一次前向预测所有框。

### 2.1 结构

```
Image (448×448) -> GoogLeNet 风格 backbone ->
  S×S grid (7×7) × (B=2 boxes × 5 + C=20 classes)
```

每 grid cell 预测：

- $B$ 个 bounding box（x, y, w, h, confidence）；
- $C$ 个类别条件概率；
- 输出张量：$7 \times 7 \times (2 \times 5 + 20) = 7 \times 7 \times 30$。

### 2.2 损失

$$
L = \lambda_{coord} L_{bbox} + L_{cls} + \lambda_{noobj} L_{conf}
$$

- $\lambda_{coord} = 5$：框回归权重；
- $\lambda_{noobj} = 0.5$：无目标时 confidence 权重小；
- 用 sum-squared error。

### 2.3 优点

1. **极快**：45 FPS（Fast YOLO 155 FPS）；
2. 端到端：一次前向；
3. 全局推理：背景误检少。

### 2.4 缺点

1. **小目标精度低**：grid 划分粗；
2. **多目标密集场景差**：每 cell 只预测 2 个框；
3. **形变适应性差**：直接预测 w, h。

## 3.YOLOv2 / YOLO9000（2017）

**论文**：YOLO9000: Better, Faster, Stronger (Redmon & Farhadi)

### 3.1 改进

1. **Batch Normalization**：所有 conv 后加 BN，训练更稳，mAP +2；
2. **High Resolution Classifier**：先在 448×448 fine-tune 分类，再训检测；
3. **Anchor Boxes**：引入 anchor（k-means 聚类先验框），mAP -0.3 但 recall 大幅提升；
4. **多尺度训练**：每 10 batch 随机换输入尺寸（320~608），适应多尺度；
5. **Passthrough Layer**：把浅层细粒度特征传递到深层（类似 FPN）；
6. **Darknet-19**：新 backbone，比 VGG 更轻；
7. **多标签分类**：用 sigmoid 替代 softmax，支持多标签。

### 3.2 性能

- VOC2007：67 FPS + 76.8 mAP；
- 比 YOLOv1 全面提升。

## 4.YOLOv3（2018）

**论文**：YOLOv3: An Incremental Improvement

### 4.1 改进

1. **Darknet-53**：ResNet 风格 backbone，比 Darknet-19 深且强；
2. **多尺度预测**：3 个尺度（FPN 思想），分别检测小、中、大目标；
3. **9 个 anchor**：3 尺度 × 3 长宽比，k-means 聚类；
4. **独立 logistic 分类**：每类独立 sigmoid，支持多标签。

### 4.2 多尺度检测

```
Backbone Darknet-53
       │
   3 个尺度输出：
   1. 13×13 (stride 32) -> 大目标
   2. 26×26 (stride 16) -> 中目标
   3. 52×52 (stride 8)  -> 小目标
```

### 4.3 性能

- COCO mAP 33.0（vs YOLOv2 21.6）；
- 30 FPS；
- 长期是工业主流选择。

## 5.YOLOv4（2020）

**论文**：YOLOv4: Optimal Speed and Accuracy of Object Detection (Bochkovskiy et al.)

### 5.1 核心创新

**Bag of Freebies（BoF）**：训练时增加但不增加推理开销：

1. **Mosaic** 数据增强：4 图拼接；
2. **CutMix**、**Mixup**；
3. **Class Label Smoothing**；
4. **Self-Adversarial Training（SAT）**；
5. **Cosine LR schedule**；
6. **CTA Loss**。

**Bag of Specials（BoS）**：少量推理开销但提升明显：

1. **Mish 激活**：$x \cdot \tanh(\text{softplus}(x))$；
2. **CSP（Cross Stage Partial）**：backbone 跨阶段部分连接；
3. **SPP（Spatial Pyramid Pooling）**；
4. **PANet**（替代 FPN）；
5. **SAM（Spatial Attention Module）**。

### 5.2 CSP 思想

```
输入 -> 一半 -> 卷积 -> 输出 1
     └─ 另一半 -> 跨阶段 -> 直接 concat 到输出 1
```

- 减少计算量；
- 缓解梯度重复；
- 提升特征学习。

### 5.3 性能

- COCO mAP 43.5% at 65 FPS（Tesla V100）；
- 大幅超越 YOLOv3。

## 6.YOLOv5（2020）

**作者**：Glenn Jocher（Ultralytics，非论文，工程实现）

### 6.1 特点

1. **PyTorch 实现**（之前是 Darknet）；
2. **工程化优秀**：易用、文档全、社区活跃；
3. **C3 模块**：CSP 改进版；
4. **Focus -> Conv**：早期版本用 Focus 切片，后改 6×6 conv；
5. **Mosaic + Mixup + HSV 增强**；
6. **AutoAnchor**：自动 k-means 聚类 anchor；
7. **多尺度训练**；
8. **模型缩放**：n/s/m/l/x 5 个版本。

### 6.2 性能

- YOLOv5s：7.0M params，14.0 GFLOPs，COCO mAP 37.4；
- YOLOv5x：86.7M params，335.0 GFLOPs，COCO mAP 50.7；
- 工业部署首选。

## 7.YOLOv6（2022）

**作者**：美团

### 7.1 改进

1. **RepVGG 风格 backbone**：训练多分支，推理单分支；
2. **Decoupled Head**：分类回归解耦；
3. **SimOTA 标签分配**；
4. **SIoU / GIoU loss**；
5. **Anchor-free**（v6.2+）。

### 7.2 性能

- 比 YOLOv5 略快、略好；
- 适合工业部署。

## 8.YOLOv7（2022）

**作者**：YOLOv4 团队

### 8.1 改进

1. **E-ELAN**：扩展高效层聚合网络；
2. **模型重参数化**：训练多分支，推理合并；
3. **Coarse-to-Fine 导向标签分配**；
4. **多种辅助 head**：辅助训练头提升精度。

### 8.2 性能

- COCO mAP 56.8%（v7-E6）；
- 5~160 FPS 范围内 SOTA。

## 9.YOLOv8（2023）

**作者**：Ultralytics

### 9.1 改进

1. **Anchor-free**；
2. **C2f 模块**（替代 C3）；
3. **Decoupled Head**；
4. **TaskAlignedAssigner** 标签分配；
5. **DFL（Distribution Focal Loss）**：把框回归视为概率分布；
6. **统一框架**：检测、分割、姿态、分类一体化。

### 9.2 DFL（Distribution Focal Loss）

把框的连续偏移量建模为离散概率分布：

$$
y = \sum_{i=0}^{n} P(y_i) \cdot y_i
$$

- 让模型学到框的不确定性；
- 提升定位精度。

### 9.3 性能

- YOLOv8n：3.2M params，COCO mAP 37.3；
- YOLOv8x：68.2M params，COCO mAP 53.9；
- 是当前工业最广泛使用的版本之一。

## 10.YOLOv9（2024）

**论文**：Learning What You Want to Learn Using Programmable Gradient Information

### 10.1 核心创新

1. **PGI（Programmable Gradient Information）**：可编程梯度信息；
   - 解决深层网络信息丢失问题；
   - 辅助分支提供可靠梯度；
2. **GELAN（Generalized Efficient Layer Aggregation Network）**：通用高效层聚合；
   - 结合 CSP、ELAN 优点；
   - 可插拔架构。

### 10.2 性能

- 在 MS COCO 上全面超越之前 YOLO；
- 相同参数下精度更高。

## 11.YOLOv10（2024）

**论文**：YOLOv10: Real-Time End-to-End Object Detection (清华大学)

### 11.1 核心创新

1. **NMS-free**：通过一致性双分配消除 NMS；
2. **整体效率-精度驱动设计**：减少冗余；
3. **更高效 backbone**：PSA（Partial Self-Attention）模块。

### 11.2 NMS-free 的意义

- NMS 增加推理延迟（不可预测）；
- YOLOv10 通过一对一分配消除 NMS；
- 真正端到端检测。

## 13.YOLO 训练技巧

### 13.1 Mosaic 数据增强

- 4 张图拼成 1 张；
- 等效 batch size × 4；
- 自然包含小目标；
- YOLOv4+ 标配。

### 13.2 多尺度训练

- 每 10 batch 随机换输入尺寸（如 320~640，步长 32）；
- 模型适应多尺度推理。

### 13.3 Label Smoothing

- 防过自信；
- 通常 $\epsilon = 0.1$。

### 13.4 CIoU Loss

- 几何感知的框回归 loss；
- 收敛快；
- YOLOv5+ 默认。

## 14.面试常考问题

**Q1：YOLO 的核心思想？**

把检测视为**回归问题**：一次前向直接预测所有框 + 类别，无需 RPN。

**Q2：YOLOv1 vs Faster R-CNN 的区别？**

| 维度 | YOLOv1 | Faster R-CNN |
| --- | --- | --- |
| 流程 | 单阶段 | 两阶段 |
| 速度 | 快 | 慢 |
| 精度 | 低 | 高 |
| 小目标 | 差 | 好 |

**Q3：YOLOv3 的多尺度检测？**

3 个尺度（13×13、26×26、52×52），分别检测大、中、小目标，类似 FPN。

**Q4：YOLOv4 的 Bag of Freebies 和 Bag of Specials？**

- BoF：训练时增加，不增加推理开销（Mosaic、Mixup、Label Smoothing）；
- BoS：少量推理开销但提升明显（Mish、CSP、PANet、SAM）。

**Q5：YOLOv5 为什么这么流行？**

1. PyTorch 实现，易用；
2. 工程化优秀（文档、社区）；
3. 性能强；
4. 多版本（n/s/m/l/x）覆盖不同场景；
5. 支持检测、分割、姿态多任务。

**Q6：YOLOv8 的 DFL 是什么？**

- Distribution Focal Loss；
- 把框回归视为概率分布；
- 学到框的不确定性；
- 提升定位精度。

**Q7：YOLOv9 的 PGI 解决什么问题？**

- 深层网络信息丢失；
- PGI 提供可编程梯度信息；
- 让深层网络仍能学到好特征。

**Q8：YOLOv10 的 NMS-free 怎么实现？**

- 一致性双分配：训练时一对多（学得多），推理时一对一（无 NMS）；
- 通过一致性损失让一对多结果匹配一对一；
- 真正端到端检测。

**Q9：Mosaic 增强的原理和好处？**

- 4 图拼 1 图；
- 好处：
  1. 等效 batch × 4；
  2. 自然包含小目标；
  3. 减少对大 batch 的需求；
  4. 让模型适应不同尺度。

**Q10：YOLO 怎么选择版本？**

- **生产部署**：YOLOv8 / YOLOv5（成熟稳定）；
- **追求 SOTA**：YOLOv10 / YOLOv9；
- **极致速度**：YOLOv8n / YOLOv5n；
- **高精度**：YOLOv8x / YOLOv9-E；
- **特殊需求**：实时关键点检测选 YOLOv8-pose。

## 15.总结

- **YOLOv1** 开创单阶段检测；
- **YOLOv3** 多尺度检测，工业主流；
- **YOLOv4** 系统化训练技巧（BoF + BoS）；
- **YOLOv5** 工程化标杆，最广泛使用；
- **YOLOv6/v7** 性能提升，重参数化；
- **YOLOv8** Anchor-free + DFL，统一框架；
- **YOLOv9** PGI 解决信息丢失；
- **YOLOv10** NMS-free，真正端到端；
- YOLO 系列是工业实时检测的事实标准。
