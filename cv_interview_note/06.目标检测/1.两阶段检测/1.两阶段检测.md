# 1.两阶段检测

## 1.概述

**目标检测（Object Detection）** 任务是定位图像中所有目标的位置（bounding box）并识别其类别。检测算法大致分为两类：

- **两阶段（Two-stage）**：先生成候选区域，再分类+回归。代表：**R-CNN 系列**；
- **单阶段（One-stage）**：直接预测框和类别。代表：**YOLO、SSD、RetinaNet**。

两阶段方法**精度高**但速度慢，单阶段方法**速度快**但精度略低。DETR 系列开辟了第三条路：**端到端 Transformer 检测**。

## 2.R-CNN（2014）

**论文**：Rich Feature Hierarchies for Accurate Object Detection and Semantic Segmentation (Girshick et al., Berkeley)

**核心思想**：用 **Selective Search** 生成候选区域（region proposals），每个区域用 CNN 提特征 + SVM 分类。

### 2.1 流程

1. **Selective Search**：生成 ~2000 个候选区域；
2. **Resize**：每区域 resize 到 227×227；
3. **CNN 提特征**：AlexNet 提 4096 维特征；
4. **SVM 分类**：每类一个 SVM；
5. **BBox 回归**：微调框位置。

### 2.2 缺点

1. **极慢**：每图 2000 个区域独立过 CNN，~47s/image；
2. **多阶段训练**：CNN、SVM、BBox regression 分别训练；
3. **存储大**：特征需存储到磁盘。

### 2.3 贡献

- 首次把 CNN 应用于检测，开启深度学习检测时代；
- mAP 从传统方法的 31% 提升到 53.3%。

## 3.Fast R-CNN（2015）

**论文**：Fast R-CNN (Girshick, Microsoft)

**核心改进**：**整图过 CNN 一次**，候选区域从 feature map 上提取（RoI Pooling）。

### 3.1 流程

1. 整图过 CNN 得到 feature map；
2. Selective Search 生成候选区域；
3. **RoI Pooling**：从 feature map 上提取每区域的固定尺寸特征（如 7×7）；
4. FC 层 -> 分类 + BBox 回归。

### 3.2 RoI Pooling

将任意大小区域（如 $h \times w$）划分为 $H \times W$（如 7×7）网格，每网格 max pooling：

```
区域 h×w 划分为 7×7:
┌──┬──┬──┬──┬──┬──┬──┐
│  │  │  │  │  │  │  │  每子区域 max pooling
├──┼──┼──┼──┼──┼──┼──┤
│..│..│..│..│..│..│..│
└──┴──┴──┴──┴──┴──┴──┘
输出 7×7
```

### 3.3 优点

1. 速度快：CNN 只算一次；
2. 端到端训练：分类 + 回归联合优化；
3. 多任务损失：$L = L_{cls} + L_{bbox}$。

### 3.4 缺点

- **Selective Search 仍是瓶颈**（~2s/image）；
- 不是真正端到端。

## 4.Faster R-CNN（2015）

**论文**：Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks (Ren et al., Microsoft)

**核心创新**：**RPN（Region Proposal Network）** 替代 Selective Search，实现**端到端训练**。

### 4.1 整体架构

```
Image -> Backbone(ResNet+FPN) -> Feature Map
                                     │
                                     ▼
                                  RPN ─── 候选框
                                     │
                                     ▼
                                RoI Pooling/Align
                                     │
                                     ▼
                              FC -> 分类 + 回归
```

### 4.2 RPN（Region Proposal Network）

**思想**：在 feature map 上滑动，每位置预测 $k$ 个 anchor 的前景/背景 + 框偏移。

1. **Anchor**：每位置预定义 $k$ 个不同尺度、长宽比的框（如 3 尺度 × 3 长宽比 = 9）；
2. **3×3 卷积**：每位置提 512 维特征；
3. **两个 1×1 卷积**：
   - 分类：前景/背景（2k 个 score）；
   - 回归：$k$ 个框的偏移（4k 个值）。

### 4.3 RoI Pooling vs RoI Align

**RoI Pooling 问题**：

- 量化误差：区域坐标除以 stride 后取整 -> 框位置不准；
- 对小目标影响大。

**RoI Align（Mask R-CNN 提出）**：

- 不取整，用**双线性插值**在浮点位置采样；
- 每 sub-region 取 4 个采样点 max pooling；
- 消除量化误差，对小目标友好。

### 4.4 损失函数

$$
L = L_{cls} + L_{bbox} + L_{rpn\_cls} + L_{rpn\_bbox}
$$

- $L_{cls}$：分类 CE；
- $L_{bbox}$：Smooth L1；
- $L_{rpn\_cls}$：RPN 前景/背景 CE；
- $L_{rpn\_bbox}$：RPN 框回归 Smooth L1。

### 4.5 优点

1. **端到端训练**：RPN + 检测头联合优化；
2. **速度快**：~5 FPS（vs Fast R-CNN ~0.5 FPS）；
3. **精度高**：COCO mAP 36.8%（当时 SOTA）；
4. **可扩展**：加 mask 分支就是 Mask R-CNN。

### 4.6 缺点

1. 仍是两阶段，速度不如单阶段；
2. Anchor 数量多，需 NMS 后处理；
3. 超参多（anchor 尺度、长宽比、IoU 阈值等）。

## 5.FPN（Feature Pyramid Network, 2017）

**论文**：Feature Pyramid Networks for Object Detection (Lin et al., Facebook)

**核心思想**：用**自顶向下 + 横向连接**构建多尺度特征金字塔。

### 5.1 结构

```
Backbone 自底向上:
C2(1/4) -> C3(1/8) -> C4(1/16) -> C5(1/32)

FPN 自顶向下 + 横向连接:
P5 = C5
P4 = C4 + Upsample(P5)
P3 = C3 + Upsample(P4)
P2 = C2 + Upsample(P3)

每层 P 各接一个检测头
```

### 5.2 优点

1. **多尺度检测**：小目标用高分辨率特征（P2、P3），大目标用强语义特征（P5）；
2. **计算量小**：横向连接是 1×1 卷积；
3. **检测精度大幅提升**：COCO mAP +3。

### 5.3 应用

- 几乎所有现代检测器都用 FPN 或其变种（PAFPN、BiFPN）。

## 6.Cascade R-CNN（2018）

**论文**：Cascade R-CNN: Delving into High Quality Object Detection (Cai & Vasconcelos)

**核心思想**：**级联多个检测头**，每个用不同 IoU 阈值。

### 6.1 动机

- 单一 IoU 阈值难调：低阈值（0.5）产生噪声框，高阈值（0.7）训练样本不足；
- 不同 IoU 阈值的检测头互补。

### 6.2 结构

```
Stage 1: IoU=0.5  -> 框 -> Stage 2
Stage 2: IoU=0.6  -> 框 -> Stage 3
Stage 3: IoU=0.7  -> 最终框
```

每 stage 用前一 stage 的输出作为输入，IoU 阈值递增。

### 6.3 效果

- COCO mAP 42.8%（vs Faster R-CNN 36.8%）；
- 高质量检测器，对严格 IoU 评估友好。

## 7.Mask R-CNN（2017）

**论文**：Mask R-CNN (He et al., Facebook)

**核心思想**：Faster R-CNN + **mask 分支**，实现**实例分割**。

详见 [07.图像分割/2.实例分割](../../07.图像分割/2.实例分割/2.实例分割.md)。

## 8.Libra R-CNN（2019）

**核心思想**：解决训练中的**不平衡**问题：

1. 采样不平衡：oversample 罕见类；
2. 特征不平衡：用 **Feature Refinement** 平衡各层；
3. 目标不平衡：用 **Balanced L1 Loss** 平衡 easy/hard 样本。

## 10.两阶段检测优缺点

### 10.1 优点

1. **精度高**：候选区域过滤，误检少；
2. **多尺度友好**：FPN 配合；
3. **可扩展**：易加 mask、keypoint 等分支；
4. **小目标友好**：RoI Align 精确。

### 10.2 缺点

1. **速度慢**：两阶段串行；
2. **超参多**：anchor 尺度、IoU 阈值等；
3. **需 NMS**：不是真正端到端；
4. **训练复杂**：RPN + 检测头联合优化。

## 11.面试常考问题

**Q1：R-CNN 系列的演进？**

- R-CNN：Selective Search + CNN + SVM，慢；
- Fast R-CNN：整图过 CNN + RoI Pooling，快但 Selective Search 仍是瓶颈；
- Faster R-CNN：RPN 替代 Selective Search，端到端；
- Mask R-CNN：加 mask 分支，实例分割。

**Q2：RPN 的工作原理？**

在 feature map 上滑动，每位置预测 $k$ 个 anchor 的前景/背景 + 框偏移。3×3 卷积提特征 + 两个 1×1 卷积（分类、回归）。

**Q3：RoI Pooling 和 RoI Align 的区别？**

- RoI Pooling：坐标取整，量化误差，对小目标不友好；
- RoI Align：用双线性插值在浮点位置采样，无量化误差；
- Mask R-CNN 引入 RoI Align，提升小目标精度。

**Q4：FPN 解决什么问题？**

- 多尺度检测：小目标用高分辨率，大目标用强语义；
- 自顶向下 + 横向连接融合；
- 几乎所有现代检测器标配。

**Q5：Cascade R-CNN 的级联思想？**

- 单 IoU 阈值难调；
- 级联多个检测头，IoU 阈值递增（0.5 -> 0.6 -> 0.7）；
- 每阶段用前一阶段输出作为输入；
- 高质量检测器。

**Q6：两阶段 vs 单阶段？**

| 维度 | 两阶段 | 单阶段 |
| --- | --- | --- |
| 流程 | RPN + 检测头 | 直接预测 |
| 精度 | 高 | 略低 |
| 速度 | 慢 | 快 |
| 超参 | 多（anchor 等） | 较少 |
| 适合 | 高精度场景 | 实时检测 |

**Q7：Faster R-CNN 的损失函数？**

$$
L = L_{rpn\_cls} + L_{rpn\_bbox} + L_{cls} + L_{bbox}
$$

RPN 分类 + RPN 框回归 + 检测头分类 + 检测头框回归。

**Q8：Anchor 的作用？**

- 预定义不同尺度、长宽比的框；
- RPN 在 anchor 基础上回归偏移；
- 覆盖不同大小目标；
- 让回归任务更易学。

**Q9：为什么 Faster R-CNN 还需要 NMS？**

- RPN 输出大量重叠框；
- 检测头也会预测多个框；
- NMS 去除冗余；
- 真正端到端需 DETR 系列。

**Q10：Faster R-CNN 怎么处理多尺度？**

1. Backbone + FPN 提供多尺度特征；
2. Anchor 多尺度（不同尺度 + 长宽比）；
3. 不同 FPN 层用不同尺度 anchor；
4. RoI Align 精确提取任意大小区域。

## 12.总结

- **R-CNN** 开创深度学习检测，但极慢；
- **Fast R-CNN** 整图过 CNN，加速 10×；
- **Faster R-CNN** RPN 替代 Selective Search，端到端；
- **FPN** 多尺度特征，标配；
- **Cascade R-CNN** 级联 IoU 阈值，高质量检测；
- **Mask R-CNN** 加 mask 分支，实例分割；
- 两阶段方法精度高，适合对精度要求高的场景。
