# 3.标签策略

## 1.概述

**标签策略（Label Strategy）** 指训练过程中**对标签的处理方式**。除了传统的 hard label（one-hot），还有 **soft label、label smoothing、pseudo label、self-training** 等策略。标签策略与数据增强、损失函数紧密相关，能显著影响模型性能。

## 2.Hard Label vs Soft Label

### 2.1 Hard Label

- One-hot 编码：[0, 0, 1, 0]；
- 每个样本只属于一个类；
- 监督信号明确但**信息少**；
- 训练时易过自信。

### 2.2 Soft Label

- 标签是概率分布：[0.05, 0.05, 0.85, 0.05]；
- 反映"程度"或多个候选；
- **信息更丰富**；
- 来源：
  1. Teacher 模型预测（蒸馏）；
  2. 标注者多投票分布；
  3. Label smoothing；
  4. Mixup 后的标签。

### 2.3 何时用 Soft Label？

1. **知识蒸馏**：teacher soft prediction 监督 student；
2. **多标注者**：投票分布反映不确定性；
3. **数据有歧义**：模糊图像可同时属于多个类；
4. **Mixup 训练**：自然得到 soft label。

## 3.Label Smoothing

### 3.1 原理

把 hard label 变 soft：

$$
y'_i = \begin{cases}
\frac{\epsilon}{K}, & i \neq y \\
1 - \epsilon + \frac{\epsilon}{K}, & i = y
\end{cases}
$$

通常 $\epsilon = 0.1$，$K$ 是类别数。

### 3.2 作用

1. **防止过度自信**：限制最大 logit；
2. **正则化**：让模型学到类间关系；
3. **提升泛化**：测试集表现更好；
4. **与 Mixup 配合**：训练 ViT 标配。

### 3.3 缺点

- 让模型在 test 上也"不确定"；
- 概率输出不再校准（calibration 变差）；
- 解决：温度缩放（Temperature Scaling）做后处理。

## 4.Knowledge Distillation 的标签

### 4.1 Teacher-Student 蒸馏

**损失**：

$$
L = \alpha \cdot \text{CE}(y, p_s) + (1-\alpha) \cdot \text{KL}(p_t^T \| p_s^T) \cdot T^2
$$

- $p_t, p_s$：teacher、student 输出；
- $T$：温度，软化概率分布；
- $\alpha$：hard、soft loss 平衡。

### 4.2 Soft Label 的信息

- Teacher 的 soft prediction 包含**类间关系**（如猫的图片在"狗"类概率也比"汽车"高）；
- 这种**暗知识（Dark Knowledge）** 比仅 hard label 信息多。

### 4.3 温度的作用

$$
p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}
$$

- $T=1$：标准 softmax；
- $T > 1$：软化分布，让类间差异更明显；
- $T \to \infty$：均匀分布；
- 训练时 student 也用相同 $T$，loss 乘 $T^2$ 保持梯度尺度。

## 5.Pseudo Label（伪标签）

### 5.1 思想

用训练好的模型对**无标签数据**预测，把预测作为伪标签，加入训练集：

```
有标签数据 D_l → 训练模型 M
无标签数据 D_u → M 预测 → 筛选高置信度 → 伪标签 D_pseudo
合并 D_l + D_pseudo → 重新训练 M
```

### 5.2 关键问题

1. **置信度阈值**：只保留高置信度预测，避免噪声标签；
2. **类别平衡**：避免某些类伪标签过多；
3. **迭代 vs 单次**：迭代可能误差累积；
4. **可信度评估**：避免错误标签污染训练。

### 5.3 应用

- **Noisy Student**（Google）：ImageNet 用 EfficientNet 自训练，刷新 SOTA；
- **FixMatch**：弱增强预测伪标签，强增强训练，半监督学习 SOTA。

## 6.Self-Training 与 Semi-Supervised Learning

### 6.1 Self-Training

- Pseudo label 的迭代版本；
- 用模型预测扩大训练集；
- 经典方法，简单有效。

### 6.2 Mean Teacher

- Student 和 Teacher（EMA）双模型；
- Teacher 是 Student 的 EMA；
- 一致性损失：student 和 teacher 输出应一致；
- 半监督学习 SOTA。

### 6.3 FixMatch

**核心**：

1. 弱增强图像 -> 模型预测 -> 伪标签（高置信度）；
2. 强增强图像 -> 模型预测 -> 与伪标签 CE loss；
3. 仅在伪标签置信度 > 阈值时计算 loss。

**效果**：用 250 张有标签 + 50k 无标签，达到全监督 99% 性能。

### 6.4 Noisy Student

**步骤**：

1. EfficientNet 在 ImageNet 有标签数据训练；
2. 对无标签数据预测伪标签；
3. 训练 student（更强数据增强 + 噪声）；
4. 迭代。

**结果**：ImageNet top-1 = 88.4%（当时 SOTA）。

## 7.Multi-Task Label

### 7.1 多任务标签

- 同一图像有多个标签：分类 + 检测 + 分割；
- 多任务学习互相促进；
- 例如 COCO：分类、检测、分割、关键点同时标注。

### 7.2 标签权重

- 不同任务 loss 加权求和；
- 权重平衡是关键；
- 常用 **Uncertainty Weighting**（Kendall et al.）：用任务不确定性自动加权。

## 8.Noisy Label 处理

### 8.1 噪声标签问题

- 标注错误（人为、爬虫）；
- 训练被噪声标签误导；
- 表现：train acc 高，val/test acc 低。

### 8.2 解决方法

1. **Robust Loss**：Generalized Cross Entropy、Symmetric CE；
2. **Label Smoothing**：缓解过自信；
3. **Co-teaching**：两个网络互相教，选小 loss 样本；
4. **DivideMix**：用 GMM 拟合 loss 分布，分干净/噪声样本；
5. **Confident Learning**：用交叉验证估计噪声矩阵，清洗数据。

### 8.3 Confident Learning（Cleanlab）

**思想**：

1. 用交叉验证得到每样本在每类的概率；
2. 估计**联合噪声分布** $P(\tilde{y}, y)$（$\tilde{y}$ 是观察标签，$y$ 是真实标签）；
3. 找出可能错标的样本，重新标注或剔除。

## 9.Long-Tailed Label

### 9.1 长尾问题

- 类别样本数严重不均（如 LVIS：最多 100k+，最少 1）；
- 模型偏向头部类，尾部类表现差。

### 9.2 解决方法

1. **重采样**：
   - Class-balanced sampling：每类等概率采样；
   - Progressively-balanced：从 instance-balanced 渐进到 class-balanced；
2. **重加权 Loss**：
   - Focal Loss：降低易样本权重；
   - Class-Balanced Loss：按有效样本数加权；
3. **解耦训练**：
   - Stage 1：正常 instance-balanced 训 representation；
   - Stage 2：class-balanced 训 classifier；
4. **数据增强**：尾部类增强更多；
5. **GroupSoftmax**：按类分组 softmax。

## 10.代码示例

### 10.1 Label Smoothing

```python
import torch
import torch.nn.functional as F

def label_smoothing_loss(pred, target, epsilon=0.1, num_classes=1000):
    # pred: (B, C), target: (B,)
    log_prob = F.log_softmax(pred, dim=1)
    loss = -epsilon / num_classes * torch.sum(log_prob, dim=1) \
           - (1 - epsilon) * log_prob[range(pred.size(0)), target]
    return loss.mean()
```

### 10.2 Mixup 标签处理

```python
def mixup_data(x, y, alpha=0.2):
    lam = np.random.beta(alpha, alpha) if alpha > 0 else 1.0
    index = torch.randperm(x.size(0)).to(x.device)
    mixed_x = lam * x + (1 - lam) * x[index]
    y_a, y_b = y, y[index]
    return mixed_x, y_a, y_b, lam

def mixup_criterion(criterion, pred, y_a, y_b, lam):
    return lam * criterion(pred, y_a) + (1 - lam) * criterion(pred, y_b)
```

### 10.3 Pseudo Label 筛选

```python
with torch.no_grad():
    logits = model(unlabeled_images)
    probs = F.softmax(logits, dim=1)
    confidence, pseudo_labels = probs.max(dim=1)
    mask = confidence > 0.95  # 只保留高置信度
    if mask.sum() > 0:
        loss = F.cross_entropy(logits[mask], pseudo_labels[mask])
```

## 11.面试常考问题

**Q1：Label Smoothing 的原理和作用？**

把 hard label [0,0,1,0] 变成 [0.033, 0.033, 0.9, 0.033]：

1. 防止过度自信；
2. 正则化；
3. 提升泛化；
4. 与 Mixup 配合效果好。

**Q2：什么是 Soft Label？比 Hard Label 好在哪？**

Soft Label 是概率分布，Hard 是 one-hot：

- 信息更丰富（含类间关系）；
- 适合蒸馏、多标注者场景；
- 训练更稳。

**Q3：知识蒸馏为什么用 Soft Label？**

- Teacher soft prediction 包含**类间关系**暗知识；
- Student 不仅学正确类，还学类间相似度；
- 提升泛化。

**Q4：Pseudo Label 的关键问题？**

1. 置信度阈值：只保留高置信度预测；
2. 类别平衡：避免某些类伪标签过多；
3. 误差累积：迭代要谨慎；
4. 错误标签污染：要可信度评估。

**Q5：FixMatch 的核心思想？**

- 弱增强预测 -> 伪标签；
- 强增强训练 -> 与伪标签 CE loss；
- 仅在伪标签置信度 > 阈值时计算 loss；
- 简单有效，半监督 SOTA。

**Q6：长尾数据集怎么处理？**

1. 重采样：class-balanced；
2. 重加权：focal loss、class-balanced loss；
3. 解耦训练：先正常训 representation，再 class-balanced 训 classifier；
4. 数据增强：尾部类增强更多；
5. GroupSoftmax：按类分组。

**Q7：Noisy Label 怎么处理？**

1. Robust Loss：GCE、Symmetric CE；
2. Label Smoothing；
3. Co-teaching：两网络互相教；
4. DivideMix：GMM 分干净/噪声；
5. Confident Learning：估计噪声矩阵清洗。

**Q8：Mixup 后的标签为什么是 soft？**

两图混合 $\tilde{x} = \lambda x_a + (1-\lambda) x_b$，标签也混合 $\tilde{y} = \lambda y_a + (1-\lambda) y_b$，得到 soft label。

**Q9：温度 $T$ 在蒸馏中起什么作用？**

- $T > 1$ 软化概率分布，让类间差异更明显；
- 让 student 学到更多类间关系；
- 训练时 student 也用相同 $T$，loss 乘 $T^2$ 保持梯度尺度。

**Q10：Label Smoothing 会让模型概率输出不校准吗？**

会。Label smoothing 限制了最大 logit，使模型在 test 上也不到 1.0 概率。解决：温度缩放（Temperature Scaling）做后处理校准。

## 12.总结

- **Hard vs Soft Label**：soft 信息更丰富，适合蒸馏、多标注者；
- **Label Smoothing**：防过度自信、正则化；
- **Knowledge Distillation**：soft label 含暗知识；
- **Pseudo Label**：自训练、半监督；
- **FixMatch**：弱增强预测、强增强训练；
- **Noisy Student**：迭代自训练 + 强增强；
- **Long-Tailed**：重采样 + 重加权 + 解耦训练；
- **Noisy Label**：robust loss + co-teaching + confident learning；
- 标签策略与数据增强、损失函数配合使用，是提升模型性能的关键。
