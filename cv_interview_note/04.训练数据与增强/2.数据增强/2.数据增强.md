# 2.数据增强

## 1.概述

**数据增强（Data Augmentation）** 是提升模型泛化能力的最重要手段之一。通过**对训练图像做随机变换**，扩充有效训练数据，让模型学到**不变性特征**（旋转、尺度、光照等不变）。深度学习时代，**强数据增强**是 ViT、EfficientNet 等模型成功的关键。

## 2.基础数据增强

### 2.1 几何变换

| 变换 | 作用 | 注意 |
| --- | --- | --- |
| **Random Crop** | 随机裁剪 | 模拟尺度变化 |
| **Random Resize Crop** | 先 resize 再裁剪 | ImageNet 标准 |
| **Random Horizontal Flip** | 水平翻转 | 几乎通用 |
| **Vertical Flip** | 垂直翻转 | 卫星图/医学可用，自然图不可用 |
| **Rotation** | 旋转 | 小角度（<15°）常见 |
| **Translation** | 平移 | 模拟位置变化 |
| **Shear** | 剪切 | 仿射变换 |
| **Perspective** | 透视 | 模拟视角变化 |

### 2.2 颜色变换

| 变换 | 作用 |
| --- | --- |
| **Brightness / Contrast** | 亮度对比度调整 |
| **Hue / Saturation** | 色相饱和度调整 |
| **Gamma Correction** | 伽马校正 |
| **PCA Color Noise** | 主成分颜色噪声（AlexNet 用） |
| **GrayScale** | 灰度化（随机概率） |
| **Solarize** | 反相（>阈值像素反转） |

### 2.3 PyTorch 实现

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.08, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(0.4, 0.4, 0.4, 0.1),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])
```

## 3.高级数据增强

### 3.1 Mixup（2018）

**论文**：mixup: Beyond Empirical Risk Minimization (Zhang et al., MIT)

**做法**：两个样本（图像 + 标签）线性混合：

$$
\tilde{x} = \lambda x_a + (1-\lambda) x_b \\
\tilde{y} = \lambda y_a + (1-\lambda) y_b
$$

其中 $\lambda \sim \text{Beta}(\alpha, \alpha)$，$\alpha$ 常取 0.2 或 0.4。

**效果**：

1. 缓解过拟合；
2. 让模型在类间平滑过渡；
3. 提升对抗鲁棒性；
4. ViT 训练必备。

### 3.2 CutMix（2019）

**论文**：CutMix: Regularization Strategy to Strengthen Robustness (Yun et al., 2019)

**做法**：从一个图截取矩形区域粘贴到另一个图，标签按面积加权：

$$
\tilde{x} = M \odot x_a + (1-M) \odot x_b \\
\tilde{y} = \lambda y_a + (1-\lambda) y_b
$$

其中 $M$ 是二值 mask，$\lambda$ 是截取区域面积比。

**Mixup vs CutMix**：

| 维度 | Mixup | CutMix |
| --- | --- | --- |
| 混合方式 | 全图线性 | 区域拼接 |
| 局部信息 | 丢失 | 保留 |
| 适合 | 分类 | 检测、分割 |
| 效果 | 强 | 强 |

### 3.3 Cutout（2017）

**做法**：随机选一个矩形区域，置零或填充均值。

**作用**：强迫模型不依赖单一区域，提升鲁棒性。和 Random Erasing 类似。

### 3.4 Random Erasing（2017）

**做法**：随机选区域，用随机值填充（不只是 0）。

**作用**：模拟遮挡，提升对遮挡的鲁棒性。

### 3.5 AutoAugment（2019）

**论文**：AutoAugment: Learning Augmentation Strategies from Data (Cubuk et al., Google)

**思想**：用**强化学习**搜索最佳增强策略。

**做法**：

1. 定义 14 种增强操作；
2. 每个策略 = 5 个子策略 × 2 操作 + 概率 + 幅度；
3. 用 RL 在 ImageNet 上搜索；
4. 找到最优策略后用于训练。

**效果**：比手动增强提升 1~2%。

### 3.6 RandAugment（2020）

**论文**：RandAugment: Practical automated data augmentation (Cubuk et al., Google)

**改进 AutoAugment**：

- AutoAugment 搜索空间大、慢；
- RandAugment：**只用 2 个超参**（N: 操作数, M: 幅度）；
- 每次随机选 N 个操作，按幅度 M 应用。

```python
# 简化版
for op in random.sample(operations, N):
    img = op(img, magnitude=M)
```

**效果**：和 AutoAugment 相当，但**简单 1000 倍**。ViT 训练标配。

### 3.7 AugMix（2020）

**思想**：保持**语义一致性**的增强。

**做法**：

1. 选多个增强操作链；
2. 每个链随机应用；
3. 用 Mixup 混合多个链的结果；
4. 与原图混合；
5. 损失加一致性约束（与原图 augment 一致）。

**效果**：提升模型对分布偏移的鲁棒性。

### 3.8 TrivialAugment（2021）

**论文**：TrivialAugment: Tuning-free Yet State-of-the-Art Data Augmentation

**极致简化**：

- 每次随机选 1 个操作；
- 随机选幅度；
- 应用即可。

```python
op = random.choice(operations)
mag = random.uniform(0, max_mag)
img = op(img, mag)
```

**效果**：和 RandAugment 相当或更好，但**几乎无超参**。

## 4.标签策略相关增强

### 4.1 Label Smoothing

**做法**：把 hard label [0, 0, 1, 0] 变成 soft label：

$$
y' = (1-\epsilon) y + \frac{\epsilon}{K}
$$

通常 $\epsilon = 0.1$，$K$ 是类别数。

**作用**：

1. 防止模型过度自信；
2. 提升泛化；
3. 与 Mixup 配合效果更好。

### 4.2 Token Labeling（VOLO）

**做法**：除了 [CLS] token 分类，还让每个 patch token 做分类，损失加权。

## 5.特殊任务的数据增强

### 5.1 检测任务

- **Mosaic**（YOLOv4）：4 张图拼成 1 张，标签合并；
- **Copy-Paste**：把目标粘贴到其他图；
- **Random Paste**：随机贴目标；
- **Stitcher**：合并小目标图。

### 5.2 分割任务

- **ClassMix**：按类别区域混合两张图；
- **CutMix 变种**：标签同步混合。

### 5.3 关键点检测

- **Half Body Aug**：随机截取半身；
- **Rotated Aug**：旋转图像和关键点；
- **Scale Aug**：尺度抖动。

## 6.强增强组合（ViT 训练标配）

ViT 训练常组合：

```
1. RandomResizedCrop
2. RandomHorizontalFlip
3. RandAugment (n=2, m=9)
4. Mixup (alpha=0.2)
5. CutMix (alpha=1.0)
6. RandomErasing (p=0.25)
7. Normalize
```

加上：

- Label Smoothing (0.1)
- Stochastic Depth (0.1)
- Long training (300 epochs)
- Cosine LR + Warmup

这套组合是 DeiT、Swin、ConvNeXt 通用配置。

## 7.理论分析

### 7.1 为什么数据增强有效？

1. **扩充数据**：等效训练数据变多；
2. **正则化**：约束模型不变性；
3. **缓解过拟合**：减少 train/val gap；
4. **提升鲁棒性**：对扰动不敏感。

### 7.2 不同增强的互补性

- **几何增强**：模拟位置变化；
- **颜色增强**：模拟光照变化；
- **混合增强**（Mixup/CutMix）：平滑决策边界；
- **遮挡增强**（Cutout/RE）：模拟遮挡；
- **组合使用** > 单一增强。

## 8.数据增强的"坑"

### 8.1 过度增强

- 增强太强会让图像失去语义（如过度旋转导致"颠倒的人"）；
- 模型学不到正确特征；
- 一般从弱增强开始，逐步增强。

### 8.2 任务不匹配

- 检测任务不能用 RandomResizedCrop（会破坏框）；
- 关键点检测不能用水平翻转（关键点要同步翻转）；
- OCR 不能用大角度旋转。

### 8.3 Train/Val 不一致

- 训练时强增强，但 val 必须**仅做必要预处理**（resize + normalize）；
- 推理时同 val；
- 测试时增强（TTA）：推理时也做增强并集成结果。

## 9.测试时增强（TTA）

**Test-Time Augmentation**：推理时对原图做多个增强，分别预测后集成：

```python
preds = []
for aug in [identity, hflip, vflip]:
    img_aug = aug(img)
    preds.append(model(img_aug))
final_pred = average(preds)
```

**常用 TTA**：

- 水平翻转；
- 多尺度（resize 到不同尺寸）；
- 旋转；
- 集成多个模型。

**效果**：通常提升 0.5~1%。

## 10.面试常考问题

**Q1：Mixup 和 CutMix 的区别？**

- Mixup：全图线性混合 + 标签线性混合；
- CutMix：区域拼接 + 标签按面积加权；
- CutMix 保留局部结构，更适合检测分割。

**Q2：为什么 RandAugment 比 AutoAugment 好？**

- AutoAugment 用 RL 搜索，慢且容易过拟合搜索数据；
- RandAugment 只 2 个超参（N、M），泛化性好；
- 同等效果但简单 1000 倍。

**Q3：数据增强为什么能提升泛化？**

1. 等效扩充数据量；
2. 引入不变性约束（旋转、尺度不变）；
3. 平滑决策边界（Mixup）；
4. 缓解过拟合。

**Q4：Label Smoothing 的作用？**

- 防止过度自信；
- 与其他正则化配合效果好；
- 通常 $\epsilon = 0.1$。

**Q5：训练时增强，推理时要不要增强？**

- 一般推理时**不增强**（仅 resize + normalize），保证可复现；
- **TTA**：推理时做多个增强并集成，能涨 0.5~1%，但代价是推理慢。

**Q6：检测任务能用 Mixup 吗？**

可以但要小心：

- 图像混合时，目标框也要合并（不是混合）；
- 损失按面积加权；
- YOLOv4 用 Mosaic（4 图拼接）替代。

**Q7：为什么 ViT 训练需要更强的数据增强？**

- ViT 无归纳偏置（无平移不变、无局部性）；
- 必须靠数据驱动学到这些不变性；
- 强增强模拟 CNN 的归纳偏置效果。

**Q8：Mosaic 增强是什么？为什么 YOLOv4 用？**

- 把 4 张图拼成 1 张大图；
- 标签合并；
- 优点：
  1. 等效 batch size × 4；
  2. 让模型看到更多上下文；
  3. 自然包含小目标；
  4. 减少 batch size 需求。

**Q9：数据增强会导致欠拟合吗？**

可能：

- 增强太强 + 数据少 -> 模型学不到东西；
- 表现：train loss 不降，val loss 高；
- 解决：减弱增强，或加 warmup 让模型先学简单模式。

**Q10：什么是 Stochastic Depth？**

训练时随机跳过某些层（用 identity 替代）：

- 类似 Dropout 但作用在层间；
- 推理时用所有层；
- 优点：
  1. 正则化；
  2. 加速训练；
  3. 让深层网络可训。

## 11.总结

- **基础增强**：Crop、Flip、ColorJitter；
- **混合增强**：Mixup、CutMix；
- **遮挡增强**：Cutout、Random Erasing；
- **自动增强**：AutoAugment、RandAugment、TrivialAugment；
- **标签策略**：Label Smoothing；
- **特殊任务**：Mosaic（检测）、ClassMix（分割）；
- 强增强组合是 ViT 训练成功的**关键**；
- 数据增强的本质是**让模型学到不变性特征**，提升泛化能力。
