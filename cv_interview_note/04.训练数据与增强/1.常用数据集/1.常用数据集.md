# 1.常用数据集

## 1.概述

数据集是深度学习的"燃料"。CV 中数据集按任务分为**分类、检测、分割、关键点、视频、3D** 等。了解常用数据集的特点、规模、标注格式对训练和评估模型至关重要。

## 2.图像分类数据集

### 2.1 MNIST

- **任务**：手写数字识别（0~9）；
- **规模**：训练 60k，测试 10k；
- **图像**：28×28 灰度；
- **地位**：深度学习"Hello World"，几乎所有教程都用；
- **SOTA**：错误率 0.17%（CNN ensemble）。

### 2.2 CIFAR-10 / CIFAR-100

- **任务**：10 类 / 100 类物体分类；
- **规模**：训练 50k，测试 10k；
- **图像**：32×32 彩色；
- **类别**：CIFAR-10 含飞机、汽车、鸟、猫等；CIFAR-100 类别更细；
- **用途**：算力受限时的快速实验，验证网络结构；
- **SOTA**：CIFAR-10 ~99.7%（数据增强 + 大模型）。

### 2.3 ImageNet-1k（ILSVRC2012）

- **任务**：1000 类物体分类；
- **规模**：训练 1.28M，验证 50k，测试 100k；
- **图像**：分辨率不一，常用 224×224 输入；
- **地位**：**深度学习最重要的 benchmark**；
- **SOTA**：top-1 91.0%（CoAtNet-7），top-5 ~99%；
- **人类水平**：top-1 94.5%，top-5 5.1%（已经超过）；
- **下载**：image-net.org。

### 2.4 ImageNet-21k

- **任务**：21,841 类分类；
- **规模**：~14M 图像；
- **用途**：大规模预训练，再迁移到 ImageNet-1k 微调；
- **ViT、Swin、CLIP 等都使用 21k 预训练**。

### 2.5 JFT-300M

- **任务**：18k 类分类；
- **规模**：~300M 图像（私有）；
- **用途**：Google 内部预训练数据集；
- **ViT 原始论文用 JFT-300M 预训练**。

## 3.目标检测数据集

### 3.1 PASCAL VOC

- **任务**：20 类目标检测 + 分割；
- **规模**：VOC07 ~5k 图 / VOC12 ~11k 图；
- **类别**：人、动物、交通工具、家具等 20 类；
- **格式**：XML 标注，YOLO/COCO 之外的另一种格式；
- **mAP 计算**：用 IoU=0.5，不分类别大小。

### 3.2 COCO（Common Objects in Context）

- **任务**：目标检测、分割、关键点、字幕生成；
- **规模**：训练 118k，验证 5k，测试 41k；
- **类别**：80 类常见物体；
- **特点**：
  - 每图平均 7.4 个目标，场景复杂；
  - 标注框 + 实例分割 mask + 关键点；
  - 80 类是从 80 个超类（thing）+ 91 个 stuff 类衍生；
- **评估指标**：mAP@[0.5:0.95]，主指标；
- **格式**：JSON；
- **地位**：**检测分割领域最重要的 benchmark**。

### 3.3 Open Images

- **任务**：检测 + 分割 + 关系；
- **规模**：~9M 图，600 类，3500 万目标框；
- **特点**：Google 发布，规模最大；
- **类别**：600 类，比 COCO 多但分布不均。

## 8.数据集标注格式

### 8.1 VOC XML 格式

```xml
<annotation>
  <size><width>500</width><height>375</height><depth>3</depth></size>
  <object>
    <name>dog</name>
    <bndbox>
      <xmin>48</xmin><ymin>240</ymin>
      <xmax>195</xmax><ymax>371</ymax>
    </bndbox>
  </object>
</annotation>
```

### 8.2 COCO JSON 格式

```json
{
  "images": [{"id": 1, "file_name": "a.jpg", "width": 500, "height": 375}],
  "annotations": [{
    "id": 1, "image_id": 1, "category_id": 18,
    "bbox": [48, 240, 147, 131],  // [x, y, w, h]
    "area": 19257, "iscrowd": 0,
    "segmentation": [[...]]
  }],
  "categories": [{"id": 18, "name": "dog"}]
}
```

### 8.3 YOLO TXT 格式

每图一个 .txt，每行：

```
<class_id> <x_center> <y_center> <width> <height>
```

坐标为归一化值（0~1）。

- **tools**：`voc2coco`、`yolo2coco` 等脚本。

## 9.数据集划分与使用

### 9.1 train / val / test

- **train**：训练用；
- **val**：调参、模型选择；
- **test**：最终评估，**不能用于调参**；
- 典型比例：8:1:1 或 7:2:1。

### 9.2 交叉验证

- K 折交叉验证：数据分为 K 份，每份轮流做 val，其余做 train；
- K=5 或 10 常用；
- 小数据集常用。

### 9.3 数据泄漏

- 同一物体出现在 train 和 val（不同视角）-> 数据泄漏；
- 会导致 val 性能虚高，泛化能力差；
- 解决：按物体/场景/时间划分。

## 10.面试常考问题

**Q1：ImageNet-1k 和 ImageNet-21k 的区别？**

- 1k：1000 类，1.3M 图，最常用 benchmark；
- 21k：21,841 类，14M 图，常用于预训练。

**Q2：COCO 的 mAP 是怎么计算的？**

- 在 IoU 阈值 [0.5:0.05:0.95]（10 个值）上分别计算 mAP；
- 再对类别平均；
- 再对小、中、大目标平均；
- 主指标 mAP@[0.5:0.95]。

**Q3：COCO 和 VOC 的评估指标有何不同？**

- VOC：mAP @ IoU=0.5（单一阈值）；
- COCO：mAP @ IoU=[0.5:0.95]（多阈值平均），更严格。

**Q4：为什么 COCO 比 VOC 更难？**

1. 类别更多（80 vs 20）；
2. 每图目标更多（7.4 vs 2.3）；
3. 尺度变化大（小目标多）；
4. 评估更严格（多 IoU 阈值）。

**Q5：如何处理长尾数据集（如 LVIS）？**

1. **重采样**：罕见类过采样；
2. **重加权**：loss 加权（focal loss、class-balanced loss）；
3. **数据增强**：罕见类增强更多；
4. **解耦训练**：先正常训练 representation，再 class-balanced 训分类头。

**Q6：如何选择预训练数据集？**

- 任务相近 -> 选相近数据集预训练（如医学影像用医学影像预训练）；
- 通用任务 -> ImageNet-21k 或 LAION-400M；
- 计算资源充足 -> 自监督预训练（MAE、DINO）。

**Q7：标注数据贵，如何利用无标签数据？**

1. **自监督预训练**：MAE、SimCLR、MoCo；
2. **半监督学习**：Mean Teacher、FixMatch、Noisy Student；
3. **伪标签**：用模型预测作为无标签数据的标签。

**Q8：数据集的 bias 问题是什么？**

- ImageNet 中"bride"几乎都是西方白色婚纱；
- 模型可能学到偏见（如种族、性别）；
- 影响：泛化到其他文化场景时性能下降；
- 解决：构建多样化数据集、de-bias 训练。

## 11.总结

- **分类**：MNIST、CIFAR、ImageNet-1k/21k、JFT-300M；
- **检测**：PASCAL VOC、COCO、Open Images；
- **分割**：ADE20K、Cityscapes、COCO Panoptic；
- **关键点**：COCO Keypoints、MPII；
- **视频**：Kinetics、UCF-101；
- **多模态**：LAION、CC3M/12M；
- 标注格式：VOC XML、COCO JSON、YOLO TXT；
- 选择数据集时要考虑**任务匹配、规模、类别平衡、bias** 等因素。
