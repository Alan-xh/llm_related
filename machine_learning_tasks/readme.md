机器学习任务分为 **4个大类、12个具体方向**。

### 机器学习任务全景图谱

| 大类 | 核心目标 | 具体任务 | 通俗举例 |
| :--- | :--- | :--- | :--- |
| **1. 判别式任务** | **“是什么”**<br>给输入打标签 | 分类、回归、目标检测、语义分割 | 判断邮件是不是垃圾邮件；预测明天房价 |
| **2. 生成式任务** | **“怎么造”**<br>从噪声/条件中创造新数据 | 图像生成、文本生成、语音合成、数据补全 | 输入“一只猫”，输出一张猫的图片 |
| **3. 自监督/表征任务** | **“怎么理解”**<br>从无标签数据中提取通用特征 | 对比学习、掩码建模、下一词元预测 | 让模型看懂图片里的纹理和轮廓，而不只是认出猫 |
| **4. 决策式任务** | **“怎么做”**<br>在动态环境中采取行动 | 强化学习、模仿学习、主动学习 | 机器人学会走路；AI在围棋中落子 |

### 第一大类：判别式任务（感知世界）
这是最传统的AI，核心是建立“输入”到“输出”的映射。**输出通常是离散的类别或连续的数值**。

-   **1. 分类**：输出是类别。
    -   二分类（垃圾邮件/非垃圾邮件）、多分类（识别手写数字0-9）、多标签分类（一张图里同时有猫、狗和树）。
    -   **损失函数**：交叉熵损失。
    -   **评价标准**：准确率、精确率/召回率、F1-Score、AUC-ROC。
    -   **代表模型**：ResNet（图像）、BERT（文本分类）。
-   **2. 回归**：输出是连续数值。
    -   预测房价、预测股票价格、预测明天温度。
    -   **损失函数**：均方误差（MSE）。
    -   **评价标准**：MSE、MAE、R²（决定系数）。
    -   **代表模型**：线性回归、MLP（多层感知机）。
-   **3. 目标检测**：分类 + 定位。
    -   不仅要说出图里有“猫”，还要用一个框把猫圈出来。
    -   **损失函数**：分类损失 + 边框回归损失（Smooth L1）。
    -   **评价标准**：mAP（平均精度均值）。
    -   **代表模型**：YOLO（实时检测）、Faster R-CNN。
-   **4. 语义分割**：像素级分类。
    -   给图片里每一个像素点打上标签（这块是路，那块是天，那块是人）。
    -   **损失函数**：交叉熵 + Dice Loss（解决类别不平衡）。
    -   **评价标准**：mIoU（平均交并比）、Pixel Accuracy（像素精度）。
    -   **代表模型**：U-Net（医学图像）、DeepLab。
-   **5. 实例分割**：目标检测 + 语义分割。
    -   不仅分出像素类别，还要区分出“这是第一个猫”和“那是第二个猫”。
    -   **损失函数**：分类损失 + 边框回归损失 + 掩码损失（Mask BCE）。
    -   **评价标准**：AP@50、AP@75（不同IoU阈值下的mAP）。
    -   **代表模型**：Mask R-CNN。

### 第二大类：生成式任务（创造世界）
核心是学习数据的**概率分布**，然后从中采样出全新的、肉眼看起来真实的数据。

-   **6. 无条件生成**：随机生成。
    -   给一串随机噪声，生成一张从未存在过的人脸（StyleGAN）。
    -   **损失函数**：对抗损失（GAN）或 扩散损失（Denoising Score Matching）。
    -   **评价标准**：FID（弗雷歇初始距离）、IS（初始得分）。
    -   **代表模型**：Diffusion（扩散模型，如Stable Diffusion）、GAN（生成对抗网络）。
-   **7. 条件生成**：根据输入指令生成。
    -   文字生成图片（输入“宇航员骑马”，输出图片）、文字生成视频（Sora）。
    -   **损失函数**：同上，但会加入“条件对齐损失”（如CLIP Score）。
    -   **评价标准**：FID（真实度）+ CLIP Score（图文匹配度）+ LPIPS（感知相似度）。
    -   **代表模型**：Stable Diffusion + ControlNet、DALL-E。
-   **8. 序列生成（自回归）**：一个接一个地吐字。
    -   大语言模型写文章、机器翻译（中文翻译成英文）。
    -   **损失函数**：自回归交叉熵（预测下一个词的概率）。
    -   **评价标准**：困惑度（Perplexity）、BLEU/ROUGE（翻译/摘要指标）。
    -   **代表模型**：GPT系列、LLaMA。

### 第三大类：自监督/表征学习（理解世界）
这是近年来最火的领域。**不使用人工标签，而是利用数据本身的结构作为监督信号**。目的是训练出一个通用的“骨干网络”，下游任务可以直接用它。

-   **9. 生成式自监督（掩码建模）**：盖住一部分，猜缺失部分。
    -   文本领域（BERT：盖住单词填空）；图像领域（MAE：盖住75%的像素，复原回来）。
    -   **损失函数**：重构误差（L1/L2损失）。
    -   **评价标准**：重构误差、下游任务微调准确率。
    -   **代表模型**：BERT、MAE（掩码自编码器）。
-   **10. 判别式自监督（对比学习）**：判断两个视图是否来自同一物体。
    -   SimCLR、MoCo，以及图文多模态的CLIP。
    -   **损失函数**：InfoNCE（对比损失）。
    -   **评价标准**：InfoNCE Loss、Linear Probe（线性探测准确率）。
    -   **代表模型**：SimCLR、MoCo、CLIP。
-   **11. 下一词元预测（Next-Token Prediction）**：
    -   严格来说也属于序列生成，但在大模型时代，它被当作“预训练任务”来获得世界知识。
    -   **损失函数**：自回归交叉熵。
    -   **评价标准**：验证集交叉熵损失、下游任务的Few-shot性能。
    -   **代表模型**：GPT系列、LLaMA。

### 第四大类：决策式/交互式任务（行动世界）
这类任务没有固定的“正确答案”，模型需要在环境中尝试，通过**奖惩信号**来优化策略。

-   **12. 强化学习**：试错学习。
    -   智能体（Agent）观察环境（State），做出动作（Action），获得奖励（Reward）。目标是让累积奖励最大。
    -   **损失函数**：策略梯度（PPO算法）或 Q-learning损失（时序差分误差）。
    -   **评价标准**：累积奖励（Return）、平均回合得分、收敛速度。
    -   **代表模型**：AlphaGo、OpenAI的ChatGPT训练中的RLHF（基于人类反馈的强化学习）。
-   **13. 模仿学习**：看别人怎么做，我照着做。
    -   给机器人看人类抓取杯子的视频，让机器人模仿动作。不需要设计复杂的奖励函数。
    -   **损失函数**：行为克隆误差（BC Loss）或 GAIL判别器损失。
    -   **评价标准**：专家行为克隆误差、任务成功率（Success Rate）。
    -   **代表模型**：行为克隆、GAIL（生成式对抗模仿学习）。
