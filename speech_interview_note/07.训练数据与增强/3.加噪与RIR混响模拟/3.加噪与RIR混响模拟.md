# 3. 加噪与RIR混响模拟

## 1. 概述

真实部署场景（会议室、车载、开放办公区）的语音几乎从不干净：既叠加环境噪声，又经过房间混响的卷积污染。近讲干净数据训练的 ASR 模型直接放到远场，WER 通常劣化 2~5 倍。**加噪（Additive Noise）与 RIR 卷积混响（Convolutional Reverberation）** 是弥补这一 domain gap 最主要的两种数据增强手段，二者构成远场数据模拟流水线的骨架：

```
远场语音 y(t) 的物理产生模型：

  干净语音 s(t) ──> [房间冲激响应 h(t) 卷积] ──> 混响语音 s(t)*h(t) ──┐
                                                                      (+)──> 远场含噪语音 y(t)
  环境噪声 n(t) ──> [噪声信道 h_n(t) (可选)] ──────────────────────┘
                    按目标 SNR 缩放后叠加

  y(t) = s(t) * h(t) + λ·n(t)      （* 为卷积, λ 由目标 SNR 决定）
```

本篇覆盖：SNR 控制加噪公式、公开噪声/RIR 资源、image method 房间仿真原理（含 RT60）、pyroomacoustics 实战、混响的频域解释，以及完整的远场模拟流水线（加噪 + 混响 + codec + 削波）。

## 2. 加噪：SNR 控制公式

### 2.1 SNR 定义与缩放系数推导

信噪比（Signal-to-Noise Ratio）定义为信号功率与噪声功率之比（dB）：

$$\text{SNR}_{\text{dB}} = 10 \log_{10} \frac{P_s}{P_n}$$

其中功率采用均方值 $P = \frac{1}{N}\sum_{t=1}^{N} x^2[t]$。加噪时先随机采样目标 $\text{SNR}_{\text{dB}} \sim U[\text{SNR}_{\min}, \text{SNR}_{\max}]$（典型 $[5, 20]$ dB，困难场景 $[0, 15]$ dB），再反解噪声缩放系数 $\lambda$：

$$\lambda = \sqrt{\frac{P_s}{P_n \cdot 10^{\text{SNR}_{\text{dB}}/10}}}$$

$$y[t] = s[t] + \lambda \cdot n[t]$$

### 2.2 工程细节（面试易追问）

1. **噪声长度对齐**：噪声库片段（MUSAN 单条多为数秒到 1 分钟）通常比语音短，需循环补齐（repeat/tile）并**随机起始偏移**（random crop），避免每条语音总是混到同一段噪声开头。
2. **功率按重叠段算**：若噪声已循环对齐，用对齐后的整段计算 $P_n$；也可用 VAD 只取语音活动段估计 $P_s$，更准确（静音段不该计入信号功率）。
3. **防削波（clipping）**：叠加后若 $\max|y| > 1$，整体缩放 $\tilde{y} = y \cdot \frac{0.99}{\max|y|}$，或按目标响度重归一化（如 RMS 归一到 -23 dBFS，EBU R128）。
4. **噪声也要卷 RIR**：严格物理仿真中噪声源与说话人位置不同，应各自卷各自的 RIR（$y = s*h_s + \lambda \cdot n*h_n$）；简化版（多数 ASR 增强）只给语音卷 RIR。

### 2.3 代码实现

```python
import torch

def add_noise(speech: torch.Tensor, noise: torch.Tensor,
              snr_db: float) -> torch.Tensor:
    """
    speech: [1, T] 干净语音; noise: [1, T] 已对齐长度的噪声
    返回按目标 SNR 混合后的语音（已防削波）
    """
    if noise.shape[-1] < speech.shape[-1]:                 # 循环补齐
        reps = -(-speech.shape[-1] // noise.shape[-1])     # ceil div
        noise = noise.repeat(1, reps)[..., :speech.shape[-1]]
    else:                                                  # 随机裁剪
        start = torch.randint(0, noise.shape[-1] - speech.shape[-1] + 1, (1,))
        noise = noise[..., start:start + speech.shape[-1]]

    p_s = speech.pow(2).mean()
    p_n = noise.pow(2).mean()
    if p_n < 1e-10:                                        # 全零噪声保护
        return speech
    lam = torch.sqrt(p_s / (p_n * 10 ** (snr_db / 10)))
    mixed = speech + lam * noise

    peak = mixed.abs().max()                               # 防削波
    if peak > 0.99:
        mixed = mixed * (0.99 / peak)
    return mixed
```

## 4. RIR 卷积混响原理

### 4.1 房间冲激响应（RIR）与混响的物理本质

声音在房间中经过**直达声 + 一系列离散反射（早期反射，<80ms）+ 密集混叠的散射（晚期混响）** 到达麦克风。房间对该信道的完整建模是一个线性时不变系统的冲激响应 $h(t)$：

$$y(t) = s(t) * h(t) = \int s(\tau) h(t - \tau) d\tau$$

RIR 是典型的**指数衰减噪声样序列**：直达声冲激 + 逐渐衰减的反射簇。

### 4.2 RT60：混响强度的度量

**RT60（Reverberation Time）** 定义为声能衰减 60dB 所需时间（秒）：

$$RT_{60} \approx 0.161 \cdot \frac{V}{A} \quad \text{（Sabine 公式）}$$

* $V$：房间体积（m³），$A = \sum \alpha_i S_i$：总吸声量（吸声系数 × 面积）。
* 量级参考：起居室 RT60 ≈ 0.3~0.5s；会议室 ≈ 0.5~0.8s；教室/礼堂 ≈ 1~2s；教堂 > 3s。
* 实际常由 Schroeder 后向积分法从实测/仿真 RIR 估计：累加能量 $E(t) = \int_t^\infty h^2(\tau)d\tau$，取 5dB~25dB 段线性拟合斜率外推到 60dB。

### 4.3 Image Method（镜像法）RIR 生成

Allen & Berkley (1979) 经典算法：把墙壁反射等效为**声源的镜像虚源**，每个虚源贡献一个延迟且衰减的冲激：

$$h(t) = \sum_{p \in \text{镜像阶数}} \sum_{q} \frac{\beta_1^{|p_1|}\beta_2^{|p_2|}\beta_3^{|p_3|}}{4\pi d_{pq}/c} \cdot \delta\left(t - \frac{d_{pq}}{c}\right)$$

* $\beta_{1,2,3}$：六面墙的反射系数（由目标 RT60 反推：$\beta = \sqrt{1 - e^{-0.161\, V \ln 10 / (c \cdot S \cdot RT_{60})}}$ 级别的近似）。
* $d_{pq}$：第 $q$ 个 $p$ 阶镜像虚源到麦克风的距离，$c \approx 343$ m/s 为声速。
* 镜像阶数取 10~20 阶即可近似真实 RIR。

```
镜像法示意（2D 剖面）：

   房间                    虚源平面（镜像展开）
   ┌────────┐            ┌───┬───┬───┐
   │ S•     │            │S' │S''│S' │   每个虚源 = 声源关于
   │    ↘   │    ==>     ├───┼───┼───┤   墙面/多面墙的镜像
   │     ●M │            │S' │ S │S' │   麦克风收到所有虚源
   └────────┘            ├───┼───┼───┤   的叠加冲激 = RIR
                         │S' │S''│S' │
                         └───┴───┴───┘
```

### 4.4 pyroomacoustics 实战

```python
import numpy as np
import pyroomacoustics as pra

def make_rir(rt60=0.7, room_dim=[5, 4, 3], src=[2, 2, 1.7],
             mic=[3.5, 2, 1.5], fs=16000):
    # 1. 由目标 RT60 反推墙壁反射系数（Sabine 逆解，库自动完成）
    e_absorption, max_order = pra.inverse_sabine(rt60, room_dim)
    room = pra.ShoeBox(room_dim, fs=fs,
                       materials=pra.Material(e_absorption),
                       max_order=15)                    # 镜像阶数
    room.add_source(src)
    room.add_microphone_array(pra.MicrophoneArray(
        np.array([mic]).T, fs))
    room.compute_rir()                                  # image method
    return room.rir[0][0]                               # h(t), shape [L]

h = make_rir(rt60=0.7)
print(f"RIR 长度: {len(h)} taps (~{len(h)/16000:.0f} ms)")

# 用 RIR 卷积语音（FFT 加速卷积）
import torchaudio.functional as AF
wav, sr = torchaudio.load("speech.wav")                 # [1, T]
wav_reverb = AF.fftconvolve(wav, torch.from_numpy(h)[None].float())
```

## 5. 混响的频域影响（为什么混响伤 ASR）

对 $y(t) = s(t)*h(t)$ 做傅里叶变换，卷积变乘法：

$$Y(f) = S(f) \cdot H(f), \quad \text{幅度}:\ |Y(f)| = |S(f)|\cdot|H(f)|$$

1. **频谱乘性畸变**：$|H(f)|$ 是房间传递函数，存在**梳状滤波（comb filtering）**--直达声与反射声相位差导致某些频率相消（notch）、某些相长（peak）。Fbank 上表现为频带能量被随机「挖坑/抬高」，与 SpecAugment 的 freq mask 形似但结构不同。
2. **时间涂抹（temporal smearing）**：卷积把音素能量在时间上拖尾（几十至几百 ms），相邻音素互相污染，辅音（短促、高频）最先被毁--这是混响场景 **CER 上升主要来自声母错误** 的原因。
3. **自相关结构破坏**：混响使信号自相关长度变长，帧级独立假设（CTC/帧同步解码）进一步失真。
4. **对特征统计的影响**：log-Mel 域上混响近似为加性偏置（谱减法去混响的依据）：$\log|Y| = \log|S| + \log|H| \approx \log|S| + b(f)$，因此 **CMVN（倒谱均值归一化）能部分抑制混响**--这是「为什么 CMVN 对远场有效」的标准答案。

## 6. 远场数据模拟流水线（完整工业配方）

### 6.1 流水线总览

```
干净语音 s ──┬─> [可选 speed perturb 0.9/1.0/1.1]
             ├─> [RIR 卷积]  h ~ P(RIR池 或 参数随机仿真), RT60 ~ U[0.2,1.0]s
             │        │
             │        ▼
             │   混响语音 s*h ──────────────┐
             │                              (+)──> [Codec 压缩] ──> [削波] ──> [响度归一] ──> 远场训练样本
             └─> 噪声 n ×λ(SNR ~ U[5,20]dB)┘        mp3/opus/pcm 8k    clip 0.3~1.0     RMS -23dBFS
```

### 6.2 各级参数与动机

| 环节 | 随机化参数 | 动机 |
| --- | --- | --- |
| Speed perturb | $s \in \{0.9, 1.0, 1.1\}$ | 语速/基频多样性 |
| RIR | 池采样或几何随机仿真；RT60 $U[0.2, 1.0]$s；声源-麦距 $U[0.5, 6]$ m | 远场/近场连续覆盖 |
| 加噪 | 噪声类型（music/babble/ambient 按比例）；SNR $U[5, 20]$dB（困难档 $U[0,10]$） | 噪声鲁棒 |
| Codec（可选） | mp3 16~64kbps / opus / 电话 8kHz 重采样（m-law） | 信道失真（会议软件、电话、蓝牙） |
| 削波（可选） | $\text{clip}(x, \pm c), c \in [0.3, 1]\cdot\max|x|$，比例 p=0.1 | 爆音/增益过高 |
| 响度归一 | RMS / 峰值归一 | 训练稳定（配合 CMVN/BN 层可省略） |

> **顺序讲究**：RIR 必须在加噪**之前或分别卷积**（物理上噪声也经过房间）；codec/削波放最后，模拟采集链路末端失真。顺序错了会造成分布与真实不符。

### 6.3 完整代码（PyTorch 流水线）

```python
import torch, torchaudio
import torchaudio.functional as AF
import pyroomacoustics as pra
import numpy as np

class FarFieldSimulator:
    """远场数据模拟: speed(可选) -> RIR -> 加噪 -> codec -> 削波 -> 归一"""
    def __init__(self, noise_bank, sr=16000,
                 snr_range=(5, 20), rt60_range=(0.2, 1.0), p_rir=0.5,
                 p_noise=0.7, p_codec=0.3, p_clip=0.1):
        self.noise_bank, self.sr = noise_bank, sr
        self.snr_range, self.rt60_range = snr_range, rt60_range
        self.p_rir, self.p_noise = p_rir, p_noise
        self.p_codec, self.p_clip = p_codec, p_clip

    def _random_rir(self):
        rt60 = np.random.uniform(*self.rt60_range)
        dim = np.random.uniform(3, 9, 3).tolist()              # 房间尺寸
        src = np.random.uniform(0.5, dim[0] - 0.5, 3).tolist()
        mic = np.random.uniform(0.5, dim, 3).tolist()          # 可再控制间距
        e_abs, order = pra.inverse_sabine(rt60, dim)
        room = pra.ShoeBox(dim, fs=self.sr,
                           materials=pra.Material(e_abs),
                           max_order=12)
        room.add_source(src)
        room.add_microphone_array(
            pra.MicrophoneArray(np.array([mic]).T, self.sr))
        room.compute_rir()
        return torch.from_numpy(room.rir[0][0]).float()

    def __call__(self, wav: torch.Tensor) -> torch.Tensor:     # wav: [1, T]
        import random
        # 1. RIR 卷积
        if random.random() < self.p_rir:
            h = self._random_rir()[None]
            wav = AF.fftconvolve(wav, h)[..., :wav.shape[-1]]
        # 2. 加噪
        if random.random() < self.p_noise:
            noise = self.noise_bank[random.randrange(len(self.noise_bank))]
            snr = random.uniform(*self.snr_range)
            wav = add_noise(wav, noise, snr)
        # 3. codec 降质 (opus/低码率 mp3 需外部编码器, 此处以降采样+回采近似)
        if random.random() < self.p_codec:
            low_sr = random.choice([8000, 16000])
            wav = AF.resample(wav, self.sr, low_sr)
            wav = AF.resample(wav, low_sr, self.sr)
        # 4. 削波
        if random.random() < self.p_clip:
            c = random.uniform(0.3, 0.9) * wav.abs().max()
            wav = wav.clamp(-c, c)
        # 5. 峰值归一防溢出
        peak = wav.abs().max()
        return wav * (0.99 / peak) if peak > 0.99 else wav
```

### 6.4 效果量级（经验数字）

* 仅 SpecAugment 的模型在加噪（SNR 5dB）测试集上 WER 常翻 2~3 倍；加入 **MUSAN 加噪 + RIRS_NOISES 混响** 增强后，噪声测试集相对下降 20~40%，干净测试集几乎不掉点（配比得当时）。
* 真实远场阵列数据每条成本高（需真人进房间录），仿真流水线可获得等效收益，但**最后一公里仍需少量真实远场数据微调**（sim2real gap）。

## 7. 总结与最佳实践

* **加噪核心是 SNR 控制公式** $\lambda = \sqrt{P_s / (P_n \cdot 10^{\text{SNR}/10})}$，注意噪声随机裁剪、VAD 段功率估计、防削波三个工程细节。
* **混响 = RIR 卷积** $y = s * h$，RIR 来源两条路：公开实测集（OpenSLR RIRS_NOISES 等，真实但量少）与 image method 仿真（pyroomacoustics/gpuRIR，可无限随机生成，RT60 由 Sabine 公式控制）；生产中两者混用。
* **频域视角**：混响是乘性信道 $H(f)$（梳状滤波 + 时间涂抹），CMVN 能部分抵消其 log 域加性偏置，这解释了 CMVN 的远场鲁棒性。
* **流水线顺序即物理因果**：变速 -> RIR -> 加噪 -> codec -> 削波 -> 响度归一；顺序颠倒会导致分布失真。
* **增强分布对齐测试场景**：RT60、SNR、codec 类型都要覆盖目标部署条件，同时保留一部分干净数据防 train-test mismatch 反向退化。
