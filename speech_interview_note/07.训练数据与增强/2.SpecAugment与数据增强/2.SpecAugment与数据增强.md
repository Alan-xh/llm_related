# 2. SpecAugment 与数据增强

## 1. 概述

语音识别模型极易过拟合：LibriSpeech 100h 就能让一个 100M 参数的 Conformer 明显 train/test WER 分叉。**SpecAugment**（Google, 2019, "SpecAugment: A Simple Data Augmentation Method for Automatic Speech Recognition"）以极低的实现成本（特征域上抹几块 mask）在 LibriSpeech 上首次将无 LM 的端到端模型 WER 推进到 5% 以下，成为 ASR 数据增强的事实标准。

语音数据增强按作用域可分三层：

* **波形域（时域）**：速度扰动（Speed Perturb）、音量扰动（Volume Perturb）、加噪（Noise）、加混响（Reverb/RIR）、削波/丢包（Codec & Clipping）——改变的是信号本身，特征随之后移。
* **特征域（频域）**：SpecAugment 的 time warp / freq mask / time mask——直接作用于 Fbank/语谱图，不改变波形。
* **模型/训练域**：Mixup、对抗样本、自适应增强（如 AutoAugment 搜索增强策略）。

```
                    语音数据增强体系
                          │
      ┌───────────────────┼─────────────────────┐
      ▼                   ▼                     ▼
  波形域增强           特征域增强             训练域增强
  ├─ Speed Perturb     ├─ Time Warp           ├─ Mixup
  ├─ Volume Perturb    ├─ Freq Mask (F)       ├─ Adversarial
  ├─ Add Noise (SNR)   ├─ Time Mask (T)       └─ AutoAugment/RandAugment
  ├─ RIR Reverb        └─ Double Mask
  └─ Codec/Clipping
      │                   │
      ▼                   ▼
  改变波形 x(t)       改变特征 X ∈ R^{T×D}
  (可在磁盘离线做)     (必须在训练时 on-the-fly 做)
```

## 2. SpecAugment 详解

### 2.1 三种基本操作

设输入特征为 Fbank 矩阵 $X \in \mathbb{R}^{T \times F}$，$T$ 为帧数，$F$ 为 Mel 频带数（通常 80/64）。

#### (1) Time Warp（时间扭曲）

以图像的随机仿射变换为灵感，在时间轴上选一个锚点，把整段语谱图非线性拉伸/压缩：

$$t' = \begin{cases} t - \dfrac{W}{F}\cdot(F - t)(w - 1) & t \le w \cdot \dfrac{F}{T}\cdot T \text{（示意，实现略有差异）} \\ \text{线性插值重采样} & \text{otherwise} \end{cases}$$

工程实现（torchaudio）：在 $[0.5T - W, 0.5T + W]$ 内随机取中心点 $c$，将其移动到 $c + \delta,\ \delta \sim U[-W, W]$，$W$ 通常取 80（即论文的 `w=80`，允许最大 80 帧 ~ 0.8s 的扭曲量），然后做双线性插值。

**实践结论**：Time Warp 计算量大、收益小，torchaudio 的 `TimeWarp` 也标记为 deprecated；多数工业配方（如 Kaldi/WeNet/icefall）直接砍掉它，只保留两类 mask。

#### (2) Freq Mask（频率遮蔽）

随机选 $f = [0, f_{\max}]$ 个连续 Mel 通道 $[f_0, f_0 + f)$ 置零：

$$X_{t, m} := 0, \quad \forall\, m \in [f_0, f_0 + f),\ \forall\, t \in [1, T]$$

其中 $f \sim U[0, f_{\max}]$，$f_0 \sim U[0, F - f]$。可施加 $m_F$ 次独立 mask。

**直觉**：模拟窄带噪声/信道滤波（电话信道把 300~3400Hz 之外全抹掉，可视为极端 freq mask），强迫模型不依赖单一频带。

#### (3) Time Mask（时间遮蔽）

随机选 $t = [0, t_{\max}]$ 个连续帧 $[t_0, t_0 + t)$ 置零：

$$X_{t, m} := 0, \quad \forall\, t \in [t_0, t_0 + t),\ \forall\, m \in [1, F]$$

其中 $t \sim U[0, t_{\max}]$，$t_0 \sim U[0, T - t]$。可施加 $m_T$ 次独立 mask。

**直觉**：模拟瞬时丢帧、语速加速导致的帧吞并、短促噪声遮盖，同时天然**增大文本/有效音频帧比率**，缓解过拟合。

### 2.2 论文超参与挡位

| 挡位 (Policy) | Time Warp $W$ | Freq Mask $f_{\max}$ (次数 $m_F$) | Time Mask $t_{\max}$ (次数 $m_T$) | 适用条件 |
| --- | --- | --- | --- | --- |
| LibriSpeech basic (B) | 80 | 27 (2) | 100 (2) | 过拟合中等 |
| LibriSpeech double (D) | 80 | 27 (2) | 100 (2)，**每帧允许总 mask 上限 2×** | 过拟合较强 |
| LibriSpeech double-double (DD) | 80 | 27 (2) | 100 (2)，每帧允许上限 4× | 过拟合极强（大模型小数据） |

* $t_{ \max}$ 的自适应替代：取 $t_{\max} = \alpha \cdot T$（$\alpha \approx 0.05 \sim 0.1$），随句子长度缩放，避免短句被整句抹掉。
* **多 mask 重叠规则**：允许 mask 重叠（不要求不重叠）；D/DD 挡引入「每帧被遮挡比例上限」（percent masking），防止有效信息被抹光。

### 2.3 为什么有效（面试必答）

1. **破坏局部共现依赖**：DNN 会记住「这个频谱片段=这个音素」的捷径映射；mask 强制模型利用**全局上下文**（前后帧、周边频带）做推断，等价于隐式集成。
2. **特征 Dropout 的结构化推广**：对整块区域置零比逐元素 dropout 破坏性更强、更接近真实退化（信道/丢帧），类似 Vision 的 CutOut。
3. **提升有效「文本/音频」信息密度**：模型被迫学会从部分声学证据恢复文本——这正是 CTC/Transducer 隐式对齐想学的技能。
4. **等效于穷举式信道仿真**：随机 freq mask ≈ 随机带通滤波，随机 time mask ≈ 随机丢包，比显式仿真便宜且无限多样。

### 2.4 实现代码（torchaudio + 手写）

```python
import torch

def spec_augment(x, freq_mask_num=2, freq_mask_max=27,
                 time_mask_num=2, time_mask_max=100, time_max_ratio=0.1):
    """
    x: [T, F] 或 [B, T, F] 的 Fbank 特征
    返回增强后的特征（0 填充 mask）
    """
    if x.dim() == 2:
        x = x.unsqueeze(0)
    B, T, F = x.shape
    t_max = min(time_mask_max, int(time_max_ratio * T))  # 自适应短句保护

    for b in range(B):
        for _ in range(freq_mask_num):
            f = int(torch.randint(0, freq_mask_max + 1, (1,)))
            f0 = int(torch.randint(0, max(1, F - f), (1,)))
            x[b, :, f0:f0 + f] = 0.0
        for _ in range(time_mask_num):
            t = int(torch.randint(0, t_max + 1, (1,)))
            t0 = int(torch.randint(0, max(1, T - t), (1,)))
            x[b, t0:t0 + t, :] = 0.0
    return x

# 官方实现（新版推荐 TimeMasking/FrequencyMasking 模块）
import torchaudio.transforms as T
transforms = torch.nn.Sequential(
    T.FrequencyMasking(freq_mask_param=27),
    T.TimeMasking(time_mask_param=100),
)
# feats: [B, T, F] -> transforms(feats)
```

## 3. 速度扰动（Speed Perturb）

### 3.1 原理

把音频按重采样因子 $s$ 播放：$x'(t) = x(s \cdot t)$。$s > 1$ 变快（语速↑、基频↑），$s < 1$ 变慢。对 Fbank 的影响是**时间轴与频率轴同时缩放**：帧数变为 $T/s$，共振峰整体平移 $s$ 倍。

* **SOX 实现**：`sox input.wav output.wav speed 0.9`（同时改变时长与音高），等价 resample：16kHz 音频按 `rate 16000*0.9=14400` 重采样后仍标记为 16kHz。
* **工厂标准三值 {0.9, 1.0, 1.1}**（Kaldi 2015 年提出）：等效扩容 3 倍，LibriSpeech 上稳定带来 5~10% 相对 WER 下降。
* 常见扩展：{0.9, 0.95, 1.0, 1.05, 1.1} 三值扩到五值，或连续均匀采样 $s \sim U[0.9, 1.1]$。

### 3.2 代码

```python
import torchaudio.functional as AF

def speed_perturb(wav, sr, speed):
    """wav: [1, n], speed: 0.9/1.0/1.1，返回变速后波形（时长变为 n/speed）"""
    new_sr = int(round(sr / speed))          # 16k, speed=0.9 -> 17778
    wav_rs = AF.resample(wav, orig_freq=sr, new_freq=new_sr)
    return wav_rs                              # 仍按 sr 读取 => 变速变调

# torchaudio 内置：SpectrogramAugmentation 前的在线速度扰动
# torchaudio.sox_effects.apply_effects_tensor(
#     wav, sr, effects=[["speed", "0.9"], ["rate", str(sr)]])
```

## 4. 其他时域增强与 SOX 常用操作

### 4.1 Volume / Noise / Impulse 组合

| 增强类型 | 公式/参数 | 模拟场景 |
| --- | --- | --- |
| 音量扰动 | $x' = g \cdot x,\ g \sim U[g_{\min}, g_{\max}]$（如 $g \in [0.125, 2]$，注意防削波） | 麦克风距离/增益差异 |
| 加噪 | $x' = x + \lambda n$，由目标 SNR 决定 $\lambda$（详见第 3 篇） | 环境噪声 |
| 冲激响应（RIR 卷积） | $x' = x * h$，$h$ 为房间脉冲响应 | 房间混响/远场 |
| 削波 | $x' = \text{clip}(x, -c, c)$，$c \in [0.3, 1.0]\cdot\max|x|$ | 大音量爆音 |
| 丢包 | 随机置零/重复 20~200ms 片段 | 网络传输丢包 |

### 4.2 SOX 命令速查

```bash
# 速度扰动（Kaldi 经典三值）：
sox in.wav out.wav speed 0.9 rate 16000

# 音量调整/归一化：
sox in.wav out.wav gain -n -3        # 归一化到峰值 -3dBFS
sox in.wav out.wav vol 0.5           # 衰减 6dB

# 混响（简易人工 RIR，无房间几何）：
sox in.wav out.wav reverb 0.8 0.9 0.3

# 加噪（需先对齐长度）：
sox -m speech.wav noise.wav -v 0.1 out.wav   # -v 控制噪声相对增益
```

Kaldi 训练脚本的标准组合（`augment.py` 思路）：**速度扰动(3) × 加噪(MUSAN noise/babble/music) × 加 RIR**，常见展开为 5~7 份副本（1 份原始 + 2 份速度 + 1 份 babble + 1 份 music + 1 份 RIR），配合 `--num-repeats` 采样。

### 4.3 完整组合策略（工业配方模板）

```
每条训练样本的在线增强采样（概率示意）：
p(speed perturb)     = 1.0   # 从 {0.9,1.0,1.1} 等概率选
p(RIR convolve)      = 0.3   # 从 RIR 池随机选 1 条
p(add noise)         = 0.6   # MUSAN/DNS 噪声，SNR ~ U[5, 20] dB
p(volume)            = 0.5   # gain ~ U[0.125, 2] + 防削波 clamp
特征阶段：
p(SpecAugment)       = 1.0   # F=2/T=2, 27/100, 双 mask
```

## 5. on-the-fly vs 离线增强

| 维度 | 离线增强（磁盘预生成） | on-the-fly（DataLoader 内在线做） |
| --- | --- | --- |
| **磁盘占用** | 3~7 倍膨胀（10k h -> 50k h+，数百 GB~TB 级） | 零额外存储 |
| **CPU 开销** | 一次性，训练时 I/O 友好 | 每个 epoch 持续消耗（需并行 worker / GPU 变换） |
| **多样性** | 固定副本，epoch 间重复（等效样本数有限） | 理论上每个 epoch 无限新样本 |
| **可复现性** | 容易（文件级对账） | 需要 seed 管理（per-sample RNG） |
| **适用场景** | CPU 资源紧张、静态流水线、论文复现 | GPU 集群大规模训练、NVIDIA DALI/WebDataset 流水线 |

**实践结论**：现代 GPU 训练普遍 **on-the-fly**（SpecAugment 天生只能在线做，因为它作用在特征上），配合 `num_workers>=8` + DALI；磁盘只存原始波形与噪声/RIR 库。速度扰动如在线做开销大，可折中：预生成 3 份速度副本 + 在线加噪。

```python
# on-the-fly 增强 Dataset 骨架
import random, torch, torchaudio

class AugASRDataset(torch.utils.data.Dataset):
    def __init__(self, items, noise_bank, rir_bank, sr=16000):
        self.items, self.noise_bank, self.rir_bank = items, noise_bank, rir_bank
        self.sr = sr

    def __getitem__(self, i):
        wav, text = load_item(self.items[i])
        # 1. 随机速度
        if random.random() < 1.0:
            wav = speed_perturb(wav, self.sr, random.choice([0.9, 1.0, 1.1]))
        # 2. 随机 RIR 卷积
        if random.random() < 0.3:
            h = random.choice(self.rir_bank)
            wav = torch.nn.functional.conv1d(
                wav[None], h[None], padding=h.shape[-1] // 2)[0, :wav.shape[-1]]
        # 3. 随机加噪 (SNR 5~20dB)
        if random.random() < 0.6:
            wav = add_noise(wav, random.choice(self.noise_bank),
                            snr_db=random.uniform(5, 20))
        # 4. 特征后叠 SpecAugment（在 collate 或模型 forward 中）
```

## 6. 增强强度与过增强问题

### 6.1 增强不是越强越好

* **过度 time mask**：$t_{\max}$ 超过 15% 帧数或 mask 总面积过大时，关键音素信息被抹掉，模型学到「文本先验生成」而非声学建模，表现为训练 loss 下降但测试 WER 反升，甚至诱发 AED 模型幻觉。
* **过度加噪**：SNR 全部低于 0dB 时，模型退化为「噪声鲁棒但语音精度低」，在干净测试集上明显掉点（train-test mismatch 反向）。
* **过度速度扰动**（如 ±20% 以上）：基频与共振峰偏移超出真实分布，等于引入分布外数据。
* **Mixup 类增强**在 ASR 中对 CTC 有一定收益，但配比需要很小（α=0.2 以下），否则对齐假设被破坏。

### 6.2 调参法则

1. **对齐训练/测试分布**：增强目标分布应覆盖（而不是偏离）测试场景——测试集有远场就加 RIR，测试全是干净近讲就别把噪声比例拉满。
2. **从弱到强消融**：先 B 挡（F=2/T=2），观察 train-test WER gap；gap 仍大（>10 个点绝对值）再升 D/DD 挡。
3. **监控「增强诊断集」**：分别准备 clean/noisy/reverb 三套 dev 集，分别追踪；若 noisy dev 提升但 clean dev 大跌，说明噪声加过头。
4. **概率而非强度优先**：优先调「增强触发概率」（0.3 → 0.6），再调强度参数（mask 数、SNR 下限），前者更平滑。

## 7. 总结与最佳实践

* **必备组合**：SpecAugment（特征域）+ 速度扰动三值（波形域）是所有 ASR 训练的默认基线，合计带来 10~20% 相对 WER 下降；加噪/RIR 按目标场景叠加。
* **实现取舍**：Time Warp 可砍；`t_max` 用比例自适应（$0.05T \sim 0.1T$）保护短句；新版直接用 `torchaudio.transforms.FrequencyMasking/TimeMasking`。
* **在线优先**：磁盘存原始数据 + 噪声/RIR 库，增强全部在 DataLoader on-the-fly 完成，兼顾磁盘成本与样本多样性。
* **强度可控**：增强分布必须覆盖测试场景而不是偏离它；用分场景 dev 集监控增强副作用，防止「越增强越差」的过增强陷阱。
