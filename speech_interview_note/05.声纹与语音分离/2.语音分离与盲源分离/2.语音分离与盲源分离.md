# 2. 语音分离与盲源分离

## 1. 概述

**鸡尾酒会问题（Cocktail Party Problem）**：人在嘈杂的多说话人环境中能够选择性关注目标说话人，但机器系统在同样场景下性能骤降。语音分离（Speech Separation）的目标是从混合信号中分离出各个独立声源；当源信号与混合信道均未知时，该问题称为**盲源分离（Blind Source Separation, BSS）**。

任务细分：

* **语音增强（Speech Enhancement）**：从"语音 + 噪声"中恢复干净语音（目标已知为语音，噪声是残余类）。
* **说话人分离（Speaker Separation）**：从"多说话人混合"中分离出每个说话人（目标数量由说话人数决定，存在标签置换歧义）。
* **目标说话人提取（Target Speaker Extraction, TSE）**：给定目标说话人声纹线索（enrollment），只提取该说话人（回避置换问题）。

```
                语音分离技术版图
                     │
      ┌──────────────┼────────────────────┐
      ▼              ▼                    ▼
  传统 DSP         时频掩码              端到端时域
  (ICA/beamforming) (IBM/IRM, Spectral   (TasNet 系列,
      │             Subtraction, WPE)     DPRNN/SepFormer)
      └──────────────┴────────────────────┘
                     │
              混合系统: DNN + DSP (e.g. GEV + MVDR)

```

## 2. 经典 BSS：独立成分分析（ICA）

### 2.1 问题设定

瞬时线性混合模型：$C$ 个源信号 $s_i(t)$ 通过混合矩阵 $A \in \mathbb{R}^{M \times C}$ 混叠成 $M$ 个观测 $x_j(t)$：

$$x(t) = A\, s(t)$$

ICA 在以下假设下估计解混矩阵 $W = A^{-1}$：

1. 源信号**统计独立**（independent）；
2. 源信号**非高斯分布**（高斯源的混合不可分，因为高斯分布旋转对称）；
3. 混合矩阵 $M \ge C$（观测数不少于源数，欠定 $M < C$ 时需稀疏性假设）。

### 2.2 核心原理：非高斯性最大化

中心极限定理告诉我们：独立源之和比单个源"更高斯"。因此 ICA 通过最大化分离输出的非高斯性来解混。度量与求解：

* **Negentropy**：$J(y) = H(y_{\text{gauss}}) - H(y)$，与高斯的熵差，常用 $J(y) \approx \sum_k k_4 (E[G_k(y)] - E[G_k(\nu)])^2$ 近似；
* **FastICA**：固定点迭代，用非线性函数 $G(u) = \log\cosh(u)$ 或 $-e^{-u^2/2}$ 的对比函数逐个抽取独立分量；
* **Infomax**：最大化输出经非线性函数后的联合熵，等价于极大似然。

**ICA 在语音上的致命局限**：

* 语音是**卷积混合**（房间混响）而非瞬时混合，需在频域各 bin 独立做 ICA，继而引入**置换不确定（permutation ambiguity）**--各频率 bin 的分离通道需要对齐到同一源，对齐算法复杂且脆弱；
* 欠定场景（单麦克风 $M=1$）完全失效，而单通道才是大多数实际场景。

> **面试要点**：深度学习分离模型与 ICA 的精神纽带是"**标签置换不变性**"（PIT，见第 5 节）--ICA 靠后处理对齐频率 bin，神经网络靠训练目标设计对齐输出通道，本质都在解决"输出与源的无标签对应"问题。

## 3. DSP 方法：WPE 与波束形成

### 3.1 加权预测误差（WPE）去混响

混响建模为自回归过程，线性预测残差去混响（短时混响作为音乐感的部分被保留，长时混响被抑制）：

$$\tilde{x}_t = x_t - \sum_{k=d}^{d+K-1} G_k\, x_{t-k}$$

其中 $d$ 为预测延迟（约 2~5 帧，保留早期混响），$G_k$ 通过迭代求解加权最小二乘估计（权重为信号功率的倒数，语音呈现重尾分布时加权显著优于普通 LS）。WPE 对 ASR 前端 WER 改善典型在 10%~30% 相对值（REVERB challenge 量级），至今仍是多通道 ASR 流水线的标准第一级。

### 3.2 波束形成（Beamforming）

多通道场景用麦克风阵列的空间信息增强目标方向、抑制其他方向：

* **MVDR（Minimum Variance Distortionless Response）**：最小化输出功率且约束目标方向无失真：

$$w_{\text{MVDR}} = \frac{R_n^{-1} a}{a^H R_n^{-1} a}$$

其中 $a$ 为目标导向矢量（steering vector），$R_n$ 为噪声协方差矩阵。

* **GEV（Generalized EigenValue）**：神经mask 辅助的盲波束形成。用神经网络预测的时频掩码 $m$ 分别估计语音与噪声的协方差矩阵：

$$R_s = \frac{1}{\sum_t m_t}\sum_t m_t\, x_t x_t^H, \quad R_n = \frac{1}{\sum_t (1-m_t)}\sum_t (1-m_t)\, x_t x_t^H$$

GEV 波束权重取 $R_n^{-1} R_s$ 的最大特征向量。**这是"DNN + DSP"混合范式的代表作（2015~2018 CHiME 系列）**：神经网络提供 mask，DSP 保证无失真（distortionless），可解释且对误删不敏感。

| 方法 | 输入需求 | 原理 | 优劣 |
| --- | --- | --- | --- |
| Delay-and-Sum | 阵列 + TDOA | 对齐求和 | 鲁棒但增强量有限（~3dB） |
| MVDR | 协方差估计 | 约束无失真最小功率 | 依赖 $R_n/a$ 估计精度 |
| GEV + 神经mask | 阵列 + NN mask | 广义特征向量 | CHiMe 竞赛主力，可盲估计 |
| ICA | 多通道 | 独立性 | 卷积混合下置换对齐困难 |

## 4. 时域端到端：TasNet 系列

### 4.1 从时频域到时域的动机

传统流程在 STFT 幅度谱上做掩码（IBM/IRM），存在根本缺陷：

1. **相位问题**：STFT 相位被认为难以建模，重构时直接复用混合相位，混叠严重时上限被锁死（相位与幅度实际上不独立）；
2. **时频分辨率耦合**：窗长固定，长窗频率分辨率高但时间分辨率差；
3. **完美重构的幅度掩码上限**：即使 IRM=1 也无法处理两个源在同一 time-frequency bin 重叠的能量。

**TasNet（Time-domain Audio Separation Network）** 用可学习的 encoder/decoder 替代 STFT，让网络自己学出适合分离的"伪时频表征"，相位问题被隐式解决。

### 4.2 Conv-TasNet 架构详解

```
混合语音 x(t) [1D waveform]
     │
     ▼
┌─────────────┐  1D-Conv (L=2ms, N=512 filters, stride=L/2)
│  Encoder    │──────────────┐
└─────────────┘              │  分离驱动: 与混合表征逐元素相乘
     │                       ▼
     │            ┌────────────────────────────────┐
     │            │  Separator (TCN)               │
     │            │  - LayerNorm + 1x1Conv (B=128) │
     │            │  - Repeat x R=3:               │
     │            │    Dilated Conv Block x X=8    │
     │            │    (dilation 1,2,4,...,128)    │
     │            │  - 每个 Repeat 后 PReLU+BN     │
     │            │  - 1x1Conv -> C 路掩码 softmax │
     │            └────────────────────────────────┘
     │                       │ masks [C, K, T'] (每路和≈1)
     ▼                       ▼
┌─────────────┐   encoded_mix ⊙ mask_c
│  Decoder    │<──────────────┘  1D-ConvTranspose
└─────────────┘
     │
     ▼
分离信号 s_1(t), ..., s_C(t)

```

三大组件：

* **Encoder**：一维卷积基 $\\{u_k\\}$ 将波形编码为 $K$ 维表征 $w \in \mathbb{R}^{K \times T'}$，等效于可学习的滤波器组；
* **Separator**：全卷积 **TCN（Temporal Convolutional Network）**，堆叠 $R \times X$ 个膨胀卷积块，感受野随 dilation 指数扩张（如 $1,2,\dots,128$ 重复 3 轮，覆盖 ~1.5s 上下文）；输出经 softmax 生成 $C$ 路掩码 $m_c \in (0,1)$，$\sum_c m_c \approx 1$；
* **Decoder**：转置卷积将掩码后的表征重构回波形 $\hat{s}_c$。

### 4.3 训练目标：SI-SDR Loss

尺度不变信噪比（Scale-Invariant SDR）：

$$\text{SI-SDR} = 10 \log_{10} \frac{\|\alpha \, s_{\text{target}}\|^2}{\|\alpha \, s_{\text{target}} - \hat{s}\|^2}, \quad \alpha = \frac{\hat{s}^\top s_{\text{target}}}{\|s_{\text{target}}\|^2}$$

其中先把 $\hat{s}$ 在 $s_{\text{target}}$ 上的投影残差去除，使得损失对输出整体缩放不变。训练目标为最大化（等价最小化 $-\text{SI-SDR}$）。Conv-TasNet 在 WSJ0-2mix 上达到 **SI-SDRi ≈ 15.3 dB**，超越理想时频掩码上限（~13 dB），宣告时域范式的胜利。

### 4.4 后续演进：DPRNN / SepFormer / Mossformer

| 模型 | 核心创新 | WSJ0-2mix SI-SDRi (量级) |
| --- | --- | --- |
| Conv-TasNet (2018) | 时域 TCN 全卷积 | 15.3 dB |
| **DPRNN (2020)** | 双路径 RNN：长序列切成段内(Intra)+段间(Inter)交替建模，把 $O(T^2)$ 降为 $O(T)$ 级处理 | 18.8 dB |
| **SepFormer (2021)** | 双路径 Transformer，Intra/Inter 均用自注意力 | 20.4 dB (2spk) |
| **MossFormer (2023)** | 门控单头自注意力 + 卷积联合，线性复杂度处理长序列 | ~21 dB |

**DPRNN 双路径思想值得展开**（面试高频）：把长序列 reshape 成 $N$ 段 $\times$ $M$ 帧，先在段内双向 RNN 建模局部模式，再在段间（跨段的同一位置）双向 RNN 建模全局依赖，交替执行。这使模型能处理数分钟级音频，也成为长音频分离与增强的通用范式。

## 5. 置换不变训练（PIT）推导

### 5.1 问题：输出通道与源的无标签对应

$C$ 个说话人混合，网络的 $C$ 路输出与 $C$ 个参考信号之间**没有天然的对应关系**。若固定"输出 $i$ 对参考 $i$"计算损失，网络无法收敛（同一说话人在不同样本中可能被分配到不同输出通道）。

### 5.2 PIT 形式化

设输出为 $\hat{S} = (\hat{s}_1, \dots, \hat{s}_C)$，参考为 $S = (s_1, \dots, s_C)$，所有可能置换构成集合 $\mathfrak{S}_C$（大小 $C!$）。PIT 损失为：

$$\mathcal{L}_{\text{PIT}} = \min_{\pi \in \mathfrak{S}_C} \frac{1}{C}\sum_{c=1}^{C} \ell\big(\hat{s}_c,\, s_{\pi(c)}\big)$$

即**在 batch 前向时枚举（或启发式搜索）最优置换，按最优匹配计算损失**。两说话人时 $C!=2$，直接算两种配对取小；多说话人时枚举 $C!$ 代价高，可用匈牙利算法（Hungarian）在 $O(C^3)$ 内求最优指派。

推导细节：

1. 前向得到 $C$ 路输出；
2. 计算 $C \times C$ 的损失矩阵 $D_{ij} = \ell(\hat{s}_i, s_j)$；
3. 取 $D$ 的最小行列匹配 $\pi^\*$（逐样本独立）；
4. 用 $\pi^\*$ 对应的损失反传梯度（选择本身不可导，但 min 的索引固定后梯度正常回传到被选中的输出）。

> **PIT 是说话人分离的基石**：解决训练时的标签歧义；推理时输出仍无说话人身份（输出 1 不代表说话人 A），下游需 ASR/diarization 再归属。uPIT（utterance-level PIT）是逐样本全局置换而非帧级，避免同一说话人在一段内跳通道，实际最常用。

## 6. 语音增强：从谱减法到 DeepFilterNet / RNNoise

### 6.1 传统方法

**谱减法（Spectral Subtraction, 1979）**：假设噪声平稳，从静音段估计噪声谱 $N(f)$，从混合谱中直接减去：

$$|\hat{S}(f)|^p = |X(f)|^p - \beta |N(f)|^p, \quad p \in \{1, 2\}$$

缺陷：过减产生"音乐噪声"（music noise），需要地板/过减因子等工程补丁。

**维纳滤波（Wiener Filter）**：最小均方误差意义下的最优线性滤波：

$$H(f) = \frac{\xi(f)}{1 + \xi(f)}, \quad \xi(f) = \text{SNR}_{\text{prior}}(f)$$

平滑但有先验 SNR 估计依赖（常用 decision-directed 方法）。

### 6.2 神经网络增强

* **RNNoise（2018）**：GRU 混合信号处理--输入带限 BFCC 特征，输出 22 个临界频带的增益（gain），DSP 式的频带增益而非逐 bin 掩码。**极低计算量（~10 MFLOPS 量级）**，可跑在任意 CPU/WebRTC 上，是端侧实时降噪的标杆；
* **DeepFilterNet（2022~）**：**深度滤波器（Deep Filter）**替代逐帧独立掩码--对每个频点预测一组时域 FIR 滤波器系数 $a_{k, i}$（跨 $M$ 帧作用），显著抑制非平稳、低频噪声（键盘声、稳态嗡鸣），且支持实时因果部署：

$$\hat{S}(k, t) = \sum_{i=0}^{M-1} a_{k, i}\, \bar{S}(k, t-i) \cdot g_{k, t}$$

（先验增强 $\bar{S}$ 乘深度滤波系数，再乘整体增益 $g$。）DF 结构对延迟友好，WebRTC/客户端场景广泛落地。

### 6.3 增强与分离的关系

| 维度 | 语音增强 | 说话人分离 |
| --- | --- | --- |
| 目标定义 | 目标类="语音"，残余="噪声" | 目标数=说话人数，对称无特权 |
| 标签歧义 | 无（目标唯一） | 有（需 PIT） |
| 先验利用 | 噪声非语音、语音有谐波结构等 | 说话人同源性弱先验 |
| 典型方法 | 谱减/Wiener/RNNoise/DFN | PIT/TasNet 系列 |
| 共同点 | 掩码/滤波器估计、SI-SDR 目标、时域端到端均通用 | |

> 两者本质上是同一个"从混叠观测恢复目标源"的问题在不同约束下的实例；目标说话人提取（VoiceFilter、Spex/Spex+）用注册声纹作为条件，把分离问题转化为"条件增强"，天然回避 PIT。

## 7. PyTorch 代码：PIT 损失与 SI-SDR

```python
import torch
import itertools

def si_sdr(est, ref, eps=1e-8):
    """单条信号的 SI-SDR, est/ref: [T]"""
    est = est - est.mean()
    ref = ref - ref.mean()
    proj = torch.dot(est, ref) * ref / (torch.dot(ref, ref) + eps)
    noise = est - proj
    return 10 * torch.log10((proj.pow(2).sum() + eps) / (noise.pow(2).sum() + eps))

def pit_loss(ests, refs, loss_fn=si_sdr):
    """
    uPIT 损失 (2 speakers 可枚举; C 说话人建议匈牙利算法)
    ests: [C, T] 网络输出, refs: [C, T] 参考
    返回: 最优置换下的平均损失与最优置换
    """
    C = refs.size(0)
    perms = list(itertools.permutations(range(C)))   # C! 种置换
    best_loss, best_perm = None, None
    for perm in perms:
        # ests[i] 对齐 refs[perm[i]]
        loss = sum(-loss_fn(ests[i], refs[perm[i]]) for i in range(C)) / C
        if best_loss is None or loss < best_loss:
            best_loss, best_perm = loss, perm
    return best_loss, best_perm


class ConvTasNetStyleSeparator(torch.nn.Module):
    """Conv-TasNet 骨架示意 (Encoder-TCN Separator-Decoder)"""
    def __init__(self, L=16, N=512, B=128, C=2):
        super().__init__()
        self.encoder = torch.nn.Conv1d(1, N, L, stride=L // 2, bias=False)
        self.norm = torch.nn.InstanceNorm1d(N, affine=True)
        self.in_conv = torch.nn.Conv1d(N, B, 1)
        # TCN: 3 repeats x 8 dilated blocks (示意简化为 6 层)
        self.blocks = torch.nn.ModuleList([
            torch.nn.Conv1d(B, B, 3, padding=2 ** (i % 4), dilation=2 ** (i % 4))
            for i in range(6)
        ])
        self.out_conv = torch.nn.Conv1d(B, C * N, 1)  # C 路掩码
        self.decoder = torch.nn.ConvTranspose1d(N, 1, L, stride=L // 2, bias=False)
        self.C = C

    def forward(self, mixture):                    # mixture: [B, T]
        w = self.encoder(mixture.unsqueeze(1))     # [B, N, T']
        feat = self.norm(w)
        feat = torch.relu(self.in_conv(feat))      # [B, B_, T']
        for blk in self.blocks:
            feat = torch.relu(blk(feat)) + feat    # 残差 TCN
        masks = torch.softmax(self.out_conv(feat), dim=1).view(
            mixture.size(0), self.C, -1, feat.size(-1))        # [B, C, N, T']
        ests = [self.decoder(masks[:, c] * w.unsqueeze(1))    # [B, 1, T]
                .squeeze(1)[:, :mixture.size(1)] for c in range(self.C)]
        return torch.stack(ests, dim=1)            # [B, C, T]


if __name__ == "__main__":
    model = ConvTasNetStyleSeparator()
    mix = torch.randn(2, 8000)                     # [B, T] 模拟 0.5s@16k
    ests = model(mix)                              # [B, C, T]
    # 对 batch 内每个样本独立做 PIT
    total = 0.0
    for b in range(mix.size(0)):
        refs = torch.randn(2, 8000)                # 假设的干净源
        loss, perm = pit_loss(ests[b], refs)
        total += loss
        print(f"sample {b}: PIT loss={loss.item():.3f} dB, best perm={perm}")
    (total / mix.size(0)).backward()
    print("backward OK")

```

## 8. 总结与最佳实践

* **范式演进**：ICA（独立性假设，瞬时混合 + 置换对齐难题）-> 时频掩码 + 波束形成（DSP 可解释，相位上限锁死）-> Conv-TasNet 时域端到端（可学习 encoder/decoder，SI-SDR 超理想掩码）-> DPRNN/SepFormer/MossFormer（双路径长序列建模，2mix 提升 5+ dB）。
* **PIT 是分离训练的灵魂**：逐样本最优置换对齐损失，多说话人时用匈牙利算法避免 $C!$ 枚举；uPIT 粒度最常用。
* **混合系统仍是工业主流**：神经 mask + GEV/MVDR 的"DNN + DSP"方案在多通道场景兼顾性能、失真控制与可解释性；单通道实时场景倾向 RNNoise/DeepFilterNet 类低算力设计。
* **增强 vs 分离**：同一问题的两种实例化；目标说话人提取（声纹条件化）回避置换歧义，是多说话人 ASR 前端的实用路线。
* **落地 checklist**：明确通道数与延迟约束 -> 选择掩码/深度滤波/波束形成 -> SI-SDR 训练 + PIT（若分离）-> 关注泛化（说话人数、混响、域偏移），推理输出仍需 diarization/ASR 完成语义归属。
