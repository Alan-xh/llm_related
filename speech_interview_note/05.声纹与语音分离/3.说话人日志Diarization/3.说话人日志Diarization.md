# 3. 说话人日志Diarization

## 1. 概述

说话人日志（Speaker Diarization）的任务是回答 **"who spoke when"（谁在什么时候说话）**：给定一段（可能很长的）音频，输出每个时间区间对应的说话人身份标签（无需知道真实姓名，只区分 spk-1 / spk-2 ...）。它和声纹验证（1:1 判断）、说话人分离（波形级分离）构成"说话人处理"三大任务：

* **Diarization 不需要注册**，是"无监督聚类"式任务：输出标签只保证同类同说话人；
* 典型应用：会议转写归属、访谈/播客字幕、呼叫中心质检、影视字幕对齐。

```
"who spoke when" 输出示例:
时间轴(s)  0 ──── 5 ──── 10 ──── 15 ──── 20 ──── 25
           ┌─────┬──────┬───────┬────────┬───────┐
说话人A     │██████      │███████        │██████ │
说话人B     │      ██████│       ████████│       │
           └─────┴──────┴───────┴────────┴───────┘
           (重叠区 10~12s: A 与 B 同时说话, 最难处理)

```

技术路线演进：**VAD + 声纹嵌入 + 聚类（流水线式）-> 端到端神经 diarization（EEND / EEND-EDA）-> 目标说话人 VAD（TS-VAD）-> 与 ASR 联合一体化建模**。

---

## 2. 经典流水线：VAD + 嵌入 + 聚类

### 2.1 流水线总览

```
长音频 ──> [1. VAD] ──> 语音段 ──> [2. 切分] ──> 子段(sub-segment)
                                                        │
                                                        ▼
                                        [3. 声纹嵌入提取]
                                        (x-vector/ECAPA, 滑窗 1.5s 步长 0.75s)
                                                        │
                                                        ▼
                                        [4. 聚类 AHC / 谱聚类]
                                                        │
                                                        ▼
                                        [5. 重分割 Resegmentation]
                                        (神经网络帧级 refine 类边界)
                                                        │
                                                        ▼
                                        输出: <spk, t_start, t_end> 列表

```

各阶段要点：

1. **VAD（Voice Activity Detection）**：基于能量的传统方法或 neural VAD（如 Silero）。VAD 错误直接传播--漏检的语音段永远丢失；过检引入非语音噪声段污染聚类。
2. **子段切分**：将 VAD 语音切成滑窗子段（典型 1.5s 窗、0.75s 步长），每段独立提嵌入。过长的段混合多个说话人导致嵌入"平均化"，过短则嵌入估不准。
3. **嵌入提取**：复用声纹验证训练的 ECAPA-TDNN/x-vector 编码器；3D-Speaker、WeSpeaker 均提供 diarization 预训练模型。
4. **聚类**：见 2.2。
5. **重分割**：用聚类结果作为伪标签，训练帧级分类器（或直接用隐马尔可夫平滑）在更细粒度（如 10ms~100ms）上修正边界。

### 2.2 聚类算法：AHC 与谱聚类

**AHC（Agglomerative Hierarchical Clustering，凝聚层次聚类）**：

* 初始每个子段自成一簇，迭代合并距离最近的两个簇，直到满足停止条件（距离阈值或簇数达到估计的说话人数）；
* 簇间距离的链接准则：single / complete / average-linkage，diarization 中常用平均余弦距离；
* 停止阈值是超参，需与嵌入分布匹配；工业实现（如 pyannote）多在 PLDA/cosine 打分上做 AHC。

**谱聚类（Spectral Clustering）**：

1. 构建子段相似度矩阵 $S$（余弦相似度，可用高斯核 $S_{ij} = \exp(-d_{ij}^2 / 2\sigma^2)$）；
2. 计算归一化拉普拉斯矩阵 $L = I - D^{-1/2} S D^{-1/2}$（$D$ 为度矩阵）；
3. 取最小 $k$ 个特征值对应的特征向量，行归一化后用 k-means 聚类。

谱聚类对非凸簇结构更鲁棒，**k-means 的 k（即说话人数）需事先估计**--常用 eigen-gap（特征值跳变）或 VB-HMM（变分贝叶斯自动推断说话人数）。

| 维度 | AHC | 谱聚类 | VB / HMM 类 |
| --- | --- | --- | --- |
| 说话人数估计 | 阈值停止（隐式） | 需外部估计（eigen-gap） | 可自动推断 |
| 复杂度 | $O(n^2)$~$O(n^3)$ | 特征分解 $O(n^3)$ | 逐迭代，较慢 |
| 边界精度 | 子段粒度 | 子段粒度 | 帧级（HMM 状态） |
| 工业采用 | 广泛（简单稳定） | 学术/竞赛常用 | pyannote 传统后端 |

> 流水线方法的固有缺陷：**误差级联**（VAD 错 -> 切分错 -> 嵌入污染 -> 聚类错）与**无法处理重叠语音**（一个子段含两人时嵌入为混合，聚类天然将其归为"第三类"）。

## 3. 端到端神经 Diarization：EEND 与 EEND-EDA

### 3.1 EEND（End-to-End Neural Diarization）

EEND 的核心洞察：把 diarization 转化为**帧级多标签分类（multi-label classification）**。对每一帧 $t$、每个说话人 $k$（固定上限 $K$ 个输出通道），直接预测其是否活跃：

$$P(\hat{y}_{t,k} = 1 \mid X) = \sigma(\text{EEND}(X)_{t,k})$$

```
        BlSTM Encoder (帧级自注意力替代亦可)
音频 ──────────────────────────────────────────────>
   t: | 0 | 1 | 2 | 3 | 4 | 5 | ... |
spk1:   1   1   1   0   0   0        帧级多标签
spk2:   0   0   1   1   1   1        (重叠处 1,1 允许同时激活)

损失 = 帧级 BCE (无需聚类、无需说话人数先验、天然处理重叠)

```

* 损失为帧级 binary cross-entropy，**输出通道与真实说话人的对应由 PIT 解决**（与说话人分离的 PIT 精神一致，只是损失作用在帧级标签而非波形）；
* 训练数据由人工对话按说话人混合仿真生成（因此泛化到真实域是难点）；
* 局限：**固定说话人上限 $K$**（原论文 2~3 人，人多时输出通道不够）；长音频（> 数分钟）时自注意力受限且激活向量会"漂移"。

### 3.2 EEND-EDA：自回归说话人数扩展

EEND-EDA 引入**Encoder-Decoder Attractor（EDA）**机制，把"说话人上限"从固定改为动态生成：

1. Encoder 输出经过一个 LSTM（EDA decoder）自回归地读完全部帧嵌入；
2. EDA 逐个**生成 attractor（吸引子）向量** $a_k$，每个 attractor 对应一个可能存在的说话人；
3. 每帧的说话人活动概率 = 帧嵌入与 attractor 的内积过 sigmoid：$P(y_{t,k}) = \sigma(h_t^\top a_k)$；
4. 生成"结束 attractor"（其激活概率代表"没有更多说话人"）自动决定说话人数。

```
        ┌──────────────── Encoder (BlSTM/Transformer) ───────────────┐
音频 ──>│  h_1  h_2  ... h_T                                        │
        └───────────────────────────────────────────────────────────┘
                     │                        │
                     ▼                        ▼
              ┌────────────┐          ┌──────────────┐
              │   Frame    │          │ EDA (LSTM)   │──> a_1, a_2, ..., a_K, a_∞
              │  自注意力   │          │ 自回归attractor│    (逐个吐出, 直到结束符)
              └────────────┘          └──────────────┘
                     │                        │  P(y_{t,k}) = σ(h_t·a_k)
                     ▼                        ▼
                  输出活动矩阵          说话人数 = 已生成的有效attractor数

```

EEND-EDA 可处理未知人数（含 3 人以上对话），是学术界端到端 diarization 的重要基线。

### 3.3 流水线 vs 端到端对比

| 维度 | VAD+聚类流水线 | EEND / EEND-EDA |
| --- | --- | --- |
| 说话人数 | 需估计或自动推断 | EEND-EDA 自动生成 |
| 重叠语音 | 天然不支持 | 原生支持 |
| 训练数据 | 真实数据可用（无监督聚类） | 依赖仿真混合，域差距大 |
| 长音频 | 天然分块处理 | 需分块 + attractor 保持机制 |
| 工业采用 | 仍为主流 | 新系统逐步引入（含 meeting 场景） |

## 4. TS-VAD：目标说话人 VAD

**TS-VAD（Target-Speaker VAD）** 是流水线与端到端的折中：先用传统方法得到初始说话人集合，再针对每个候选说话人做"该说话人在帧级的活动检测"。

核心机制：给每个候选说话人 $k$ 计算其初始嵌入 $e_k$（来自第一轮聚类的 i-vector/x-vector），网络以音频特征 + $e_k$ 为条件，逐帧输出该特定说话人的 VAD 概率：

$$P(y_{t}^{(k)} = 1 \mid X, e_k) = \text{TS-VAD}(X, e_k)_t$$

* 数学形式可理解为**说话人条件化的 VAD**：同一网络在 $K$ 个嵌入条件下跑 $K$ 次，得到 $K$ 条活动轨迹；
* 优势：初始嵌入来自真实数据的聚类，避免 EEND 的仿真域差距；重叠语音处理能力接近 EEND；Google 多次在会议 diarization 落地中报告 TS-VAD 显著优于 AHC 基线；
* 迭代版 TS-VAD 还用第一轮输出反过来 refine 嵌入，多轮交替提升精度。

```
第一轮: VAD + 嵌入 + AHC ──> 初始说话人集合 {e_1, ..., e_K}
                                  │
                                  ▼
音频特征 + e_k ──> [TS-VAD 网络] ──> 说话人k的帧级活动轨迹 (共K条)
                                  │
                                  ▼ (可选: 反向更新嵌入, 迭代精化)
                          最终 diarization 输出

```

## 5. ASR 与 Diarization 的联合建模

### 5.1 串联式（ Cascaded / Independent）

```
音频 ──> ASR (Whisper/Transducer) ──> 文本 + 词级时间戳
   │
   └──> Diarization ──> <spk, t_start, t_end>
                              │
                 按时间戳重叠将词归属到说话人
                              ▼
                  "谁说了什么" (带说话人标签的转写)

```

* 优点：两个系统独立开发、独立优化，可分别选最优模型；
* 缺点：误差复合（diarization 边界错 -> 词归属错）；重叠语音区域 ASR 识别率本就骤降（两人同时说，声学模型混淆），而该区域恰恰是归属最需要的信息。

### 5.2 一体化（ Joint / Integrated）

* **Serialized Output Tacking (SOT) 式**：单个 ASR 模型按说话人顺序连续输出多说话人文本（"说话人1的整句 + 说话人2的整句"），隐式学习归属；
* **Target-Speaker ASR / 说话人条件 ASR**：将目标说话人嵌入作为 ASR encoder 的条件输入（如 Spex+、SA-ASR），每个说话人各解码一次，天然将重叠语音拆开；
* **多任务学习**：同一 encoder 同时输出 ASR token 与 diarization 标签（如 Whispert、并联 diarization + CTC 头），共享声学表征并互相促进；
* 工程现状：**串联仍是大段落转写的默认选择**（可解释、可插拔），一体化方案在重叠密集的会议场景收益最大。

## 6. DER 计算与重叠语音难点

### 6.1 DER（Diarization Error Rate）公式

DER 是 diarization 的标准指标，定义为总错误时间归一化：

$$\text{DER} = \frac{\text{FA（误归属语音时间）} + \text{MISS（漏归属语音时间）} + \text{CF（说话人混淆时间）}}{\text{全部真实语音时间（含重叠部分按人数计）}}$$

* **FA（False Alarm）**：假设语音时间（VAD 输出但无真实语音）；
* **MISS（Missed Speech）**：真实语音未被覆盖；
* **CF（Speaker Confusion）**：有语音但说话人标签错误的部分（按时间累积，重叠区若标错人数按差额累计）。

> 注意：分母是"真实语音总时长 $\times$ 人数（重叠段按多人累计）"，重叠语音越多的数据集 DER 天然越高。**collar（项圈）容忍度**：评测时常在边界两侧各留 0.25s 不计错（吸收人工标注边界抖动），但会掩盖真实边界精度。

数值量级参考：单人独白场景 DER 可 < 5%；两三人会议（CALLHOME / AMI），流水线方法 10%~15%，EEND-EDA / TS-VAD 在重叠多的集上可到 8% 以下；预训练大模型（pyannote-3.x、3D-Speaker 系）在 common 会议基准已进入 10% 以内。

### 6.2 重叠语音：核心难点

1. **数据稀缺**：自然对话重叠比例 5%~20%（会议可更高），真实标注的重叠数据极少；
2. **评测放大**：重叠段每个说话人都计分，漏一个说话人就罚一段 CF + MISS；
3. **声学挑战**：重叠段的"混合嵌入"不接近任何单说话人，流水线聚类必然出错；
4. **ASR 联动恶化**：重叠段 ASR WER 通常翻倍以上，"谁说了什么"双重出错。

对策：EEND 类多标签建模、TS-VAD 说话人条件检测、重叠检测单独模块（overlap detection）辅助切分、仿真混合增广训练数据。

## 7. 长音频处理

* **分段处理与全局一致性冲突**：一段数小时的音频不能整体聚类（$O(n^3)$ 复杂度 + 内存），但独立分块聚类会导致"同一人在 chunk-1 是 spk-1、在 chunk-2 是 spk-3"的标签漂移；
* 常用策略：
  1. **滑窗 + 局部聚类 + 全局标签映射**：局部聚类后，用相邻 chunk 的嵌入相似度把局部标签映射回全局标签；
  2. **在线聚类**（online clustering）：按时间顺序逐段嵌入，与已有簇中心比较，超过阈值入新簇，否则归入最接近的簇（资源受限但存在路径依赖）；
  3. **两遍处理（two-pass）**：第一遍快速在线 diarization，第二遍收集全局统计后精化（工业界常用，类似流式 ASR 的 two-pass 设计）；
  4. **recurrent/状态保持端到端模型**：EEND-EDA 长音频版维持 attractor 状态跨块传递。
* **域偏移**：长会议中说话人状态变化（走动、加人减人）、多麦克风切换，需 VB/HMM 类概率平滑或说话人数自动增减机制。

## 8. PyTorch 代码：DER 计算与 EEND 风格损失

```python
import torch
import torch.nn as nn
from itertools import permutations

# ---------------------------------------------------------
# 1. DER 计算 (基于时间区间集合运算)
# ---------------------------------------------------------
def merge_intervals(intervals):
    """合并重叠区间: [(s, e, spk), ...] -> [(s, e, [spks]), ...]"""
    intervals = sorted(intervals, key=lambda x: x[0])
    merged = []
    for s, e, spk in intervals:
        if merged and s <= merged[-1][1]:
            merged[-1] = (merged[-1][0], max(merged[-1][1], e),
                          merged[-1][2] + [spk])
        else:
            merged.append((s, e, [spk]))
    return merged

def compute_der(ref_turns, sys_turns, collar=0.0, frame_step=0.01):
    """
    ref_turns / sys_turns: [(start, end, spk_id), ...] 秒为单位
    collar: 边界容忍(秒)
    """
    ref_m = merge_intervals(ref_turns)
    sys_m = merge_intervals(sys_turns)
    # 构建帧级说话人集合序列
    total = max(e for _, e, _ in ref_m + sys_m)
    n_frames = int(total / frame_step) + 1
    ref_sets = [set() for _ in range(n_frames)]
    sys_sets = [set() for _ in range(n_frames)]
    for s, e, spks in ref_m:
        for f in range(int(s / frame_step), int(e / frame_step)):
            ref_sets[f].update(spks)
    for s, e, spks in sys_m:
        for f in range(int(s / frame_step), int(e / frame_step)):
            sys_sets[f].update(spks)
    fa = miss = cf = 0.0
    for r, s_ in zip(ref_sets, sys_sets):
        fa   += len(s_ - r) * frame_step          # 系统多出的说话人时间 (误归属)
        miss += len(r - s_) * frame_step          # 真实有但系统漏掉的说话人时间
        cf   += 0.0 if r == s_ else len(r ^ s_) * frame_step  # 标签混淆时间
    total_ref = sum(len(r) for r in ref_sets) * frame_step
    return (fa + miss + cf) / total_ref

# ---------------------------------------------------------
# 2. EEND 风格训练: 帧级多标签 BCE + PIT
# ---------------------------------------------------------
def eend_pit_loss(logits, targets):
    """
    logits:  [B, T, K] 帧级说话人激活 logits
    targets: [B, T, K] 0/1 多标签真值 (K 个通道, 顺序与输出可能不一致)
    """
    B, T, K = logits.shape
    best = None
    for perm in permutations(range(K)):
        t = targets[..., list(perm)]           # 重排真值通道
        loss = nn.functional.binary_cross_entropy_with_logits(
            logits.reshape(-1), t.reshape(-1), reduction='mean')
        best = loss if best is None else torch.minimum(best, loss)
    return best

if __name__ == "__main__":
    # EEND 风格前向示意
    B, T, K, D = 2, 300, 3, 80
    feats = torch.randn(B, T, D)
    encoder = nn.LSTM(D, 64, num_layers=2, batch_first=True,
                      bidirectional=True)
    out, _ = encoder(feats)                       # [B, T, 128]
    logits = nn.Linear(128, K)(out)               # [B, T, K]
    targets = (torch.rand(B, T, K) > 0.7).float() # 帧级多标签(含重叠)
    loss = eend_pit_loss(logits, targets)
    print(f"EEND PIT-BCE loss: {loss.item():.4f}")

    # DER 示例
    ref = [(0.0, 5.0, 'A'), (5.0, 10.0, 'B'), (8.0, 10.0, 'A')]  # 8~10s 重叠
    sys = [(0.0, 4.8, 'A'), (5.2, 10.0, 'B')]
    print(f"DER = {compute_der(ref, sys):.4f}")

```

> 注：示例 DER 实现为教学简化（帧级对称差口径），生产评测请使用 `pyannote.metrics` 或 NIST 官方 `md-eval`（含完整的 collar、映射最优说话人对应等逻辑，其中系统标签与真实标签的最优一一映射用匈牙利算法求解）。

## 9. 总结与最佳实践

* **任务本质**：diarization 是"无注册、开集、聚类式"的说话人结构分析，输出只需保持"同类同人"；与声纹验证（1:1）和分离（波形恢复）共享嵌入技术但目标不同。
* **方法选型**：
  * 干净、少重叠、说话人稳定的场景（访谈、双人对话）：VAD + ECAPA 嵌入 + AHC/谱聚类流水线仍是性价比首选；
  * 重叠密集会议：EEND-EDA / TS-VAD 类方法明显占优；
  * 需要"谁说了什么"的最终产品：串联式（ASR 时间戳 + diarization 归属）为主，重叠严重时考虑 target-speaker ASR 一体化。
* **评测要点**：DER 的三分量（FA/MISS/CF）要分开看，重叠比例不同的数据集不可直接比较；注意 collar 设置与说话人数估计口径。
