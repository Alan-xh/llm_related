# 1. 声纹识别与Speaker ID

## 1. 概述

声纹识别（Speaker Recognition）是从语音信号中提取说话人身份信息的技术，核心目标是回答"这段语音是谁说的"。与 ASR 关注"说了什么"（ linguistic content）不同，声纹识别关注的是**说话人特质（speaker traits）**——由声道形状、发音习惯、语速语调等生理与行为特征共同决定。

按任务划分，声纹识别分为两个子任务：

* **说话人辨认（Speaker Identification, SI）**：1:N 闭集问题，从注册库中找出最可能的说话人。
* **说话人验证（Speaker Verification, SV）**：1:1 开集问题，给定一条注册语音（Enrollment）与一条测试语音（Trial），判断二者是否为同一说话人。

工业界声纹系统（支付验证、智能设备唤醒、公安司法鉴定、会议纪要归属）几乎都以 SV 为核心，因为 SI 在开集场景下（库外说话人 impostor 众多）性能急剧退化。

```
                    ┌─────────────────────────────────────┐
  语音 x ──────────>│  前端 (VAD/降噪/特征提取 Fbank)      │
                    └─────────────────────────────────────┘
                                       │
                                       ▼
                    ┌─────────────────────────────────────┐
                    │  说话人编码器 Speaker Encoder        │
                    │  (i-vector / x-vector / ECAPA-TDNN) │
                    └─────────────────────────────────────┘
                                       │
                            声纹向量 (Embedding)
                                       │
                    ┌──────────────────┴──────────────────┐
                    ▼                                     ▼
          ┌───────────────────┐               ┌───────────────────┐
          │ 注册 Enrollment    │               │ 验证 Verification  │
          │ 提取并存储声纹模板 │               │ cosine 打分 + 阈值 │
          └───────────────────┘               └───────────────────┘

```

技术演进主线：**GMM-UBM → i-vector（因子分析）→ d-vector → x-vector → ECAPA-TDNN / ResNet / CAM++ / 说话人 Transformer**，本质是从"统计生成式建模"走向"深度判别式表征学习"。

## 2. 经典时代：GMM-UBM 与 i-vector

### 2.1 GMM-UBM 框架

**通用背景模型（Universal Background Model, UBM）**是用海量多人语音训练的一个大规模高斯混合模型（通常 512~2048 个分量），刻画"所有人共享的语音空间分布"：

$$p(x \mid \lambda_{\text{UBM}}) = \sum_{c=1}^{C} w_c \, \mathcal{N}(x \,;\, \mu_c, \Sigma_c)$$

目标说话人的模型通过对 UBM 做**最大后验自适应（MAP Adaptation）**得到——只自适应均值向量：

$$\hat{\mu}_c = \alpha_c \frac{\sum_i \gamma_c(x_i)\, x_i}{\sum_i \gamma_c(x_i)} + (1 - \alpha_c)\, \mu_c^{\text{UBM}}$$

其中 $\gamma_c(x_i)$ 是帧 $x_i$ 对分量 $c$ 的后验占用率（responsibility），$\alpha_c = \frac{N_c}{N_c + r}$ 是数据相关的自适应系数（$r$ 为相关性因子，常取 16）。说话人间的差异被压缩到所有高斯均值拼接成的**超向量（Supervector，维度 $M = C \times F$，如 512 × 60 = 30720 维）**中，验证时用似然比打分。缺点：参数量巨大、与说话人无关，且 supervector 冗余度极高。

### 2.2 i-vector：联合因子分析

i-vector（identity vector, 2011 年提出）是深度学习之前声纹领域的统治性框架。核心思想是把说话人 supervector 建模为一个**低维隐变量**的线性生成：

$$M = m + T w$$

* $M$：说话人 supervector（含信道因素）
* $m$：UBM 均值 supervector（与说话人、信道无关的"原点"）
* $T$：**全局差异空间矩阵（Total Variability Matrix）**，维度 $M \times R$（$R$ 常取 400~600）
* $w \sim \mathcal{N}(0, I)$：总变异隐变量，其最大后验估计即为 i-vector

训练 $T$ 的过程与训练 UBM 类似，只是 EM 的统计量计算从"按分量聚帧"改为"按总变异空间投影"。得到 i-vector 后，传统流水线还要做：

1. **信道补偿**：LDA（类内方差最小化、类间方差最大化）+ WCCN（Within-Class Covariance Normalization），消除信道（麦克风/电话）差异；
2. **PLDA 打分**：概率线性判别分析，将 i-vector 建模为说话人空间 + 信道空间的高斯生成模型，输出对数似然比作为验证分数。

```
i-vector 流水线:
语音 ──> UBM posterior 统计量 ──> Total Variability T ──> i-vector (400~600维)
        ──> LDA / WCCN 降维去信道 ──> PLDA 打分 ──> 似然比判决

```

> **面试要点**：i-vector 是无监督/生成式的（不需要说话人标签训练 $T$，PLDA 才用标签），而 x-vector 之后全部是判别式深度模型；这也是 EER 从 ~5% 降到 <2% 的分水岭（VoxCeleb1 测试集量级）。

## 3. 深度学习时代：从 d-vector 到 CAM++

### 3.1 三种嵌入范式对比

| 模型 | 年代 | 网络结构 | 嵌入提取方式 | 特点 |
| --- | --- | --- | --- | --- |
| **i-vector** | 2011 | GMM-FA + PLDA | 统计后验 MAP 估计 | 生成式，短语音性能崩塌 |
| **d-vector** | 2014 | DNN（帧级分类） | 所有帧嵌入做平均 | 需要先训分类器，text-dependent 唤醒词场景常用 |
| **x-vector** | 2018 | TDNN + statistics pooling | 帧级 TDNN → 统计池化 → 段级 FC | 判别式端到端训练的开山之作 |
| **ECAPA-TDNN** | 2020 | TDNN + SE-Res2Net + Attentive-StatPool | 通道注意力 + 多层特征聚合 | 长期是开源 SOTA 基线 |
| **ResNet / Res2Net** | 2019~ | 2D 卷积残差网络 | 帧级特征平均池化 | 简单稳定，工业部署广泛 |
| **CAM++** | 2022 | ResNet + 上下文感知掩码 (CAM) 池化 | 学习时域注意力权重池化 | WeSpeaker/3D-Speaker 主力模型 |

### 3.2 x-vector：统计池化的关键设计

x-vector 的核心贡献是**将帧级特征转换为段级（utterance-level）嵌入的统计池化（Statistics Pooling）**：对帧级输出 $h_t$ 计算均值与标准差拼接：

$$\mu = \frac{1}{T}\sum_{t=1}^{T} h_t, \quad \sigma = \sqrt{\frac{1}{T}\sum_{t=1}^{T} (h_t - \mu)^2}, \quad f = [\mu; \sigma]$$

拼接后的 $f$ 经过段级 FC 层得到 x-vector（192 维），再接 softmax 分类损失训练。推理时丢弃分类头，x-vector 即声纹表征。

### 3.3 ECAPA-TDNN 详解

ECAPA-TDNN（Emphasized Channel Attention, Propagation and Aggregation in TDNN）在 x-vector 基础上做了三点增强：

```
Fbank (80维) ──> SE-Res2Block x3 (1D-Conv + SE通道注意力 + Res2Net多尺度)
                        │ (多层特征聚合 MFA: 拼接三层中间输出)
                        ▼
              Attentive Statistics Pooling (注意力统计池化)
                        │
                        ▼
              FC -> BN -> AAM-Softmax 训练 / L2-norm 后即 192维声纹向量

```

1. **SE-Res2Block**：引入 Squeeze-Excitation 通道注意力与 Res2Net 分层卷积（感受野呈组合式扩张，参数量低于大核卷积）；
2. **多层特征聚合（Multi-Layer Feature Aggregation, MFA）**：拼接多个 SE-Res2Block 的输出再池化，兼顾浅层细节与深层语义；
3. **注意力统计池化（Attentive Statistics Pooling）**：用一个小的 NN 计算每帧的注意力分数 $\alpha_t$，再做加权均值与加权标准差：

$$e_t = v^\top \tanh(W h_t + b), \quad \alpha_t = \frac{\exp(e_t)}{\sum_{\tau} \exp(e_\tau)}$$

$$\tilde{\mu} = \sum_t \alpha_t h_t, \quad \tilde{\sigma} = \sqrt{\sum_t \alpha_t (h_t - \tilde{\mu})^2}$$

其动机是：语音中的静音、噪声帧不应与有效语音帧同权重，注意力让池化聚焦于判别性强的帧。

### 3.4 CAM++ 与 Transformer 变体

* **CAM++**：用**上下文感知掩码（Context-Aware Masking）池化**替代 ASP——先生成一组可学习的全局 query，对各帧计算注意力掩码，天然支持流式与变长输入，且在多语种大数据上稳定性优于 ASP。
* **说话人 Transformer**：以 Conformer/SimAM Transformer 为 encoder，帧级自注意力建模长程说话人特性；缺点是全注意力计算量大，工业界多与 TDNN/ResNet 混用。
* 工业界的实际选择往往是 **ResNet34/ResNet101 + ASP/CAM 池化**：纯卷积对时移鲁棒、易于流式化与量化部署（VoxCeleb1-O EER 可达 0.7%~1.0% 量级，参考 WeSpeaker 训练方案）。

## 4. 损失函数：从 Triplet 到 ArcFace/AAM-Softmax

### 4.1 分类损失的基础地位

说话人嵌入通常以分类任务训练：训练集 $N$ 个说话人，最后一层 softmax 输出说话人 ID。交叉熵在网络收敛后丢弃分类头，嵌入层的类间几何结构即为声纹空间。但普通 softmax 的嵌入不具判别性（类内散布大），因此发展出一系列**度量学习损失（metric learning loss）**。

### 4.2 Triplet Loss

$$\mathcal{L}_{\text{tri}} = \max\big(0,\; d(a, p) - d(a, n) + \alpha\big)$$

* anchor $a$、正样本 $p$（同说话人）、负样本 $n$（异说话人），$\alpha$ 为 margin
* 关键在**难例挖掘（hard mining）**：随机采样三元组大多满足约束（loss=0），需在线挑 $d(a,n)$ 最小的 semi-hard negative，否则收敛慢、性能差
* 缺点：对 batch 构造敏感、收敛慢，现已少作为主损失，多与分类损失联用

### 4.3 AAM-Softmax（ArcFace）公式推导

**CosFace / AM-Softmax** 先把 logits 归一化为余弦相似度再加 margin：

$$\mathcal{L}_{\text{cos}} = -\frac{1}{N}\sum_i \log \frac{e^{s(\cos\theta_{y_i} - m)}}{e^{s(\cos\theta_{y_i} - m)} + \sum_{j \ne y_i} e^{s \cos\theta_j}}$$

**ArcFace（Additive Angular Margin）** 则把 margin 加在**角度空间**：

$$\mathcal{L}_{\text{arc}} = -\frac{1}{N}\sum_i \log \frac{e^{s \cdot \cos(\theta_{y_i} + m)}}{e^{s \cdot \cos(\theta_{y_i} + m)} + \sum_{j \ne y_i} e^{s \cos\theta_j}}$$

推导要点：

1. 归一化权重与特征：$W_j^\top x = \|W_j\| \|x\| \cos\theta_j \Rightarrow \cos\theta_j = \hat{W}_j^\top \hat{x}$；
2. 用 $s$（scale，常取 32）缩放余弦值以弥补归一化导致的 logit 值域压缩；
3. 目标类角度加 $m$（margin，常取 0.2~0.5），等价于在单位超球面上**把同类样本收紧到一个更小的角锥中**，几何意义比加性 margin 更清晰；
4. 训练时 $\theta_{y_i} + m$ 可能超出 $[0, \pi]$ 导致梯度异常，需做 $\cos$ 单调区间裁剪（AAM-Softmax 论文即 ArcFace 在声纹上的直接应用，VoxCeleb 上典型配置 $s=32, m=0.2$）。

### 4.4 损失函数对比

| 损失 | margin 空间 | 优点 | 缺点 |
| --- | --- | --- | --- |
| Softmax CE | 无 | 训练稳定 | 类内散布大，验证泛化弱 |
| Triplet | 欧氏/余弦距离 | 不依赖分类头、类数可增长 | 采样复杂、收敛慢 |
| CosFace/AM-Softmax | 余弦（加性） | 简单有效 | 边界几何意义较间接 |
| **AAM-Softmax (ArcFace)** | 角度（加性角度） | 测地距离意义清晰、SOTA 标配 | 对 $s, m$ 超参敏感 |

## 5. Text-Dependent vs. Text-Independent

| 维度 | Text-Dependent（文本相关） | Text-Independent（文本无关） |
| --- | --- | --- |
| **约束** | 注册与测试必须说同一内容（如唤醒词、密码） | 内容任意 |
| **信息利用** | 文本一致 → 差异全部来自说话人，等错误率更低（EER 可低至 0.1% 量级） | 需同时抑制文本内容干扰，EER 通常 1%~3% |
| **典型场景** | "Hi Siri" 唤醒词声纹确认、声纹支付 | 会议归属、司法鉴定、检索 |
| **短语音鲁棒性** | 1~2 秒固定短语即可 | 测试语音过短（<3 秒）时嵌入估不准，性能显著下降 |
| **安全性** | 易受语音合成/拼接攻击（攻击面固定） | 攻击难度更高，但系统仍需反欺骗模块 |

> **实践细节**：text-dependent 系统常用 d-vector + 帧对齐（DTW）或直接用注册短语的模板匹配；text-independent 系统是 x-vector/ECAPA 的主战场，需要长语音（注册 10s+，测试 5s+）才能稳定。

## 6. 评估指标：EER 与 minDCF

### 6.1 混淆矩阵与 DET 曲线

SV 是二分类问题（target / non-target），调节判决阈值 $\tau$ 可得一系列 FPR/TPR，绘制 **DET 曲线（Detection Error Tradeoff）**（横轴 FPR、纵轴 FNR，正常化坐标下接近直线）。

### 6.2 EER（Equal Error Rate）

**等错误率**：错误接受率（FAR，冒认者被接受）与错误拒绝率（FRR，真实说话人被拒绝）相等时的错误率。数值上解方程：

$$\text{FAR}(\tau^\*) = \text{FRR}(\tau^\*) = \text{EER}$$

EER 与代价、先验无关，是学术 benchmark（VoxCeleb、CN-Celeb）的标准指标。数值量级参考：VoxCeleb1-O 上 i-vector/PLDA ≈ 5.4%，ECAPA-TDNN ≈ 0.8~0.9%，ResNet + AAM-Softmax + 大数据 ≈ 0.7%。

### 6.3 minDCF（Minimum Detection Cost Function）

NIST SRE 定义的应用代价函数，模拟真实业务（司法/安防）中两类错误的代价不对称：

$$C_{\text{DET}} = C_1 \cdot P_{\text{miss}} + C_2 \cdot P_{\text{fa}}$$

归一化并取阈值扫描下的最小值：

$$\text{minDCF} = \min_\tau \frac{C_1 P_{\text{miss}}(\tau) + C_2 P_{\text{fa}}(\tau)}{C_1 P_{\text{target}} + C_2 (1 - P_{\text{target}})}$$

典型配置 $C_1 = 10, C_2 = 1, P_{\text{target}} = 0.01$（漏接代价远大于误接，且冒认远多于真目标）。**面试常问**：EER 低不代表 minDCF 低，minDCF 关注 DET 曲线低 FPR 端的形态，score normalization 对低 FPR 端改善尤其明显。

## 7. Score Normalization：AS-Norm

验证分数的绝对值依赖测试语音与冒认人群的分布，不同 trial 之间不可比。**自适应得分归一化（Adaptive Score Normalization, AS-Norm）**为每个测试对估计一个局部分数分布：

$$s'_{\text{norm}} = \frac{s - \mu_{\text{imp}}}{\sigma_{\text{imp}}}$$

AS-Norm 的工程做法：

1. 准备一个**冒认语料库（cohort）**（与注册/测试说话人无关的几百~几千条语音）；
2. 对每个测试 embedding，取 cohort 中与其**最相似的 top-N**（如 N=600，自适应地排除 cohort 中本身和测试很像的"伪 target"）计算 $\mu, \sigma$；对注册 embedding 同样操作；
3. 用两侧归一化参数的均值归一化最终分数。

| 归一化方法 | 思路 | 适用 |
| --- | --- | --- |
| Z-norm | 全局冒认分布归一化 | 简单，对 cohort 敏感 |
| T-norm | 按测试语音自适应 | 更贴合 trial |
| **AS-Norm** | top-N 自适应 cohort，两侧归一化 | 工业/竞赛标配，EER 相对降 5%~15% |

## 8. 声纹注册与验证全流程（工业实践）

```
【离线训练】
海量说话人数据 (VoxCeleb2 ~6100人 / 内部 10k+人)
  ──> 数据增广: 加性 MUSAN 噪声 + RIR 混响 (速度扰动 0.9/1.0/1.1)
  ──> ECAPA/CAM++ + AAM-Softmax 训练
  ──> 大-margin 微调 (margin 0.0 -> 0.5 递增)

【注册 Enrollment】
用户语音 (10~30s, 过 VAD)
  ──> 切分多段分别提嵌入 ──> L2 归一化 ──> 平均/存储模板 (可选多模板)

【验证 Verification】
测试语音 (3~10s) ──> 提嵌入 ──> 与模板 cosine 打分 ──> AS-Norm
  ──> 与阈值 τ 比较 ──> 接受 / 拒绝 (阈值按业务 EER 点或 minDCF 点选取)

```

工程要点：

* **数据增广必不可少**：加性噪声（MUSAN）、房间脉冲响应（RIR）与速度扰动可带来相对 10%~20% 的 EER 下降；
* **注册语音质量门控**：信噪比、时长、VAD 语音占比不合格时拒绝注册并引导重录，远比事后打分补偿有效；
* **嵌入维度与后端**：主流 192~256 维；cosine + AS-Norm 已基本取代 PLDA（深度嵌入在 cosine 空间已线性可分）;
* **反欺骗（Anti-spoofing）**：声纹支付类系统必须叠加语音合成/转换/重放检测模块（如 AASIST），否则 TTS 克隆语音可直接攻破验证。

## 9. PyTorch 代码：AAM-Softmax 与 ECAPA 风格池化

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class AAMSoftmax(nn.Module):
    """Additive Angular Margin Softmax (ArcFace), 声纹标准分类头"""
    def __init__(self, emb_dim=192, n_classes=1000, s=32.0, m=0.2):
        super().__init__()
        self.s = s
        self.m = m
        self.weight = nn.Parameter(torch.randn(n_classes, emb_dim))
        nn.init.xavier_uniform_(self.weight)
        self.cos_m = math.cos(m)
        self.sin_m = math.sin(m)
        self.th = math.cos(math.pi - m)   # cos 单调区间裁剪下界
        self.mm = math.sin(math.pi - m) * m

    def forward(self, embeddings, labels):
        # embeddings: [B, D] (已L2归一化), labels: [B]
        cosine = F.linear(F.normalize(embeddings), F.normalize(self.weight))  # [B, C]
        sine = torch.sqrt((1.0 - cosine ** 2).clamp(min=1e-8))
        # cos(theta + m) = cos(theta)cos(m) - sin(theta)sin(m)
        phi = cosine * self.cos_m - sine * self.sin_m
        phi = torch.where(cosine > self.th, phi, cosine - self.mm)  # 数值稳定裁剪
        one_hot = F.one_hot(labels, num_classes=cosine.size(1)).float()
        logits = one_hot * phi + (1.0 - one_hot) * cosine
        logits *= self.s
        return F.cross_entropy(logits, labels)


class AttentiveStatPooling(nn.Module):
    """ECAPA-TDNN 注意力统计池化"""
    def __init__(self, in_dim=512, hidden=128):
        super().__init__()
        self.score = nn.Sequential(
            nn.Linear(in_dim, hidden), nn.Tanh(),
            nn.Linear(hidden, 1)
        )

    def forward(self, x, lengths=None):
        # x: [B, T, D]
        e = self.score(x)                              # [B, T, 1]
        if lengths is not None:                        # mask 掉 padding 帧
            mask = torch.arange(x.size(1), device=x.device)[None, :] < lengths[:, None]
            e = e.masked_fill(~mask.unsqueeze(-1), float('-inf'))
        alpha = F.softmax(e, dim=1)                    # [B, T, 1]
        mu = (alpha * x).sum(dim=1)                    # [B, D]
        var = (alpha * (x - mu.unsqueeze(1)) ** 2).sum(dim=1)
        return torch.cat([mu, torch.sqrt(var.clamp(min=1e-8))], dim=-1)  # [B, 2D]


if __name__ == "__main__":
    B, T, D, C = 4, 200, 512, 500
```

## 10. 总结与最佳实践

* **演进主线**：GMM-UBM（生成式，supervector 冗余）→ i-vector + PLDA（总变异空间压缩，短语音崩塌）→ x-vector（统计池化 + 判别训练）→ ECAPA-TDNN / ResNet / CAM++（注意力池化 + AAM-Softmax，EER 进入 1% 以内）。
* **损失函数是声纹表征的灵魂**：AAM-Softmax 在角度空间收紧类内、推开类间，是当前所有主流方案的标配；Triplet 多用于无分类头或持续学习场景。
* **评估要看双指标**：EER 衡量整体 DET 形态，minDCF 衡量低误报端的业务代价，二者对 score normalization 的敏感度不同。
* **工业落地 checklist**：强数据增广（MUSAN/RIR/速度扰动）、注册质量门控、AS-Norm 分数归一化、按业务代价选阈值、必须叠加 anti-spoofing 模块防 TTS 攻击。
* **与相邻任务的接口**：声纹嵌入是 diarization（说话人日志）与 target-speaker 提取/ASR（个性化识别）的基础组件，后两篇文档将展开。
