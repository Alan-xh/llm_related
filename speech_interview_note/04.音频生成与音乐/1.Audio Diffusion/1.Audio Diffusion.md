# 1. Audio Diffusion

## 1. 概述

**扩散模型（Diffusion Model）** 是 2020 年后音频生成领域最重要的生成范式之一。其核心思想是：定义一个逐步加噪声的前向过程将真实音频样本破坏成高斯噪声，再训练一个神经网络学习**逆转该过程**，从纯噪声出发逐步去噪还原出音频。

相比 GAN 的对抗训练（模式坍塌、训练不稳定）与自回归模型的逐 Token 生成（误差累积、推理串行），扩散模型具有：

* **训练稳定**：目标函数是简单的 MSE 去噪损失，无对抗博弈；
* **生成质量高**：在语音波形（DiffWave）、歌声（DiffSinger）、通用音频（AudioLDM）上均达到或超过 GAN 水平；
* **灵活的条件机制**：文本、Mel 谱、phoneme 等条件均可注入。

其代价是**迭代采样步数多导致的推理慢**，由此催生了 DDIM、DPM-Solver 等采样加速方法，以及 Stable Audio / AudioLDM 的 **Latent Diffusion** 路线（在低维隐空间而非像素/波形级做扩散）。

```
音频生成三大范式:

  GAN:          噪声 z ──> [Generator] ──> 音频   (一步生成, 对抗训练)
  Autoregressive:  token ──> [LM] ──> token ──> [Vocoder/Codec] ──> 音频  (逐 Token 生成)
  Diffusion:    噪声 x_T ──> [Denoise] ──> x_{T-1} ──> ... ──> x_0 ──> 音频  (迭代去噪)

```

## 2. DDPM 原理回顾

DDPM（Denoising Diffusion Probabilistic Models, Ho et al. 2020）是音频扩散模型的理论基础。

### 2.1 前向过程（加噪）

对真实音频样本 $x_0 \sim q(x_0)$（波形或 Mel 谱），定义 $T$ 步（典型 $T=1000$）马尔可夫加噪过程，每步加一小份高斯噪声：

$$q(x_t \mid x_{t-1}) = \mathcal{N}(x_t;\ \sqrt{1-\beta_t}\, x_{t-1},\ \beta_t \mathbf{I})$$

其中 $\beta_1, \dots, \beta_T$ 为噪声调度（noise schedule），$\beta_t \ll 1$。令 $\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$，则任意步 $t$ 可以**一步采样**得到（这是训练高效的关键）：

$$q(x_t \mid x_0) = \mathcal{N}(x_t;\ \sqrt{\bar{\alpha}_t}\, x_0,\ (1-\bar{\alpha}_t)\mathbf{I}), \quad x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1-\bar{\alpha}_t}\, \epsilon, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$$

当 $t \to T$ 时，$\bar{\alpha}_T \to 0$，$x_T$ 近似为标准高斯噪声。

### 2.2 逆向过程（去噪）

逆向过程也是马尔可夫的，其每步转移被参数化为高斯分布：

$$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}(x_{t-1};\ \mu_\theta(x_t, t),\ \Sigma_\theta(x_t, t))$$

$$p_\theta(x_{0:T}) = p(x_T) \prod_{t=1}^{T} p_\theta(x_{t-1} \mid x_t), \quad p(x_T) = \mathcal{N}(0, \mathbf{I})$$

### 2.3 噪声预测目标与 Loss

推导变分下界（ELBO）后，训练目标可化简为极其简洁的形式——**让网络从加噪样本中预测当初加入的噪声 $\epsilon$**：

$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{x_0, \epsilon, t}\Big[ \big\| \epsilon - \epsilon_\theta(x_t, t, \mathbf{c}) \big\|^2 \Big], \quad t \sim \mathcal{U}\{1, T\}$$

其中 $\mathbf{c}$ 为可选条件（文本 embedding、Mel 谱等）。已知 $\epsilon_\theta$ 后，逆向均值有闭式解：

$$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\Big( x_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}} \epsilon_\theta(x_t, t) \Big)$$

采样时：$x_{t-1} = \mu_\theta(x_t, t) + \sigma_t z,\ z \sim \mathcal{N}(0, \mathbf{I})$，$\sigma_t = \sqrt{\beta_t}$。

> **等价目标**：除 $\epsilon$-prediction 外，还有预测 $x_0$（x0-prediction）与预测速度场 $v = \alpha_t \epsilon - \sigma_t x_0$（v-prediction，Stable Diffusion 2 / AudioLDM 采用，数值上更稳定）。

## 3. 噪声调度（Noise Schedule）

### 3.1 Linear 与 Cosine 调度

| 调度 | 定义 | 特点 | 代表模型 |
| --- | --- | --- | --- |
| **Linear** | $\beta_t$ 从 $\beta_1=10^{-4}$ 线性增至 $\beta_T=0.02$ | 实现简单；末期 $\bar\alpha_t$ 过快趋于 0，信息破坏太彻底 | DDPM、DiffWave |
| **Cosine** | $\bar{\alpha}_t = \frac{f(t)}{f(0)},\ f(t)=\cos^2\!\Big(\frac{t/T + s}{1+s}\cdot\frac{\pi}{2}\Big),\ s=0.008$ | 中间阶段加噪更平缓，末端保留更多信息，训练更稳定 | iDDPM、AudioLDM |
| **Sqrt / Sigmoid** | 针对 waveform 幅度分布设计 | 音频波形稀疏、尖峰多，需要更陡的早期调度 | WaveGrad、DiffWave 变体 |

### 3.2 音频特有的调度问题

* **波形 vs Mel 谱**：原始波形幅值分布集中在 0 附近（尖峰稀疏），linear 调度下低噪声阶段（小 $t$）信噪比已经很高，模型学不到东西；DiffWave 发现在 waveform 级使用 **$\beta$ 上界更大的噪声调度**（如 nosied schedule 上界 0.05+）效果更好。
* **连续时间调度**：将离散 $t$ 推广为连续 $t \in [0,1]$（Score-based SDE 视角），便于用 DPM-Solver 等 ODE Solver 加速。
* **训推调度可解耦**：WaveGrad 提出训练时随机采样多组调度、推理时可以调整迭代步数（50/25/甚至 4 步），实现质量-速度 trade-off，这一思想影响了后续所有快速音频扩散系统。

## 4. 扩散模型在音频上的经典应用

### 4.1 WaveGrad 与 DiffWave（波形级 vocoder）

两者（2020 年底同期工作）首次证明扩散可以做**神经声码器（Neural Vocoder）**，质量匹敌 HiFi-GAN：

* **WaveGrad**（NVIDIA）：以 Mel 谱为条件，U-Net 结构预测噪声；支持可变推理步数。
* **DiffWave**（Microsoft）：**非自回归**的空洞卷积 backbone，以 Mel 谱为条件；生成 22.05 kHz 波形，MOS 可达 4.44（GT 为 4.56）。其核心卖点：扩散 vocoder 没有 GAN 的模式坍塌，对小数据集更鲁棒。

### 4.2 Diff-TTS / Grad-TTS（频谱级 TTS）

* **Grad-TTS**（2021）：将文本 encoder 输出作为逆向过程每步的均值先验（类似 Glow-TTS 的单调对齐），在 Mel 谱上做扩散，速度可与 FastSpeech 系竞争。
* **Diff-TTS**：以 phoneme 为条件在 Mel 上扩散，非自回归并行生成，规避了自回归 TTS 的注意力失败问题。

### 4.3 DiffSinger（歌声合成 / SVS）

* DiffSinger（2022, CVPR）在**Mel 谱**上做扩散，条件为 phoneme/音素时长与乐谱（音高、节拍）；
* 采样 100 步可超过 FastSpeech 系基线，64 步几乎无损；后续版本引入 **浅层扩散（shallow diffusion）**：先用快速网络生成粗略 Mel，再从中间步 $t_0 \ll T$ 开始扩散精修高频细节，把推理压到个位数步；
* 与 GAN 声码器（HiFi-GAN）级联组成完整歌声合成流水线。

```
DiffSinger 浅层扩散:

乐谱/歌词 ──> [Length Regulator] ──> [Encoder] ──> 条件 c ──┐
                                                            ▼
                    粗略 Mel (aux decoder) ──> 加噪到 t0 ──> [Diffusion] ──> 精修 Mel ──> [Vocoder] ──> 歌声

```

## 5. Latent Diffusion：Stable Audio 与 AudioLDM 系列

### 5.1 为什么需要 Latent Diffusion

波形（44.1 kHz、立体声、分钟级）维度极高：1 分钟音频 ~ 5M 采样点。直接做扩散，U-Net 每步都要在百万维张量上运行数百次，不可行。**Latent Diffusion（LDM）** 先用预训练的自编码器（VAE）把音频压缩到隐空间（压缩比几十倍），在隐空间扩散，生成后再解码回波形/频谱。

### 5.2 AudioLDM 系列（HaoAI / 北大）

* **AudioLDM**（2023）：文本条件，VAE 压缩 Mel 谱到隐空间（降采样率 $4\times$ 时间、隐维 8），扩散 backbone 为 U-Net + **cross-attention** 注入 CLAP/T5 文本 embedding；首次在文本到音频上做到"generate once, eval everywhere"（推理 25 步内）。
* **AudioLDM 2**（2023）：提出**双前置表示学习**——用同一个自编码器同时对齐 *文本* 与 *音频* 到共享隐空间，并引入 GPT-2 风格的"语言建模自解码器"（LMA-D）作为桥梁，统一 TTS、TTM（text-to-music）、TTA（text-to-audio）三大任务。

### 5.3 Stable Audio（Stability AI）

* **Stable Audio（2023）**：专为**音乐/音效**设计的 latent diffusion：
  * Codec：**CRESCENDO / VAE over 41 Hz latent**，支持 44.1 kHz 立体声，时间压缩约 1024 倍量级（下采样至约 41 Hz 帧率）；
  * 条件：文本经 CLAP 文本编码器 + 时间条件（音频起始/结束秒数），使模型可生成**指定时长**（最长 47 秒，训练窗 30 秒）；
  * Backbone：DiT 风格 U-Net + cross-attention；
  * 采样 100 步（DPM-Solver ++ 后续版本 4~20 步即可），单卡 A100 实时率远超实时。
* **Stable Audio Open 1.5 / Stable Audio 2.0（2024）**：升级为扩散 Transformer（DiT）+更大规模数据（含 licensed 音乐），支持最长 3 分钟结构与 upscaling。

```
Latent Diffusion 总体架构:

  文本 ──> [Text Encoder (CLAP/T5/FLAN-T5)] ──> 条件向量 c
                                                    │ cross-attention
                                                    ▼
  训练: 音频 ──> [VAE Encoder] ──> z0 ──(加噪)──> zt ──> [U-Net / DiT] ──> 预测噪声
  推理: zT ~ N(0,I) ──> [去噪 x N 步] ──> z0 ──> [VAE Decoder] ──> 波形

```

## 6. 采样加速：DDIM 与 DPM-Solver

### 6.1 DDIM（Denoising Diffusion Implicit Models）

DDIM 推导出一族**非马尔可夫**的等价生成过程，令采样确定性（$\sigma_t = 0$）且可**跳步**：

$$x_{t-1} = \sqrt{\bar{\alpha}_{t-1}}\, \underbrace{\Big( \frac{x_t - \sqrt{1-\bar{\alpha}_t}\,\epsilon_\theta}{\sqrt{\bar{\alpha}_t}} \Big)}_{\text{预测的 } \hat{x}_0} + \sqrt{1-\bar{\alpha}_{t-1}}\, \epsilon_\theta$$

* 取步长子序列（如 1000 步中均匀采 50 步），1000 → 50 步质量几乎不降；音频 vocoder 场景 10 步可用。
* 确定性采样使同一 latent 可复现同一音频（编辑/插值的基础）。

### 6.2 DPM-Solver / DPM-Solver++

将扩散 SDE 转为 ODE 后，其解具有**半线性（semi-linear）结构**：

$$\frac{d x_t}{d t} = f(t) x_t + g(t)^2 \nabla_{x_t} \log p_t(x_t)$$

DPM-Solver 对噪声项做指数积分的解析近似，仅需求解一个线性子问题：

* **DPM-Solver（2M / 3M）**：10~15 步达到 DDIM 50 步质量；
* **DPM-Solver++**：预测 $x_0$ 版本更稳定，Stable Audio / AudioLDM 2 默认使用，**8~20 步生成音频**；
* 工业界实践：`diffusers` 库 `DPMSolverMultistepScheduler` 一行替换即可。

### 6.3 其它加速手段（面试加分点）

| 方法 | 思路 | 音频代表 |
| --- | --- | --- |
| 蒸馏（Progressive Distillation） | 教师多步 → 学生减半步，迭代蒸馏 | Consistency 模型思想 |
| Consistency Models | 一步直接映射到 $x_0$ | 语音编辑、codec latent 一步生成 |
| Rectified Flow / Flow Matching | 学习直线概率流，少步采样 | Stable Audio 2.0 后期版本、F5-TTS |
| Speculative / 并行采样 | 利用音频冗余并行去噪 | SpecGrad 等 |

## 7. 连续生成 vs. 离散生成

| 维度 | 连续扩散（Diffusion / Flow） | 离散自回归（Codec + LM） |
| --- | --- | --- |
| **建模对象** | 连续波形 / Mel / VAE latent | RVQ 离散 token（EnCodec / SoundStream） |
| **生成方式** | 全局迭代去噪（非自回归） | 逐 Token 左到右 |
| **长序列一致性** | 受 U-Net 感受野与训练时长限制（<1 min 常见） | 可借 LLM 长上下文建模分钟级结构 |
| **推理速度** | 10~50 步去噪，并行可调 | 与 token 数线性，kv-cache 加速 |
| **可编辑性** | 确定性 DDIM 支持 latent 插值/编辑 | 离散难以连续插值 |
| **与 LLM 生态结合** | 弱 | 强（天然兼容 Transformer LM） |
| **代表** | DiffWave、AudioLDM、Stable Audio | AudioLM、MusicGen、VALL-E |

> **趋势**：两条路线在融合——AR 生成粗粒度/语义层，Diffusion 精修细节（如 Voicebox 的 Flow Matching + infilling、MusicGen 的 codec + 可选 diffusion 上采样）。

## 8. PyTorch 代码实战：简化版音频 DDPM

以下实现一个可在 Mel 谱（或任意连续特征）上训练的条件 DDPM，包含 linear/cosine 调度与 DDIM 采样：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class GaussianDiffusion(nn.Module):
    def __init__(self, timesteps: int = 1000, schedule: str = "cosine"):
        super().__init__()
        self.T = timesteps
        if schedule == "linear":
            betas = torch.linspace(1e-4, 0.02, timesteps)
        elif schedule == "cosine":
            # Nichol & Dhariwal iDDPM cosine schedule
            s = 0.008
            steps = torch.arange(timesteps + 1, dtype=torch.float64)
            f = torch.cos(((steps / timesteps) + s) / (1 + s) * math.pi / 2) ** 2
            alphas_bar = f / f[0]
            betas = 1 - (alphas_bar[1:] / alphas_bar[:-1])
            betas = betas.clamp(1e-8, 0.999)
        else:
            raise ValueError(schedule)

        self.register_buffer("betas", betas.float())
        self.register_buffer("alphas", 1.0 - betas.float())
        self.register_buffer("alphas_cumprod", torch.cumprod(1.0 - betas.float(), dim=0))
        self.register_buffer("sqrt_ac", torch.sqrt(self.alphas_cumprod))
        self.register_buffer("sqrt_omac", torch.sqrt(1.0 - self.alphas_cumprod))

    def q_sample(self, x0: torch.Tensor, t: torch.Tensor, noise: torch.Tensor):
        """前向过程: 一步采样 x_t = sqrt(ac_t)*x0 + sqrt(1-ac_t)*eps"""
        shape = (x0.size(0),) + (1,) * (x0.dim() - 1)
        return (
            self.sqrt_ac[t].view(shape) * x0
            + self.sqrt_omac[t].view(shape) * noise
        )

    def loss(self, net: nn.Module, x0: torch.Tensor, cond: torch.Tensor = None):
        """简化版 DDPM 训练目标: ||eps - eps_theta(x_t, t, c)||^2"""
        B = x0.size(0)
        t = torch.randint(0, self.T, (B,), device=x0.device).long()
        noise = torch.randn_like(x0)
        x_t = self.q_sample(x0, t, noise)
        eps_pred = net(x_t, t, cond)
        return F.mse_loss(eps_pred, noise)

    @torch.no_grad()
    def ddim_sample(self, net: nn.Module, shape, cond=None, steps: int = 50):
        """DDIM 确定性跳步采样"""
        device = self.betas.device
        # 均匀抽取步长子序列, 例如 1000 步中取 50 步
        step_idx = torch.linspace(0, self.T - 1, steps, dtype=torch.long)
        x = torch.randn(shape, device=device)
        for i in reversed(range(steps)):
            t = torch.full((shape[0],), int(step_idx[i]), device=device, dtype=torch.long)
            t_prev = int(step_idx[i - 1]) if i > 0 else 0
            eps = net(x, t, cond)
            ac_t = self.alphas_cumprod[t].view(-1, 1, 1)
            ac_prev = self.alphas_cumprod[t_prev].view(-1, 1, 1)
            # 预测 x0 (clipped 提升稳定性)
            x0_pred = (x - torch.sqrt(1 - ac_t) * eps) / torch.sqrt(ac_t)
            x0_pred = x0_pred.clamp(-1, 1)
            x = torch.sqrt(ac_prev) * x0_pred + torch.sqrt(1 - ac_prev) * eps
        return x0_pred


class TinyCondUNet(nn.Module):
    """演示用 1D U-Net (实际工程用 ResNet/WaveNet/DiT blocks)"""

    def __init__(self, channels: int = 64, cond_dim: int = 128):
        super().__init__()
        self.time_embed = nn.Sequential(
            nn.Linear(64, cond_dim), nn.SiLU(), nn.Linear(cond_dim, cond_dim)
        )
        # Sinusoidal timestep embedding
        self.register_buffer("freqs", 2 ** torch.arange(6).float() * math.pi)
        self.proj_in = nn.Conv1d(channels, 128, 1)
        self.proj_out = nn.Conv1d(128, channels, 1)
        self.blocks = nn.ModuleList(
            [nn.Sequential(nn.Conv1d(128, 128, 5, padding=2), nn.SiLU(),
                           nn.Conv1d(128, 128, 5, padding=2)) for _ in range(4)]
        )
        if cond_dim is not None:
            # 条件以 FiLM (scale-shift) 方式注入, 等价 AdaLN 的简化形式
            self.cond_proj = nn.Linear(cond_dim, 256)

    def forward(self, x_t, t, cond=None):
        # x_t: [B, C, L]; t: [B]; cond: [B, cond_dim]
        half = self.freqs.size(0)
        ang = t.float()[:, None] / self.freqs[None, :]           # [B, 6]
        temb = torch.cat([torch.sin(ang), torch.cos(ang)], dim=-1)  # [B, 12] -> pad
        temb = F.pad(temb, (0, 64 - temb.size(1)))
        temb = self.time_embed(temb)                              # [B, cond_dim]

        h = self.proj_in(x_t)
        for blk in self.blocks:
            h = h + blk(h)
        if cond is not None:
            scale, shift = self.cond_proj(cond + temb).chunk(2, dim=-1)
            h = h * (1 + scale.unsqueeze(-1)) + shift.unsqueeze(-1)  # FiLM
        return self.proj_out(h)


if __name__ == "__main__":
    B, C, L = 2, 80, 300     # 80 维 Mel, 300 帧 (~3 秒 @ 10ms hop)
    diff = GaussianDiffusion(timesteps=1000, schedule="cosine")
    net = TinyCondUNet(channels=C, cond_dim=128)

    mel = torch.randn(B, C, L)          # 模拟真实 Mel 谱 (已归一化)
    cond = torch.randn(B, 128)          # 模拟 CLAP 文本 embedding

    loss = diff.loss(net, mel, cond)
    print(f"DDPM training loss: {loss.item():.4f}")

    sample = diff.ddim_sample(net, shape=(B, C, L), cond=cond, steps=50)
    print(f"DDIM sampled Mel shape: {tuple(sample.shape)}  (50 steps)")
