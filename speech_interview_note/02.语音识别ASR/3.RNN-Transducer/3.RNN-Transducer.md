# 3. RNN-Transducer (RNN-T)

## 1. 概述

在端到端（E2E）语音识别的发展历程中，**RNN-Transducer (RNN-T)** 是由 Alex Graves 于 2012 年提出的一种经典流式序列到序列（Seq2Seq）架构。

针对 CTC（Connectionist Temporal Classification）和基于 Attention 的 AED（Encoder-Decoder）模型的痛点，RNN-T 巧妙地给出了折中方案：

* **对比 CTC**：CTC 假设帧与帧之间的输出相互独立，缺乏语言模型能力；而 **RNN-T 引入了显式的预测网络（Prediction Network）来建模历史文本依赖**。
* **对比 AED (如 Lasso/Whisper)**：AED 在解码时依赖全局注意力机制，通常需要等待整句语音输入完毕才能开始解码（非流式）；而 **RNN-T 天生支持流式（Streaming）低延迟在线解码**。

因为这一特性，RNN-T 曾长期作为工业界（如 Google、Apple、Bilibili、字节跳动等）端侧与云端流式 ASR 部署的标杆架构。

---

## 2. 核心架构与组件

RNN-T 模型主要由三大核心模块组成：**编码器（Encoder / Audio Network）**、**预测器（Prediction Network / Label Network）** 以及 **联合网络（Joint Network）**。

```
                       ┌──────────────────────┐
  语音特征 X ─────────>│  编码器 (Encoder)    │────────┐
  (T 帧音频)           └──────────────────────┘        │
                                                       ▼
                                             ┌──────────────────┐      Softmax      输出分布
                                             │  联合网络 (Joint) │ ───────────────> P(y_t, u)
                                             └──────────────────┘                   (T x U x V)
                                                       ▲
                       ┌──────────────────────┐        │
  历史文本 Y_<u ──────>│  预测器 (Prediction) │────────┘
  (U 个 Label)         └──────────────────────┘

```

### 2.1 编码器 (Encoder)

* **输入**：一维或二维声学特征序列 $X = (x_1, x_2, \dots, x_T)$（如 80 维 Fbank 特征）。
* **作用**：抽取音频的时域与频域高阶表征，将声学帧映射为声学隐状态 $h_t^e$。
* **网络选型**：早期为 Pyramidal BLSTM / Uni-LSTM，现代工程实现普遍升级为 **Conformer / Emformer / Zipformer**。

$$h_t^e = \text{Encoder}(x_{1:t}), \quad h_t^e \in \mathbb{R}^{D_e}$$

### 2.2 预测器 (Prediction Network)

* **输入**：前 $u-1$ 个已预测出的非空白（non-blank）文本 Label 序列 $y_{<u} = (y_1, y_2, \dots, y_{u-1})$。
* **作用**：类似于一个自回归的语言模型（LM），自动建模历史文本 Token 之间的上下文依赖关系。
* **网络选型**：单层/多层 LSTM、Stateless LM（用 Embedding/Conv 替换 RNN 以降低推理延迟）。

$$h_u^p = \text{PredictionNet}(y_{1:u-1}), \quad h_u^p \in \mathbb{R}^{D_p}$$

### 2.3 联合网络 (Joint Network)

* **输入**：声学隐状态 $h_t^e$ 与 语言隐状态 $h_u^p$ 的结合。
* **作用**：通过前馈神经网络（FFN）将声学特征与语言特征进行非线性融合，输出维度映射至词表大小 $V + 1$（$V$ 为实际 Label 词表，`+1` 为 Blank 占位符 $\varnothing$）。

$$z_{t,u} = \text{JointNet}(h_t^e, h_u^p) = \text{Linear}(\tanh(\text{Linear}_e(h_t^e) + \text{Linear}_p(h_u^p)))$$

$$P(y_{t,u} \mid x_{1:t}, y_{1:u-1}) = \text{Softmax}(z_{t,u})$$

> **数据维度提示**：联合网络的输出张量维度通常为 `(Batch, T, U, V+1)`。这里的 $T$ 为音频帧数，$U$ 为目标文本长度 + 1（包含起始符 `<sos>`）。

## 3. 2D 网格与对齐网络 (Alignment Lattice)

RNN-T 处理序列对齐的核心工具是 **2D 对齐网格（Lattice）**。

与 CTC 仅沿时间轴 $T$ 前进不同，RNN-T 的解码路线定义在一个 $T \times U$ 的二维网格平面上：

* **横轴（$T$ 轴）**：代表音频时间帧指数（从 $t=1$ 到 $t=T$）。
* **纵轴（$U$ 轴）**：代表预测文本 Token 的位置（从 $u=0$ 到 $u=U$）。

```
 U (Text)
 ^
4│  o───>o───>o───>o  (最终节点: t=T, u=U)
 │  │    ^    │    ^
3│  o───>o───>o───>o
 │  ^    │    ^    │
2│  o───>o───>o───>o
 │  │    ^    │    │
1│  o───>o───>o───>o
 │  ^    │    ^    │
0│ (0,0)─>o───>o───>o
 └───────────────────────> T (Time)

```

在网格中的任意状态 $(t, u)$ 处，模型有两个且仅有两个动作选择：

1. **向右移动（ Emit Blank $\varnothing$ ）**：
* 转移路径：$(t, u) \to (t+1, u)$
* 语义：当前时间帧 $t$ 没有产生新的有效文本，消耗一帧音频，移动到下一帧 $t+1$。
* 概率：$P(\varnothing \mid t, u)$


2. **向上移动（ Emit Label $y_u$ ）**：
* 转移路径：$(t, u) \to (t, u+1)$
* 语义：当前时间帧 $t$ 输出了一个具体的文本 Token $y_u$，时间帧保持在 $t$，更新预测网络输入，准备在相同帧预测下一个词。
* 概率：$P(y_u \mid t, u)$

## 4. 前向-后向算法与损失函数

RNN-T 损失函数 $L_{\text{RNNT}}$ 的目标是最大化所有能够合法从节点 $(1,0)$ 走到节点 $(T, U)$ 的路径概率之和：

$$\mathcal{L}_{\text{RNNT}} = -\ln P(Y \mid X) = -\ln \sum_{\pi \in \Omega(X, Y)} P(\pi \mid X)$$

为了高效地在 $O(T \cdot U)$ 复杂度内求解该损失，引入了**前向-后向算法（Forward-Backward Algorithm）**。

### 4.1 前向变量 $\alpha(t, u)$

$\alpha(t, u)$ 表示模型从起点 $(1,0)$ 到达节点 $(t, u)$ 并输出前 $u$ 个 Label 的累积概率：

$$\alpha(t, u) = \alpha(t-1, u) \cdot P(\varnothing \mid t-1, u) + \alpha(t, u-1) \cdot P(y_u \mid t, u-1)$$

* 边界条件：$\alpha(1, 0) = 1.0$

### 4.2 后向变量 $\beta(t, u)$

$\beta(t, u)$ 表示从节点 $(t, u)$ 开始到最终终点 $(T, U)$ 的剩余路径累积概率：

$$\beta(t, u) = \beta(t+1, u) \cdot P(\varnothing \mid t, u) + \beta(t, u+1) \cdot P(y_{u+1} \mid t, u)$$

* 边界条件：$\beta(T, U) \cdot P(\varnothing \mid T, U) = \text{Target}$

### 4.3 梯度计算

通过 $\alpha(t, u) \cdot \beta(t, u)$ 的乘积可以计算出任何节点在整个对齐中的后验概率，进而在 Softmax 层反向传播计算交叉熵梯度。

## 5. 解码策略 (Decoding Strategies)

### 5.1 贪婪搜索 (Greedy Search)

流式推理中最基础且快速的方法：

```python
# RNN-T 贪婪解码伪代码逻辑
t = 1
u = 0
y_seq = [<sos>]

while t <= T:
    # 1. 抽取当前帧声学向量与当前文本隐状态
    h_e = Encoder(x[t])
    h_p = Predictor(y_seq[-1])
    
    # 2. 联合网络计算
    logits = JointNet(h_e, h_p)
    pred_token = argmax(logits)
    
    if pred_token == BLANK:
        # 输出了 Blank，时间轴向前推进一帧
        t += 1
    else:
        # 输出了真实词，记录词并在同一帧继续循环
        y_seq.append(pred_token)
        u += 1
        if u_in_same_frame > max_symbols_per_frame: # 终止死循环保护
            t += 1

```

### 5.2 束搜索 (Beam Search)

在流式场景下，常见的 Beam Search 算法包含：

* **Default Beam Search**：在 $(t, u)$ 平面上维护扩展 Beam。
* **Time-Sync Beam Search**：按时间帧 $t$ 同步推进 Beam（更契合实时流式输出）。
* **Alignment-Sync Beam Search**：按发射路径步数同步推进。

## 6. CTC、AED 与 RNN-T 架构对比

| 维度 | CTC (Connectionist Temporal Classification) | AED (Attention-based Encoder-Decoder) | RNN-T (RNN-Transducer) |
| --- | --- | --- | --- |
| **输出假设** | 帧间条件独立假设 | 无独立假设（全局 Attention） | 无独立假设（自回归 Predictor） |
| **流式推理能力** | **天然支持**（单帧即时解码） | **困难**（需依赖 Chunk/Swin Window 变体） | **天然支持**（时间与文本维双向推进） |
| **语言模型集成** | 需要外部语言模型（WFST / N-gram） | 隐式内置强语言模型 | 隐式内置语言模型 |
| **计算复杂度** | $O(T \cdot V)$ | $O(U^2 \cdot D)$ | $O(T \cdot U \cdot V)$（显存占用高） |
| **对齐依赖** | 显式强制单向对齐 | 隐式交叉注意力对齐 | 显式 2D Lattice 网格对齐 |
| **工业界首选** | 声学对齐、超轻量端侧 ASR | 非流式大模型（Whisper、SenseVoice） | **端侧与云端流式 ASR 系统** |

## 7. Python / PyTorch 代码实战

PyTorch 官方从 `torchaudio` 0.10+ 开始提供了高效的 CUDA 版 `rnnt_loss` C++ 原生实现。下面展示一个完整的 RNN-T 模型前向计算与 Loss 求解示例：

```python
import torch
import torch.nn as nn
import torchaudio.functional as F

class JointNet(nn.Module):
    def __init__(self, encoder_dim: int, pred_dim: int, joint_dim: int, num_classes: int):
        super().__init__()
        self.fc_enc = nn.Linear(encoder_dim, joint_dim)
        self.fc_pred = nn.Linear(pred_dim, joint_dim)
        self.fc_out = nn.Linear(joint_dim, num_classes)
        self.act = nn.Tanh()

    def forward(self, encoder_out: torch.Tensor, pred_out: torch.Tensor) -> torch.Tensor:
        """
        encoder_out: [Batch, T, Encoder_Dim]
        pred_out:    [Batch, U, Pred_Dim]
        Return:      [Batch, T, U, Num_Classes]
        """
        # 利用广播机制 (Broadcasting) 组合 T 和 U 维度
        e_act = self.fc_enc(encoder_out).unsqueeze(2)  # [B, T, 1, Joint_Dim]
        p_act = self.fc_pred(pred_out).unsqueeze(1)    # [B, 1, U, Joint_Dim]
        
        joint_stage = self.act(e_act + p_act)          # [B, T, U, Joint_Dim]
        logits = self.fc_out(joint_stage)              # [B, T, U, Num_Classes]
        return logits

class SimpleRNNT(nn.Module):
    def __init__(self, input_dim=80, encoder_dim=256, pred_dim=256, joint_dim=128, vocab_size=1000, blank_id=0):
        super().__init__()
        self.blank_id = blank_id
        
        # 1. 声学编码器 (Simplified Conv + BiLSTM)
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, encoder_dim),
            nn.ReLU(),
            nn.LSTM(encoder_dim, encoder_dim // 2, num_layers=2, batch_first=True, bidirectional=True)
        )
        
        # 2. 预测器 (Prediction Network)
        self.predictor = nn.Sequential(
            nn.Embedding(vocab_size, pred_dim, padding_idx=self.blank_id),
            nn.LSTM(pred_dim, pred_dim, num_layers=1, batch_first=True)
        )
        
        # 3. 联合网络
        self.joint = JointNet(encoder_dim, pred_dim, joint_dim, vocab_size)

    def forward(self, audio_features, audio_lens, targets, target_lens):
        """
        audio_features: [Batch, T, Feature_Dim]
        audio_lens:     [Batch]
        targets:        [Batch, U_text] (不包含 blank)
        target_lens:    [Batch]
        """
        # A. 编码器前向
        enc_out, _ = self.encoder(audio_features)  # [B, T, Encoder_Dim]
        
        # B. 预测器前向：首位拼上 Blank / SOS 符号
        batch_size = targets.size(0)
        sos_tensor = torch.full((batch_size, 1), self.blank_id, dtype=targets.dtype, device=targets.device)
        pred_input = torch.cat([sos_tensor, targets], dim=1) # [B, U_text + 1]
        
        pred_out, _ = self.predictor(pred_input)   # [B, U, Pred_Dim] (U = U_text + 1)
        
        # C. 联合网络计算 Logits
        logits = self.joint(enc_out, pred_out)      # [B, T, U, Vocab_Size]
        
        return logits

# ==================== 测试运行与 Loss 计算 ====================
if __name__ == "__main__":
    B, T, U_text = 2, 100, 15
    feature_dim = 80
    vocab_size = 500
    blank_id = 0

    # 模拟数据
    dummy_audio = torch.randn(B, T, feature_dim)
    dummy_audio_lens = torch.tensor([100, 85], dtype=torch.int32)
    dummy_targets = torch.randint(1, vocab_size, (B, U_text), dtype=torch.int32)
    dummy_target_lens = torch.tensor([15, 10], dtype=torch.int32)

    # 实例化模型
    model = SimpleRNNT(input_dim=feature_dim, vocab_size=vocab_size, blank_id=blank_id)
    
    # 计算 Logits
    logits = model(dummy_audio, dummy_audio_lens, dummy_targets, dummy_target_lens)
    
    # 转化为 Log-Softmax (torchaudio.functional.rnnt_loss 要求输入为 Log Probs)
    log_probs = torch.log_softmax(logits, dim=-1)

    # 计算 RNN-T Loss
    loss = F.rnnt_loss(
        logits=log_probs,
        targets=dummy_targets,
        logit_lengths=dummy_audio_lens,
        target_lengths=dummy_target_lens,
        blank_idx=blank_id,
        reduction="mean"
    )

    print(f"RNN-T Output Logits Shape: {logits.shape}") # [2, 100, 16, 500]
    print(f"Calculated RNN-T Loss: {loss.item():.4f}")

```

## 8. 总结与最佳实践

* **核心优势**：摒弃了 CTC 的条件独立假设，拥有自回归文本预测能力的同等情况下，原生支持真正的**低延迟流式解码**。
* **主要痛点**：
1. **显存占用大**：训练期间联合网络产生 `(Batch, T, U, V)` 的 4D 张量，导致显存消耗剧烈（工程上常用 Pruned RNN-T 或 Fast-RNNT 优化）。
2. **死循环预测**：在推理时，若某帧连续 Emit 多个非 Blank 字符，可能引发极少量的无限循环，需要人为设置每帧最大发射阈值 `max_symbols_per_frame`（通常设为 3~5）。


* **工业界演进路径**：
* **Encoder**：BLSTM $\to$ Chunk-based Conformer / Emformer / Zipformer
* **Predictor**：RNN Predictor $\to$ **Stateless Predictor**（去除记忆单元，仅使用无状态 Embedding/Conv 拼接历史 2~3 个 Token，大幅降低显存占用与解码推理延迟）。
