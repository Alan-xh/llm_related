# 1. 传统 ASR 与 WFST 架构

## 1. 概述

自动语音识别（Automatic Speech Recognition, ASR）旨在将输入的连续语音信号转换为对应的文本序列。在端到端（End-to-End, E2E）深度学习模型（如 Conformer-CTC、RNN-T、Whisper 等）大行其道之前，**传统 HMM-GMM / HMM-DNN 架构与加权有限状态转换器（Weighted Finite-State Transducer, WFST）** 在工业界占据了绝对的统治地位。

即便在现代语音大模型与端到端系统广泛应用的背景下，基于 WFST 的解码与图构建技术依然在**热词增强（Hotword Boosting）**、**特定域词典约束**、**低延迟流式解码**以及**极小资源设备的语音唤醒（KWS）** 中扮演着不可替代的角色。

---

## 2. 传统 ASR 的概率统计模型

传统语音识别的核心建立在**贝叶斯决策理论（Bayesian Decision Theory）** 之上。给定输入的声学特征序列 $\mathbf{X} = (\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_T)$，目标是寻找概率最大的词序列 $\mathbf{W}^* = (w_1, w_2, \dots, w_N)$：

$$\mathbf{W}^* = \arg\max_{\mathbf{W}} P(\mathbf{W} \mid \mathbf{X}) = \arg\max_{\mathbf{W}} \frac{P(\mathbf{X} \mid \mathbf{W}) P(\mathbf{W})}{P(\mathbf{X})} = \arg\max_{\mathbf{W}} P(\mathbf{X} \mid \mathbf{W}) P(\mathbf{W})$$

该公式将 ASR 任务解耦为三个独立模块：

```
                ┌────────────────────────────────────────────────────────┐
                │                     贝叶斯概率分解                      │
                └───────────────────────────┬────────────────────────────┘
                                            │
               ┌────────────────────────────┴───────────────────────────┐
               │                                                        │
               ▼                                                        ▼
┌──────────────────────────────┐                         ┌──────────────────────────────┐
│     声学模型 (Acoustic Model)  │                         │     语言模型 (Language Model) │
│       $P(\mathbf{X} \mid \mathbf{W})$│                         │         $P(\mathbf{W})$      │
└──────────────┬───────────────┘                         └──────────────┬───────────────┘
               │                                                        │
               │ (通过发音词典分解: $P(\mathbf{X} \mid \mathbf{S}) P(\mathbf{S} \mid \mathbf{W})$)       │
               ▼                                                        │
┌──────────────────────────────┐                                        │
│     发音词典 (Lexicon/Dict)    │                                        │
│       $P(\mathbf{S} \mid \mathbf{W})$│                                        │
└──────────────┬───────────────┘                                        │
               │                                                        │
               └───────────────────────────┬────────────────────────────┘
                                           │
                                           ▼
                            ┌────────────────────────────┐
                            │    解码器 (WFST Decoder)   │
                            │      寻找 $\mathbf{W}^*$    │
                            └────────────────────────────┘

```

1. **声学模型（Acoustic Model, AM - $P(\mathbf{X} \mid \mathbf{W})$）**：描述给定词序列（或音素序列）时，产生特定声学特征序列的概率。传统方法通过隐马尔可夫模型（HMM）进一步拆解为状态转移概率与发散概率：

$$P(\mathbf{X} \mid \mathbf{W}) = \sum_{\mathbf{S}} P(\mathbf{X} \mid \mathbf{S}) P(\mathbf{S} \mid \mathbf{W})$$


2. **发音词典（Lexicon / Pronunciation Dictionary - $P(\mathbf{S} \mid \mathbf{W})$）**：将正字法文本词序列 $\mathbf{W}$ 映射为音素/上下文相关音素序列 $\mathbf{S}$（如 CMUDict，或中文的拼音-音素映射）。
3. **语言模型（Language Model, LM - $P(\mathbf{W})$）**：估算文本词序列 $\mathbf{W}$ 在自然语言中的合理性概率，传统上采用 N-gram（如 3-gram、4-gram）概率统计模型。

## 3. 声学建模：从 GMM-HMM 到 DNN-HMM

### 3.1 隐马尔可夫模型（HMM）在语音中的应用

由于语音信号具有时变性（说话快慢不一），发音音素的持续时长存在弹性。HMM 通过引入**隐状态序列 $\mathbf{S} = (s_1, s_2, \dots, s_T)$** 来建模这种时间轴上的非线性对齐。

* **HMM 三要素**：
* **初始状态概率分布 $\boldsymbol{\pi}$**：$\pi_i = P(s_1 = i)$
* **状态转移概率矩阵 $\mathbf{A}$**：$a_{ij} = P(s_t = j \mid s_{t-1} = i)$
* **观察概率分布 $\mathbf{B}$**：$b_j(\mathbf{x}_t) = P(\mathbf{x}_t \mid s_t = j)$



#### 三状态 Bakis 模型（Left-to-Right HMM）

标准语音建模中，每个单音素（Monophone）或上下文相关音素（Triphone）通常被拆分为 **3 个自左向右的状态（Begin, Middle, End，简写为 $S_0, S_1, S_2$）**，且不允许跨状态倒退：

```
      a_00                a_11                a_22
      ┌───┐               ┌───┐               ┌───┐
      │   ▼               │   ▼               │   ▼
    ┌───────┐   a_01    ┌───────┐   a_12    ┌───────┐
───►│  S_0  ├──────────►│  S_1  ├──────────►│  S_2  ├──────────►
    └───────┘           └───────┘           └───────┘
     b_0(x)              b_1(x)              b_2(x)

```

---

### 3.2 GMM-HMM 与 DNN-HMM 的对决

| 维度 | GMM-HMM | DNN-HMM (Hybrid Model) |
| --- | --- | --- |
| **观察概率计算** | 高斯混合模型：$b_j(\mathbf{x}_t) = \sum_{k=1}^K w_{jk} \mathcal{N}(\mathbf{x}_t; \boldsymbol{\mu}_{jk}, \boldsymbol{\Sigma}_{jk})$ | 神经网络计算后验概率 $P(s_t = j \mid \mathbf{x}_t)$，通过贝叶斯定理转换为似然度 |
| **特征输入** | 极度依赖手工特征的独立性（如 MFCC + $\Delta$ + $\Delta\Delta$），需要对特征做高斯化/解相关 | 可直接输入连续多帧拼接的 Fbank 特征、FMLLR 特征或原始频谱 |
| **状态建模建模能力** | 对高维非线性特征拟合能力弱，受限于高斯分布假设 | 拟合非线性能力强，能捕捉长上下文依赖 |
| **训练与对齐** | 采用 **EM 算法（Baum-Welch 算法）** 迭代对齐与更新参数 | 通常先用 GMM-HMM 强制对齐（Force Alignment），再通过交叉熵（CE）或序列准则（MMI/sMBR）训练 |

#### DNN-HMM 中的伪似然转换（Pseudo-Likelihood Computation）

DNN 输出的是隐状态的后验概率 $P(s_j \mid \mathbf{x}_t)$，而 HMM 解码时需要的是声学似然度 $P(\mathbf{x}_t \mid s_j)$。利用贝叶斯公式转换：

$$b_j(\mathbf{x}_t) = P(\mathbf{x}_t \mid s_j) = \frac{P(s_j \mid \mathbf{x}_t) P(\mathbf{x}_t)}{P(s_j)} \propto \frac{P(s_j \mid \mathbf{x}_t)}{P(s_j)}$$

其中 $P(s_j)$ 是隐状态 $s_j$ 在训练集上的先验概率（先验统计频率）。在解码时除去先验概率 $P(s_j)$ 可有效防止高频状态占据主导地位。

---

### 3.3 上下文相关音素与 CD-State（Triphone / Senone）

自然发音中存在严重的**协同发音效应（Co-articulation Effect）**（例如 `/b/` 在 `/a/` 和 `/u/` 后的频谱特性截然不同）。为了准确建模，工业界引入了 **上下文相关音素（Context-Dependent Phone, Triphone）**。

例如，`d-o+g` 表示左边是音素 `d`、右边是音素 `g` 的音素 `o`。

* **参数爆炸问题**：若音素集中有 50 个音素，理论上的 Triphone 数量可达 $50 \times 50 \times 50 = 125,000$ 个。对应 3 状态 HMM，状态总数达到 $375,000$ 个。
* **决策树状态绑定（Decision Tree State Tying）**：通过建立声学决策树，根据上下文发音属性（如“左边是否是双唇音？”）将物理上相似的 Triphone HMM 状态合并为同一个共享状态，称为 **Senone**（物理 HMM 绑定状态）。

```
                        [All HMM States for /o/ (middle state)]
                                          │
                               Is Left Phone a Stop?
                                   /         \
                             Yes  /           \ No
                                 /             \
                   Is Right Phone Front Vowel?  ...
                       /            \
                 Yes  /              \ No
                     /                \
             [Senone #1042]     [Senone #1043]

```

## 4. 加权有限状态转换器（WFST）原理

在传统 ASR 中，解码实质上是在由 **HMM 状态 $\rightarrow$ Triphone $\rightarrow$ Monophone/Lexicon $\rightarrow$ 语言模型词序列** 构成的巨大网格中寻找最优路径。WFST 提供了一套优雅的数学工具，将上述多层异构信息统一表示并高效融合。

### 4.1 FSM / FSA / FST / WFST 的概念演进

```
┌────────────────────────────────────────────────────────────────────────┐
│ 有限状态自动机 (Finite State Automaton, FSA)                            │
│ 接受/拒绝字符串 (仅有输入标记 Input Label)                               │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 扩展输出
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 有限状态转换器 (Finite State Transducer, FST)                          │
│ 字符串到字符串的映射 (包含输入标记 Input Label 与输出标记 Output Label)    │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 赋予权重 (半环代数 Semiring)
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 加权有限状态转换器 (Weighted Finite State Transducer, WFST)             │
│ 带权重的输入到输出的映射                                                │
└────────────────────────────────────────────────────────────────────────┘

```

#### WFST 的形式化定义

一个在半环 $\mathbb{K}$ 上的 WFST 定义为七元组：$T = (\Sigma, \Omega, Q, E, i, F, \lambda, \rho)$：

* $\Sigma$：输入字母表（Input Alphabet）
* $\Omega$：输出字母表（Output Alphabet）
* $Q$：有限状态集合（Finite set of States）
* $E \subseteq Q \times (\Sigma \cup \{\epsilon\}) \times (\Omega \cup \{\epsilon\}) \times \mathbb{K} \times Q$：转移边集合（Transitions）
* $i \in Q$：初始状态（Initial State）
* $F \subseteq Q$：终止状态集合（Final States）
* $\lambda$：初始权重； $\rho: F \rightarrow \mathbb{K}$：终止权重

转移边 $e \in E$ 可记作：$p[e] \xrightarrow{i[e] : o[e] / w[e]} n[e]$，分别表示：源状态 $\rightarrow$ 输入符号 : 输出符号 / 权重 $\rightarrow$ 目标状态。

---

### 4.2 热带半环与对数半环（Semiring）

WFST 中的“权重”并不是简单的实数加减，而是定义在**半环（Semiring）** $(\mathbb{K}, \oplus, \otimes, \bar{0}, \bar{1})$ 之上的代数结构。

| 半环类型 | 集 $\mathbb{K}$ | 加法 $\oplus$（路径汇总） | 乘法 $\otimes$（路径延伸） | 零元 $\bar{0}$ | 单位元 $\bar{1}$ | 典型应用 |
| --- | --- | --- | --- | --- | --- | --- |
| **热带半环 (Tropical Semiring)** | $\mathbb{R} \cup \{+\infty\}$ | $\min(a, b)$ | $a + b$ | $+\infty$ | $0$ | **Viterbi 解码（求解单条概率最大/代价最小路径）** |
| **对数半环 (Log Semiring)** | $\mathbb{R} \cup \{+\infty\}$ | $-\log(e^{-a} + e^{-b})$ | $a + b$ | $+\infty$ | $0$ | **前向-后向算法（计算 Total Likelihood / Lattice 边缘概率）** |

---

### 4.3 WFST 的核心代数运算

#### 1. 复合（Composition, $\circ$）

将两个转换器 $T_1$（实现 $\Sigma \rightarrow \Gamma$）和 $T_2$（实现 $\Gamma \rightarrow \Omega$）整合为一个直接从 $\Sigma \rightarrow \Omega$ 的转换器 $T = T_1 \circ T_2$。

$$(T_1 \circ T_2)(x, z) = \bigoplus_{y} T_1(x, y) \otimes T_2(y, z)$$

> **核心逻辑**：当 $T_1$ 的输出标记 $y$ 与 $T_2$ 的输入标记 $y$ 相匹配时，建立新的直接转移路径。

#### 2. 确定化（Determinization）

去除网络中的非确定性转移（即消除同一个状态下存在多条相同输入标记的出口边），确保对于给定的输入序列，在图中推演的路径是**唯一**的。这能显著缩减解码过程中的搜索空间。

#### 3. 最小化（Minimization）

在保持转换器输入输出等价的前提下，将状态数和边数压缩到**理论上的极小值**。

#### 4. 推拉权重（Weight Pushing）

在不更改整条路径总权重的条件推拉边上的权重，使权重**尽可能靠近图的前端（起始状态）**。这使得解码器可以在搜索早期根据语言模型/声学剪枝策略尽早剪掉低概率分支（Early Pruning）。

## 5. 解码图构建：$H \circ C \circ L \circ G$ 体系

Kaldi 等传统 ASR 引擎的核心技术，在于通过级联复合（Cascade Composition）将四个层级的 WFST 压缩拼接到一张统一的大图 $HCLG$ 中：

$$HCLG = \text{min}\left(\text{det}\left(H \circ \text{det}\left(C \circ \text{det}\left(L \circ G\right)\right)\right)\right)$$

```
                                  构建层级与映射关系
      
┌────────────────────────────────────────────────────────────────────────┐
│ G (Grammar / Language Model WFST)                                      │
│ 输入: 词 (Word)  │  输出: 词 (Word)  │  权重: -log P_LM(Word)          │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ $\circ$ (Composition)
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│ L (Lexicon / Pronunciation Dict WFST)                                  │
│ 输入: 音素 (Phone)  │  输出: 词 (Word)  │  权重: Pronunciation Probability│
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ $\circ$ (Composition)
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│ C (Context-Dependency WFST)                                            │
│ 输入: 三音素 (Triphone / Context-Phone)  │  输出: 单音素 (Phone)         │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ $\circ$ (Composition)
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│ H (HMM Topology WFST)                                                  │
│ 输入: 转移标识/Senone ID  │  输出: 三音素 (Triphone)  │  权重: Transition│
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│ HCLG (最终一体化解码图)                                                 │
│ 输入: HMM 状态/Senone ID  │  输出: 词序列 (Words)                        │
└────────────────────────────────────────────────────────────────────────┘

```

### 5.1 各级组件详解

1. **G (Grammar / Language Model)**：
* 将 N-gram 语言模型转化为 FSA（输入等于输出）。
* 状态表示上下文历史，转移边表示拟预测的词，边上的权重为对应的负对数概率 $-\log P(w_k \mid w_{k-n+1} \dots w_{k-1})$。


2. **L (Lexicon)**：
* 将音素序列映射为单词。例如：`a p p l e` $\rightarrow$ `apple`。
* 支持多音字与变体发音；引入 $\epsilon$ 处理词间停顿。


3. **C (Context-Dependency)**：
* 将无上下文的单音素（Monophone）映射为上下文相关的三音素（Triphone）。
* 解决声学协同发音的物理约束。


4. **H (HMM Topology)**：
* 将 HMM 状态（Transition-ID / Senone-ID）序列映射为上下文相关的三音素。
* 包含自环（Self-loop）与状态间跨越转移。



---

### 5.2 构建过程中的消歧标识符（Disambiguation Symbols）

在复合 $L \circ G$ 时，若存在同音词（如 “red” 与 “read” 的发音完全一致 `r e d`），或者一个词是另一个词的严格前缀，会导致图在确定化（Determinization）时遭遇无限循环或非确定状态。

* **解决方案**：在音素序列末尾插入消歧符号（如 `#1`, `#2`），确保每个词的发音序列在确定化过程中具有唯一性，并在完成确定化后再予以移除。

## 6. Viterbi 解码与束搜索（Beam Search）

在构筑好 $HCLG$ 解码图后，语音识别过程转化为在 $HCLG$ 状态空间中基于网格（Trellis）寻找最优路径的问题。

### 6.1 动态规划 Viterbi 算法

假设时刻 $t$ 位于状态 $j$ 的最大累积对数似然概率为 $V_t(j)$：

$$V_t(j) = \max_{i} \left[ V_{t-1}(i) + a_{ij} \right] + b_j(\mathbf{x}_t)$$

其中：

* $a_{ij}$ 是 $HCLG$ 图上的转移权重（包含 HMM 转移率、发音概率及 LM 概率）。
* $b_j(\mathbf{x}_t)$ 是 DNN/GMM 计算出的声学观察似然度（Acoustic Score）。

---

### 6.2 束搜索剪枝策略（Beam Search Pruning）

在真实的连续语音识别中，全图状态空间极其庞大（$HCLG$ 节点数可达数千万级别）。为了达到实时解码（Real-Time Factor, RTF < 1），必须引入剪枝：

```
帧时刻 t
─────────────────────────────────────────────────────────────────────────►

  所有活跃状态的最佳得分: V_max(t)
 ┌──────────────────────────────────────────────────────────┐
 │  V_max(t)                                                │
 │  ● (最佳候选状态)                                         │
 │  │                                                       │
 │  │ ◄─── Beam Width (相对剪枝阈值, 例如 13.0)              │
 │  │                                                       │
 │  ● (仍保留在活跃列表中的状态)                             │
 │  ─────────────────────────────────────────── 剪枝线 (Cut-off)
 │  x (被剪枝丢弃的状态)                                     │
 └──────────────────────────────────────────────────────────┘

```

1. **声学/相对束剪枝 (Acoustic / Relative Beam Pruning)**：
在 $t$ 时刻，找出当前所有活跃 token 中的最大得分 $V_{\max}(t)$。凡是得分低于 $V_{\max}(t) - \text{Beam\_Width}$ 的路径全部被淘汰剪枝。
2. **绝对最大活跃数剪枝 (Max Active / Hash Pruning)**：
限制每帧保留的最大候选状态总数（例如限制 `max_active = 7000`）。若超出，仅保留得分最高的前 $N$ 个状态。
3. **Lattice 词网格生成**：
解码器不仅输出一条最优文本，还会保留部分次优路径，生成包含丰富时序对齐信息的词图（Lattice），以便后处理（如语言模型重打分 N-best Rescoring）。

### 7.2 代码实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import openfst_python as fst

# =====================================================================
# 1. DNN 声学模型输出与伪似然计算 (Simulated Acoustic Model)
# =====================================================================
class SimpleAcousticModel(nn.Module):
    def __init__(self, input_dim=80, num_senones=100):
        super(SimpleAcousticModel, self).__init__()
        self.fc1 = nn.Linear(input_dim, 256)
        self.fc2 = nn.Linear(256, num_senones)

    def forward(self, x):
        # x: [Batch, Frames, Feature_Dim]
        h = F.relu(self.fc1(x))
        logits = self.fc2(h)
        # 输出 Log-Softmax 后验概率 log P(s_j | x_t)
        log_posterior = F.log_softmax(logits, dim=-1)
        return log_posterior

def compute_pseudo_likelihood(log_posterior, log_prior):
    """
    根据贝叶斯公式计算伪似然声学得分: log P(x_t | s_j) = log P(s_j | x_t) - log P(s_j)
    """
    return log_posterior - log_prior

# =====================================================================
# 2. 基于 OpenFST 的 L o G 解码图构建与 Viterbi 求解示例
# =====================================================================
def build_lexicon_and_grammar_wfst():
    """
    构建简化的 L (Lexicon) 和 G (Grammar) WFST
    音素映射:
      1: 'a', 2: 'p', 3: 'l'
    词映射:
      1: "apple"
    """
    # -----------------------------------------------------------------
    # A. 构建词典 L (Phones -> Words)
    # -----------------------------------------------------------------
    # 符号表定义
    phone_syms = fst.SymbolTable()
    phone_syms.add_symbol("<eps>", 0)
    phone_syms.add_symbol("a", 1)
    phone_syms.add_symbol("p", 2)
    phone_syms.add_symbol("l", 3)

    word_syms = fst.SymbolTable()
    word_syms.add_symbol("<eps>", 0)
    word_syms.add_symbol("apple", 1)

    compiler = fst.Compiler(isyms=phone_syms, osyms=word_syms, keep_isyms=True, keep_osyms=True)
    
    # 定义 L 状态转换 (Tropical Semiring)
    # apple -> a p p l e (Simplified: a p l)
    # 格式: src_state dst_state in_label out_label [weight]
    fsm_l_text = """
    0 1 a apple 0.0
    1 2 p <eps> 0.0
    2 3 l <eps> 0.0
    3 0.0
    """
    L = compiler.compile(fsm_l_text.splitlines())

    # -----------------------------------------------------------------
    # B. 构建语言模型 G (Words -> Words)
    # -----------------------------------------------------------------
    compiler_g = fst.Compiler(isyms=word_syms, osyms=word_syms, keep_isyms=True, keep_osyms=True)
    fsm_g_text = """
    0 1 apple apple 0.5
    1 0.0
    """
    G = compiler_g.compile(fsm_g_text.splitlines())

    # -----------------------------------------------------------------
    # C. 复合与优化 L o G
    # -----------------------------------------------------------------
    # 必须对输入/输出进行排序以执行 Compose
    L_sorted = fst.arcSort(L, sort_type="olabel")
    G_sorted = fst.arcSort(G, sort_type="ilabel")
    
    # 复合 L o G
    LG = fst.compose(L_sorted, G_sorted)
    
    # 确定化与最小化
    LG_det = fst.determinize(LG)
    LG_opt = fst.minimize(LG_det)

    return LG_opt, phone_syms, word_syms

if __name__ == "__main__":
    # A. 运行声学模型模拟
    batch_size, num_frames, feat_dim, num_senones = 1, 50, 80, 100

    # 求解图中的最短路径 (Viterbi 最优解)
    shortest_path = fst.shortestpath(LG_graph)
```

## 8. 传统 ASR 与现代端到端（E2E）ASR 的全方位对比

随着深度学习的发展，端到端（E2E）架构（如 CTC、RNN-T、Attention-based Encoder-Decoder/Whisper）逐渐取代了传统 HMM-WFST 架构的主导地位。

| 维度 | 传统 ASR (GMM/DNN-HMM + WFST) | 端到端 ASR (E2E: CTC / RNN-T / AED) |
| --- | --- | --- |
| **模块构建** | 独立训练 AM、Lexicon、LM，通过 WFST 显式组合 | 单一神经网络直接实现 $\text{Audio} \rightarrow \text{Text}$ 的映射 |
| **对齐依赖** | 极其依赖 HMM 状态与帧精度的强制对齐（Force-Alignment） | 隐式对齐（CTC Blank 标记 / Transducer 交叉注意力机制） |
| **解码复杂度** | 构建 $HCLG$ 解码图极度消耗内存与 CPU（建图耗时、占用数百 MB 至数 GB） | 算法简单，直接在神经网络输出的 Token 空间进行 Beam Search |
| **未登录词 (OOV)** | 只要将新词及其音素标注加入 Lexicon 和 LM，**无需重新训练声学模型** | 难以识别未登录词，通常需要针对新词重新微调模型或追加复杂的 Contextual Adapter |
| **热词/特定域适配** | **极强**：可以直接修改 G 或在 $HCLG$ 上快速 Compose 热词 WFST | 较弱：依赖提示词（Prompting）、深层融合（Deep Bias）或浅层融合（Shallow Fusion） |
| **流式推理与延迟** | 天然支持基于帧的高效流式解码，延迟极低（低至数十毫秒） | RNN-T / Emformer 支持流式；AED (Whisper) 天然属于非流式架构，需特殊改造 |
| **工业现状** | **未被淘汰**：广泛应用于车载唤醒、特定域指令识别、热词加权解码器底座 | 互联网通用大流式/非流式语音识别、跨语言听写的主流选择 |

## 9. 总结

* **概率解耦本质**：传统 ASR 将识别问题划分为声学模型（$P(\mathbf{X}\mid\mathbf{W})$）、发音词典（$P(\mathbf{S}\mid\mathbf{W})$）与语言模型（$P(\mathbf{W})$），各部分可独立收集数据进行优化。
* **HMM 解决时间对齐**：通过 Bakis 3-状态模型以及上下文相关音素（Triphone/Senone），成功建模了语音信号的时间弹性和协同发音效应。
* **WFST 是知识融合的核心**：WFST 依托半环代数结构，利用确定化、最小化、推拉权重和复合运算，将异构的 $H, C, L, G$ 四层网络融合为一张高度优化的静态解码图 $HCLG$。
* **互补的工业价值**：尽管端到端（E2E）模型在通用识别准确率上超越了传统架构，但 WFST 在**可控性、热词实时注入、极小资源部署**等方面依然发挥着核心价值。
