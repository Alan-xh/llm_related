# 1.音频信号基础

## 1.概述

声音是由物体振动产生的**声波（Sound Wave）**，是一种在介质（如空气、水等）中传播的连续**模拟信号（Analog Signal）**。在计算机视觉（CV）中，图像是二维/三维的离散像素阵列；而在语音与音频处理（Speech & Audio Processing）中，声音的本质是**一维的时间序列信号（Time-Series Signal）**。

理解声音的物理特性以及如何将连续的声波转化为计算机可处理的离散数字信号，是迈入语音识别（ASR）、语音合成（TTS）、音频生成以及语音大模型（Speech-LLM）领域的第一步。

---

## 2.音频的物理特性与感知

声音信号在物理上可用声压随时间的变化曲线来表示。人耳对声音的感知主要取决于三个基本物理要素：

```
                             ┌─ 振幅 (Amplitude)  ───> 响度/音量 (Loudness)
                             │
连续声波 (Continuous Wave) ──┼─ 频率 (Frequency)  ───> 音调/音高 (Pitch)
                             │
                             └─ 波形 (Waveform)   ───> 音色/音质 (Timbre)

```

1. **响度（Loudness）**：由声波的振幅（Amplitude）**决定。振幅越大，声音越响。工程中常使用**分贝（dB, Decibel）来表示声压级或能量强度，遵循对数比例。
2. **音调（Pitch）**：由声波的基频（Fundamental Frequency, $f_0$）决定。频率越高，音调越高。人类听觉的频率范围大约在 **20 Hz ~ 20,000 Hz (20 kHz)**。
* **人声（Speech）** 的主要频率范围通常集中在 **80 Hz ~ 8,000 Hz** 之间，其中男声基频约为 85~180 Hz，女声基频约为 165~255 Hz。


3. **音色（Timbre）**：由声波的**波形结构与谐波（Harmonics）/泛音组成**决定。即便两个人以相同的音调和响度发音，其波形的谐波能量分布不同，人耳也能轻易区分出不同的说话人或乐器。

## 3.音频信号的数字化表示

与图像数字化类似，模拟音频信号转化为数字音频信号（Digital Audio Signal）需要经历**采样**与**量化**两大核心步骤，通常被称为**脉冲编码调制（PCM, Pulse Code Modulation）**。

```
模拟信号           [1. 采样 Sampling]          [2. 量化 Quantization]        数字信号
(Continuous)  ───────────────────────────>  ───────────────────────────>  (Discrete PCM)
               (时间轴离散化: 采样率 Fs)     (幅度轴离散化: 位深 Bit Depth)

```

### 3.1 采样（Sampling）与奈奎斯特定理

**采样**是指在时间轴上每隔固定的时间间隔 $T_s$ 对连续声波的振幅进行一次抽取。

* **采样周期 $T_s$**：两次采样之间的时间间隔（单位：秒）。
* **采样率（Sampling Rate, $F_s$）**：单位时间内采样的次数，单位为赫兹（Hz）。$F_s = \frac{1}{T_s}$。

#### 奈奎斯特-香农采样定理（Nyquist-Shannon Sampling Theorem）

为了保证在重构模拟信号时不发生**混叠（Aliasing）**失真，采样率 $F_s$ 必须**至少大于或等于模拟信号中最高有效频率 $f_{\max}$ 的两倍**：

$$F_s \ge 2 f_{\max}$$

* **奈奎斯特频率（Nyquist Frequency）**：$f_{\text{Nyquist}} = \frac{F_s}{2}$，即给定采样率下能无失真还原的最高信号频率。

> **工业界常见采样率：**
> * **8,000 Hz (8 kHz)**：传统电话语音通信（涵盖 4 kHz 以内主要语音能量）。
> * **16,000 Hz (16 kHz)**：**语音识别（ASR）、语音大模型（Speech-LLM）的标准输入采样率**（涵盖 8 kHz 以内的完整人声频段）。
> * **44,100 Hz (44.1 kHz)**：CD 音质标准（覆盖人耳极限 20 kHz 频段）。
> * **48,000 Hz (48 kHz)**：专业音频、电影、高质量 TTS 声码器输出标准。

注意： 人声 80-8000 Hz，听觉范围 20-20khz ，采样需要在最高有效频率的2倍以上无失帧， 16k 采样率即人声的 2 倍

---

### 3.2 量化（Quantization）与位深

**量化**是指将采样得到的连续振幅值映射到有限个离散的数值级数上。

* **位深/比特深度（Bit Depth）**：表示每个采样点振幅值所需的比特数（Bit）。
* 若位深为 $B$ bit，则振幅轴被划分为 $2^B$ 个量化级数。

> **常见位深格式：**
> * **16-bit PCM（最常用）**：符号整型 `int16`，可表示的范围为 $[-32768, 32767]$。动态范围约为 $96\text{ dB}$。
> * **24-bit / 32-bit PCM**：专业录音与高清音频处理。
> * **32-bit Float**：深度学习模型内部常用的浮点表示，数值范围归一化至 $[-1.0, 1.0]$，便于梯度计算与反向传播。

### 3.3 声道数（Channels）与音频数据形状

音频数据的维度通常由样本数（Sampling Points）**和**声道数（Channels）共同决定。

* **单声道（Mono / 1 Channel）**：仅有一个音频采集通道。语音识别与语音大模型训练中最常用的格式。
* **双声道/立体声（Stereo / 2 Channels）**：包含左右两个独立的音频通道（Left/Right），能提供空间方位感。
* **多声道/麦克风阵列（Microphone Array / $N$ Channels）**：常用于智能音箱、会议系统，用于声源定位（SSL）**与**波束形成（Beamforming）降噪。

#### 深度学习中常见音频数据格式（Shape）

对于时长为 $T$ 秒、采样率为 $F_s$ 的音频：总采样点数 $N = T \times F_s$。

* **单样本 Raw Waveform 形状**：
* 单声道：`(1, N)` 或 `(N,)`
* 双声道：`(2, N)`


* **批处理 Batch 形状**（PyTorch 默认格式）：
* `(Batch_Size, Channels, Length)` $\rightarrow$ 例如 `(32, 1, 160000)` 表示 32 条 10 秒长、16kHz 的单声道音频。

---

### 3.4 音频码率（Bitrate）与存储计算

**码率（Bitrate）** 指**单位时间**内传输或存储音频数据所需要的比特数（通常单位为 kbps）：

$$\text{Bitrate (bps)} = \text{Sampling Rate (Hz)} \times \text{Bit Depth (bit)} \times \text{Channels}$$

**计算示例**：
一段 10 秒长、采样率为 16 kHz、16-bit 单声道的未压缩 PCM 语音：

* 数据点数：$16000 \times 10 = 160,000$ 个采样点
* 码率：$16000 \times 16 \times 1 = 256,000\text{ bps} = 256\text{ kbps}$ (bit per second)
* 内存占用：$160,000 \times 2\text{ Bytes} = 320,000\text{ Bytes} \approx 312.5\text{ KB}$

注意： “采样”不是去“跟踪”或“计数”声波的频率，而是去“定格”声波每一瞬间的“幅度（音量）”。只要帧率足够快（满足奈奎斯特定理），后期把这些“高度值”连起来，就能完美还原出波浪起伏的形状——至于这个波浪是快是慢（频率高低），完全包含在那个起伏形状里了。

## 4.常见音频文件格式

依据压缩方式，音频文件格式主要分为三类：

| 类别 | 格式 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| **无压缩 (Uncompressed)** | **WAV** | 微软与 IBM 联合开发，通常直接包裹原生 PCM 数据，保留完全真实信息 | **语音 AI 算法研发、模型训练与推理的标准输入格式** |

## 5.音频的时域分析（Time-Domain Analysis）

直接对原始一维时间序列波形进行统计计算的方法称为**时域分析**。

### 5.1 短时能量（Short-Time Energy, STE）

音频信号是非平稳信号，但**在极短的时间间隔内（如 10~30ms）可近似看作平稳信号**。我们将音频切分为多个重叠的帧（Frame），计算每一帧内信号幅度的平方和：

$$E_m = \sum_{n=0}^{N-1} [x_m(n)]^2$$

* **作用**：区分**语音段与无声段（静音帧）**；区分**清音（Unvoiced）与浊音（Voiced）**（浊音能量通常远高于清音）。

### 5.2 过零率（Zero-Crossing Rate, ZCR）

过零率指信号波形穿过零电平（改变符号）的频率：

$$\text{ZCR}_m = \frac{1}{2} \sum_{n=1}^{N-1} \vert{}\operatorname{sgn}(x_m(n)) - \operatorname{sgn}(x_m(n-1))\vert{}$$

* **作用**：
* **高频噪音 / 清音（如 /s/, /f/, /t/）**：波形变化剧烈，过零率较高。
* **浊音（如 /a/, /o/, /m/）**：具有明显的周期性，过零率较低。
* 常联合**短时能量**用于传统的**端点检测 / 语音活动检测（VAD, Voice Activity Detection）**。

问题: 为什么高频噪音过零率就高，有明显周期性过零率就低，不是高频过零率就高吗？比如频率正好是采样率的一半

在相同时间内，频率越高，波形上下穿越零点的次数确实越多（过零率越高）。但你说的“有明显周期性的声音过零率低”和“高频噪音过零率高”，这两个描述其实并不矛盾，因为它们对比的参照物不同：

情况A（高频纯音 vs 低频纯音）：1000Hz的正弦波，每秒过零2000次；100Hz的正弦波，每秒过零200次。确实高频过零率更高。

情况B（高频噪音 vs 高频纯音）：同样都是高频（比如都是3000Hz附近），噪音的过零率通常比纯音更高，因为噪音的波形杂乱无章，会在短时间内来回剧烈摆动，而纯音的波形是平滑规则的。

所以准确的说法是：频率越高，过零率越高；但波形越不规则（噪音），过零率也比同频率的规则波更高

## 6.Python 音频处理代码实践

在现代语音深度学习工程中，`torchaudio` 与 `librosa` 是两个最核心的音频处理库。

```python
import torchaudio
import librosa
import numpy as np
import torch

# 1. 使用 torchaudio 加载音频 (返回 Tensor: [Channels, Time])
waveform, sample_rate = torchaudio.load("example.wav")
print(f"Shape: {waveform.shape}, Sample Rate: {sample_rate} Hz")

# 2. 重采样 (Resample) 至语音标准采样率 16kHz
if sample_rate != 16000:
    resampler = torchaudio.transforms.Resample(orig_freq=sample_rate, new_freq=16000)
    waveform = resampler(waveform)
    sample_rate = 16000

# 3. 单声道转换 (若为多声道，取通道平均值)
if waveform.shape[0] > 1:
    waveform = torch.mean(waveform, dim=0, keepdim=True)

# 4. 计算短时能量 (STE) 与帧归一化
frame_length = 512
frames = waveform.unfold(dimension=-1, size=frame_length, step=256)
short_time_energy = torch.sum(frames ** 2, dim=-1)

print(f"Processed Waveform Shape: {waveform.shape}")
print(f"Short-Time Energy Frame Count: {short_time_energy.shape[-1]}")

```

## 7.总结

* 音频信号本质是一维连续的时间序列，通过 **采样（时间轴）** 和 **量化（幅度轴）** 转化为数字 PCM 信号。
* 语音处理领域的黄金标准：**16 kHz 采样率、16-bit 位深、单声道（Mono）**。
* **奈奎斯特定理**（$F_s \ge 2 f_{\max}$）定义了无失真还原信号的采样下限；混叠现象是低于该下限时的主要失真来源。
* 时域特征（短时能量、过零率）是基础音频分析与简单 VAD 算法的重要依据，但在复杂任务中通常需要进一步提取**时频域特征（如 Mel-Spectrogram）**。
