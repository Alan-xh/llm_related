# 3.梅尔频谱与 MFCC

## 1.概述

在上一章中，我们学习了通过短时傅里叶变换（STFT）得到**线性语谱图（Linear-Frequency Spectrogram）**。线性语谱图在频率轴上是等间隔均匀分布的（例如在 $16\text{ kHz}$ 采样率、$\text{n\_fft}=512$ 下，每个 Frequency Bin 之间的间隔均为约为 $31.25\text{ Hz}$）。

然而，**人类耳蜗对声音频率的感知是非线性的**：

* 人耳对低频声音极其敏感（能轻易区分 $200\text{ Hz}$ 和 $300\text{ Hz}$ 的差异）；
* 对高频声音的辨别能力则大幅下降（很难察觉 $10,000\text{ Hz}$ 和 $10,100\text{ Hz}$ 的区别）。

为了让计算机提炼出的音频特征更符合人耳的听觉感知特性，**梅尔标度（Mel Scale）**、**梅尔频谱（Mel-Spectrogram）** 以及 **梅尔频率倒谱系数（MFCC, Mel-Frequency Cepstral Coefficients）** 应运而生。它们是现代语音处理、ASR（语音识别）、TTS（语音合成）以及语音大模型（Speech-LLM）中最核心的特征表示。

---

## 2.梅尔标度（Mel Scale）

### 2.1 物理频率与梅尔标度的转换

**梅尔标度（Mel Scale）** 是一种基于人耳对等距音调感知（Perceptual Pitch Scale）的非线性频率标度。1000 Mel 被定义为感知上等同于 $1000\text{ Hz}$、高于人耳听阈 $40\text{ dB}$ 的纯音音调。

物理频率 $f$（单位：$\text{Hz}$）与梅尔频率 $m$（单位：$\text{Mel}$）之间的经典转换公式（O'Shaughnessy 公式）为：

$$m = 2595 \cdot \log_{10} \left(1 + \frac{f}{700}\right)$$

其逆转换公式为：

$$f = 700 \cdot \left(10^{\frac{m}{2595}} - 1\right)$$

```
    Mel 频率 ▲
             │                                   / (高频段：对数增长，斜率平缓)
             │                                 /
             │                               /
             │                             /
             │                           /
             │                         /
             │                       /
             │                     /
             │                   /
             │                 / (低频段：近似线性，斜率陡峭)
             └─────────────────────────────────────────────► 物理频率 f (Hz)

```

从曲线变化趋势可以看出：

* **在低频区（$<1000\text{ Hz}$）**：$\text{Mel}$ 与 $\text{Hz}$ 近似呈**线性关系**；
* **在高频区（$>1000\text{ Hz}$）**：$\text{Mel}$ 与 $\text{Hz}$ 呈**对数关系**，物理频率大幅增加时，$\text{Mel}$ 频段的增长趋于平缓。

## 3.梅尔三角滤波器组（Mel Filter Bank）

为了将线性语谱图转换为梅尔语谱图，我们需要在频域使用一组重叠的**三角滤波器（Triangular Filters）**，这组滤波器被称为**梅尔滤波器组（Mel Filter Bank）**。

### 3.1 滤波器组的构建过程

假设我们需要构建包含 $M$ 个滤波器的梅尔滤波器组（如 $M = 80$）：

```
    增益 (Gain) ▲
               │    H_1(k)    H_2(k)        H_m(k)
             1 ┼     /\        /\            /\
               │    /  \      /  \          /  \
               │   /    \    /    \        /    \
               │  /      \  /      \      /      \
             0 ┴─┴────────┴─┴───────┴────┴────────┴───► Frequency Bin (k)
                 f(m-1)     f(m)        f(m+1)

```

1. **确定频率边界**：设定分析的最低频率 $f_{\min}$（通常为 $0\text{ Hz}$）和最高频率 $f_{\max}$（通常为奈奎斯特频率 $F_s / 2$，如 $8000\text{ Hz}$）。
2. **映射到 Mel 域**：利用转换公式将 $f_{\min}$ 和 $f_{\max}$ 转化为 $m_{\min}$ 和 $m_{\max}$。
3. **Mel 域等间距采样**：在 $[m_{\min}, m_{\max}]$ 范围内均匀插入 $M$ 个点，得到 $M+2$ 个等间距的 Mel 刻度点 $m_0, m_1, \dots, m_{M+1}$。
4. **映射回 Hz 域与 Bin 索引**：将这 $M+2$ 个 Mel 点使用逆转换公式映射回物理频率 $f_0, f_1, \dots, f_{M+1}$，再进一步换算为 STFT 中的离散频率 Bin 索引 $k_0, k_1, \dots, k_{M+1}$：

$$k_m = \left\lfloor \frac{n\_fft + 1}{F_s} \cdot f_m \right\rfloor$$


5. **构造三角响应函数**：第 $m$ 个滤波器的频响 $H_m(k)$ 表达式为：

$$H_m(k) = \begin{cases}     0 & k < k_{m-1} \\    \frac{k - k_{m-1}}{k_m - k_{m-1}} & k_{m-1} \le k \le k_m \\    \frac{k_{m+1} - k}{k_{m+1} - k_m} & k_m \le k \le k_{m+1} \\    0 & k > k_{m+1}    \end{cases}$$

## 4.梅尔频谱（Mel-Spectrogram）计算流程

**梅尔频谱**是将短时傅里叶变换得到的功率谱通过梅尔滤波器组进行降维与频域加权，再取对数得到的时频矩阵。

### 4.1 计算步骤全解析

```
一维原始音频 x[n]
   │
   ▼  [1. 短时傅里叶变换 (STFT)]
复数频谱 X(t, k)
   │
   ▼  [2. 计算模长平方 (Power Spectrum)]
功率谱 P(t, k) = |X(t, k)|^2   ───> 维度: [Frames, n_fft // 2 + 1]
   │
   ▼  [3. 乘以梅尔滤波器组矩阵 (Mel Filter Bank)]
梅尔功率谱 S_mel(t, m) = P(t, k) · H_mel^T  ───> 维度: [Frames, n_mels]
   │
   ▼  [4. 对数取样 (Log Compression)]
对数梅尔频谱 Log-Mel Spectrogram = Log(S_mel + ε)  ───> 维度: [Frames, n_mels]

```

### 4.2 为什么必须进行对数压缩（Log Compression）？

1. **拟合听觉响度感知**：人耳对声音响度（Loudness）的感知遵循韦伯-费希纳定律（Weber-Fechner Law），即响度的感知与声强呈**对数关系**。
2. **降低动态范围**：声波功率的量级跨度非常大（可达 $10^8$ 以上）。取对数后可以将巨大的动态范围压缩到平缓的区间（如转换为 $\text{dB}$ 刻度），使神经网络更容易稳定训练。

## 5.梅尔频率倒谱系数（MFCC）

在深度学习爆发之前，传统的 GMM-HMM 语音识别框架更倾向于使用 **MFCC**，而不是原始的 Log-Mel 频谱。

### 5.1 倒谱（Cepstrum）与声学发音模型

根据语音生成的**声门-声道卷积模型（Source-Filter Model）**：

$$x(t) = e(t) * h(t)$$

* $e(t)$：**声门激励信号（Source）**，代表声带振动，包含基频 $f_0$ 和细致的谐波结构（高频信息）；
* $h(t)$：**声道冲激响应（Filter）**，代表口腔、鼻腔形态，决定发音的音素（低频包络信息）。

在频域中，卷积变为乘积：

$$X(f) = E(f) \cdot H(f)$$

取对数后，乘积转化为**加法解耦**：

$$\log \vert{}X(f)\vert{} = \log \vert{}E(f)\vert{} + \log \vert{}H(f)\vert{}$$

```
  对数频谱 Log|X(f)|                                  倒域 (Quefrency)
  ▲                                                  ▲
  │  /\  /\  /\  /\  (高频快速波动: 声门激励 E)      │  |  (低倒频率: 声道包络 H -> 音素信息)
  │ /  \/  \/  \/  \                                 │  |
  │/────────────────\ (低频缓慢包络: 声道响应 H)     │  │
  └──────────────────────────────► 频率 f            │  │          |  (高倒频率: 声带基频 E)
                                                     └─────────────┴────────► 伪时间 (Quefrency)
                                                           [做离散余弦变换 DCT]

```

为了彻底分离这两者，对 $\log \vert{}X(f)\vert{}$ 再做一次频域的变换（即**倒频谱变换**）。因为对数频谱在频率轴上具有高频波动（激励）和低频包络（声道），对其应用离散余弦变换（DCT, Discrete Cosine Transform）后：

* **低阶 DCT 系数**（通常取前 $1\sim13$ 维）：代表声道的形貌与包络，即**音素语义特征**；
* **高阶 DCT 系数**：代表声带振动细节，通常作为噪声或个性化音色被剥离。

### 5.2 MFCC 的完整提取步骤

1. 提取 **Log-Mel 频谱**；
2. 对 Log-Mel 频谱的每一个时间帧沿 Mel 轴做 **离散余弦变换（DCT-II）**：

$$c_n = \sum_{m=1}^{M} \log(S_{\text{mel}}(m)) \cdot \cos\left[ \frac{\pi n}{M} \left(m - \frac{1}{2}\right) \right], \quad n = 0, 1, \dots, C-1$$


3. 保留前 $C$ 个系数（通常 $C = 12$ 或 $13$）；
4. **计算一阶差分（$\Delta$）与二阶差分（$\Delta\Delta$）**：动态反映帧间的变化趋势，将 13 维静态特征扩充为 **39 维** 标准 MFCC 特征向量（$13 + 13 + 13$）。

## 6.梅尔频谱 vs. MFCC：深度学习时代的演进对比

在传统语音识别与现代深度学习模型中，特征的选择发生了深刻变化：

| 维度 | 梅尔频谱（Log-Mel Spectrogram） | MFCC |
| --- | --- | --- |
| **维数大小** | 较高（常见 80, 128 维） | 较低（常见 13, 39 维） |
| **特征相关性** | 频域相邻信道存在**高相关性** | 经过 DCT 去相关，信道间**相互正交** |
| **信息保留度** | 丰富，保留了完整的时频包络与局部纹理 | 丢弃了高频倒谱细节，信息有损 |
| **主流适配算法** | **CNN、Transformer、Conformer、Diffusion** | GMM-HMM、SVM、简单 MLP |
| **代表应用场景** | **Whisper、HiFi-GAN、FastSpeech2、Speech-LLM** | 传统嵌入式 KWS、低算力声纹识别 |

> **关键面试考点：为什么现代深度学习模型更偏爱 Log-Mel 频谱，而不是 MFCC？**
> 1. **深度神经网络（如 CNN/Transformer）具备极强的非线性拟合与去相关能力**，不再依赖 DCT 手动解耦相关性；
> 2. **DCT 属于有损压缩**，去除了高阶倒谱信息。现代端到端模型（如 ASR/TTS/声码器）需要丰富的细节来重建语音或提升泛化性能；
> 3. Log-Mel 保持了二维网格图像形态，天然契合 **2D 卷积与 Self-Attention** 机制。

## 7.Python / Torchaudio 代码实战

在 PyTorch 生态中，`torchaudio.transforms.MelSpectrogram` 和 `MFCC` 是最标准的实现。

```python
import torch
import torchaudio
import torchaudio.transforms as T

# 1. 模拟 16kHz 1 秒长的单声道音频
sample_rate = 16000
waveform = torch.randn(1, sample_rate)

# 2. 提取 Log-Mel 频谱 (80 维, 对应主流 ASR/Speech-LLM 配置)
n_fft = 512
hop_length = 160  # 10ms 帧移
n_mels = 80

mel_spectrogram_transform = T.MelSpectrogram(
    sample_rate=sample_rate,
    n_fft=n_fft,
    win_length=n_fft,
    hop_length=hop_length,
    f_min=0.0,
    f_max=sample_rate / 2.0,
    n_mels=n_mels,
    power=2.0
)

# 计算梅尔功率谱 [Batch, n_mels, Frames]
mel_spec = mel_spectrogram_transform(waveform)

# 对数压缩数值转换为 dB 标度 (Log-Mel)
log_mel_spec = torchaudio.functional.amplitude_to_DB(
    mel_spec,
    multiplier=10.0,
    amin=1e-10,
    db_multiplier=0.0
)

print(f"Log-Mel 频谱形状 [Batch, n_mels, Frames]: {log_mel_spec.shape}")
# 预期输出: [1, 80, 101]

# 3. 提取 MFCC 特征 (13 维)
mfcc_transform = T.MFCC(
    sample_rate=sample_rate,
    n_mfcc=13,
    melkwargs={
        "n_fft": n_fft,
        "hop_length": hop_length,
        "n_mels": n_mels
    }
)

mfcc = mfcc_transform(waveform)
print(f"MFCC 特征形状 [Batch, n_mfcc, Frames]: {mfcc.shape}")
# 预期输出: [1, 13, 101]

```

## 8.总结

* **梅尔标度（Mel Scale）** 依据人耳“低频敏感、高频迟钝”的听觉感知特性，对物理频率进行非线性压缩。
* **梅尔频谱（Log-Mel Spectrogram）** 通过在功率谱上作用**梅尔三角滤波器组**并进行**对数压缩**得到，是现代语音大模型（如 Whisper、GLM-4-Voice）最主流的输入特征。
* **MFCC** 在 Log-Mel 的基础上应用 **DCT 变换** 实现了特征解耦与降维，保留声道包络信息，是传统语音识别时代的支柱特征，但在现代深度学习中大多被 Log-Mel 频谱取代。
