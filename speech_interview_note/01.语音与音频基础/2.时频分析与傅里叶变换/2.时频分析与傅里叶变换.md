# 2.时频分析与傅里叶变换

## 1.概述

在上一章中，我们了解到原始音频信号在时域上表现为随时间变化的振幅序列。然而，时域波形虽然能直接反映声音的响度和时间变化，却无法直接展现声音的**频率组成**（如音调高低、谐波结构等）。

为了分析音频的频率特征，我们需要借助于**傅里叶变换（Fourier Transform）**，将信号从**时域（Time Domain）**转换到**频域（Frequency Domain）**。但由于语音信号具有高度的**非平稳性（Non-stationary）**，单纯的频域分析会丢失时间信息。因此，**时频分析（Time-Frequency Analysis）**——特别是**短时傅里叶变换（STFT, Short-Time Fourier Transform）**与**语谱图（Spectrogram）**——成为了连接一维时域波形与现代深度学习模型（如 Conformer、Whisper、HiFi-GAN 等）的关键桥梁。

---

## 2.傅里叶变换基础

### 2.1 连续傅里叶变换（CFT）

傅里叶变换的核心思想是：**任何满足狄利克雷条件的连续信号，都可以分解为一系列不同频率的正弦波与余弦波（或复指数信号）的叠加**。

连续信号 $x(t)$ 的傅里叶变换公式定义为：

$$X(f) = \int_{-\infty}^{\infty} x(t) e^{-j 2 \pi f t} \, dt$$

其中：

* $x(t)$ 为时域连续信号；
* $X(f)$ 为频域连续复数频谱；
* $e^{-j 2 \pi f t} = \cos(2\pi f t) - j \sin(2\pi f t)$ 为欧拉公式展开，包含实部（余弦）与虚部（正弦）。

---

### 2.2 离散傅里叶变换（DFT）

计算机处理的是离散的 PCM 数字信号。假设对连续信号采样得到长为 $N$ 的有限长离散序列 $x[n]$（$n = 0, 1, \dots, N-1$），其 **离散傅里叶变换（DFT）** 定义为：

$$X[k] = \sum_{n=0}^{N-1} x[n] e^{-j \frac{2\pi}{N} k n}, \quad k = 0, 1, \dots, N-1$$

其中：

* $X[k]$ 表示第 $k$ 个频率点（Frequency Bin）处的复数响应；
* 频率点 $k$ 对应的实际物理频率为 $f_k = \frac{k \cdot F_s}{N}$（$F_s$ 为采样率）， 是频率的索引，计算出每种频率的旋转波有多少含量；
* **对称性**：若 $x[n]$ 为实数信号，则 $X[k]$ 具有共轭对称性（$X[k] = X^*[N-k]$）。因此对于实数音频信号，只需保留前 $N/2 + 1$ 个点（即 $0 \sim F_s/2$ 的奈奎斯特频段）即可完全重构频域信息。

---

### 2.3 快速傅里叶变换（FFT）

直接计算长度为 $N$ 的 DFT 需要执行 $O(N^2)$ 次复数乘加运算。对于高采样率音频而言计算成本极高。

**快速傅里叶变换（FFT, Fast Fourier Transform）** 是由 Coole 与 Tukey 于 1965 年提出的高效计算算法（利用分治法与旋转因子的周期性/对称性），将复杂度降低至：

$$O(N \log_2 N)$$

在实际工程（如 PyTorch、C++ LibTorch 或 DSP 硬件）中，FFT 是时频转换的底层执行引擎。

---

## 3.短时傅里叶变换（STFT）与时频分析

### 3.1 为什么需要短时傅里叶变换？

* **全局傅里叶变换的局限**：DFT 假设信号是平稳的（Stationary），且积分范围是全时域。它能告诉你信号中“包含哪些频率”，但完全丢失了“这些频率在什么时候发生”的时间信息。
* **语音的短时平稳性（Short-time Stationarity）**：人声通过发声器官（声带、声道）振动产生，受物理结构运动限制，语音信号在 **10ms ~ 30ms** 的极短时间范围内可以近似看作平稳信号。

为了同时捕获时间与频率信息，**短时傅里叶变换（STFT）** 应运而生：通过一个滑动窗函数（Window Function）在时域截取局部片段，对每个局部片段分别进行 FFT，从而得到随时间变化的频率响应。

---

### 3.2 STFT 的数学表达

对于离散信号 $x[n]$，STFT 的数学定义为：

$$X(m, k) = \sum_{n=0}^{N-1} x[n + m \cdot H] \cdot w[n] \cdot e^{-j \frac{2\pi}{N} k n}$$

关键参数含义：

| 参数 | 英文名称 | 说明与推荐值 |
| --- | --- | --- |
| $w[n]$ | **窗函数 (Window Function)** | 用于对截取片段边缘进行平滑，减少频谱泄露，例如汉宁窗或者海明窗 |
| $W$ | **窗长 (Win Length / Frame Length)** | 从原始信号截取的单个时间帧的样本点数，决定时频分辨率的物理权衡（16kHz 采样下通常取 25ms 即 400 点，或 32ms 即 512 点） |
| $N$ | **FFT 长度 (n_fft / FFT Length)** | 每次计算 FFT 使用的点数，必须满足 $N \ge W$。通常补零取 2 的幂次方（如 512 或 1024）以加速计算并插值平滑频谱 |
| $H$ | **帧移 (Hop Length)** | 滑动窗口每次移动的样本点数，通常取 $1/4$ 或 $1/2$ 窗长（如 160 点，对应 10ms） |
| $m$ | **帧索引 (Frame Index)** | 对应时间轴上的第 $m$ 帧 |
| $k$ | **频率频段 (Frequency Bin)** | 对应频率轴上的第 $k$ 个 Bin |
```
时域信号 x[n] ════════════════════════════════════════════════════════════
                  ┌─────────┐
                  │ 窗函数  │ (n_fft)
                  └─────────┘
                  <──Hop───> ┌─────────┐
                             │ 窗函数  │
                             └─────────┘
                                   │
                                   ▼  (每个片段分别做 FFT)
时频矩阵 X(m, k)  [ 帧 1 ][ 帧 2 ][ 帧 3 ] ... ───> 幅度/相位谱

```

---

### 3.3 海森堡不确定性原理（时频分辨率权衡）

在 STFT 中，**时间分辨率与频率分辨率不可兼得**，受制于声学领域的海森堡不确定性原理（Heisenberg Uncertainty Principle）：

$$\Delta t \cdot \Delta f \ge \frac{1}{4\pi}$$

* N 为窗口长度，根据 DFT 公式，窗口大小和频率正相关，和时间分辨率负相关。
* **大窗长（Large `n_fft`）**：时间跨度大，时间分辨率低，但频域点数多，**频率分辨率高**（适合分析乐器谐波、精细音高）。
* **小窗长（Small `n_fft`）**：时间跨度小，**时间分辨率高**，但频域点数少，频率分辨率低（适合定位语音中的爆发音、清音突变）。
* 频率分辨率计算公式:
$$ \Delta f = \frac{\text{sample\_rate}}{\text{n\_fft}} $$
​
> **工业界 ASR / Speech-LLM 通用折中配置（以 16kHz 为例）：**
> * `n_fft(快速傅里叶变换点数)` = 512 或 400（对应 32ms 或 25ms 窗长）
> * `hop_length(跳跃长度)` = 160（对应 10ms 帧移）
> * 这种配置下，1 秒钟音频会被切分为约 100 帧（100 Hz 帧率）。
> 
>

### 3.4 常用窗函数（Window Functions）与频谱泄露

如果直接对信号截断（相当于乘以矩形窗），截断边界处的突变会导致信号能量扩散到邻近频率，称为**频谱泄露（Spectral Leakage）**。为了缓解这一问题，通常使用两端平滑衰减的窗函数：

1. **汉宁窗（Hanning Window, 最常用）**：

$$w[n] = 0.5 - 0.5 \cos\left(\frac{2\pi n}{N-1}\right)$$

- 0.5：这是一个常数系数，用于调整窗函数的幅度比例，确保窗函数的最大值为 1。

    - 当 n=0 时，cos(0)=1，则 w[0] = 0.5 - 0.5×1 = 0；

    - 当 n=(N-1)/2 时，cos(π) = -1，则 w[(N-1)/2] = 0.5 - 0.5×(-1) = 1。

    - 所以，0.5 的作用是使窗函数的两端（n=0 和 n=N-1）归零，中间峰值为 1。

- 负号（-）：表示从常数项中减去余弦项，从而实现两端低、中间高的“钟形”曲线形状。

- 余弦项：这是窗函数的“形状”部分。它决定了一个平滑的余弦波，其频率由分母决定。

- π（圆周率）：约等于 3.14159，用于将角度从“弧度”转换为“周期”的倍数。

- 2：这个因子表示在一个周期内完成一个完整的余弦波形。当 n 从 0 变化到 N-1 时，(2πn)/(N-1) 的取值从 0 变化到 2π，正好走完一个完整的余弦周期。

- N-1：归一化分母。它确保当 n 取到最后一个值 N-1 时，余弦函数的自变量正好是 2π，从而使窗函数两端点值为零。使用 N-1 而不是 N，是为了让窗函数关于中心点 (N-1)/2 完全对称。

旁瓣衰减快，能有效抑制频域泄漏，是 ASR 和 TTS 的默认标准。

2. **海明窗（Hamming Window）**：

$$w[n] = 0.54 - 0.46 \cos\left(\frac{2\pi n}{N-1}\right)$$

- 0.54 和 0.46：这是两个固定的常数系数，它们的和恰好为 1（0.54 + 0.46 = 1.0）。这是海明窗与汉宁窗最大的不同。海明窗通过调整这两个系数（汉宁窗是 0.5 和 0.5），使得窗函数在两端不降为零，而是有一个小的正值（当 n=0 时，w[0] = 0.54 - 0.46 = 0.08）。
这种设计有助于在“主瓣宽度”和“旁瓣衰减”之间取得另一种平衡，使得主瓣稍窄一些（频率分辨力略好），但旁瓣衰减不如汉宁窗那么快。

- 负号（-）：同样用于从常数项中减去余弦项，形成中间高、两端低的形状，但两端不为零。

- 余弦项及其分母：与汉宁窗的余弦项含义完全相同，同样是 (2πn)/(N-1)，确保窗函数在定义域内完成一个完整周期，并保持对称性。

主瓣较窄，频域选择性略好于 Hanning 窗。

w[n]：窗函数的输出值，即第 n 个采样点的幅度权重。它是一个离散序列，n 的取值范围通常是 0 到 N-1。

n：离散时间索引（或采样点序号）。它表示当前计算的是窗序列中的第几个点。注意，索引从 0 开始。

N：窗函数的长度（即包含的采样点总数）。这是一个正整数，通常等于你进行傅里叶变换时选取的信号帧的长度（例如，在语音处理中常取 256、512 或 1024）。

## 4.语谱图（Spectrogram）

经过 STFT 运算后得到的 $X(m, k)$ 是一个**复数矩阵**，包含**幅度信息（Magnitude）**和**相位信息（Phase）**。

### 4.1 幅度谱与功率谱

* **复数表达**：$X(m, k) = \vert{}X(m, k)\vert{} e^{j \phi(m, k)}$
* **幅度谱（Magnitude Spectrogram）**：$M(m, k) = \vert{}X(m, k)\vert{} = \sqrt{\text{Re}^2 + \text{Im}^2}$
* **功率谱（Power Spectrogram）**：$P(m, k) = \vert{}X(m, k)\vert{}^2$
* **对数功率谱（Log-Power Spectrogram / Log-Spectrogram）**：
人耳对声音响度的感知是非线性的对数关系（遵循韦伯-费希纳定律），因此工程上通常会对功率取对数：

$$S_{\text{log}}(m, k) = 10 \cdot \log_{10} \left( \vert{}X(m, k)\vert{}^2 + \epsilon \right)$$



（其中 $\epsilon$ 为防止零取对数的极小常数，如 $10^{-10}$）。

| 概念 / 特征 | 数学表达式 | 物理含义 | 主要用途 / 作用 |
| --- | --- | --- | --- |
| **复数光谱** $X(m,k)$ | $\text{Re} + j\text{Im}$ | STFT 变换后的原始复数结果 | 完整保留幅度与相位，用于信号重构 |
| **幅度谱** $M(m,k)$ | $\sqrt{\text{Re}^2 + \text{Im}^2}$ | 某个时刻、某个频率上的振幅强度 | 表示信号震荡的基础物理强度，取模后不保留相位，不可逆还原 |
| **功率谱** $P(m,k)$ | $\vert X(m,k) \vert^2$ | 某个时刻、某个频率上的物理能量密度 | 量化震荡过程中的能量大小，同样不保留相位信息 |
| **对数功率谱** $S_{\text{log}}(m,k)$ | $10 \cdot \log_{10}(\vert X \vert^2 + \epsilon)$ | 映射为分贝（dB），模拟人耳听觉响度感知 | **压缩动态范围**，突出弱音细节，直接用于生成语谱图与模型特征 |


---

### 4.2 相位谱与其解耦处理

* **相位的意义**：相位 $\phi(m, k) = \arctan\left(\frac{\text{Im}}{\text{Re}}\right)$ 决定了不同正弦波在时间轴上的相对对齐位置。
* **为什么深度学习特征通常丢弃相位？**
人耳对稳态语音的**相位不敏感**（Phase-deafness），语音识别（ASR）、关键词识别（KWS）等任务只需提取对数幅度谱/Mel 频谱即可获得绝大部分语义特征。
* **语音合成（TTS）/ 声码器（Vocoder）中的相位恢复**：
在 TTS 任务中，如果直接对生成的幅度谱进行逆短时傅里叶变换（ISTFT），由于缺少匹配的相位，会导致严重失真或金属杂音。常用解决方案包括：
1. **传统方法**：Griffin-Lim 迭代相位估计算法；
2. **现代方法**：神经网络声码器（如 HiFi-GAN、BigVGAN）从 Mel 频谱直接预测时域波形（内部隐式重建了相位信息）。

## 5.Python / PyTorch 代码实战

在 PyTorch 中，`torch.stft` 与 `torchaudio.transforms.Spectrogram` 是极其高频使用的底层算子。

```python
import torch
import torchaudio
import torchaudio.transforms as T
import matplotlib.pyplot as plt

# 1. 模拟或加载音频数据 (Shape: [Batch, Time])
# 假设 1 秒 16kHz 单声道音频
sample_rate = 16000
waveform = torch.randn(1, sample_rate) 

# 2. 参数定义
n_fft = 512          # FFT 点数 (约 32ms)
win_length = 512     # 窗长
hop_length = 160     # 帧移 (10ms)
window = torch.hann_window(win_length)

# 3. 方法 A: 直接使用 torch.stft 算子
# 返回复数 Tensor, Shape: [Batch, Freq_Bins, Frames, 2] (若 return_complex=False)

# 当 return_complex=True 时，返回复数 [Batch, Freq_Bins, Frames]
# 
# 1. Batch (批大小): 并行处理的音频样本数量。
# 2. Freq_Bins (频域点数): 频率分析通道数，数值大小为 (n_fft // 2) + 1 (即从 0 到奈奎斯特频率)。
# 3. Frames (时间帧数): 滑动窗口切分出的总时间帧数，取决于音频长度与 hop_length 的比例。
# 
# 注：若 return_complex=False，形状为 [Batch, Freq_Bins, Frames, 2]：
#     最后一维 index 0 为实部 (Real)，index 1 为虚部 (Imag)。

stft_complex = torch.stft(
    waveform,
    n_fft=n_fft,
    hop_length=hop_length,
    win_length=win_length,
    window=window,
    return_complex=True
)

# 计算幅度谱 [Batch, Freq_Bins, Frames] (Freq_Bins = n_fft // 2 + 1 = 257)
magnitude_spectrogram = torch.abs(stft_complex)

# 计算对数功率谱 (dB 缩放)
log_power_spectrogram = 10 * torch.log10(torch.pow(magnitude_spectrogram, 2) + 1e-10)

# 4. 方法 B: 使用 torchaudio 高阶 Transform 接口
spec_transform = T.Spectrogram(
    n_fft=n_fft,
    win_length=win_length,
    hop_length=hop_length,
    power=2.0  # 计算功率谱
)
power_spectrogram = spec_transform(waveform)

print(f"输入音频波形 Shape: {waveform.shape}")
print(f"STFT 频谱形状 (Freq_Bins x Frames): {magnitude_spectrogram.shape[1]} x {magnitude_spectrogram.shape[2]}")
# 输出预期: Freq_Bins = 257, Frames = 101 (1000ms / 10ms + 1)

```

## 6.总结与对比

| 概念 | 时域 (Time Domain) | 频域 (Frequency Domain) | 时频域 (Time-Frequency Domain) |
| --- | --- | --- | --- |
| **代表形式** | 原始 PCM 波形 ($x[n]$) | 离散傅里叶变换 ($X[k]$) | 语谱图 ($X(m, k)$) / STFT |
| **数学工具** | 无 / 采样与量化 | DFT / FFT | **STFT / 窗函数截断** |
| **主要优点** | 保持精确的时间采样点 | 直观展示全局频率成分分布 | **兼顾时间与频率局部特征**，拟合人声短时平稳性 |
| **缺点/局限** | 无法直接观察高低音与频段能量 | 彻底丢失时间信息（不知道何时发音） | 受海森堡不确定性原理制约，需权衡时频分辨率 |
| **主流应用场景** | Wav2Vec2/CLAP 底层输入、端到端时域声码器 | 降噪滤波、频域均衡器 | **ASR、TTS、Speech-LLM 的主流输入表示** |
