# 评估指标面试题（语音评估体系与工业界高频考点）

## 1. 概述

评估指标是语音算法岗面试中"人人都会、深挖必挂"的板块：每个候选人都背得出 $\text{WER} = (S+D+I)/N$，但面试官真正想考察的是--编辑距离 DP 怎么拆分三类错误、归一化怎么做才不虚报、MOS 测试为什么要 20 个听者和置信区间、UTMOS 为什么能无参考预测打分、测试集怎么分层才能暴露真实短板、Speech-LLM 时代的基准污染怎么防。

本文档汇总评估指标体系在工业界面试中的高频考点，按"**指标体系对比 -> 核心机制推导 -> 工业界实战 -> 高频问答**"的主线展开，覆盖第 10 章前四篇（WER/CER、MOS/UTMOS、评估与测试集、Speech-LLM 基准测试）的全部核心内容。

| **风险** | 被刷分、与真实听感脱节 | 人群不可控、跨实验不可比 |

| --- | --- | --- | --- | --- |

## 3. 核心机制与推导

### 3.1 编辑距离 DP 与 S/D/I 拆分

设参考 $R$（长 $N$）、假设 $H$（长 $M$），$D(i,j)$ 为 $H$ 前 $i$ 单元与 $R$ 前 $j$ 单元的编辑距离：

$$D(i, j) = \min \begin{cases} D(i-1, j) + 1 & \text{（插入 I：} H \text{ 多出单元）} \\ D(i, j-1) + 1 & \text{（删除 D：漏识 } r_j\text{）} \\ D(i-1, j-1) + \text{cost}(i,j) & \text{（匹配 0 / 替换 S 为 1）} \end{cases}$$

边界：$D(i,0)=i$，$D(0,j)=j$。复杂度 $O(M \times N)$，滚动数组可优化空间至 $O(\min(M,N))$。

**拆分 S/D/I 的关键**：从 $D(M,N)$ 回溯来源方向，每次入栈一个错误类型。三类的**诊断含义**不同：

```
回溯方向          错误类型       典型根因
(↖ + cost=1)  ->  替换 S    ->  口音/同音字/热词缺失
(↑ +1)        ->  插入 I    ->  幻觉、噪声误识为语音（AED 高发）
(← +1)        ->  删除 D    ->  VAD 截断、弱读漏识、LM 偏短输出
```

语料级聚合用 **micro-average**：先累加所有句子的 $S,D,I,N$ 再相除，不能对句级错误率取平均（否则短句主导）。

### 3.2 WER 公式的三个细节

1. **分母固定为参考词数 $N$**：保证不同模型在同一测试集上可比；代价是 $I$ 无上限约束 -> WER 可超 100%，本身就是幻觉信号；
2. **归一化先于打分**：大小写、标点、数字（`五` vs `5`）、简繁、语气词必须两侧统一规则；Whisper 评测必须用官方 `EnglishTextNormalizer`，否则 WER 虚高；
3. **统计显著性**：用 bootstrap 重采样估计 95% 置信区间，两版本差距小于 CI 宽度时不能下结论。

### 3.3 MOS 测试规范（ITU-T P.800）

* **5 级量表**：5 优 / 4 良 / 3 中 / 2 差 / 1 劣，MOS 为所有打分均值；
* **规范要点**：每条件 ≥ 15~24 名听力正常母语听者、安静环境（<30 dBA）、高质量耳机固定音量、样本 3~8 秒、单次听测 ≤ 20~30 分钟、顺序随机化、混入高低锚点样本筛除乱打者；
* **必报置信区间**：

$$\text{CI}_{95\%} = \bar{s} \pm 1.96 \cdot \frac{\sigma}{\sqrt{K \cdot L}}$$

* **核心性质**：MOS 绝对值只在本实验内部可比，跨论文比较 MOS 数字不严谨（人群、锚点、疲劳度都不同）。

### 3.4 UTMOS：无参考 MOS 预测器原理

```
[被测音频 16kHz] --> [wav2vec2 / HuBERT 中间多层特征堆叠 (SSL-stack)] ─┐
      --> [Mel 频谱] ──────────────────────────────────────────────┼--> 拼接 --> [轻量 MLP] --> MOS (1~5)
      --> [8 维人工声学特征: F0/能量/语速/静音比...] ────────────────┘
```

* **训练**：在 VoiceMOS 数据集（BVCC、SOMOS 等数万条"音频-人工MOS"对）上做回归；
* **效果**：与人工 MOS 的 **SRCC ≈ 0.83**（VoiceMOS 2022 主赛道冠军），远超纯 Mel+BLSTM baseline（~0.53）；
* **本质**：SSL 表征中已包含音色/韵律/语义质量信息，MOS 预测只需轻量回归头；
* **边界**：排序能力好，**绝对分有域偏移**（新录音条件下系统性偏高/偏低），不可直接当人工 MOS 汇报。

同类：DNSMOS P.835（SIG/BAK/OVRL 三头）、NISQA、MOS-SSL。评估预测器本身用 **SRCC + KTAU + LCC + RMSE** 四件套（VoiceMOS Challenge 官方指标）。

## 4. 工业界实战：A/B 测试与 badcase 驱动迭代

### 4.1 评估驱动的迭代闭环

```
 ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
 │ 分层测试集│-->│ 客观指标  │-->│ badcase  │-->│ 定向修复  │-->│ 小流量   │
 │ (内/外/脏)│   │ + UTMOS  │   │ 归因聚类 │   │(数据/模型 │   │ A/B 实验 │
 └──────────┘   └──────────┘   └──────────┘   │ /后处理)  │   └────┬─────┘
      ▲                                        └──────────┘        │
      └────────────── badcase 入库 + 回归集沉淀 ←────────────────────┘
```

### 4.2 语音方向的 A/B 测试要点

1. **线上 A/B**：新旧模型各分流 5%~50% 真实流量，比较**业务指标**（转写可用率、字幕修改率、对话任务完成率、用户中断率）与**代理指标**（线上采样 CER、UTMOS）；
2. **代理指标校准**：上线前先用离线集验证"离线 CER 变化 -> 线上业务指标变化"的历史相关性，相关性差的代理指标会误导决策；
3. **听感类用 CMOS**：TTS/增强类改动，模型发布前做同批听者的 CMOS/AB 测试，CMOS > 0 且 CI 不含 0 才算真实提升；
4. **防新奇效应**：语音交互的用户行为在新版本上线初期会漂移，观察期要足够（1~2 周）。

### 4.3 badcase 分析流程（面试高频）

1. 打分保留对齐结果，按 **S/D/I** 拆分（见 3.1 的诊断表）；
2. 按归因维度打标签聚类统计：

| 归因类别 | 典型表现 | 修复手段 |
| --- | --- | --- |
| 口音/方言 | 声学偏移致替换错 | 口音数据增补加权、多方言联合训练 |
| 专有名词/热词 | 人名产品名错 | contextual biasing、浅融合加成 |
| 噪声/混响 | 远场漏识 | 前端增强、多条件训练 |
| 数字/格式 | 日期金额手机号错 | TN 规则、约束解码 |
| 幻觉/重复 | 静音段出字 | no-speech 阈值、重复惩罚 |
| 标注问题 | 参考文本本身错 | 先剔除（通常占 5%~10%） |

3. 按错误量 x 业务权重排优先级，修复后 badcase 转入回归集防复发。

### 4.4 测试集分层速记

* **内测 vs 外测**：内测管回归、外测管泛化；内升外降 = 过拟合警报；
* **纯净 vs 脏测**：加噪/RIR/codec 仿真 + 真实回流；两者跷跷板必须同时报告；
* **说话人隔离**：测试说话人绝不能进训练集（否则指标虚高数个点）；
* **流式专项**：CER-Latency 帕累托曲线 + 中间结果闪烁率，需词级时间戳标注。

## 5. 核心代码：WER 计算与显著性检验

```python
import numpy as np
from typing import List, Tuple


def edit_distance_with_ops(hyp: List[str], ref: List[str]) -> Tuple[int, int, int]:
    """编辑距离 DP + 回溯拆分 S/D/I（以参考为基准：I=模型多识, D=模型漏识）"""
    M, N = len(hyp), len(ref)
    dp = [[0] * (N + 1) for _ in range(M + 1)]
    for i in range(M + 1):
        dp[i][0] = i
    for j in range(N + 1):
        dp[0][j] = j
    for i in range(1, M + 1):
        for j in range(1, N + 1):
            cost = 0 if hyp[i-1] == ref[j-1] else 1
            dp[i][j] = min(dp[i-1][j] + 1,      # I: hyp 多出
                           dp[i][j-1] + 1,      # D: ref 被漏
                           dp[i-1][j-1] + cost) # 匹配/替换
    # 回溯
    S = I = D = 0
    i, j = M, N
    while i > 0 or j > 0:
        if i > 0 and j > 0 and dp[i][j] == dp[i-1][j-1] + (0 if hyp[i-1] == ref[j-1] else 1):
            if hyp[i-1] != ref[j-1]:
                S += 1
            i, j = i - 1, j - 1
        elif i > 0 and dp[i][j] == dp[i-1][j] + 1:
            I += 1
            i -= 1
        else:
            D += 1
            j -= 1
    return S, D, I


def corpus_wer(hyps: List[List[str]], refs: List[List[str]]) -> dict:
    """语料级 micro-average：累加 S/D/I/N 后再相除"""
    tot_S = tot_D = tot_I = tot_N = 0
    for h, r in zip(hyps, refs):
        s, d, ins = edit_distance_with_ops(h, r)
        tot_S += s; tot_D += d; tot_I += ins; tot_N += len(r)
    return {"S": tot_S, "D": tot_D, "I": tot_I, "N": tot_N,
            "WER": (tot_S + tot_D + tot_I) / tot_N}


def bootstrap_wer_ci(hyps, refs, n_boot=1000, seed=0):
    """bootstrap 重采样估计 WER 的 95% 置信区间"""
    rng = np.random.default_rng(seed)
    n = len(refs)
    wers = []
    for _ in range(n_boot):
        idx = rng.integers(0, n, n)
        wers.append(corpus_wer([hyps[k] for k in idx], [refs[k] for k in idx])["WER"])
    return float(np.percentile(wers, 2.5)), float(np.percentile(wers, 97.5))


if __name__ == "__main__":
    hyps = [["i", "am", "very", "happly"], ["the", "the", "cat", "sleeps"]]
    refs = [["i", "am", "very", "happy"], ["the", "cat", "sleeps"]]
    res = corpus_wer(hyps, refs)
    print(res)   # S=1, I=1, N=6 -> WER = 2/6 ≈ 33.3%
    lo, hi = bootstrap_wer_ci(hyps, refs)
    print(f"95% CI: [{lo:.3f}, {hi:.3f}]")
```

生产工具：**jiwer**（HF `evaluate` 底层）、torchmetrics `WordErrorRate/CharErrorRate`、NIST SCTK（输出逐词 S/D/I 对齐报告）、`torch.hub` 的 `utmos22_strong`（一行 MOS 预测）。

## 6. 高频面试问答 (Q&A)

### Q1: WER 为什么可以超过 100%？这说明了什么？

**答**：WER 分母固定为参考词数 $N$，而分子中的插入 $I$ 没有上限。当模型幻觉输出大量参考中不存在的词时（典型如 Whisper 类 AED 在长静音、强噪声、非语音段的自回归死循环），$S+D+I > N$，WER 即超 100%。这本身是一个**免费的幻觉检测信号**：线上如果某场景 WER 显著超 100% 或插入错误占比异常，优先排查幻觉（VAD 前置、no_speech 阈值、重复惩罚、temperature fallback）。

---

### Q2: 中文为什么用 CER 而不是 WER？两者数值能直接比较吗？

**答**：中文没有空格分词，"词"的边界依赖分词器且分词标准不统一（PKU/MSR/jieba 各不相同），分词误差会污染评估、指标不可复现；以汉字为原子单元是唯一无歧义的对齐方式，因此中文统一用 CER。数值上不能直接比：英文一个多字符词错记 1 个 WER 错误，中文一个字错记 1 个 CER 错误，中文单字信息密度高、错误粒度细，同水平系统 CER 通常显著低于英文 WER。中英混排时按"汉字逐字 + 英文按词 + 数字归一化后切分"的口径统一处理。

---

### Q3: 两条识别结果："很开心"识别成"很高兴"，和漏掉一个"不"字，CER 相同吗？说明什么问题？

**答**：前者记 2 次替换、后者记 1 次删除，CER 上前者反而"更差"，但语义上后者（否定丢失，意思完全反转）远比前者（同义替换，语义不变）严重。这暴露了 WER/CER 的两大缺陷：**所有错误等权**、**对语义等价替换惩罚过重**。LLM 时代尤其突出，补救方案：(1) 语义级指标（BERT-Score、LLM-as-a-Judge 按要点打分）；(2) 业务加权指标（否定词/数字/实体错加权，NER-F1）；(3) 数字单独报数字 CER。工业报告应"通用 CER + 关键实体准确率 + 语义指标"组合。

---

### Q4: 详细说一下 MOS 测试怎么做才规范？为什么论文里的 MOS 不能直接横向比较？

**答**：按 ITU-T P.800：(1) 每条件 ≥ 15~24 名听力正常的母语听者；(2) 安静环境（<30 dBA）、高质量耳机、固定校准音量；(3) 每条样本 3~8 秒、单次听测 ≤ 20~30 分钟防疲劳；(4) 样本与系统顺序对每人随机化；(5) 混入已知质量的高低锚点样本，事后剔除乱打者；(6) 报告均值 + 95% 置信区间 $\bar{s} \pm 1.96\sigma/\sqrt{KL}$，比较用 t 检验/Wilcoxon。不能横比的原因：打分人群的宽严、锚点设置、样本难度、疲劳程度、语言背景全部不同，人群间绝对分漂移可达 0.3~0.5。跨系统严格比较要用同一批听者（被试内设计）+ CMOS 相对分，或 Z-score 归一化消除个人宽严。

---

### Q5: UTMOS 是怎么做到无参考预测 MOS 的？它能不能替代人工听测？

**答**：原理是"SSL 表征 + MOS 回归"：wav2vec2/HuBERT 中间多层特征堆叠（蕴含音色、韵律、语义质量信息）+ Mel 频谱 + 8 维人工声学特征（F0/能量/语速/静音比等），拼接后过一层小 MLP 回归 MOS，在 VoiceMOS 数万条"音频-人工 MOS"对上训练，与人工分 SRCC 约 0.83。不能完全替代：(1) 绝对分存在域偏移，换录音条件系统性偏高/偏低，只宜做排序和监控；(2) 会被间接"刷分"（模型优化方向偏向预测器偏好而非真实听感）。工业实践：训练/回归阶段用 UTMOS/DNSMOS 做海量初筛与线上监控，**版本发布决策必须补人工 CMOS/AB 确认**。

---

### Q6: 如何设计一个测试集，才能保证模型上线后不掉链子？

**答**：五条原则：(1) **场景覆盖矩阵**：设备/距离/噪声/口音/领域/特殊事件（重叠说话、长静音）维度组合，逐格补足样本；(2) **难度分层**：纯净朗读/真实口语/口音/远场/热词分桶报告，防总分掩盖短板；(3) **说话人隔离与均衡**：测试说话人绝不进训练集，长尾人群（口音/儿童/老人）超采样，单人条数设上限；(4) **内测 + 外测 + 脏测**：内测管回归、外测（跨域/跨信道）管泛化、脏测（加噪/RIR/codec 仿真 + 线上回流）管鲁棒性，跷跷板现象同时呈现；(5) **冻结与置信**：测试集冻结保证历史可比，每桶 ≥ 数百句，bootstrap CI 判断版本差异显著性。流式系统另建带词级时间戳的测试集，报 CER-Latency 帕累托曲线。

---

### Q7: 线上模型 CER 5%，新模型离线 CER 4.5%，可以直接全量上线吗？

**答**：不可以，至少四步：(1) **显著性**：0.5 个点的差距是否超出 bootstrap CI 宽度？桶内样本少时可能是噪声；(2) **分桶核查**：总分提升是否掩盖某些场景（如远场、口音桶）退化；(3) **业务指标验证**：离线 CER 与线上业务指标（字幕修改率、任务完成率）的历史相关性是否成立，做小流量线上 A/B 观察 1~2 周（防新奇效应）；(4) **主观确认**：若涉及音质/听感（TTS/增强），补人工 CMOS。工业界大量案例是"离线赢 0.5 点、线上无感甚至负向"，评估与决策必须分层。

---

### Q8: 评估 Speech-LLM（语音大模型）和评估传统 ASR/TTS 有什么本质区别？主要基准有哪些？

**答**：本质区别：(1) 输出开放式（问答/指令），无唯一参考文本，WER/BLEU 失效，需要 **LLM-as-a-Judge** 或可验证规则（多选、约束校验）；(2) 感知与理解耦合，需要 **speech-text gap**（同题语音版 vs 文本版分差）区分"听错"还是"不会"；(3) 能力多维（识别/翻译/音频理解/指令遵循/对话）。主要基准选型：表征理解选 **SUPERB/SUPERB-SR**（10 项理解 + 恢复任务）；多语 ASR/ST 选 **SpeechBench**；Audio-LLM 选 **AudioBench**（语音+音频+音色三板块）；语音助手选 **VoiceBench**（文本基准 TTS 语音化 + GPT-4 判分）与 **Sakura 系列**（SESB 语音化 MMLU、Speech-IFEval 可验证指令遵循、Speech-MT LLM 裁判翻译评测）；TTS/克隆选 **Seed-TTS eval**（WER + SIM + SWS/SPCUR/SFR/SDR 韵律四指标）+ **TTS Arena**（众包 Elo）。

---

### Q9: 什么是基准污染？语音领域的基准污染比 NLP 更严重吗，怎么防？

**答**：污染指测试数据泄漏进训练数据导致指标虚高。语音更严重的原因：LibriSpeech/CommonVoice 等**音频与文本均公开可爬**，语音 LLM 的海量预训练语料极可能包含基准本身，模型可以"背答案"。识别信号：基准分数异常高但自录同分布音频明显变差；对测试集做扰动（加噪/变速/换说话人/TTS 重合成）后大幅掉分即疑似背诵。防护手段：(1) 私有留出集永不公开（对外报公开榜、对内用私有集决策）；(2) 动态/程序化生成基准（Dynamic-SUPERB）；(3) 训练语料与基准做 n-gram 重叠扫描，命中剔除；(4) LLM 裁判去偏（交换顺序、双裁判一致性、人工抽检校准）；(5) Arena 类榜单匿名复测、限制投票频控。

---

### Q10: 评估声音克隆系统需要哪些指标？各覆盖什么维度？

**答**：三维度拆解：(1) **内容**：WER（ASR 转写生成语音 vs 目标文本）、SWS（基于 ASR 词级时间戳的词相似度）；(2) **音色**：SIM/SECS（ECAPA-TDNN 说话人嵌入与参考的余弦相似度），主观对应 SMOS；(3) **韵律/副语言**：Seed-TTS eval 提出的 SPCUR（停顿正确性）、SFR（音高能量波动率）、SDR（时长比率），主观对应 ABX（X 与目标真声是否可区分，正确率越接近 50% 越逼真）。完整评估 = 客观（上述自动化指标）+ 主观（SMOS + MOS 自然度 + ABX），只报 SIM 和 WER 会漏掉"停顿语调像不像"这一克隆体验的关键。

---

## 7. 总结

* **体系观**：客观指标（WER/CER/PESQ/UTMOS）管高频回归与初筛，主观评测（MOS/CMOS/AB/ABX/SMOS）管发布决策；两者互补而非替代，UTMOS 类 MOS 预测器（SRCC ~0.8）是有价值的中间层。
* **机制观**：编辑距离 DP 回溯拆分 S/D/I 是 badcase 归因的基石（替换=口音/热词、删除=VAD/漏识、插入=幻觉）；MOS 的规范性（人群、随机化、锚点、CI）决定数据可信度；UTMOS 本质是 SSL 表征上的 MOS 回归。
* **实战观**：分层测试集（内/外、脏/纯净、长音频/流式）+ S/D/I 归因聚类 + badcase 回归入库 + 离线指标到线上 A/B 的分层决策，是工业界评估迭代的完整闭环。
* **时代观**：Speech-LLM 评估转向"客观 + 可验证规则 + LLM-as-a-Judge"三件套，speech-text gap 与基准污染（背诵、刷榜、裁判偏置）成为新的核心考点，私有留出集与动态基准是终极防线。
