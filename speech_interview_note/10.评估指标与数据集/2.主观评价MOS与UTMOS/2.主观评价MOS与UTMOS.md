# 2. 主观评价 MOS 与 UTMOS

## 1. 概述

WER/CER 这类客观指标只能回答"识别得准不准"，而语音合成（TTS）、语音增强、编解码、声音克隆等方向的核心问题是"**听上去好不好**"。这类质量感知问题目前仍以**主观听测（Subjective Listening Test）**为金标准，其中最通用的范式就是 **MOS（Mean Opinion Score，平均意见得分）**。

但主观测试昂贵、缓慢、不可复现（每次都要重新招人听），因此工业界发展出两条互补路线：

* **侵入式客观指标**（需要干净参考）：PESQ、STOI、VISQOL；
* **无参考客观指标**（只要被测音频）：UTMOS、DNSMOS、NISQA 等基于深度学习的 **MOS 预测器（MOS Predictor）**，用神经网络直接回归人类打分。

```
                 ┌──────────────────────────────────────────┐
                 │              语音质量评估                 │
                 └──────────────────────────────────────────┘
                          │                            │
                  主观评测 (金标准)               客观评测 (低成本代理)
                          │                            │
        ┌─────────┬───────┴──────┬─────────┐    ┌──────┴──────┐
        │         │              │         │    │             │
       MOS      CMOS          AB / ABX   SMOS  侵入式        无参考
    (绝对质量) (相对比较)     (偏好选择) (相似度)  PESQ/STOI   UTMOS/DNSMOS
                                                  VISQOL      NISQA
```

本文按"主观测试规范 -> 各种主观范式 -> 客观 MOS 预测器 -> 主客观相关性"的主线展开。

## 2. MOS 定义与测试规范

### 2.1 MOS 定义

MOS 源自电信语音质量评价，由 **ITU-T P.800** 标准化。听者对每条语音的总体质量在 **5 级量表**上打分：

| 分数 | 质量等级 | 典型描述 |
| --- | --- | --- |
| 5 | Excellent（优） | 与自然人声无差别 |
| 4 | Good（良） | 略有可闻失真，不影�响听感 |
| 3 | Fair（中） | 有明显失真，略感不适 |
| 2 | Poor（差） | 失真严重，需要努力才能听懂 |
| 1 | Bad（劣） | 无法接受/难以听懂 |

单个系统的 MOS 为所有听者所有样本打分的算术平均：

$$\text{MOS} = \frac{1}{K \cdot L}\sum_{k=1}^{K}\sum_{l=1}^{L} s_{k,l}$$

其中 $K$ 为听者数、$L$ 为每人的样本数、$s_{k,l} \in \{1,2,3,4,5\}$。

**典型量级参考**：

| 系统 | MOS 大致区间 |
| --- | --- |
| 电话带宽（300~3400Hz）传统语音 | 3.0 ~ 4.0 |
| Opus/EVS 高码率编解码 | 4.2 ~ 4.5 |
| 真人高清录音 | 4.6 ~ 4.9 |
| VITS / 商用 TTS（如 Seed-TTS、Vivoice） | 4.0 ~ 4.5（论文报告值，受打分人群影响大） |
| 强噪声/丢包退化语音 | 1.5 ~ 2.5 |

> **面试要点**：论文里的 MOS 普遍偏高且互不可比（打分人群、样本、锚点、疲劳程度都不同）。**MOS 只有在同一实验、同一批听者内部才有可比性**，跨论文比较 MOS 数值是不严谨的。

### 2.2 ITU-T P.800 测试规范要点

P.800 对实验室 MOS 测试有严格规定：

1. **听者数量**：每条件至少 **15~24 人**以上（统计稳定通常要求 ≥ 20；顶会 TTS 论文常见 20~50 人）；
2. **听者要求**：听力正常（可先做听力筛查）、母语或目标语言使用者、此前未深度参与该系统开发（避免偏见）；
3. **试听环境**：安静房间（环境噪声 < 30 dBA）、高质量耳机、固定音量校准；
4. **样本长度**：每条 3~8 秒为宜；
5. **会话时长控制**：单次听测不超过 20~30 分钟，防止听者疲劳导致打分离散；
6. **随机化**：样本顺序、系统顺序对每位听者随机打乱，消除顺序效应；
7. **暗锚/明锚**（Anchors）：混入已知质量的样本（如原始录音为高锚、强降质样本为低锚），用于事后筛除乱打的听者。

### 2.3 置信区间与显著性

MOS 是随机变量的均值估计，论文报告必须附带 **95% 置信区间（CI）**：

$$\text{CI}_{95\%} = \bar{s} \pm 1.96 \cdot \frac{\sigma}{\sqrt{K \cdot L}}$$

* $\sigma$ 为打分标准差（人群分歧大时 CI 宽）；
* 常见画法：MOS 柱状图 + 误差棒（error bar）；
* 判断 A 系统是否显著优于 B：比较均值差与 CI 重叠情况，或做 **t 检验 / Wilcoxon 检验**。两个系统 MOS 差 0.05 而 CI 半宽 0.15 时，结论无效。

### 2.4 人群内嵌校准（论文实践）

由于绝对分数跨人群漂移，严格对比实验还常用：

* **同批听者评所有系统**（被试内设计，within-subject）；
* **Z-score 归一化**：对每位听者的打分减去其人均值、除以其标准差，消除个人宽严差异（MUSHRA 风格）；
* **暗锚筛人**：剔除对高锚打分低于 4 或对低锚打分高于 3 的不可靠听者。

## 3. 其他主观评测范式

### 3.1 CMOS（Comparative MOS，相对 MOS）

听者对**同一段文本的两个系统输出 A/B** 按 7 级量表打相对分：-3（A 差得多）~ 0（一样）~ +3（A 好得多）。

$$\text{CMOS} = \frac{1}{K L}\sum c_{k,l}, \quad c \in \{-3,-2,-1,0,+1,+2,+3\}$$

* **用途**：A/B 迭代对比（新模型 vs 线上模型），对样本内差异更敏感，消除人群绝对分漂移；
* **解读**：CMOS > 0 且 CI 不含 0，说明新系统显著更好。工业界模型上线前常用 CMOS 判断"听感是否真的提升"。

### 3.2 AB Test（偏好测试）

听者听同一文本的两个输出，二选一："A 更好 / B 更好 / 持平"。报告各选项比例。简单直接，适合大样本众测（如 TTS Arena 就是大规模 AB 投票的变体）。注意持平选项的设置会影响结论解读。

### 3.3 ABX Test

听者先听样本 A 和 B（两个不同来源），再听样本 X，判断 X 来自 A 还是 B。**广泛用于说话人相似度/声音克隆评估**：X 是克隆语音，A 是目标说话人真声，B 是另一位说话人。若克隆完美，理论上无法区分，正确率应接近 50%（随机水平）；正确率越接近 50% 克隆越逼真。

### 3.4 SMOS（Similarity MOS）

针对声音克隆的相似度主观分：听者对"合成语音与目标说话人真声的相似程度"打 1~5 分（5 = 完全是同一个人）。Seed-TTS、CosyVoice 等论文同时报告 **SMOS（相似度）+ MOS/MOS-net（自然度）** 两个维度。

### 3.5 各范式对比

| 范式 | 量表 | 衡量维度 | 典型用途 | 成本 |
| --- | --- | --- | --- | --- |
| MOS | 1~5 绝对分 | 整体质量/自然度 | 系统级质量报告 | 高 |
| CMOS | -3~+3 相对分 | 两系统相对优劣 | 迭代 A/B 对比 | 中 |
| AB/Preference | 选择题 | 偏好 | 上线决策、众测 | 低 |
| ABX | 判断来源 | 可区分性 | 声音克隆相似度 | 中 |
| SMOS | 1~5 绝对分 | 说话人相似度 | 克隆/变声评估 | 高 |

## 4. 语音质量的三个维度

讨论 MOS 时必须先明确在测哪个维度，不同任务关心点不同：

| 维度 | 定义 | 主流度量 |
| --- | --- | --- |
| **自然度 (Naturalness)** | 听起来像不像真人说的话：韵律、音色、连贯性、有无机器味/电音/气泡音 | MOS (Naturalness)、MOS-net |
| **相似度 (Similarity)** | 与目标说话人（音色）有多像 | SMOS、Speaker Embedding 余弦相似度（ECAPA-TDNN）、ABX |
| **可懂度 (Intelligibility)** | 内容能不能被听懂，尤其噪声/损毁条件下 | STOI、ESTOI、词正确率（WAcc，不含插入） |

```
       语音质量
          │
   ┌──────┼──────────┐
自然度   相似度     可懂度
(MOS)   (SMOS)    (STOI/WAcc)
"像人吗" "像他吗"  "听懂吗"
```

三者独立：一个电音很重的克隆语音可能相似度高但自然度低；一个清晰的陌生人声自然度高但相似度为零。

## 5. 客观指标：PESQ / STOI / VISQOL / UTMOS

### 5.1 侵入式（需要干净参考）指标

#### PESQ（ITU-T P.862）

* **原理**：将干净参考信号与退化信号分别映射到**响度/感知域**（仿人耳听觉的 Bark 频率尺度 + 响度压缩），在感知域中对比两者的差异（时间对齐 + 频率失真加权），经认知模型映射到 -0.5 ~ 4.5 的 MOS-like 分数。
* **流程**：电平对齐 -> IRS 滤波 -> Bark 谱 + 响度变换 -> 时间对齐 -> 失真密度计算 -> Bad/Symmetrical 分量组合 -> PESQ 分。
* **适用**：编解码、语音增强（有干净参考）；
* **局限**：只针对窄带(8kHz)/宽带(16kHz)；对高阶失真（时间拉伸、机器学习类失真）相关性下降；不可用于评估 TTS（无"干净参考"概念）。

#### STOI（Short-Time Objective Intelligibility）

* **原理**：计算退化信号与参考信号在短时（386ms 帧）频带能量上的**归一化互相关**，对可懂度相关性高：
$$d = \frac{1}{J}\sum_j \frac{\mathbf{x}_j^{\top}\mathbf{y}_j}{\Vert\mathbf{x}_j\Vert \Vert\mathbf{y}_j\Vert}$$
* 输出 0~1，与语音可懂度（词正确率）相关性约 0.9+；
* 计算快、无需训练模型，是增强论文标配可懂度指标。

#### VISQOL（Google, Quality of Experience）

* 使用**频谱时间相似度（NSIM）**：提取 Gammatone 频谱图中的局部相似度块，聚合为 1~5 分；
* 支持宽带与全频带（音乐+语音），是 PESQ 的现代化替代，Google 在 DNS Challenge 中推广。

#### 对比

| 指标 | 类型 | 分数范围 | 依赖参考 | 主要场景 | 标准 |
| --- | --- | --- | --- | --- | --- |
| PESQ | 侵入式 | -0.5 ~ 4.5 | 需要 | 编解码/增强 | ITU-T P.862 |
| POLQA | 侵入式 | 1 ~ 4.5 | 需要 | 现代网络语音（PESQ 升级版） | ITU-T P.863 |
| STOI | 侵入式 | 0 ~ 1 | 需要 | 可懂度预测 | 学术 |
| VISQOL | 侵入式 | 1 ~ 5 | 需要 | 宽带/全频带质量 | Google 开源 |
| UTMOS / DNSMOS | **无参考** | 1 ~ 5 | **不需要** | 真实场景/TTS/盲评 | 学术开源 |

### 5.2 UTMOS：无参考 MOS 预测器

**UTMOS**（VoiceMOS Challenge 2022 冠军，Sakaue et al.）是一个**无需参考音频、直接预测人耳 MOS 的回归模型**。

* **架构**：SSL 特征（wav2vec 2.0 / HuBERT 中间多层特征，"SSL-stack"）+ 多域特征（Mel 频谱 + 8 种信号处理声学特征）拼接，过轻量全连接层（1 层 hidden=128 的 MLP）回归 MOS；
* **训练数据**：VoiceMOS 数据集，包含 VoiceMOS 2022 主赛道数据（如 BVCC，约 7000+ 句带 MOS 标注样本）+ 一批众测数据（SOMOS 等），合计数万条"音频-MOS"对；
* **输入特征三大类**：
  1. 自监督表征：wav2vec2 第 1~12 层 hidden states 堆叠，捕捉音色/语义/韵律；
  2. Mel 频谱；
  3. 人工声学特征：F0 统计、能量、语速、静音比例等 8 维（对域偏移更稳）。
* **效果**：在 VoiceMOS 2022 Track1（主赛道）上与人类 MOS 的 **SRCC（Spearman 相关）约 0.83**，显著超过 baseline（仅用 Mel+MLP 的 BLSTM，SRCC ~0.53）；
* **用法**：`utmos` / `utmos22` 开源权重一行推理，输出 1~5 连续分。工业界常称其输出为 **MOS-net / predicted MOS / MOS^*`，TTS 论文标配自动指标。

同类无参考 MOS 预测器：

* **DNSMOS / DNSMOS P.835**：微软为 DNS Challenge 设计，P.835 版本分三头输出 **SIG（语音质量）/ BAK（背景噪声）/ OVRL（整体）** 三个分；
* **NISQA**：非侵入式质量评估，兼容多场景；
* **MOS-SSL / UTMOS-strong**：后续更强化的 SSL 回归版本。

### 5.3 客观指标能否替代主观评测

**结论：不能完全替代，但可以做高效的初筛与回归监控。**

* **有参考场景**（增强/编解码）：PESQ/POLQA 与人工 MOS 的相关系数可达 0.8+，接近可用，但对新型失真（神经网络失真、时间拉伸）仍会失效；
* **无参考场景**（真实录制/TTS）：UTMOS 类预测器 SRCC 0.8 左右，**排序能力不错，绝对分值有域偏移**（在新录音条件下系统性偏高/偏低）；
* **工业实践**：训练/回归阶段用 UTMOS/DNSMOS 做海量筛选与监控，**版本发布前仍必须做小规模人工 MOS/CMOS 确认**，防止预测器被对抗性地"刷分"（如模型优化方向偏向预测器偏好而非真实听感）。

## 6. 主观与客观的相关性度量

评估一个客观指标"学得像不像人"，标准做法是在留出集上计算其预测分数与人工分的**排序/数值相关性**：

| 度量 | 定义 | 特点 |
| --- | --- | --- |
| **Pearson (LCC)** | 线性相关系数 | 衡量数值接近程度 |
| **Spearman (SRCC)** | 秩相关系数 | 衡量排序一致性，VoiceMOS 主指标 |
| **KTAU (Kendall)** | 一致对比例 | 同为排序型，更稳健 |
| **RMSE** | 预测-人工分均方根误差 | 绝对偏差 |

VoiceMOS Challenge 官方指标即 **SRCC + KTAU + LCC + RMSE** 四件套。

## 7. Python 实践：UTMOS 推理与 PESQ/STOI 计算

```python
# pip install utmos  (或下载官方 torchscript: utmos22.pt)
# pip install pesq pystoi

import torch
import torchaudio
import numpy as np

# ---------- 1. UTMOS: 无参考 MOS 预测 ----------
predictor = torch.hub.load("tarepan/SpeechMOS:v1.2.0", "utmos22_strong", trust_repo=True)

wav, sr = torchaudio.load("tts_output.wav")
assert sr == 16000, "UTMOS 要求 16kHz"
score = predictor(wav, sr)          # 输入 [1, T]，输出 1~5 连续分
print(f"UTMOS (predicted MOS): {score.item():.3f}")

# ---------- 2. PESQ: 侵入式质量 (窄带 nb / 宽带 wb) ----------
from pesq import pesq

ref, _ = torchaudio.load("clean.wav")     # [1, T]
deg, _ = torchaudio.load("enhanced.wav")
ref_np = ref.squeeze(0).numpy()
deg_np = deg.squeeze(0).numpy()
pesq_wb = pesq(16000, ref_np, deg_np, "wb")   # 宽带模式, 输出 -0.5~4.5
print(f"PESQ (wideband): {pesq_wb:.3f}")

# ---------- 3. STOI: 可懂度 ----------
from pystoi import stoi

stoi_score = stoi(ref_np, deg_np, 16000, extended=False)  # 0~1
print(f"STOI: {stoi_score:.3f}")

# ---------- 4. 简易相关性评估 (预测器 vs 人工MOS) ----------
from scipy.stats import spearmanr, pearsonr

pred_scores = np.array([3.2, 4.1, 2.8, 4.5, 3.9])   # UTMOS 对 5 个系统
human_mos   = np.array([3.0, 4.3, 2.5, 4.6, 4.0])   # 人工 MOS
print(f"SRCC: {spearmanr(pred_scores, human_mos).statistic:.3f}")
print(f"LCC : {pearsonr(pred_scores, human_mos).statistic:.3f}")
```

工程提示：UTMOS/DNSMOS 输入需重采样到 16kHz 单声道；同一批评估请固定模型版本与采样率，保证分数可比。

## 8. 总结与最佳实践

* **MOS 是金标准但昂贵且不可跨实验比较**：严格遵循 P.800 规范（≥20 听者、随机化、锚点、报告 95% CI），绝对值只在本实验内部有意义。
* **范式选型**：整体质量用 MOS；迭代对比用 CMOS/AB；声音克隆相似度用 SMOS + 说话人向量余弦 + ABX；噪声下可懂度用 STOI/词正确率。
* **三维度拆分**：自然度 / 相似度 / 可懂度相互独立，报告时明确区分，避免笼统的"音质好"。
* **客观指标分层使用**：有参考场景 PESQ/POLQA/VISQOL；无参考场景 UTMOS/DNSMOS/NISQA 做 MOS 预测（SSL 表征 + MOS 回归，SRCC ~0.8）。
* **工业组合拳**：训练监控用 UTMOS/DNSMOS（免费、秒级、可海量），版本发布决策必须补人工 CMOS/AB；发布任何 MOS 数字必须带置信区间与测试条件说明。
