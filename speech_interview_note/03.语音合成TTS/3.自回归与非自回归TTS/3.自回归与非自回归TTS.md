# 3. 自回归与非自回归TTS

## 1. 概述

端到端 TTS 的解码器存在两条根本不同的技术路线：

* **自回归（Autoregressive, AR）**：Mel 谱逐帧生成，第 $t$ 帧依赖第 $t-1$ 帧（Tacotron 2、DurIAN、Transformer-TTS）。音质高（历史帧提供强先验），但**推理慢、attention 对齐易失败、无法精确控制时长**。
* **非自回归（Non-Autoregressive, NAR）**：所有帧并行一次性生成（FastSpeech 1/2、StyleTTS 的梅尔解码器）。**速度快 1~2 个数量级、鲁棒、时长显式可控**，但早期音质存在"多对一映射"导致的过平滑问题。

本篇围绕三组核心展开：AR vs NAR 的理论权衡、FastSpeech 系列的 length regulator / duration predictor / non-attention 机制、以及 NAR 音质补全路线（VAE-based StyleTTS、iterative refinement 的 Grad-TTS）。

```
                 文本 (Phonemes)
                      │
        ┌─────────────┴──────────────┐
        ▼ AR 路线                     ▼ NAR 路线
  ┌──────────────┐            ┌──────────────────┐
  │ Attention    │            │ Duration         │
  │ (隐式对齐)    │            │ Predictor (显式)  │
  └──────┬───────┘            └────────┬─────────┘
         ▼                             ▼
  ┌──────────────┐            ┌──────────────────┐
  │ AR Decoder   │ 逐帧串行    │ Length Regulator │ 按时长复制帧
  │ RNN/Transf.  │═══════════>│ + NAR Decoder    │ 全帧并行
  └──────┬───────┘   慢/不稳   └────────┬─────────┘   快/稳
         ▼                             ▼
      Mel 谱                         Mel 谱
   (Tacotron2/DurIAN)            (FastSpeech2/Grad-TTS)
```

## 2. AR vs NAR：理论权衡

### 2.1 数学视角：多对一映射

AR 模型学习 $p(y_t \mid y_{<t}, x)$，条件分布是**单峰的**（历史帧已确定上下文）；NAR 模型学习 $p(y \mid x)$ 中每个 $y_t$ 仅依赖源文本 $x$ 与时长对齐，当一句话存在多种合理发音（不同 F0、能量、停顿）时，NAR 对 $p(y_t \mid x)$ 建模会得到**多个目标平均后的模糊分布**--这就是 NAR 谱过平滑（over-smoothing）、听感"闷"的理论根源。

### 2.2 核心权衡对比

| 维度 | AR（Tacotron2 / DurIAN） | NAR（FastSpeech2 / Grad-TTS） |
| --- | --- | --- |
| **推理速度（RTF）** | GPU 0.1~0.5（逐帧串行） | **GPU 0.01~0.05（并行，快 10~70x）** |
| **对齐稳定性** | 依赖 attention，长句易重复/跳读 | **时长显式给定，天然单调** |
| **音质上限** | 高（MOS 4.5+） | 略低，靠 variance adaptor / VAE / 扩散补齐 |
| **谱细节** | 清晰（条件生成单峰） | 易过平滑，高频细节弱 |
| **时长控制** | 只能全局缩放，无法逐音素控制 | **逐音素时长可编辑（语速/停顿控制）** |
| **流式潜力** | 可边算边出帧 | 整句并行，需 chunk 切分做流式 |
| **训练数据效率** | 单句即可学（隐式对齐） | 依赖外部时长标注（MFA 蒸馏） |

> **一句话总结**：AR 用"串行条件生成"换音质，NAR 用"显式结构先验"换速度与可控性；现代工业系统（如 StyleTTS2、CosyVoice 的 NAR 阶段）普遍走**混合路线**：AR/迭代模型出粗谱或离散 token，NAR/声码器补细节。

## 3. FastSpeech 1/2：NAR 的奠基之作

### 3.1 FastSpeech 1（2019）

核心贡献：用 **duration-informed attention** 替代普通 attention：

1. 用预训练的 Transformer-TTS **自蒸馏（self-decoding）**出对齐矩阵（其 attention 权重即软对齐）。
2. 训练一个 **duration predictor**（卷积 + 回归）预测每个音素的发音帧数。
3. 推理时用 **length regulator** 按预测时长把编码器隐状态复制扩展成帧序列，非自回归解码器并行输出全帧 Mel。

### 3.2 Length Regulator 推导与实现

设音素级隐状态 $H = (h_1, \dots, h_N)$，时长预测 $D = (d_1, \dots, d_N)$（可取整或高斯上采样），扩展后：

$$\tilde{h}_{t} = h_i, \quad \text{if } \sum_{j<i} d_j \le t < \sum_{j \le i} d_j$$

即第 $i$ 个音素的隐状态被连续复制 $d_i$ 次，得到长度 $T = \sum_i d_i$ 的帧级序列。为了让复制边界不过于尖锐，FastSpeech2 之前的变体（如 FastPitch）改用**高斯软复制**：$\tilde{h}_t = \sum_i w_{t,i} h_i$，其中 $w_{t,i} \propto \exp(-(t - \mu_i)^2 / 2\sigma_i^2)$。

### 3.3 FastSpeech 2（2020）：显式方差建模补音质

针对 NAR 过平滑，FastSpeech 2 提出 **Variance Adaptor**，向解码器注入显式声学条件：

```
 Phonemes -> [Phoneme Embedding] -> [Encoder]
                                          │
                                          ▼
                              ┌──── Variance Adaptor ────┐
                              │ duration -> pitch(F0)     │
                              │ -> energy (逐帧, 提取自GT) │
                              │ 各自过 Quantization       │
                              │ + Conv + Upsample         │
                              └──────────┬───────────────┘
                                         ▼
                              [NAR Decoder] -> Mel 谱
```

* **duration / pitch / energy 三个 predictor**：训练时以 GT 值（由 MFA 对齐与信号处理提取）为输入条件（teacher forcing），推理时由 predictor 自回归生成（每个 predictor 是自回归的小模块，逐音素预测）。
* **连续特征离散化**：F0/energy 做分桶量化成 embedding，比连续回归更易学（分类损失 + 离散表示缓解过平滑）。
* **效果**：音质追平 Tacotron2（MOS ~4.0+），同时快约 38.6 倍（V100 上 mel 生成 RTF 0.0033 级别），成为工业界标配骨干。

### 3.4 Duration 标注从哪来：MFA 蒸馏流水线

```
 <文本, 波形> 对 -> Montreal Forced Aligner (MFA, 基于 Kaldi GMM-HMM
 或 Transformer 对齐模型) -> 音素级时间戳 -> 逐音素帧数 = duration 标签
```

* MFA 是工业界标准工具，输出音素边界精度可达 10~20ms。
* 另一路线：用预训练 AR-TTS 的 attention 矩阵提取对齐（FastSpeech 1 的做法），省去外部工具但质量受 attention 稳定性限制。

## 4. DurIAN：AR 音质 + 显式时长

DurIAN（2020）保留了**自回归解码器**（音质高），但用显式时长替代 attention：

* **时长预测器**：2 层 BLSTM + 输出**混合密度网络（MDN）**--把每个音素的帧数建模为高斯混合分布 $p(d_i) = \sum_m \pi_m \mathcal{N}(d_i; \mu_m, \sigma_m^2)$，比点回归更能刻画时长的多峰性（同一音素在不同语境时长差异大）。
* 解码器输入是按时长复制后的编码器帧序列 + 前一帧 mel（prenet），不再需要 attention。
* **收益**：attention 失败问题根除；时长可编辑；少样本声音克隆质量高于同期 NAR 方案。

## 5. VAE 路线：StyleTTS 的隐变量解耦

### 5.1 用 VAE 解决多对一映射

StyleTTS（2021）的核心洞察：NAR 过平滑的病根是"一句文本对应多种韵律"，于是显式引入**隐变量 $z$ 承载文本之外的信息**：

$$p(mel \mid text) = \int p(mel \mid text, z) p(z \mid mel) \, dz$$

* 训练时从 GT mel 的 posterior $q(z \mid mel)$ 采样（WAE 风格训练，reference encoder + reparameterization），$z$ 携带韵律/录音条件信息，NAR 解码器条件于 $(text, z)$ 后目标分布重新变单峰。
* 推理时用 Style-Adaptive LayerNorm（SALN）把 $z$ 注入解码器每一层，实现风格控制。
* **StyleTTS 2**（2023）进一步用**对抗训练 + 可微分时长建模（SDP, Stochastic Duration Predictor）+ 人类反馈优化（HFPO）**，单语料库音质达到 SOTA（MOS 4.5+，齐平甚至超过真人录音复刻）。

### 5.2 与 GST 的区别

GST（参考音频 -> 离散 token，见第 5 篇）是**判别式**风格提取；StyleTTS 的 VAE 是**生成式**建模，训练时 KL 约束 latent 空间结构化，支持采样生成多样韵律。

## 6. Iterative Refinement：Grad-TTS

### 6.1 思想

把"从文本生成 mel"视为**由粗到精的迭代去噪**（Diffusion），多 pass 修正替代一次性并行生成：

**前向**：对 GT mel 逐步加噪：$y_k = \sqrt{\bar{\alpha}_k}\, y_0 + \sqrt{1-\bar{\alpha}_k}\,\epsilon$

**反向**：从噪声 $y_K \sim \mathcal{N}(0, I)$ 出发，以**编码器输出（文本）与时长对齐**为条件迭代去噪：

$$y_{k-1} = \frac{1}{\sqrt{\alpha_k}}\Big(y_k - \frac{1 - \alpha_k}{\sqrt{1 - \bar{\alpha}_k}} \epsilon_\theta(y_k, k, H_{\text{aligned}})\Big) + \sigma_k z$$

* Grad-TTS（2021）用 duration predictor + Diffusion decoder；音质超过 FastSpeech2，接近 Grad-TTS 的 GT 上限。
* 同族：**Diff-TTS / DiffSpeech / Genhancer / EdiTTS**；到 **StyleTTS2 / NaturalSpeech 3（采用扩散 + 语音令牌分解）** 将该路线推向 SOTA。
* **multi-pass 的本质**：每次迭代相当于对 $p(mel \mid text)$ 做一轮修正，逐步消除并行生成的独立假设误差，是"AR 串行细化"与"NAR 一步到位"之间的可控折中（步数可 1~1000 调节速度/质量）。

### 6.2 三种音质补全路线对比

| 路线 | 代表 | 核心机制 | 代价 |
| --- | --- | --- | --- |
| 显式声学条件 | FastSpeech2 | 提供 GT F0/energy/duration 作为条件 | 推理需 predictor 级联，误差传播 |
| VAE 隐变量 | StyleTTS/2 | $z \sim q(z \mid mel)$ 消解多对一 | 训练复杂（对抗+多阶段） |
| 迭代精化 | Grad-TTS / DiffSpeech | 扩散多步去噪 | 推理多步迭代，速度劣于单 pass |

## 7. Attention 失败 vs 显式时长建模：一次对比实验视角

**Attention 失败的典型表现**（Tacotron2 长句推理）：

```
文本: "此外 还 包括 一些 特别 长 的 句子 用于 测试 模型 稳定性"
正常: [此外][还包括一些][特别长的][句子][用于测试][模型稳定性]   ← 单调对角
失败1: [此外][还包括一些][特别长的][特别长的]...                 ← 重复读(attention 停滞)
失败2: [此外][用于测试模型稳定性]                                ← 跳读(attention 越过)
失败3: [此外] <stop>                                            ← 提前终止
```

**失败根源**：softmax attention 无单调性/覆盖约束；长句下解码 RNN 状态与编码器隐状态区分度不足，注意力在相似音素间抖动。Location-sensitive attention、guided attention、单调 attention（Monotonic Attention / GMM attention）都是补丁。

**显式时长的根治性**：对齐在推理前已经确定（$d_1, \dots, d_N$ 固定），解码器只需在给定帧位置上填谱，**不存在对齐搜索失败的空间**；副产品是逐音素时长可人为编辑（语速调整、停顿插入、数字逐位读时延长）。

## 8. PyTorch 实战：Length Regulator 与 Duration Predictor

```python
import torch
import torch.nn as nn

class LengthRegulator(nn.Module):
    """FastSpeech 核心模块: 按时长把音素级隐状态复制/高斯扩展为帧级序列"""
    def __init__(self, gaussian=False, gaussian_scale=2.0):
        super().__init__()
        self.gaussian = gaussian
        self.gaussian_scale = gaussian_scale

    def forward(self, enc_out, durations):
        """
        enc_out:   [B, N, D]  音素级隐状态
        durations: [B, N]     每个音素的帧数 (float, 可为高斯加权)
        return:    [B, T, D]  T = sum(durations)
        """
        B, N, D = enc_out.shape
        device = enc_out.device
        max_len = int(durations.sum(dim=1).max().item())
        cum_dur = torch.cumsum(durations, dim=1)          # [B, N] 累积结束帧
        cum_start = cum_dur - durations                    # 每音素起始帧

        t = torch.arange(max_len, device=device).view(1, -1)          # [1, T]
        ends = cum_dur.unsqueeze(1).long()                             # [B, 1, N]
        starts = cum_start.unsqueeze(1).long()                         # [B, 1, N]
        mask = (t >= starts) & (t < ends)                              # [B, T, N]

        if not self.gaussian:
            # 硬复制: 帧t落在音素i的区间则取 h_i
            out = torch.bmm(mask.float(), enc_out)                     # [B, T, D]
        else:
            # 高斯软复制: 以音素中心 c_i 为均值加权
            centers = (cum_start + durations / 2.0).unsqueeze(1)       # [B, 1, N]
            sigma = (durations / self.gaussian_scale).unsqueeze(1).clamp(min=1e-2)
            w = torch.exp(-((t.float().unsqueeze(-1) - centers) / sigma) ** 2)
            w = w * torch.cat([mask.float(), torch.ones_like(w[:, :, :1])], dim=-1)[..., :N]
            w = w / (w.sum(dim=-1, keepdim=True) + 1e-8)               # 归一化
            out = torch.bmm(w, enc_out)
        return out, max_len

class VariancePredictor(nn.Module):
    """FastSpeech2 duration/pitch/energy predictor: Conv + LayerNorm + Dropout + Linear"""
    def __init__(self, enc_dim=384, filter_size=256, kernel=3, dropout=0.5):
        super().__init__()
        self.layers = nn.Sequential(*[
            nn.Sequential(
                nn.Conv1d(enc_dim if i == 0 else filter_size, filter_size,
                          kernel_size=kernel, padding=(kernel - 1) // 2),
                nn.ReLU(),
                nn.LayerNorm([filter_size]),
                nn.Dropout(dropout),
            ) for i in range(2)
        ])
        self.proj = nn.Linear(filter_size, 1)

    def forward(self, enc_out, mask=None):
        """
        enc_out: [B, N, D] -> log-duration 预测 [B, N]
        """
        x = enc_out.transpose(1, 2)                       # [B, D, N]
        for layer in self.layers:
            x = layer(x)
        out = self.proj(x.transpose(1, 2)).squeeze(-1)    # [B, N]
        if mask is not None:
            out = out.masked_fill(~mask, 0.0)
        return out

def duration_loss(pred, target, mask):
    """FastSpeech 系列 duration 损失: MSE on log-duration (量纲归一)"""
    return (((pred - target) ** 2) * mask).sum() / mask.sum()

if __name__ == "__main__":
    B, N, D = 2, 12, 384
    enc_out = torch.randn(B, N, D)
    log_dur_gt = torch.randn(B, N) * 0.5 + 3.0            # 假设 log 时长 ~ N(3, 0.5)
    mask = torch.ones(B, N, dtype=torch.bool)

    predictor = VariancePredictor()
    log_dur_pred = predictor(enc_out, mask)
    print(f"Duration Loss: {duration_loss(log_dur_pred, log_dur_gt, mask):.4f}")

    durations = torch.exp(log_dur_gt)                     # 恢复线性时长
    lr = LengthRegulator(gaussian=True)
    frame_out, max_len = lr(enc_out, durations)
    print(f"Phoneme seq: {enc_out.shape} -> Frame seq: {frame_out.shape}, T={max_len}")
```

## 9. 总结与最佳实践

* **架构选型**：
  * 追求音质上限、可接受秒级延迟：AR（DurIAN 思路）或 Diffusion 多步（StyleTTS2）。
  * 低延迟实时合成（<300ms 出声）：**NAR 骨干（FastSpeech2 式）+ 流式 vocoder**，RTF 可压到 0.05 以下。
  * 大模型时代：AR 的思想转移到**离散 token 域**（VALL-E 的 AR codec LM）+ NAR 声码/修正（详见第 4 篇）。
* **工程经验**：
  1. 时长标注优先 MFA，attention 蒸馏仅作快速原型。
  2. F0/energy 量化成 embedding 比连续回归稳（训练收敛快、过平滑轻）。
  3. NAR 推理时 duration predictor 输出可加温度/随机采样，实现同文本多韵律。
* **面试要点**：能画出 length regulator 的数据流并手写伪代码；能解释 NAR 过平滑的"多对一"成因；能对比 FastSpeech 1 与 2 的差异（variance adaptor + 去掉自蒸馏依赖）。
