# 2. 声码器Vocoder

## 1. 概述

声码器（Vocoder）位于 TTS 流水线的最后一环，负责把声学模型输出的中间声学表示（Mel 谱、线性谱或 F0/谱参数）还原为可听的语音波形。它本质上是解决一个**不适定问题（ill-posed problem）**：Mel 谱是相位盲的（相位信息已丢失），从 Mel 谱到波形存在无穷多解，声码器必须"脑补"出相位与高频细节。

声码器的发展史就是一部**生成模型的发展史**：

* **信号处理时代**：Griffin-Lim（迭代估计相位）、STRAIGHT / WORLD（参数化 vocoder）。
* **自回归神经网络**：WaveNet、WaveRNN、LPCNet。
* **流模型（Flow）**：WaveGlow、FlowaveNet、Parallel WaveNet（含 IAF 蒸馏）。
* **GAN**：MelGAN、HiFi-GAN、Vocos。
* **扩散模型（Diffusion）**：WaveGrad、DiffWave。

---

## 2. 问题定义与评价指标

### 2.1 数学形式

给定 Mel 谱条件 $c$，生成波形 $x = (x_1, \dots, x_T)$：

* **自回归建模**：$p(x \mid c) = \prod_t p(x_t \mid x_{<t}, c)$，16kHz 下 1 秒音频需采样 16000 次。
* **并行建模**：直接建模 $p(x \mid c)$（GAN 无显式似然；Flow 有精确似然；Diffusion 用变分下界）。

### 2.2 评价指标

| 指标 | 含义 | 典型量级 |
| --- | --- | --- |
| **MOS**（Mean Opinion Score） | 主观听感 1~5 分（置信区间约 ±0.05~0.15） | 真人录音 4.5~4.8；HiFi-GAN 4.3~4.5；WaveNet 4.2~4.5；Griffin-Lim 2.5~3.0 |
| **RTF**（Real-Time Factor） | 合成 1 秒音频耗时（越小越好，<1 即实时） | WaveNet CPU 上 >50；WaveRNN ~1；HiFi-GAN V1 GPU ~0.02~0.06、CPU <0.1 |
| **CMOS** | 相对参考系统的 MOS 差 | 用于 A/B 对比 |
| **UTMOS / MOSNet** | 神经网络预测 MOS，大规模筛选用 | 与人评相关性 0.8+ |

## 3. 信号处理声码器：Griffin-Lim 与 WORLD

### 3.1 Griffin-Lim

已知幅度谱 $|X|^2$、未知相位 $\phi$，通过**交替投影（Alternating Projection）**迭代优化相位使波形谱与目标谱一致：

$$x^{(k+1)} = \mathcal{STFT}^{-1}\big(|X| \cdot e^{j\hat{\phi}^{(k)}}\big), \quad \hat{\phi}^{(k+1)} = \angle \mathcal{STFT}(x^{(k+1)})$$

* 优点：无需训练、速度快。缺点：相位估计不准，听感金属感重，MOS 仅 2.5~3.0，现代系统仅用于快速验证。

### 3.2 WORLD / STRAIGHT

参数化声码器：提取 **F0（基频）、频谱包络（MGC/MSP）、浊摩擦参数（BAP）**，用最小相位近似重建。HMM-TTS 时代的标准配置，缺点同过平滑问题--高频细节丢失。

---

## 4. WaveNet：自回归的鼻祖（PixelCNN 思想）

### 4.1 核心思想

借鉴 PixelCNN 对图像的像素级建模，WaveNet 把波形生成建模为**逐样本自回归**：

$$p(x \mid c) = \prod_{t=1}^{T} p(x_t \mid x_1, \dots, x_{t-1}, c)$$

* **离散化**：16-bit 采样点量化为 256 个 $\mu$-law 等级，输出 256 类 Softmax。
* **因果膨胀卷积（Dilated Causal Conv）**：指数级膨胀率（1,2,4,...,512，堆叠多轮）使感受野指数增长，覆盖数百毫秒上下文。

```
感受野随 dilation 指数增长 (d = 1, 2, 4, 8):

 t=1  t=2  t=3  t=4  t=5  t=6  t=7  t=8
  ●────●────●────●────●────●────●────●   d=8
       └─●────●         └─●────●         d=4
            └───●───●                     d=2
                 └─●                       d=1
                                     ▲ 输出 x_t 只依赖 <t
```

* **门控激活**：$z = \tanh(W_f * x + V_f c) \odot \sigma(W_g * x + V_g c)$（condition 通过 1x1 卷积注入）。
* **音质**：MOS 4.2+，远超 Griffin-Lim；但**逐样本生成导致极慢**，GPU 上 RTF 也接近 10~50，无法上线。

### 4.2 WaveRNN / LPCNet

* **WaveRNN**（2018）：单层 GRU + 稀疏化（sparsification）+ 子批量（subscale）技巧，16kHz 下 CPU RTF ≈ 1，端侧可用。
* **LPCNet**（2019）：结合传统线性预测编码（LPC）--先用 LPC 估计谱包络（确定性部分），神经网络只预测残差（condition + F0），大幅降低建模难度，CPU 实时。

## 5. 并行化路线一：流模型（Flow）

### 5.1 原理

Invertible 变换 $z \leftrightarrow x$，似然可精确计算并快速采样：

$$\log p(x \mid c) = \log p(z) - \log \left|\det \frac{\partial f_\theta(x; c)}{\partial x}\right|, \quad z \sim \mathcal{N}(0, I)$$

* **WaveGlow**（NVIDIA, 2018）：Glow 架构（invertible 1x1 conv + Affine Coupling），一次性并行生成整段波形，V100 上 RTF < 0.1；代价是参数量大（~88M）、训练需大量 GPU。
* **FlowaveNet**：把 WaveNet 的膨胀卷积改造成可逆流。
* **Parallel WaveNet**（DeepMind, 2017/2018）：**IAF（Inverse Autoregressive Flow）**学生网络 + **从自回归 WaveNet 教师蒸馏**（Probability Distillation）：

$$\mathcal{L}_{\text{distill}} = \mathbb{E}_{x \sim \text{student}}\big[ D_{\mathrm{KL}}(\text{Teacher}(x_t) \,\|\, \text{Student}(x_t)) \big]$$

学生逆自回归（采样并行），教师正向自回归（似然精确）--蒸馏让"并行采样"与"自回归质量"兼得，是 Google 助理曾用的上线方案。

## 6. 并行化路线二：GAN 声码器（工业界主流）

### 6.1 MelGAN（2019）

* **Generator**：转置卷积塔式上采样（Hop 逐级 8x8x2x2）+ 大核残差块，直接 Mel -> Waveform。
* **Multi-Scale Discriminator（MSD）** + 后续改进 **Multi-Period Discriminator（MPD）**：把波形 reshape 成 $[B, 1, T/p, p]$ 的伪 2D，用 2D 卷积挖掘周期 $p$（2,3,5,7,11）上的伪周期模式--语音是强周期信号，MPD 对基频谐波结构判别力极强。
* 训练目标：对抗 GAN loss + Feature Matching loss + Mel loss，MOS ~3.9~4.2，CPU 实时。

### 6.2 HiFi-GAN（2019/2020，事实标准）

* **G**：多转置卷积上采样（总倍率 = hop size，如 512）+ **Multi-Receptive Field Fusion（MRF）**：并行多组不同膨胀率/核宽的残差块融合，扩大感受野。
* **D**：MPD + MSD。
* **损失**：

$$\mathcal{L}_G = \mathbb{E}_{(x, c)}\Big[\sum_{k} \big(1 - D_k(G(c))\big) + \lambda_f \sum_k \|\phi_k(x) - \phi_k(G(c))\|_1 + \lambda_m \|\text{Mel}(x) - \text{Mel}(G(c))\|_1\Big]$$

* **性能**：MOS 4.3~4.5（V1），比 GT 仅低 0.1 以内；**GPU RTF 0.0015~0.06、单核 CPU 也可实时**，训练收敛快（单机 V100 数天），是工业界部署最广的声码器。

### 6.3 Vocos（2023，先进方案）

用 **ConvNeXt 骨干 + ISTFT 头**直接预测 STFT 复数谱（幅度 + 相位），不做时域上采样：参数量仅 ~13M，比 HiFi-GAN 小一个量级，音质持平（MOS ~4.5 级），已成为开源社区新默认（如 CosyVoice 部分配置采用）。

### 6.4 GAN 声码器家族横向对比

| 模型 | 判别器 | MOS（22/24kHz, GT 4.4~4.6） | CPU RTF | 特点 |
| --- | --- | --- | --- | --- |
| MelGAN | MSD | 3.90 (ord) / 4.12 (large) | ~1.0 | 首个并行 GAN vocoder，音质有限 |
| HiFi-GAN V1 | MPD+MSD | ~4.41 | <0.1（CPU） | 音质/速度均衡，事实标准 |
| HiFi-GAN V2 | MPD+MSD | ~4.38 | 更快 | 缩小版 V1，端侧友好 |
| UnivNet | MPD+MRD(多分辨率谱) | ~4.45 | ~0.1 | 多分辨谱判别器 |
| BigVGAN | MPD+MSD+MRD | ~4.55（48kHz 可用） | 慢于 HiFi-GAN | 抗混叠激活函数，高保真 |
| Vocos | -（GAN + Mel/Spec loss） | ~4.5 | ~0.01（CPU） | ConvNeXt+ISTFT，轻量高效 |

## 7. 并行化路线三：Diffusion 声码器

### 7.1 WaveGrad（2020）与 DiffWave（2021）

以 DiffWave 为例，前向加噪、反向去噪：

**前向过程**（固定 schedule $\bar{\alpha}_k$）：

$$q(x_k \mid x_0) = \mathcal{N}(x_k; \sqrt{\bar{\alpha}_k}\, x_0, (1 - \bar{\alpha}_k) I), \quad x_k = \sqrt{\bar{\alpha}_k} x_0 + \sqrt{1 - \bar{\alpha}_k}\, \epsilon$$

**训练目标**（预测噪声）：

$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{x_0, \epsilon \sim \mathcal{N}(0,I), k} \big\| \epsilon - \epsilon_\theta(x_k, k, c) \big\|^2$$

**采样**：从高斯噪声出发迭代 $K$ 步去噪（WaveGrad 可用少至 6~25 步，DiffWave 默认 50 步）。

* **优点**：训练稳定（回归损失，无对抗博弈），音质高（MOS 4.4+），采样步数可调换速度/质量。
* **缺点**：迭代采样天然慢于 GAN 单次前向，工程上常需蒸馏（如 Consistency Model）加速。

### 7.2 四大路线总览

| 维度 | AR（WaveNet/WaveRNN） | Flow（WaveGlow/PWNet） | GAN（HiFi-GAN） | Diffusion（DiffWave） |
| --- | --- | --- | --- | --- |
| 训练稳定性 | 高（显式似然） | 高（显式似然） | **低**（对抗博弈、模式坍塌） | 高（L2 回归） |
| 采样速度 | **极慢**（RTF>1~50） | 快（1 次前向） | **最快**（1 次前向） | 慢~中（需 N 步迭代） |
| 音质上限 | 高 | 中高 | 高 | 高 |
| 显存/参数 | 中 | 大（可逆约束） | 中小 | 中 |
| 工业地位 | 端侧（LPCNet） | 已边缘化 | **主流** | 追求极致音质/新场景 |

## 8. PyTorch 实战：HiFi-GAN Generator 简化实现

```python
import torch
import torch.nn as nn

class ResBlock(nn.Module):
    """HiFi-GAN 残差块: 一串 1D 膨胀卷积 + 残差连接"""
    def __init__(self, channels=128, dilations=(1, 3, 5), kernel=3, leak=0.1):
        super().__init__()
        self.convs = nn.ModuleList([
            nn.Conv1d(channels, channels, kernel, dilation=d,
                      padding=(kernel * d - d) // 2)
            for d in dilations for _ in range(2)   # 每个膨胀率两层
        ])
        self.act = nn.LeakyReLU(leak)

    def forward(self, x):
        for conv in self.convs:
            x = self.act(conv(x)) + x               # 残差连接
        return x

class HiFiGANGenerator(nn.Module):
    """Mel谱 -> Waveform, 上采样总倍率 = hop_size"""
    def __init__(self, mel_bins=80, hidden=128, upsample_rates=(8, 8, 2, 2),
                 mrf_dilations=((1, 3, 5), (1, 3, 5))):
        super().__init__()
        self.conv_pre = nn.Conv1d(mel_bins, hidden, kernel_size=7, padding=3)
        total_up = 1
        ups, mrfs = [], []
        for r in upsample_rates:
            ups.append(nn.ConvTranspose1d(hidden, hidden // 2, kernel_size=r * 2,
                                          stride=r, padding=r // 2))
            mrfs.append(nn.ModuleList([ResBlock(hidden // 2, dil) for dil in mrf_dilations]))
            hidden //= 2
            total_up *= r
        self.ups = nn.ModuleList(ups)
        self.mrfs = nn.ModuleList(mrfs)
        self.conv_post = nn.Conv1d(hidden * 2, 1, kernel_size=7, padding=3)
        self.hop_size = total_up                     # 8*8*2*2 = 512
        self.lrelu = nn.LeakyReLU(0.1)

    def forward(self, mel):
        """
        mel: [B, mel_bins, T_mel]  ->  wav: [B, 1, T_mel * hop_size]
        """
        x = self.lrelu(self.conv_pre(mel))           # [B, C, T]
        for up, mrf in zip(self.ups, self.mrfs):
            x = self.lrelu(up(x))                    # 时域上采样 xR
            x = x + sum(block(x) for block in mrf)   # MRF: 多感受野并联求和
        return torch.tanh(self.conv_post(x))         # 输出波形 [-1, 1]

class MultiPeriodDiscriminator(nn.Module):
    """MPD: 按周期 p 把波形折叠成 2D, 用卷积捕捉基频谐波结构"""
    def __init__(self, periods=(2, 3, 5, 7, 11)):
        super().__init__()
        self.discs = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(1, 32, (5, 1), (3, 1), padding=(2, 0)),
                nn.LeakyReLU(0.1),
                nn.Conv2d(32, 128, (5, 1), (3, 1), padding=(2, 0)),
                nn.LeakyReLU(0.1),
                nn.Conv2d(128, 512, (5, 1), (3, 1), padding=(2, 0)),
                nn.LeakyReLU(0.1),
                nn.Conv2d(512, 1024, (5, 1), (3, 1), padding=(2, 0)),
                nn.LeakyReLU(0.1),
                nn.Conv2d(1024, 1, (3, 1), 1, padding=(1, 0)),
            ) for _ in periods])
        self.periods = periods

    def forward(self, wav):
        """wav: [B, 1, T] -> list of [B, 1, T', p] logits"""
        outs = []
        for p, d in zip(self.periods, self.discs):
            B, _, T = wav.shape
            T_pad = (p - T % p) % p                   # 补齐为周期整数倍
            x = wav.view(B, 1, -1, p) if T_pad == 0 else \
                torch.cat([wav, wav.new_zeros(B, 1, T_pad)], dim=2).view(B, 1, -1, p)
            outs.append(d(x))
        return outs

if __name__ == "__main__":
    G = HiFiGANGenerator()
    D = MultiPeriodDiscriminator()
    mel = torch.randn(2, 80, 100)                     # 100 帧 Mel (hop=512 -> 51200 samples)
    wav = G(mel)
    print(f"Generator output: {wav.shape}")           # [2, 1, 51200]
    logits = D(wav)
    print(f"MPD outputs: {[l.shape for l in logits]}")
    print(f"RTF 参考量级: HiFi-GAN V1 GPU RTF ≈ 0.0015~0.06, CPU < 0.1")
```

## 9. 总结与最佳实践

* **选型经验**：
  * 通用云端/离线 TTS：**HiFi-GAN**（24kHz、音质均衡、训练省心）；追求极致可用 **BigVGAN**。
  * 端侧/低算力：**Vocos**（轻量）或 **LPCNet / iSTFTNet** 类轻结构。
  * 音乐/高保真/48kHz：**BigVGAN v2** 或 Diffusion。
  * 与 LLM/Diffusion TTS 生态对接：Vocos、HiFi-GAN 变体（CosyVoice、F5-TTS 默认配置）。
* **面试高频**：
  1. 为什么 GAN 声码器能并行而 WaveNet 不能？--GAN 生成器一次前向输出全部采样点，判别器只在训练时存在；WaveNet 似然链式分解必须逐点采样。
  2. MPD 为什么有效？--语音波形具有基频周期性，折叠成 2D 后周期结构在同一列对齐，卷积判别器能敏锐发现谐波断裂/基频错误。
  3. Diffusion 声码器为什么音质高但落地少？--多步迭代 RTF 劣于 GAN，且 GAN 音质已逼近 GT，收益边际递减。
