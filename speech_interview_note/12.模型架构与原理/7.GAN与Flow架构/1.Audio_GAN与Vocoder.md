# 1. Audio GAN 与声码器 (Vocoder)

## 1. 概述

在语音合成 (TTS) 和音频生成领域，**GAN (Generative Adversarial Networks)** 主要用于**声码器 (Vocoder)** 阶段（将 Mel 频谱转换为高保真 1D 原始波形），或作为非自回归 TTS 模型的端到端生成头。

* **核心矛盾**：1D 语音波形采样率极高（例如 22.05kHz / 44.1kHz），存在极长程的相位依赖与高频谐波。传统 AutoRegressive (AR) 模型（如 WaveNet）推理极其缓慢。
* **GAN 优势**：**单次前向传播（非自回归，并行计算）**，推理速度极快（RTF $\ll 0.01$），且生成的波形高频细节丰富。
* **核心挑战**：训练不稳定、模式崩塌 (Mode Collapse) 以及高频相位不连续产生伪影（如 "Buzzing" 杂音）。

---

## 2. 损失函数体系：高保真音频 GAN 的三剑客

不同于图像 GAN 仅依赖对抗损失，音频 GAN（如 MelGAN, HiFi-GAN）能够稳定训练并达到 MOS > 4.5 的关键在于**组合损失函数**。

### 2.1 Adversarial Loss (LSGAN / Hinge Loss)

HiFi-GAN 采用 **Least Squares GAN (LSGAN)** 损失，比标准 Sigmoid 交叉熵更稳定，能有效避免梯度消失：

$$\mathcal{L}_{\mathrm{Adv}}(G) = \mathbb{E}_{s}\left[ (D(G(s)) - 1)^2 \right]$$

$$\mathcal{L}_{\mathrm{Adv}}(D) = \mathbb{E}_{x}\left[ (D(x) - 1)^2 \right] + \mathbb{E}_{s}\left[ D(G(s))^2 \right]$$

*(其中 $x$ 为真实波形，$s$ 为输入条件 Mel 谱，$G(s)$ 为生成的波形)*

### 2.2 Feature Matching Loss (特征匹配损失)

借鉴自 Progressive GAN 与 MelGAN，测量真实波形与生成波形在**判别器中间隐层特征**上的 $L_1$ 距离：

$$\mathcal{L}_{\mathrm{FM}}(G) = \mathbb{E}_{(x, s)} \left[ \sum_{i=1}^{D} \frac{1}{N_i} \left\Vert{} D^{(i)}(x) - D^{(i)}(G(s)) \right\Vert{}_1 \right]$$

* **作用**：引导生成器学习判别器在不同抽象尺度上提取的统计特征，大幅提升训练稳定性与收敛速度。

### 2.3 Multi-Resolution STFT Loss (多分辨率 STFT 损失)

仅靠对抗损失很难保证频域能量谱的精确重构。STFT Loss 约束生成波形在**短时傅里叶变换**下的频域一致性。单分辨率损失包含 **Spectral Convergence (光谱收敛度)** 与 **Log Magnitude Loss (对数幅值损失)**：

$$\mathcal{L}_{\mathrm{sc}}(x, \hat{x}) = \frac{\Vert{} \vert{}\mathrm{STFT}(x)\vert{} - \vert{}\mathrm{STFT}(\hat{x})\vert{} \Vert{}_F}{\Vert{} \vert{}\mathrm{STFT}(x)\vert{} \Vert{}_F}$$

$$\mathcal{L}_{\mathrm{mag}}(x, \hat{x}) = \frac{1}{N} \left\Vert{} \log \vert{}\mathrm{STFT}(x)\vert{} - \log \vert{}\mathrm{STFT}(\hat{x})\vert{} \right\Vert{}_1$$

**多分辨率 (Multi-Resolution) 组合**：通过设置不同的 $FFT\_size$（如 512, 1024, 2048）、$hop\_size$ 和 $win\_length$，同时兼顾**时间分辨率**（捕捉瞬态打击音/清音）与**频率分辨率**（捕捉浊音谐波）：

$$\mathcal{L}_{\mathrm{mr\_stft}}(G) = \sum_{m=1}^{M} \left( \mathcal{L}_{\mathrm{sc}}^{(m)}(x, \hat{x}) + \mathcal{L}_{\mathrm{mag}}^{(m)}(x, \hat{x}) \right)$$

## 3. 经典架构演进

### 3.1 MelGAN：首个实时高保真 GAN 声码器
* **Generator**：全卷积转置卷积 (Transposed Conv) 网络，逐步上采样（如 $8 \times 8 \times 2 \times 2 = 256$ 倍）对齐 Mel 步长。
* **Multi-Scale Discriminator (MSD)**：设置 3 个结构相同但输入经过不同倍率下采样（原始、2x 下采样、4x 下采样）的判别器，分别捕捉不同频段的全局与局部特征。

### 3.2 HiFi-GAN：里程碑式的 Vocoder 标杆
针对 MelGAN 在谐波建模和周期性波形上的不足，HiFi-GAN 推出了两个核心设计：

1. **Multi-Period Discriminator (MPD, 多周期判别器)**：
   * 将 1D 连续波形展开（Reshape）为 2D 矩阵，行宽为指定的周期 $p \in \{2, 3, 5, 7, 11\}$。
   * 采用 2D 卷积提取周期性特征，**专攻音频中的基频 ($F_0$) 谐波结构**。
2. **Multi-Receptive Field Fusion (MRF, 多感受野融合模块)**：
   * 在生成器残差块中，并行使用多种不同 Kernel size 和 Dilation rate 的 1D 卷积，加权融合不同感知的长短期依赖。

### 3.3 BigVGAN：大模型时代的带外泛化与无伪影设计
NVIDIA 提出的 BigVGAN 将生成式声码器带入 100M+ 参数规模，解决了超集数据集（带噪、音乐、多语种）上的泛化问题：

* **Anti-Aliased Representation (抗锯齿模块)**：在转置卷积上采样层后引入带通/低通滤波抗锯齿（Low-pass Filter），消除高频混叠（Aliasing）。
* **Snake 激活函数**：替代 LeakyReLU，使用带有周期自适应能力的激活函数 $x + \frac{1}{a} \sin^2(ax)$，天然拟合周期性波形。

## 4. PyTorch 核心代码：HiFi-GAN 生成器与 MPD 判别器

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# ==================== 1. Multi-Period Discriminator (MPD) ====================
class PeriodDiscriminator(nn.Module):
    def __init__(self, period, kernel_size=5, stride=3):
        super().__init__()
        self.period = period
        self.convs = nn.ModuleList([
            nn.Conv2d(1, 64, (kernel_size, 1), (stride, 1), padding=(kernel_size//2, 0)),
            nn.Conv2d(64, 128, (kernel_size, 1), (stride, 1), padding=(kernel_size//2, 0)),
            nn.Conv2d(128, 256, (kernel_size, 1), (stride, 1), padding=(kernel_size//2, 0)),
            nn.Conv2d(256, 512, (kernel_size, 1), 1, padding=(kernel_size//2, 0)),
            nn.Conv2d(512, 1024, (kernel_size, 1), 1, padding=(kernel_size//2, 0)),
        ])
        self.conv_post = nn.Conv2d(1024, 1, (3, 1), 1, padding=(1, 0))

    def forward(self, x):
        fmap = []
        # x: [B, 1, T] -> Reshape 为 2D 图像: [B, 1, T // period, period]
        b, c, t = x.shape
        if t % self.period != 0:
            pad_len = self.period - (t % self.period)
            x = F.pad(x, (0, pad_len), "reflect")
            t = x.shape[-1]
        x = x.view(b, c, t // self.period, self.period)

        for conv in self.convs:
            x = F.leaky_relu(conv(x), 0.1)
            fmap.append(x)
        x = self.conv_post(x)
        fmap.append(x)
        return torch.flatten(x, 1, -1), fmap

# ==================== 2. Multi-Receptive Field Fusion (MRF) ====================
class ResBlock(nn.Module):
    def __init__(self, channels, kernel_size=3, dilations=(1, 3, 5)):
        super().__init__()
        self.convs1 = nn.ModuleList([
            nn.Conv1d(channels, channels, kernel_size, 1, dilation=d, padding=(kernel_size * d - d) // 2)
            for d in dilations
        ])
        self.convs2 = nn.ModuleList([
            nn.Conv1d(channels, channels, kernel_size, 1, dilation=1, padding=(kernel_size - 1) // 2)
            for d in dilations
        ])

    def forward(self, x):
        for c1, c2 in zip(self.convs1, self.convs2):
            xt = F.leaky_relu(x, 0.1)
            xt = F.leaky_relu(c1(xt), 0.1)
            xt = c2(xt)
            x = x + xt
        return x

# ==================== 3. HiFi-GAN Generator ====================
class HiFiGANGenerator(nn.Module):
    def __init__(self, in_channels=80, upsample_rates=[8, 8, 2, 2], upsample_kernel_sizes=[16, 16, 4, 4]):
        super().__init__()
        self.num_kernels = 3
        self.conv_pre = nn.Conv1d(in_channels, 512, 7, 1, padding=3)
        
        self.ups = nn.ModuleList()
        for i, (u, k) in enumerate(zip(upsample_rates, upsample_kernel_sizes)):
            self.ups.append(
                nn.ConvTranspose1d(512 // (2**i), 512 // (2**(i+1)), k, u, padding=(k - u) // 2)
            )

        self.mrf_blocks = nn.ModuleList()
        for i in range(len(self.ups)):
            ch = 512 // (2**(i+1))
            for k, d in zip([3, 7, 11], [[1, 3, 5], [1, 3, 5], [1, 3, 5]]):
                self.mrf_blocks.append(ResBlock(ch, k, d))

        self.conv_post = nn.Conv1d(ch, 1, 7, 1, padding=3)

    def forward(self, mel):
        # mel: [B, 80, T_mel]
        x = self.conv_pre(mel)
        for i, up in enumerate(self.ups):
            x = F.leaky_relu(x, 0.1)
            x = up(x)
            # 融合不同感受野的 MRF 输出
            xs = 0
            for j in range(self.num_kernels):
                xs += self.mrf_blocks[i * self.num_kernels + j](x)
            x = xs / self.num_kernels
        x = F.leaky_relu(x, 0.1)
        x = torch.tanh(self.conv_post(x)) # 输出波形幅值 [-1, 1]
        return x

```

## 5. 面试高频追问

* **追问 1：为什么 GAN 生成的波形容易产生相位不连续和金属音（Metal/Buzzing Noise）？**
* *答*：因为标准 1D 转置卷积在逐层上采样时容易引发**高频混叠 (Aliasing)**；此外，Mel 频谱丢失了相位信息，仅靠 $L_1$ 或单分辨率损失无法完备约束高频相位。解决方案是引入多分辨率 STFT 损失、MPD 多周期判别器以及 BigVGAN 的抗锯齿滤波。


* **追问 2：GAN Vocoder 与 Diffusion Vocoder (如 DiffWave) 相比优缺点是什么？**
* *答*：
* **GAN**：推理速度极快（单次前向），适合实时 TTS/流式语音合成；但跨域泛化较差，训练时存在对抗博弈不稳定风险。
* **Diffusion**：极强的数据分布拟合能力与跨域泛化性，高频细节更真实；但推理需多步迭代，实时性（RTF）不如 GAN。
