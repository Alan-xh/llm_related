# 1. wav2vec 2.0

## 1. 概述

**wav2vec 2.0** 由 Facebook AI（Baevski et al., NeurIPS 2020）提出，是语音自监督预训练（Self-Supervised Pre-training）的里程碑之作。它的核心思想是：**在大规模无标注语音上，通过「掩码 + 对比学习」学习通用语音表征，再用极少量的有标注数据微调即可完成 ASR**。

理解 wav2vec 2.0 需要先梳理其技术脉络：

* **vq-wav2vec（2019）**：将语音用 vq-VAE 风格的离散量化切成「离散语音 token」，再套用 BERT 的 masked LM 训练 —— 缺点是量化模块与预测模块**分两阶段训练**，误差累积。
* **wav2vec 1.0（2020）**：完全连续表征，用「未来帧预测（future prediction）」的对比学习目标 —— 缺点是只做局部时序预测，学到的表征偏声学细节。
* **wav2vec 2.0（2020）**：**合二为一** —— 在线（end-to-end）的量化模块提供离散对比目标 + 掩码机制让模型基于全局上下文做预测，兼顾了 BERT 式的上下文建模与对比学习的简单性。

其在面试中的高频考点：

1. 为什么需要量化模块？为什么不直接用连续表征做对比目标？（**避免模型坍缩：若正负样本同源且模型容量足够，连续目标可被捷径绕过**）
2. Gumbel-Softmax 的推导与 Straight-Through Estimator（STE）。
3. contrastive loss 与 diversity loss 的公式与作用。
4. 10 min / 1 h / 100 h 有标注数据的 WER 数据效率。

## 2. 算法架构

### 2.1 整体架构图

```
                        wav2vec 2.0 预训练架构
 ┌────────────────────────────────────────────────────────────────────┐
 │                                                                    │
 │  原始波形 X                                                       │
 │  (16kHz, T' 采样点)                                                │
 │      │                                                             │
 │      ▼                                                             │
 │  ┌───────────────────────┐    z_t (T 帧, 每帧约 20ms)             │
 │  │ CNN Feature Encoder   │──────────────┬──────────────┐          │
 │  │ (7 层卷积)            │              │              │          │
 │  └───────────────────────┘              ▼              ▼          │
 │                              ┌──────────────┐  ┌──────────────┐   │
 │                              │  Masking     │  │  Quantizar   │   │
 │                              │  (span=10,   │  │  (Gumbel-    │   │
 │                              │   p=0.065)   │  │   Softmax)   │   │
 │                              └──────┬───────┘  └──────┬───────┘   │
 │                                     ▼                 │           │
 │                              ┌──────────────┐         │           │
 │                              │ Transformer  │  量化向量 q_t        │
 │                              │ Encoder      │         │           │
 │                              │ (12/24 层)   │         │           │
 │                              └──────┬───────┘         │           │
 │                                     ▼                 │           │
 │                              上下文表征 c_t ──── InfoNCE ────►     │
 │                              (被 mask 位置)     q_t vs K 个负样本  │
 │                                                                    │
 └────────────────────────────────────────────────────────────────────┘
```

三个模块的分工：

| 模块 | 输入 | 输出 | 作用 |
| --- | --- | --- | --- |
| **Feature Encoder** | 原始波形 | 连续潜在表征 $z_t$（约 50 帧/秒） | 时域特征抽取（替代 Fbank） |
| **Context Network** | masked 后的 $z_t$ | 上下文表征 $c_t$ | 建模全局时序上下文 |
| **Quantization Module** | 未 mask 的 $z_t$ | 离散量化目标 $q_t$ | 生成对比学习的目标（正/负样本） |

> **关键设计**：mask 发生在 quantization **之前**（context network 的输入端），而量化目标来自**未被破坏**的 $z_t$ —— 这与 BERT 中「输入打掩码、标签看原文」的思想一致。

### 2.2 CNN Feature Encoder（7 层卷积）

wav2vec 2.0 直接以原始波形为输入（不需要人工 Fbank 特征），用 7 层一维卷积下采样：

| 层 | 卷积核宽度 | 步长 stride | 输出通道 |
| --- | --- | --- | --- |
| Conv1 | 10 | 5 | 512 |
| Conv2 | 3 | 2 | 512 |
| Conv3 | 3 | 2 | 512 |
| Conv4 | 3 | 2 | 512 |
| Conv5 | 3 | 2 | 512 |
| Conv6 | 2 | 2 | 512 |
| Conv7 | 2 | 2 | 512 |

* **总下采样率**：$5 \times 2^6 = 320$ 倍。16 kHz 波形 → 每帧 320 个采样点 = **20 ms/帧，约 49 帧/秒**。
* **感受野**：约 25 ms（覆盖一个以上音素的核心区间），使每帧表征具备类似 phone 的声学判别性。
* **归一化**：第一层卷积使用 GroupNorm（波形幅值不稳定），全部层接 ReLU；encoder 输入端施加 dropout（Base 为 0.1，低资源微调时调大）。
* **微调时冻结**：fine-tune 阶段通常冻结整个 feature encoder，一是防止小数据过拟合，二是减少显存（无需对其计算梯度）。

### 2.3 Transformer Encoder（Context Network）

对 masked 后的序列 $z̃$ 施加 **卷积位置编码 + Transformer**：

$$c = \text{Transformer}(\text{ConvPosEnc}(z̃) + z̃)$$

| 配置 | 层数 | 维度 $d$ | FFN | 注意力头 | 预训练数据 |
| --- | --- | --- | --- | --- | --- |
| **BASE** | 12 | 768 | 3072 | 8 | LibriSpeech 960 h |
| **LARGE** | 24 | 1024 | 4096 | 16 | LibriVox 53.6k h (LV-60k) |

* 参数量级：Base 约 95 M，Large 约 317 M（均不含微调头）。
* 卷积位置编码（Convolutional Positional Embedding，核 128、分组 16）比 sin/cos 更适合相对位置建模。

### 2.4 量化模块与 Gumbel-Softmax 推导

**为什么必须离散化？** 若对比目标直接用连续的 $z_t$，由于 $z_t$ 与 $c_t$ 由同一 encoder 的相邻路径产生，模型可以通过「缩短 $z_t$ 与 $c_t$ 的欧氏距离」这类捷径完成任务，表征容易坍缩。把目标替换为**离散 code** 后，目标空间被约束为一个有限集合，迫使 context network 真正利用上下文信息。

**结构**：将 $z_t \in \mathbb{R}^{D}$ 均匀拆分为 $G$ 组（$G=2$），每组与独立 codebook $E_g \in \mathbb{R}^{V \times d}$（$V=320$，$d=D/G$）做相似度计算，每组独立选 1 个 code，拼接得到 $q_t$。理论组合数 $V^G = 320^2 = 102400$ 种，codebook 总向量数仅 $G \times V = 640$ 个。

**推导：从 argmax 采样到 Gumbel-Softmax**

第 1 步，组内 logits（缩放点积）：

$$\ell_{g,v} = \frac{\langle z_t^{(g)},\ e_{g,v} \rangle}{\sqrt{d}}, \quad v \in \{1,\dots,V\}$$

第 2 步，Gumbel-Max Trick —— 对 categorical 采样 $\pi = \text{softmax}(\ell)$，有如下恒等式：

$$\arg\max_v \big(\ell_{g,v} + \gamma_v\big) \sim \text{Categorical}(\pi), \quad \gamma_v = -\log(-\log u_v),\ u_v \sim U(0,1)$$

> **证明思路**：Gumbel 分布 $G(x) = e^{-e^{-x}}$，则 $P(\ell_v + \gamma_v \text{ 是最大值}) = \int \prod_{j \neq v} e^{-e^{-(\ell_v - \ell_j + g)}} \cdot f(g)\, dg \propto e^{\ell_v}$，归一化后恰为 $\text{softmax}(\ell)_v$。即「加噪取 argmax」等价于按 softmax 概率采样，且 argmax 可导性交由下一步解决。

第 3 步，连续松弛（Soft）——把 argmax 换成带温度 $\tau$ 的 softmax：

$$\tilde{q}_{g,v} = \frac{\exp\big((\ell_{g,v} + \gamma_{g,v})/\tau\big)}{\sum_{v'=1}^{V} \exp\big((\ell_{g,v'} + \gamma_{g,v'})/\tau\big)}$$

* $\tau \to 0$：$\tilde{q}$ 趋近 one-hot（离散化彻底）；
* $\tau \to \infty$：$\tilde{q}$ 趋近均匀分布（梯度稳定但量化模糊）。
* 训练中从 $\tau = 2$ 逐步退火到 $0.5$（fairseq 实现中按指数衰减）。

第 4 步，Straight-Through Estimator（STE）——前向用 hard、反向用 soft：

$$\bar{\imath}_{g,\cdot} = \text{onehot}\big(\arg\max_v \tilde{q}_{g,v}\big), \qquad q_t = \big[\bar{\imath}_{1,\cdot} E_1;\ \bar{\imath}_{2,\cdot} E_2\big] \in \mathbb{R}^{D}$$

反向传播时梯度绕过不可导的 onehot，直接作用在 $\tilde{q}$ 上：

$$\frac{\partial \mathcal{L}}{\partial \ell} \approx \frac{\partial \tilde{q}}{\partial \ell}\cdot \frac{\partial \mathcal{L}}{\partial \bar{\imath}}\Big|_{\bar{\imath} \leftarrow \tilde{q}}$$

> **面试要点**：Gumbel 噪声保证「选哪个 code」带随机性（等价按概率采样），STE 保证「code 向量拼出的 $q_t$」能把梯度传回 codebook 与 encoder；$\tau$ 控制离散化的激进程度。

## 3. 目标函数：掩码对比学习

### 3.1 掩码策略

* 以概率 $p = 0.065$ 随机选起始帧，从该帧开始连续 **mask 10 帧（span mask）**。
* 有效掩码比例：$1 - (1 - p)^{10} \approx 49\%$，即约一半的帧被置为可学习的 mask 向量。
* span mask 优于逐帧独立 mask：迫使模型用一个「洞」两侧的上下文填补整段信息，而不是逐帧插值。

### 3.2 InfoNCE 推导

对每个被 mask 的时间步 $t$：模型输出 $c_t$，量化模块提供正样本 $q_t = Q(z_t)$；从**同一句话**中均匀采样 $K = 100$ 个其他时间步的量化向量 $\tilde{q}_k$ 作为负样本（ negatives 与正样本时间上不重叠）。

相似度函数用 **余弦相似度除以温度**：

$$s(c_t, q) = \frac{\cos(c_t, q)}{\kappa}, \quad \kappa = 0.1$$

对比损失（InfoNCE 的单时间步形式）：

$$\mathcal{L}_{t} = -\log \frac{\exp\big(s(c_t, q_t)\big)}{\exp\big(s(c_t, q_t)\big) + \sum_{k=1}^{K} \exp\big(s(c_t, \tilde{q}_k)\big)}$$

对整个 batch 内所有被 mask 位置求和取平均：

$$\mathcal{L}_{\text{con}} = -\frac{1}{|\tilde{Z}|} \sum_{t \in \tilde{Z}} \log \frac{\exp(s(c_t, q_t))}{\sum_{\tilde{q} \in \{q_t\} \cup \mathcal{N}_t} \exp(s(c_t, \tilde{q}))}$$

其中 $\tilde{Z}$ 为被 mask 的时间步集合，$\mathcal{N}_t$ 为负样本集合，$|\mathcal{N}_t| = K$。

> **数字量级**：若模型毫无判别能力（正负样本相似度同分布），损失期望为 $\log(K+1) = \log 101 \approx 4.6$。训练收敛后该值通常降到 **0.1 以下**，即模型在 101 个候选中几乎总能锁定正确的量化目标。这个 $\log(K+1)$ 基线是排查训练是否正常的重要参照。

### 3.3 负样本多样化

* 负样本全部来自同一条 utterance（而非跨 batch 采样），保证负样本与正样本在说话人、信道、内容分布上一致，让任务聚焦于「时序内容差异」而非「说话人差异」。
* $K$ 的量级：$K=100$ 是精度与计算量的折中；$K$ 太小（如 10）任务过于简单，表征判别性不足；$K$ 太大收益递减。
* 由于负样本本身来自量化模块，若 codebook 坍缩（所有帧量化成同一 code），正负样本将无差异、损失无法下降 —— 这正是引入 diversity loss 的原因。

## 4. 损失函数

### 4.1 联合损失公式

$$\mathcal{L} = \mathcal{L}_{\text{con}} + \lambda \cdot \mathcal{L}_{\text{div}}, \qquad \lambda = 0.1$$

* $\mathcal{L}_{\text{con}}$：上述 InfoNCE 对比损失（主体）。
* $\mathcal{L}_{\text{div}}$：codebook 多样性损失（正则项）。

### 4.2 Diversity Loss（codebook entropy 正则）

对每个 batch，统计各 code 的**平均使用概率**。对组 $g$，将所有时间步的 soft 概率 $\tilde{q}_{g,v,t}$ 在时间与 batch 维平均：

$$\bar{p}_{g,v} = \frac{1}{T \cdot B} \sum_{b,t} \tilde{q}_{g,v,t}^{(b)}$$

多样性项采用（vq-wav2vec 延续而来的形式）：

$$\mathcal{L}_{\text{div}} = \frac{1}{G V} \sum_{g=1}^{G} \sum_{v=1}^{V} \bar{p}_{g,v}\,(1 - \bar{p}_{g,v})$$

该式在 $\bar{p}_{g,v} = 1/V$（均匀使用）时**取最大值**，在 code 坍缩（$\bar{p}$ 接近 0 或 1）时趋近 0。因此在实现中该项以**被最大化**的方向加入总目标（等价于在最小化目标中取负），直观等价于**最大化 codebook 平均分布的熵 $H(\bar{p}_g)$**：

$$H(\bar{p}_g) = -\sum_{v=1}^{V} \bar{p}_{g,v} \log \bar{p}_{g,v} \leq \log V$$

> **面试要点**：diversity loss 的作用是防止 Gumbel-Softmax codebook 坍缩 —— 若没有它，模型可能只用极少数 code，导致负样本「不够难」、对比学习退化为记忆任务。可以把它理解为把 vq-VAE 的 KL 均匀先验搬到 wav2vec 2.0 中的等价物。工程上还常用 **codebook perplexity**（$= e^{H(\bar{p})}$，理想值接近 $V$）监控坍缩：健康训练时 perplexity 应持续上升至数百量级。

### 4.3 PyTorch 实现要点

```python
import torch
import torch.nn as nn
import torch.nn.functional as Fn

class GumbelQuantizer(nn.Module):
    """wav2vec 2.0 量化模块: G 组 x V code, Gumbel-Softmax + STE"""
    def __init__(self, dim=768, groups=2, vars=320, temp=2.0, temp_min=0.5):
        super().__init__()
        self.groups, self.vars = groups, vars
        self.temp, self.temp_min = temp, temp_min
        d = dim // groups
        # 每组一个线性投影产生 logits (实现中投影与 codebook 可共享)
        self.codebooks = nn.Parameter(torch.randn(groups, vars, d))
        self.weight_proj = nn.Linear(dim, groups * vars)

    def forward(self, z):
        # z: [B, T, D]
        B, T, D = z.shape
        logits = self.weight_proj(z).view(B, T, self.groups, self.vars)

        # 1) Gumbel 噪声: g = -log(-log(u)), 对 softmax(负向)扰动
        gumbel = -torch.log(-torch.log(
            torch.rand_like(logits).clamp(1e-9, 1.0 - 1e-9)))
        soft = Fn.softmax((logits + gumbel) / self.temp, dim=-1)

        # 2) STE: 前向 one-hot, 反向走 soft 概率
        hard = Fn.one_hot(
            soft.argmax(dim=-1), num_classes=self.vars).float()
        probs = (hard - soft).detach() + soft    # straight-through

        # 3) 拼接各组选中的 code 向量 -> [B, T, D]
        codes = self.codebooks.unsqueeze(0).unsqueeze(0)  # [1,1,G,V,d]
        q = torch.einsum("btgv,gvwd->btgd", probs, codes).flatten(start_dim=2)
        return q, soft  # soft 用于计算 diversity loss


def wav2vec2_contrastive_loss(c_masked, q_pos, q_negs, logit_temp=0.1):
    """InfoNCE: c_masked [M, D], q_pos [M, D], q_negs [M, K, D]"""
    pos = torch.cosine_similarity(c_masked, q_pos, dim=-1) / logit_temp  # [M]
    neg = torch.cosine_similarity(
        c_masked.unsqueeze(1), q_negs, dim=-1) / logit_temp              # [M, K]
    logits = torch.cat([pos.unsqueeze(1), neg], dim=1)                   # [M, K+1]
    targets = torch.zeros(len(pos), dtype=torch.long, device=pos.device)
    return Fn.cross_entropy(logits, targets)  # 即 -log softmax 正样本


def diversity_loss(soft):
    """soft: [B, T, G, V] —— 鼓励 codebook 平均分布接近均匀(最大化熵)"""
    p_bar = soft.mean(dim=(0, 1))                       # [G, V]
    ent = -(p_bar * (p_bar + 1e-9).log()).sum(-1)       # [G]
    return -(ent / torch.log(torch.tensor(
        float(soft.shape[-1])))).mean()                 # 归一化后取负 -> 待最小化

# 总损失: loss = wav2vec2_contrastive_loss(...) + 0.1 * diversity_loss(soft)
```

实现细节提醒：

* 负样本采样要排除正样本自身的时间步（以及相邻帧，避免「假负样本」）。
* $\kappa$（logit_temp）固定 0.1 而非可学习，cos 相似度已天然归一化到 $[-1,1]$，除以 0.1 拉伸到 $[-10,10]$，让 softmax 有足够区分度。
* 温度退火：`temp = max(temp_min, temp * decay^step)`，训练前期 soft 采样保证探索，后期逼近硬量化。

## 5. 微调与零样本评估

### 5.1 CTC 微调（标准做法）

1. 冻结 CNN feature encoder（低资源时甚至只解冻最后几层 Transformer）。
2. 在 context network 输出上接一个随机初始化的 **线性 CTC 分类头**（输出维度 = 词表大小，LibriSpeech 实验中用 28 个字符级 token + blank）。
3. 微调时施加 **SpecAugment**（time/freq mask）+ 更高的 dropout（Base 用 0.1，10 min 数据时 dropout 上调），学习率远小于预训练（如 $1\text{e-}5 \sim 3\text{e-}5$ 量级，warmup + 线性衰减）。
4. 损失即标准 CTC 前后向（参考本仓库 RNN-Transducer 笔记中的 CTC 依赖）。

### 5.2 Transducer 微调

工业界（流式 ASR 场景）常把预训练的 wav2vec 2.0 encoder 作为 **RNN-T / Conformer-Transducer 的声学编码器**：

* 冻结或低学习率微调 CNN encoder，Transformer 层用较大学习率。
* 输出帧率 50 帧/s 需下采样（如 4 倍）到 12.5 帧/s 以对齐 Transducer 延迟与显存需求。
* 代表工作：wav2vec 2.0 + Pruned RNN-T（如 Google 的 Conformer + SSL 预训练系列）。

### 5.3 零样本 / 无标注评估

* **无监督 ASR（wav2vec 2.0 for ASR without labels, 2021）**：利用预训练量化模块把无标注语音转成离散 pseudo-token，再通过发音词典（lexicon）+ 字符 LM 把 token 映射到词，实现**完全不用标注**的 ASR —— 在 LibriSpeech 上达到约 5.9（test-clean）/ 10（test-other）WER 量级（配合语言模型重打分），首次把无监督 ASR 推进到可用水平。
* **SUPERB（2021）**：冻结上游模型，仅在其上加轻量下游头，统一评测 PR（音素识别）、ASR、SI（说话人识别）、SV（说话人验证）、SD（说话人分离）、SE（语音增强）、SF（语义理解）等任务。wav2vec 2.0 在 **PR 上尤其强**（帧级声学判别性强），在说话人任务上弱于 HuBERT（对比目标不保留 speaker 信息，甚至隐式抑制）。

## 6. 数据效率与关键实验数字

LibriSpeech test-clean / test-other 上的 WER（%，无语言模型，除非注明）：

| 有标注数据量 | Base（LS-960 预训练） | Large（LV-60k 预训练） |
| --- | --- | --- |
| **10 min** | 4.8 / 8.2 | **3.0 / 6.2** |
| **1 h** | 3.6 / 7.8 | 2.5 / 5.6 |
| **10 h** | 2.9 / 6.8 | 2.1 / 4.5 |
| **100 h** | 2.2 / 5.7 | 1.8 / 4.3 |
| **960 h（全量）** | 1.9 / 4.2 | 1.7 / 3.4（+LM 后 1.8 / 3.3） |

关键结论（面试常引用）：

* **10 分钟标注 + 5.3 万小时无标注** 即可达到 3.0/6.2 WER —— 相当于用过去「不可用」的量级数据做出了可用系统。
* **100 h 标注的 Large 模型（1.8/4.3）超过了当时所有用 960 h 全监督训练的 SOTA**，即「1/10 标注量、超越全监督」。
* 全监督上限：+ Transformer LM 后 test-other 3.3，当时（2020）为 LibriSpeech 公开 SOTA。
* 预训练数据从 960 h → 53.6k h，各档 WER 均有 30%~50% 相对下降，说明 **自监督收益随无标注数据量近似对数线性增长**。

## 7. 总结

* **架构一句话**：7 层 CNN 把 16 kHz 波形压成 49 帧/s 的潜在表征，Transformer 基于被 mask 的输入输出上下文表征，Gumbel-Softmax 量化模块（G=2 组、V=320 code、STE 直通梯度）从干净表征生成离散对比目标。
* **目标函数一句话**：对 49% 被 span-mask 的帧做 InfoNCE 对比学习 —— 余弦相似度 / 0.1，正样本是真实量化向量，负样本是同句采样的 K=100 个量化向量，随机基线 $\log 101 \approx 4.6$。
* **损失函数一句话**：$\mathcal{L} = \mathcal{L}_{\text{con}} + 0.1\,\mathcal{L}_{\text{div}}$，diversity 项通过最大化 codebook 平均分布熵防止量化坍缩。
* **优缺点**：
  * 优点：标注效率极高（10 min 可用）、无需人工特征、下游头部极简（一层线性 + CTC）。
  * 缺点：对比目标偏**帧级短期声学**，对音素/词级长时结构建模弱于 masked prediction 类方法（HuBERT/w2v-BERT，见下一篇）；量化模块训练有不稳定性（需监控 codebook perplexity）。
* **后续演进**：HuBERT（伪标签 masked prediction）、w2v-BERT（对比 + masked 双目标）、XLS-R / w2v-BERT 2.0（多语言规模化）、data2vec（多模态统一自监督）。
