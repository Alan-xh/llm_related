# 2. HuBERT 与 w2v-BERT

## 1. 概述

wav2vec 2.0 用「对比学习」定义了语音自监督的主流范式，但暴露出两个问题：

1. **对比目标太「局部」**：正负样本都是同一句话里的帧级量化向量，模型只需区分短期声学细节即可完成任务，对音素类别、词级结构等高阶信息的建模动力不足。
2. **量化模块不稳定**：Gumbel-Softmax + STE 的 codebook 存在坍缩风险，依赖 diversity loss 调参。

针对这两点，2021 年出现了两条互补的改进路线：

* **HuBERT**（Hsu et al., IEEE TASLP 2021, Facebook）：干脆放弃在线量化，**离线用聚类产生伪标签（pseudo-label），把 BERT 的 masked prediction 原封不动搬到语音上**。核心贡献是证明： masked prediction 的关键在于「目标单位」（ clustered latent ），而不是目标函数本身。
* **w2v-BERT**（Chung et al., NeurIPS 2021, Google）：**把对比学习与 masked prediction 合成一个双目标**，用一个端到端可微的 softmax 离散化模块（无需 Gumbel 噪声与 STE）同时服务两个任务，兼得稳定性与高阶语义建模，后来被 Google 的 **USM（Universal Speech Model）** 选为大规模预训练方案（1B 参数、12M 小时）。

面试高频考点：

1. HuBERT 伪标签怎么来？为什么要迭代两轮（MFCC k-means -> 学到的表征 k-means）？
2. HuBERT 的 Begin/End 标签技巧是什么、解决什么问题？
3. w2v-BERT 为什么不需要 STE 与 diversity loss？
4. wav2vec 2.0 / HuBERT / w2v-BERT 三者的目标函数与稳定性对比。
5. 语音离散单元（speech unit）的下游应用：Speech-LLM、codec 语义蒸馏、unit discovery 评测（ABX、sWUGGY）。

## 2. HuBERT：算法架构

### 2.1 整体架构图

```
                        HuBERT 预训练架构
 ┌──────────────────────────────────────────────────────────────┐
 │                                                              │
 │  原始波形 X ──► CNN Encoder ──► z_t ──► Masking ──► Transformer │
 │                (与 wav2vec 2.0 同款 7 层卷积)    (p=0.08,     │
 │                                                  span=10)   │
 │                                                      │       │
 │                                                      ▼       │
 │                                          上下文表征 o_t             │
 │                                                      │       │
 │                                          分类头: Linear            │
 │                                          + Softmax(2C 类)          │
 │                                                      │       │
 │              ┌───────────────────────────────────────┘       │
 │              ▼                                               │
 │   CE 损失（仅在被 mask 位置）:                                │
 │   目标 = 离线 k-means 伪标签                                  │
 │                                                              │
 │   [离线流程, 不参与梯度]                                      │
 │   音频 ──► MFCC / 上一轮 HuBERT 中间层表征 ──► k-means ──►    │
 │            帧级 cluster id 序列（伪标签）                      │
 └──────────────────────────────────────────────────────────────┘
```

* **骨干与 wav2vec 2.0 完全一致**：7 层 CNN feature encoder（20 ms/帧）+ 卷积位置编码 + Transformer encoder；Base 12 层 / Large 24 层。
* **关键差异**：**没有在线量化模块**。离散目标完全由离线聚类产生，网络本身只做一个「对 masked 位置的多类分类」。
* 分类头输出维度为 $2C$（$C$ 为聚类数），原因见 2.4 的 Begin/End 技巧。

### 2.2 Masked Prediction 目标函数推导

设被 mask 的时间步集合为 $\tilde{Z}$，对每个 $t \in \tilde{Z}$，模型输出 $o_t$ 后接线性投影 + softmax，预测其伪标签 $z_t \in \{1, \dots, 2C\}$：

$$p(z_t \mid \tilde{Z}, t) = \text{softmax}(W o_t + b)_{z_t}$$

训练目标为**负对数似然（NLL），即交叉熵（CE）**：

$$\mathcal{L}_{\text{mask}} = -\sum_{t \in \tilde{Z}} \log p(z_t \mid \tilde{Z}, t)$$

实现上对**未被 mask 的位置损失权重置 0**（masked weight $\alpha = 1$，unmasked weight $\beta = 0$；论文消融显示在 unmasked 位置加小权重（如 0.1）也能工作，但默认只算 masked 位置）。

掩码策略：起始概率 $p = 0.08$、span 长 $M = 10$，有效掩码比例 $1 - 0.92^{10} \approx 56\%$（比 wav2vec 2.0 的 49% 略高）。

**为什么 masked prediction 优于纯对比学习（HuBERT 论文的核心论证）**：

* 对比学习的负样本来自同句，模型只需「区分这一帧和别人」；masked prediction 的类别是**跨句聚类的声学单元**，逼着模型学习「这一帧属于哪个音素级类别」，目标的**语义抽象层级更高**。
* 对比损失对「目标表示坍缩」敏感，而 CE + 大量类别天然是更稳定的判别问题。

### 2.3 离线聚类伪标签与两轮迭代

**第 1 轮（iter1）**：对 39 维 MFCC 特征做 k-means，聚类数 $C = 100$，得到初始伪标签训练 HuBERT Base。
**第 2 轮（iter2）**：用 iter1 模型的**中间层表征**（论文取第 9 层，即约 12 层的 3/4 深度处 -- 中间层对音素判别性最好，最深层偏语义）重新聚类，聚类数增至 $C = 500$，再训一个新模型。

迭代逻辑（鸡生蛋问题的解法）：

$$\text{弱伪标签} \to \text{更好的表征} \to \text{更好的伪标签} \to \text{更好的表征}$$

* MFCC 聚类质量差（纯声学、无上下文），但足以提供「冷启动」信号 -- 论文证明即便第 1 轮标签噪音很大，模型也能学到接近音素边界的表征。
* 第 2 轮聚类数从 100 -> 500：表征能力增强后可以支撑更细粒度的单元划分（500 类已接近「带上下文的音素状态」粒度）。
* Large 模型（LL-60k 预训练）直接用 iter2 的 Base 模型在 60k 小时数据上产出伪标签；XL（约 1B 参数，96 层）沿用同样流程。

### 2.4 Begin/End 预测损失与标签去重技巧

**问题**：k-means 伪标签是**逐帧（每 20 ms 一个）**的 cluster id，相邻同音帧的标签大量重复（如一个 300 ms 的元音对应 15 个相同的 cluster id）。直接逐帧预测有两个弊端：

1. 模型大量「免费」预测容易的重复帧，损失被简单样本主导；
2. 无法强迫模型感知「单元边界」。

**HuBERT 的三步处理**：

```
帧级标签:    [5, 5, 5, 5, 17, 17, 8, 8, 8, ...]
① 去重:      [5, 17, 8, ...]                       (类似 run-length 压缩)
② 边界标注:  [(5, Begin), (17, Begin), (8, Begin), ...]
             每个单元内: 首帧 = c, 其余帧 = c + C
③ 展开回帧级: [5, 5+C, 5+C, 5+C, 17, 17+C, 8, 8+C, 8+C, ...]
```

即：**每个单元的首帧标签为 $c \in [1, C]$，其余帧标签为 $c + C \in [C+1, 2C]$**，分类头维度因此为 $2C$。

效果（面试要点）：

* 有效类别数接近真实「声学单元」数而非帧数，损失不再被重复帧稀释；
* 「首帧 vs 非首帧」的二分隐藏在标签里，模型隐式学到了**单元边界检测**；
* 保持输出帧数与输入帧数一一对应， masking 与 CE 计算无需特殊对齐逻辑；
* 消融实验中去掉该技巧（直接用原始帧级标签）性能明显下降。

## 3. HuBERT 损失函数与 PyTorch 实现要点

总损失即加权 masked CE（展开写）：

$$\mathcal{L} = -\frac{1}{|\tilde{Z}|} \sum_{t=1}^{T} \mathbb{1}[t \in \tilde{Z}] \cdot \log \frac{\exp(w_{z_t}^\top o_t + b_{z_t})}{\sum_{j=1}^{2C} \exp(w_j^\top o_t + b_j)}$$

```python
import torch
import torch.nn as nn
import torch.nn.functional as Fn

class HubertLoss(nn.Module):
    """HuBERT masked prediction loss: masked 位置 CE, unmasked 权重 0"""
    def __init__(self, num_classes=1000, mask_weight=1.0, unmask_weight=0.0):
        super().__init__()
        self.mask_weight = mask_weight
        self.unmask_weight = unmask_weight
        # label smoothing eps=0.1 (fairseq 默认), 忽略 padding(-100)
        self.ce = nn.CrossEntropyLoss(
            reduction="none", label_smoothing=0.1, ignore_index=-100)

    def forward(self, logits, targets, mask):
        """
        logits:  [B, T, 2C]  (Transformer 输出 + 线性头)
        targets: [B, T]      (Begin/End 展开后的帧级伪标签)
        mask:    [B, T] bool (True = 该帧被 mask)
        """
        B, T, C2 = logits.shape
        loss = self.ce(
            logits.view(B * T, C2), targets.view(B * T))          # [B*T]
        weight = torch.where(
            mask, self.mask_weight, self.unmask_weight).view(-1)  # [B*T]
        # 仅对有效(masked)位置加权平均
        return (loss * weight).sum() / weight.sum().clamp(min=1.0)
```

实现细节：

* label smoothing $\epsilon = 0.1$ 是 fairseq 默认配置，对伪标签噪声有缓冲作用。
* 伪标签存储为离散 id 的 LZMA 压缩文件（离线生成、不占显存），训练时按需解码。
* 大规模训练（LL-60k）时聚类在 64GPU 上分片跑 k-means，伪标签生成是一次性的预处理成本。

## 4. w2v-BERT：算法架构与双目标

### 4.1 动机

w2v-BERT 观察：wav2vec 2.0 的对比学习**训练信号稳定但目标抽象层级低**；BERT 式 masked prediction**目标抽象层级高但依赖离散单元（鸡生蛋问题）**。于是把两者放进一个模型：

* **对比任务**在训练早期提供稳定、密集的帧级监督信号；
* **masked prediction** 随训练推进逐步接管，用离散单元分类学习高阶语音结构；
* 两个任务**共享同一个离散化模块** -- masked prediction 的分类目标（离散单元 id）与对比任务的量化向量同源，离散化模块被两个损失共同驱动，**不再需要 diversity loss 来对抗坍缩**（masked LM 本身就是 codebook 的强正则）。

### 4.2 架构与 Discretization 模块

```
                       w2v-BERT 双目标结构
 原始波形 ──► CNN Encoder ──► z_t ──┬──► Masking ──► Transformer ──► o_t
                                   │                              │
                                   ▼                              ├─► 头1: 对比学习
                          ┌──────────────────┐                    │    (o_t vs 量化向量
                          │ Discretization   │◄── (对干净 z_t)     └─► 头2: Masked LM
                          │ (G 组 softmax,   │                         (o_t 分类离散 id)
                          │  可微、无 STE)    │
                          └──────────────────┘
```

**Discretization 模块与 wav2vec 2.0 量化模块的对比**：

| 维度 | wav2vec 2.0 量化 | w2v-BERT 离散化 |
| --- | --- | --- |
| 概率化方式 | Gumbel-Softmax（加噪） | **纯 softmax**（不加噪） |
| 离散化梯度 | STE 直通估计（有偏） | softmax 端到端可微（soft 概率参与计算） |
| 额外正则 | 需要 diversity loss ($\lambda=0.1$) | 不需要（masked LM 已提供 codebook 监督） |
| 输出形式 | one-hot 拼 code 向量（hard） | 组内 soft/加权组合向量 |

softmax 量化第 $g$ 组的概率：

$$p_{g,v} = \text{softmax}_v\big(\langle z_t^{(g)}, e_{g,v} \rangle / \tau\big)$$

由于不采样、不加 Gumbel 噪声，整个「表征 -> 离散分布 -> 目标」链路可微，梯度可以直接更新 codebook -- 这是 w2v-BERT 训练稳定性优于 wav2vec 2.0 的架构根源。

### 4.3 双目标损失函数

对被 mask 的位置 $t$（span masking，约一半帧）：

**目标 1 -- 对比损失**（与 wav2vec 2.0 同构，负样本来自同句、$K$ 个）：

$$\mathcal{L}_{\text{con}} = -\sum_{t \in \tilde{Z}} \log \frac{\exp\big(s(o_t, q_t)/\kappa\big)}{\exp\big(s(o_t, q_t)/\kappa\big) + \sum_{k=1}^{K} \exp\big(s(o_t, \tilde{q}_k)/\kappa\big)}$$

**目标 2 -- Masked LM 损失**（预测离散单元 id，组内独立 CE）：

$$\mathcal{L}_{\text{mlm}} = -\sum_{t \in \tilde{Z}} \sum_{g=1}^{G} \log p_{\text{head}}\big(u_{g,t} \mid o_t\big), \qquad u_{g,t} = \arg\max_v p_{g,v}(z_t)$$

**总损失为简单相加**：

$$\mathcal{L}_{\text{w2v-BERT}} = \mathcal{L}_{\text{con}} + \mathcal{L}_{\text{mlm}}$$

> **面试要点**：两个头看到的输入 $o_t$ 相同、mask 相同，但监督形式不同 -- 对比头在**连续向量空间**拉近 $o_t$ 与量化目标，分类头在**离散类别空间**对齐单元 id。前者保证表征几何结构，后者保证语义抽象与 codebook 健康。相同数据/规模下 w2v-BERT 在 LibriSpeech 上稳定优于 wav2vec 2.0；该方案随后被 USM 扩展到 1B 参数、12M 小时，支撑 Google 的多语言大模型时代。

## 5. wav2vec 2.0 / HuBERT / w2v-BERT 对比

| 维度 | wav2vec 2.0 | HuBERT | w2v-BERT |
| --- | --- | --- | --- |
| **预训练目标** | 掩码对比学习（InfoNCE） | masked prediction（对伪标签 CE） | 对比 + masked prediction 双目标 |
| **离散目标来源** | 在线 Gumbel 量化 | **离线 k-means 伪标签，两轮迭代** | 在线 softmax 离散化（可微） |
| **量化是否参与训练** | 是（STE + 温度退火） | 否（纯离线预处理） | 是（端到端可微） |
| **辅助正则** | diversity loss（$\lambda=0.1$） | 无 | 无 |
| **训练稳定性** | 中（codebook 坍缩风险） | **高**（CE 分类稳定；但伪标签质量影响上限） | 高（双目标互为正则） |
| **目标抽象层级** | 帧级声学（局部） | 音素级单元（高阶） | 两者兼有 |
| **SUPERB 表现** | PR（音素识别）最强 | **综合最均衡**（SI/SV/SD/PR 全面强） | ASR/PR 强 |
| **典型规模** | Base 95M / Large 317M | 同左；XL 约 1B | Large 级；USM 版 1B |
| **后续影响** | XLS-R 多语言版 | XLS-R 沿用 HuBERT 目标；speech unit 事实标准 | USM、SER 框架 |

补充两点对比细节：

* **伪标签 vs 对比学习的哲学差异**：对比学习「实例判别」不需要任何先验单位，但天花板受限于负样本设计；HuBERT 先验地承认「语音存在离散单元结构」，用聚类显式造出来 -- 对小数据更稳，但引入聚类质量这一额外变量。
* **表征偏差**：wav2vec 2.0 的目标在同句内做判别，天然抑制说话人信息 -> 说话人任务弱；HuBERT 伪标签只按声学聚类、未显式去除说话人因子 -> speaker 相关任务（SV/SI）显著更强。这解释了 SUPERB 上两者的分工。

## 6. 下游应用：从 SUPERB 到 Speech-LLM

### 6.1 SUPERB 与传统任务

* **ASR 微调**：HuBERT 与 wav2vec 2.0 同样接 CTC/Transducer 头微调，LL-60k 预训练的 HuBERT Large 在 LibriSpeech 960h 达到约 1.9 / 3.3 WER（+LM），与 wav2vec 2.0 Large 同档。
* **说话人任务**：SUPERB 上 HuBERT Large 的 SV EER 约 1.4%、SI ACC 约 87% 量级，优于 wav2vec 2.0 -- 冻结 encoder + 轻量头即可用，是「SSL encoder 当通用特征」这一说法的实证来源。
* **语音分离/增强/翻译**：encoder 输出直接替换传统谱特征接入下游模型。

### 6.2 Speech-LLM 与 codec 语义蒸馏

自监督离散单元是「语音大模型」的关键中间层：

* **GSLM（Generative Spoken Language Model）**：用 vq-wav2vec / HuBERT unit 训自回归语音 LM，实现无文本的语音对话与 TTS/ASR 零资源闭环。
* **AudioLM（2022）**：语义阶段 token 来自 **w2v-BERT 表征 + k-means（约 100 类）**，声学阶段再用 SoundStream -- 证明 SSL 单元携带足够语义且可级联生成。
* **codec 语义蒸馏**：神经 codec（EnCodec / SoundStream）的 RVQ token 原本是纯声学重建目标，缺语义；**SpeechTokenizer 等工作把 HuBERT 表征蒸馏进 RVQ 第一层量化器**，使第一层 token 与语义单元对齐 -- 下游 Speech-LLM（如基于 EnCodec 的 TTS/LLM 级联）用「一层语义 token + 多层声学 token」获得更好可懂性与可移植性。这正是「HuBERT 用于 codec 语义蒸馏」的标准场景。
* **USM / 多语言 ASR**：w2v-BERT 预训练 + 有监督微调的两阶段范式支撑了 Google 2023 年后的大规模多语言模型。

### 6.3 Speech Unit Discovery 面试点

1. **什么是 unit discovery**：零资源（zero-resource）场景下，无文本无对齐，从原始语音中发现可复用的离散符号系统（音素级 token）。
2. **主流方法**：k-means over SSL 表征（HuBERT unit 已是事实标准）、对比预测编码 + 量化（wav2vec 系列）、无监督 HMM/自组织方法（历史路线）。
3. **评测指标**：
   * **ABX discriminability**：跨说话人/上下文比较两个 unit 的表征距离，衡量音素判别性（HuBERT 中间层是 ABX 最强特征之一）；
   * **sWUGGY / sBLIMP**：语音版语法/词汇探针，评 unit 支撑的语音 LM 语言能力；
   * **token F1 / 边界对齐**：与真实音素边界的吻合度。
4. **常见追问**：
   * 「HuBERT unit 为什么比 MFCC 聚类好？」-- 带上下文的判别表征 + 迭代自提升，聚类纯度高、边界准。
   * 「unit 数（100/500/1000）怎么选？」-- 与目标粒度（音素 vs 音素状态）和下游任务（LM vs TTS 声学细节）匹配，常用 grid search 以 ABX/sWUGGY 选定。
   * 「SSL unit 与 codec token 的关系？」-- 前者语义为主、后者声学为主；现代系统（SpeechTokenizer、AudioLM 类）常将两者对齐或级联。

## 7. 总结

* **HuBERT 一句话**：骨干同 wav2vec 2.0，但把目标换成「对离线 k-means 伪标签的 masked CE」；两轮迭代（MFCC k=100 -> 自身表征 k=500）解决冷启动；Begin/End 标签展开技巧让损失聚焦单元级预测并隐式学习边界。
* **w2v-BERT 一句话**：对比 + masked LM 双目标共享一个可微 softmax 离散化模块，无需 Gumbel/STE/diversity loss，稳定性与语义抽象兼得，后经 USM 验证了规模化能力。
* **损失函数对照**：
  * wav2vec 2.0：$\mathcal{L}_{\text{con}} + 0.1\,\mathcal{L}_{\text{div}}$（InfoNCE + codebook 熵正则）；
  * HuBERT：$-\sum_{t \in \tilde{Z}} \log p(z_t \mid \tilde{Z}, t)$（masked CE / NLL）；
  * w2v-BERT：$\mathcal{L}_{\text{con}} + \mathcal{L}_{\text{mlm}}$（简单相加）。
* **选型建议**：需要 speaker/通用特征或 speech unit -> **HuBERT**；需要 ASR 导向且想要稳定端到端训练 -> **w2v-BERT / wav2vec 2.0**；低资源微调首选带大规模预训练（LV-60k/XLS-R）的 checkpoint。
* **趋势**：自监督单元已成为 Speech-LLM 的标准中间表示（语义 token、codec 蒸馏、AudioLM 式级联），unit discovery 与 ABX 等零资源评测仍是活跃研究方向。
