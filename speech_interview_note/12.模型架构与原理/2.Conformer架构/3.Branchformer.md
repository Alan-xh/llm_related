# 3. Branchformer

## 1. 概述

**Branchformer**（Peng et al., INTERSPEECH 2022）针对 Conformer「CNN 与 Attention **串行** 融合」提出的反思性架构：

> 局部建模与全局建模是两种**本质不同的能力**，串行堆叠（一个模块的输出作为另一个的输入）让二者耦合，既不便于分析各能力的贡献，也不便于针对流式场景做差异化因果化。Branchformer 将其**解耦为两条并行分支**，用可学习权重合并。

核心卖点：

1. **双分支并行**：cgMLP 分支（局部）+ Self-Attention 分支（全局）并行，输出加权合并；
2. **可解释性**：通过 merge 权重可以直观观察每一层偏向局部还是全局（实验发现浅层偏 attention、深层偏 cgMLP 等有趣模式）；
3. **流式友好**：两条分支可**独立**做 causal 化（cgMLP 用因果深度卷积，attention 用 chunk 内注意力），比串行结构灵活得多；
4. **E-Branchformer**（2023）：增强版，把合并点提前、引入卷积融合模块，在流式场景下显著增强。

* **论文**：*Branchformer: Parallel MLP-Attention Architectures to Capture Local and Global Context Behind Speech*（INTERSPEECH 2022）；E-Branchformer: *E-Branchformer: Branchformer with Enhanced Merging for Speech Recognition* (2023)。

## 2. 算法架构

### 2.1 整体结构

与 Conformer 相同的前端（Conv subsampling 4x + Linear projection），主体为 N 个 Branchformer layer（通常 12 层 encoder，d=256/512）：

```
  80-d Fbank ─► Conv Subsampling (4x) ─► N × Branchformer Layer ─► CTC / Transducer head
```

### 2.2 Branchformer Layer（双分支结构）

单个 layer 的数据流：

```
                 x_in
                  │
            ┌─────┴─────┐
            │  LN       │
      ┌─────▼────┐ ┌────▼─────────┐
      │ cgMLP    │ │ Self-Attn    │      两分支并行处理
      │ (局部)   │ │ (全局, 含    │
      │          │ │  相对位置)   │
      └─────┬────┘ └────┬─────────┘
            │            │
            │  α·z_cg    │  (1-α)·z_attn     可学习 merge 权重
            └─────►(+)◄──┘
                  │
                 x_in + merged            残差
                  │
                 LN ─► FFN ─► (+)         标准 FFN 子层
                  │
                 x_out
```

公式：

$$z = \alpha \cdot \text{cgMLP}(\text{LN}_1(x)) + (1 - \alpha) \cdot \text{MHSA}(\text{LN}_1(x))$$
$$x' = x + z$$
$$x_{out} = x' + \text{FFN}(\text{LN}_2(x')), \quad \text{FFN}(h) = \text{Linear}_2(\text{GeLU}(\text{Linear}_1(h)))$$

其中 $\alpha \in (0,1)$ 为每层独立的**可学习标量 merge 权重**（用 sigmoid 参数化），初始化 0.5。

### 2.3 cgMLP 分支

cgMLP（convolutional gated MLP）来自 MLP 系列工作（Pay Less Attention with Lightweight & Dynamic Convolutions / ResMLP 思路），结构：

$$\text{cgMLP}(x) = \text{Linear}_2\Big( u \odot \sigma(v) \Big), \quad u = \text{DWConv}_k\big(\text{Linear}_{u}(x)\big),\ v = \text{Linear}_{v}(x)$$

```
x ─► LN ─► Linear(d→d) ─► DWConv(k=31) ─┐ u
    └► Linear(d→d) ─────────────────────┘ v
                     GLU: u ⊗ sigmoid(v)
                  ─► Linear(d→d) ─► (+)
```

* **通道投影 + 深度卷积 + 门控**：深度卷积（kernel≈31）负责局部时序模式，GLU 门控做通道筛选，FFN-风格的逐帧变换提供容量；
* 参数量约 $O(d^2)$ 每层，与 attention 分支相当，保持平衡；
* **与 Conformer Conv Module 的区别**：cgMLP 无 BatchNorm、两路通道投影做 GLU（Conv Module 是 PWConv 升维 2d 后 GLU），且 cgMLP 在分支内自带 Pre-LN 归一化（Conv Module 内为独立 LN）。

### 2.4 Self-Attention 分支

标准 MHSA + **相对位置编码**（沿用 Conformer/Transformer-XL 风格），注意力 logit 同样分解为四项：

$$\text{logit}_{ij} = q_i^T k_j + q_i^T p^{K}_{j-i} + u^T k_j + v^T p^{K}_{j-i}$$

* $p^{K}_{j-i}$ 为按相对距离查表的可学习嵌入，$u, v$ 为全局偏置向量；
* 相对位置编码保证 chunk 训练/推理时 chunk 内距离分布与全序列一致，是流式可迁移的关键；
* 该分支负责全局上下文，是双分支中唯一具备「任意距离交互」能力的通路。

> 面试记忆点：**cgMLP 完全没有时间维全局交互（除局部 kernel 外逐帧独立），Attention 没有显式局部偏置**——两分支是「纯局部」与「纯全局」的两个极端，merge 权重让网络自己学每层的配比。

### 2.5 可学习 merge 权重与可解释性

训练后各层的 $\alpha$（attention 占比 $1-\alpha$）呈现规律：

* 靠近输入的层 attention 占比更高（全局语义抽象）；
* 中后层 cgMLP 占比升高（细粒度声学特征）；
* 相比 Conformer 串行结构「每层都被迫同时做两件事」，Branchformer 的每层职责由数据自动分配，分析两层分支各自贡献变得透明。

### 2.6 流式友好性

串行结构（Conformer）流式化时，MHSA 与 Conv 必须一起处理 chunk 边界，且 Conv 在 Attention 之后导致有效左上下文相互纠缠。Branchformer 解耦后：

* **cgMLP 分支**：把 DWConv 改为 **causal padding**，天然支持任意流式；
* **Attention 分支**：改为 **chunk-based attention**（只看当前 chunk + 有限左上下文，例如 4 帧右上下文）；
* 两分支各自因果化后合并，可精细控制「局部分支看多远、全局分支看多远」的差异化配置；

典型流式配置（LibriSpeech chunk-based 实验）：

| 配置项 | cgMLP 分支 | Attention 分支 |
| --- | --- | --- |
| 因果化 | causal DWConv（左 context = kernel - 1） | chunk attention（chunk 64 帧 + 左 context 128 帧为例） |
| 计算量 | 与离线几乎一致 | 随 chunk 长度平方缩减 |
| 延迟 | 零（纯因果） | 取决于右 context（可设为 0） |

* 与 Conformer 流式化的对比：Conformer 中 Conv Module 位于 MHSA 之后，chunk 截断会同时伤害两个模块且难以独立补偿；Branchformer 可仅对 attention 分支缩短上下文而保留 cgMLP 全量左 context，在相同延迟预算下保留更多有效信息。

### 2.7 E-Branchformer（增强版）

E-Branchformer 的三项改动：

1. **提前合并（early merge）**：把两分支的合并点从 FFN 之前移到**各分支内部输出后立刻合并，再共享一个大 FFN**（两份 FFN 合一，省参数且让融合表征统一过 FFN）；
2. **CGMLP 的 kernel pooling**：DWConv 前后加 pooling（如 kernel-size 2 的平均池化）进一步扩大局部感受野、降低计算；
3. **Convolutional Fusion Module（CFM）**：合并后的表征再过一个「深度卷积 + GLU」融合模块，弥补 chunk 流式下 attention 分支缺乏跨 chunk 交互的问题，在流式场景收益显著（相比未加 CFM 的流式基线 WER 降低 0.2~0.4）。

结构对比：

```
Branchformer:  x + [α·cgMLP(LN x) + (1-α)·Attn(LN x)] ─► x + FFN(LN ·)
E-Branchformer: x + CGMLP_kernel_pool(LN x) ┐
                                              ├ merge ─► x + CFM(FFN(LN ·))
               x + ChunkAttn(LN x)          ─┘
```

（E-Branchformer 中 merge 通常为加权池化式的可学习合并，且 FFN 只有一份，参数量比 Branchformer 的双 FFN 思路更省。）

### 2.8 效果数字量级（LibriSpeech）

| 模型 | 头/解码 | test-clean | test-other | 备注 |
| --- | --- | --- | --- | --- |
| Conformer-M 基线 | CTC + LM | ~2.9 | ~6.9 | 同尺寸对比 |
| Branchformer（cgMLP+Attn, 12L, d=256） | CTC + LM | ~2.8 | ~6.8 | 与 Conformer 基本持平 |
| Branchformer large（d=512） | Transducer | ~2.2 | ~5.1 | 非流式 |
| E-Branchformer + CFM | 流式 Transducer | ~2.4~2.8 | ~5.8~6.5 | 相同延迟下优于流式 Conformer/Branchformer |

* 结论量级：**非流式精度与 Conformer 持平（互有 ±0.1~0.2），流式同延迟下 E-Branchformer 更优**；训练配置（SpecAugment + speed perturb，Adam + warmup）与 Conformer 完全一致，保证公平对比。

## 3. 目标函数

Branchformer 是纯 encoder 架构，目标函数随下游头选择：

**CTC 搭配**：

$$P(Y \mid X) = \sum_{\pi \in \mathcal{B}^{-1}(Y)} \prod_t P(\pi_t \mid h_t), \quad h_t = \text{Branchformer}(x)_{t}$$

**Transducer 搭配**（如 Stateless Transducer / pruned RNN-T，均兼容）：

$$P(y_{t,u} \mid x_{1:t}, y_{1:u-1}) = \text{Softmax}\big(\text{Joint}(h_t, p_u)\big)$$

论文主要报告 CTC 与 Transducer 两种；流式实验（E-Branchformer）以 Transducer 为主。与 Conformer 一样，encoder 的改动不改变目标函数形式，**「目标函数 = 头的选择 + 条件独立/自回归假设」这一层次要分清楚**。

---

## 4. 损失函数

### 4.1 与 CTC 组合

$$\mathcal{L}_{\text{CTC}} = -\ln \sum_{\pi \in \mathcal{B}^{-1}(Y)} \prod_{t=1}^{T} P(\pi_t \mid h_t)$$

* 用 log 域前向-后向算法（`torch.nn.functional.ctc_loss` 或 torchaudio 的 CUDA warp-ctc）计算；
* 通常加 **SpecAugment + speed perturb**；单 CTC 训练时常用中等模型（12 层，d=256）即可在 LibriSpeech 拿到 test-clean $\approx$ **2.79 ~ 2.88**（CTC + LM rescoring，视配置）的量级，与同尺寸 Conformer-CTC 基本持平或略优。

### 4.2 与 Transducer 组合

$$\mathcal{L}_{\text{RNNT}} = -\ln \sum_{\pi \in \Omega(X,Y)} \prod_{(t,u)} P(\pi_{t,u} \mid h_t, p_u)$$

* 常见为 **joint CTC-Transducer 多任务**（利于对齐稳定）：

$$\mathcal{L} = \lambda \mathcal{L}_{\text{CTC}} + (1-\lambda)\mathcal{L}_{\text{RNNT}}, \quad \lambda \approx 0.2 \sim 0.5$$

* 流式 E-Branchformer Transducer（chunk 训练）在 LibriSpeech 上流式 WER 量级：test-clean $\approx$ **2.4 ~ 2.8**（非流式 Branchformer Transducer 大模型约 **2.24 / 5.06**，E-Branchformer + CFM 流式版可将流式损失较 Branchformer 流式版再降 5~10% 相对）。

### 4.3 PyTorch 实现要点

```python
import torch
import torch.nn as nn

class BranchformerLayer(nn.Module):
    def __init__(self, d_model=256, n_heads=4, kernel_size=31, ffn_ratio=4):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        # 分支 1: cgMLP (局部)
        self.cgmlp = CgMLP(d_model, kernel_size)   # LN->PW->DWConv->GLU->PW
        # 分支 2: self-attention (全局, 相对位置编码)
        self.attn = RelPosSelfAttention(d_model, n_heads)
        # 可学习 merge 权重 (sigmoid 参数化, 初始 0.5)
        self.merge_logit = nn.Parameter(torch.zeros(1))
        # 后置 FFN
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, ffn_ratio * d_model), nn.GELU(),
            nn.Linear(ffn_ratio * d_model, d_model))

    def forward(self, x, pos_emb):
        alpha = torch.sigmoid(self.merge_logit)          # cgMLP 权重
        z_local  = self.cgmlp(self.norm1(x))
        z_global = self.attn(self.norm1(x), pos_emb)
        x = x + alpha * z_local + (1.0 - alpha) * z_global   # 双分支加权合并
        x = x + self.ffn(self.norm2(x))
        return x

# 训练损失 (joint CTC-Transducer):
# loss = 0.3 * F.ctc_loss(ctc_logits.log_softmax(-1), ...) \
#      + 0.7 * rnnt_loss(joint_logits, ...)
```

要点：

* merge 权重是**标量**（per-layer），也可以做成 per-channel（$\alpha \in \mathbb{R}^{d}$），论文消融显示标量已足够；
* 两分支共享同一个 `norm1`（与并行结构对应的 Pre-LN 写法），流式化时仅需替换分支内部实现（causal DWConv / chunk attention），merge 与 FFN 不动。

## 5. 与 Conformer 的对比

| 维度 | Conformer | Branchformer / E-Branchformer |
| --- | --- | --- |
| 融合方式 | CNN 与 Attention **串行**（Conv 在 MHSA 后） | 局部/全局 **并行双分支** + 加权合并 |
| LN 位置 | Post-LN（块尾） | Pre-LN（分支入口） |
| 局部建模 | Conv Module（PW-GLU-DW-BN-Swish-PW） | cgMLP（PW-DWConv-GLU-PW），无 BN |
| 可解释性 | 难以拆分局部/全局贡献 | merge 权重直接量化各层配比 |
| 流式改造 | 需同时因果化 MHSA+Conv，耦合 | 分支独立 causal 化，配置灵活 |
| 精度（LibriSpeech 非流式） | 基线 | 同量级（互有胜负，略优） |
| 精度（流式） | chunk 化退化明显 | **E-Branchformer + CFM 退化更小** |

---

## 6. 总结

* **架构记忆点**：cgMLP（局部）∥ Self-Attention（全局），$\alpha$ 可学习加权 merge，后接共享 FFN；E-Branchformer 提前合并 + kernel pooling + Convolutional Fusion Module。
* **动机**：局部与全局建模解耦——既方便分析（merge 权重可视化），又方便工程（分支独立因果化做流式）。
* **目标/损失**：纯 encoder，头即插即用；实践中以 joint CTC-Transducer 损失（$\lambda$ 加权）和 pruned RNN-T 为主。
* **定位**：Branchformer 的价值不在绝对精度碾压（与 Conformer 大体持平），而在**解耦带来的可解释性与流式灵活性**；其「并行分支 + 可学习合并」的设计思想后续被 Emformer/Streamformer 等流式架构广泛借鉴。
