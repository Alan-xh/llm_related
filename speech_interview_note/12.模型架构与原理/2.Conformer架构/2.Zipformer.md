# 2. Zipformer

## 1. 概述

**Zipformer** 是 Daniel Povey 团队（k2 / icefall，Yao et al., ICASSP 2024）提出的 ASR 编码器架构，可以理解为「**对 Conformer 做一次全面的工程与算法再设计**」：保留「注意力 + 卷积混合」的思路，但在模块结构、归一化方式、激活函数、下采样策略、位置编码与损失函数上全部重构。

核心改进点（面试记忆清单）：

1. **Downsampled encoder structure**：由多个 stack 组成，中间 stack 做 2 倍逐级下采样（最高 8 倍），大部分计算在低帧率上进行，速度与显存同时受益。
2. **BiasEncoder（Belief-Encoder）**：把「帧是否激活、chunk 内相对位置、说话人」三种信息编码为偏置向量，注入自注意力与 pooling 模块，专为**流式 chunk 训练**设计。
3. **Swoosh-R / Swoosh-L 激活函数**：ReLU/Mish 的平移修正版本，输出均值更接近 0，适配「弱归一化」网络。
4. **normalize-and-project 策略**：用 Balancer / Whiten / BiasNorm 取代 LayerNorm，配合 skip 分支的非线性投影，让网络在**不强行归一化尺度**的前提下稳定训练。
5. **复数域（complex domain）处理**：自注意力与 ConvNeXt 模块的特征视为复数（实部/虚部各占一半通道），用复数线性变换建模。

* **论文**：*Zipformer: Faster Transformer-based Encoder for NeurIPS 2023 (Speech Recognition)*，工程实现在 icefall 的 `pruned_transducer_stateless7` / `pruned_transducer_stateless8`（含流式 `streaming` 版本）。

## 2. 算法架构

### 2.1 整体结构：Downsampled Encoder

Conformer 的所有层都在 $T/4$ 帧率下计算，而 Zipformer 把 encoder 组织成 **7 个 stack**，帧率沿深度先降后升：

```
                        T (输入帧, 10ms)
   ┌────────────────────────────────────────────────────┐
   │ Stack 0  (1x,  T 帧)     ── 2 层, 帧率最高, 层最"薄"│
   │ Stack 1  (2x,  T/2)     ↓ 下采样                    │
   │ Stack 2  (4x,  T/4)     ↓ 下采样                    │
   │ Stack 3  (8x,  T/8)     ── 低帧率区, 层数最多        │
   │ Stack 4  (4x,  T/4)     ↑ 上采样 + 加法融合          │
   │ Stack 5  (2x,  T/2)     ↑ 上采样                    │
   │ Stack 6  (1x,  T 帧)                               │
   └────────────────────────────────────────────────────┘
```

* 下采样用带学习因子的 strided convolution（SimpleDownsample），上采样用转置卷积/插值（SimpleUpsample），且上采样结果与跳连的对应下采样层输出**相加**，形成 encoder 级别的 U-Net 式结构。
* **收益**：约一半的层工作在 $T/4 \sim T/8$ 帧率上，注意力与卷积的计算量近似按帧率平方（注意力）或线性（卷积）下降；同时低帧率层拥有更大的有效感受野，等效于「先粗后细」的多尺度建模。
* 各 stack 的宽度（embedding 维度）也可不同，形成「沙漏型」的参数分布。icefall 典型 medium 配置（7 stack，共 24 层）下：

| stack | 下采样率 | 层数 | 模块排布 |
| --- | --- | --- | --- |
| 0 | 1x | 2 | attn + conv |
| 1 | 2x | 2 | conv + attn |
| 2 | 4x | 2 | attn + conv |
| 3 | 8x | 2 | conv + attn |
| 4 | 4x | 2 | attn + conv |
| 5 | 2x | 2 | conv + attn |
| 6 | 1x | 2 | attn + conv |

（更大的 large/XL 配置会把中层加厚到 3~4 层，低帧率区参数占比更高。）

**下采样/上采样模块**：

* `SimpleDownsample`：strided 卷积（stride=r）+ 可学习缩放，把帧率从 $T/r_1$ 降到 $T/r_2$；
* `SimpleUpsample`：近邻/转置卷积上采样 + 线性变换，恢复帧率；
* 每个 stack 的输入 = 上采样的深层输出 **+ 同帧率浅层跳连**（对应 U-Net 的 skip connection），保证细节信息不因下采样丢失。

### 2.2 紧凑相对位置编码与 Attention Pooling

两个与 Conformer 不同的细节：

1. **Compact RelPos**：注意力内的相对位置编码只区分「$-128 \sim +127$」的相对距离（更远的截断共享边缘 bin），用一个 $(2B-1) \times d$ 的可学习表查表相加；比 Conformer 的全长度相对位置嵌入更省参数，且对长序列泛化更好。
2. **Attention Pooling**：每个 stack 末尾接一个由 BiasEncoder 偏置辅助的池化模块（把高层帧率信息汇总回低帧率表征），替代简单的 mean pooling，其 score 同样受 BiasEncoder 的激活/位置偏置调制。

### 2.3 Zipformer Block

每个 stack 内的 block 交替使用两种模块（attention 与 ConvNeXt），与 Conformer block 的串行 macro 结构不同，Zipformer 把 **self-attention 模块和 ConvNeXt（卷积）模块作为并列的子模块交替堆叠**：

```
        x
        │
   ┌────▼──────────────────────────────────────┐
   │  x = x + SelfAttn( Whiten(x) + attn_bias )│   ← 带 BiasEncoder 偏置
   │  x = x + ConvNeXt(x)                       │   ← depthwise conv + GLU
   │  (skip 分支附非线性投影 + ScaledResidual)    │
   └────────────────────────────────────────────┘
```

* **Self-Attention 模块**：输入先 Whiten，加上 BiasEncoder 输出的偏置（attention bias），再进简化版自注意力（无 QK 归一化的紧凑实现），输出经 BiasNorm + 缩放。
* **ConvNeXt 模块**：`LN -> PW(升维 2x) -> GLU? -> DWConv(k=7) -> SwooshL -> PW(降维)`，思想来自 ConvNeXt，但用 depthwise conv 替代大 kernel。
* **复数域处理**：模块内的线性层把特征视为复数——通道对半拆成实部 $a$ 与虚部 $b$，线性变换为 $y_{re} = W_{re} a - W_{im} b$，$y_{im} = W_{re} b + W_{im} a$，相当于学习幅度-相位联合表征，与语音频谱的复数本质对齐。

### 2.4 BiasEncoder（Belief-Encoder）

为流式 chunk 训练设计的偏置编码器，输入三路 embedding：

```
 激活 embedding(每帧是否激活)  ┐
 位置 embedding(chunk 内相对位置)┼─► Conv(k=128? 简化) ─► Swish ─► Linear ─► bias
 说话人 embedding(如有)        ─┘
```

* **激活信息**：标记当前帧属于哪个 chunk（以激活帧为锚点），等价于告诉模型「当前 chunk 的时间起点」，缓解 chunk 训练中位置信息的缺失；
* **位置信息**：chunk 内相对位置 embedding（128 维可学习表）；
* 输出 bias 以加法形式注入自注意力的 score，以及 pooling 模块（相当于把绝对位置信息「外挂」进来，使网络主体可以用无位置的紧凑注意力）。

### 2.5 Swoosh-R 激活函数

$$\text{Swoosh-R}(x) = \log\big(1 + e^{\,x-1}\big) + 0.08\,x - 0.313261687$$

* 形态上是**右移 + 下压的 softplus**：比 ReLU 更平滑、有小的负输出区，均值接近 0；
* 动机：Swoosh 系（SwooshR / SwooshL）让激活输出天然零均值化，从而允许网络**去掉大部分 BatchNorm/LayerNorm**（过度归一化会抹掉尺度信息，而尺度对区分「语音/静音、响度」有意义）；
* SwooshL（log 项移位 2、斜率系数略不同）用于 ConvNeXt 模块，SwooshR 用于 attention pooling / 简化模块。

### 2.6 normalize-and-project

Zipformer 的稳定性方案（替代 LayerNorm-everywhere）：

| 组件 | 作用 |
| --- | --- |
| **ActivationBalancer** | 约束激活的均值/方差范围（软约束），防止发散 |
| **Whiten** | 模块入口做白化（去均值 + 去相关），让 Swoosh 工作在合适输入分布 |
| **BiasNorm** | $\text{BiasNorm}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$，保留**全局尺度信息**（log-scale 偏置），不像 LayerNorm 把尺度完全抹掉 |
| **ScaledResidual / 非线性投影** | skip 分支乘可学习缩放并加非线性投影（normalize-and-project），缓解深层残差网络的梯度病态 |

一句话总结：**Conformer 用强归一化换取稳定，Zipformer 用「弱归一化 + 尺度保留 + 平衡器」换取更强的表达力与更快的收敛**。

### 2.7 与 Conformer Block 的逐项对照

| 维度 | Conformer Block | Zipformer Block |
| --- | --- | --- |
| 模块组织 | FFN-MHSA-Conv-FFN 串行 sandwich | attention / conv 模块交替，各自独立残差 |
| 归一化 | LayerNorm（模块内 + 块尾 Post-LN） | Whiten / BiasNorm / Balancer（保留尺度） |
| 激活 | Swish | SwooshR / SwooshL |
| 位置编码 | 相对位置嵌入（每层 attention 内） | Compact RelPos + BiasEncoder 偏置注入 |
| 帧率 | 全网络固定 $T/4$ | 多帧率（1x~8x）沙漏结构 |
| 线性层 | 实数域 | 部分**复数域**（实虚双通道联合变换） |
| skip 分支 | 简单相加 | ScaledResidual + 非线性投影 |

## 3. 目标函数

Zipformer 采用 **pruned RNN-T + 多尺度 averaged Transducer loss** 的目标：

### 3.1 pruned RNN-T 目标

标准 RNN-T 的联合分布：

$$P(Y \mid X) = \sum_{\pi \in \Omega(X,Y)} \prod_{t,u} P(\pi_{t,u} \mid h_t, p_u)$$

其中 $\Omega$ 是 $T \times U$ 全网格路径集合。pruned 版本将其限制到每帧附近的**稀疏格点**（见 4.1）。

### 3.2 Averaged Transducer loss（多尺度目标）

由于 Zipformer 输出多个帧率（1x/2x/4x/8x）的表征，训练时对每个尺度 $r \in \{1,2,4,8\}$ 分别接一个 Transducer head（encoder 输出按 $r$ 下采样、预测器共享），目标为各尺度损失平均：

$$\mathcal{L}_{\text{avg}} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}_{\text{pruned-RNNT}}^{(r)}$$

直觉：低帧率（8x）head 逼模型「粗粒度看全局、快速出字」，高帧率（1x）head 逼模型「细粒度对齐」，多尺度监督显著加速收敛并提升精度（消融约带来 0.1~0.2 WER 收益）。

## 4. 损失函数

### 4.1 pruned RNN-T loss 推导

直接算 RNN-T 需要物化 $(B, T, U, V)$ logits，显存爆炸。pruned RNN-T 分两步：

**Step 1：Simple loss（粗对齐）**。对每个（下采样后的）时间帧 $t$，只允许它对齐到「至多一个」token 位置 $u_t$，做逐帧多分类：

$$\mathcal{L}_{\text{simple}} = -\sum_t \log P\big(u = u_t \mid h_t\big)$$

本质是用一个轻量 head 学出近似单调对齐 $u_t \approx \text{round}\big(\frac{t \cdot U}{T}\big)$（编码器的单调性先验）。

**Step 2：根据 simple loss 的梯度做剪枝**。simple loss 反传后，每个帧 $t$ 会对若干 $u$ 位置产生梯度；据此为每帧挑选出最相关的 $u$ 邻域（宽度 $w$，如 $r \times 1.9$ 帧等价的 token 范围），把 RNN-T 的 $T \times U$ 网格剪成**带状稀疏网格**：

$$\Omega_{\text{pruned}} = \{(t,u) : |u - u_t| \le w\}$$

**Step 3：在稀疏网格上算标准 RNN-T 前向-后向**（log 域），最终损失：

$$\mathcal{L}_{\text{pruned-RNNT}} = -\ln \sum_{\pi \in \Omega_{\text{pruned}}} P(\pi) \approx \mathcal{L}_{\text{RNNT}}$$

* **显存收益**：logits 从 $(B,T,U,V)$ 降为 $(B,T',w,V)$（$T' = T/8$、$w \approx 30$），显存下降一个数量级，可以用大 batch + fp32 稳定训练；
* 实现：k2 的 `mutual_information_recursion` + `get_rnnt_prune_ranges` / `prune_and_set_grad`，简单 head 与主 head 联合训练（simple loss 权重通常很小或随训练退火）。

### 4.2 PyTorch 实现要点

```python
# icefall 风格的 pruned RNN-T 训练伪代码
encoder_out, encoder_out_lens = zipformer(features, feature_lens)   # [B, T', D], T'≈T/8

# 1) simple loss: 每帧预测对齐 token 位置
simple_logits = simple_proj(encoder_out)               # [B, T', U_amax+1]
simple_loss = ce(simple_logits, token_ids_padded)

# 2) 依据 simple 梯度挑选每帧保留的 u 范围
ranges = get_rnnt_prune_ranges(simple_logits, ...)     # [B, T', W]

# 3) 在稀疏格点上物化 logits 并算 rnnt loss
pruned_logits = joint(enc_out_gather, pred_out_gather) # [B, T', W, V+1]
pruned_loss = rnnt_loss(pruned_logits, ...)

loss = 0.5 * pruned_loss + 0.5 * simple_loss + (可选) lm_loss
```

### 4.3 与 Conformer 效率/精度对比

| 维度 | Conformer-M (~30M) | Zipformer-M (~69M) |
| --- | --- | --- |
| 训练显存（同等 batch） | 1x | **约 1/2 ~ 1/3**（pruned loss + 下采样） |
| 训练/推理速度 | 1x | **约 2x+ 提速**（RTF 显著降低） |
| LibriSpeech test-clean WER (pruned RNN-T) | ~2.6 | **~2.3** |
| LibriSpeech test-other WER | ~5.9 | **~4.9** |

* icefall 官方结果：Zipformer-M（69M，averaged loss）在 LibriSpeech 上 test-clean $\approx$ **2.28 / 4.84**（无外部 LM，pruned transducer stateless7 配置）；较小版本 Zipformer-S（~23M）约 **2.7 / 5.9**；
* 同等精度下 Zipformer 训练时间约为 Conformer 的一半；同等参数量下 WER 更低、尤其 test-other 提升明显；
* 流式版本（chunk-based，左 context 1200 帧 + 右 5 帧 etc.）相比离线版 WER 退化控制在 0.3~0.5 以内。

### 4.4 流式部署要点

* **模拟流式训练**：注意力带有限左上下文的因果 mask，模拟推理时的 chunk 输入；
* **仿真模拟（simulated streaming）**：非流式训练 + 流式解码（借助 attention 的左 context 设计），免去 chunk 训练，部署成本最低；
* **下采样与延迟**：8x stack 的感受野巨大但输出帧率低，端到端延迟主要由 1x/2x 外层 stack 的有限上下文决定，可在精度-延迟曲线上灵活取点；
* **onnx/tensorrt 导出**：Whiten/BiasNorm/Swoosh 均为基本算子组合，导出比带 BatchNorm 的 Conformer Conv Module 更友好。

### 4.5 训练配置与消融要点

* **优化器**：Eden 调度器 + AdamW（Povey 课题组为弱归一化网络设计的组合），batch 内按音频时长动态调整学习率尺度；
* **数据增广**：SpecAugment + Speed Perturb（0.9/1.0/1.1）；
* **关键消融**（论文/icefall 实验量级）：
  * 去掉 averaged transducer loss（只保留 8x 单尺度）：test-clean WER 上升约 0.1~0.3；
  * 去掉 BiasEncoder：流式（chunk）训练下退化明显，非流式影响较小；
  * Swoosh 换回 ReLU + 常规 LayerNorm：训练更难收敛，同等 epoch WER 略差，说明显存/稳定性收益是「组合拳」的结果；
  * 下采样 stack 换成全 1x：显存与速度回到 Conformer 量级，凸显「计算搬到低帧率区」是效率的主要来源。

---

## 5. 总结

* **架构记忆点**：U 型下采样 stack（1x→8x→1x）+ 交替的 self-attn / ConvNeXt 模块 + 复数域线性层 + BiasEncoder 偏置注入；
* **稳定性哲学**：Swoosh 激活 + Whiten/BiasNorm/Balancer + 非线性 skip 投影，弱归一化但保留尺度信息；
* **损失创新**：simple loss 做粗对齐 -> 梯度剪枝 -> 稀疏网格 RNN-T（pruned RNN-T），配合多尺度 averaged transducer loss；
* **一句话定位**：Conformer 解决「卷积+注意力怎么融合」，Zipformer 解决「怎么把这套混合架构训得更快、更省、更稳」，是目前 icefall/k2 生态流式与非流式 ASR 的事实标准骨干。
