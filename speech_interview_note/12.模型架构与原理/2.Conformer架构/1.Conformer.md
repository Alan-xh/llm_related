# 1. Conformer

## 1. 概述

**Conformer**（Convolution-augmented Transformer）是 Google Brain 在 2020 年提出的语音识别编码器架构，其核心论点是：

> 语音识别同时需要 **Transformer 的全局依赖建模能力**（学习长时上下文、类似语言模型的高层语义）与 **CNN 的局部模式捕获能力**（发音事件的局部平移不变性、音素细节），二者是**互补**的，单纯依靠任意一方都会损失精度。

在此之前，Transformer（全局但缺乏局部归纳偏置）与 CNN（如 QuartzNet、ContextNet，局部但感受野受限）在 ASR 上各有胜负。Conformer 的贡献在于提出了 **Conformer Block（macro block）**：把 MHSA 与 Conv Module 以「Macaron 式 FFN 夹心」的结构**串行融合**，在 LibriSpeech 上首次同时刷新了非流式与流式（Transducer）的 SOTA。

* **论文**：*Conformer: Convolution-augmented Transformer for Speech Recognition* (Gulati et al., Interspeech 2020)
* **地位**：后续几乎所有主流 ASR 编码器（Branchformer、Zipformer、E-Branchformer、Paraformer 系列变体）都以 Conformer 为直接基线进行改进。

## 2. 算法架构

### 2.1 整体结构

Conformer 整体沿袭「前端 subsampling + Transformer 编码器」范式：

```
  80-d Fbank
      │
      ▼
┌──────────────────────┐
│ Conv Subsampling     │   2 层 stride=2 卷积，时间降采样 4 倍 (T/4)
│ + Linear Projection  │
└──────────────────────┘
      │
      ▼
┌──────────────────────┐
│ Dropout / Positional │   绝对正弦位置编码（仅输入处）
└──────────────────────┘
      │
      ▼
┌──────────────────────┐
│ Conformer Block × N  │   N = 16 (S/M) ~ 17 (L)
└──────────────────────┘
      │
      ├──> CTC Head / Transducer Encoder / AED Encoder
```

* **Subsampling**：卷积下采样 4 倍（时间分辨率 40ms/帧），大幅降低序列长度，是后续所有架构的标准配置。
* **参数配置量级**（论文三档）：

| 型号 | d_model | encoder 层数 | head 数 | conv kernel | 参数量 |
| --- | --- | --- | --- | --- | --- |
| Conformer-S | 144 | 16 | 4 | 31 | ~10.3M |
| Conformer-M | 256 | 16 | 4 | 31 | ~30.7M |
| Conformer-L | 512 | 17 | 8 | 32 | ~118.8M |

### 2.2 Conformer Block（macro block）详解

单个 Conformer Block 的串行数据流为：

```
        x_i
        │
   ┌────▼─────────────────────────────────────────┐
   │  x = x + 1/2 * FFN_1(x)        ← Macaron FFN（前半）│
   │  x = x + MHSA(x)               ← 相对位置自注意力  │
   │  x = x + ConvModule(x)         ← 卷积模块         │
   │  x = x + 1/2 * FFN_2(x)        ← Macaron FFN（后半）│
   │  x = LayerNorm(x)              ← Post-LN        │
   └───────────────────────────────────────────────┘
        │
        x_{i+1}
```

写成公式：

$$x_i' = x_i + \frac{1}{2}\text{FFN}(x_i)$$
$$x_i'' = x_i' + \text{MHSA}(x_i')$$
$$x_i''' = x_i'' + \text{ConvModule}(x_i'')$$
$$x_i'''' = x_i''' + \frac{1}{2}\text{FFN}(x_i''')$$
$$x_{i+1} = \text{LayerNorm}(x_i'''')$$

两个关键设计选择：

* **乘性（Multiplicative）而非加性（Additive）融合**：Macaron-Net 的消融实验表明，两个 FFN 各乘 0.5 系数、把 MHSA/Conv「夹」在中间的 sandwich 结构，优于把 Conv 与 MHSA 并列相加的方案。
* **Post-LN**：LayerNorm 放在残差链末端（macaron 结构能稳定 Post-LN 训练），这一点与标准 Transformer 的 Pre-LN 惯例不同，面试中常被追问。

### 2.3 Multi-Head Self-Attention 与相对位置编码

语音信号对**相对位置**（说话快慢导致绝对位置漂移）远比绝对位置敏感，Conformer 采用 Transformer-XL 式相对位置编码。对 query $q_i$ 与 key $k_j$，注意力 logit 分解为四项：

$$\text{logit}_{ij} = \underbrace{q_i^T k_j}_{内容-内容} + \underbrace{q_i^T p_{j-i}^{K}}_{内容-位置} + \underbrace{u^T k_j}_{全局内容偏置} + \underbrace{v^T p_{j-i}^{K}}_{全局位置偏置}$$

其中：

* $p^{K}$ 为可学习的相对位置嵌入表，按相对距离 $j - i$ 查表；
* $u, v$ 为可学习的全局偏置向量（每个 head 独立）；
* 工程上通过**相对距离矩阵 + gather/embedding 查表**实现，$O(T^2)$ 的查表代价与注意力本身同阶，不增加复杂度量级。

相对位置编码是 Conformer 流式化（如 Conformer-Transducer、chunk-based 训练）的基础：chunk 内相对距离分布不变，模型对 chunk 边界的泛化更好。

### 2.4 Macaron FFN

FFN 本体与标准 Transformer 相同（两层线性 + 激活），但整体乘 0.5 后进入残差：

$$\text{FFN}(x) = \text{Dropout}\Big(\text{Linear}_2\big(\text{Swish}(\text{Linear}_1(x))\big)\Big)$$

* 隐层维度为 $4 d_{model}$（与 Transformer 一致）；
* 激活用 **Swish**（$\text{Swish}(x) = x \cdot \sigma(x)$），对深层网络优于 ReLU；
* 乘 $1/2$ 的直觉：两个 FFN 的贡献各减半，避免残差分支幅值累积过大导致 Post-LN 训练不稳定；消融实验中去掉 Macaron 式拆分会带来约 0.3~0.5 个点的 WER 损失。

### 2.5 Conv Module

卷积模块是 Conformer 区别于 Transformer 的核心部件，结构为：

```
x ─► LayerNorm ─► Pointwise Conv (d→2d) ─► GLU (2d→d) ─► Depthwise Conv (k=32)
  ─► BatchNorm ─► Swish ─► Pointwise Conv (d→d) ─► Dropout ─► (+) 残差
```

$$\text{ConvModule}(x) = \text{PWConv}_2 \big( \text{Swish}( \text{BN}( \text{DWConv}( \text{GLU}( \text{PWConv}_1(\text{LN}(x))))))\big)$$

各组件职责：

| 组件 | 作用 |
| --- | --- |
| **Pointwise Conv (1×1)** | 升维至 $2d$，为 GLU 门控提供通道 |
| **GLU** | $\text{GLU}(a, b) = a \otimes \sigma(b)$，将 $2d$ 投回 $d$，引入通道级门控 |
| **Depthwise Conv** | 每通道独立卷积，kernel=32（约覆盖 1.28s @ 4x subsampling），参数量 $O(k \cdot d)$ 而非 $O(k \cdot d^2)$，负责局部时序模式 |
| **BatchNorm** | 沿通道归一化，稳定卷积输出分布 |
| **Pointwise Conv + Swish** | 逐点非线性变换回原维度 |

注意卷积使用 **causal padding 或对称 padding** 的选择：原始论文非流式用对称 padding，流式版本改为因果卷积 + 左侧 context。

### 2.6 为什么 CNN + Attention 融合有效

面试高频问题，标准回答分三点：

1. **感受野互补**：MHSA 一层即可获得全局感受野，但分辨率是均匀的（对无信息的远距离帧也分配注意力）；CNN 感受野受限但局部分辨率高、参数共享带来的平移不变性天然契合发音事件（音素在时间轴上小幅平移语义不变）。
2. **归纳偏置互补**：Transformer 缺乏局部归纳偏置，在中等数据量（百~千小时）下容易欠拟合局部声学细节；CNN 补上这一偏置后，小数据场景也能收敛到较好水平。
3. **串行 vs 并行的取舍**：Conformer 把 Conv 放在 MHSA 之后（串行、加性融合在残差层面），让注意力先做全局上下文对齐，卷积再对对齐后的表征做局部特征增强。Branchformer 的后续研究指出串行不是唯一解（并行双分支更好流式化），但精度上串行 Conformer 仍是最强基线之一。

## 3. 目标函数

Conformer 本身是**纯编码器**，不含解码结构，因此其训练目标取决于下游头（head）的选择。论文系统评测了三种搭配：

### 3.1 CTC 搭配（Conformer-CTC）

$$P(Y \mid X) = \sum_{\pi \in \mathcal{B}^{-1}(Y)} \prod_t P(\pi_t \mid h_t)$$

* CTC head：Linear($d_{model} \to V+1$)，逐帧 softmax。
* 特点：训练稳定、推理极快，但帧间条件独立，语言建模能力弱，通常需要外部 LM（如 4-gram + LM Rescoring）才能追平 Transducer。

### 3.2 Transducer 搭配（Conformer-Transducer）

编码器输出接入 RNN-T 的 Joint Network，预测器用 1 层 LSTM（1024 维）：

$$P(y_{t,u} \mid x_{1:t}, y_{1:u-1}) = \text{Softmax}\big(\text{Joint}(h_t, p_u)\big)$$

* 特点：内置语言模型能力、天然流式，是工业界部署最多的形态（流式时 MHSA 换成 chunk-based attention、卷积改因果）。

### 3.3 AED 搭配（Conformer-AED）

编码器 + Transformer Decoder（交叉注意力自回归解码），损失为标准交叉熵：

$$\mathcal{L} = -\sum_u \log P(y_u \mid y_{<u}, h_{1:T})$$

* 特点：非流式场景精度上限最高（配合语言模型），但解码延迟大。

## 4. 损失函数

### 4.1 各搭配的损失公式

**CTC 损失**（前向-后向求解）：

$$\mathcal{L}_{\text{CTC}} = -\ln \sum_{\pi \in \mathcal{B}^{-1}(Y)} \prod_t \frac{P(\pi_t \mid h_t)}{u_t \cdot v_t \cdot m_t} \cdot u_t \cdot v_t \cdot m_t$$

（工程实现用 log 域的前向变量 $\ln \alpha$ 累加，避免数值下溢。）

**RNN-T 损失**（$T \times U$ 网格上的前向-后向）：

$$\mathcal{L}_{\text{RNNT}} = -\ln \sum_{\pi} \prod_{t,u} P(\pi_{t,u} \mid h_t, p_u)$$

**AED 损失**：label-smoothed cross entropy（smoothing $\epsilon = 0.1$）：

$$\mathcal{L}_{\text{AED}} = -\sum_u (1-\epsilon)\log P(y_u) - \frac{\epsilon}{V}\sum_{v}\log P(v)$$

### 4.2 Joint CTC-Transducer 训练

工业实践中最常用的多任务训练方式：同一编码器同时接 CTC head 和 Transducer head，损失加权：

$$\mathcal{L} = \lambda \cdot \mathcal{L}_{\text{CTC}} + (1 - \lambda) \cdot \mathcal{L}_{\text{RNNT}}, \quad \lambda \in [0.2, 0.5]$$

* **动机**：CTC 的单调对齐先验可以正则化编码器表征，加速收敛并缓解 Transducer 训练早期 alignment 漂移问题。
* **推理**：只用 Transducer 分支解码；CTC 分支可用于多任务（对齐、 timestamps）或两次解码（CTC beam + Transducer rescoring）。
* **变体**：也有 CTC + AED 联训（ESPnet 风格）及 CTC + AED + Transducer 三头联训的方案，加权思想相同。

### 4.3 PyTorch 实现要点

```python
import torch
import torch.nn as nn

class ConformerBlock(nn.Module):
    def __init__(self, d_model=256, n_heads=4, ffn_dim=1024, kernel_size=31, dropout=0.1):
        super().__init__()
        self.ffn1 = nn.Sequential(          # Macaron FFN: 各乘 0.5
            nn.LayerNorm(d_model),
            nn.Linear(d_model, ffn_dim), nn.SiLU(),
            nn.Dropout(dropout), nn.Linear(ffn_dim, d_model), nn.Dropout(dropout))
        self.mhsa = RelPosMultiHeadSelfAttention(d_model, n_heads)  # 相对位置编码
        self.conv = ConvModule(d_model, kernel_size, dropout)       # PW-GLU-DW-BN-Swish-PW
        self.ffn2 = nn.Sequential(
            nn.LayerNorm(d_model),
            nn.Linear(d_model, ffn_dim), nn.SiLU(),
            nn.Dropout(dropout), nn.Linear(ffn_dim, d_model), nn.Dropout(dropout))
        self.norm = nn.LayerNorm(d_model)   # Post-LN

    def forward(self, x, pos_emb):
        x = x + 0.5 * self.ffn1(x)
        x = x + self.mhsa(x, pos_emb)
        x = x + self.conv(x)
        x = x + 0.5 * self.ffn2(x)
        return self.norm(x)

# joint CTC-Transducer 训练循环（示意）
# loss = 0.3 * ctc_loss(ctc_logits, ...) + 0.7 * rnnt_loss(joint_logits, ...)
```

要点：

* FFN 系数 0.5 是 **乘在 FFN 输出上**，不是乘在残差上（等价但写法上注意与 $x + \text{FFN}(x)/2$ 区分清楚）；
* Conv Module 内首层 LN 与块尾 Post-LN 并存，实现时容易遗漏；
* 相对位置编码通常实现为 `nn.Embedding(2*T_max-1, d_model)` 加距离索引。

## 5. 实验效果（LibriSpeech WER）

| 模型 | 参数量 | 解码/LM | test-clean | test-other |
| --- | --- | --- | --- | --- |
| Transformer-L (基线) | 118M | AED + LM | 2.61 | 5.54 |
| Conformer-CTC-L | 118.8M | + 4-gram + LM | ~2.8 | ~6.5 |
| Conformer-Transducer-L | 118.8M | RNN-T beam | 2.62 | 5.87 |
| **Conformer-AED-L** | 118.8M | + 4-gram + LM | **2.1** | **4.3** |

* 相对同期 Transformer-L（test-clean 2.61），Conformer-AED-L 直接降到 2.1，其中 test-other 提升尤其明显（局部卷积对噪声/口音鲁棒）；
* 小模型收益更大：Conformer-S（10.3M）即可达到早期几十 M 参数 Transformer 的水平，端侧部署价值高；
* 训练配置：SpecAugment + Speed Perturb、AdamW + warmup 25k steps、学习率峰值 $5 \times 10^{-4}$（S/M）或 $2 \times 10^{-4}$（L）、40 epoch（L 用 200k steps 大规模增广训练）。

---

## 6. 总结

* **架构记忆点**：`FFN(half) → MHSA → Conv → FFN(half) → PostLN` 的 Macaron sandwich；相对位置 MHSA + depthwise conv（kernel≈32）是两大灵魂部件。
* **融合有效性**：全局依赖（Attention）与局部模式（CNN）互补，串行残差融合在精度上仍是强基线。
* **目标/损失**：编码器架构无关，CTC / Transducer / AED 三种头即插即用；工业界最常见 joint CTC-Transducer 多任务损失。
* **局限与演进**：Post-LN 难以做非常深的网络；串行结构流式化后 chunk 边界损失明显 → Branchformer（并行双分支解耦）、Zipformer（下采样 + 更稳的归一化）分别从架构与训练稳定性两条路线改进它。
