# 2. ResNet 与 CNN 前端

## 1. 概述

在语音领域，**CNN 扮演两个角色**：一是作为端到端模型（DeepSpeech、Conformer、Whisper）的**卷积前端（frontend）**负责降采样与低层特征提取；二是作为说话人验证/说话人日志任务的**独立骨干网络**，其中 **ResNet 系（ResNet-18/34/50 及 Res2Net）** 是与 ECAPA-TDNN 长期并立的另一大主流骨干。

* **VGG 前端**：DeepSpeech 2 / Conformer / Whisper 等模型在输入端堆叠 2~3 层 VGG 风格小卷积，把 80 维 Fbank 下采样 4 倍，使后续 Transformer/Attention 层的计算量降低约 16 倍。
* **ResNet 声纹骨干**：利用 2D 卷积同时沿时间和频率两个维度建模，配合残差连接可以堆到 34 层以上；在此结构上叠加 AAM-Softmax 训练，在 VoxCeleb 上长期保持 SOTA。
* **夹层 CNN（sandwich / timestep CNN）**：在流式 ASR 中用 stride 卷积对时间轴下采样，降低 Transducer/CTC 解码的计算量。

面试考察重点：残差连接为什么能解决退化（degradation）问题、感受野的递推计算、下采样卷积的时延代价。

## 2. 算法架构：CNN 在语音中的角色

### 2.1 VGG 前端：端到端模型的"降采样模块"

典型 Conformer / Whisper 风格前端（输入 `[B, T, 80]` Fbank）：

```
  Fbank [B, T, 80]
       │
  ┌────▼────────────┐  Conv2d(1->32, 3x3, stride=1)  + ReLU
  │  VGGBlock 1     │  时间/频率轴均不下采样
  └────┬────────────┘
       │
  ┌────▼────────────┐  Conv2d(32->64, 3x3, stride=(2,2)) + ReLU
  │  VGGBlock 2     │  时间减半, 频率减半
  └────┬────────────┘
       │
  ┌────▼────────────┐  Conv2d(64->64, 3x3, stride=(2,1)) + ReLU   (部分模型有第3层)
  │  VGGBlock 3     │  仅时间减半, 频率保持
  └────┬────────────┘
       │
  reshape: [B, T/4, 64*F/4] -> Linear -> 后续 Encoder
```

下采样的直接收益：Conformer 编码器的 self-attention 复杂度为 $O(T^2 d)$。一条 10 秒音频（T=1000 帧）下采样 4 倍后 T=250，注意力计算量降为原来的 1/16，同时等效帧移从 10 ms 增大到 40 ms，对多数音素（80~200 ms）仍然足够。

### 2.2 ResNet 声纹骨干

ResNet-34 声纹版（输入 `[B, 1, T, 80]`，把 Fbank 当作单通道"图像"）：

```
  Fbank [B, 1, T, 80]
       │
  ┌────▼───────────────┐  Conv2d(1->32, 3x3, stride=1)
  │  stem               │
  └────┬───────────────┘
       │
  ┌────▼───────────────┐ ×3   BasicBlock(32)     时间/频率 stride=1
  │  stage 1            │
  └────┬───────────────┘
  ┌────▼───────────────┐ ×4   BasicBlock(64)     首块 stride=(2,2)
  │  stage 2            │      -> T/2, F/2
  ┌────▼───────────────┐ ×6   BasicBlock(128)    首块 stride=(2,2)
  │  stage 3            │      -> T/4, F/4
  ┌────▼───────────────┐ ×3   BasicBlock(256)    首块 stride=(2,2)
  │  stage 4            │      -> T/8, F/8
  └────┬───────────────┘
  ┌────▼───────────────┐  Attentive Statistics Pooling (复用 ECAPA 的 ASP)
  │  池化               │
  └────┬───────────────┘
  ┌────▼───────────────┐  BN->FC->BN->embedding
  │  嵌入层             │  128~256 维
  └────────────────────┘
```

ResNet 与 TDNN 的本质区别：**TDNN 只沿时间轴卷积，每层输入是 1D 序列；ResNet 沿 (时间 × 频率) 2D 卷积**，频率轴卷积能捕捉跨 Mel 滤波器组的共振峰结构，这是 1D 模型需要靠多层堆叠才能间接获得的。Res2Net / ResNetSE 变体在声纹任务上进一步引入多尺度与 SE 模块。

### 2.3 夹层 CNN（Sandwich CNN）与下采样用法

在流式 Transducer/CTC 中，常把卷积下采样"夹"在编码器层之间，而不只放在最前端：

* **只放前端的问题**：连续两层 stride 卷积叠加，一次性看 20~30 帧才输出 1 帧，首帧响应延迟大；且前端感受野过大反而损害浅层声学建模。
* **Sandwich 结构**（如 `Conv -> Conformer x N -> Conv -> Conformer x N -> ...`）：把下采样均匀分摊到网络各处。每处只下采样 2 倍，既得到总 8 倍降帧，又保证每一级卷积的上下文窗口很小（典型 3~5 帧，因果设计时仅看左上下文），流式延迟可控。
* **因果化要点**：流式卷积必须**只在时间轴左侧 pad**（kernel 第一维 padding=(k-1, 0)），或直接把窗口对齐到右侧，否则引入右看时长，破坏流式承诺。

```python
import torch
import torch.nn as nn

class CausalConv2dSubsampling(nn.Module):
    """流式场景: 只看左上下文的 2 倍时间下采样卷积 (sandwich CNN 基本单元)"""
    def __init__(self, in_ch: int, out_ch: int):
        super().__init__()
        self.conv = nn.Conv2d(in_ch, out_ch, kernel_size=(3, 3), stride=(2, 2))
        self.pad  = (2, 1)   # 时间轴 pad 2 (只向左), 频率轴对称 pad 1

    def forward(self, x):        # x: [B, C, T, F]
        x = nn.functional.pad(x, (self.pad[1], self.pad[1],  # 频率: 左右各1
                                  self.pad[0], 0))           # 时间: 只 pad 左侧 2
        return self.conv(x)      # [B, out_ch, T/2, F/2]
```

## 3. 残差连接推导：为什么解决退化问题

### 3.1 退化问题（Degradation）

He et al. (2015) 的实验现象：56 层普通 CNN 在 CIFAR 上的训练误差**反而高于** 20 层版本。这不是过拟合（训练误差也变高），而是深层网络难以学到恒等映射——网络加深后优化变难，称为**退化**。

### 3.2 残差学习的重构

设期望映射为 $\mathcal{H}(x)$。ResNet 不让堆叠层直接拟合 $\mathcal{H}(x)$，而是拟合**残差** $\mathcal{F}(x) = \mathcal{H}(x) - x$，原始映射变为：

$$\mathcal{H}(x) = \mathcal{F}(x) + x$$

前向通过**捷径连接（shortcut / skip connection）** 实现，恒等捷径不增加任何参数与计算量。

### 3.3 梯度视角的推导

对输出求关于输入的梯度（链式法则）：

$$\frac{\partial \mathcal{H}(x)}{\partial x} = \frac{\partial \mathcal{F}(x)}{\partial x} + 1$$

关键在 **"+1"**：普通 CNN 的梯度是连乘 $\prod_i W_i$，一旦多数因子小于 1 则梯度指数级衰减（梯度消失），大于 1 则指数级爆炸；而残差结构的梯度由两条路汇合——残差支路 $\partial\mathcal{F}/\partial x$ 可以衰减到很小，但恒等支路的 **1 保证梯度至少原样回传一层**。跨 $L$ 层时：

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L}\left( 1 + \frac{\partial}{\partial x_l}\sum_{i=l}^{L-1}\mathcal{F}(x_i) \right)$$

梯度不会消失，任意深度的层都能得到有效更新信号，退化问题因此缓解。此外，最差情况下网络只需学会 $\mathcal{F}(x) \to 0$ 即退化为恒等映射，"加深"永远不会比"不加"更差。

### 3.4 BN 与残差的配合

每个卷积层后接 BatchNorm（`Conv-BN-ReLU`），BN 把每层输入拉回均值 0 方差 1 的分布，缓解内部协变量偏移（internal covariate shift），同时让残差支路输出量级与捷径支路可比。实验上**去掉 BN 的残差网络训练会明显不稳定**，BN 与 skip 连接是残差网络成功的双支柱。

## 4. 感受野计算公式

对一维时间轴，设第 $l$ 层卷积核宽 $k_l$、步长 $s_l$、空洞率 $d_l$（等效核宽 $k_l' = d_l(k_l - 1) + 1$）。**第 $l$ 层输出相对原始输入的感受野**递推：

$$R_l = R_{l-1} + (k_l' - 1) \cdot J_{l-1}$$

其中**跳连累积步长（jump）**：

$$J_l = J_{l-1} \cdot s_l, \qquad R_0 = 1, \ J_0 = 1$$

**举例**：三层卷积，均为 $k=3, s=1$：

| 层 | $k'$ | $J_{l-1}$ | 感受野 $R_l$ |
| --- | --- | --- | --- |
| conv1 | 3 | 1 | 1 + 2×1 = 3 |
| conv2 | 3 | 1 | 3 + 2×1 = 5 |
| conv3 | 3 | 1 | 5 + 2×1 = 7 |

若 conv1 改为 $s=2$：conv2 处 $J_1 = 2$，则 $R_2 = 3 + 2\times2 = 7$，$R_3 = 7 + 2\times2 = 11$——**下采样层之后的卷积对感受野有放大效应**，这正是 sandwich CNN 中深层卷积即使 kernel 很小也能覆盖长时上下文的原因。声纹 ResNet 末层感受野通常达到 2~3 秒。

## 5. 目标函数与损失函数

### 5.1 ASR 分类场景：交叉熵（CE）

CNN 前端服务于编码器，目标函数与所接模型一致：

* **CTC / Transducer**：$\mathcal{L}_{\text{CTC/RNNT}}$ 按对齐求和的负对数似然（前端只影响 encoder 表征）。
* **AED / Whisper**：注意力量化的自回归 CE。

### 5.2 声纹场景：CE 与 AAM-Softmax 复用

ResNet 声纹骨干的目标函数与损失函数与 TDNN 系完全同构，可直接复用 `12.模型架构与原理/3.TDNN与CNN架构/1.TDNN与ECAPA-TDNN.md` 第 5 节的推导与实现：

$$\mathcal{L}_{\text{CE}} = -\log \frac{\exp(w_y^\top x)}{\sum_j \exp(w_j^\top x)} \quad \longrightarrow \quad \mathcal{L}_{\text{AAM}} = -\log \frac{\exp(s(\cos\theta_y - m))}{\exp(s(\cos\theta_y - m)) + \sum_{j\neq y}\exp(s\cos\theta_j)}$$

即：闭合集训练用 CE 作为 baseline（欠拟合诊断用），正式训练换 AAM-Softmax（$s=32, m=0.2$ 起步），可选叠加 batch-hard triplet（权重 0.01~0.05）。唯一工程差异是 ResNet 的 embedding 维度常取 128/256（低于 ECAPA 的 192/512），分类头参数相应更少。

### 5.3 多任务变体

说话人 + 语音识别联合（如 ASR 声学模型加说话人分类辅助损失）：

$$\mathcal{J} = \mathcal{L}_{\text{ASR}} + \lambda \mathcal{L}_{\text{spk-CE}}, \quad \lambda \approx 0.1 \sim 0.3$$

辅助 CE 促使前端 CNN 提取更纯净的音色相关表征，常用于说话人自适应 ASR。

## 6. ResNet 前端 PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class BasicBlock(nn.Module):
    """声纹 ResNet 的 2 层 BasicBlock (含投影捷径)"""
    expansion = 1
    def __init__(self, in_ch: int, out_ch: int, stride=(1, 1)):
        super().__init__()
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3, stride=stride, padding=1, bias=False)
        self.bn1   = nn.BatchNorm2d(out_ch)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3, stride=1, padding=1, bias=False)
        self.bn2   = nn.BatchNorm2d(out_ch)
        self.relu  = nn.ReLU(inplace=True)
        # 维度不一致时用 1x1 卷积投影捷径
        self.shortcut = nn.Sequential()
        if in_ch != out_ch or stride != (1, 1):
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_ch, out_ch, 1, stride=stride, bias=False),
                nn.BatchNorm2d(out_ch),
            )

    def forward(self, x):
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out = out + self.shortcut(x)      # 残差: 恒等/投影捷径
        return self.relu(out)


class ResNetSpeaker(nn.Module):
    """ResNet-18 声纹骨干: Fbank -> 4 stage -> ASP 池化 -> embedding"""
    def __init__(self, embed_dim: int = 256):
        super().__init__()
        self.stem = nn.Sequential(
            nn.Conv2d(1, 32, 3, stride=1, padding=1, bias=False),
            nn.BatchNorm2d(32), nn.ReLU(inplace=True),
        )
        cfgs = [(32, 2, (1, 1)), (64, 2, (2, 2)), (128, 2, (2, 2)), (256, 2, (2, 2))]
        layers, in_ch = [], 32
        for out_ch, n, stride in cfgs:
            layers.append(self._make_layer(in_ch, out_ch, n, stride))
            in_ch = out_ch
        self.layers = nn.Sequential(*layers)
        self.asp_score = nn.Conv2d(256, 1, 1)          # 简化版 ASP: 帧级注意力打分
        self.fc = nn.Linear(256 * 2, embed_dim)        # mean||std -> embedding

    @staticmethod
    def _make_layer(in_ch, out_ch, n, stride):
        return nn.Sequential(BasicBlock(in_ch, out_ch, stride),
                             *[BasicBlock(out_ch, out_ch) for _ in range(n - 1)])

    def forward(self, x):                 # x: [B, T, F] Fbank
        x = x.unsqueeze(1)                # [B, 1, T, F]
        x = self.stem(x)                  # [B, 32, T, F]
        x = self.layers(x)                # [B, 256, T/8, F/8]
        score = self.asp_score(x)         # [B, 1, T/8, F/8]
        w = F.softmax(score.flatten(2), dim=-1).unsqueeze(1)      # [B,1,T',1] 时间维注意力
        feat = x.mean(dim=3)              # 频率维先均值 -> [B, 256, T']
        mu   = (feat * w.squeeze(1)).sum(-1)                       # 加权均值
        sg   = (feat ** 2 * w.squeeze(1)).sum(-1) - mu ** 2        # 加权方差
        return self.fc(torch.cat([mu, sg.sqrt()], dim=-1))          # [B, embed_dim]


if __name__ == "__main__":
    model = ResNetSpeaker(256)
    x = torch.randn(4, 800, 80)           # 4 条 8 秒音频
    emb = model(x)
    print(f"embedding: {emb.shape}")      # [4, 256]
    # 后接 AAMSoftmax(embed_dim=256, num_classes=5994, s=32, m=0.2) 训练
```

## 7. TDNN / ResNet / Transformer 骨干对比

| 维度 | TDNN / ECAPA-TDNN | ResNet (声纹) | Transformer / Conformer |
| --- | --- | --- | --- |
| **卷积维度** | 1D（仅时间轴） | 2D（时间 × 频率） | 无卷积/局部卷积 + 全局注意力 |
| **感受野扩张** | dilated context 逐层扩张 | 下采样 + 深层堆叠（指数级） | 单层即全局 |
| **计算复杂度** | $O(T \cdot k \cdot C^2)$ 线性 | $O(T \cdot F \cdot k^2 \cdot C^2)$ 线性 | $O(T^2 \cdot C)$ 二次 |
| **长程依赖** | 需很深才能覆盖秒级 | 感受野 2~3 秒（末层） | 天然全局 |
| **参数量级** | ECAPA ~20 M | ResNet-34 ~6.5 M | 数十至数百 M |
| **量化/部署** | 一般 | **友好**（规则结构、INT8 损失小） | 需专门优化 |
| **流式适配** | 天然因果（左上下文） | 需因果 padding | 需 chunk/limited attention 改造 |
| **典型任务** | 声纹、说话人日志 | 声纹、说话人日志 | ASR、多任务语音大模型 |

选型经验：端侧低算力/低延迟选 ResNet；追求极致精度且算力充足选 Conformer/Transformer；TDNN 系介于两者之间，工程遗产（x-vector 流水线、ASP 池化）被两大阵营共同吸收。

## 8. 总结

* **CNN 两大角色**：① VGG 前端为 attention 模型降采样（4 倍降帧 → 计算量降约 16 倍）；② ResNet 作为声纹骨干，2D 卷积同时建模时频结构。
* **残差连接**：拟合 $\mathcal{F}(x) = \mathcal{H}(x) - x$，梯度中恒等项 "+1" 保证深层的有效更新信号，配合 BN 支撑 34+ 层训练，解决退化而非过拟合。
* **感受野递推**：$R_l = R_{l-1} + (k_l' - 1) J_{l-1}$、$J_l = J_{l-1} s_l$——下采样层对后续卷积的感受野有放大效应，是 sandwich CNN 高效降帧的数学基础。
* **Sandwich CNN**：下采样分摊到编码器各处而非集中在前端，每次只降 2 倍、窗口 3~5 帧，流式延迟可控；时间轴必须只向左 pad。
* **损失函数复用**：声纹任务上 ResNet 与 TDNN 共用同一套目标函数体系——CE 起步、AAM-Softmax 主训、triplet 辅助，embedding 维度与骨干无关。
