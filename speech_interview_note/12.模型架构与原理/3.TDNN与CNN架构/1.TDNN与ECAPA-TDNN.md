# 1. TDNN 与 ECAPA-TDNN

## 1. 概述

在说话人识别（Speaker Verification / Identification）领域，**TDNN（Time Delay Neural Network，时延神经网络）** 及其衍生的 **ECAPA-TDNN（Emphasized Channel Attention, Propagation and Aggregation TDNN）** 是深度学习时代的标杆骨干架构。

* **TDNN（1989 年 Waibel 提出，2015 年 Snyder 等复兴）**：通过**延时上下文卷积（dilated context）** 在语音帧周围捕捉跨时间的音素级上下文，是替代 GMM-UBM 的第一代深度说话人嵌入提取器。
* **x-vector（2018, Snyder et al.）**：在 TDNN 之上引入**统计池化（Statistics Pooling）**，将变长帧级特征聚合成定长句子级嵌入，成为工业界声纹 embedding 的事实标准（512 维）。
* **ECAPA-TDNN（2020, Desplanques et al., Interspeech）**：在 x-vector 基础上引入 **SE-Res2Block 多尺度残差 + 通道注意力、Attentive Statistics Pooling、多层特征聚合** 三大改进，在 VoxCeleb 上将 EER 从 ~5% 拉低至 ~1%，长期霸榜说话人验证任务。

面试考察重点：TDNN 的 dilated context 为什么能扩大感受野、统计池化如何处理变长序列、AAM-Softmax 的 margin 几何意义与完整推导。

## 2. 算法架构：TDNN 延时上下文卷积原理

### 2.1 一维时序卷积与 dilated context

TDNN 本质上是一个**沿时间轴滑动的一维卷积网络**。与普通 CNN 不同，TDNN 的卷积核**不作用于相邻连续帧，而是作用于带空洞（dilated）的上下文帧**：

$$h_t^{(l)} = f\left( W^{(l)} \cdot [h_{t-\delta_{l,1}}^{(l-1)}, \dots, h_t^{(l-1)}, \dots, h_{t+\delta_{l,R}}^{(l-1)}] + b^{(l)} \right)$$

其中 $\delta_{l,i}$ 为第 $l$ 层第 $i$ 个卷积抽头的**时间偏移（dilation）**，$R$ 为上下文各取的帧数。

经典 x-vector TDNN 的 5 层 dilated context 配置（输入为 40 维 MFCC，帧移 10ms）：

| 层 | 上下文（相对偏移） | 等效 dilation | 输出维度 | 单层感受野 |
| --- | --- | --- | --- | --- |
| TDNN1 | {-2, 0, +2} | 2 | 512 | 5 帧（50 ms） |
| TDNN2 | {-2, 0, +2} | 2 | 512 | 9 帧（90 ms） |
| TDNN3 | {-3, 0, +3} | 3 | 512 | 15 帧（150 ms） |
| TDNN4 | {0} | 0（帧级） | 512 | 15 帧 |
| TDNN5 | {0} | 0（段级输入） | 1500 | — |

### 2.2 为什么 dilated context 有效

1. **扩大感受野而不增参数**：第 $l$ 层的感受野按 $R^{(l)} = R^{(l-1)} + \delta_l \cdot R^{(l-1)}_{\text{step}}$ 逐层指数级扩张，堆叠 3 层 dilation=2/2/3 即可覆盖约 150 ms，恰好对应一个音素级的时域跨度。
2. **参数共享 + 位移不变**：同一组卷积核在整条时间轴上共享，说话人音色特征不依赖绝对时间位置。
3. **与 Receptive Field 对齐任务粒度**：底层捕捉短时声道特征（如基频、共振峰微变），高层覆盖长时韵律、口音模式。

### 2.3 x-vector 结构与统计池化

x-vector 的完整流水线为：**TDNN 帧级编码 → 统计池化 → 段级 TDNN → 嵌入提取**：

```
  Fbank (T x 40)
       │
  ┌────▼─────┐  dilated 1D-conv x5
  │  TDNN 1-4│  帧级特征 h_t  (T x 512)
  └────┬─────┘
       │
  ┌────▼──────────────────┐
  │ Statistics Pooling     │   mean + std over T
  │  μ, σ  (2 x 512)      │   → 拼接为 1024 维段级向量
  └────┬──────────────────┘
       │
  ┌────▼─────┐
  │ TDNN 5-6 │  段级全连接 (1500 → 512)
  └────┬─────┘
       │
  ┌────▼─────┐
  │ x-vector │  512 维说话人嵌入
  └──────────┘
```

统计池化将变长输入压缩为定长表示：

$$\mu_d = \frac{1}{T}\sum_{t=1}^{T} h_{t,d}, \qquad \sigma_d = \sqrt{\frac{1}{T}\sum_{t=1}^{T} (h_{t,d} - \mu_d)^2 + \epsilon}$$

一阶矩 $\mu$ 捕捉平均说话人特质，二阶矩 $\sigma$ 编码时序动态性（语速、能量起伏），二者拼接后经段级 TDNN 映射为 **512 维 x-vector**。推理时提取倒数第二层输出作为 embedding，用 cosine 相似度或 PLDA 打分。

## 3. 算法架构：ECAPA-TDNN 三大改进

### 3.1 整体结构

```
  Fbank (T x 80)
       │
  ┌────▼────────┐
  │ Conv2D 前端  │  (3x3, 通道扩至 1024)  ← 替代 TDNN1
  └────┬────────┘
       │
  ┌────▼────────┐   ×3 个 SE-Res2Block (1024 通道)
  │ SE-Res2Block│──────────────┐ (跳跃输出 1024×3=3072)
  └────┬────────┘              │
       │  MFA 拼接 3072         │
  ┌────▼────────┐              │
  │ Conv1D 1x1  │  → 1536 维    │
  └────┬────────┘              │
  ┌────▼──────────────┐        │
  │ Attentive Stats   │        │
  │ Pooling (ASP)     │        │
  └────┬──────────────┘        │
       │  3072 维段级向量       │
  ┌────▼─────┐  AAM-Softmax 分类头（训练）
  │ FC 192/512│  embedding（推理）
  └──────────┘
```

### 3.2 改进一：SE-Res2Block（含 Res2Net 多尺度卷积）

每个 Block 的结构为 `1x1 Conv → Res2Net(3x3) → SE → 1x1 Conv` + 残差连接。

**Res2Net 多尺度卷积**：将通道分成 $s$ 组，第 $i$ 组的输入是第 $i-1$ 组经过 3x3 卷积后的输出累加，形成层级化的多尺度感受野（$s=4$ 为 ECAPA 默认，scale=8 为 Res2Net 原文设置）：

$$y_i = \begin{cases} K_{3\times3}^{(1)}(x_i) & i = 1 \\ K_{3\times3}^{(i)}(x_i + y_{i-1}) & 2 \le i \le s \end{cases}$$

等效感受野从单一 3x3 扩展为层级组合（组 4 的感受野约等于 3 个 3x3 级联），同时参数量保持不变，还隐式增强了跨通道信息交互。

**SE（Squeeze-Excitation）通道注意力**：

$$z_c = \text{ReLU}\left( W_2 \, \text{ReLU}(W_1 \cdot \mu_c) \right), \qquad \tilde{h}_{t,c} = \sigma(z_c) \cdot h_{t,c}$$

其中 $\mu_c$ 为全局均值池化（squeeze），$W_1 \in \mathbb{R}^{C/r \times C}$、$W_2 \in \mathbb{R}^{C \times C/r}$ 为瓶颈全连接（降维比 $r=16$），动态重标定各通道对当前说话人的贡献度——浊音段与清音段依赖的通道天然不同。

### 3.3 改进二：Attentive Statistics Pooling 公式推导

x-vector 的均值池化对所有帧一视同仁，但语音中存在静音、噪声帧等说话人信息稀疏的区域。ECAPA 引入自注意力加权：

**第一步，计算帧级注意力分数**（$\mathrm{tanh}$ 双线性打分）：

$$e_t = v^{\top} \tanh\left( W_h h_t + W_g g + b\right)$$

其中 $h_t$ 为当前帧特征，$g$ 为全局上下文（整段特征的均值池化），$v$ 为打分向量。

**第二步，softmax 归一化得到权重**：

$$\alpha_t = \frac{\exp(e_t)}{\sum_{\tau=1}^{T} \exp(e_{\tau})}$$

**第三步，加权统计替代朴素统计**：

$$\mu_d = \sum_{t=1}^{T} \alpha_t h_{t,d}, \qquad \sigma_d = \sqrt{\sum_{t=1}^{T} \alpha_t h_{t,d}^2 - \mu_d^2 + \epsilon}$$

注意二阶矩用的是 $\sum \alpha_t h^2 - \mu^2$（加权方差），且 $\sum \alpha_t h^2$ 中权重未归一化（$\sum \alpha_t = 1$ 已保证量级正确）。注意力机制使模型自动聚焦高信噪比、高说话人信息量的帧，长语音（VoxCeleb 平均 8 秒以上）收益尤为明显。

### 3.4 改进三：Multi-layer Feature Aggregation (MFA)

x-vector 只使用最后一个 TDNN 层，而不同层编码不同粒度的说话人信息。ECAPA 将 3 个 SE-Res2Block 的输出**沿通道拼接**（1024×3 = 3072 维）后再做 1x1 卷积降维与 ASP。这一聚合相当于 ensemble 了浅层声学特征与深层语义特征，在消融实验中单独贡献约 5%~8% 的相对 EER 下降。

## 4. 目标函数：说话人判别与度量学习

训练目标可分两大范式：

1. **判别式（Classification）**：将每个说话人当作一个类，训练闭合集 Softmax 分类器，推理时丢弃分类头只用 embedding。优点是类内紧致、训练稳定；缺点是类别数大（VoxCeleb2 训练集 5994 人）时分类头参数达 5994×192 ≈ 115 万，且对未见过说话人泛化依赖 margin 设计。
2. **度量式（Metric Learning）**：直接优化 embedding 空间中的距离结构（三元组损失、ProtoNet 等），按 batch 内的 pair 采样构造约束。优点是天然开集；缺点是对采样策略和难例挖掘极其敏感。

现代主流做法是**二者联合**：AAM-Softmax 为主损失 + triplet 为辅助正则，即：

$$\mathcal{J} = \mathcal{L}_{\text{AAM}} + \lambda \mathcal{L}_{\text{triplet}}, \quad \lambda \approx 0.01 \sim 0.1$$

embedding 空间的目标几何：**类内距离 < 类间距离**，且经过 $L_2$ 归一化后所有 embedding 落在单位超球面上，cosine 相似度等价于欧氏距离单调变换。

## 5. 损失函数：Softmax → AAM-Softmax 完整推导

### 5.1 从 Softmax 到带 margin 的 Softmax

设第 $i$ 个样本的 embedding 为 $x_i \in \mathbb{R}^d$（$L_2$ 归一化后 $\|x_i\| = 1$），其真实说话人标签为 $y$，分类权重矩阵 $W = [w_1, \dots, w_N]$，每个 $w_j$ 也归一化到单位长度。Softmax 损失：

$$\mathcal{L}_{\text{softmax}} = -\log \frac{\exp(w_y^{\top} x_i)}{\sum_{j=1}^{N} \exp(w_j^{\top} x_i)}$$

归一化后 $w_j^{\top} x_i = \cos\theta_j$（$\theta_j$ 为两向量夹角）。**问题**：Softmax 只要求 $\cos\theta_y$ 最大，不要求"大多少"，类间边界（decision margin）不存在，embedding 空间类间区分度不足。

### 5.2 ArcFace / AAM-Softmax：加性角度间隔

**AAM-Softmax（Additive Angular Margin Softmax）** 在 logits 上直接加上角度间隔 $m$：

$$\mathcal{L}_{\text{AAM}} = -\log \frac{\exp\left( s \cdot (\cos\theta_y - m)\right)}{\exp\left(s \cdot (\cos\theta_y - m)\right) + \sum_{j \neq y} \exp\left( s \cdot \cos\theta_j \right)}$$

推导分三步：

1. **归一化**：$\|x_i\| = \|w_j\| = 1$，则 $w_j^{\top} x_i = \cos\theta_j$，logits 只剩角度信息；
2. **加 margin**：仅对**正确类别** $y$ 的角度加惩罚 $\cos\theta_y - m$（$m$ 典型取 0.2~0.5，对应约 11.5°~30° 的角度间隔）；
3. **缩放**：用特征尺度 $s$（典型 30~64）放大 logits，弥补归一化导致的 logits 绝对值过小、梯度不足的问题。

### 5.3 margin 的几何解释

在二维单位圆上直观理解：训练收敛时要求

$$s(\cos\theta_y - m) > s\cos\theta_j, \ \forall j \neq y \ \Rightarrow \ \theta_y + \Delta < \theta_j$$

即**真实类别的角度必须比最难的负类再小一个由 $m$ 决定的间隔**。决策边界从 Softmax 的"过原点超平面"变成围绕各类别中心的**收窄扇形区域**，等效于在超球面上给每个说话人划出一块排他性的"领地"，类内被进一步压紧、类间被推开。

与两个前身的对比：

| 损失 | margin 注入位置 | 公式核心 | 缺点 |
| --- | --- | --- | --- |
| SphereFace (AM) | 乘性角度 $\cos(m\theta_y)$ | $\cos(m\theta)$ | 需 annealing，数值不稳 |
| CosFace (LM) | 加性余弦 $\cos\theta_y - m$ | 余弦域减 $m$ | 间隔几何意义稍弱 |
| **AAM-Softmax** | 加性角度 $\cos(\theta_y + m)$ | 角度域加 $m$，与 $\cos\theta - m$ 等价单调 | 超参 $s, m$ 需调 |

### 5.4 三元组损失（Triplet Loss）

以 anchor $x_a$、正样本 $x_p$（同说话人）、负样本 $x_n$（异说话人）构成三元组：

$$\mathcal{L}_{\text{triplet}} = \max\left( 0, \, \|f(x_a) - f(x_p)\|_2^2 - \|f(x_a) - f(x_n)\|_2^2 + \alpha \right)$$

其中 $\alpha$ 为 margin（典型 0.2~0.5）。训练中使用 **batch-hard 挖掘**：每个 batch 按 $P$ 个说话人 × $K$ 条语音（如 PK=64×2=128）组织，对每个 anchor 选 batch 内最难的正样本与最难的负样本，保证损失非零、信息量最大。

### 5.5 PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class AAMSoftmax(nn.Module):
    """Additive Angular Margin Softmax (ArcFace / AAM-Softmax)"""
    def __init__(self, embed_dim: int, num_classes: int, s: float = 32.0, m: float = 0.2):
        super().__init__()
        self.s = s
        self.m = m
        # 每类一个可学习的权重向量 (归一化后即类中心方向)
        self.weight = nn.Parameter(torch.randn(num_classes, embed_dim))
        nn.init.xavier_uniform_(self.weight)
        self.cos_m = math.cos(m)
        self.sin_m = math.sin(m)
        self.th = math.cos(math.pi - m)   # cos(pi - m)，限制 theta <= pi - m
        self.mm = math.sin(math.pi - m) * m

    def forward(self, x: torch.Tensor, labels: torch.Tensor) -> tuple:
        """
        x:      [B, embed_dim]  (未归一化的 embedding)
        labels: [B]
        return: (loss, logits_with_margin)
        """
        # 1. 权重与输入均 L2 归一化 → 余弦相似度
        cosine = F.linear(F.normalize(x), F.normalize(self.weight))  # [B, N], 值域 [-1, 1]
        sine = torch.sqrt((1.0 - cosine ** 2).clamp(0, 1))

        # 2. cos(theta + m) = cos(theta)cos(m) - sin(theta)sin(m)
        phi = cosine * self.cos_m - sine * self.sin_m
        phi = torch.where(cosine > self.th, phi, cosine - self.mm)  # 数值稳定保护

        # 3. 仅对正确类别使用 margin logits，其余类别保持原 cosine
        one_hot = F.one_hot(labels, num_classes=cosine.size(1)).float()
        logits = torch.where(one_hot.bool(), phi, cosine)

        # 4. 尺度缩放后计算交叉熵
        logits = logits * self.s
        loss = F.cross_entropy(logits, labels)
        return loss, logits


class BatchHardTripletLoss(nn.Module):
    """Batch-Hard 三元组损失, batch 组织方式: P 个说话人 x K 条语音"""
    def __init__(self, margin: float = 0.3):
        super().__init__()
        self.margin = margin

    def forward(self, embeddings: torch.Tensor, labels: torch.Tensor) -> torch.Tensor:
        # L2 归一化后, 欧氏距离平方 = 2 - 2*cos
        emb = F.normalize(embeddings, p=2, dim=1)
        dist = torch.cdist(emb, emb, p=2) ** 2          # [B, B]
        same = labels.unsqueeze(0) == labels.unsqueeze(1)  # [B, B] 同说话人掩码

        # hardest positive: 同说话人中距离最大的
        hardest_pos = dist[same].view(-1)                # 先简化取均值便于演示
        # 严格实现应按行取 max(dist * same) 并去掉对角线
        pos_dist = dist * same.float()
        pos_dist.fill_diagonal_(0)
        hardest_pos, _ = pos_dist.max(dim=1)

        # hardest negative: 异说话人中距离最小的
        neg_dist = dist * (~same).float()
        neg_dist[neg_dist == 0] = float("inf")
        hardest_neg, _ = neg_dist.min(dim=1)

        loss = F.relu(hardest_pos - hardest_neg + self.margin)
        return loss.mean()


if __name__ == "__main__":
    B, d, N = 128, 192, 5994
    emb = torch.randn(B, d)
    labels = torch.randint(0, N, (B,))
    aam = AAMSoftmax(d, N, s=32.0, m=0.2)
    loss_cls, _ = aam(emb, labels)
    loss_tri = BatchHardTripletLoss(0.3)(emb, labels)
    total = loss_cls + 0.05 * loss_tri
    print(f"AAM-Softmax loss: {loss_cls.item():.4f}")   # 初始约 ln(5994) ≈ 8.7
    print(f"Triplet loss:     {loss_tri.item():.4f}")
```

| x-vector (TDNN) | ~4.3 M | 512 | ~4.8% |

## 7. 总结

* **TDNN 核心**：dilated context 一维卷积以极少参数覆盖音素级时域上下文；统计池化（mean + std）将变长序列压缩为定长 x-vector。
* **ECAPA 三大改进**：① SE-Res2Block——Res2Net 分组级联卷积获得多尺度感受野，SE 模块做通道注意力重标定；② Attentive Statistics Pooling——注意力加权的一二阶统计，聚焦信息量大的帧；③ MFA——多层特征拼接聚合，浅层与深层信息互补。
* **目标函数**：判别式（分类）与度量式（距离结构）两大范式，工业界以 AAM-Softmax 为主、triplet 为辅联合训练。
* **AAM-Softmax 要点**：归一化把 logits 变成纯角度 → 对正确类加角度 margin $m$（几何上在超球面划出排他领地）→ 尺度 $s$ 放大恢复梯度；典型超参 $s = 30 \sim 64$，$m = 0.2 \sim 0.5$。
* **工程演进**：ECAPA-TDNN 之后主流方向为 ResNet 系骨干（更易量化部署）与 CAM++/Transformer 系骨干，但 ASP 池化与 AAM-Softmax 训练范式被完整继承。
