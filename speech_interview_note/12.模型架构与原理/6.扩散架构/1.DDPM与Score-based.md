# 1. DDPM 与 Score-based 模型

## 1. 概述

**DDPM（Denoising Diffusion Probabilistic Models, Ho et al. 2020）** 与 **Score-based Generative Models（Score Matching with Langevin Dynamics / SDE, Song & Ermon）** 是同一生成范式的两种视角：前者从**变分推断（ELBO）** 出发，后者从**分数匹配（Score Matching）与随机微分方程（SDE）** 出发，二者在数学上严格等价。

* **DDPM 视角**：定义一个逐步加噪的马尔可夫前向过程 $q(x_t | x_{t-1})$，再学习其逆过程 $p_\theta(x_{t-1}|x_t)$，训练目标最终化简为**预测噪声的 MSE 损失**。
* **Score-based 视角**：学习分布的分数函数 $s_\theta(x) \approx \nabla_x \log p(x)$，再通过 **Langevin dynamics 或概率流 ODE** 采样。

> **与 04 章的分工**：`04.音频生成与音乐/1.Audio Diffusion.md` 是**应用综述视角**（Latent Diffusion、AudioLDM、Stable Audio、音乐生成等）。本篇是**架构与损失函数深挖视角**：完整推导 ELBO → 简化损失、SDE/ODE 公式、DDIM 加速推导，以及 DiffWave/WaveGrad 的网络结构如何嵌入语音波形。

## 2. 算法架构：前向过程与闭式解推导

### 2.1 逐步加噪过程

对真实样本 $x_0 \sim q(x_0)$（图像、语音波形或 Mel 谱），定义 $T$ 步（典型 $T=1000$）马尔可夫加噪链：

$$q(x_t \mid x_{t-1}) = \mathcal{N}(x_t;\ \sqrt{1-\beta_t}\, x_{t-1},\ \beta_t \mathbf{I})$$

其中 $\beta_1, \dots, \beta_T \in (0,1)$ 为**噪声调度（noise schedule）**，DDPM 原文取线性调度：$\beta_1 = 10^{-4}$ 线性增至 $\beta_T = 0.02$。

重参数化等价形式：

$$x_t = \sqrt{1-\beta_t}\, x_{t-1} + \sqrt{\beta_t}\, \epsilon_{t-1}, \quad \epsilon_{t-1} \sim \mathcal{N}(0, \mathbf{I})$$

### 2.2 闭式解 $q(x_t | x_0)$ 推导（训练高效的关键）

若必须逐步迭代 $T$ 次才能得到 $x_t$，训练将不可行。幸运的是，任意 $t$ 步可**一步采样**。记 $\alpha_t = 1-\beta_t$，$\bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$，递推展开前两步：

$$x_t = \sqrt{\alpha_t}\, x_{t-1} + \sqrt{1-\alpha_t}\, \epsilon_{t-1}$$

$$= \sqrt{\alpha_t \alpha_{t-1}}\, x_{t-2} + \sqrt{\alpha_t (1-\alpha_{t-1})}\, \epsilon_{t-2} + \sqrt{1-\alpha_t}\, \epsilon_{t-1}$$

两个独立高斯噪声合并：$\alpha_t(1-\alpha_{t-1}) + (1-\alpha_t) = 1 - \alpha_t\alpha_{t-1}$，故方差系数为 $\sqrt{1-\alpha_t\alpha_{t-1}}$。归纳递推至 $x_0$：

$$\boxed{q(x_t \mid x_0) = \mathcal{N}(x_t;\ \sqrt{\bar{\alpha}_t}\, x_0,\ (1-\bar{\alpha}_t)\mathbf{I})}$$

$$x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1-\bar{\alpha}_t}\, \epsilon, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$$

当 $t \to T$，$\bar{\alpha}_T \to 0$，$x_T$ 近似各向同性标准高斯。**训练时随机采样 $t \sim \mathcal{U}\{1,T\}$ 并一步构造 $x_t$，无需跑完整条链。**

### 2.3 整体架构示意

```
训练 (Training):
  x_0 ──(一步加噪: x_t = √ᾱ_t·x_0 + √(1-ᾱ_t)·ε)──> x_t ──> [ε_θ(x_t, t, c)] ──> ε̂
  Loss = || ε - ε̂ ||²                              (t 随机采样, 无需跑完整链)

采样 (Sampling):
  x_T ~ N(0, I) ──> [p_θ(x_{T-1}|x_T)] ──> x_{T-1} ──> ... ──> x_1 ──> [p_θ(x_0|x_1)] ──> x_0
                    (迭代 T 次, 推理慢的根源)

ε_θ 骨干 (图像): UNet + 时间嵌入 + 自注意力
ε_θ 骨干 (语音): DiffWave/WaveGrad 用 1D 空洞卷积代替 UNet (见 §8)
```

## 3. 逆向过程参数化

### 3.1 学习的逆向高斯

$$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}(x_{t-1};\ \mu_\theta(x_t, t),\ \Sigma_\theta(x_t, t)), \quad \Sigma_\theta = \sigma_t^2 \mathbf{I}$$

$\sigma_t^2$ 取固定值（DDPM 取 $\sigma_t^2 = \beta_t$ 或 $\beta_t$ 的变体，见 §5）。

### 3.2 真实后验 $q(x_{t-1} | x_t, x_0)$（推导的关键桥梁）

利用贝叶斯公式与高斯乘积公式（两个高斯的乘积仍是高斯，均值方差有闭式组合规则），可推出**前向过程的后验**也是高斯：

$$q(x_{t-1} \mid x_t, x_0) = \mathcal{N}(x_{t-1};\ \tilde{\mu}_t(x_t, x_0),\ \tilde{\beta}_t \mathbf{I})$$

$$\tilde{\mu}_t = \frac{\sqrt{\bar{\alpha}_{t-1}}\, \beta_t}{1-\bar{\alpha}_t} x_0 + \frac{\sqrt{\alpha_t}\,(1-\bar{\alpha}_{t-1})}{1-\bar{\alpha}_t} x_t, \quad \tilde{\beta}_t = \frac{1-\bar{\alpha}_{t-1}}{1-\bar{\alpha}_t}\, \beta_t$$

### 3.3 噪声参数化（$\epsilon$-prediction）

将 $x_0 = \frac{1}{\sqrt{\bar{\alpha}_t}}\left(x_t - \sqrt{1-\bar{\alpha}_t}\, \epsilon_0\right)$ 代入 $\tilde{\mu}_t$，整理得：

$$\tilde{\mu}_t = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}} \epsilon_0\right)$$

于是**参数化逆向均值为同一函数形式，只是把真噪声 $\epsilon_0$ 换成网络预测 $\epsilon_\theta(x_t, t)$**：

$$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}}\, \epsilon_\theta(x_t, t)\right)$$

采样更新：$x_{t-1} = \mu_\theta(x_t,t) + \sigma_t z,\ z\sim\mathcal{N}(0,\mathbf{I})$（$t=1$ 时去掉噪声项）。

> **等价参数化**：还有 $x_0$-prediction（直接预测干净样本）与 **v-prediction**（$v = \sqrt{\bar\alpha_t}\,\epsilon - \sqrt{1-\bar\alpha_t}\,x_0$，Stable Diffusion 2 / AudioLDM 采用，高噪声区数值更稳定）。三者可互相线性换算，本篇以 $\epsilon$-prediction 为主线。

## 4. 目标函数：从 ELBO 到简化损失的完整推导

### 4.1 变分下界（ELBO）分解

对任意分布 $q(x_{1:T}|x_0)$（不需要知道真实 $p(x_0)$ 的形式），有：

$$-\log p_\theta(x_0) = -\log \int p_\theta(x_{0:T})\, dx_{1:T} \le \mathbb{E}_{q(x_{1:T}|x_0)}\left[-\log \frac{p_\theta(x_{0:T})}{q(x_{1:T}|x_0)}\right] =: L_{\text{VLB}}$$

利用两种过程都是马尔可夫链，交叉熵项可拆成一条「链式 KL」：

$$L_{\text{VLB}} = \underbrace{\mathbb{E}_q\left[D_{\mathrm{KL}}\big(q(x_T|x_0)\,\|\,p(x_T)\big)\right]}_{L_T\ (\text{无参数，常数)}} + \sum_{t=2}^{T} \underbrace{\mathbb{E}_q\left[D_{\mathrm{KL}}\big(q(x_{t-1}|x_t,x_0)\,\|\,p_\theta(x_{t-1}|x_t)\big)\right]}_{L_{t-1}} + \underbrace{\mathbb{E}_q\left[-\log p_\theta(x_0|x_1)\right]}_{L_0}$$

* $L_T$：两个几乎都是标准高斯，接近常数，无学习参数。
* $L_0$：最后一步离散化重建项（实践中用独立的离散解码器）。
* **$L_{t-1}$ 是训练主体**：把学习的逆向分布去逼近已知闭式的真实后验。

### 4.2 高斯 KL 的闭式展开

两个等方差高斯的 KL 散度退化为均值的平方距离：

$$L_{t-1} = \mathbb{E}_q\left[\frac{1}{2\sigma_t^2}\left\| \tilde{\mu}_t(x_t, x_0) - \mu_\theta(x_t, t) \right\|^2\right] + C$$

### 4.3 代入 $\epsilon$ 参数化

将 §3.3 中 $\tilde{\mu}_t$ 与 $\mu_\theta$ 的表达式代入，$\frac{1}{\sqrt{\alpha_t}}x_t$ 两项相消，剩下纯噪声预测项：

$$L_{t-1} = \mathbb{E}_{x_0, \epsilon}\left[\frac{\beta_t^2}{2\sigma_t^2\, \alpha_t\, (1-\bar{\alpha}_t)} \left\| \epsilon_0 - \epsilon_\theta\big(\sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon_0,\ t\big) \right\|^2\right] + C$$

### 4.4 简化损失 $L_{\text{simple}}$

DDPM 发现**丢掉权重系数 $\lambda_t = \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar{\alpha}_t)}$、丢掉 $L_0$** 反而生成质量更好（等价于对高噪声步重新加权，见 §5.3），得到最终形式：

$$\boxed{\mathcal{L}_{\text{simple}} = \mathbb{E}_{x_0,\, \epsilon \sim \mathcal{N}(0,I),\, t\sim\mathcal{U}\{1,T\}}\Big[\left\| \epsilon - \epsilon_\theta(x_t,\ t) \right\|^2\Big]}$$

DDPM 在 CIFAR-10 上取得 IS 9.46 / FID 3.17（当年无 GAN 参与时最优水平），$T=1000$。

## 5. 损失函数加权、噪声调度与 SNR

### 5.1 信噪比 SNR

定义每一步的**信噪比（Signal-to-Noise Ratio）**：

$$\mathrm{SNR}(t) = \frac{\bar{\alpha}_t}{1-\bar{\alpha}_t}$$

由 $x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon$ 直接得出。$\mathrm{SNR}(t)$ 随 $t$ 单调下降，$t \to T$ 时趋于 0（纯噪声）。采用 $\sigma_t^2 = \beta_t$ 时，VLB 权重近似满足 $\lambda_t \propto 1/\mathrm{SNR}(t)$——**VLB 天然压低高噪声步（大 $t$）的权重，$L_{\text{simple}}$ 则把权重拉平（相当于 $\lambda_t \equiv 1$）**，更强调低噪声精细重建，这在实验中被证明对感知质量更有利。

### 5.2 常见调度

| 调度 | 定义 | 特点 | 代表 |
| --- | --- | --- | --- |
| **Linear** | $\beta_t$ 从 $10^{-4}$ 线性到 $0.02$ | 简单；末期信息破坏过快 | DDPM |
| **Cosine** | $\bar{\alpha}_t = \frac{f(t)}{f(0)},\ f(t)=\cos^2\!\big(\frac{t/T+s}{1+s}\cdot\frac{\pi}{2}\big),\ s=0.008$ | 中段加噪更平缓 | iDDPM、AudioLDM |
| **音频定制** | 波形尖峰稀疏，低噪声段 SNR 已极高，需更大 $\beta$ 上界 / 更陡早期调度 | WaveGrad / DiffWave 变体 | 见 04 章调度小节 |

### 5.3 训练目标统一形式

各种加权可统一写成：

$$\mathcal{L} = \mathbb{E}_{t}\Big[ w(t)\, \left\| \epsilon - \epsilon_\theta(x_t, t) \right\|^2 \Big], \quad w(t) = 1\ (L_{\text{simple}}) \ \text{或}\ \lambda_t\ (\text{VLB}) \ \text{或 SNR 加权}$$

## 6. Score-based 视角：SDE 与概率流 ODE

### 6.1 Score Function 与 Score Matching

定义分布的**分数函数**：

$$s(x) = \nabla_x \log p(x)$$

即对数密度在样本空间的梯度场，指向密度增大方向。**分数匹配（Score Matching）** 目标：

$$\mathbb{E}_{p}\big[\left\| s_\theta(x) - \nabla_x \log p(x) \right\|^2\big]$$

直接计算需要未知的 $\nabla_x \log p(x)$。**去噪分数匹配（Denoising Score Matching, DSM）** 证明了等价目标可观测：

$$\mathbb{E}_{x_0, \epsilon}\left[\left\| s_\theta(x_t) + \frac{\epsilon}{\sqrt{1-\bar{\alpha}_t}} \right\|^2\right] \quad\Longleftrightarrow\quad \epsilon_\theta(x_t,t) = -\sqrt{1-\bar{\alpha}_t}\; s_\theta(x_t, t)$$

**即 DDPM 的噪声预测网络就是（缩放后的）分数网络**，这是两个视角等价的核心。

### 6.2 Langevin Dynamics 采样

仅用分数即可采样（无需归一化常数）：

$$x_{k+1} = x_k + \frac{\eta}{2} s_\theta(x_k) + \sqrt{\eta}\, z_k, \quad z_k \sim \mathcal{N}(0, \mathbf{I}), \quad \eta \to 0,\ k \to \infty$$

缺点：步长需极小、步数需极多（数千步），且低密度区域分数估计不准 → 引出多尺度加噪（噪声条件分数网络 NCSN）与 SDE 统一框架。

### 6.3 前向 SDE 与逆向 SDE

将离散加噪链推广为连续时间 $t \in [0, T]$ 的伊藤 SDE：

$$dx = f(x, t)\, dt + g(t)\, dw$$

* **VP-SDE**（对应 DDPM）：$dx = -\frac{1}{2}\beta(t) x\, dt + \sqrt{\beta(t)}\, dw$
* **VE-SDE**（对应 NCSN）：$dx = \sqrt{\frac{d\sigma^2(t)}{dt}}\, dw$

**Anderson (1982) 逆向时间 SDE**（可证明）：

$$dx = \big[f(x, t) - g^2(t)\, \nabla_x \log p_t(x)\big]\, d\bar{t} + g(t)\, d\bar{w}$$

只需把 $\nabla_x \log p_t$ 换成 $s_\theta(x,t)$ 即可逆向采样——**逆向过程唯一依赖分布的信息就是分数**。

### 6.4 概率流 ODE（Probability Flow ODE）

Song et al. (2021) 证明存在与 SDE 边际分布完全相同的**确定性 ODE**：

$$\frac{dx}{dt} = f(x,t) - \frac{1}{2} g^2(t)\, \nabla_x \log p_t(x)$$

价值：① 确定性轨迹，一次采样可复现；② 可用高阶 ODE solver（DPM-Solver 等）**大步长加速**（10~25 步即可接近 1000 步质量）；③ ODE 换元可算**精确似然**。

### 6.5 Tweedie 公式视角（选学，面试加分）

后验均值（"理想去噪器"）满足：

$$\mathbb{E}[x_0 \mid x_t] = x_t + (1-\bar{\alpha}_t)\, \nabla_{x_t} \log p_t(x_t)$$

结合 $\epsilon_\theta = -\sqrt{1-\bar{\alpha}_t}\, s_\theta$ 可推出 $x_0$ 的估计：$\hat{x}_0 = \frac{1}{\sqrt{\bar{\alpha}_t}}\big(x_t - \sqrt{1-\bar{\alpha}_t}\, \epsilon_\theta\big)$——与 DDIM 采样中的 $\hat{x}_0$ 一致。

## 7. 条件生成与 Classifier-Free Guidance (CFG)

语音任务几乎总是条件生成（条件 $c$ = Mel 谱 / 文本 / 音色 embedding）：

$$\mathcal{L}_{\text{cond}} = \mathbb{E}\big[\left\| \epsilon - \epsilon_\theta(x_t, t, c) \right\|^2\big]$$

条件注入方式：concat 到输入、加到时间嵌入、或 Cross-Attention（DiffSinger、AudioLDM 用后者）。

**CFG** 训练时以概率 10%~20% 随机丢弃条件（用空条件 $\varnothing$ 代替），采样时外推：

$$\tilde{\epsilon}_\theta(x_t, t, c) = \epsilon_\theta(x_t, t, \varnothing) + w \cdot \big(\epsilon_\theta(x_t, t, c) - \epsilon_\theta(x_t, t, \varnothing)\big)$$

* $w = 0$：无条件；$w = 1$：普通条件生成；$w > 1$：沿「条件减无条件」方向外推，**提升条件依从度与生成多样性**，但过大损害保真（图像典型 $w \in [3, 10]$，语音 TTS 常用 $1 \sim 3$）。

## 8. 语音应用：DiffWave 与 WaveGrad 架构

> 应用全景（Latent Diffusion、歌声、音效）见 `04.音频生成与音乐/1.Audio Diffusion.md`；本节聚焦**去噪骨干网络如何为波形定制**。

### 8.1 DiffWave（Ning et al. 2020）

图像 DDPM 用 UNet，而 DiffWave 骨干是**双向空洞卷积残差网络（非自回归、非 UNet）**：

```
                 ┌────────────────────────────────────────────┐
  x_t (波形) ──> │ ResLayer 1..30 (空洞卷积, dilation 循环1..16)│──> 求和 ──> 1x1Conv ──> ε̂ (单通道)
       │         └────────────────────────────────────────────┘
       │              ▲ 扩散步嵌入(128维正弦→FC)   ▲ Mel条件(转置卷积上采样对齐波形后逐层相加)
       └──────────────┴───────────────────────────┘
```

* **噪声预测头**：30 层残差、128 通道，输出逐样本噪声 $\hat\epsilon \in \mathbb{R}^{L}$。
* **条件**：Mel 谱经转置卷积上采样（hop 对齐）后与扩散步嵌入一起逐层注入。
* **效果量级**：LJSentence 22.05 kHz vocoder 任务 MOS ≈ 4.4，与自回归 WaveNet teacher 统计上不可区分，超过同期 WaveGlow/Mel-GAN（约 4.0~4.2）；仅用 **T = 50** 步即可（远小于 DDPM 的 1000）。

### 8.2 WaveGrad（Chen et al. 2020）

* 骨干为 **FCNN + 下采样/上采样跳连（类 UNet 的 1D 卷积版本）**，同样双向非自回归。
* 核心贡献：**细粒度噪声调度（fine-grained noise schedule）**——训练时对连续 $\beta_t$ 插值随机采样，使推理步数可灵活调整（1000 / 256 / 50 / 25 / 12 / 6 步），50 步左右即可获得 MOS > 4.0 的质量，**训练一次、推理时按算力换取质量**。
* 这一「训推调度解耦 + 少步采样」思想直接影响了后续所有快速音频扩散系统。

## 9. 采样加速：DDIM 确定性采样推导

DDPM 慢的根源是 $T=1000$ 次串行网络前向。DDIM（Song et al. 2020）构造一族**非马尔可夫**前向过程，保持每步边缘 $q(x_t|x_0)$ 不变（因此训练目标不变、模型无需重训），但允许跳步与确定性采样。

### 9.1 非马尔可夫前向

定义 $q_\sigma(x_{t-1} \mid x_t, x_0)$（注意依赖 $x_0$，破坏马尔可夫性）：

$$q_\sigma(x_{t-1} \mid x_t, x_0) = \mathcal{N}\left(\sqrt{\bar{\alpha}_{t-1}}\, x_0 + \sqrt{1-\bar{\alpha}_{t-1} - \sigma_t^2}\cdot\frac{x_t - \sqrt{\bar{\alpha}_t}\, x_0}{\sqrt{1-\bar{\alpha}_t}},\ \ \sigma_t^2 \mathbf{I}\right)$$

可验证：该族联合分布诱导的边缘 $q_\sigma(x_t | x_0)$ 与原 DDPM 完全一致，且对应 ELBO 化简后**与 $\sigma$ 无关、仍为同一个 $\epsilon$-prediction 损失**——所以已训练好的 DDPM 模型可直接换用 DDIM 采样。

### 9.2 采样更新式

先由 $\hat{x}_0 = \frac{1}{\sqrt{\bar{\alpha}_t}}\big(x_t - \sqrt{1-\bar{\alpha}_t}\,\epsilon_\theta(x_t,t)\big)$ 估计干净样本，再在跳步子序列 $\tau_1 < \tau_2 < \dots < \tau_S = T$ 上更新：

$$x_{\tau_{i-1}} = \sqrt{\bar{\alpha}_{\tau_{i-1}}}\, \hat{x}_0 + \sqrt{1-\bar{\alpha}_{\tau_{i-1}} - \sigma_{\tau_i}^2}\cdot\frac{x_{\tau_i} - \sqrt{\bar{\alpha}_{\tau_i}}\, \hat{x}_0}{\sqrt{1-\bar{\alpha}_{\tau_i}}} + \sigma_{\tau_i} z$$

* 取 $\sigma_{\tau_i} = 0$：**完全确定性 ODE 式采样**，同一 $x_T$ 生成同一 $x_0$（可做音频插值、声音编辑）。
* 取 $\sigma_{\tau_i} = \sqrt{\tilde{\beta}_{\tau_i}}$：退化为 DDPM 随机采样。
* 加速效果量级：**CIFAR-10 上 S=10 步的 FID 已低于 DDPM 1000 步采样**；语音上 WaveGrad/DiffWave 少步采样同理。

## 10. PyTorch 实现核心代码

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GaussianDiffusion(nn.Module):
    """DDPM 核心：噪声调度 + 训练损失 + 采样 (骨干 epsilon_net 以任意 1D 网络代替)"""
    def __init__(self, epsilon_net: nn.Module, T: int = 1000):
        super().__init__()
        self.epsilon_net = epsilon_net          # 输入 (x_t, t_emb, cond) -> 噪声预测
        self.T = T
        betas = torch.linspace(1e-4, 0.02, T)   # linear schedule
        alphas = 1.0 - betas
        alphas_cumprod = torch.cumprod(alphas, dim=0)  # ᾱ_t

        # 注册为 buffer: 随模型迁移设备但不参与训练
        for name, tensor in [("betas", betas), ("alphas", alphas),
                             ("alphas_cumprod", alphas_cumprod),
                             ("sqrt_ac", alphas_cumprod.sqrt()),
                             ("sqrt_om_ac", (1 - alphas_cumprod).sqrt())]:
            self.register_buffer(name, tensor)

    def q_sample(self, x0: torch.Tensor, t: torch.Tensor, eps: torch.Tensor):
        """一步构造 x_t = √ᾱ_t·x0 + √(1-ᾱ_t)·ε  (训练高效的关键)"""
        return (self._gather(self.sqrt_ac, t) * x0
                + self._gather(self.sqrt_om_ac, t) * eps)

    @staticmethod
    def _gather(buf: torch.Tensor, t: torch.Tensor):
        """按 batch 内每个样本的 t 取标量系数, 并 reshape 成 [B,1,1] 以便广播"""
        return buf.gather(0, t).view(-1, 1, 1)

    def training_loss(self, x0: torch.Tensor, cond: torch.Tensor = None):
        """L_simple = E || ε - ε_θ(x_t, t) ||²"""
        B = x0.size(0)
        t = torch.randint(1, self.T, (B,), device=x0.device)
        eps = torch.randn_like(x0)
        x_t = self.q_sample(x0, t, eps)
        eps_hat = self.epsilon_net(x_t, t, cond)
        return F.mse_loss(eps_hat, eps)         # 简化损失: 权重恒为 1

    @torch.no_grad()
    def sample(self, shape, cond=None, device="cuda", ddim_steps: int = 0):
        """DDPM 随机采样; ddim_steps>0 时切换为 DDIM 确定性跳步采样"""
        x = torch.randn(shape, device=device)   # x_T ~ N(0, I)
        ts = torch.linspace(self.T - 1, 0, ddim_steps or self.T, device=device).long()
        for i, t in enumerate(ts):
            tb = t.repeat(shape[0])
            eps_hat = self.epsilon_net(x, tb, cond)
            x0_hat = (x - self._gather(self.sqrt_om_ac, tb) * eps_hat) / self._gather(self.sqrt_ac, tb)
            if ddim_steps > 0:                              # DDIM: σ = 0, 确定性
                t_prev = ts[i + 1] if i + 1 < len(ts) else ts.new_zeros(1)
                tbp = t_prev.repeat(shape[0])
                dir_xt = (x - self._gather(self.sqrt_ac, tb) * x0_hat) / self._gather(self.sqrt_om_ac, tb)
                x = self._gather(self.sqrt_ac, tbp) * x0_hat + self._gather(self.sqrt_om_ac, tbp) * dir_xt
            else:                                           # DDPM: σ_t = √β_t, 随机
                mean = (x - self._gather(self.betas, tb) / self._gather(self.sqrt_om_ac, tb) * eps_hat) \
                       / self._gather(self.alphas, tb).sqrt()
                x = mean + self._gather(self.betas, tb).sqrt() * torch.randn_like(x) if t > 0 else mean
        return x

# ==================== 训练循环 ====================
if __name__ == "__main__":
    # epsilon_net 为任意去噪骨干 (UNet / DiffWave 式空洞卷积栈), 此处以占位
    epsilon_net = nn.Sequential()          # 替换为真实网络
    diff = GaussianDiffusion(epsilon_net).cuda()
    opt = torch.optim.AdamW(diff.parameters(), lr=2e-4)

    for step in range(200_000):            # DDPM 典型总步数
```

## 11. 总结与最佳实践

* **一条主线**：前向闭式解 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$ → ELBO 分解成逐层高斯 KL → $\epsilon$ 参数化抵消均值项 → **$L_{\text{simple}} = \|\epsilon - \epsilon_\theta\|^2$**。
* **两个视角**：DDPM（离散、变分）与 Score-based（连续 SDE、分数匹配）通过 $\epsilon_\theta = -\sigma_t s_\theta$ 等价；概率流 ODE 给出确定性采样与精确似然。
* **工程要点**：
1. 训练随机采样 $t$、一步加噪；采样慢用 **DDIM（$\sigma=0$ 确定性）或 DPM-Solver**，语音上 25~50 步通常够用；
2. 波形级扩散注意噪声调度偏陡（波形尖峰稀疏），并优先考虑 Latent/Mel 级扩散降低算力（见 04 章）；
3. 条件生成优先 CFG（丢条件概率 0.1~0.2，$w$ 从 1 起调）。
* **面试高频追问**：为什么丢掉 VLB 权重反而更好？（等价于按 SNR 重加权，强化低噪声步的感知细节）；DDIM 为什么可以不重训？（非马尔可夫前向保持边缘与训练目标不变）。
