# 2. Speech-Transformer

## 1. 概述

**Speech-Transformer**（Dong et al., 2018, *Speech-Transformer: A No-Recurrence Sequence-to-Sequence Model for Speech Recognition*）是**首个将 vanilla Transformer 完整引入端到端语音识别的工作**，发表于 Interspeech 2018，与 Google 的另一篇工作几乎同期。

其历史意义与核心贡献：

* **去递归化的 ASR 骨干**：证明不依赖任何 RNN/CNN 时序结构，纯 Self-Attention 即可完成声学建模与序列生成，训练完全并行，在 Wall Street Journal（WSJ）数据集上超过了当时的 RNN-Based AED 与 CTC 基线。
* **2D Attention 机制**：语音的梅尔谱本质是 **时间 × 频率的二维图像**，而 NLP token 只有一维序列。Speech-Transformer 提出**分轴（time-axis / frequency-axis）的 2D 注意力**，分别建模时间维上下文与频率维上下文。
* **多任务训练范式的起点**：该工作同时将 **CTC 辅助损失**引入 Transformer 编码器（ Encoder 顶部接 CTC 分支），即 $\mathcal{L} = \lambda \mathcal{L}_{CTC} + (1-\lambda)\mathcal{L}_{ATT}$ 的雏形，奠定了后续 ESPnet、WeNet 等框架中 **joint CTC-Attention** 的标准训练范式。

它是理解 Conformer、Transformer-Transducer、Whisper 等现代模型的直接前身。

## 2. 算法架构

整体上仍是 Encoder-Decoder（AED）形态，但编码器针对梅尔谱的二维结构做了专门的 2D attention 设计，解码器对音素序列做自回归生成。

```
                        音素概率 P(y_u | y_<u, X)
                              ▲
                     ┌────────┴────────┐
                     │ Linear + Softmax │
                     └────────▲────────┘
              ┌───────────────┴──────────────────┐
              │        Decoder (x N_d 层)        │
              │  Masked Self-Attn (音素间依赖)   │
              │  Cross-Attn  (Q: 音素隐状态,      │
              │              K/V: 编码器输出)     │
              │  FFN + LayerNorm (Pre-LN)        │
              └───────▲──────────────────▲───────┘
                      │                  │ K, V
              ┌───────┴───────┐   ┌──────┴────────────────────────┐
   音素 y_<u  │ 音素 Embedding │   │        Encoder (x N_e 层)     │
   + PE(时间轴)│               │   │  ┌─────────────────────────┐  │
              └───────────────┘   │  │  Time-Axis Attention     │  │
                                  │  │  (沿 t 轴, 帧间依赖)      │  │
  梅尔谱 X ∈ R^{T×F}              │  │  Freq-Axis Attention     │  │
  (T 帧 × 80 维 Fbank)            │  │  (沿 f 轴, 频带间依赖)    │  │
        │                         │  │  2D Conv (局部模式)       │  │
        ▼                         │  │  FFN + LayerNorm         │  │
  ┌──────────────┐                │  └─────────────────────────┘  │
  │ Linear:      │                │           ▲                    │
  │ F=80→d_model │───────────────►│────────────┘                   │
  │ + PE(t, f)   │                │                                │
  └──────────────┘                │  ┌─────────────────────────┐  │
                                  │  │  Top: CTC 分支 (辅助)    │  │
                                  │  │  Linear(T×d → V) + CTC  │  │
                                  │  │  Loss L_CTC             │  │
                                  │  └─────────────────────────┘  │
                                  └────────────────────────────────┘
```

### 2.1 编码器：2D Attention 分轴建模

 vanilla Transformer 的 Self-Attention 假设输入是一维 token 序列，注意力同时混合所有位置；对语音谱而言，$(t, f)$ 平面上的位置关系有两个正交的轴：

* **时间轴（Time-axis）**：同一频带内相邻/远距离帧之间的动态演化（协同发音、长程语境）。
* **频率轴（Frequency-axis）**：同一帧内不同频带之间的相关结构（共振峰、谐波能量分布）。

Speech-Transformer 将每个 Encoder Layer 的注意力拆为两路：

**时间维注意力**（对每个频率分量，沿时间轴 attend）：

$$\text{head}_i^{(t)} = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V) \quad \text{（Q/K/V 在 } t \text{ 轴上展开）}$$

**频率维注意力**（对每个时间帧，沿频率轴 attend）：

$$\text{head}_i^{(f)} = \text{Attention}(Q' W_i'^{Q}, K' W_i'^{K}, V' W_i'^{V}) \quad \text{（Q/K/V 在 } f \text{ 轴上展开）}$$

两路输出拼接后过 FFN。由于频率维长度仅 $F=80$（远小于 $T$），分轴注意力的复杂度为 $O(T F^2 d + F T^2 d)$，相比把 $(t,f)$ 拉平成一维 $O((TF)^2 d)$ 的做法低一个数量级以上：

* 拉平 1D：$TF = 1000 \times 80 = 8 \times 10^4$，$(TF)^2 = 6.4 \times 10^9$ —— 不可行；
* 分轴 2D：$T F (T+F) = 1000 \times 80 \times 1080 \approx 8.6 \times 10^7$，**约缩小 74 倍**。

此外编码器前端用一层 **2D Conv（kernel 3×3, stride 2×2）** 做下采样与局部声学模式提取：一方面压缩序列长度（$T \to T/2$），另一方面为纯注意力结构补充 CNN 的局部平移不变性（这一思路后来被 Conformer 发扬光大）。

### 2.2 位置编码：二维 PE

一维正弦 PE 推广到 $(t, f)$ 平面，将 $d_{model}$ 维拆成两半分别编码时间与频率：

$$PE(t, f) = \left[\ PE^{(t)}(t)_{1:d/2}\ ;\ PE^{(f)}(f)_{d/2:d}\ \right]$$

即前一半维度携带时间位置信息、后一半携带频率位置信息，与投影后的特征相加。

### 2.3 解码器：音素序列自回归生成

解码器与 vanilla Transformer 完全一致：

* **输入端**：音素 Embedding（×$\sqrt{d_{model}}$ 缩放）+ 一维 PE。
* **Masked Self-Attention**：因果掩码保证 $y_u$ 只依赖 $y_{<u}$。
* **Cross-Attention**：Query 来自解码器隐状态，K/V 来自编码器输出，隐式学习声学帧与音素的对齐（替代 HMM 的显式对齐）。
* 输出层投影至音素表 $V$（WSJ 上为 59 个音素 + 特殊符号），Softmax 给出 $P(y_u | y_{<u}, X)$。

**典型配置**：$d_{model}=512$，$h=8$，$d_{ff}=2048$，Encoder 18 层 / Decoder 6 层，dropout 0.1，总参数量约 **60M** 量级；WSJ eval93 上 CER 约 **7.4%**（超越同期 BLSTM-based AED 的 ~9% 与 CTC 的 ~10% 水平）。

### 2.4 CTC 辅助分支

编码器顶部额外接一个 `Linear(d_model → V+1)` + Softmax，输出帧级 CTC 分布：

$$P_{CTC}(y_t \mid X) = \text{Softmax}(\text{Linear}(h_t))$$

作用（详见第 4 节）：加速编码器收敛、提供单调对齐先验、改善注意力「对齐漂移」（attention drifting，即注意力在长句上跳帧/重复的失稳现象）。

## 3. 与 Vanilla Transformer 的差异

| 维度 | Vanilla Transformer (NLP) | Speech-Transformer |
| --- | --- | --- |
| **输入** | 离散 Token Embedding | 连续梅尔谱，Linear(80→512) 投影 + 2D Conv 下采样 |
| **输入结构** | 一维序列（T 个 token） | 二维谱图（T 帧 × F 频带），天然是图像 |
| **注意力** | 单轴 1D Self-Attention | **2D 分轴：Time-axis + Freq-axis Attention** |
| **位置编码** | 一维正弦 PE | 二维 PE（维度拆半分别编码 t 与 f） |
| **局部建模** | 无（FFN 逐位置） | 前端 2D Conv 提供局部声学模式 + 下采样 |
| **解码目标** | 子词/词级文本 | **音素序列**（短序列，对齐更容易） |
| **训练目标** | 纯 Attention CE | **CE + CTC 辅助多任务**（$\lambda$ 加权） |
| **归一化** | Post-LN | Post-LN（2018 年原文；现代复现多改 Pre-LN） |

后续普遍演进的共识：频率轴注意力收益有限（频带相关性强、Fbank 维度已较小），**Conformer 等后续工作保留了「时间轴注意力 + 卷积」而放弃了独立的频率轴注意力**，只在特征端保留 2D 卷积下采样。

## 4. 目标函数与损失函数：Joint CTC-Attention

### 4.1 目标函数分解

模型整体仍是极大化条件似然，但被分解为两个互补项：

* **Attention 分支**（自回归，无对齐假设）：

$$P_{ATT}(Y \mid X) = \prod_{u=1}^{U} P(y_u \mid y_{<u}, X)$$

$$\mathcal{L}_{ATT} = -\sum_{u=1}^{U} \log P(y_u \mid y_{<u}, X) \quad \text{（即交叉熵，见《1.Transformer 基础》第 7、8 节）}$$

* **CTC 分支**（帧级单调对齐，条件独立假设）：

$$P_{CTC}(Y \mid X) = \sum_{\pi \in \mathcal{B}^{-1}(Y)} \prod_{t=1}^{T} P(\pi_t \mid X)$$

其中 $\mathcal{B}$ 是折叠重复、删 blank 的多对一映射，$\pi$ 为帧级路径。由前向-后向算法在 $O(T \cdot U)$ 内求解：

$$\mathcal{L}_{CTC} = -\log P_{CTC}(Y \mid X)$$

### 4.2 多任务损失 $L = \lambda L_{CTC} + (1-\lambda) L_{ATT}$ 推导

由于两个分支共享编码器（$\theta_{enc}$），各自拥有输出头（$\theta_{ctc}, \theta_{dec}$），联合训练目标写作：

$$\mathcal{L}(\theta_{enc}, \theta_{ctc}, \theta_{dec}) = \lambda \mathcal{L}_{CTC}(\theta_{enc}, \theta_{ctc}) + (1-\lambda)\mathcal{L}_{ATT}(\theta_{enc}, \theta_{dec})$$

**梯度视角的推导**：对共享编码器参数 $\theta_{enc}$ 求偏导，

$$\frac{\partial \mathcal{L}}{\partial \theta_{enc}} = \lambda \frac{\partial \mathcal{L}_{CTC}}{\partial \theta_{enc}} + (1-\lambda) \frac{\partial \mathcal{L}_{ATT}}{\partial \theta_{enc}}$$

即编码器同时接收两路监督信号：

1. **CTC 梯度**：携带单调对齐信息，约束编码器隐空间中「帧级发音可分性」，等价于对编码器做帧级正则；
2. **Attention 梯度**：携带序列级语言依赖，供解码器做全局最优。

$\lambda$ 的作用与取值（任务权重，非学习所得）：

* $\lambda = 0$ 退化为纯 AED；$\lambda = 1$ 退化为纯 CTC；
* 论文与工程实践普遍取 $\lambda \in [0.2, 0.5]$，**ESPCI/WeNet 默认 $\lambda = 0.3$（CTC 占 30%）**；
* $\lambda$ 过大：编码器过度偏向单调对齐，损失语言上下文表达，Attention 解码上限受抑；
* $\lambda$ 过小：CTC 正则太弱，长句上注意力对齐易漂移（重复/跳字），收敛变慢。

**概率视角**（Kim & Hori 2017 的理论解释）：联合目标可解释为对两个分布的混合对数线性插值 $P(Y|X) \propto P_{CTC}(Y|X)^{\lambda} P_{ATT}(Y|X)^{1-\lambda}$，解码时可用该混合分布做联合搜索，优于任一单分支。

### 4.3 CTC 损失的前向-后向形式（简要）

引入前向变量 $\alpha(t, u)$（对 $Y$ 的前 $u$ 个符号，走到帧 $t$ 的路径概率和）：

$$\alpha(t, u) = \big(\alpha(t-1, u) + \alpha(t-1, u-1) + \mathbb{1}[y_u \ne y_{u-1}]\,\alpha(t-1, u-2)\big) \cdot P(y_u^{\prime} \mid x_t)$$

其中 $y'$ 表示插 blank 后的扩展标签序列。总概率 $P_{CTC}(Y|X) = \alpha(T, U^{\prime})$，损失 $\mathcal{L}_{CTC} = -\log \alpha(T, U^{\prime})$。训练中通过对数域前向-后向保证数值稳定（同 RNN-T，参见 RNN-T 笔记第 4 节）。

### 4.4 PyTorch 实现：Joint CTC-Attention 训练步

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torchaudio.functional import forced_align  # 仅用于说明; CTC loss 用内置实现


class JointCTCAttentionLoss(nn.Module):
    """L = λ·L_CTC + (1-λ)·L_ATT, 两分支共享编码器"""
    def __init__(self, vocab_att: int, vocab_ctc: int, pad_id: int = 0,
                 blank_id: int = 0, lambda_ctc: float = 0.3, smoothing: float = 0.1):
        super().__init__()
        self.blank_id = blank_id
        self.pad_id = pad_id
        self.lambda_ctc = lambda_ctc
        # 注意: CTC 词表含 blank(0), Attention 词表不含, 故 vocab_ctc = vocab_att + 1
        self.ctc_loss = nn.CTCLoss(blank=blank_id, zero_infinity=True)  # zero_infinity: 长度非法样本损失置0, 防nan
        self.att_loss_fn = nn.CrossEntropyLoss(ignore_index=pad_id,
                                               label_smoothing=smoothing,
                                               reduction="none")

    def forward(self, enc_out, dec_out, text, text_lens, tokens, token_lens, enc_lens):
        """
        enc_out:   [B, T, vocab_ctc] 编码器输出(已过顶部 CTC 投影头 Linear(d->vocab_ctc))
        dec_out:   [B, U, vocab_att] 解码器 logits
        text:      [B, U]           attention 标签(不含blank, 含pad)
        tokens:    [B, U_ctc]       CTC 标签(不含blank/pad)
        enc_lens:  [B]              下采样后帧长
        """
        # ---------- 1. CTC 分支 ----------
        # nn.CTCLoss 要求 (T, N, C) 布局 + 输入必须已是 log_softmax(数值稳定)
        log_probs = F.log_softmax(enc_out, dim=-1)
        B, T, C = log_probs.shape
        l_ctc = self.ctc_loss(log_probs.transpose(0, 1),    # [T, B, C]
                              tokens,                        # [B, U_ctc] 合并后的目标
                              enc_lens, token_lens)

        # ---------- 2. Attention 分支 (Teacher Forcing + CE) ----------
        l_att_tok = self.att_loss_fn(dec_out.reshape(-1, dec_out.size(-1)), text.reshape(-1))
        l_att_tok = l_att_tok.view(B, -1)
        mask = text.ne(self.pad_id).float()
        l_att = (l_att_tok * mask).sum() / mask.sum().clamp(min=1.0)

        # ---------- 3. 多任务加权 ----------
        loss = self.lambda_ctc * l_ctc + (1.0 - self.lambda_ctc) * l_att
        return loss, {"ctc": l_ctc.detach(), "att": l_att.detach()}


if __name__ == "__main__":
    torch.manual_seed(0)
    B, T, d, vocab_att = 4, 250, 512, 59
    enc_out = torch.randn(B, T, vocab_att + 1, requires_grad=True)   # 已过 CTC 投影头
    dec_out = torch.randn(B, 40, vocab_att, requires_grad=True)
    text    = torch.randint(1, vocab_att, (B, 40)); text[:, 30:] = 0
    tokens  = torch.randint(1, vocab_att, (B, 25))
    enc_lens  = torch.tensor([250, 250, 200, 180])
    text_lens = (text != 0).sum(-1)
    tok_lens  = torch.tensor([25, 20, 18, 22])

    crit = JointCTCAttentionLoss(vocab_att, vocab_att + 1, lambda_ctc=0.3)
    loss, parts = crit(enc_out, dec_out, text, text_lens, tokens, tok_lens, enc_lens)
    print(f"joint loss = {loss.item():.4f}, "
          f"ctc = {parts['ctc'].item():.3f}, att = {parts['att'].item():.3f}")
    loss.backward()   # 编码器同时收到 λ·∂L_ctc/∂θ_enc + (1-λ)·∂L_att/∂θ_enc 两路梯度
```

> **解码阶段**：训练后可单独用 Attention Beam Search，也可按 $P(Y|X) \propto P_{CTC}^{\lambda} P_{ATT}^{1-\lambda}$ 做 joint decoding（ESPnet/WeNet 支持），长句上 joint decoding 通常再降 5%~10% 相对 CER。

## 5. 后续演化

### 5.1 Conformer（2020）：卷积 + Transformer 的融合

Speech-Transformer 证明了注意力的可行性，也暴露了纯注意力**缺乏局部归纳偏置**的问题。Conformer（Gulati et al.）在 Encoder 每个块中同时嵌入 MHSA 与 **Depthwise Conv（kernel 31, Swish-GLU）**，配合 macaron-style 双 FFN，在 LibriSpeech 上把相对纯 Transformer 架构的 WER 再降约 15%~20%，成为工业界近五年最主流的 ASR 骨干。可视为「Speech-Transformer 的时间轴注意力 + 强化的卷积分支」。

### 5.2 Transformer-Transducer（2020）：流式化

把 RNN-T 中的 LSTM 编码器/预测器**全部替换为 Transformer**：

* Encoder：带 chunk mask 的 Transformer（限制右向上下文，实现流式）；
* Predictor：Stateless Predictor（历史 1~2 个 Token 的 Embedding）或小型 Transformer LM；
* Joint Network 与 RNN-T 相同，损失同 $\mathcal{L}_{RNNT}$。
代表：**WeNet 的 Transformer-Transducer、Pruned Transducer（zipformer）**，兼顾流式低延迟与 Transformer 的长上下文建模，是当前端侧流式 ASR 的重要路线。

### 5.3 Whisper（2022）：大规模弱监督的纯 AED

OpenAI 的 Whisper 是 Speech-Transformer 谱系「堆规模」的极致形态：

* **架构上反而做减法**：回到最朴素的 vanilla Transformer Encoder-Decoder（无 CTC 分支、无 2D attention），前端两层 Conv1d 仅 2× 下采样，正弦 PE；
* 输入 128 维 log-Mel，固定 **30 秒窗口**（$T=1500$），多语言/多任务 Token（语言、时间戳、任务指令作为特殊 Token 前缀）；
* 68 万小时弱监督数据训练，Encoder-Decoder 从 tiny（39M）到 large-v3（1.55B，96 层编码器 + 32 层解码器，$d_{model}=1280$）；
* 损失即纯交叉熵（+ label smoothing 效果的权重衰减），证明**数据规模可以弥补结构先验的缺失**。

### 5.4 演化脉络小结

```
Speech-Transformer (2018, 2D attention + CTC 辅助)
        │
        ├──► Conformer (2020): + Depthwise Conv 局部建模, 非流式主流
        ├──► Transformer-Transducer (2020): + RNN-T 联合网络, 流式主流
        ├──► ESPnet / WeNet 范式: joint CTC-Attention 训练 + 联合解码成标配
        └──► Whisper (2022): 回归 vanilla 结构, 68万小时数据 + 30s 窗口, 通用大模型路线
```

## 6. 总结

* **算法架构**：首个纯 Transformer 端到端 ASR；编码器针对梅尔谱二维结构提出 **Time/Freq 分轴的 2D Attention**（复杂度从 $(TF)^2 d$ 降至 $TF(T+F)d$，约 74 倍缩减）+ 二维 PE + 前端 2D Conv 下采样；解码器为标准自回归音素解码器。
* **目标函数**：$\log P(Y|X)$ 的似然分解为 Attention（序列级、语言依赖）与 CTC（帧级、单调对齐）两个互补视图。
* **损失函数**：$\mathcal{L} = \lambda \mathcal{L}_{CTC} + (1-\lambda)\mathcal{L}_{ATT}$（典型 $\lambda = 0.3$），共享编码器同时接收 CTC 单调对齐梯度与 Attention 语言梯度，加速收敛并抑制注意力漂移；解码可用两分支混合分布做 joint decoding。
* **历史地位**：开启了「Transformer for Speech」整条技术线--Conformer 取其注意力加卷积，Transformer-Transducer 取其流式改造，Whisper 取其朴素 AED 加规模化数据。
* **面试要点**：为什么频率轴注意力后来被抛弃（频带相关性强、收益低，Conformer 只保留时间轴）；joint CTC-Attention 中 $\lambda$ 的物理意义与调参经验；2D attention 相比拉平 1D 的复杂度对比推导。
