# 1. Transformer 基础

## 1. 概述

**Transformer** 是 Google 在 2017 年论文 *Attention Is All You Need* 中提出的序列建模架构，彻底摒弃了 RNN 的循环结构与 CNN 的局部感受野，完全依赖**自注意力机制（Self-Attention）**来建模序列内任意两个位置之间的全局依赖。

其核心动机与优势：

* **并行计算**：RNN 必须沿时间轴逐步递推（$O(T)$ 步串行），而 Self-Attention 一次矩阵乘法即可完成全部位置的交互，训练吞吐量提升一个数量级。
* **长程依赖**：任意两个位置的信息交互路径长度为 $O(1)$，而 RNN 为 $O(T)$、CNN 为 $O(\log T)$ 或 $O(T/k)$，彻底缓解了梯度消失导致的长距离遗忘。
* **架构通用性**：Transformer 已成为 ASR（Speech-Transformer、Conformer、Whisper）、TTS、LLM 几乎所有语音/文本大模型的统一骨干。

在语音领域，Transformer 是理解 **Conformer（卷积+注意力混合）、Transformer-Transducer、Whisper、 wav2vec 2.0 后端**等模型的先修知识，是面试考察频率最高的架构基础。

## 2. 算法架构：整体结构（Encoder-Decoder）

原始 Transformer 采用 **Encoder-Decoder** 结构（即 AED，Attention-based Encoder-Decoder）：

* **Encoder**：由 $N=6$ 层相同的 Layer 堆叠，每层 = Self-Attention + FFN，输入源序列（如语音特征），输出与输入等长的隐状态序列。
* **Decoder**：由 $N=6$ 层相同的 Layer 堆叠，每层 = **Masked** Self-Attention + **Cross**-Attention + FFN，自回归地生成目标序列（如音素/字/词 Token）。

```
  输出概率 P(y_t|y_<t,X)
        ▲
  ┌─────┴──────┐
  │  Linear +  │  ← Softmax 前的投影至词表 V
  │  Softmax   │
  └─────▲──────┘
  ┌─────┴──────────────────────────┐
  │  Decoder Layer x N (N=6)       │
  │  ┌───────────────────────────┐ │
  │  │ Add & Norm                │ │◄──┐
  │  │ Feed-Forward (FFN)        │ │   │ Residual
  │  │ Add & Norm                │ │◄──┤ Connection
  │  │ Multi-Head Cross-Attention│◄┼───┤ Q=Decoder隐状态
  │  │ Add & Norm                │ │◄──┤ K,V=Encoder输出
  │  │ Masked Multi-Head         │ │   │ (因果掩码,只看 y_<t)
  │  │ Self-Attention            │ │◄──┘
  │  └───────────────────────────┘ │
  └───▲───────────────────▲────────┘
      │ y_<t + Positional │ Encoder 输出 h_1..h_T (K/V)
      │ Encoding          │
  ┌───┴───────────┐  ┌────┴────────────────────────┐
  │ 目标嵌入       │  │  Encoder Layer x N (N=6)    │
  │ Embedding     │  │  ┌─────────────────────────┐ │
  │ (×√d_model)   │  │  │ Add & Norm              │ │◄──┐
  └───────────────┘  │  │ Feed-Forward (FFN)      │ │   │
                     │  │ Add & Norm              │ │◄──┤
  输入语音特征/文本    │  │ Multi-Head              │ │   │
  x_1..x_T           │  │ Self-Attention          │ │◄──┘
  + Positional       │  └─────────────────────────┘ │
    Encoding         └─────────────────────────────┘
```

**典型超参数（base 版）**：$d_{model}=512$，$h=8$ 头，$d_{ff}=2048$，$N=6+6$ 层，总参数量约 **65M**（参数大头在 FFN：每层 FFN 有 $2 \times 512 \times 2048 \approx 2.1M$ 参数，12 层约 25M；注意力投影每层 4 个 $512\times512$ 矩阵约 1M，12 层约 12M；其余为 Embedding 与 LayerNorm）。

## 3. 多头注意力机制（Multi-Head Attention, MHA）

### 3.1 Scaled Dot-Product Attention 推导

注意力本质是一个 **查询-检索** 过程：给定 Query $Q$、Key $K$、Value $V$，输出是 $V$ 的加权求和，权重为 $Q$ 与 $K$ 的相似度。

**第一步：线性投影生成 QKV。** 输入序列 $X \in \mathbb{R}^{T \times d_{model}}$ 分别乘以三个可学习矩阵：

$$Q = XW^Q, \quad K = XW^K, \quad V = XW^V$$

其中 $W^Q, W^K \in \mathbb{R}^{d_{model} \times d_k}$，$W^V \in \mathbb{R}^{d_{model} \times d_v}$。

**第二步：计算注意力分数。** 第 $i$ 个 Query 对第 $j$ 个 Key 的原始分数为点积：

$$e_{ij} = q_i \cdot k_j = \sum_{l=1}^{d_k} q_{il} k_{jl}$$

**第三步：缩放（Scale）。** 除以 $\sqrt{d_k}$。推导原因：若 $q, k$ 各分量是均值为 0、方差为 1 的独立随机变量，则 $e_{ij}$ 的方差为 $d_k$：

$$\text{Var}(e_{ij}) = \sum_{l=1}^{d_k} \text{Var}(q_{il} k_{jl}) = d_k$$

当 $d_k$ 较大（如 64）时 $e_{ij}$ 方差达 64，Softmax 会进入饱和区（梯度趋近于 0），除以 $\sqrt{d_k}$ 将方差归一化回 1。

**第四步：Softmax 加权求和。**

$$\alpha_{ij} = \frac{\exp(e_{ij}/\sqrt{d_k})}{\sum_{j'=1}^{T}\exp(e_{ij'}/\sqrt{d_k})}, \qquad \text{output}_i = \sum_{j=1}^{T} \alpha_{ij} v_j$$

矩阵形式合并为：

$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V$$

### 3.2 多头机制（Multi-Head）

将 $d_{model}=512$ 均匀拆分为 $h=8$ 个子空间，每个头的维度 $d_k = d_v = d_{model}/h = 64$，各头独立做注意力后拼接：

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W^O$$

$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

* **为什么多头**：单头注意力只能学到一种对齐模式；多头允许模型在**不同子空间**同时关注不同位置关系——例如 ASR 中有的头对齐相邻帧（声学平滑），有的头对齐长距离上下文（语言学约束）。
* **参数量不变**：8 个 $512 \times 64$ 的投影等价于 1 个 $512 \times 512$ 的投影，多头几乎不增加参数，只增加表达力。

### 3.3 三种注意力使用方式

| 类型 | Q 来源 | K/V 来源 | 是否有因果掩码 | 用途 |
| --- | --- | --- | --- | --- |
| Self-Attention (Encoder) | Encoder 输入 | Encoder 输入 | 无（双向） | 声学/文本上下文建模 |
| Masked Self-Attention (Decoder) | Decoder 输入 | Decoder 输入 | **有**（下三角掩码 $-\infty$） | 自回归生成 |
| Cross-Attention (Decoder) | Decoder 隐状态 | **Encoder 输出** | 无 | 声学与文本对齐（AED 核心） |

## 4. FFN 与 LayerNorm（Pre-LN vs Post-LN）

### 4.1 逐位置前馈网络（Position-wise FFN）

$$\text{FFN}(x) = \max(0,\ xW_1 + b_1)W_2 + b_2$$

* 两层线性变换夹 ReLU（现代实现多用 **GELU / SwiGLU**），中间扩展维度 $d_{ff}=4 d_{model}$。
* 「逐位置」指每个时间步独立共享同一组参数，**不跨时间交互**——跨时间交互完全由注意力负责，二者分工明确。
* FFN 常被视作模型存储「知识」的主要载体，参数量约占整层的 **2/3**。

### 4.2 LayerNorm 与 Pre/Post-LN

LayerNorm 对每个样本每个时间步的 $d_{model}$ 维向量做归一化：

$$\text{LN}(x) = \gamma \odot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta, \quad \mu = \frac{1}{d}\sum_{i} x_i,\ \sigma^2 = \frac{1}{d}\sum_i (x_i - \mu)^2$$

> **为什么不用 BatchNorm**：语音序列长度可变、padding 位置无效，BatchNorm 沿 batch 统计会受变长与 batch 内分布差异干扰，且流式推理时 batch=1 无法维护统计量；LayerNorm 与序列长度和 batch 大小完全解耦。

两种连接顺序：

$$\text{Post-LN (原始)}: \quad x_{l+1} = \text{LN}(x_l + \text{Sublayer}(x_l))$$

$$\text{Pre-LN (主流)}: \quad x_{l+1} = x_l + \text{Sublayer}(\text{LN}(x_l))$$

* **Post-LN**：输出始终经过归一化，梯度稳定但**深层（>12 层）难以训练**，需 learning rate warmup 精细调节。
* **Pre-LN**：残差主干上是纯恒等映射，梯度可无衰减直通底层，训练更稳定、可省去 warmup；缺点是输出方差随层数增长，最终需额外 Final LN。**现代语音模型（Conformer、Whisper、多数 LLM）几乎都采用 Pre-LN（或其变体 RMSNorm）**。

## 5. 位置编码（Positional Encoding）

Self-Attention 本身是置换不变的（打乱输入顺序输出同步打乱），必须显式注入位置信息。

### 5.1 正弦/余弦编码（Sinusoidal，原始版）

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

* 不同维度对应不同周期的正弦波（波长从 $2\pi$ 到 $10000 \cdot 2\pi$ 几何递增），类似二进制计数的多尺度编码。
* 关键性质：$PE_{pos+k}$ 可以表示为 $PE_{pos}$ 的线性变换（旋转），使模型能学到**相对偏移**关系；且可外推到训练未见的长度。
* 直接与 Embedding 相加：$x = \text{Embedding}(token) + PE$。

### 5.2 相对位置编码（Relative PE）

绝对编码在长句上泛化差。相对位置编码让注意力分数直接依赖 **$q_i$ 与 $k_j$ 的位置差 $i-j$** 而非绝对位置。代表工作：

* **Shaw et al. 2018 / Transformer-XL**：在注意力分数中加入可学习的相对位置嵌入 $a_{ij} = a_{i-j}$，把 $q_i \cdot k_j$ 分解出相对偏置项。
* **T5-style 相对偏置**：直接用一个标量桶函数 $b(i-j)$ 加到注意力 logits 上，简单有效，Conformer/Speech-Transformer 系常用此类做法。

### 5.3 RoPE 旋转位置编码（LLM 时代主流）

**RoPE（Rotary Position Embedding）** 将 $q, k$ 向量按维度两两配对，视作复平面上的向量，乘以与位置成正比的旋转矩阵：

$$q_m' = R(m\theta) q_m, \quad k_n' = R(n\theta) k_n, \quad \theta_i = 10000^{-2i/d}$$

核心性质：旋转保内积结构性，注意力分数只依赖**相对旋转角** $q_m^{\top} R(n\theta)^{\top} R(m\theta) k_n = q^{\top} R((m-n)\theta) k$，天然编码相对位置，且不引入额外可学习参数。LLaMA、Qwen、SenseVoice 等现代模型标配。

### 5.4 ALiBi（Attention with Linear Biases）

不做任何位置嵌入，直接在注意力分数上**线性惩罚距离**：

$$e_{ij} \leftarrow e_{ij} - m_h \cdot (i - j), \quad m_h \in \{1/2^{8h/H}, \dots\}$$

每个头一个斜率 $m_h$（几何序列），距离越远分数惩罚越大。实现零成本、外推（length extrapolation）能力极强，BLOOM / MPT 等模型采用。

## 6. 复杂度分析：$O(T^2 d)$

设序列长 $T$、维度 $d$，单层各模块计算量（FLOPs 级别）：

| 模块 | 计算复杂度 | 参数量 | 关键矩阵 |
| --- | --- | --- | --- |
| Self-Attention | $O(T^2 d + T d^2)$ | $4 d^2$（QKVO 投影） | $QK^{\top}$ 为 $T \times T$ |
| Cross-Attention | $O(T U d + (T+U) d^2)$ | $4 d^2$ | 分数矩阵 $T \times U$ |
| FFN | $O(T d^2 \cdot 8)$（$d_{ff}=4d$，两次投影） | $8 d^2$ | 逐位置，无 $T^2$ 项 |

**注意力中 $T^2$ 项的来源**：$\text{Softmax}(QK^{\top})$ 需要计算全部 $T \times T$ 个位置对的分数，且注意力矩阵本身的显存占用也是 $O(T^2)$（多头则为 $O(h T^2)$）。

**数值量级示例（ASR 场景）**：10 秒语音，帧移 10ms，$T = 1000$ 帧；经 4 倍下采样后 $T=250$。

* 下采样前：$T^2 = 10^6$ 个分数对/头/层，仅注意力分数矩阵就 $8 \times 10^6$ 元素/层（float16 约 16MB），24 层训练时（含反向）显存压力巨大。
* 下采样后：$T^2 = 6.25 \times 10^4$，缩减 **16 倍**——这就是几乎所有语音 Transformer 前端都带卷积下采样（如 4×/8× subsampling）的根本原因。

对比：RNN 单层为 $O(T d^2)$ 且无 $T^2$ 项，但无法并行；FFT 类线性注意力可降到 $O(T \log T \cdot d)$，属于后续高效化方向（Performer、线性注意力等）。

## 7. 目标函数：序列条件似然

Decoder 是自回归语言模型形式，训练目标是**最大化给定源序列条件下目标序列的条件似然**。设目标序列 $Y = (y_1, \dots, y_U)$，模型分解为：

$$P(Y \mid X) = \prod_{t=1}^{U} P(y_t \mid y_{<t}, X)$$

其中每步分布由 Decoder 顶层 Softmax 给出：

$$P(y_t = v \mid y_{<t}, X) = \frac{\exp(z_{t,v})}{\sum_{v'=1}^{V} \exp(z_{t,v'})}$$

取负对数得到训练目标（最小化）：

$$\mathcal{L} = -\sum_{t=1}^{U} \log P(y_t \mid y_{<t}, X)$$

这**正是交叉熵（Cross-Entropy）**：负对数似然在 one-hot 标签下与 CE 完全等价。整个语料级目标即 $\mathbb{E}_{(X,Y)}[-\log P(Y|X)]$，也就是最小化模型分布与数据分布的 KL 散度。

### 7.1 Teacher Forcing

训练时 Decoder 输入使用**真实标签的前缀** $y_{<t}$（而非模型自身预测），配合因果掩码实现一步前向并行计算所有位置的损失（避免 $U$ 步串行）。代价是 exposure bias（训练见真值、推理见自身预测的分布失配），语音中常用 scheduled sampling / 最小错误率训练缓解。

### 7.2 Label Smoothing

对 one-hot 标签做平滑：真实类概率 $1-\epsilon$，其余类均分 $\epsilon/(V-1)$（原论文 $\epsilon = 0.1$）。将目标分布 $q$ 改为：

$$q'(k) = (1-\epsilon)\cdot \mathbb{1}[k = y_t] + \frac{\epsilon}{V}$$

作用：防止 logits 过度自信、软化过度尖锐的 softmax、提升泛化与 BLEU/WER（原论文 BLEU +1.x）。注意 label smoothing 下训练 loss 的理论下界不再是 0，而是 $\mathcal{L}_{min} \approx \epsilon \log \frac{\epsilon}{(V-1)} + (1-\epsilon)\log(1-\epsilon)$ 量级的正数。

## 8. 损失函数：交叉熵与数值稳定实现

### 8.1 CE 损失公式

对单个时间步，标签为 $y_t$（one-hot 记为 $q$，模型 log 概率为 $\log p$）：

$$\mathcal{L}_{CE}(t) = -\sum_{v=1}^{V} q_v \log p_v = -\log p_{y_t} = -z_{y_t} + \log\sum_{v'=1}^{V} \exp(z_{v'})$$

### 8.2 数值稳定性两要点

**（1）log-softmax 合并计算**：若先 `softmax` 再取 `log`，当 $z_v$ 很大时 $\exp$ 溢出、很小时 $\log(0)$ 下溢。稳定做法是先减去行最大值再合并：

$$\log \text{Softmax}(z)_v = z_v - \max_{v'} z_{v'} - \log \sum_{v'} \exp(z_{v'} - \max_{v'} z_{v'})$$

由于减去常数后 softmax 值不变（分子分母同乘 $\exp(-m)$），上式恒等且 $\exp$ 的参数恒 $\le 0$，不会上溢。

**（2）NLL 直接取对数概率**：PyTorch 中 `F.cross_entropy = log_softmax + nll_loss` 融合为单核，既避免中间 `exp`/`log` 分离的精度损失，也不产生 $T \times V$ 的概率中间张量的两次物化。

### 8.3 PyTorch 实现（含 label smoothing 与数值稳定性）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class TransformerLoss(nn.Module):
    """AED 式 Transformer 的 CE 损失: 支持 ignore_index / label smoothing / 逐样本长度归一"""
    def __init__(self, vocab_size: int, pad_id: int = 0, smoothing: float = 0.1):
        super().__init__()
        self.vocab_size = vocab_size
        self.pad_id = pad_id
        self.smoothing = smoothing

    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        """
        logits:  [B, U, V]  Decoder 输出（未经 softmax）
        targets: [B, U]     真实标签序列（含 pad）
        """
        B, U, V = logits.shape
        # 展平为 [B*U, V] —— F.cross_entropy 内部即执行
        # log_softmax(x - x.max(dim=-1, keepdim=True)) + nll 的融合稳定实现
        loss = F.cross_entropy(
            logits.reshape(-1, V),
            targets.reshape(-1),
            ignore_index=self.pad_id,      # pad 位置不计损失
            reduction="none",              # 先逐 token，便于长度归一
            label_smoothing=self.smoothing,
        ).view(B, U)

        # 按“有效 token 数”归一（而非 B*U），避免 padding 稀释梯度
        token_mask = targets.ne(self.pad_id).float()
        nll = (loss * token_mask).sum() / token_mask.sum().clamp(min=1.0)
        return nll


# ==================== 手写数值稳定版（面试加分项） ====================
def stable_cross_entropy(logits: torch.Tensor, target: torch.Tensor) -> float:
    """
    logits: [V]  单个时间步的原始输出
    target: 标量 index
    """
    m = logits.max()                                   # 1. 减 max 防 exp 上溢
    z = logits - m
    log_z_sum = torch.logsumexp(z, dim=0)              # 2. logsumexp 内部稳定实现
    loss = -(z[target] - log_z_sum)                    # 3. -log p_target = z_max - z_target
    return loss.item()


if __name__ == "__main__":
    torch.manual_seed(0)
    B, U, V = 4, 50, 5000
    logits = torch.randn(B, U, V, requires_grad=True)
    targets = torch.randint(1, V, (B, U))
    targets[:, 40:] = 0                                # 模拟 padding

    crit = TransformerLoss(V, pad_id=0, smoothing=0.1)
    loss = crit(logits, targets)
    print(f"CE loss (label smoothing=0.1): {loss.item():.4f}")

    # 极端 logits 下的稳定性验证: 直接 softmax+log 会溢出为 inf/0
    huge = torch.tensor([1e4, 0.0, -1e4])
    print(f"stable CE of huge logits: {stable_cross_entropy(huge, torch.tensor(0)):.4f}")  # ≈ 0.0, 无 inf
    print(f"naive log(softmax)        : {torch.log(torch.softmax(huge, 0))[0].item():.4f}")  # 可能 nan
```

## 9. 语音场景适配点

直接把 NLP Transformer 用于音频有三大不适配，工业方案均有定制：

### 9.1 下采样（Subsampling）：压缩 $T$

10ms 帧移产生 $T=1000$（10 秒音频），$O(T^2)$ 注意力代价过高，且音素级 token 通常仅 30~50 个，帧级分辨率严重冗余。标准做法是**前端卷积下采样**：

* **Embedding + 2 层 strided Conv（Speech-Transformer / Conformer 标准 frontend）**：Conv2d stride=2 两层共 **4× 下采样**，$T: 1000 \to 250$，注意力开销降 16 倍。
* **Whisper**：两层 Conv1d stride 1/2，共 2× 下采样，配合 30 秒固定窗口（$T=1500$）。
* **Zipformer**：多级下采样（不同 stride 并行），在不同时间分辨率上分别建模。
* 代价：下采样倍数过高会损失细粒度对齐信息（流式场景延迟下界 = 下采样倍数 × 帧移）。

### 9.2 梅尔特征输入与特征变换

* 输入一般为 **80 维 log-Mel Fbank**（Whisper 用 128 维，帧移 10ms）。经 `nn.Linear(80, d_model)`（或 Conv1d）投影到模型维度后加入位置编码。
* Mel 谱是**二维图像结构**（时间 × 频率），原始 Speech-Transformer 据此提出 2D attention 分别在两个轴向建模（见下一篇文章详述）。
* 现代方案（wav2vec 2.0 / HuBERT）则直接输入原始波形，用 CNN 特征提取器（7 层 Conv，总下采样 320×，约 20ms 感受野）替代手工 Fbank，实现端到端学习。

### 9.3 注意力掩码与长音频

* 训练长音频（>30s）时全局注意力既昂贵又会「注意力分散」；Whisper 直接固定 30s 窗口对齐训练；流式模型（Transformer-Transducer、Chunk-based Conformer）用 **chunk mask** 限制每帧只能看到当前 chunk + 左侧上下文。

## 10. 总结

* **架构**：Encoder（双向 Self-Attention + FFN）与 Decoder（Masked Self-Attention + Cross-Attention + FFN）各 $N$ 层堆叠；核心公式 $\text{Softmax}(QK^{\top}/\sqrt{d_k})V$，多头在子空间并行捕捉多种对齐模式。
* **位置编码**：正弦式（绝对、可外推）→ 相对位置（偏置加在分数上）→ **RoPE**（旋转保内积、LLM 主流）→ **ALiBi**（线性距离惩罚、外推强）。
* **目标函数**：序列条件似然的负对数 $\mathcal{L} = -\sum_t \log P(y_t|y_{<t}, X)$，配合 Teacher Forcing 并行训练与 label smoothing 正则。
* **损失函数**：即交叉熵；工程上必须用 log-softmax 融合 + 减最大值实现数值稳定（`F.cross_entropy` 已内置）。
* **复杂度**：注意力 $O(T^2 d)$ 是瓶颈，语音中靠前端 4× 卷积下采样把 $T$ 压到 200~300 量级使其可训练、可部署。
* **面试要点**：能推导缩放因子 $\sqrt{d_k}$ 的方差来源、说清 Pre/Post-LN 训练稳定性差异、解释为什么语音必须下采样，是 Transformer 三连问的高频考点。
