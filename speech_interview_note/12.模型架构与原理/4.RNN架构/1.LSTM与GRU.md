# 1. LSTM 与 GRU

## 1. 概述

**RNN（循环神经网络）** 是 Transformer 出现之前语音建模的主流架构：声学建模（GMM-HMM 时代的 DNN-HMM 混合系统中的 RNN、LSTM-HMM）、语言模型（RNNLM）、以及端到端模型（LAS、RNN-T、DeepSpeech）都以其为骨干。

其核心思想是**沿时间轴递推的隐状态**：

$$h_t = f(W_h h_{t-1} + W_x x_t + b)$$

* **优势**：天然处理变长序列；参数沿时间共享；对流式（因果）推理极其友好——每帧只依赖上一帧的隐状态，$O(1)$ 内存。
* **致命缺陷**：BPTT 中梯度连乘 $W_h^{T}$ 导致**梯度消失/爆炸**，长程依赖（>100 帧）难以学习；训练必须沿时间串行，无法并行。

**LSTM**（Hochreiter & Schmidhuber, 1997）通过**门控机制 + 细胞状态**解决梯度消失，**GRU**（Cho et al., 2014）是它的简化版。即便在今天，LSTM 仍活在 RNN-T 的 Prediction Network、ConvTasNet、语音增强等对因果性/算力敏感的场景中，是面试考察 RNN 基础的核心考点。

## 2. 算法架构

### 2.1 为什么 Vanilla RNN 会梯度消失

展开 BPTT，损失对 $W_h$ 的梯度包含连乘项：

$$\frac{\partial \mathcal{L}_T}{\partial W_h} = \sum_{t=1}^{T} \frac{\partial \mathcal{L}_T}{\partial h_T}\frac{\partial h_T}{\partial h_t}\frac{\partial h_t}{\partial W_h}, \qquad \frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^{T} \frac{\partial h_k}{\partial h_{k-1}} = \prod_{k=t+1}^{T} W_h^T \cdot \text{diag}(f'(a_k))$$

* $|\lambda_{\max}(W_h)| < 1$（配合 $|f'| \le 1$）时连乘指数衰减 -> **梯度消失**，远处的信息学不到；
* $|\lambda_{\max}(W_h)| > 1$ 时连乘指数增长 -> **梯度爆炸**（可用梯度裁剪缓解，但消失不行）。

**LSTM 的解法不是消灭连乘，而是让连乘项≈1**：细胞状态 $c_t$ 到 $c_{t-1}$ 的雅可比为对角矩阵 $\text{diag}(f_t)$（遗忘门输出，可学习到接近 1），梯度可以**无衰减地沿细胞状态直通**（类比 ResNet 的 identity shortcut，LSTM 比 ResNet 早了 18 年）。

### 2.2 LSTM 门控结构

```
c_{t-1} ───────(× f_t)───(＋ i_t⊙g_t)──────► c_t ──────────────┐
   │            ▲  ▲        ▲  ▲                               │ tanh
   │            │  │        │  │                               ▼
   │           遗忘门      输入门  候选        ┌─────────┐   h_t = o_t ⊙ tanh(c_t)
h_{t-1} ──► [sigmoid sigmoid tanh sigmoid] ◄──┤ x_t     │
                f_t    i_t    g_t    o_t      └─────────┘
```

四个门的公式（所有门的输入都是 $[h_{t-1}; x_t]$ 拼接）：

$$\begin{aligned} f_t &= \sigma(W_f [h_{t-1}, x_t] + b_f) & \text{遗忘门：保留多少旧记忆} \\ i_t &= \sigma(W_i [h_{t-1}, x_t] + b_i) & \text{输入门：写入多少新信息} \\ g_t &= \tanh(W_g [h_{t-1}, x_t] + b_g) & \text{候选记忆（cell candidate）} \\ o_t &= \sigma(W_o [h_{t-1}, x_t] + b_o) & \text{输出门：暴露多少记忆给外面} \\ c_t &= f_t \odot c_{t-1} + i_t \odot g_t & \text{细胞状态更新（加法！梯度高速路）} \\ h_t &= o_t \odot \tanh(c_t) & \text{隐状态输出} \end{aligned}$$

面试要点：

* **$c_t$ 的更新是加法而非矩阵乘法**，这是梯度直通的关键：$\partial c_t / \partial c_{t-1} = \text{diag}(f_t)$，无 $W$ 连乘；
* **peephole 连接**（Gers & Schmidhuber）：门计算额外看 $c_{t-1}$，部分任务有小幅提升，工程上少用；
* 初始化技巧：**遗忘门偏置 $b_f$ 初始化为 1~2**，训练初期 $f_t \approx 1$，记忆不轻易丢失（PyTorch 需手动设置）。

### 2.3 GRU：LSTM 的简化

GRU 合并了细胞状态与隐状态，把四门减为两门：

$$\begin{aligned} z_t &= \sigma(W_z [h_{t-1}, x_t]) & \text{更新门（≈ 遗忘门 + 输入门联动）} \\ r_t &= \sigma(W_r [h_{t-1}, x_t]) & \text{重置门：候选状态看多少历史} \\ \tilde{h}_t &= \tanh(W [r_t \odot h_{t-1}, x_t]) & \text{候选状态} \\ h_t &= (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t & \text{插值更新（门控直通）} \end{aligned}$$

| 对比项 | LSTM | GRU |
| --- | --- | --- |
| 门数量 | 4（$f, i, o$ + candidate） | 2（$z, r$） |
| 状态 | $c_t$ 与 $h_t$ 分离 | 单一 $h_t$ |
| 参数量 | $4 d(d+x) + 4d$ | $3 d(d+x) + 3d$（约少 25%） |
| 表达能力 | 理论上更强（输出门独立控制暴露） | 略弱，中小数据集常打平 |
| 训练速度 | 慢 | 快，小数据更不易过拟合 |

经验结论：语音任务上二者差距通常在 0.1 个点 WER 以内；**GRU 少一个门、推理更快**，端侧常用；LSTM 在 RNN-T predictor、语言模型等需要长记忆的场合仍是默认。

### 2.4 双向与深层 RNN

* **双向（BLSTM）**：正向 $\overrightarrow{h}_t$ 与反向 $\overleftarrow{h}_t$ 拼接，非流式 ASR 的标配（如 BLSTM-HMM、LAS encoder）；**流式场景必须放弃反向**或用时延双向（delayed BLSTM）。
* **深层堆叠**：多层 LSTM 串联（3~5 层），也常用残差连接缓解深 RNN 的优化困难。
* **Pyramid/Bucketing RNN**：LAS 中每层时间下采样 2 倍，缩短解码注意力长度——这是后来卷积 subsampling 的前身。

## 3. 目标函数

RNN 是纯架构，目标函数由任务决定，语音领域常见搭配：

| 任务 | 输出 | 目标/损失 |
| --- | --- | --- |
| 帧级声学模型（DNN-HMM 混合） | 每帧 senone 后验 | CE（帧对齐标签由 GMM-HMM 强制对齐产生） |
| LAS / AED 解码器 | 自回归 token | label-smoothed CE |
| RNN-T | RNN-T 负对数似然 | 前向-后向计算的 $\mathcal{L}_{RNNT}$（详见 `02/3.RNN-Transducer`） |
| RNN 语言模型 | 下一词概率 | CE，用于 shallow fusion / rescoring |
| 说话人/分类 | 池化后嵌入 | CE / AAM-Softmax |

RNN 特有的训练细节：

* ** truncated BPTT（截断 BPTT）**：长音频按 20~50 帧截断反传，隐状态跨段传递（carry over），兼顾效率与长依赖；
* **梯度裁剪（gradient clipping）**：LSTM 也仍有梯度爆炸风险，语音训练普遍按全局范数裁剪（如 clip norm = 5）。

## 4. 损失函数与 PyTorch 实现要点

```python
import torch
import torch.nn as nn

class LSTMASR(nn.Module):
    def __init__(self, feat_dim=80, hidden=512, layers=5, vocab=5000, dropout=0.2):
        super().__init__()
        self.rnn = nn.LSTM(feat_dim, hidden, layers,
                           batch_first=True, bidirectional=True,
                           dropout=dropout)
        self.classifier = nn.Linear(hidden * 2, vocab)

    def forward(self, x, hx=None):          # x: (B, T, 80)
        h, _ = self.rnn(x, hx)              # (B, T, 2*hidden)
        return self.classifier(h).log_softmax(-1)

# 遗忘门偏置初始化为 1（关键技巧）
for name, p in model.rnn.named_parameters():
    if "bias_ih" in name:
        n = p.numel() // 4                  # LSTM: [i, f, g, o] 四段
        torch.nn.init.zeros_(p)
        p.data[n:2*n].fill_(1.0)            # f 段置 1
    elif "bias_hh" in name:
        torch.nn.init.zeros_(p)
```

要点：

* PyTorch 的 `nn.LSTM` 把四门打包成一个矩阵（`weight_ih_l0` 形状 $4d \times d$，顺序为 **i, f, g, o**），做门级操作（如改偏置、单调 RNN-T）时必须知道这个布局；
* `PackedSequence`（`pack_padded_sequence`）处理变长 batch，避免 padding 帧污染隐状态；
* 流式推理用 `nn.LSTM` 的 `(h_0, c_0)` 状态接口逐 chunk 递推，配合缓存即是流式 ASR 的最简实现。

## 5. 实验效果与现状

* LibriSpeech 时代：BLSTM-HMM 混合系统（5×1024 BLSTM）test-clean WER ≈ 4.0~5.0；LAS（4 层 BLSTM pyramid encoder + 2 层 LSTM decoder）≈ 5.0（+LM 后 ~4.5）；
* 对比 Conformer 同参数量约差 1.5~2 个点 WER，训练吞吐差 5~10 倍（无法并行）；
* 但 RNN/LSTM 并未消失：**RNN-T 的 predictor 至今是 1~2 层 LSTM**（也可换 FFN，但 LSTM 记忆标签历史更有利）；Whisper 之前的流式工业系统大量使用 BLSTM；ConvTasNet 等语音分离模型用 1 层 BLSTM 做瓶颈。

---

## 6. 总结

* **记忆点**：LSTM = 遗忘门 × 旧记忆 + 输入门 × 候选（**加法更新是梯度高速路**）；GRU = 更新门插值 $(1-z)h_{t-1} + z\tilde{h}$。
* **梯度分析是最高频面试题**：vanilla RNN 连乘 $W_h^T$ 指数衰减；LSTM 的 $\partial c_t/\partial c_{t-1} = \text{diag}(f_t)$ 无权重连乘，本质是**可学习的 identity shortcut**。
* **工程要点**：遗忘门偏置初始化为 1；truncated BPTT；梯度裁剪；`PackedSequence`；流式逐 chunk 状态传递。
* **历史定位**：RNN 输给 Transformer 的原因是**串行不可并行**（吞吐）而非精度上限；LSTM 在流式、predictor、算力受限场景仍有不可替代性。
