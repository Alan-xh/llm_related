# 2. LAS 与 RNN-T 架构

## 1. 概述

RNN 时代的两个端到端里程碑架构：

* **LAS（Listen, Attend and Spell）**（Chan et al., 2016）：第一个完整的 attention-based encoder-decoder（AED）语音识别模型，编码器 RNN 逐层降采样，解码器注意力对齐 + 自回归拼写，**非流式精度高但无法流式**。
* **RNN-T（RNN Transducer）**（Graves, 2012 提出、2019 随 Google 流式系统复兴）：编码器 + 预测器 + 联合网络的**单调对齐**架构，天然支持**流式双向实时**（一边放音频一边出字、可回改中间结果），是工业界流式 ASR 的绝对主流（详见 `02/3.RNN-Transducer`，本篇侧重架构视角）。

连同 CTC，它们构成 E2E ASR 的三大范式；后续的 Conformer-Transducer、Transformer-AED（Whisper）都只是把 RNN 骨干替换为注意力架构，**范式本身不变**。

---

## 2. 算法架构

### 2.1 LAS：Listen, Attend and Spell

```
音频 ─► Listen (Encoder)          ─► Spell (Decoder, 自回归)
        Pyramid BLSTM ×4                LSTM ×2 + Attention
        每层时间减半 (T → T/16)          每步出 1 个字/词片
             │                               ▲
             │      h_1..h_S (S=T/16)        │ attention 对齐
             └───────────────────────────────┘
```

**Listen（编码器）**：底层金字塔 BLSTM，每层双向 LSTM 后做时间维 2 倍降采样（相邻帧拼接），4 层共降 16 倍。动机：T≈1000 帧的注意力矩阵太长，且 60ms 分辨率足够区分音素。这是**现代卷积 subsampling（降 4 倍）的思想前身**。

**Spell（解码器）**：两层 LSTM，attention 机制（MLP attention，先于 dot-product 流行）：

$$\begin{aligned} e_{t,s} &= v^T \tanh(W h_s^{enc} + U y_{t-1}^{dec}) \\ \alpha_{t,s} &= \text{softmax}_s(e_{t,s}), \quad c_t = \sum_s \alpha_{t,s} h_s^{enc} \\ P(y_t \mid y_{<t}, x) &= \text{Softmax}(\text{MaxOut}(\text{LSTM}([y_{t-1}, c_t]))) \end{aligned}$$

特点与问题：

* **无单调约束**：attention 可任意跳动，长音频上易出现**对齐漂移（attention derailment）**--训练早期 attention 乱跳导致 loss 不降；缓解手段：注意力平滑正则、单调注意力（MoChA）。
* **延迟不可控**：必须等整句（或大 chunk）编码完才能解码，本质上非流式。
* **输出语言建模能力强**：自带 LM，甚至能「纠正」声学上模糊的拼写（subword 级），这是 CTC 做不到的。

### 2.2 RNN-T：编码器 + 预测器 + 联合网络

```
音频 x ─► Encoder (BLSTM/T.编码器) ─► h_t (t = 1..T 帧轴)
                                        │
标签 y_<u ─► Prediction Network (LSTM) ─► p_u (u = 1..U 标签轴)
                                        │
              Joint: z_{t,u} = tanh(W h_t + V p_u)
                                        │
              P(k | t, u) = Softmax(W_o z_{t,u})     ← T×U×(V+1) 概率网格
```

三大组件：

* **Encoder**：音频帧编码（原版 BLSTM，现代为 Conformer/Zipformer），输出时间轴 $t$；
* **Prediction Network**：1~2 层 LSTM，输入已发射的标签 $y_{<u}$，输出标签轴 $u$--**一个内置的神经 LM**，但只看已发射标签、不看未来音频；
* **Joint Network**：逐元素相加（或拼接）+ tanh + softmax，产生 $T \times U \times (V+1)$ 的发射概率（$V+1$ 含空白 $\varnothing$）。

**解码（贪心）**：网格上从 $(1, 0)$ 出发，每步比较 $P(y | t, u)$ 与 $P(\varnothing | t, u)$：

* 发射非空白 -> 输出符号，$u \leftarrow u+1$（$t$ 不动）；
* 发射空白 -> **时间前进** $t \leftarrow t+1$（$u$ 不动），表示「这一帧没有新字」。

于是**同一帧上可以连续出多个字**（快语速），也可以**多帧不出字**（静音），流式时每来一帧编码即可增量计算，已发射结果可被后续重新解码修正（双下发/部分假设）。

### 2.3 三大范式对比（高频面试题）

| | CTC | LAS (AED) | RNN-T |
| --- | --- | --- | --- |
| 条件独立假设 | 输出符号间条件独立（无 LM） | 无 | 预测器建模标签依赖（有 LM） |
| 对齐假设 | 单调、多对一 | 无单调约束 | 单调、多对一 |
| 空白符号 | 有（帧间对齐） | 无 | 有（时间推进） |
| 流式 | 天然流式但每帧只出一字 | 难流式 | **天然流式且延迟可控** |
| 长音频稳定性 | 稳定 | attention 漂移风险 | 稳定（单调） |
| 训练难度 | 简单 | 需 attention 预热 | 前向-后向较复杂、显存高 |

## 3. 目标函数

**LAS**：标准自回归负对数似然（label smoothing $\epsilon=0.1$ 常用）：

$$\mathcal{L}_{LAS} = -\sum_{u} \log P(y_u \mid y_{<u}, h_{1:S})$$

**RNN-T**：对所有单调对齐路径求和的负对数似然。定义发射符号序列 $\pi \in (V \cup \varnothing)^{*}$ 满足移除空白后等于 $y$，路径概率为网格上逐步转移概率之积：

$$P(y \mid x) = \sum_{\pi: \mathcal{B}(\pi) = y} P(\pi \mid x), \qquad \mathcal{L}_{RNNT} = -\log P(y \mid x)$$

与 CTC 的关键区别：CTC 假设**帧间条件独立**（每帧概率独立连乘），RNN-T 的转移概率 $P(k|t,u)$ 依赖标签历史 $u$，因此**对齐路径共享语言模型信息**，同等数据下 WER 更低。

## 4. 损失函数：RNN-T 前向-后向计算

在 $T \times U$ 网格上定义前向变量 $\alpha(t, u)$ = 走到 $(t, u)$ 且已发射 $y_{1:u}$ 的路径概率和：

$$\begin{aligned} \alpha(t, u) &= \alpha(t-1, u) \cdot P(\varnothing \mid t-1, u) \\ &\quad + \alpha(t, u-1) \cdot P(y_u \mid t, u-1) \end{aligned}$$

$$\mathcal{L}_{RNNT} = -\log \alpha(T, U) \cdot P(\varnothing \mid T, U)$$

* 计算需在 log 域进行（logaddexp），$O(TU)$ 复杂度；
* 工程实现：`warprnct_numba` / `torchaudio.transforms.RNNTLoss`，GPU 上配合 **fused joint + 降显存技巧**（分段计算 log-softmax，避免实体化 $T \times U \times (V+1)$ 张量）；
* **流式/稳定性变体**：每个时间步后强制发射的 **RNN-T with monotonic attention**、限制对齐带宽的 **pruned RNN-T（Zipformer 采用）** 等。

LAS 侧的辅助损失：**joint CTC-attention**（encoder 同时接 CTC，多任务正则化对齐，详见 `12/1.Transformer架构/2.Speech-Transformer`）。

## 5. 实验效果（LibriSpeech test-clean/other WER）

| 模型 | 参数量 | test-clean | test-other |
| --- | --- | --- | --- |
| LAS (4 层 pyramid + 2 层 LSTM) | ~100M | 5.05 / +LM 4.51 | 13.28 |
| DeepSpeech2（CNN+BI-GRU） | ~300M | 5.33 | 10.87 |
| LSTM-T（原版流式配置） | - | 9.0+ | - |
| Conformer-Transducer-L（同范式换骨干） | 118.8M | 2.62 | 5.87 |

* 同为 RNN 骨干时 RNN-T 略逊于 LAS（预测器 LM 弱于完整 decoder LM），但流式价值使工业界倒向 Transducer；
* 换成 Conformer/Zipformer 编码器后范式潜力被完全释放--说明**三大范式的差异是结构先验，最终精度由骨干与数据决定**。

---

## 6. 总结

* **LAS 记忆点**：pyramid encoder 降采样（subsampling 前身）+ attention 对齐 + 自回归拼写；痛点是 attention 漂移与不可流式。
* **RNN-T 记忆点**：编码器（时间轴）+ 预测器（标签轴，内置 LM）+ Joint 的 $T \times U$ 网格；解码规则「发射字 $u{+}{=}1$、空白 $t{+}{=}1$」；前向变量递推 logaddexp。
* **范式层面的对比**（CTC / AED / Transducer）是 ASR 架构面试的必考题，务必能从条件独立、单调性、流式能力三个维度展开。
* **演进**：骨干从 LSTM → Transformer/Conformer/Zipformer；predictor 也出现 FFN 化（SimulRNN-T）、无 predictor（CIF/Paraformer 非自回归路线），但「帧轴 × 标签轴联合」的 Transducer 结构仍是流式工业标准。
