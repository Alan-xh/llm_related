# 1. LSTM-BLSTM 与 LAS

## 1. 概述

在 Transformer 出现之前，**RNN 系架构（LSTM / BLSTM）** 是语音识别编码器的主流选择，而 **LAS（Listen, Attend and Spell）** 则是 2015 年 Google 提出的首个完全端到端的基于注意力的语音识别架构，开创了 AED（Attention-based Encoder-Decoder）范式。

* **LSTM（Long Short-Term Memory, 1997）**：通过门控机制（遗忘/输入/输出门）解决 vanilla RNN 的梯度消失问题，能够建模数百帧级别的长程依赖。
* **BLSTM（双向 LSTM）**：正向与逆向 LSTM 拼接，同时利用左右上下文，是非流式 ASR 编码器的经典配置。
* **LAS（Listen, Attend and Spell, 2015）**：pyramidal BLSTM 编码器 + 注意力解码器，首次抛弃 HMM 与对齐标注，直接完成"音频 -> 文本"的 seq2seq 映射，是 Whisper 等现代 AED 模型的直系祖先。

面试考察重点：LSTM 逐门公式与梯度流动分析（细胞状态的记忆传送带作用）、GRU 与 LSTM 的简化对比、LAS 的 attention 机制与 teacher forcing 训练、以及流式改造的难点。

## 2. 算法架构：LSTM 门控公式逐门推导

### 2.1 从 vanilla RNN 的困境说起

vanilla RNN 的隐状态递推：$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$。沿时间反传时梯度为连乘形式：

$$\frac{\partial h_t}{\partial h_{t-1}} = W_h^{\top} \, \text{diag}\left( 1 - h_t^2 \right)$$

若 $W_h$ 的最大奇异值 $\sigma_{\max} < 1$，梯度随时间步数 $t$ 呈 $\sigma_{\max}^t$ 指数级衰减（梯度消失）；反之爆炸。实践中 tanh 导数有界且多数时候偏小，消失占主导，导致 RNN 实际有效记忆只有 10~20 帧。

### 2.2 LSTM 整体结构

LSTM 引入**细胞状态 $c_t$（cell state）** 作为信息传送带，配合三个 sigmoid 门（输出 0~1，等效开关/阀门）和一个候选记忆：

```
                c_{t-1} ───(×)────(+)──────────────> c_t
                            ▲      │
  忘记什么: f_t ────────────┘      │  tanh(c_t) ──(×) o_t ──> h_t
                              │    │      ▲
  写入多少: i_t ──(×)候选 c̃_t ─(+)  │      │
                              ▲            │
  h_{t-1}, x_t ──> [f_t, i_t, c̃_t, o_t] 四个门并行计算
```

### 2.3 逐门公式推导

设 $h_{t-1} \in \mathbb{R}^d$、$x_t \in \mathbb{R}^m$，拼接 $[h_{t-1}; x_t] \in \mathbb{R}^{d+m}$。四个部件**共享输入、各自独立权重**：

**① 遗忘门（forget gate）-- 决定细胞状态中多少旧记忆被保留：**

$$f_t = \sigma\left( W_f [h_{t-1}; x_t] + b_f \right)$$

$f_t \to 1$ 表示完全保留历史，$f_t \to 0$ 表示完全遗忘。初始化技巧：将 $b_f$ 初始化为 +1 ~ +2，使训练初期 $f_t \approx 1$，细胞倾向长期记忆。

**② 输入门（input gate）-- 决定多少新信息写入细胞：**

$$i_t = \sigma\left( W_i [h_{t-1}; x_t] + b_i \right)$$

**③ 候选细胞状态 -- 当前输入产生的新记忆内容：**

$$\tilde{c}_t = \tanh\left( W_c [h_{t-1}; x_t] + b_c \right)$$

**④ 细胞状态更新 -- 旧记忆衰减 + 新记忆写入（核心传送带公式）：**

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$

其中 $\odot$ 为逐元素乘。**⑤ 输出门（output gate）-- 决定细胞状态中多少被暴露为隐状态：**

$$o_t = \sigma\left( W_o [h_{t-1}; x_t] + b_o \right)$$

**⑥ 隐状态输出：**

$$h_t = o_t \odot \tanh(c_t)$$

参数量核算：四个门各 $(d+m) \times d$ 权重 + $d$ 偏置，共 $4d(d+m+1)$。典型 $d=512, m=80$ 时约 $4 \times 512 \times 593 \approx 121$ 万参数/层，是同宽度 RNN 的 4 倍。

### 2.4 梯度流动分析：为何缓解梯度消失

对细胞状态递推式求梯度：

$$\frac{\partial c_t}{\partial c_{t-1}} = \text{diag}(f_t) + \underbrace{\frac{\partial f_t}{\partial c_{t-1}} \odot c_{t-1} + \frac{\partial i_t}{\partial c_{t-1}} \odot \tilde{c}_t + i_t \odot \frac{\partial \tilde{c}_t}{\partial c_{t-1}}}_{\text{间接项，权重小可忽略}}$$

主通路是 $\text{diag}(f_t)$--**加性更新 + 元素级门控乘法**取代了 RNN 的矩阵连乘。当 $f_t \approx 1$ 时该 Jacobian 近似单位阵，梯度跨时间步**近乎无衰减地线性流动**（类似 ResNet 的恒等捷径）。梯度的"保留比例"由可学习的 $f_t$ 自适应控制：需要长记忆的时刻 $f_t$ 自动变大，信息不重要时变小截断。这正是 LSTM 能建模 200+ 帧（2 秒以上）依赖的根源。

## 3. GRU 简化对比与 BLSTM

### 3.1 GRU：三个门变两个门

GRU（Gated Recurrent Unit, 2014）合并了细胞状态与隐状态，去掉输出门，用**更新门 $z_t$ 同时承担遗忘与写入**（二者互补，$1 - z_t$ 直接出现在写入项中），并引入**重置门 $r_t$ 控制候选状态对历史的依赖**：

$$z_t = \sigma(W_z [h_{t-1}; x_t]), \qquad r_t = \sigma(W_r [h_{t-1}; x_t])$$

$$\tilde{h}_t = \tanh(W [r_t \odot h_{t-1}; x_t]), \qquad h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

| 维度 | LSTM | GRU |
| --- | --- | --- |
| 门数量 | 3（f/i/o）+ 候选 | 2（z/r）+ 候选 |
| 状态 | $h_t$ 与 $c_t$ 分离 | 单一 $h_t$ |
| 参数量 | $4d(d+m+1)$ | $3d(d+m+1)$（省约 25%） |
| 遗忘/写入耦合 | 独立（$f_t$、$i_t$ 可同时大或小） | 互补强制（保留旧 = 少写新） |
| 记忆容量与表达力 | 略强（任务大数据多时占优） | 略弱（小数据/低延迟场景占优） |

经验：语音识别编码器两者精度差距通常在 0.3% CER 以内；GRU 参数少 25%、单步计算少一次逐元素乘，端侧推理更常用；LAS 原文使用 LSTM。

### 3.2 BLSTM 双向拼接

正向 LSTM 从 $t=1 \to T$ 读入，逆向 LSTM 从 $t=T \to 1$ 读入，两个方向的隐状态拼接：

$$\overrightarrow{h_t} = \text{LSTM}^f(x_1, \dots, x_t), \qquad \overleftarrow{h_t} = \text{LSTM}^b(x_T, \dots, x_t)$$

$$h_t = [\overrightarrow{h_t}; \overleftarrow{h_t}] \in \mathbb{R}^{2d}$$

双向拼接使每帧表征同时包含左右上下文，**同一帧的声学歧义（如同音不同字）可被后文消解**，非流式 ASR 中 BLSTM 比单向 LSTM 的词错率典型低 10%~20% 相对值。代价是**逆向支路必须等整句（或整个 chunk）输入完毕**，这是 LAS 非流式的根源，也是后续流式改造的主攻点。

## 4. 算法架构：LAS（Listen, Attend and Spell）

### 4.1 整体结构

```
  Fbank X (T x 80, T 约 800~1200)
       │
  ┌────▼────────────────────┐  3 层 pyramidal BLSTM
  │  Listener (Encoder)     │  每层时间减半: T -> T/2 -> T/4 -> T/8
  │  h_1..h_S  (S = T/8)    │  帧移等效从 10ms 增至 80ms
  └────┬────────────────────┘
       │
       │          y_{u-1} (上一输出 token)
       │                │
  ┌────▼────────────────▼────┐
  │  Attention               │  s_u = Attn(q=s'_{u-1}, K=H, V=H)
  │  context c_u (2d 维)      │  (原文为 additive/内容注意力)
  └────┬────────────────────┘
       │  [s'_{u-1}; c_u]
  ┌────▼────────────────────┐
  │  Speller (2 层 LSTM)     │  s_u = LSTM([s'_{u-1}; c_u])
  └────┬────────────────────┘
       │
  ┌────▼────────────────────┐
  │  Char Softmax           │  P(y_u | y_{<u}, X)
  └─────────────────────────┘
```

### 4.2 Listener：Pyramidal BLSTM 编码器

标准 BLSTM 编码 1000 帧音频的 attention 计算成本高且对齐搜索空间大。金字塔 BLSTM 在层间做时间维**下采样**：第 $l$ 层的输入是把第 $l-1$ 层输出沿时间**每 2 帧拼接**：

$$h_t^{(l)} = \text{BLSTM}^{(l)}\left( [h_{2t-1}^{(l-1)}; h_{2t}^{(l-1)}] \right)$$

3 层金字塔后序列长度 $T \to T/8$（1000 帧 -> 125 步），后续 attention 的键值对数量降为 1/8，注意力更容易学出单调对齐，也缓解了长音频注意力退化解（attention 总盯着少数几帧）的问题。这与现代 Conformer/Whisper 用卷积下采样 4 倍的动机完全一致。

### 4.3 Attention 机制详解

LAS 原文使用 **additive attention（Bahdanau）**，并以解码器上层状态 $s'_{u-1}$ 为 query（还支持上一层注意力的动态加权，用于刻画对齐的单调性）：

$$e_{u,t} = v^{\top} \tanh\left( W_s s'_{u-1} + W_h h_t + b \right), \qquad \alpha_{u,t} = \frac{\exp(e_{u,t})}{\sum_{t'} \exp(e_{u,t'})}$$

$$c_u = \sum_{t=1}^{S} \alpha_{u,t} \, h_t$$

注意力权重 $\alpha_{u,t}$ 起到了**隐式软对齐**的作用：生成第 $u$ 个字符时，注意力峰值应对应发音所在帧--LAS 无需任何显式对齐标注（对比 CTC/RNN-T 需要空白符机制），对齐关系完全从数据中学出。

### 4.4 Speller 与 teacher forcing 训练

Speller 为 2 层 LSTM：输入是 $[s'_{u-1}; c_u]$（上一解码状态拼接注意力上下文），输出经 softmax 得到字符分布（词表含字母 + 空格 + 标点，通常 30~50 类）。

训练时使用 **teacher forcing**：解码器每一步的输入用**真实标签 $y_{u-1}^*$** 而非模型自己的 argmax 预测：

$$P(Y \mid X) = \prod_{u=1}^{U} P(y_u \mid y_{<u}^{\text{gt}}, X)$$

优点：训练稳定收敛快（避免早期错误滚雪球）、每一步都有有效梯度。缺点：**训练/推理曝光偏差（exposure bias）**--推理时只能喂自己上一步的预测，错误会沿自回归链传播。缓解手段：scheduled sampling（训练中按概率用模型输出替代真值）、label smoothing。

## 5. 目标函数：seq2seq 似然

LAS 的目标是最大化给定音频条件下目标文本的自回归条件似然：

$$P(Y \mid X) = \prod_{u=1}^{U} P(y_u \mid y_{1:u-1}, X)$$

这个目标函数的关键性质：

1. **无对齐假设**：不像 CTC 需要对所有对齐路径求和（条件独立 + 前向-后向），LAS 直接对文本序列建模，注意力自己隐式决定对齐；
2. **内置语言模型**：$P(y_u \mid y_{<u}, X)$ 中的 $y_{<u}$ 依赖使解码器天然是一个条件语言模型，训练数据中文本可以独立于音频扩充（外部 LM 融合仅需浅融合即可起效）；
3. **条件化逐步进行**：每步条件同时含声学（经 $c_u$）与文本历史，这也是 RNN-T 借鉴的"声学 + 语言双通道"思想的来源。

## 6. 损失函数：attention CE 与 coverage penalty

### 6.1 基础损失：逐字符交叉熵

对整个训练集，损失为负对数似然，即每步字符分布的交叉熵求和再平均：

$$\mathcal{L}_{\text{LAS}} = -\frac{1}{U} \sum_{u=1}^{U} \log P(y_u^{\text{gt}} \mid y_{<u}^{\text{gt}}, X)$$

标签平滑（label smoothing，$\epsilon = 0.1$）几乎总是与 CE 同用：目标分布从 one-hot 变为 $(1-\epsilon)$ 给真类、$\epsilon$ 均分给其余类，防止 softmax 过度自信，对 attention 收敛尤其重要。

### 6.2 Coverage penalty（覆盖惩罚）

长音频上注意力可能出现**重复注意（重复生成、跳跃漏词）或覆盖不足**。coverage penalty 在**解码打分阶段**对"注意力总量"施加软约束，鼓励每个音频帧被恰好注意一次：

$$\text{CP}(Y, X) = \beta \sum_{t=1}^{S} \min\left( \sum_{u=1}^{U} \alpha_{u,t}, \, 1 \right)$$

$$\text{score}(Y) = \log P(Y \mid X) + \text{CP}(Y, X)$$

直觉：理想对齐下 $\sum_u \alpha_{u,t} \approx 1$（每帧恰好覆盖一次）；某帧累计注意力超过 1 说明被重复注意，$\min(\cdot, 1)$ 截断后超出部分不再得分；未被覆盖的帧则拉低总分。$\beta$（如 0.2~0.5）平衡两项。训练阶段也可用显式 coverage 损失 $\mathcal{L}_{\text{cov}} = \sum_{u,t} \alpha_{u,t} \cdot \text{sg}(\sum_{u'<u} \alpha_{u',t})$，惩罚"已覆盖区域再次被注意"。

### 6.3 PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class PyramidalBLSTM(nn.Module):
    """LAS Listener: 3 层金字塔 BLSTM, 每层时间下采样 2 倍"""
    def __init__(self, input_dim=80, hidden=256, num_layers=3, dropout=0.2):
        super().__init__()
        self.layers = nn.ModuleList()
        in_dim = input_dim
        for _ in range(num_layers):
            # 输入时间减半靠 forward 里拼接相邻 2 帧实现 (维度 x2)
            self.layers.append(nn.LSTM(in_dim * 2, hidden, bidirectional=True,
                                       batch_first=True, dropout=dropout))
            in_dim = hidden * 2

    def forward(self, x, lens):                      # x: [B, T, D]
        for lstm in self.layers:
            B, T, D = x.shape
            if T % 2: x = x[:, :-1]                  # 丢尾部 1 帧保证可整除
            x = x.reshape(B, T // 2, D * 2)          # 相邻 2 帧拼接: 时间减半
            x, _ = lstm(x)                           # [B, T/2, 2H]
            lens = torch.div(lens, 2, rounding_mode="floor")
        return x, lens                               # [B, T/8, 2H]


class LAS(nn.Module):
    def __init__(self, input_dim=80, enc_hidden=256, dec_hidden=256, vocab=50):
        super().__init__()
        self.listener = PyramidalBLSTM(input_dim, enc_hidden)
        self.embed = nn.Embedding(vocab, 128)
        self.att_W_s = nn.Linear(dec_hidden, dec_hidden, bias=False)
        self.att_W_h = nn.Linear(enc_hidden * 2, dec_hidden, bias=True)
        self.att_v   = nn.Linear(dec_hidden, 1, bias=False)
        self.cell1 = nn.LSTMCell(128 + enc_hidden * 2, dec_hidden)   # 注意力 RNN
        self.cell2 = nn.LSTMCell(dec_hidden + enc_hidden * 2, dec_hidden)  # 主 RNN
        self.out = nn.Linear(dec_hidden, vocab)

    def _attend(self, q, enc_out, enc_mask):
        e = self.att_v(torch.tanh(self.att_W_h(enc_out) + self.att_W_s(q).unsqueeze(1)))
        e = e.squeeze(-1).masked_fill(enc_mask, -1e9)
        alpha = F.softmax(e, dim=-1)                 # [B, S]
        ctx = torch.bmm(alpha.unsqueeze(1), enc_out).squeeze(1)   # [B, 2H]
        return ctx, alpha

    def forward(self, x, lens, y_in):                # y_in: teacher forcing 输入(含<sos>)
        enc_out, enc_lens = self.listener(x, lens)   # [B, S, 2H]
        S = enc_out.size(1)
        enc_mask = torch.arange(S, device=x.device).unsqueeze(0) >= enc_lens.unsqueeze(1)

        emb = self.embed(y_in)                       # [B, U, 128]
        h1 = c1 = h2 = c2 = None
        logits_list, alpha_list = [], []
        for u in range(emb.size(1)):
            y_u = emb[:, u]
            # 第一步: 用上一主 RNN 状态 h2 计算注意力
            q = h2 if h2 is not None else torch.zeros_like(y_u.new_zeros(
                                        (y_u.size(0), self.cell1.hidden_size),
                                        dtype=enc_out.dtype))
            ctx, alpha = self._attend(q, enc_out, enc_mask)
            h1, c1 = self.cell1(torch.cat([y_u, ctx], -1),
                                (h1, c1) if h1 is not None else
                                (torch.zeros_like(q), torch.zeros_like(q)))
            ctx2, alpha = self._attend(h1, enc_out, enc_mask)   # 再算一次注意力
            h2, c2 = self.cell2(torch.cat([h1, ctx2], -1),
                                (h2, c2) if h2 is not None else
                                (torch.zeros_like(q), torch.zeros_like(q)))
            logits_list.append(self.out(h2))
            alpha_list.append(alpha)
        return torch.stack(logits_list, dim=1), torch.stack(alpha_list, dim=1)
        # logits: [B, U, V];  alpha: [B, U, S]


def las_loss(logits, alpha, targets, enc_out, label_smooth=0.1):
    """attention CE (含 label smoothing) + 简化版 coverage 正则"""
    B, U, V = logits.shape
    # 1) 逐字符交叉熵 + label smoothing
    log_p = F.log_softmax(logits, dim=-1)
    nll = -log_p.gather(-1, targets.unsqueeze(-1)).squeeze(-1)      # [B, U]
    smooth = -log_p.mean(dim=-1)                                    # 均匀部分
    ce = ((1 - label_smooth) * nll + label_smooth * smooth).sum(-1).mean()

    # 2) coverage 正则: 惩罚累计覆盖 > 1 的帧 (训练期软约束)
    cov = alpha.sum(dim=1)                                          # [B, S] 每帧累计注意力
    coverage = (torch.minimum(cov, torch.ones_like(cov))).sum(-1).mean() / enc_out.size(1)
    return ce - 0.2 * coverage, ce


if __name__ == "__main__":
    B, T, U, V = 4, 800, 30, 50
    model = LAS()
    x = torch.randn(B, T, 80)
    lens = torch.tensor([800, 760, 720, 640])
    y_in = torch.randint(0, V, (B, U))
    logits, alpha = model(x, lens, y_in)
    loss, ce = las_loss(logits, alpha, y_in, None)
    print(f"logits: {logits.shape}, alpha: {alpha.shape}")   # [4,30,50], [4,30,100]
    print(f"total loss: {loss.item():.4f}, CE: {ce.item():.4f}")
```

## 7. 流式局限与受限双向改造

### 7.1 非流式的根源

LAS 的三个组件都依赖"看完整句"：

1. **逆向 LSTM**：每帧隐状态依赖未来帧；
2. **全局 attention**：softmax 在全部 $S$ 个编码帧上归一化，生成第一个字符前就需读完全部编码；
3. **pyramidal 下采样**：拼接 2 帧的操作在层间累积，末层每一格都含未来信息。

因此 LAS 原文即为非流式设计，延迟等于整句时长 + 解码时间。

### 7.2 受限双向（limited/chunk-based bi-directionality）改造

工业界主流改造思路是**限制双向上下文的未来窗口**：

* **Chunk-based BLSTM**：把音频切成定长 chunk（如 640 ms），BLSTM 只在 chunk 内双向，chunk 间用携带状态（state carrying）的单向 LSTM 传递历史，右看时长被压到 chunk 内（最长一个 chunk）。chunk 越小延迟越低、精度损失越大，典型 chunk=40 帧 + 左上下文 80 帧时相对精度损失 3%~8%。
* **延迟受控训练（delayed feedback / lookahead）**：人为把编码器输入整体右移 $d$ 帧，等效"只允许看未来 $d$ 帧"，实现简单且延迟恒定为 $d \times 10$ ms。
* **注意力改造**：单调注意力（Monotonic Attention、MMA）把 softmax 滑窗化/单调化，使解码可以随编码增量进行。
* **体系性替代**：上述改造均属补丁性质，这是 RNN-T / Chunk-based Conformer 被设计出来的直接动机--在架构层面原生支持流式。

---

## 8. 总结

* **LSTM 核心**：细胞状态 $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$ 是加性传送带；梯度主通路 $\partial c_t / \partial c_{t-1} \approx \text{diag}(f_t)$，$f_t \approx 1$ 时梯度无衰减回传，从机制上缓解了 RNN 的梯度消失。
* **GRU**：两门（更新 $z_t$ + 重置 $r_t$）、单状态、参数省 25%，精度与 LSTM 接近，端侧更常用。
* **BLSTM**：双向拼接让每帧看到全句上下文，非流式精度显著优于单向，但逆向前提使其天然非流式。
* **LAS**：pyramidal BLSTM 编码器（T/8 降帧）+ additive attention 隐式软对齐 + LSTM 自回归解码 + teacher forcing 训练；目标函数为 seq2seq 自回归似然，损失为逐字符 CE（+ label smoothing），解码打分可加 coverage penalty 抑制重复/漏注意。
* **历史地位**：LAS 确立了 AED 范式（Whisper 是其现代放大版），其"编码器降帧 + 注意力 + 自回归解码"三件套与曝光偏差、非流式两大缺陷，直接催生了后续 scheduled sampling、单调注意力与 RNN-T 等一系列经典工作。
