# 1. 必读论文清单

## 1. 概述

语音算法岗的面试本质上是「论文理解深度 + 工程复现能力」的双重考核。本清单按主题分类整理语音领域必读论文，每篇给出**论文名 / 年份 / 机构 / 一句话核心贡献 / 面试考点**，并按阅读优先级分为三档：

* **入门必读**：构成语音技术知识骨架的奠基性工作，面试前必须能脱稿讲清动机、方法与缺陷；
* **进阶**：在入门基础上扩展深度（流式优化、编解码器、融合策略），中高级岗位与论文深挖面试的核心；
* **前沿追踪**：语音大模型时代的最新方向，用于展示技术视野与趋势判断。

```
阅读路径建议:

入门必读 (骨架: CTC/RNN-T/Conformer/Whisper + Tacotron/FastSpeech + Conv-TasNet/ECAPA)
   │
   ├──> 进阶 (深度: Zipformer/流式/Codec/VALL-E/ILME/DPO)
   │
   └──> 前沿追踪 (视野: Audio-LLM / 全双工 / 大规模多语种 / 上下文感知 ASR)
```

| *Deep Speech* (Hannun et al.) | 2014 | Baidu | 首个大规模纯端到端 CTC 系统，RNN+CTC 从频谱直接到字符 | CTC 工程化细节、N-gram WFST 解码融合 |

## 6. 论文阅读方法论（面试向）

| 步骤 | 关注点 | 面试转化 |
| --- | --- | --- |
| 1. 动机 | 解决了什么痛点？前作缺陷是什么？ | 「为什么需要这篇论文」是面试官最爱问的开场 |
| 2. 方法主干 | 核心公式/结构图能否白板推出？ | 手推 CTC/RNN-T 前向、AAM-Softmax、RVQ 是硬门槛 |
| 3. 实验 | 消融实验说明了每个组件的必要性？ | 用消融数据支撑自己的观点更显功底 |
| 4. 缺陷与后继 | 局限是什么？后续谁改进了它？ | 体现批判性思维（如 Whisper 幻觉 -> Distil/VAD 修复） |
| 5. 复现 | 用 icefall/espnet 跑通配方 | 「我复现过」是最强加分项 |

## 7. 总结

* **第一优先级**：CTC / RNN-T / Conformer / Whisper 四篇是所有语音算法岗的共同语言，务必脱稿讲透；TTS 的 Tacotron -> FastSpeech 链路、分离的 Conv-TasNet、声纹的 ECAPA 构成跨方向基础词汇。
* **第二优先级**：Zipformer/流式优化（工业岗高频）、SoundStream/EnCodec/DAC（大模型时代通用底座）、VALL-E/CosyVoice（语音生成前沿）、ILME（LM 融合深水区）、DPO（对齐基础）。
* **第三优先级**：Audio-LLM（SALMONN/Qwen-Audio/Moshi）与工业新范式（Seed-ASR/SenseVoice）用于展示视野，重点理解「Codec Token + LLM」这一统一范式而非逐篇细读。
* **配套实践**：每个方向至少跑通一个开源配方（icefall 的 Zipformer-Transducer、FunASR 的 Paraformer、espnet 的 Conformer Hybrid），论文 + 代码互证才是面试的最强护城河。
